# Culture Page Schema (Extended)

**Base spec**: see `AGENTS.md` §"Culture Pages"
**This document**: 게임 스테이지 도입부/엔딩, NPC 대사, 시나리오용 확장

## Full Template

```markdown
# {Cultural Topic}

**Type:** social-ritual | dining | romance | workplace | family | festival | etiquette | taboo

**Overview:** [Brief description — 2-3 sentences]

**Setting:** [Where this happens — e.g., "도쿄 신주쿠의 izakaya, 저녁 7시"]

**Roles:** [Participants in the cultural scenario]
- 1) 손님 (customer)
- 2) 점원 (server)
- 3) 옆자리 손님 (neighboring diner)

**Scenario:** [Step-by-step flow — what happens from start to end]
1. **인사와 자리 잡기** (greeting and seating)
2. **주문** (ordering)
3. **건배** (toast)
4. **대화** (small talk)
5. **계산** (paying)
6. **헤어짐** (leaving)

**Cultural Insight:** [What native speakers know, learners don't]
- [Important social rule 1]
- [Important social rule 2]
- [What "looks weird" if broken]

**Useful Phrases:**
- [[乾杯]] — 건배 (Kanpai!)
- [[お会計]] — 계산 (Okaikei, check please)
- [[ありがとうございました]] — 감사합니다 (Arigatou gozaimashita)

**What NOT to Do:**
- ❌ [Common foreigner mistake 1]
- ❌ [Common foreigner mistake 2]

**Body Language:**
- [Gesture 1] → [Meaning]
- [Gesture 2] → [Meaning in this culture]

**Cross-Reference:**
- Compare with: [[korean-dining-etiquette]], [[american-dining-etiquette]]
- See also: [[romance-conversation-starters]] (if relevant to topic)

## Sources

- [[source-1]]
- [[source-2]]
```
