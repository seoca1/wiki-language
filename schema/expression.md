## Pattern Notation by Language

### Spanish (ES)
- Verb mood: `indicativo` / `subjuntivo` / `imperativo` / `infinitivo`
- Tense: `presente` / `pretérito` / `imperfecto` / `futuro` / `condicional`
- Pronoun context: `tú` / `usted` / `vosotros` / `vos` / `ustedes`

### Japanese (JP)
- Verb form: `て形` / `辞書形` / `ます形` / `ない形` / `た形` / `ば形`
- Politeness: `普通形` / `丁寧形` / `敬語`
- Noun + particle: `N + を` / `N + に` / etc.

### Korean (KR)
- Speech level: `해요체` / `합쇼체` / `해체` / `하소서체`
- Honorific markers: `(으)시` for subject honorific
- Sentence endings: `-습니다/-어요/-어` etc.

### English (EN)
- Phrasal: `verb + particle(s)`
- Tense: `present` / `past` / `future` / `present perfect`
- Aspect: `simple` / `continuous` / `perfect`
