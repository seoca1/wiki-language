# technology vocabulary - 기술 어휘 (Spanish → Korean Translation)

**Overview:** 스페인어 기술 어휘의 한국어 번역본. 일상 디지털 생활에서 자주 사용되는 필수 단어 모음.

### computadora (컴퓨터)

**Part of Speech:** 명사 (여성, f)

**Definition:** 컴퓨터 — 스페인어 여성 명사 (라틴아메리카). 한국어 한자어 "컴퓨터" / 차용어 "computadora".

**Pronunciation / IPA:** /kom.pu.taˈðo.ɾa/

**Etymology:** "computar" (계산하다) + "-dora" → 스페인어 "computadora". 라틴어 "computare". 한국어 차용어 "컴퓨터" 동일.

#### 예문

- Uso la **computadora** para trabajar. — 일할 때 **컴퓨터**를 사용해요.

#### 관련 용어

- Related: [[technology-vocabulary]]
- ordenador (컴퓨터, 스페인)
- PC (개인용 컴퓨터)

#### 문화적 맥락

스페인어 "computadora" = 라틴아메리카, "ordenador" = 스페인. 한국어 "컴퓨터" 동일. 스페인어 "computadora" 발음: /kom.pu.taˈðo.ɾa/ (스페인) vs /kom.pu.taˈdo.ɾa/ (라틴아메리카). 영어 "computer" ↔ 스페인어 "computadora" / 한국어 "컴퓨터".

### teléfono (전화)

**Part of Speech:** 명사 (남성, m)

**Definition:** 전화 — 스페인어 남성 명사. 한국어 한자어 "전화(電話)"와 의미 동일.

**Pronunciation / IPA:** /teˈle.fo.no/

**Etymology:** 그리스어 "tēle" (먼) + "phōnē" (소리) → 라틴어 → 스페인어 "teléfono". 한국어 한자어 "전" = 電, "화" = 話.

#### 예문

- Mi **teléfono** es nuevo. — 내 **전화**는 새로워요.

#### 관련 용어

- Related: [[technology-vocabulary]]
- móvil (모바일)
- fijo (유선 전화)

#### 문화적 맥락

스페인어 "teléfono"은 일반. 한국어 "전화" 동일. 영어 "telephone" ↔ 스페인어 "teléfono" / 한국어 "전화". 스페인어 "teléfono" 발음: /teˈle.fo.no/.

### correo electrónico (이메일)

**Part of Speech:** 명사 (남성, m)

**Definition:** 이메일 — 스페인어 일반 명사 "correo" (우편) + "electrónico" (전자의). 한국어 한자어 "전자우편(電子郵便)" / 차용어 "이메일".

**Pronunciation / IPA:** /koˈre.o e.lekˈtɾo.ni.ko/

**Etymology:** "correo" (우편) + "electrónico" (전자의) → 스페인어 "correo electrónico" (전자 우편 = 이메일). 한국어 한자어 "전자" = 電, "우" = 郵, "편" = 便.

#### 예문

- Reviso el **correo** cada día. — 매일 **이메일**을 확인해요.

#### 관련 용어

- Related: [[technology-vocabulary]]
- email (이메일, 영어 차용)
- correo (우편)

#### 문화적 맥락

스페인어 "correo electrónico"은 일반. 한국어 "이메일" / "전자우편" 동일. 영어 "email" ↔ 스페인어 "correo electrónico" (완전 번역) / "email" (차용어) / 한국어 "이메일". 스페인어 "email"도 사용하지만 공식적 표현은 "correo electrónico" 또는 약식 "e-mail".

#### 출처

**Pronunciation / IPA:** /ˈsi.tjo web/

**Etymology:** "sitio" (장소) + "web" (거미줄/웹) → 스페인어 "sitio web". 한국어 차용어 "웹사이트" 동일.

#### 예문

#### 관련 용어

- Related: [[technology-vocabulary]]
- página web (웹페이지)
- web (웹)

#### 문화적 맥락

스페인어 "sitio web"은 일반. 한국어 "웹사이트" 동일. 스페인어 "página web" (웹페이지) / "sitio web" (웹사이트, 여러 페이지) 구별. 영어 "website" ↔ 스페인어 "sitio web" / 한국어 "웹사이트". 한국어 학습자에게 발음 연습.

### aplicación (앱)

**Part of Speech:** 명사 (여성, f)

**Definition:** 앱 (응용 프로그램) — 스페인어 차용어 "aplicación" (응용). 한국어 "앱" (차용어) / "응용 프로그램".

**Pronunciation / IPA:** /a.pli.kaˈθjon/ (스페인) /a.pli.kaˈsjon/ (라틴아메리카)

**Etymology:** 라틴어 "applicare" (접목하다) → 스페인어 "aplicación". 한국어 차용어 "앱" 동일.

#### 예문

- Descargué una **aplicación** nueva. — 새 **앱**을 다운로드했어요.

#### 관련 용어

- Related: [[technology-vocabulary]]
- app (앱, 영어 차용)
- programa (프로그램)

#### 문화적 맥락

스페인어 "aplicación"은 일반. 한국어 "앱" 동일. 스페인어 "aplicación"은 길고 정식, "app" 짧고 비격식. 영어 "application" / "app" ↔ 스페인어 "aplicación" / "app" / 한국어 "앱". 한국어 학습자에게 스페인어 "app" 차용어 사용 가능.

### contraseña (비밀번호)

**Part of Speech:** 명사 (여성, f)

**Definition:** 비밀번호 — 스페인어 여성 명사. 한국어 한자어 "비밀번호(秘密番號)"와 의미 동일.

**Pronunciation / IPA:** /kon.tɾaˈse.ɲa/

**Etymology:** "contra-" (~에 반대) + "seña" (신호/표시) → 스페인어 "contraseña" (반대 신호 = 비밀번호). 한국어 한자어 "비" = 秘密, "번" = 番號.

#### 예문

- Olvidé mi **contraseña**. — 내 **비밀번호**를 잊어버렸어요.

#### 관련 용어

- Related: [[technology-vocabulary]]

- PIN (개인 식별 번호)

#### 문화적 맥락

스페인어 "contraseña"는 일반. 한국어 "비밀번호" 동일. 스페인어 "contraseña" 발음: /kon.tɾaˈse.ɲa/ (스페인) vs /kon.tɾaˈse.ɲa/ (라틴아메리카). 영어 "password" ↔ 스페인어 "contraseña" / 한국어 "비밀번호".

### ratón (마우스)

**Part of Speech:** 명사 (남성, m)

**Definition:** 마우스 — 스페인어 남성 명사 (쥐 의미도 포함). 한국어 차용어 "마우스" 동일.

**Pronunciation / IPA:** /raˈton/

**Etymology:** 라틴어 "ratto" → 고대 프랑스어 "raton" → 스페인어 "ratón" (쥐). 컴퓨터 장치로 사용 시 형태 유사 어원. 한국어 차용어 "마우스" 동일.

#### 예문

- El **ratón** está roto. — **마우스**가 고장났어요.

#### 관련 용어

- Related: [[technology-vocabulary]]
- mousepad (마우스 패드)
- click (클릭)

#### 문화적 맥락

스페인어 "ratón"은 "쥐" + "마우스" 의미. 한국어 "마우스" / "쥐" 구별. 스페인어 "ratón" 발음: /raˈton/. 영어 "mouse" ↔ 스페인어 "ratón" / 한국어 "마우스" / "쥐". 한국어 학습자에게 발음 연습.
