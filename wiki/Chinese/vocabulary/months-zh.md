| 3월 | 三月 (sān yuè) | 3 + 월 |
| 4월 | 四月 (sì yuè) | 4 + 월 |
| 5월 | 五月 (wǔ yuè) | 5 + 월 |
| 6월 | 六月 (liù yuè) | 6 + 월 |
| 7월 | 七月 (qī yuè) | 7 + 월 |

> **핵심**: 한국어 "일월, 이월..." = 중국어 "숫자 + 월" — **완전 동일 구조**

| 한국어 | 중국어 | 비고 |

> **비고**: 한국어 "월 일" = 중국어 "月 日" 어순 동일

| 2024년 1월 15일 | 2024年1月15日 (nián yuè rì) | 년-월-일 순서 동일 |

| 한국어 | 중국어 | 비고 |
|--------|--------|------|
| 1달 | 一个月 (yí gè yuè) | 个 (gè) 카운터 필수 |
| 2달 | 两个月 (liǎng gè yuè) | 两 (liǎng) + 个 + 월 |
| 3달 | 三个月 (sān gè yuè) | 개 + 월 |

## 7. 한국어 학습자 필수 팁 (Key Tips for Korean Learners)

### 1. 月 (yuè) = "월/달" — 핵심 단어
- 一月 ~ 十二月 — 1~12월
- 月 (yuè) = 월/달 — 핵심 단어

### 2. 월 + 일 순서 동일 (Month + Day Order Same)
- 한국어: "1월 1일"
- 중국어: 一月一日 (yī yuè yī rì) — 어순 동일!

### 3. 년-월-일 순서 동일 (Year-Month-Day Order Same)
- 한국어: "2024년 1월 15일"
- 중국어: 2024年1月15日 (nián yuè rì) — 순서 동일!

### 4. 월 카운터 个 (gè) 필수
- 한 달 = 一个月 (yí gè yuè)
- 두 달 = 两个月 (liǎng gè yuè) — 两 (liǎng) 필수
- 세 달 = 三个月 (sān gè yuè)
- 여섯 달 = 六个月 (liù gè yuè)

### 5. 음력/양력 구별 필수 (Lunar/Solar Distinction Critical)
- 양력 = 阳历 (yáng lì) / 公历 (gōng lì)
- 음력 = 阴历 (yīn lì) / 农历 (nóng lì)
- 설날 = 春节 (chūn jié) = 음력 1월 1일
- 생일: 양력/음력 구분해서 말하기

## 8. 필수 문장 패턴 (Essential Sentence Patterns)

### 월 묻기/대답
- 现在几月? — 지금 몇 월이에요?
- 现在一月 — 지금 1월이에요
- 几月几号? — 몇 월 며칠이에요?
- 一月一日 — 1월 1일

### 생일/기념일
- 你生日几月? — 생일 몇 월이에요?
- 我生日五月二十日 — 제 생일 5월 20일이에요
- 农历生日 / 阳历生日 — 음력/양력 생일 구분

### 계절/달 관련
- 现在几月? — 지금 몇 월이에요?
- 现在三月 — 지금 3월이에요
- 春天是三月到五月 — 봄은 3월부터 5월까지

### 날짜 예약/약속
- 我们十月十五日见吧 — 10월 15일에 봅시다
- 下个月见 — 다음 달에 봅시다
- 这个月月底 — 이달 말
- 下个月初 — 다음 달 초

## 9. 한국어 학습자 주의 (Pitfalls)

| 실수 | 올바른 표현 | 설명 |
|------|-------------|------|
| 1달 | 一个月 (O) / 一月 (X) | 개수 셀 때 个 필수 |
| 2달 | 两个月 (O) / 二个月 (X) | 两 (liǎng) + 개 필수 |
| 1월 1일 | 一月一日 (O) | 월 + 일 순서 동일 |
| 2024년 1월 | 2024年一月 (O) | 년 + 월 순서 동일 |
| 음력 설날 | 春节 (O) / 过年 (△) | 春节 = 정식, 过年 = 구어 |
| 양력 생일 | 阳历生日 / 公历生日 (O) | 구분 필수 |
| 음력 생일 | 农历生日 (O) | 구분 필수 |

## 10. 문화적 배경 (Cultural Notes)

### 1. 24절기 (24 Solar Terms)
중국 전통 농사력 기반 24절기 (節氣, jié qì):
- 입춘(立春), 우수(雨水), 경칩(惊蛰), 춘분(春分), 청명(清明), 곡우(穀雨)
- 입하(立夏), 소만(小满), 망종(芒种), 하지(夏至), 소서(小暑), 대서(大暑)
- 입추(立秋), 처서(处暑), 백로(白露), 추분(秋分), 한로(寒露), 상강(霜降)
- 입동(立冬), 소설(小雪), 대설(大雪), 동지(冬至), 소한(小寒), 대한(大寒)

### 2. 주요 명절과 월
- 春节 (chūn jié) — 음력 1월 1일 (설날, 최대 명절)
- 元宵节 (yuán xiāo jié) — 정월 대보름 (음력 1월 15일)
- 清明节 (qīng míng jié) — 청명절 (양력 4월 4-6일)
- 端午节 (duān wǔ jié) — 단오절 (음력 5월 5일)
- 中秋节 (zhōng qiū jié) — 추석/중추절 (음력 8월 15일)
- 国庆节 (guó qìng jié) — 국경절 (양력 10월 1일)

### 3. 월별 별칭 (Traditional Month Names)
- 正月 (zhēng yuè) = 음력 1월 (정월)
- 杏月 (xìng yuè) = 2월 (살구꽃 달)
- 桃月 (táo yuè) = 3월 (복숭아꽃 달)
- 梅月 (méi yuè) = 4월 (매화 달)
- 榴月 (liú yuè) = 5월 (석류꽃 달)
- 荷月 (hé yuè) = 6월 (연꽃 달)
- 兰月 (lán yuè) = 7월 (난초 달)
- 桂月 (guì yuè) = 8월 (계수나무 달)
- 菊月 (jú yuè) = 9월 (국화 달)
- 良月 (liáng yuè) = 10월 (좋은 달)
- 冬月 (dōng yuè) = 11월 (겨울 달)
- 腊月 (là yuè) = 12월 (납월/섣달)
