# 颜色 (Chinese Colors)

**Source:** [[colors-zh]]
**Theme:** 颜色
**Level:** HSK 1-2

中文颜色词汇。韩国 한자어와 매우 비슷 — 뜻은 거의 동일, 발음만 다름. 색깔 + 的 + 명사 패턴 학습 필수.

## 기본 색깔 (Basic Colors)

### 红色 (hóngsè)

**品词:** 명사/형용사 (noun/adjective)

**정의:** 빨강, 빨간색

**병음:** hóng sè (2성 + 4성)

**어원:** 红 (hóng, 빨강) + 色 (sè, 색깔). 형용사 사용 시 + 的 (de). 한국 한자음 "적" ≠ 중국 "hóng".

#### 예문

- 红色的车 (hóng sè de chē) — 빨간 차
- 我喜欢红色 (wǒ xǐ huan hóng sè) — 나는 빨강을 좋아한다

## 색깔 + 的 + 명사 패턴 (Color + de + Noun)

### 形容사용 시 + 的 (de) 필수

- 红色的车 — 빨간 차
- 蓝色的天空 — 파란 하늘
- 我喜欢红色的衣服 — 나는 빨간 옷을 좋아한다

### 명사 단독 사용 (색깔 자체 명사)

- 我喜欢红色 — 나는 빨강을 좋아한다 (색깔 자체를 명사로)
- 红色是我的最爱 — 빨강이 내 최애다

## 문화적 배경 (Cultural Notes)

### 红色 (hóng sè) — 빨강
- 중국: 기쁨, 행운, 축제, 결혼, 새해 상징
- 红包 (hóng bāo) — 세뱃돈 봉투 (빨간 봉투)
- 红灯笼 — 빨간 등불 (축제)
- "红红火火" — 번창하다, 활기차다

### 白色 (bái sè) — 흰색
- 한국: 순수, 깨끗함
- 중국: 장례, 슬픔, 상복 색 → 선물 포장 흰색 피함

### 红 vs 白 대조
- 한국: 흰색 = 순수, 검정 = 장례
- 중국: 빨강 = 축복/행운, 흰색 = 장례/슬픔

### 青 (qīng) — 청록/파랑/초록/젊음
- 青色 — 청록/파랑/초록 사이 색
- 青年 (qīng nián) — 청년, 젊은이
- 青春 (qīng chūn) — 청춘

## 한국어 학습자 필수 팁 (Key Tips for Korean Learners)

### 1. 色 (sè) = 색깔 접미사
- 모든 색깔 명사 = 색깔 한자 + 色 (sè)
- 예외: 青 (qīng) 단독 사용 시 "청록/파랑/젊음"

### 2. 형용사화 시 + 的 (de) 필수
- 红色的车 (O) / 红色车 (X — 구어에서만 허용)

### 3. 색깔 + 명사 순서 = 색깔 + 的 + 명사
- 한국어: 빨간 차 (형용사+명사)
- 중국어: 红色的车 (색깔+的+명사)

### 4. ü 발음 주의 (绿 lǜ, 雨 yǔ, 女 nǚ 등)
- 绿 (lǜ) — 입술 둥글게, 혀 위치 한국어 "위" 와 다름

### 5. 색깔 문화적 금기/선호
- 흰색 선물 포장 피하기 (장례 연상)
- 빨간 봉투(홍바오) = 축하금 표준
- 4 (四) 층/방 번호 피하기 (사망 연상)
