# 第几 (Chinese Ordinal Numbers)

**Source:** [[ordinal-numbers-zh]]
**Theme:** 序数 (Ordinal numbers)
**Level:** HSK 1-2

中文序数。한국 한자어와 매우 비슷 — 뜻은 거의 동일, 발음만 다름. **第 (dì)** prefix 필수 + 숫자 (一/二/三/...). 영어 first/second/third 와 다른 패턴 학습.

---

## 기본 패턴: 第 + 숫자

中文序数 = **第 (dì)** prefix + 普通 숫자. 普通 숫자 단독 사용 = 普通 (cardinal). 例: 一 (yī, 1) vs 第一 (dì yī, 첫째).

| 序数 | 병음 | 뜻 |
|---|---|---|
| 第一 | dì yī | 첫째 (first) |
| 第二 | dì èr | 둘째 (second) |
| 第三 | dì sān | 셋째 (third) |
| 第四 | dì sì | 넷째 (fourth) |
| 第五 | dì wǔ | 다섯째 (fifth) |
| 第六 | dì liù | 여섯째 (sixth) |
| 第七 | dì qī | 일곱째 (seventh) |
| 第八 | dì bā | 여덟째 (eighth) |
| 第九 | dì jiǔ | 아홉째 (ninth) |
| 第十 | dì shí | 열째 (tenth) |

### 第一 (dì yī)

**品词:** 序数词 (ordinal number)

**정의:** 첫째, 첫 번째

**병음:** dì yī (4성 + 1성)

**어원:** 第 (dì, 순서 표시) + 一 (yī, 1). 한국 한자음 "제일" ≠ 중국 "dì yī". **第 는 단독 사용 안 함** (항상 숫자 + 함께).

#### 예문

- 我是第一 (wǒ shì dì yī) — 나는 첫째다
- 第一名 (dì yī míng) — 일등, 1등석
- 第一天 (dì yī tiān) — 첫날

#### 관련어

- [[numbers-zh#一|一 (yī, 1)]]
- [[ordinal-numbers-zh#第二|第二 (dì èr)]]

#### 출처

### 第二 (dì èr)

**품사:** 序数词

**정의:** 둘째, 두 번째

**병음:** dì èr (4성 + 4성)

## 第 + 名词 패턴 (Ordinal + Noun)

### 楼层 (층수)

- 第二层 / 二楼 — 2층

## 文化적 배경 (Cultural Notes)

### 第 (dì) prefix — 한국 한자어와 차이
- 한국: 제일/제이/제삼 (어근 그대로 사용)
- 중국: 第 (dì) prefix **필수** + 普通 숫자
- "第一" 발음 차이: 한국 "제일" ≠ 중국 "dì yī" (혀 위치/성조 다름)

### 第几 (dì jǐ) = "몇 번째"
- jǐ (몇) — 의문대명사
- 例: 你第几个? (nǐ dì jǐ ge?) — 너는 몇 번째니?

### 四 (sì, 4) 발음 회피
- 사 (sǐ, 죽다) 와 유사 → 일부 方言/구어에서 변형 발음
- 但 序数 第四 (dì sì) 는 변형 거의 없음

### 二 (èr) vs 两 (liǎng)
- 二 (èr) — 격식, 序数, 전화번호
- 两 (liǎng) — 일반 수량 (两个, 두 개)
- 例: 二楼 (2층) vs 两个 (두 개) — 二 vs 两

### 한국어 학습자 필수 팁 (Key Tips for Korean Learners)

1. **第 (dì) prefix 필수** — 한국 한자어와 다름
2. **성조 주의**: dì (4성, 억양 강하게) — 한국어 "제" 와 음조 다름
3. **第几 (dì jǐ)** = "몇 번째" (jǐ = 의문사 몇)
4. **두 가지 숫자 발음**: 二 (èr, 격식) vs 两 (liǎng, 일반)
5. **第 단독 사용 안 함** — 항상 普通 숫자 동반
6. **第 (dì) = 4성** — 한국어 "제" (2성) 와 음조 다름
7. **第十一名** = "열한 번째" (한국어와 다른 명수 pattern)
