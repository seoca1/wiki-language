# 时间 (Chinese Time)

**Source:** [[time-zh]]
**Theme:** 时间
**Level:** HSK 1-2

한국어 시간 어휘. 한국어와 매우 비슷하지만 어순/카운터/빈도 표현 차이 있음. HSK 1-2 수준.

---

## 1. 기본 시간 단위 (Basic Time Units)

| 한글 | 한자 | 병음 | 의미 | 비고 |
|------|------|------|------|------|
| 년 | 年 | nián | 년 | 今年 (jīn nián) = 올해 |
| 월/달 | 月 | yuè | 월/달 | 1월 = 一月 (yī yuè) |
| 주 | 周 / 星期 | zhōu / xīng qí | 주 | 周末 (zhōu mò) = 주말 |
| 일 | 天 / 日 | tiān / rì | 일 | 天 (tiān) = 날, 日 (rì) = 날짜/태양 |

| 한글 | 한자 | 병음 | 용법 | 예시 |
|------|------|------|------|------|

## 5. 한국어와 차이점 (Key Differences for Korean Learners)

### 1. 시간 단위 카운터 (Time Counters)
| 한국어 | 중국어 | 비고 |
|--------|--------|------|
| 1시간 | 一个小时 (yí gè xiǎo shí) | 个 (gè) 카운터 필수 |
| 30분 | 三十分钟 (sān shí fēn zhōng) | 分钟 (fēn zhōng) = 분 단위 |
| 2일 | 两天 (liǎng tiān) | 天 (tiān) = 날 카운터, 两 (liǎng) 사용 |
| 3주 | 三周 (sān zhōu) | 周 (zhōu) = 주 카운터 |
| 5달 | 五个月 (wǔ gè yuè) | 个月 (gè yuè) = 달 카운터, 个 필수 |

### 2. 시/분/초 표현 (Time Format)
| 한국어 | 중국어 | 비고 |
|--------|--------|------|
| 8시 | 八点 (bā diǎn) | 点 (diǎn) = 시 |
| 8시 30분 | 八点半 (bā diǎn bàn) / 八点三十分 | 半 (bàn) = 반, 分 (fēn) = 분 |
| 7시 55분 | 差五分八点 (chà wǔ fēn bā diǎn) | 차(差) + 분 + 시 = ~분 전 |

### 3. 상대적 시간 표현 (Relative Time)
| 한국어 | 중국어 | 비고 |
|--------|--------|------|
| 3일 전 | 三天前 (sān tiān qián) | 前 (qián) = 전 |
| 3일 후 | 三天后 (sān tiān hòu) | 后 (hòu) = 후 |
| 2시간 뒤 | 两小时后 (liǎng xiǎo shí hòu) | 后 (hòu) = 후 |
| 1주일 전 | 一周前 (yī zhōu qián) | 前 (qián) = 전 |

### 4. "시간" 단어 구별 (Time Word Distinctions)
| 한국어 "시간" | 중국어 | 의미 구분 |
|---------------|--------|----------|
| 시간 (hour) | 小时 (xiǎo shí) | 1시간 = 60분 단위 |
| 시간 (time) | 时间 (shí jiān) | 추상적 시간, 때, 시기 |
| 때/때때로 | 时候 (shí hou) | 구체적 때, 기회 |
| 시기/계절 | 季节 (jì jié) / 时期 (shí qī) | 시즌, 기간 |

## 8. 필수 문장 패턴 (Essential Sentence Patterns)

### 시간 묻기/말하기
- 现在几点? (xiàn zài jǐ diǎn?) — 지금 몇 시예요?
- 现在八点 (xiàn zài bā diǎn) — 지금 8시예요
- 现在八点半 (xiàn zài bā diǎn bàn) — 지금 8시 반이에요

### 약속 시간 잡기
- 我们几点见面? (wǒ men jǐ diǎn jiàn miàn?) — 우리 몇 시에 만날까요?
- 下午三点见面吧 (xià wǔ sān diǎn jiàn miàn ba) — 오후 3시에 만나요
- 明天早上九点 (míng tiān zǎo shàng jiǔ diǎn) — 내일 아침 9시

### 지속 시간
- 我学了两个小时 (wǒ xué le liǎng gè xiǎo shí) — 두 시간 동안 공부했어요
- 电影持续两小时 (diàn yǐng chí xù liǎng gè xiǎo shí) — 영화가 두 시간 지속돼요

### 빈도 표현
- 我每天跑步 (wǒ měi tiān pǎo bù) — 저는 매일 뛰어요
- 我一周去一次 (wǒ yī zhōu qù yī cì) — 일주일에 한 번 가요
- 我有时去 (wǒ yǒu shí qù) — 가끔 가요

## 9. 한국어 학습자 필수 팁 (Key Tips for Korean Learners)

### 1. 点 (diǎn) vs 小时 (xiǎo shí)
- 点 (diǎn) = "시" (시각) — 8点 = 8시
- 小时 (xiǎo shí) = "시간" (지속시간) — 两小时 = 2시간

### 2. 分 (fēn) vs 分钟 (fēn zhōng)
- 分 (fēn) = 분 (단위) — 十分 = 10분
- 分钟 (fēn zhōng) = 분 (시간 단위) — 十分钟 = 10분간

### 3. 天 (tiān) vs 日 (rì)
- 天 (tiān) = 날 (카운터) — 三天 = 3일간
- 日 (rì) = 날짜/날 — 15日 = 15일, 日记 (rì jì) = 일기

### 4. 个 (gè) 카운터 필수
- 一个小时 (yí gè xiǎo shí) — 1시간 (个 필수)
- 两个月 (liǎng gè yuè) — 2달 (个 필수)
- 三天 (sān tiān) — 3일 (天 자체 카운터, 个 불필요)

### 5. 반(半) 표현
- 8시 반 = 八点半 (bā diǎn bàn)
- 반 년 = 半年 (bàn nián)
- 반 개 = 半个 (bàn gè)

## 10. 한국어 학습자 주의 (Pitfalls)

| 실수 | 올바른 표현 | 설명 |
|------|-------------|------|
| 8시간 | 八个小时 (O) / 八点钟 (X) | 시간 단위는 小时, 시각은 点 |
| 30분 | 三十分钟 (O) / 三十分 (△) | 分钟 표준, 분 단위일 때 分 가능 |
| 2일 | 两天 (O) / 二天 (X) | 양 표현 시 两 (liǎng) 필수 |
| 한 달 | 一个月 (O) / 一月 (X) | 개월 수 셀 때 个月 + 个 필수 |
| 지난 주 | 上周 (O) / 最后一周 (X) | 上周 = 지난 주, 最后一周 = 마지막 주 |
| 다음 주 | 下周 (O) / 下个星期 (△) | 下周 구어 표준 |
