# 天气 (Chinese Weather)

**Source:** [[weather-zh]]
**Theme:** 天气
**Level:** HSK 1-2

한국어 날씨/기상 어휘. 한국어와 유사하지만 동사 패턴/형용사 구분/온도 표현 차이 있음. HSK 1-2 수준.

## 8. 필수 문장 패턴 (Essential Sentence Patterns)

### 날씨 묻기/대답
- 今天天气怎么样? — 오늘 날씨 어때요?
- 今天晴天 — 오늘 맑아요
- 今天下雨 — 오늘 비 와요
- 今天很冷 — 오늘 아주 추워요

### 날씨 예보
- 明天会下雨 — 내일 비 올 거예요
- 后天会下雪 — 모레 눈 올 거예요
- 这周天气不错 — 이번 주 날씨 괜찮아요

### 날씨 대비
- 带伞 — 우산 챙기세요
- 穿厚点 — 두껍게 입으세요
- 多穿点 — 더 두껍게 입으세요
- 注意保暖 — 따뜻하게 하세요 / 감기 조심하세요

### 날씨 대화
- 今天真热啊! — 오늘 진짜 덥네요!
- 好冷啊! — 진짜 춥네요!
- 好大的风! — 바람 진짜 세네!
- 终于不下雨了 — 드디어 비가 그쳤네!

## 9. 한국어 학습자 필수 팁 (Key Tips for Korean Learners)

### 1. "비 오다" = 下雨 (xià yǔ) — "내리다" + "비"
- 下 (xià) = 내리다, 내려가다
- 雨 (yǔ) = 비
- 눈 = 下雪 (xià xuě), 우박 = 下冰雹 (xià bīng bǎo)

### 2. 형용사 = 상태동사 (Stative Verbs)
- 热 (rè) = 덥다 (형용사지만 동사처럼 활용)
- 很热 (hěn rè) = 매우 덥다 (很 + 형용사)
- 不热 (bú rè) = 안 덥다 (不 + 형용사)

### 3. "매우/아주" = 很 (hěn) — 형용사 수식어 기본
- 很热 (hěn rè) = 매우 덥다
- 很冷 (hěn lěng) = 매우 춥다
- 很好 (hěn hǎo) = 매우 좋다

### 4. 완료/상태 변화 = 了 (le)
- 下雨了 (xià yǔ le) = 비가 와요 (시작/상태)
- 雨停了 (yǔ tíng le) = 비가 그쳤어요 (종료)
- 变冷了 (biàn lěng le) = 추워졌어요 (변화)

### 5. 온도 단위
- 摄氏度 (shè shì dù) = 섭씨 (Celsius) — 중국 표준
- 华氏度 (huá shì dù) = 화씨 (Fahrenheit)
- 度 (dù) = 도 (degree)

## 10. 한국어 학습자 주의 (Pitfalls)

| 실수 | 올바른 표현 | 설명 |
|------|-------------|------|
| 비 와요 | 下雨 (O) / 来雨 (X) | 비 = 下雨, 눈 = 下雪 |
| 비 그쳤어요 | 雨停了 (O) / 雨没了 (△) | 停 (멈추다) + 了 표준 |
| 더워요 | 热 (O) / 很热 (더 자연스러움) | 형용사 단독 사용 시 很 권장 |
| 추워요 | 冷 (O) / 很冷 (더 자연스러움) | 동일 |
| 영하 5도 | 零下五度 (O) / 零下5度 (△) | 한자 숫자 권장 |
| 습도 높아요 | 湿度大 (O) / 湿度高 (△) | 중국어: 습도 크다/작다 (大/小) |
