# 星期 (Chinese Weekdays)

**Source:** [[weekdays-zh]]
**Theme:** 星期
**Level:** HSK 1

한국어 요일 어휘. 한국어 "월화수목금토일" 고유어 vs 중국어 "星期 + 숫자" 체계적. 친/외가 완전 분리, 형제자매 호칭은 화자 성별 구분 없음, 일요일 두 표기.

## 5. 한국어와 차이점 (Key Differences for Korean Learners)

### 1. 요일 체계 — 숫자 기반 (Number-based)
| 한국어 | 중국어 | 구조 |
|--------|--------|------|
| 월요일 | 星期一 (xīng qí yī) | 星期 + 1 |
| 화요일 | 星期二 (xīng qí èr) | 星期 + 2 |
| 수요일 | 星期三 (xīng qí sān) | 星期 + 3 |
| 목요일 | 星期四 (xīng qí sì) | 星期 + 4 |
| 금요일 | 星期五 (xīng qí wǔ) | 星期 + 5 |
| 토요일 | 星期六 (xīng qí liù) | 星期 + 6 |
| 일요일 | 星期日 / 星期天 | 星期 + 日/天 |

> **핵심**: 한국어 "월화수목금토일" 고유어 = 중국어 "星期 + 숫자" 체계적

### 2. 일요일 두 가지 표기
| 표기 | 병음 | 비고 |
|------|------|------|
| 星期日 | xīng qí rì | 文어/표준, 日 = 해/날 |
| 星期天 | xīng qí tiān | 구어/일상, 天 = 하늘/날 |

> **비고**: 둘 다 표준, 星期天이 구어에서 더 흔함

### 3. "주" 단어 두 가지
| 한글 | 한자 | 병음 | 용도 |
|------|------|------|------|
| 주 (week) | 周 | zhōu | 약어/구어, 周一~周日 |
| 주 (week) | 星期 | xīng qí | 표준/정식, 星期一~星期日 |

> **핵심**: 周 = 약어/구어, 星期 = 표준/정식

### 4. 주말 표현
| 한글 | 중국어 | 비고 |
|------|--------|------|
| 주말 | 周末 (zhōu mò) | 가장 일반적 |
| 주말에 | 周末 | 전치사 없이 사용 |
| 이번 주말 | 这周末 (zhè zhōu mò) | |
| 다음 주말 | 下周末 (xià zhōu mò) | |
| 지난 주말 | 上周末 (shàng zhōu mò) | |

### 5. 평일/주중 표현
| 한글 | 중국어 | 비고 |
|------|--------|------|
| 평일 | 工作日 (gōng zuò rì) | 근무일 = 평일 표준 |

| 주중 | 工作日 / 周一到周五 | 월~금 |

## 6. 필수 문장 패턴 (Essential Sentence Patterns)

### 요일 묻기/대답
- 今天星期几? (jīn tiān xīng qí jǐ?) — 오늘 무슨 요일이에요?
- 今天星期一 — 오늘 월요일이에요
- 明天星期几? (míng tiān xīng qí jǐ?) — 내일 무슨 요일이에요?
- 后天星期三 (hòu tiān xīng qí sān) — 모레 수요일이에요

### 요일 + 일정
- 星期一我有课 (xīng qí yī wǒ yǒu kè) — 월요일에 수업 있어요
- 周末去北京 (zhōu mò qù běi jīng) — 주말에 베이징 가요
- 这个周末有空吗? (zhè zhōu mò yǒu kòng ma?) — 이번 주말 시간 있어요?
- 下周一见 (xià zhōu yī jiàn) — 다음 주 월요일에 봬요

### 반복 일정
- 每周一 (měi zhōu yī) — 매주 월요일
- 每周末 (měi zhōu mò) — 매주 주말
- 每天 (měi tiān) — 매일
- 工作日 (gōng zuò rì) — 평일마다

### 약속 잡기
- 我们周六见吧 (wǒ men zhōu liù jiàn ba) — 우리 토요일에 보자
- 下周二方便吗? (xià zhōu èr fāng biàn ma?) — 다음 주 화요일 어때요?
- 这周五晚上有空吗? (zhè zhōu wǔ wǎn shàng yǒu kòng ma?) — 이번 주 금요일 저녁 시간 있어요?

## 7. 한국어 학습자 필수 팁 (Key Tips for Korean Learners)

### 1. 星期 (xīng qí) = "주/요일" — 핵심 단어
- 星期一 = 월요일 (1)
- 星期二 = 화요일 (2)
- ...
- 星期日/天 = 일요일 (7)

### 2. 周 (zhōu) = "주" 약어
- 周一 = 월요일 (구어/약어)
- 周末 = 주말
- 本周 (běn zhōu) = 이번 주
- 上周 (shàng zhōu) = 지난 주
- 下周 (xià zhōu) = 다음 주

### 3. 일요일 두 가지 표기
- 星期日 (xīng qí rì) — 표준/문어
- 星期天 (xīng qí tiān) — 구어/일상
- 둘 다 정답, 상황에 맞게 사용

### 4. 요일 + 시간 조합
- 星期一早上 (월요일 아침)
- 星期五晚上 (금요일 저녁)
- 周末 (주말)

### 5. 반복 표현
- 每周一 (měi zhōu yī) — 매주 월요일
- 每周末 (měi zhōu mò) — 매주 주말
- 每天 (měi tiān) — 매일

## 8. 한국어 학습자 주의 (Pitfalls)

| 실수 | 올바른 표현 | 설명 |
|------|-------------|------|
| 일요일 | 星期日/天 (O) / 星期七 (X) | 7 = 日/天, "七" 안 씀 |
| 주말 | 周末 (O) / 星期末 (X) | 周末 표준 |
| 평일 | 工作日 (O) / 平日 (△) | 工作日 표준 |
| 이번 주 | 这周/本周 (O) / 这星期 (△) | 这周/本周 구어 표준 |
| 지난 주 | 上周 (O) / 最后一周 (X) | 上周 = 지난 주 |
| 다음 주 | 下周 (O) / 下个星期 (△) | 下周 구어 표준 |

## 9. 문화적 배경 (Cultural Notes)

### 1. 주 5일제/주 6일제
- 중국: 주 5일제 (월~금 근무, 토일 휴무) — 1995년부터 시행
- 주말 = 周末 (토, 일)
- 법정 공휴일: 춘절(설), 청명절, 노동절, 단오절, 중추절, 국경절 등

### 2. 주말 문화
- 주말 = 쇼핑, 외식, 여행, 가족 모임
- "周末愉快" (zhōu mò yú kuài) — 주말 잘 보내세요
- "周末愉快" = "주말 잘 보내세요" 표준 인사

### 3. 달력 표기
- 달력: 周一~周日 또는 星期一~星期日
- 주말(토일) 빨간색/강조 표시
- 공휴일 빨간색 표시
