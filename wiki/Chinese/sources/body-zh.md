## Key Takeaways

- 手 (shǒu) vs 手臂 (shǒu bì) — 손 vs 팔 (한국어 "손/팔" 두 단어 = 중국어 手 vs 手臂)
- 脚 (jiǎo) vs 腿 (tuǐ) — 발 vs 다리 (한국어 "발/다리" 두 단어 = 중국어 脚 vs 腿)
- 头 (tóu) vs 头发 (tóu fa) — 머리 vs 머리카락
- 眼 (yǎn) vs 眼睛 (yǎn jing) — 눈 (단독 vs 복수형 표기)
- 배 vs 위: 肚子 (복부) vs 胃 (위장)
- 신체 부위 + 疼 (téng) 패턴: 头疼, 肚子疼, 牙疼 등

## Cultural Insights

- 手 (shǒu) vs 手臂 (shǒu bì) — 손 vs 팔: "손 들다" = 举手 (jǔ shǒu) / "팔 들다" = 举手臂 (jǔ shǒu bì)
- 脚 (jiǎo) vs 腿 (tuǐ) — 발 vs 다리: "발 씻다" = 洗脚 (xǐ jiǎo) / "다리 씻다" = 洗腿 (xǐ tuǐ)
- 头 (tóu) vs 头发 (tóu fa) — 머리 vs 머리카락: "머리 감다" = 洗头发 (xǐ tóu fa) / "머리 자르다" = 理发 (lǐ fa)
- 眼 (yǎn) vs 眼睛 (yǎn jing) — 눈: 단독 眼 (yǎn) = 눈(해부학) / 眼睛 (yǎn jing) = 눈(일상)
- 疼 (téng) = 아프다 — 동사/형용사 겸용
