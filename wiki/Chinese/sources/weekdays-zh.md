# Weekdays Vocabulary (Chinese)

**Type:** vocabulary list  
**Date Added:** 2026-08-09  
**Language Level:** HSK 1

## Summary

한국어 요일 어휘 — 기본 요일 (7일), 요일 관련 표현, 주/주말 관련 어휘, 요일 약어, 문화적 배경(주 5일제, 주말 문화)을 망라. 출처: HSK 1 교재, Chinese Weekdays Guide.

## Key Takeaways

- 중국어 요일 = "星期 + 숫자" 체계적
- 한국어 "월화수목금토일" 고유어 ≠ 중국어
- 일요일 = 星期日/星期天 (둘 다 표준)
- "주" 단어 두 가지: 周 (약어) vs 星期 (표준)
- 주말 = 周末 (가장 일반적)

## Expressions Extracted

- 今天星期几? — 오늘 무슨 요일이에요?

## Cultural Insights

- 중국어 요일 = "星期 + 숫자" 체계적 (1~7)
- 한국어 "월화수목금토일" 고유어 ≠ 중국어
- 일요일 = 星期日/星期天 (둘 다 표준)
- "주" 단어 두 가지: 周 (약어) vs 星期 (표준)
- 주말 = 周末 (가장 일반적)
- 주 5일제 (월~금 근무, 토일 휴무) — 1995년부터 시행
- 주말 문화: 쇼핑, 외식, 여행, 가족 모임
- "周末愉快" (zhōu mò yú kuài) — "주말 잘 보내세요" 표준 인사
