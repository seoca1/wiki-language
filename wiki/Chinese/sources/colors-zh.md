# Colors Vocabulary (Chinese)

**Type:** vocabulary list  
**Date Added:** 2026-08-09  
**Language Level:** HSK 1-2

## Summary

중국어 색깔 어휘 (11개 항목) — 기본 색깔 11개. 한국 한자어와 매우 비슷 — 뜻은 거의 동일, 발음만 다름. 색깔 + 的 + 명사 패턴 학습 필수.

## Key Takeaways

- 색깔 명사 = 색깔 한자 + 色 (sè) — 모든 색깔에 色 접미사 필수
- 형용사화 시 + 的 (de) 필수: 红色的车 (O) / 红色车 (X)
- 색깔 + 명사 순서 = 색깔 + 的 + 명사 (한국어와 어순 다름)
- ü 발음 주의: 绿 (lǜ), 雨 (yǔ), 女 (nǚ) 등
- 문화적 금기/선호: 흰색 선물 포장 피하기 (장례 연상), 빨간 봉투(홍바오) = 축하금 표준, 4 (四) 층/방 번호 피하기

## Vocabulary Extracted

- ''红色 (hóngsè)'' - ''蓝色 (lánsè)'' - ''黄色 (huángsè)'' - ''绿色 (lǜsè)'' - ''白色 (báisè)'' - ''黑色 (hēisè)'' - ''灰色 (huīsè)'' - ''橙色 (chéngsè)'' - ''紫色 (zǐsè)'' - ''棕色 (zōngsè)'' - ''青色 (qīngsè)''

## Expressions Extracted

- 红色的车 (hóng sè de chē) = 빨간 차
- 蓝色的天空 (lán sè de tiān kōng) = 파란 하늘
- 白色的花 (bái sè de huā) = 흰 꽃

## Cultural Insights

- 红色 (hóng sè) = 기쁨, 행운, 축제, 결혼, 새해 상징 / 红包 = 세뱃돈 봉투
- 白色 (bái sè) = 한국: 순수 / 중국: 장례, 슬픔, 상복 → 선물 포장 흰색 피함
- 红 vs 白 대조: 한국 흰색=순수 vs 중국 빨강=축복, 흰색=장례
- 青 (qīng) = 청록/파랑/초록/젊음 / 青年 = 청년, 青春 = 청춘
- 4 (四, sì) = 死 (sǐ, 죽다) 동음 → 불길함 → 4층 생략 흔함
