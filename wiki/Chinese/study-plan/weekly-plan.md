# 中文 週/周学习计划 (Chinese Weekly Study Plan)

**Level:** HSK 5-6 (高级)
**Weekly commitment:** 3-4 hours (weekday 30min × 5 + weekend 60min × 2)
**Started:** 2026-08-19
**Cycle:** 4-week rotation (one grammar axis + one vocabulary theme + one output per cycle)

---

## Plan philosophy

- **Microlearning on weekdays**: 30 min sessions minimize friction
- **Deep work on weekends**: 1-hour focused sessions
- **4-week rotation**: one grammar axis + one vocab theme + one output per cycle
- **Output obligation**: every Sunday, ship a 5-sentence Chinese summary to blog
- **Character priority**: prioritize 汉字 reading (繁体+简体) + pinyin辅助

## Weekly distribution

### 周一至周五 (Mon-Fri · 30 min each day)

| Day | Block 1 (10 min) | Block 2 (10 min) | Block 3 (10 min) |
|---|---|---|---|
| 周一 | 词汇 (Anki 15 new) | 表达 1个 分析 | 轻阅读 (新闻 1页) |
| 周二 | 词汇 复习 (Anki) | 语法 1点 | 听力 (Podcast 5-10分) |
| 周三 | 词汇 (Anki 15 new) | 表达 1个 分析 | 轻阅读 |
| 周四 | 词汇 复习 (Anki) | 语法 1点 | 听力 |
| 周五 | 每周 词汇 复习 | 表达 1个 分析 | 自由阅读/观看 (YouTube) |

**Tools:**
- 词汇: Anki (HSK-tagged decks)
- 表达: 1 entry/day to `expressions/`
- 阅读: 莫言, 余华, 刘慈欣 (light chapters)
- 听力: *ChinesePod*, *Mandarin Corner*, *Slow Chinese*

### 周六 (Saturday · 60 min · deep session)

1. **深度阅读 (25 min)**: 中文原书 1章 or 长散文 1篇
   - 未知 词汇 to `vocabulary/` 1-3个 添加 (over-collection 禁止)
2. **语法 整理 (20 min)**: 当周 语法 axis
   - `grammar/` 页面 更新
3. **表达 笔记 (15 min)**: 当周 收集 表达 5个 with 使用 例文

### 周日 (Sunday · 60 min · output + review)

1. **写作/会话 (25 min)**: 中文 短文 5-8句
   - Optional: italki / Preply 25-min session (周1次)
2. **每周 复习 (20 min)**: Anki 全复习 + 表达 总结
3. **博客 出版 (15 min)**: wiki 内容 → markdown → 博客 publish
4. **下周 计划 (with LLM)**:
   ```
   "基于本周学习的表现和语法，制定下周计划。
   请同时指出3个不足之处并建议补充资料。"
   ```

## 4-week rotation

### Block A · 把字句 + 结果补语 (1-4周)

- **语法 axis**: 把字句, 结果补语 (看/听/吃 + V2)
- **词汇 axis**: 处置式 + 结果表达
- **阅读**: 短篇 (*Chinese short stories*)
- **Output**: 自我介绍 扩展 (200字)
- **语法页面**: `grammar/chinese-ba-sentence.md` + `grammar/chinese-resultative-complements.md`

### Block B · 是...的 + 时态 (5-8周)

- **语法 axis**: 是...的 强调 + 了/过/在 时态
- **词汇 axis**: 强调 + 时间/地点/方式
- **阅读**: *活着* (余华) 1-3章
- **Output**: 商务邮件 1封 + 翻译 解释
- **语法页面**: `grammar/chinese-shi-de-emphasis.md` + `grammar/chinese-aspect-le-guo.md`

### Block C · 话题-评述 + 量词 (9-12周)

- **语法 axis**: 话题-评述 (topic-comment) + 量词系统
- **词汇 axis**: 强调 + 分类
- **阅读**: *三体* (刘慈欣) 拔萃
- **Output**: 过去 回忆 短篇 (300字)
- **语法页面**: `grammar/chinese-topic-comment.md` + `grammar/chinese-measure-words.md`

### Block D · 整合 · 自由项目 (13-16周)

- **语法 axis**: 复合 (把 + 是...的 + 话题-评述 + 量词)
- **词汇 axis**: 自由 (用户兴趣领域)
- **阅读**: 用户选择
- **Output**: 自由主题 散文 or 视频 脚本
- **语法页面**: 用户选择
