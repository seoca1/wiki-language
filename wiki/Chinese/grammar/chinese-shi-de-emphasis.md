# 是...的 (shì...de) 강조 구문

**Type:** grammar
**Level:** HSK 4-5 (Intermediate)
**Date Added:** 2026-08-19

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 이미 일어난 일의 **세부 정보**를 강조하는 구문. "나는 (어제/北京에서/跟她) 만났다" 처럼 시간/장소/방법/대상을 부각.
> - **한국어 차이:** 한국어에는 직접 대응 구문 없음. "~한 거다" 어미로 부분 표현 가능 ("北京에서 만난 거다"). 영어 "It is... that..." 강조 구문과 유사.
> - **구조:** 是 + [강조 부분] + 的 + [나머지 동사구]. 是 와 的 가 문장 안에서 강조 대상을 감싼다.
> - **한국어 학습자 팁:** 了 (완료) 와 혼동 주의. **了 = 동작 완료**, **是...的 = 이미 완료된 동작의 세부 강조**. 시제는 과거이지만 강조점은 부가 정보.

---

## 是...의 (shì...de) 의 3가지 기능

| 기능 | 강조 대상 | 예시 |
|:---|:---|:---|
| **시간 강조** | 언제 일어났는가 | 我是**昨天**来的 |
| **장소 강조** | 어디서 일어났는가 | 我是**在北京**学的汉语 |
| **방식/대상 강조** | 어떻게 / 누구와 | 我是**跟她**认识的 |

---

## 1. 시간 강조 (Time emphasis)

```
是 + [시간] + 的 + [동사]
```

| 패턴 | 병음 | 한국어 |
|:---|:---|:---|
| 我是**昨天**来的 | wǒ shì zuótiān lái de | 나는 어제 온 것이다 |
| 他是**去年**去的北京 | tā shì qùnián qù de Běijīng | 그는 작년 북경에 간 것이다 |
| 我们是**2010年**结婚的 | wǒmen shì èr líng yī líng nián jiéhūn de | 우리는 2010년에 결혼한 것이다 |

### 부사 시간 부사 강조

> 시간 부사가 부사 위치 (주어 직후) 가 아닌 강조 위치 (是 다음) 에 사용:

| 평서문 | 강조형 |
|:---|:---|
| 我昨天来了 | 我是**昨天**来的 |
| 他今天到的 | 他是**今天**到的 |

---

## 2. 장소 강조 (Place emphasis)

```
是 + [장소] + 的 + [동사]
```

| 패턴 | 병음 | 한국어 |
|:---|:---|:---|
| 我是**在北京**学的汉语 | wǒ shì zài Běijīng xué de Hànyǔ | 나는 북경에서 중국어를 배운 것이다 |
| 他是**在美国**出生的 | tā shì zài Měiguó chūshēng de | 그는 미국에서 태어난 것이다 |
| 这本书是**在上海**买的 | zhè běn shū shì zài Shànghǎi mǎi de | 이 책은 상해에서 산 것이다 |

---

## 3. 방식/수단 강조 (Manner emphasis)

```
是 + [방식] + 的 + [동사]
```

| 패턴 | 병음 | 한국어 |
|:---|:---|:---|
| 我是**坐飞机**去的 | wǒ shì zuò fēijī qù de | 나는 비행기를 타고 간 것이다 |
| 他是**用筷子**吃饭的 | tā shì yòng kuàizi chī fàn de | 그는 젓가락을 사용하여 밥을 먹는 사람이다 |

---

## 4. 대상 강조 (Object/Recipient emphasis)

```
是 + [대상/상대] + 的 + [동사]
```

| 패턴 | 병음 | 한국어 |
|:---|:---|:---|
| 我是**跟她**认识的 | wǒ shì gēn tā rènshi de | 나는 그녀와 알게 된 것이다 |
| 这本书是**老师**推荐的 | zhè běn shū shì lǎoshī tuījiàn de | 이 책은 선생님이 추천한 것이다 |

---

## 是...의 vs 了 비교 (한국어 학습자 핵심)

| 구문 | 강조점 | 사용 시점 |
|:---|:---|:---|
| **了** (단독) | 동작 **완료** | 동작 자체의 완료를 강조 |
| **是...的** | 이미 완료된 동작의 **세부 정보** | 언제/어디서/어떻게/누구와 를 묻거나 강조 |

### 비교 예시

| 문장 | 의미 |
|:---|:---|
| 我**昨天**去了北京 | 나는 어제 북경에 갔다 (어제 갔음 — 시간 정보는 부가) |
| 我是**昨天**去的北京 | 나는 어제 북경에 **간 것이다** (어제 — 시간 **강조**) |
| 我在**北京**学了汉语 | 북경에서 중국어 배웠다 (장소 정보는 부가) |
| 我是**在北京**学的汉语 | 나는 **북경에서** 중국어를 **배운 것이다** (장소 **강조**) |

## 是...의 가 아닌 경우 (주의)

### 미래/현재 동작 — 사용 불가**

> 강조는 **이미 완료된** 과거 동작에만 적용. 현재/미래 동작 은 是...의 부적절.

| 부적절 | 이유 |
|:---|:---|
| *我是明天去的北京 | 미래 동작 강조 — 是...의 사용 불가 |
| 我明天去北京 | 단순 미래 — 적합 |

### 습관/반복 동작 — 사용 회피**

> 습관적 동작 강조 시 是...的 보다 **는** 또는 **经常** 사용 권장.

| 회피 권장 | 대안 |
|:---|:---|
| *我是每天跑步的 | 나는 매일跑步한다 — **是...의 비적합** (습관 강조 부자연) |
| 我每天跑步 / 我是每天跑步的人 | 매일 뛴다 / 매일跑步하는 사람이다 (자연스러움) |

| 중국어 | 한국어 (부분) | 영어 |
|:---|:---|:---|
| 我是昨天来的 | 나는 어제 온 거다 | I came yesterday (강조) |
