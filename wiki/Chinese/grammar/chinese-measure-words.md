# 个/位/只/条/张/本/件 — 汉语量词 (Chinese Measure Words)

**Overview:** 중국어는 **量词 (liàng cí, 분류사/양사)** 가 명사와 수량사 사이에 필수. 한국어 "한 명/마리/권" 처럼 명사별 고유 양사가 있음. 가장 흔한 양사: 个 (gè, 범용), 位 (wèi, 사람 정중), 只 (zhī, 동물/한 쪽), 条 (tiáo, 길쭉한 것), 张 (zhāng, 평평한 것), 本 (běn, 책), 件 (jiàn, 옷/사건). **HSK 1-3** 핵심.

> **简/繁:** 简 = 个/位/只/条/张/本/件, 繁 = 個/位/隻/條/張/本/件. 본 페이지는 简体 (Simplified).

## Key Points

- **个 (gè, 범용 양사)** — 가장 흔한 양사. 사람, 사물 모두 사용 가능. 例: 一个苹果 (yī gè píng guǒ = 사과 하나), 一个人 (yī gè rén = 사람 한 명).
- **位 (wèi, 사람 정중)** — 사람을 정중하게 셀 때. 例: 一位老师 (yī wèi lǎo shī = 선생님 한 분), 三位客人 (sān wèi kè rén = 손님 세 분).
- **只 (zhī, 동물/한 쪽)** — 동물, 신체의 한 쪽, 한 짝. 例: 一只猫 (yī zhī māo = 고양이 한 마리), 一只手 (yī zhī shǒu = 손 한 쪽).
- **条 (tiáo, 길쭉한 것)** — 길고 가는 물건 (길/강/물고기/바지). 例: 一条鱼 (yī tiáo yú = 물고기 한 마리), 一条路 (yī tiáo lù = 길 하나).
- **张 (zhāng, 평평한 것)** — 종이/테이블/입/침대. 例: 一张纸 (yī zhāng zhǐ = 종이 한 장), 一张桌子 (yī zhāng zhuō zi = 책상 하나).
- **本 (běn, 책)** — 묶음 단위 (책/공책/잡지). 例: 一本书 (yī běn shū = 책 한 권).
- **件 (jiàn, 옷/사건)** — 옷 한 벌 또는 사건/일. 例: 一件衣服 (yī jiàn yī fu = 옷 한 벌), 一件事 (yī jiàn shì = 일 하나).
- **两 vs 二 before 量词** — **两 (liǎng) = 양사 앞에서만 사용**, **二 (èr) = 숫자/호수**. 例: 两个人 (liǎng gè rén = 두 명) BUT 二十个人 (èr shí gè rén = 20명).
- **수량사 위치** — [수사 + 양사 + 명사]. 한국어와 다르게 수사와 명사 사이에 양사 필수. 例: 我买了一个苹果 (나는 사과 하나를 샀다).
- **한국 한자음 ≠ 중국 발음** — 개 (한) ≠ gè (zh), 위 (한) ≠ wèi (zh), 척 (한) ≠ zhī (zh), 조 (한) ≠ tiáo (zh).
