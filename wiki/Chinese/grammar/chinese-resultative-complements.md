# 결과 보어 (Resultative Complements 结果补语)

**Type:** grammar
**Level:** HSK 4-5 (Intermediate)
**Date Added:** 2026-08-19

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 동사 뒤에 **결과/방향/상태**를 나타내는 보조 동사/형용사. 한국어의 "보조용언" (~아/어 보다, ~아/어 주다) 과 유사하지만 더 체계적.
> - **한국어 차이:** 한국어 보조용언 (~보다, ~주다, ~놓다) 은 어미 결합. 중국어는 **두 동사/형용사 결합** 으로 표현. 看见 = "보다 + 결과(발견)" = 한국어 "보다" 만으로는 부족.
> - **구조:** [동사V1] + [결과 보어V2/Adj]. V1 = 동작, V2/Adj = 결과. 可能 (kěnéng) / 得 (dé) / 不 (bù) 삽입 가능.
> - **한국어 학습자 팁:** "看见 vs 看" 처럼 결과 강조 시 **V1+V2 결합 필수**. 영어 "see" 는 단일 동사이지만 중국어는 동사 + 결과 보조 동사.

---

## 결과 보어 의 4가지 카테고리

| 카테고리 | 의미 | 예시 |
|:---|:---|:---|
| **결과** | 동작의 결과/상태 | 看见 (kàn jiàn) — 보다 + 결과 (발견) |
| **방향** | 동작의 방향 | 上来 (shàng lái) — 위 + 오다 |
| **가능** | 능력/가능성 | 听得懂 (tīng de dǒng) — 듣다 + 가능 + 이해 |
| **정도** | 동작의 정도 | 吃饱 (chī bǎo) — 먹다 + 결과 (배 부름) |

---

## 1. 결과/상태 보어 (Result complements)

### 보어 동사 (V2)

> V1 = 동작, V2 = 결과. V2 가 완료/변화의 의미를 부여.

```
[V1] + [V2 결과]
```

| V2 | 의미 | V1 + V2 예시 | 병음 | 한국어 |
|:---|:---|:---|:---|:---|
| 见 (jiàn) | 발견/지각 | 看见 | kàn jiàn | 보다 + 발견 = 보다 (대상이 보임) |
| 到 (dào) | 도달/완료 | 看到 | kàn dào | 보다 + 도달 = 보다 (대상에 도달) |
| 懂 (dǒng) | 이해 | 听懂 | tīng dǒng | 듣다 + 이해 = 듣다 (내용 이해) |
| 会 (huì) | 습득 | 学会 | xué huì | 배우다 + 습득 = (스킬) 터득 |
| 完 (wán) | 완결 | 吃完 | chī wán | 먹다 + 완결 = (전부) 먹다 |
| 好 (hǎo) | 완료/준비 | 做好 | zuò hǎo | 만들다 + 완료 = 만들어 두다 |
| 对 (duì) | 정확 | 看对 | kàn duì | 보다 + 정확 = (정답을) 보다 |

### 보어 형용사 (Adj)

| Adj | 의미 | V1 + Adj 예시 | 병음 | 한국어 |
|:---|:---|:---|:---|:---|
| 清楚 (qīngchu) | 명확 | 听清楚 | tīng qīngchu | 듣다 + 명확 = 명확히 듣다 |
| 干净 (gānjìng) | 깨끗 | 洗干净 | xǐ gānjìng | 씻다 + 깨끗 = 깨끗이 씻다 |
| 饱 (bǎo) | 배 부름 | 吃饱 | chī bǎo | 먹다 + 배 부름 = 배부르게 먹다 |

## 2. 방향 보어 (Directional complements)

### 방향 + 동사 패턴

> V + 上/下/进/出/回/过/起 + 来/去

```
[V] + [방향1 + 방향2]
```

| 방향1 | 방향2 | 결합 | 의미 |
|:---|:---|:---|:---|
| 上 | 来 | 上来 | 위에서 오다 (→ 이쪽으로) |
| 上 | 去 | 上去 | 위에서 가다 (→ 저쪽으로) |
| 下 | 来 | 下来 | 아래에서 오다 |
| 进 | 去 | 进去 | 안으로 들어가다 |
| 出 | 来 | 出来 | 밖에서 나오다 (→ 이쪽으로) |
| 回 | 去 | 回去 | 돌아가다 |
| 过 | 来 | 过来 | 이쪽으로 오다 (건너편→) |
| 起 | 来 | 起来 | 일어나다/시작하다 |

### 예시

| 패턴 | 병음 | 한국어 |
|:---|:---|:---|
| 走**进来** | zǒu jìn lái | (안으로) 걸어 들어오다 |
| 拿**出去** | ná chū qù | (밖으로) 가져가다 |
| 跑**上来** | pǎo shàng lái | (위로) 뛰어오르다 |
| 想**起来** | xiǎng qǐ lái | (기억이) 떠오르다 |

---

## 3. 가능 보어 (Potential complements) — 得/不 패턴

### 긍정 (Positive)

```
[V1] + 得 + [V2/Adj 결과]
```

| 패턴 | 병음 | 한국어 |
|:---|:---|:---|
| 听**得**懂 | tīng de dǒng | 들을 수 있다 (이해 가능) |
| 看**得**见 | kàn de jiàn | 볼 수 있다 |
| 吃**得**完 | chī de wán | 먹을 수 있다 (전부) |
| 买**得**起 | mǎi de qǐ | 살 수 있다 (돈 여유) |

### 부정 (Negative)

```
[V1] + 不 + [V2/Adj 결과]
```

| 패턴 | 병음 | 한국어 |
|:---|:---|:---|
| 听**不**懂 | tīng bù dǒng | 들을 수 없다 (이해 불가) |
| 看**不**见 | kàn bù jiàn | 볼 수 없다 |
| 吃**不**完 | chī bù wán | 먹을 수 없다 (너무 많아서) |
| 买**不**起 | mǎi bù qǐ | 살 수 없다 (돈 부족) |

### 가능 의문

> 가능 보어 는 의문문 시 得→不 변형:

| 의문 | 답변 |
|:---|:---|
| 你看得懂吗? | 看得懂 / 看不懂 |

## 4. 정도 보어 (Degree complements)

> 동사 + 정도 부사 (Adj) 의 결합.

```
[V] + [정도 형용사]
```

| Adj | 의미 | V + Adj | 병음 | 한국어 |
|:---|:---|:---|:---|:---|
| 饱 (bǎo) | 배 부름 | 吃饱 | chī bǎo | (배부르게) 먹다 |
| 够 (gòu) | 충분 | 吃够 | chī gòu | (충분히) 먹다 |
| 多 (duō) | 많음 | 吃多 | chī duō | (너무 많이) 먹다 |
| 久 (jiǔ) | 오래 | 等久 | děng jiǔ | (오래) 기다리다 |

### 결과 vs 정도 의 구분

| 결합 | 의미 |
|:---|:---|
| 看完 | 보다 + 완결 = 다 보다 (결과) |
| 看久 | 보다 + 오래 = 오래 보다 (정도) |

## 5. 혼동 주의 (한국어 학습자 흔한 실수)

### (1) 看 vs 看见

| 어법 | 의미 |
|:---|:---|
| 看 | 보다 (동작, 결과 불문) |
| 看见 | 보다 + 결과 = 보다 (대상이 보임) |
| *我看了他 | (부자연) — 그를 봤다 (결과 미명시) |
| 我看见他了 | (자연) — 그를 **봤다** (발견 결과 강조) |

### (2) 听 vs 听见 vs 听懂

| 어법 | 의미 |
|:---|:---|
| 听 | 듣다 (동작) |
| 听见 | 듣다 + 결과 = 들리다 (소리가 도달) |
| 听懂 | 듣다 + 이해 = 듣다 (내용 이해) |
| 我听到了声音 | (자연) — 소리가 **들렸다** |
| 我听懂了 | (자연) — (내용을) **이해했다** |

### (3) 做 vs 做好

| 어법 | 의미 |
|:---|:---|
| 做 | 만들다 (동작) |
| 做好 | 만들다 + 완료 = 만들어 두다 |
| 我做了饭 | (불완전) — 밥을 만들었다 (미완성 암시) |
| 我做好饭了 | (완료) — 밥을 **완성했다** |

## 한국어 학습자 비교표

| 중국어 | 한국어 | 영어 |
|:---|:---|:---|
| 看见 | 보다 (대상이 보임) | see (catch sight of) |
| 听懂 | 듣다 (내용 이해) | understand (by listening) |
| 做完 | 끝내다 (전부) | finish (completely) |
| 洗干净 | 깨끗이 씻다 | wash (clean) |
| 听**得**懂 / 听**不**懂 | ~을 수 있다 / 없다 | can / cannot |
| 走进来 / 走出去 | 안으로/밖으로 들어가다 | walk in / out |
| 想起来 | (기억이) 떠오르다 | recall |
