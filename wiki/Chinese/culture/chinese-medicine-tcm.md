# 中医 (Zhōngyī) — Traditional Chinese Medicine (TCM)

**Overview:** 中医 (Zhōngyī) = 中国传统 医学, 起源 5-6 千年, 系统 化 于 黄帝内经 (Huángdì Nèijīng, Yellow Emperor's Inner Classic, 约 公元前 200 - 公元 200). UNESCO 2010 "'Acupuncture and moxibustion' (针灸)" 부분 列入 人类 非物质文化遗产. UNESCO 2018 "黄历 24节气" + "中国传统 中医" 등 多 页 时 listing에 포함. 现代 中医 + 西医 (xīyī, Western) 并存 中国 — 大 多 大医院 合并 中西医.

## Key Points

- **核心 概念 (Héxīn gàiniàn)**:
  - **阴阳 (Yīnyáng)**: 阴 阳 平衡 = 健康. 阴虚 / 阳虚 = 病.
  - **五行 (Wǔxíng)**: 金 / 木 / 水 / 火 / 土, 与 五脏 (zàng) 对应 (肺 / 肝 / 肾 / 心 / 脾).
  - **气 (Qì)**: 生命力, 经 络 中 流动. 气 虚 / 气 滞 = 病.
  - **血 (Xuè)**: 血液, 气 之 载体.
  - **津 液 (Jīnyè)**: 体内 液体 总.
- **脏腑 (Zàngfǔ) = 5 脏 + 6 腑**:
  - **5 脏 (Zàng, solid organs)**: 心 (xīn, heart) / 肝 (gān, liver) / 脾 (pí, spleen) / 肺 (fèi, lung) / 肾 (shèn, kidney). "藏 精 气".
  - **6 腑 (Fǔ, hollow organs)**: 胆 (dǎn) / 胃 (wèi) / 小肠 (xiǎocháng) / 大肠 (dàcháng) / 膀胱 (pángguāng) / 三焦 (sānjiāo). "传 化 物".
- **经络 (Jīngluò)**: 经 脉 (jīngmài) + 络 脉 (luòmài) — 人 体 气 + 血 运 行 路 径. **12 正经** + **奇经八脉** (incl. 任 Rèn 脉, 督 Dū 脉). 12 正经 与 12 脏腑 对应.
- **诊断 (Zhěnduàn)**: 望 (wàng, observe) / 闻 (wén, listen/smell) / 问 (wèn, ask) / 切 (qiè, pulse). **四诊 (Sìzhěn, four diagnostic methods)**.
- **脉 象 (Mài xiàng)**: 28 脉. 主 要: 浮 (fú, floating) / 沉 (chén, deep) / 迟 (chí, slow) / 数 (shuò, rapid) / 虚 (xū, weak) / 实 (shí, full).
- **治疗 (Zhìliáo)**:
  - **中药 (Zhōngyào)**: 草本 + 动物 + 矿 物. 名 方: **四君子汤** (sì jūnzǐ tāng, 益气) / **六味地黄丸** (liù wèi dìhuáng wán, 肾 阴) / **藿香正气散** (huòxiāng zhèngqì sǎn, 湿).
  - **针灸 (Zhēnjiǔ)**: 针 + 灸 (moxibustion = 艾 叶 烧, 暖 经 络). 经 络 114 个 穴 位 (Shū) + 奇 穴.
  - **推拿 (Tuīná)**: 按摩 / 推 拿 治疗.
  - **拔罐 (Báguàn)**: 火 罐 or 吸 罐 (suction cup) 拔 背部. 留罐 ~10 分钟.
  - **刮痧 (Guāshā)**: 用 牛 角 / 玉 板, 刮 出 红 痧.
  - **气功 (Qìgōng)**: 导 引 (movement) + 调 息 (breathing) + 心 理.
- **常用 药 (Chángyòng yào)**:
  - **人 参 (Rénshēn, Ginseng)**: 大 补 元气. 东北 + 韩国.
  - **黄 芪 (Huángqí, Astragalus)**: 补气.
  - **当归 (Dāngguī, Angelica)**: 补血.
  - **枸杞 (Gǒuqǐ, Wolfberry)**: 补 肾 + 益 精.
  - **陈 皮 (Chénpí, tangerine peel)**: 健 脾.
- **理论 经典 (Lǐlùn jīngdiǎn)**:
  - 《黄帝内经》(Huángdì Nèijīng) = 医 家 总 源头.
  - 《难经》(Nánjīng) = 脉 学 + 经 络.
  - 《伤寒论》(Shānghán Lùn, 张仲景 Zhāng Zhòngjǐng) = 寒 病 治 疗.
  - 《本草纲目》(Běncǎo Gāngmù, 李时珍 Lǐ Shízhēn, 1578) = 药 物 学.
- **体质 (Tǐzhì, constitution)**: 9 种 主要 体质 (平和 / 气虚 / 阳虚 / 阴虚 / 痰湿 / 湿热 / 血瘀 / 气郁 / 特禀).

## Cross-language Connections

- **한국어**: 한국 한의학 (韓醫學, Korean medicine) 는 中 医 의 直接 派生 + 韩医 独自 发展. 둘 다 阴阳 + 五行 + 经络, 但是 한국 한의학 은 四象 医学 (李 济马, Lee Jema, 19c) + 독자 의학. 한국 약 药材 = 한약.
- **Japonés**: 일본 漢方 (kanpō, "Chinese method") 는 中国 医의 流入 ("中 世") + 现代 약. 日本 江戸 时代 의 방 医学 (腹診) 등 独自 发展. UNESCO "Kampo" 2008 부터 잠재 等待. 그러나 现代 Japan 는 한방약 医学 약간 弱.
- **Inglés**: 없음 直 接 对应. Western "alternative medicine" 包括 acupuncture / herbalism, 그러나 哲学 背景 完 全 不同.

## Ejemplos

「我最近总是手脚冰凉,中医说我这是阳虚,让我多吃点羊肉和生姜。」— 阳虚 + 食疗.

「我朋友肩颈酸痛,每周去做一次推拿,效果比吃止痛药还明显。」— 推拿 + 西药 对照.

「中医讲究'上工治未病',最高明的医生在病发生之前就预防了。」— 上工治未病 = 预防 哲学.
