# 关系 (Guānxi) — Guanxi Networking

**Overview:** 关系 (Guānxi) 是中国社会运转的核心,译作 "relationships / networks / personal connections". 含义比英文 "relationships" 或韩文 "관계" 更深. 包括: 血脉关系 (xiěmài guānxì = 血缘 = 血缘亲属, 距离 远近) / 同学 (tóngxué = school) / 同乡 (tóngxiāng = 同省) / 同事 (tóngshì = workplace) / 朋友 (péngyǒu = friend) / 业务 (business contact). 同日语의 "人脈 (jinmyaku)" / 韩国 "인맥 (inmaek)" 类似, 但是 中文 "关系" 有 "情面 / 好处 / 拉拢" 等含义.

## Key Points

- **词源 (Cíyuán)**: 关系 由 关 (gate, contact) + 系 (system) 组成. 含 "contacts / network / ties" 义. 拉关系 (lā guānxi) = 通过中间人 联系. 托关系 (tuō guānxi) = ask someone to introduce 朋友 / 同事 / 客户.
- **关系 vs 朋友 (Yǔ péngyǒu de qūbié)**: 
  - **朋友 (péngyǒu)**: 단순 心 + 兴趣 = "friend"; 부분 관계 中的 子集
  - **关系**: 含 利益 + 责任 + 回报 + 长期성; 朋友 是 关系 中 较近 的一层
- **关系 维度 / 文化 圈 (Quānzi)**: 中国 사회의 "圈子" (quānzi, circles) — 同学 圈 (universities 名 校 圈 / 中学 圈 / 高中 圈), 同乡 圈 (福建 帮 / 温州 帮 / 山西 帮 etc), 同事 圈 (外资 圈 / 国企 圈 / 体制内 圈 / 互联网 圈).
- **请客 (Qǐngkè)**: 关系 维护 의 核心 方法. 请客 = 请人 吃饭, 主人 出资. 包括: 商务 请客 / 婚礼 请客 / 春节 请客 / 求办事 请客. 与 韩国 大体 相似 (한국 초대 와 비슷), 但 좀 더系统化.
- **送礼 (Sònglǐ)**: 烟酒 / 茶 / 月饼 / 茶叶 / 名酒 / 现金 (礼金) etc. 商业 大额 送礼 = "走账 (zǒu zhàng)". 年节 必访 礼.
- **互惠 (Hùhuì)**: "礼尚往来 (lǐ shàng wǎng lái)" — 礼物 来回. 不回 = 关系 破产 风险.
- **面子 (Miànzi) = 关系 的 货币 (Miànzi = currency of relations)**: 面子 = face, 关系 银行 货币. 谁 帮 谁 是 储蓄. 拒绝 帮 = 取费 别人 面子.
- **办事情 通过 关系 (Bàn shìqíng tōngguò guānxi)**: 找 关系 = "走后门 (zǒu hòumén, 后门)" = "ask guanxi for favor". 教育 / 医疗 / 就业 / 商业 牌照 经常 guanxi-dependent.
- **关系 类型 / 亲属 + 非亲属 (Qīnshǔ + fēi qīnshǔ)**:
  - **亲 (qīn)**: 血亲 (父母 / 兄弟姐妹 / 亲戚); 姻亲 (wedding kinship / 岳父 etc)
  - **故 (gù)**: 老朋友 + 老同学 = 历史 关系
  - **友 (yǒu)**: 业务 / 校友 / 同乡 / 朋友
- **临时 请托 关系 (Línshí qǐngtuō)**: 找 一个 中间人 (介绍人, jiè shàorén) 帮你 引荐. 中间人 自己 也欠 对方 一个人情 (rénqíng).
- **人情 (Rénqíng)**: "人情" 中 + 人情 heavy 含义 = 感情 + 礼尚往来 义务. "欠 人情" (qiàn rénqíng) = owe a favor. "还不清 人情" (huán bù qīng rénqíng) = endless.

## Cross-language Connections

- **한국어**: 한국 의 "인맥" (inmaek, social connections) 와 직접 대응. 둘 다 网络 / 圈 / 走动 (뒤풀이). 한국 의 "정 (jeong)" 는 中 国 "人情" 보다는 深 (entre-emotional bond). 中国 "关系" + 韩国 "정" 与 일본 "義理 (giri)" 합친 컨셉.
- **Japonés**: 일본 "人脈 (jinmyaku, jinck connections)" 또는 "コネ (kone, connection)" 가 中国 "关系" 의 similar. 그러나 일본 "義理 (giri)" 와 "世間体 (sekentei)" 라는 더 보이지 않는 의식 上 多.
- **Inglés**: 영어 의 "networking" / "personal connections" / "whom you know" — 비유 술 (condescending) 意 도 있음 (Chinese nepotism). 中国 "关系" 는 Chinese "nepotism" 또는 "cronyism" 와 다름 — 关系 既 是 必要 의 (健康 관계) 와 滥用 (腐败) 의 분기선.

## Ejemplos

「我刚到北京,人生地不熟,幸好父亲介绍了一个老乡——我们算是建立了一点关系。」— 关系 의 시작.

「在生意场上,关系是第一位的。你认识谁,决定了谁愿意给你机会。」— 商业 关系 = 资本.

「这个人情我还不起,所以他的忙我一定要帮。」— 人情 + 互惠.
