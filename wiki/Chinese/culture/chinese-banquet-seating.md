# 中国 圆桌 席位 (Yuánzhuō Xíwèi) — Banquet Seating

**Overview:** 中国圆桌席位 (Yuánzhuō xíwèi) 是一套酒席安排礼仪。8-12 人大圆桌 (或 10-12人),只有一张圆桌 → 主客位 主桌 separate. 关键:主客位 (zhǔkè wèi, host-guest position) — 圆桌 设一个 入口 (门), 面对门 的座位 = 主客位 (最尊), 靠门 = 末位 (陪客位). 圆桌文化 与 韩国/日本 저상桌 / Western rectangular 의 安排 完全 不同.

## Key Points

- **圆桌 (Yuánzhuō)**: 传统 = 圆桌 (常 8-12人). 多桌 (10+) 选最大或独立 的 圆桌 为 "主桌 (zhǔzhuō, main table)" = 主 人 + 主客.
- **主位 (Zhǔwèi)**: 主桌内面对门 的 位置 = 主客位. 主人 (东家 host) 右手 或 左手 顺位 (谁更尊) 招 坐.
- **主客位 (Zhǔkè wèi)**: 圆桌 内 最 尊 的位置, 通常 面对门 / 面对墙 / 远离门. 圆桌文化 中, 背门 是 次尊, 正对门 是 高位.
- **末位 (Mòwèi)**: 圆桌 中靠近门 / 背对主席 / 上菜口 = low. 陪客位.
- **敬酒顺序 (Jìngjiǔ shùnxù)**:
  1. 主宾 (zhǔbīn, guest of honor) 先敬
  2. 主宾 second, 主宾邻居 / 第二 客人 …
  3. 主宾 单独 敬 第一杯
  4. 其余 顺位 敬
  5. 末位 (最 courteous) 主动 跑去 主动 敬 首席 嘉宾
- **中国传统方向 (Fāngxiàng)**: "尚东右" — 古代 east / right = 尊位 (东 右). 圆桌 如今 多数 以面对门 = 主客位.
- **菜单顺序 (Càidān shùnxù)**: 凉菜 → 热菜 (荤菜 → 蔬菜 → 海鲜 → 汤 → 主食) → 甜品 → 水果 → 茶. 现代 大桌 菜 数 = 1人/菜 约 1-2 个, 8 人 桌 8-12 道菜.
- **首位菜 (Shǒuwèi cài)**: 鱼 (有头有尾) 或 全鸡. 上鱼 时主人 发言 "鱼到酒到" = start.
- **菜摆放**: 鱼 头朝 首席 (senior); 蟹 / 海鲜 也在 单方; 主菜 鱼 + 鸡 应 在 桌 中心; 凉菜 周边 分.
- **敬酒礼仪 (Jìngjiǔ lǐyí)**:
  - 敬酒 者 持 桌 中 杯 + 酒瓶 / 酒壶
  - 向 首席 主席 (客气 首席) 伸手 献 杯
  - 老 客 受敬 后 归还 同酒 杯
  - **干杯 (gānbēi)**: 满杯 一饮而尽 (full empty) = 干杯 (vs. 随意 suíyì 自由喝)
- **茶礼仪**: 与 酒 不同. 敬茶 仅 2-3杯, 主宾 受茶 后 叩指礼 (kòu zhǐ lǐ). 
- **酒桌游戏**: 划拳 (huáquán, finger guessing game) / 真心话大冒险 (zhēnxīnhuà dà màoxiǎn, truth or dare) / 摇骰子 (shake dice) — 现代社会 酒桌 气氛.

## Cross-language Connections

- **한국어**: 한국 식당 의 좌석 は 보통 矩形 또는 round (모통 정방형). 韩国 정담 = 어른 / 主客 上位. 韩国 좌석 의 上位 (장 안자리) 为 中国 主客位 类似. 그러나 중국 圆桌 의 "面对门" 규칙 은 한국 의 예약 제 一번째 row 에선 部석 없음.
- **Japonés**: 日本 의 좌석 — 座敷 (zashiki) 의 上座 (kamiza, 입구 옆 쪽이 上位). 中国 의 "面对门" 규칙 은 日本 의 "입구 옆이 上位" 과 매칭. 그러나 日本 은 정방형 / 신발 의식 포함 多.
- **Inglés**: Western 의 Banquet / Wedding seating — 정형 좌석 + place card. Round "sweetheart table" 仅 bride + groom. China 의 圆桌 는 group unit 의 family / friend circle.

## Ejemplos

「长辈坐主桌,面对门的位置;新人和父母挨着主桌。父母陪客坐相邻一桌,司仪引导我们逐桌敬酒。」— 婚宴 圆桌 设置.

「'鱼到酒到!'主人举杯向主客敬酒,主客回应'承让承让',全场举杯同饮。」— 首位菜 + 敬酒 文化.

「小白不懂规矩,一屁股坐到了靠近门口的位置,后来才知道那是末位,赶紧让给晚辈。」— 圆桌 礼仪 学习 必备.
