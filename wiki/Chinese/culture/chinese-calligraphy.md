# 书法 (Shūfǎ) — Chinese Calligraphy

**Overview:** 书法 (Shūfǎ) = 中国 视觉 艺术 的 最 高 代表. "Chinese calligraphy" 译. 起源 自 商代 甲骨文 (jiǎgǔwén, oracle bone script, 14-11세 BC). 2009 UNESCO "Chinese calligraphy" 列入 人类非物质文化遗产. 不 像 西画 (visual), 书法 = 时间 + 节奏 + 力量 + 灵魂 의 표出. 4 大 媒体: 毛笔 + 墨 + 纸 + 砚.

## Key Points

- **文房四宝 (Wénfáng sìbǎo)**: "Four Treasures of the Study":
  - **笔 (Bǐ, brush)**: 毛笔 (máobǐ), 狼毫 (lángháo, weasel hair, hard) / 羊毫 (yángháo, goat hair, soft) / 兼毫 (jiānháo, blend). 笔 头 选 毛 决定 笔性.
  - **墨 (Mò, ink)**: 墨 块 (inkstick) + 砚 + 水 研墨 (yànmò). 胡开文 / 曹素功 / 徽墨 (Huīmò, Anhui) = 名牌. 一得阁 / 曹素功 墨汁 (modern).
  - **纸 (Zhǐ, paper)**: 宣纸 (xuānzhǐ, Xuan paper, Anhui) = 最佳. 生宣 (shēngxuān, absorbent, practicing) / 熟宣 (shúxuān, treated, final). 还 有 高丽 纸 / 绢.
  - **砚 (Yàn, inkstone)**: 端砚 (Duān yàn, Guangdong) / 歙砚 (Xī yàn, Anhui) / 洮砚 (Táo yàn, Gansu) / 澄泥砚 (Chéngní yàn, 4 大名砚).
- **5 major 字体 (Zìtǐ)**: 见 [[chinese-five-script-styles|5种字体专题]].
  - **篆 (Zhuàn)**: 篆书 (seal script). 上古 (甲骨文 金文 → 小篆 Qín).
  - **隶 (Lì)**: 隶书 (clerical script). 汉代.
  - **楷 (Kǎi)**: 楷书 (regular). 楷 模 = 范本, 唐 成熟.
  - **行 (Xíng)**: 行书 (running). 介于 楷 + 草.
  - **草 (Cǎo)**: 草书 (grass). 难 辨 but 极 美.
- **书法家 (Shūfǎ jiā)**:
  - **王羲之 (Wáng Xīzhī, 303-361)**: 楷书 + 行书, "书圣 (shūshèng)". 《兰亭集序》(Lántíng Jíxù) = 天下 第一 行书.
  - **颜真卿 (Yán Zhēnqīng, 709-785)**: 楷书, 雄强, "颜体".
  - **柳公权 (Liǔ Gōngquán, 778-865)**: 楷书, "柳体". 
  - **欧阳询 (Ōuyáng Xún, 557-641)**: 楷书, "欧体".
  - **苏轼 (Sū Shì, 1037-1101)**: 宋 "苏 / 黄 / 米 / 蔡" 四家 之 首. 《黄州寒食诗帖》(Huángzhōu Hánshí Shītiè).
  - **米芾 (Mǐ Fú)**: 行书.
  - **赵孟頫 (Zhào Mèngfǔ, 1254-1322)**: 元代, 复古.
  - **王羲之 + 王献之 (Wáng Xiànzhī, 王子)**: 父子.
- **执笔 (Zhíbǐ, hold-brush)**: 大 拇指 (t, th) 与 食指 (index) 对 握, 中指 钩 内, 无名 指 + 小指 后 顶. 腕 / 肘 / 肩 活 动.
- **意 在 笔 先 (Yì zài bǐ xiān)**: "Before brush, there's intent." 笔 = follow 思.
- **气 韵 (Qìyùn)**: "Spirit-resonance" — 笔画 间, 气脈 贯串.
- **章法 (Zhāngfǎ)**: 整体 布 局, 行 间, 留白.
- **墨 法 (Mòfǎ)**: 干 (gān, dry) / 湿 (shī, wet) / 浓 (nóng, dense) / 淡 (dàn, light) / 焦 (jiāo, burnt) / 涨 (zhǎng, flooded).
- **力透纸背 (Lì tòu zhǐ bèi)**: "Force behind paper." 力 强 之 极.

## Cross-language Connections

- **한국어**: 한국 서예 (書藝, seoye) 는 中国 书法 의 영향. 韩 鲜 时代 王羲之 忠 실 大家, 现代 서예 = 한자 文化 (汉 字 书写). 한국 谚文 (Hunmin Jeongeum 1443) 에서 similar "书法" 의 观念. 그러나 한국 은 谚文 로 서예 极 약함. 공통점: "毛笔 + 墨 + 笔 架" 都是 文房四宝类似.
- **Japonés**: 日本 書道 (shodō, calligraphy) — 平安 时代 假名 (hiragana) + 漢字 混 写 (汉字仮名交じり文). 일본 書道 의 假名 의 美 (hiragana のみ) 是 中国 书法 의 思想 + 美학. 共通: 三 筆 三 跡 (calligraphers of 7c), 中国 王羲之 와 直接 关联.
- **Inglés**: Western calligraphy ≠ Chinese 书法. 西方 calligraphy = 装饰 (e.g. 婚礼 invitation) + 各种 gothic / italic typeface. 中国 书法 = 哲学 + 艺术 + 灵魂. 不类.

## Ejemplos

「我爷爷写得一手好字,过年的时候他写春联,全村的人都来要。」— 春联 民俗 应用.

「王羲之的《兰亭集序》是'天下第一行书',里面 '惠风和畅' 四个字写得飘逸潇洒。」— 兰亭集序.

「学书法要先学楷,再学行,最后才学草,这叫'楷行为草本'。」— 楷 → 行 → 草 学习 顺序.
