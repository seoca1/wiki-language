# 面子 (Miànzi) — Face / Mianzi

**Overview:** 面子 (Miànzi) 是中国社交的核心动态概念. 译作 "face" / "social standing / reputation". 与英文 "face" / 한국 "체면 (ch'e-myeon)" / 일본 "面目 (menboku)" 直接对应, 但 中国 面子 含义 (社 + 互 面) 更 复杂. 面子 文化 是 关系 网络 的 货币, 是 给面子 + 丢面子 + 看面子 + 保全面子 的 系统.

## Key Points

- **概念 (Gàiniàn)**: "面子" + "脸 (liǎn)" 가 配合. 脸 = literal face; 面子 = social face / reputation. 体面 (tǐmiàn) = 实在 体面 / 颜值 OK. 不给面子 = insult.
- **给面子 (Gěi miànzi, "give face")**: 公然 show 尊重 — 称尊号 / 让位 / 同意 / 夸赞 / 敬酒 / 送礼. 必要场合: 上级 → 下级 / 长辈 → 晚辈 / 主人 → 客人 / 重要 客人.
- **丢面子 (Diū miànzi, "lose face")**: insult / 公开 拒 / 不敬 / 对方 缺席 / 饭桌 不付账 / 让 难堪 / 当众 拒绝. 后果: 关系 恶化 / 报复 / 关系 破裂.
- **有面子 (Yǒu miànzi)**: 社 资源 + 地位 / 财富 + 关系. 例: 老板 开 宝马 是 有面子; 名牌 大学 = 有面子; 大房子 儿子 = 有面子.
- **看面子 (Kàn miànzi)**: 因 关系 / 因 别人 给 面子而 do something. 例: "看在他的面子上, 这事 我帮你." 
- **要面子 (Yào miànzi)**: 对 外 形象 重视. e.g., 结婚 婚礼 筹 100桌, 实际 支付 不到; 不愿意 丈夫 开 国产 车.
- **死要面子活受罪 (Sǐ yào miànzi huó shòuzuì)**: "Dying to save face but suffering." 贬义 = 重视 面子 到 silly extent.
- **长面子 (Zhǎng miànzi)**: 给父母 长面子 = 考上 好 大学 / 高薪 offer / 结婚 / 生孩子. **长子 + 长孙 = 家族 面子**.
- **没面子 (Méi miànzi)**: 公开 失败 / 被 拒. 例: 送 礼 别人不收 = 没面子; 老板 当众 批评 = 没面子 (老板 + 员工 都 丢面子).
- **面子里子 (Miànzi lǐzi)**: 面子 = 外 面 (exterior); 里子 = 内 实际 (interior). 现实 / 实惠 vs 表面 荣耀.
- **回面子 (Huí miànzi)**: 被 insult 后 报复 + 恢复 面子. 间接, 公开, 长期.
- **礼物的 面子 (Lǐwù miànzi)**: 礼物 的 价格 + 品牌 = 决定 面子 value. 例: 礼 茅台 vs 礼 啤酒 = 完全 不同 面子.
- **面子的 数字 (Miànzi shùzì)**: 红包 金额 must 选 8 / 6 开头, 避 4 / 14.
- **面子 与 关系 (Guanxi)**: 面子 = 关系 的 货币. 谁 帮 你 一回 = 给 你 面子; 谁 不给 = 损 面子.

## Cross-language Connections

- **한국어**: 한국 의 "체면 (ch'e-myeon)" 와 직접 매치. 둘 다 "face" + "give face" + "lose face" + "save face" 의 구조. 한국 은 Body Language (예절 + 言) 中, 中国 보다 체면 기 조용한 다 吃 // 表.
- **Japonés**: 일본 の "面目 (menboku)" + "体面 (teimen)" + "世間体 (sekentei)" 와 直接 대응. 그러나 日本 세분화 (3 term) 는 中国 의 단순 "面子" + "脸" (2 term) 보다는 多. 둘 다 face 概念 大事 변.
- **Inglés**: English 里 "saving face" + "losing face" + "giving face" 와 同义. 그러나 英语 는 face 의 부분 / dim. 中国 / 韩国 / 日本 보다는 약한 의식.

## Ejemplos

「他当众驳了我的提议,我丢了好大面子,以后在合作方那里我还怎么抬头。」— 公开 驳 + 面子 动态.

「看在他父亲的面子上,我决定再给他一次机会。」— 关系 / 长辈 面子 = 决策 影响力.

「过年回家给爸妈包一千块的压岁钱,也是给爸妈长面子——左邻右舍看到了他们也会骄傲。」— 长面子 包含 家族.
