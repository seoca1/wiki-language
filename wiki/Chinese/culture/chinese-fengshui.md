# 风水 (Fēngshuǐ) — Feng Shui

**Overview:** 风水 (Fēngshuǐ, "wind and water") = 中国传统 选择建筑 + 墓地 + 风水摆设 的 选址 / 布局 / 设计 哲学. 起源 = 殷商 (Yīnshāng, 14세기 BC), 兴于 秦汉, 系统化 唐宋. 2014 UNESCO "24节气" 部分 包含 立春 / 立夏 etc, 部分 含 风水 elements. 现代 中国 风水 = 民间 信 仰 + 商业 装饰 + 建筑 摆设.

## Key Points

- **哲学基础 (Zhéxué jīchǔ)**: 阴阳 (Yīnyáng, yin-yang) + 五行 (Wǔxíng, five elements) + 罗盘 (Luópán, compass) + 气 (Qì, energy flow).
- **阴阳 (Yīnyáng)**: 万物 有 阴阳 两 面. 阴 = 暗 / 静 / 内 / 下 / 阴 / 女. 阳 = 明 / 动 / 外 / 上 / 阳 / 男. 阴 阳 平衡 = 好事.
- **五行 (Wǔxíng)**: 金 (jīn, metal) / 木 (mù, wood) / 水 (shuǐ, water) / 火 (huǒ, fire) / 土 (tǔ, earth). 五行 相生 (one generates another): 金生水, 水生木, 木生火, 火生土, 土生金. 相克 (clashes): 金克木, 木克土, 土克水, 水克火, 火克金.
- **罗盘 (Luópán, compass)**: 风水 测量 工具. 24 山 向 (24 shān xiàng) = 24 方向 (15° each). 24 山 含 12 地支 + 8 天干 + 4 维 (乾 坤 艮 巽).
- **气 (Qì)**: 能量 + 流动. 风水 重 "藏风聚气 (cáng fēng jù qì)" — 避免风 直吹, 让 气 聚集.
- **吉祥方位 (Jíxiáng fāngwèi)**: 
  - **坐北朝南 (Zuò běi cháo nán)**: 房屋 坐北朝南 = 阴阳 调和 + 采光 + 抵御 北方 寒风.
  - **背山面水 (Bèi shān miàn shuǐ)**: 后 山 前 水 = 前 财 后 靠.
- **主 要 形 势 (Fēngshuǐ forms)**:
  - **峦头 (Luántóu)**: 峦头 形势 = 山水 地形 评 价.
  - **理气 (Lǐqì)**: 罗盘 飞星 公式 / 八宅 / 八字, 数学 公式 计算 气 场.
  - **形 势派 (Xíngshì pài)** vs **理气派 (Lǐqì pài)**: 两个 main 分支.
- **家居 / 办公室 风水 常 见**:
  - **入门 (Rùmén)**: 门 vs 窗 对穿 = 穿堂风, 不利 = "穿心 (chuānxīn)". 解决: 屏风 (píngfēng, screen).
  - **明堂 (Míngtáng)**: 客厅 / 门 厅 = 房屋 腹地. 宽 阔 亮 = 财.
  - **财位 (Cáiwèi)**: 客厅 / 大门 对角 (东 南 角 多) — 摆 金 财 / 绿 植物.
  - **卧室 (Wòshì)**: 床 头 靠 实 墙; 镜 不 对 床.
  - **厨房 (Chúfáng)**: 炉灶 不 对 门 / 对 厕所.
  - **厕所 (Cèsuǒ)**: 不 居 中 央, 不 对 厨房.
- **公墓/墓地**: 风水 选 坟 = 阴宅 (yīnzhái). 坐 山 抱 水. 影响 后代.
- **开业 时间**: 选 黄道吉日 (huángdào jírì, lucky day). 黄历 笔记.
- **常用 镇 物 (Zhènwù)**: 八 卦 镜 (bāguà jìng, Bagua mirror) / 貔貅 (píxiū, mythical hoarder) / 金蟾 (jīnchán, money toad) / 风水 球 (fēngshuǐ qiú, crystal ball).

## Cross-language Connections

- **한국어**: 한국 의 풍수 (風水) 同 单词, 从 中国 借入 (越 南 = phong thuỷ). 한국 풍수지리 + 명당 (명당, blessed site) + 정풍 + 관풍 + 터. 공통점 多. 다만 韓 国 풍수 의 应用 大多 民居 + 坟墓, 中国 보다 弱.
- **Japonés**: 일본 風水 の 적용 약함. 그러나 気 の concept (気 + 陰陽道 / onmyōdō / geomancer) Japanese culture 에 强함. 風水 라는 用语 자체는 1990s+ 부터 现代 인테리어 用语 로 도입.
- **Inglés**: 없음 직 접 대응. Western Vastu Shastra (印度) - 같은 唯心 + 装饰, 도 들어가 cultures. Euro-American 는 "feng shui" 直接 借词 로 "创 interior design" concept.

## Ejemplos

「我买房的时候请了位风水先生看,他说这房子坐北朝南,明堂开阔,适合聚财。」— 风水 + 房屋.

「我家的屏风是挡穿堂风的,这是风水的基本功,气不能直穿。」— 屏风 风水 原理.

「公司新办公室装修,总经理特意请风水师来选定开业日期。」— 商业 风水 应用.
