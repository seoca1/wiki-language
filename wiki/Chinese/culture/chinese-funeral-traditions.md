# 中国 丧礼 (Zhōngguó Sànglǐ) — Chinese Funeral Traditions

**Overview:** 中国传统丧礼 (Zhōngguó chuántǒng sànglǐ) 是从临终/初终到下葬、守孝三年的礼仪系统。核心:守孝 (shǒuxiào) + 烧纸 (shāozhǐ) + 棺椁土葬 (现代多火葬 huǒzàng)。2006 年土葬 + 灵堂祭祀部分列入国家级非物质文化遗产。

## Key Points

- **临终 (Línzhōng)**: 临终前招家人到病榻前"送终 (sòngzhōng)"。病人落最后一口气前移至正厅。
- **初终 (Chūzhōng)**: 烧"倒头纸 (dàotóu zhǐ, 元纸 烧)", 给亡者擦拭身体 (沐浴 mùyù), 换寿衣 (shòuyī)。亲属用棉絮 / 秤砣 / 镜子置于特定位置。
- **停灵 (Tínglíng)**: 家中设灵堂 (língtáng), 摆遗像、灵位、供品 (香/烛/花/水果), 子女守灵 (shǒulíng), 不睡 3-7 天。
- **讣告 (Fùgào)**: 通报亲友。发白事短信 / 微信群通知。亲友来丧家 (吊唁 diàoyàn) 携礼金 (yījīn, 奠仪) + 香烛 + 纸花。
- **出殡 (Chūbìn)**: 出殡日, 抬棺 (棺出大门). 现代:殡仪馆告别仪式. 现代 大都市 火葬 (huǒzàng) 多. 偏远地区 仍 土葬 (tǔzàng) 多.
- **烧纸 (Shāozhǐ) / 烧纸钱 (Shāo zhǐqián)**: 路边 / 街口 / 墓地烧纸钱给亡者. 7天/14天/21天/百日/头七 (tóuqī) 仍会祭祀. 现代 鲜花/小红花 / 网上云祭扫.
- **守孝 (Shǒuxiào)**: 父母亡故后, 子女戴孝 (dàixiào) — 穿白色 (近) / 麻衣 (白色粗麻). 3 年内 (实 27 个月, deceased 兄弟 6 个月). 现代 简化, 头 7-49 天 穿黑/素服 即可.
- **棺材 (Guāncai) + 墓穴 (Mùxué)**: 风水 宝地 (fēngshuǐ bǎodì, lucky fengshui spot). 山地/平原差别. 现代 火葬 = 骨灰盒 (gǔhuī hé).
- **祭日 (Jìrì)**: 头七 (死后 7 天) / 二七 / 三七 / 四七 / 五七 / 六七 / 七七 / 百日 / 周年. 每年 清明, 春节, 中秋 也祭.
- **禁忌**: 春节期间 不串门 不拜年; 满月 / 18岁 / 婚嫁 不能同月 (重孝期间); 服丧中 不动土 / 嫁娶.
- **纸扎 (Zhǐzā)**: 纸糊 房子 / 车 / 电视 / 衣服, 殡仪时 烧给亡者. 现代 多 鲜花 取代.

## Cross-language Connections

- **한국어**: 한국 丧礼 (장례) 와 같은 의식 — 招魂 + 吊丧 + 守灵 + 火葬. 然而 한국 은 佛教 / 基督教 양분, 기독교 教堂 장례 와 佛家 영구 (yunggu) 영정 (yeongjeong) 다름. 중국은 风水/阴宅 概念 (한국 과 부분 동일).
- **Japonés**: 日本 お葬式 (葬礼) + 仏坛 拜 + お盆 8월 13-16 祭祖 (お盆 お 彼岸). 焼香 (しょうこう) + 遺影 (えい) 拜 + 御香典 (香典, 奠仪). 中国 烧纸 与 日本 焼香 不同, 但 의식 近.
- **Inglés**: 없음; Western葬礼 之 Christian tradition (memorial service, urn burial) 는 中国 火葬 + 微信 群通知 와 약간 유사.

## Ejemplos

「我奶奶去世后,我们全家为她守灵三天三夜,每天都有亲友来吊唁。」— 守灵 + 吊唁 礼仪.

「烧纸时要画一个圆圈,留一个口子,据说这是给亲人'收钱'用的。」— 烧纸圈 习俗.

「城市现在多火葬,但老家农村很多还保留着土葬传统,讲究'入土为安'。」— 火葬 vs 土葬 城乡 差异.
