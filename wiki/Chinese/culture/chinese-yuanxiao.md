# 元宵节 (Yuánxiāo Jié) — Lantern Festival

**Overview:** 元宵节 (Yuánxiāo Jié) 是农历正月十五 (음력 1월 15일),春节的收官节 (春节 first day + 15th day = 元宵节)。核心:元宵 (yuánxiāo, glutinous rice balls in soup) + 花灯 (huādēng, lanterns) + 灯谜 (dēngmí, riddles)。2008 年列入国家级非物质文化遗产。

## Key Points

- **日期**: 农历 1月 15日,2024 = 2024-02-24, 2025 = 2025-02-12. 公历 2월 中旬-下旬。正月 = 春节的第一个月。
- **元宵 (Yuánxiāo)**: 糯米粉团,内馅 (黑芝麻/花生/红豆/枣泥),煮甜汤。象征"团圆" (tuányuán) — 圆形象征。北方"滚"元宵 (roll technique),南方"包"汤圆 (wrap technique)。量词:一**碗**/一**颗**。
- **花灯 (Huādēng)**: 传统花灯 — 兔子灯/莲花灯/龙灯/走马灯。现代:豫园灯会、自贡灯会、夫子庙灯会 (南京)、开封菊花灯。上海豫园灯会每年正月举办。
- **灯谜 (Dēngmí)**: 把谜语写在花灯上,赏灯人猜。谜语多为中文汉字谜 (形/音/义)。
- **舞龙舞狮 (Wǔlóng wǔshī)**: 元宵节常见街头表演。
- **吃汤圆 vs 元宵**: 南方"汤圆"(包馅糯米粉团),北方"元宵"(馅在糯米粉里滚成)。中秋节也吃汤圆 (但叫 汤圆 不叫元宵)。
- **观灯 (Guāndēng)**: 古代女性外出赏灯的少数机会之一 (freeing from confinement)。
- **诗词**: "东风夜放花千树,更吹落,星如雨" (辛弃疾《青玉案·元夕》)。
- **传统**: 古代元宵节 = 中国情人节 (约等于 七夕),未婚男女相会。

## Cross-language Connections

- **한국어**: 한국 정월대보름 (음력 1월 15일) 와 같은 날. 둘 다 음력 15일, 달 가득 참. 한국은 十五 쌀 + 부럼 + 쌍둥이 탯줄; 중국은 元宵 + 花灯 + 灯谜. 같은 "lunar full moon" 배경.
- **Japonés**: 일본 小正月 (음력 1월 15일, 또는 양력 1월 15일) — 初詣 마무리 + 小豆粥 + 左義長 (sagichō) 의식. 중국 元宵节 의 花灯 보다는 차분한 의식.
- **Español**: 없음 정확히 대응하는 것 없음. Western Carnival (카니발) 가 사순절 직전 + 가면/축제 의식 유사하지만 보름달/음력 기준 아님.

## Ejemplos

「元宵节那天,我和家人在夫子庙逛灯会,猜灯谜,吃汤圆,热闹非凡。」— 灯会 + 灯谜 + 汤圆 = 元宵节 三部曲.

「妈妈今天煮了一锅黑芝麻汤圆,甜甜的,一家人围坐在一起吃,象征团团圆圆。」— 元宵의 핵심 의미:团圆.

「古时候的元宵节是未婚男女相识的好机会,有'众里寻他千百度,蓦然回首,那人却在灯火阑珊处'的浪漫意境。」— 辛弃疾 词.
