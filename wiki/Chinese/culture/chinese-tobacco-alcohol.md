# 中国 烟酒 (Yānjiǔ) — Tobacco, Alcohol & Social Currency

**Overview:** 烟酒文化 (Yānjiǔ wénhuà) 在中国是社交货币 (shèjiāo huòbì). 烟酒本身 是 商品, 但 是 gift / connect / 庆典. 茅台 (Máotái) + 中华 (Zhōnghuá 烟) = 标配. 用于求人办事, 招待, 商务 谈判, 婚礼 庆典. 烟酒 = 餐桌 必齐. 现代 中国 是 世界 第一 大 白酒 consuming + 烟 consuming 国.

## Key Points

- **白酒 (Báijiǔ, "white liquor")**: 透明色 高粱酒 (gāoliáng jiǔ). 度数 38-65%. 主流香型:
  - **酱香 (Jiàngxiāng, soy sauce aroma)**: 茅台 (Máotái), 郎酒 (Lángjiǔ). Kweichow.
  - **浓香 (Nóngxiāng, strong aroma)**: 五粮液 (Wǔliángyè), 泸州老窖 (Lúzhōu Lǎojiào). Sichuan.
  - **清香 (Qīngxiāng, light aroma)**: 汾酒 (Fénjiǔ). Shanxi.
  - **米香 (Mǐxiāng, rice aroma)**: 桂林三花酒 (Guìlín sānhuā jiǔ). Guangxi.
  - **凤香 (Fèngxiāng)**: 西凤酒 (Xīfèng jiǔ). Shaanxi.
- **茅台 (Máotái)**: 茅台镇 (Máotái zhèn), 贵州. 53 度 / 百年品牌 (1915 巴拿马 金奖). 飞天茅台 (Fēitiān Máotái) = 标准. 普通 1499 元/瓶, 但 实际 零售 2500-3000+ 元. 送礼 标配.
- **中华 烟 (Zhōnghuá yān)**: 上海 烟草. 硬中华 + 软中华 (软 50/包, 硬 30/包). 红色包装. 200 元/条 - 600 元/条. 收礼 商/政务 通用.
- **烟 一根 礼节 (Yān yī gēn lǐjié)**: 两男见面,主人开 一整包,发 一根 to each. 火 = 30+yo uses 打火机 提供给他人. 拒 烟 = 거절 (不恭敬). 烟 名牌 例: 中华 / 玉溪 / 黄鹤楼 / 云烟 / 利群 / 南京 (九五之尊).
- **酒桌 礼仪** (见 [[chinese-banquet-seating|圆桌席位]]):
  - **干杯 (gānbēi)**: 满杯 一饮而尽. 与 韩国 건배 类似.
  - **随意 (suíyì)**: "freely drink" — 自由 喝. 通常 上级 → 下级 说 "随意".
  - **敬酒 顺序**: 主人 → 主宾 → 主宾 邻居 → 一般 宾. (顺时针 还是 逆时针 一般 对主宾 而言 近 高优先级).
  - **打圈 (dǎquān)**: 主人敬 时 一桌 一杯 不挨个 敬, 依次 一桌喝 一杯. 例如 10桌 婚礼 → 主人 一杯桌桌 end.
- **酒量 / 拼酒 (Pīnjiǔ)**: 拼酒 = 较量酒量. 商业 deal / 兄弟 感情 = 拼 必要. "感情深,一口闷" (gǎnqíng shēn, yī kǒu mèn) 说法.
- **名酒 礼品 (Mǐngjiǔ lǐpǐn)**:
  - **送礼 (sònglǐ)**: 茅台 + 五粮液 = 老人 / 老人 长辈 上级; 普通场景 剑南春 (Jiànnánchūn) / 洋河 (Yánghé) / 古井贡 (Gǔjǐnggòng).
  - **婚礼 酒 (hūnlǐ jiǔ)**: 茅台 + 五粮液 + 数百 喜烟 (Xǐ yān, 红双喜 烟) + 红盒 / 喜糖.
  - **女儿红 (Nǚ'ér hóng)**: 黄酒 + 当女儿 出嫁 时 喝 = 传统 习俗. 浙江 绍兴 (Shàoxīng) 产.
- **喝酒 风俗**: 
  - **无酒不成席 (wú jiǔ bù chéng xí)**: "Without liquor not a proper banquet." 
  - **敬酒 厚礼**: 双杯 + 5-6 客人 满杯 = "诚意" 表达.
- **现代 变迁**: 反腐 (2013+) + 限酒令 + 健康 概念 上升. 茅台 价格 升 名义 (礼品 市场), 但是 实际 大桌 拼酒 减.
- **青少年 烟**: 与 韩国 不同, 中国 2024 烟民 超 3 亿 (= 24% 成年 人口). 男性 도 35%+, 较少 女性.

## Cross-language Connections

- **한국어**: 한국 의 酒桌 文化 와 같은 干杯 / 막걸리 / 소주 (烧酒) / 안주 - 둘 다 含酒精饮料的饭菜. 韩国 烧酒 (소주) ~20%, 中国 白酒 38-65%, 酒量 上限 한국 多. 敬酒 순서 매우 비슷.
- **Japonés**: 日本 은 술 горазды 更 적음 (원룸 酒量 적어). 酒桌 의 仪式 较弱. 日本 清酒 ~15%, 中国 白酒 38-65%, 中国 가 强함.
- **Inglés**: 보이지 가장 다름. Drinking culture in US / UK 식당 에선 会 单独 饮, 中国 은 반 필수적 餐桌 礼仪. China 의 "拼酒 / 干杯" 是 Western 에 없음.

## Ejemplos

「老板拿出一瓶飞天茅台,说:'来,大家干一杯,合作愉快!'」— 茅台 + 干杯 + 商务.

「给客户送了两条软中华和两瓶五粮液,这是最体面的见面礼。」— 烟酒 礼品 配置.

「老一辈说'感情深,一口闷',可现代年轻人流行'随意喝',没那么拼酒了。」— 拼酒 의 现代 变迁.
