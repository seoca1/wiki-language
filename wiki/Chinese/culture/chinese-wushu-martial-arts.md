# 武术 (Wǔshù) — Chinese Martial Arts

**Overview:** 武术 (Wǔshù) = 中国 传统 武术, 又名 国术 (guóshù), 含 套路 (tàolù, forms) + 散打 (sǎndǎ, free combat) + 兵器 (bīngqì, weapons). 起源 自 原始 社会 部落 战斗, 系统 化 于 春秋 + 宋朝 "十八般武艺" (shíbā bān wǔyì). UNESCO 2020 "'Taijiquan' (太极拳)" + 2021 "Shaolin kungfu" (少林功夫) 都 列入 人类非 物质 文化遗产.

## Key Points

- **主要 门派 (Zhǔyào ménpài)**:
  - **少林 (Shàolín)**: 河南 登封, 嵩山. 拳 法 硬, 刚 猛. 套路 多 (72 艺). 拳 = 长拳 (chángquán, long form) / 炮 拳 (pàoquán) / 洪 拳 (Hóngquán) 等.
  - **武当 (Wǔdāng)**: 湖北 武当山. 内家 拳, 柔 / 静 / 慢 / 含. 太极 (tàijí) + 形意 (xíngyì) + 八 卦 (bāguà).
  - **峨眉 (Éméi)**: 四川. 含 三大 支 (佛 / 道 / 俗). 套路 灵 活.
  - **陈式太极 (Chénshì tàijí)**: 河南 陈家沟. 太极 起源.
  - **杨式太极 (Yángshì tàijí)**: 杨露禅 (Yáng Lùchán) 改良. 多 大众 学.
  - **吴式太极 (Wúshì tàijí) / 孙式 / 武式**: 各 派.
- **常见 拳 (Chángjiàn quán)**:
  - **太极拳 (Tàijíquán)**: 内家, 24 / 48 / 108 式. 动作 慢, 调 息, 医 疗 + 武术.
  - **长拳 (Chángquán)**: 少林 代表. 节奏 快, 跳跃 多. 1950s 全国 统一 套路.
  - **形意拳 (Xíngyì quán)**: 五行 + 十二 形 (龙 / 虎 / 猴 / 马 / 鸡 / 燕 etc).
  - **八卦掌 (Bāguà zhǎng)**: 走 圈, 掌 法.
  - **咏春 (Yǒngchūn)**: 南 方, 短 桥 窄 马. 葉問 (Yè Wèn, Ip Man) + 李 小龙 (Lǐ Xiǎolóng, Bruce Lee) 推.
  - **截拳道 (Jiéquándào)**: 李 小龙 (Bruce Lee) 创.
  - **擒拿 (Qínná)**: 控制 关节.
  - **散打 (Sǎndǎ)**: 现代 武术, 中国 自由 搏击.
- **套路 vs 散打 (Tàolù vs sǎndǎ)**:
  - **套路**: 单 人 / 双 人 / 集体 演 练, 美观, "表演 化".
  - **散打**: 实战, 自由, 打对手. 1950+ 现 代 比 赛.
- **兵器 (Bīngqì, weapons)**: 刀 (dāo) / 剑 (jiàn) / 枪 (qiāng) / 棍 (gùn) / 鞭 (biān) / 锤 (chuí).
  - **剑 = 短 兵, 刀 = 长 兵**. 古 "十八般 武艺" 含 9 长 9 短.
- **练功 器具 (Liàngōng qìjù)**:
  - 木 桩 (mùzhuāng, wooden dummy) — 咏春 用.
  - 沙 包 (shābāo, sandbag).
  - 梅花 桩 (méihuāzhuāng, plum blossom stakes).
- **学习 路线 (Xuéxí lùxiàn)**: 基本 功 (jīběngōng, basics) → 套路 → 拆招 (chāizhāo, drilling) → 实战.
- **武 德 (Wǔdé)**: 武 术 道德 — 尊师 / 重义 / 守约 / 强身 + 不 恃 强 凌 弱.
- **现代 武术 (Xiàndài wǔshù)**:
  - **武术 比赛**: 全国 武术 套路 锦标赛 (1959+), 1990 亚 运 会 入.
  - **Wushu-Kungfu Federation**: 国际 推广.
  - **影视 / 武打片 (yǐngshì wǔdǎ piān)**: 成龙 (Chéng Lóng) / 李连杰 (Lǐ Liánjié) / 李小龙 (Lǐ Xiǎolóng) — Kung Fu 功夫.

## Cross-language Connections

- **한국어**: 한국 의 무예 (武藝) + 택견 (Taekkyeon) + 합기도 (合氣道) + 태권도 (TKD). 다 中의武术 独立 派生. 한국 어 有跆跟 跟 跆괸 (Tae Kwon) "脚 拳". 둘 다 套路 + 实战. 한국 태권도 는 현대 Olympic sport.
- **Japonés**: 일본 의 武道 (budō): 空手 (karate) + 柔道 (judō) + 剣道 (kendo) + 合気道 (aikido). 中 武术 와 직접 影响 但 多 自 발. 일본 "柔道" (Jigoro Kano) + "空手" (沖繩) Chinese martial context 와.
- **Inglés**: 없음 直 接 对应. Western "martial arts" = 빈 term, 含 TKD / kungfu / karate / boxing / muay thai / judo. 中国 武术 = unique 概念.
