# 胡同 文化 (Hútòng Wénhuà) — Beijing Hutong Culture

**Overview:** 胡同 (Hútòng) = 北京 (Běijīng) 旧 城 内 的 窄 巷 / 小 街, 是 元 明 清 北京 城 的 基 本 街 巷 系统. 6000+ 条 现 存 (元 大都 时代 起 始, 13c 1267+ 起). 现 代 部 分 保 护 (南 锣 鼓 巷 / 烟 袋 斜 街 / 帽 儿 巷 等) + 部 分 拆 除. 2009 北京 烟 袋 斜 街 等 列 入 文 化 部 国 家 级 风 景 名 胜 区 域.

## Key Points

- **词源 (Cíyuán)**: "胡同" 起源 蒙 古 语 (13c 元 朝): "hottog / gudum" (井 / 水 源). 北京 蒙 古 语 接触 期, 多 蒙 古 借 词 同 时 进 入. "胡同" = "guttural / 路". 全 国 仅 北京 沿 用.
- **四合院 (Sìhéyuàn, "four-side courtyard")**: 胡同 的 基 本 居住 单 元.
  - **布局**: 方 正 院, 北 房 (正 房 zhèngfáng) + 东 房 (东 厢 dōngxiāng) + 西 房 (西 厢 xīxiāng) + 南 房 (倒 座 房 dàozuòfáng) + 院门. 四 方 围 合, 中 = 院 子.
  - **大门 (Dàmén)**: 大 多 开 东 南 角 / 北 西. 红 门 / 油 漆. 黑 漆 门 + 铜 铺 首 = 中 高 官 门. 一般市民 灰 门.
  - **照壁 (Zhàobì)**: 大门 内 / 外 的 影 壁 = 防 鬼 / 挡 风 / 保 私.
  - **垂 花 门 (Chuíhuā mén)**: 二 进 / 三 进 四 合 院 中 连接 中. 木 雕.
  - **屋 顶**: 灰 瓦 顶 (gǎu wǎ) + 筒 瓦.
  - **宅 内 布 局**: 中 堂 (中 厅) + 祖 先 牌 位 + 家 神.
- **居民 / 邻里 (Jūmín / línlǐ)**:
  - **大 杂 院 (Dàzáyuàn)**: 一 个 大院 住 几 十 家, 公 用 厕所 / 自 来 水.
  - **邻里 文化 (Línlǐ wénhuà)**: 互 助 / 互 访 / 看 门 / 叫 卖 (叫卖 者, 摇 拨 浪 鼓, 4py 4yāo 摇 头). 冬季 自 助 (大 妈 互 助 拉 煤 球).
  - **爷 (yé)**: 长 者 / 胡 同 大爷 = 大 院 老 前 辈 = 调 解 邻 里 争 执.
- **商业 (Shāngyè)**: 
  - **小 店 (xiǎo diàn)**: 茶 馆 / 烧 饼 铺 / 豆 汁 店 / 修 鞋 / 修 伞 / 旧 书 摊. 商业 文化 = 房 街 共 生.
  - **门 联 / 招 牌**: 胡 同 小 店 的 手 写 牌 匾 + 春 联.
- **胡同 名 含义 (Hútòng míng hányì)**:
  - 方 位 (南 / 北 / 东 / 西 + 司 胡同).
  - 人 名 (X 人 故 居).
  - 商 业 (X 楼 + 胡同 = 当 年 该 商 业 发 达).
  - 形 状 (九 条 巷, 帽 儿 巷).
  - 动 植 物 (花 枝 胡 同, 鹊 儿 胡 同).
- **代表 性 胡同 (Dàibiǎoxìng hútòng)**:
  - **南 锣 鼓 巷 (Nánluógǔ Xiàng)**: 元 大 都 时 代. 现 游 客 文 化 + 创 意 商 业.
  - **烟 袋 斜 街 (Yāndài Xiéjiē)**: 后 海 旁. 烟 袋 店 多, 现 古 玩 + 风 味 食 物.
  - **什 刹 海 (Shíchàhǎi)**: 后 海 + 银锭 桥. 元 代 名 胜.
  - **帽 儿 巷 (Màor Xàng)**: 现 文 化 区.
- **历史 变迁 (Lìshǐ biànqiān)**: 
  - 元 大都 (1267+): 胡 同 系统 成 形.
  - 明 清 繁 荣: 3000+ 条.
  - 1949 后: 国 家 机 关 住 胡 同 + 大 杂 院.
  - 1990s+ 旧 城 改 造: 部 分 胡 同 + 四合 院 拆 建 高 层.
  - 2000+: 文 化 保 护 强 化. 现 存 ~6000 条.

## Cross-language Connections

- **한국어**: 한국 의 한옥 (hanok) 마을 (북촌 한옥마을) 와 비교. 둘 다 "한 집 院 + 巷 道" 의 형태, 北韩 백제 + 中의 传统. 韩国 한옥마을 (北村) 유사 Beijing 帽 儿 巷 / 南 锣 鼓 巷. 韩国 에 도 韩屋 (한옥) + 鬪 / 옹 / 비석. 다 似.
- **Japonés**: 일본 "路地 (roji)" + "長屋 (nagaya)" + "町家 (machiya)" 가 中 의 类似. 둘 다 窄 路 + 共同 院 + 邻 里. 그러나 北京 胡同 의 4 合 院 = 庭 院 独立 (4 面), 日本 长屋 = 共 用 墙 + 内 侧 (semi-shared).
- **Inglés**: 없음 직 接 대응. Western "alley" / "lane" (= 胡同 의 동 等), 그러나 4 合 院 (4-sided courtyard) は 없습니다.

「老北京的四合院里,中堂上是供祖先牌位,两侧是长辈的房间。」— 四合 院 中堂 礼.

「北京的胡同名字特别好听,什么帽儿巷、烟袋斜街、九条巷,每条都有一段历史。」— 胡 同 名 含义.
