# 竹 文化 (Zhú Wénhuà) — Bamboo Culture / 君子四友

**Overview:** 竹 (Zhú, Bamboo) 在中国文化中象征文人气节 (jīeqiě, integrity). 与 松 / 梅 / 兰 并称 "岁寒三友" (suì hán sān yǒu = "Three Friends of Winter") 或 加入 菊 = "四君子" (sì jūnzǐ = "Four Gentlemen"). 文人 园 画 诗 中 重要 题材. 中国 是 世界竹 main 产出国 (世界 竹林 70%+). 2001 世界园艺大会 在 中国 100+ 城市 设立 "竹园" 公园. UNESCO 2008 "中国 四川 成都 大熊猫栖息地" 间接 保护 了 竹林.

## Key Points

- **植物学 (Zhíwù xué)**: 
  - **学名 (Xué-míng)**: Bambusoideae (禾本 科 竹亚科). 多 1000+ 种.
  - **生长 (Shēngzhǎng)**: 竹 一日 长 1米+ (some species). 3-5 年 可成 林.
  - **主产区 (Zhǔchǎnqū)**: 四川, 湖南, 浙江, 安徽, 福建, 江西, 贵州.
- **品种 (Pǐnzhǒng)**:
  - **毛竹 (Máozhú, Moso bamboo)**: 最大 生 食 工艺.
  - **紫竹 (Zǐzhú, Purple bamboo)**: 庭院 装饰.
  - **方竹 (Fāngzhú, Square bamboo)**: 贵州 桐梓.
  - **佛肚竹 (Fódùzhú, Buddha belly bamboo)**: 节间 鼓起, 装饰.
- **"岁寒三友" / "四君子"**:
  - **松 (Sōng, Pine)** — 坚韧 (jiānrèn, resilience) / 长青
  - **竹 (Zhú, Bamboo)** — 中空 (zhōngkōng, hollow / modest) / 柔韧 / 不 折
  - **梅 (Méi, Plum)** — 傲雪 (àoxuě, snow-resistant) / 春 报
  - **兰 / 菊 (Lán / Jú, Orchid / Chrysanthemum)** — 高洁 / 不 妖
  - **四君子** = 梅 + 兰 + 竹 + 菊
- **象征 (Xiàngzhēng)**:
  - 虚心 (xūxīn, modest / humble) — 竹 空心 = 心 中 虚.
  - 有节 (yǒujié, principled) — 竹 节 明显 = 君子 刚 直.
  - 坚韧 (jiānrèn, resilient) — 弯 不 折.
  - 不断 (bù duàn, ongoing) — 竹 节 不断, 比喻 子孙 continuously.
- **工艺 (Gōngyì)**: 筷子 (kuàizi) / 竹编 (竹工艺品) / 笔 (毛笔 màobǐ) / 竹笛 (zhúdí) / 竹筏 (zhú fá). 2008 UNESCO "贵州 苗族 竹编" 部分 列表.
- **食物 (Shíwù)**: 竹笋 (zhúsǔn, bamboo shoots) — 春 节 鲜 鲜 食, 配 鸡 / 火腿 = "腌笃鲜 (yān dǔ xiān)". 冬笋 / 春笋 / 鞭笋.
- **竹 建筑 (Zhú jiànzhú)**: 竹 房 (安吉), 竹 桥, 竹 亭, bamboo scaffolding.
- **竹 造纸 (Zhú zàozhǐ)**: 竹 纤维 强, 古 仍 用 (e.g. 福建 闽北 竹纸).
- **画 / 诗 (Huà / shī)**: 竹 是 "画竹 (huàzhú)" 经典 题材. 苏轼 (Sū Shì) "宁可食无肉,不可居无竹. 无肉令人瘦,无竹令人俗." (Nǐngkě shí wú ròu, bùkě jū wú zhú...).
- **风水 (Fēngshuǐ)**: 院 子 栽竹 旺 财 / 学 / 官. 竹 7 棵 together = 平安.

## Cross-language Connections

- **한국어**: 한국 의 대나무 (대, dae) 文化 가 부분 类似 — 大君子的 "竹" 사진 보단 적음. 그러나 한국 의 "매죽 (梅竹)" 의 "竹" + "죽세 (竹세)" + 대나무 숟가락 등. 한국 어 "竹 (대)" 上, 학 (학조) 安 风景 의 竹 主题.
- **Japonés**: 일본 の 竹 (たけ, take) 文化 매우 강함 — 竹 工艺品 (竹製品 / 竹 箸 / 竹 笛) + 竹 取物 语 (Taketori Monogatari, Princess Kaguya). 그러나 君子 의 symbolism 日本 보다는 약함.
- **Inglés**: 없음. 영어 bamboo 은 단순 식물. "bamboo culture" 는 中国 만의 noun.

## Ejemplos

「苏东坡说:'宁可食无肉,不可居无竹。无肉令人瘦,无竹令人俗。' 这最能说明竹在文人生活中的地位。」— 苏轼 (Sū Shì) 의 竹诗.

「我祖父喜欢在院子里种竹子,他说:'门前有竹,家有万卷书。'」— 风水 + 学问 象征.

「江南人春天挖竹笋,做出腌笃鲜,是红楼梦里贾府宴席上常有的汤菜。」— 竹笋 文学 关联.
