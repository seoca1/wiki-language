# 中文 5 种 字体 (Zhōngwén 5 Zhǒng Zìtǐ) — Five Major Script Styles

**Overview:** 中文 五种主要字体 (5 zhǒng zìtǐ) = 篆 (zhuàn, seal) / 隶 (lì, clerical) / 楷 (kǎi, regular) / 行 (xíng, running) / 草 (cǎo, grass). 历经 商 (14c BC) → 汉 (206 BC-220 AD) → 魏晋 (220-420) → 唐 (618-907) → 今. 每 字体 含 历史 时代 + 书法美 学. 整体 = 中 国 文字 演 化 完整 链.

## Key Points

- **篆书 (Zhuànshū, Seal Script)**:
  - **时代 (Shídài)**: 商 周 (商 14c BC, 周 1046-256 BC) → 秦 (221-206 BC, 小篆). 起源 甲骨文 (jiǎgǔwén, oracle-bone). 古 文字.
  - **特点**: 线条 圆转, 笔 画 均 匀, 字 形 长 方.
  - **类型**: 大篆 (dàzhuàn, 籀文) / 小篆 (xiǎozhuàn, 秦 统一). 秦 李斯 (Lǐ Sī) 统一 全 国 字 体.
  - **用途**: 1) 印章 (yìnzhāng, seal), 2) 碑 额 题 字, 3) 装饰, 4) 书法 收藏.
- **隶书 (Lìshū, Clerical Script)**:
  - **时代**: 秦 末 → 汉 (206 BC-220 AD) 成 熟, 魏 晋 后 慢 慢 没 落.
  - **特点**: "蚕 头 燕 尾" = 横 笔 起 头 蚕 (silkworm head) + 收 尾 燕 (swallow tail). 横 平 竖 直, 字 形 方.
  - **改革**: 简化 篆 圆转 = 方 折. 加 "波 磔 bōzhé" (挑 出). 笔 法 完 全 重 新 设 计.
  - **用 途**: 1) 官 府 公文 (汉 隶 = 公文), 2) 石 碑 摹刻, 3) 书法 练 习.
- **楷书 (Kǎishū, Regular Script)**:
  - **时代**: 汉 末 → 魏 晋 (220-420) → 唐 (618-907) 成熟.
  - **特点**: 标准, 字 形 正 方, 笔 画 清楚, 是 现 代 通 用 字.
  - **代 表**: 欧 (欧阳询 Ōuyáng Xún, 欧体) / 颜 (颜真卿 Yán Zhēnqīng, 颜体) / 柳 (柳公权 Liǔ Gōngquán, 柳体) / 赵 (赵孟頫 Zhào Mèngfǔ, 元). 共 "楷 书 四 大 家".
  - **用途**: 1) 教 育 写 字, 2) 公 文, 3) 印刷, 4) 各 种 文 体.
- **行书 (Xíngshū, Running Script)**:
  - **时代**: 后 汉 / 魏 晋 → 唐 成熟.
  - **特点**: 介于 楷 + 草 之 间. 多 连 笔, 简 化 + 流 动, 可 辨 认.
  - **代 表**: 王羲之 (Wáng Xīzhī) 《兰亭集序》= "天下 第一 行 书". 苏轼 (Sū Shì), 米芾 (Mǐ Fú), 赵孟頫 (Zhào Mèngfǔ).
  - **用途**: 1) 公 文, 2) 笔 记, 3) 信 函, 4) 公 务 日 常 书 写.
- **草书 (Cǎoshū, Grass Script)**:
  - **时代**: 汉 → 唐 成熟.
  - **特点**: 多 连 笔, 笔 画 简 省, 美 学 极 强, 但 难 辨 认. "龙 飞 凤 舞".
  - **类 型**: 章 草 (zhāngcǎo, 汉, 较 含 蓄) / 今 草 (jīncǎo, 唐, 自 由 飞 动) / 狂 草 (kuángcǎo, 极 端 自 由).
  - **代 表**: 张 旭 (Zhāng Xù) "草 圣" / 怀 素 (Huái Sù) "狂 草".
  - **用途**: 1) 美 术 艺 术, 2) 表 达 情 绪, 3) 收 藏.
- **顺序 / 演 化 图 (Shùnxù)**:
  - 甲骨 文 → 金 文 → 大 篆 → 小 篆 (秦) → 隶 (汉) → 楷 (魏 晋 - 唐) → 行 (晋 唐) → 草 (唐).
- **书 法 美 学 + 哲学 (Shūfǎ měixué)**:
  - 各 体 有 异 美. 篆 = 古朴 / 隶 = 雄强 / 楷 = 端庄 / 行 = 流 畅 / 草 = 飞 动.
  - 中国 书法 哲 学 重 "气 韵" + "骨 力" + "神 韵" 三 要 素.

## Cross-language Connections

- **한국어**: 한국 학자 的 한자 字 体 (篆/隶/楷/行/草) 와 direct mapping. 韩国 の 书法 (서예) 가 위 다 5 体 모두 写, 그러나 主流 = 楷 + 行 + 草. 韩文 (훈민정음 1443) 의 서체 통 26 字 + 现代 한글, slightly 다름.
- **Japonés**: 일본 書道 (shodō) 도 5 体 모두 知하나, 主流 楷 / 行 / 草. 일본 片假名 (片仮名) + 平假名 (平仮名) 는 平安 时代 "草書体" 에서 파생 (히라가나) + "楷 書体" から 변형 (カタカナ).
- **Inglés**: 없음 직 接 대 응. Latin alphabet 의 script styles (capitalis / uncial / italic / cursive) 와 隐喻 类似, 但是 中国 5 体 의 哲学 / 美学 / 历史 의 깊이 ≠.

## Ejemplos

「我学书法时老师先让我临摹《颜勤礼碑》,打好楷书基础,再学行书和草书。」— 楷 → 行 → 草 顺序.

「王羲之的《兰亭集序》被称为'天下第一行书',全文二十八行,每行都流畅自然。」— 行书 代表.

「张旭写狂草时常常酒醉后挥毫,笔走龙蛇,字字连绵,外人几乎认不出来。」— 狂草 + 酒 情.
