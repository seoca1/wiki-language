# 中国 戏曲 (Zhōngguó Xìqǔ) — Regional Chinese Opera Genres

**Overview:** 中国 戏曲 (Zhōngguó xìqǔ) 是中国 传统 戏剧 总 称. 以 "唱 (chàng) + 念 (niàn) + 做 (zuò) + 打 (dǎ)" 四 功 配 "手 (shǒu) / 眼 (yǎn) / 身 (shēn) / 法 (fǎ) / 步 (bù)" 五 法. 起源 自 汉代 百 戏, 成熟 于 宋 元 南 戏, 顶峰 于 明 清. "百 戏 之 祖" + "百 戏 之 王" = 昆曲 + 京剧. UNESCO 2001 "Kunqu Opera" (昆曲) 列入 人类 非物 质 文化 遗产. UNESCO 2010 "Beijing Opera" + 2009 "Naxi ancient music" 等 多。

## Key Points

- **京剧 (Jīngjù, Beijing Opera)**: 1790+ 形成, 1840s 成熟. 4 大 徽班 进 京 + 1 大 秦腔 进 京. 服饰 (lièshì / chángpáo), 脸谱 (liǎnpǔ, painted face), 唱 念 做 打.
  - **角色 (Juésè)**: 生 (shēng, male) / 旦 (dàn, female) / 净 (jìng, painted face) / 丑 (chǒu, clown). 生 细分 老生 (lǎoshēng) / 小生 (xiǎoshēng) / 武生 (wǔshēng). 旦 细分 青衣 (qīngyī) / 花旦 (huādàn) / 武旦 (wǔdàn) / 老旦 (lǎodàn).
  - **脸谱 (Liǎnpǔ)**: 红 = 忠 勇 / 黑 = 正直 / 白 = 阴 / 金 = 神. 颜色 复杂 象征.
  - **代 表 作**: 《霸王别姬》(Bàwáng Bié Jī) / 《贵妃醉酒》(Guìfēi Zuìjiǔ) / 《三岔口》(Sānchàkǒu) / 《空城计》(Kōngchéng Jì).
- **昆曲 (Kūnqǔ, Kunqu)**: 元 末 (14 c) 起源. 江苏 昆山. "百 戏 之 祖" — 多 剧种 的 父 母. 明 清 的 主 流 剧 种. UNESCO 2001. 文雅, 唱 词 文学 性 高. 《牡丹亭》(Mǔdāntíng) / 《长生殿》(Chángshēng Diàn) / 《桃花扇》(Táohuā Shàn).
- **粤剧 (Yuèjù, Cantonese Opera)**: 广东 + 香港. 清 代 中 期 成熟. 普通 话 改 用 粤 语 + 广 州 话. 配 器 富 岭 南 特色 (高胡 / 秦琴 / 椰胡). 《帝女花》(Dìnǚhuā).
- **越剧 (Yuèjù, 区别于粤剧)**: 浙江 嵊州. 女性 角色 主 演 (清 一色 女 演员). 《梁山伯与祝英台》(Liáng Shānbó Yǔ Zhù Yīngtái) — "中国 罗 密欧 与 朱丽叶". 
- **川剧 (Chuānjù, Sichuan Opera)**: 四川. **变 脸 (biànliǎn, "changing faces")** 绝 技 — 数 秒 内 换 多 张 脸. 3 类: 抹 脸 / 吹 脸 / 扯 脸. 《白蛇传》变脸.
- **豫剧 (Yùjù, Henan Opera)**: 河南. 高亢, 板 腔. 《花木兰》(Huā Mùlán) 代表.
- **评剧 (Píngjù, Pingju)**: 河北 + 东北. 《刘巧儿》《花为媒》.
- **黄梅戏 (Huángméi xì, Huangmei Opera)**: 安徽 黄梅. 婉 转 优 美. 《天仙配》(Tiānxiān Pèi).
- **秦腔 (Qínqiāng)**: 陕西. "梆 子 腔" 之 父. 高亢 悲壮.
- **昆曲 + 京剧 差异 (Kūnqū vs Jīngjù)**:
  - 昆曲 文学 性 + 婉 转. 京剧 大气 + 武功.
  - 昆曲 唱 词 (念 白) 多 古 典. 京剧 念 白 近 口语.
- **伴奏 (Bànzòu)**: 京剧 = 京胡 (jīnghú) + 京二胡 + 月琴 + 三 弦. 昆曲 = 笛 子为主.

## Cross-language Connections

- **한국어**: 한국 의 杂剧 (Cháogǔ, 朝鲜 초 12th-14th c) + 唱剧 (Changgeuk, 19th c+) + 国 乐 唱 — 影响 与 中国 元 代 杂剧. 韩国 唱剧의 板 调系统 (pyŏngjŏn-라리 etc) 与 中国 鼓 + 梆 子 关联. 然而 韩国 传统 戏曲 现代 弱하다.
- **Japonés**: 日本 能 (Nō, 14c) + 歌舞伎 (Kabuki, 17c). 能剧 神秘 / 简素. 京剧 / 能剧 둘 다 mask / costume / dance + drama. 그러나 能剧 일인 演 多 角色 (shite / waki / tsure). 다面具 有 / mask.
- **Inglés**: 없음 직 접 대응. Western opera / musical theater 是 vocal + dramatic, however 아무 나름의 face painting + form / mask + dance combo = 없음.
