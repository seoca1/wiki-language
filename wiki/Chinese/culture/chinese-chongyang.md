# 重阳节 (Chóngyáng Jié) — Double Ninth Festival

**Overview:** 重阳节 (Chóngyáng Jié) 是农历九月初九 (음력 9월 9일),"九九重阳" = 二九相重,故名。2006 年列入国家级非物质文化遗产。核心:登高 (dēnggāo) + 敬老 (jìnglǎo) + 菊花 (júhuā) + 重阳糕 (chóngyáng gāo)。1989 年起 定为中国法定"老年节" (老 niánjié, Senior Citizens' Day)。

## Key Points

- **日期**: 农历 9月 9日,公历通常 10월 (2024 = 2024-10-11, 2025 = 2025-10-29)。
- **登高 (Dēnggāo)**: 登山 / 爬塔 / 登高台。古人相信登高避灾 (辟邪)。现代:重阳节老人徒步。
- **敬老 (Jìnglǎo)**: "老吾老以及人之老" (孟子). 1989 年中国定为"敬老日 / 老年节",2007 年起定为法定节日(非法定假日,2013 年起部分省市给假)。
- **菊花 (Júhuā)**: 9月-10月 盛开,菊花酒 (júhuā jiǔ) + 菊花糕 + 赏菊。菊花 = 高洁、傲霜 (抵抗衰老) 象征。
- **重阳糕 (Chóngyáng gāo)**: 米粉/糯米粉糕,有"步步高"寓意。层数 = 9 或 7。
- **茱萸 (Zhūyú)**: 古代佩戴"茱萸囊"辟邪。现代少见,但仍是文化符号。
- **重阳/九**: "九"为阳数 (单数) ;九月初九 = 双重阳 (重 chóng) = 阳气极盛。
- **诗词**: "独在异乡为异客,每逢佳节倍思亲。遥知兄弟登高处,遍插茱萸少一人。" (王维《九月九日忆山东兄弟》)。
- **别名**: 重九节 (Chóngjiǔ jié)、老人节 (Lǎorén jié)、登高节 (Dēnggāo jié)。
- **登高禁忌**: 部分地区认为"重阳登高是辟邪",忌讳不登高。

## Cross-language Connections

- **한국어**: 한국 중양절 (음력 9월 9일) 와 같은 날. 한국 중양절 의식 大部分 단절 (일본 강점기 이후), 남은 문화: 重陽餅 (중양떡) + 국화 (菊花) + 登高. 한국 의식 약화는 중국 과 대비.
- **Japonés**: 日本 重陽 (菊の節句, 9월 9일) — 五節句 중 5번째. 菊の酒 + 栗ご飯 + 菊花祭り. 현대 일본 에서 의식 거의 사라짐. 중국 重阳 + 敬老 의식 이 훨씬 강함.
- **Inglés**: 없음; Western Grandparents' Day (9월 둘째 주 일요일, US) 가 부분적으로 유사. 가족 노인 尊敬 의식.

## Ejemplos

「重阳节那天,我和爷爷一起登上了香山,看漫山遍野的红叶。」— 登高 + 秋景 = 经典重阳活动.

「在中国,每年重阳节也是老人节,子女会回家陪伴父母,带他们去公园赏菊。」— 敬老 是 现代 主流 主题.

「古人有在重阳节插茱萸、饮菊花酒的习俗,寓意辟邪、长寿。」— 茱萸 + 菊花 传统.
