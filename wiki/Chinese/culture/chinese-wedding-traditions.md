# 中国 婚礼 (Zhōngguó Hūnlǐ) — Chinese Wedding Traditions

**Overview:** 中国传统婚礼 (Zhōngguó chuántǒng hūnlǐ) 是一套包括拜堂、闹洞房、回门、敬茶的礼仪系统。现代简化版多保留红盖头、龙凤褂、敬茶、收红包的关键仪式,2009 年广东大襟婚礼列入省级非物质文化遗产。核心:红色 (hóng, 喜), 鞭炮 + 全家福 + 拜堂。

## Key Points

- **日期选择 (Rìqī xuǎnzé)**: 中国黄历 (nónglì, lunar calendar) + 命理 (八字 bāzì / 生肖) 选定 "良辰吉日 (liángchén jírì)"。避免新寡年, 避开 3/7 月, 选双日子 (初一/十五)。
- **彩礼 (Cǎilǐ)**: 男方给女方的聘金 + 礼品 (现代含三金/五金:项链/戒指/耳环/手镯/金条)。**聘礼 (pìnlǐ)** 含鱼 (有头有尾)、枣 (早生贵子) 等食物。
- **迎亲 (Yíngqīn)**: 结婚当日,新郎 (xīnláng) 带车队从酒店/男方家出发去接新娘 (xīnniáng)。新郎需"闯关"(姐妹/伴娘设考验,如找鞋)。
- **拜堂 (Bàitáng) / 三拜**: 一拜天地 (bàitiāndì, 감사), 二拜高堂 (bàogāotáng, 신랑 신부 부모), 夫妻对拜 (fūqī duìbài)。
- **敬茶 (Jìngchá)**: 新人给公婆/岳父母敬茶,改口叫"爸妈"。茶中放红枣/莲子 (早生贵子)。长辈给红包/金饰。
- **酒席 (Jiǔxí)**: 宴席,大圆桌 8-12 人桌,8-12 道菜 (主菜:鱼+鸡+肉+甜品),新郎新娘逐桌敬酒。
- **闹洞房 (Nào dòngfáng)**: 婚礼夜,亲友(主要是兄弟姐妹 + 同事)闹新房,戏弄新人,求热闹吉利。现代:游戏/玩笑/偷藏衣物。
- **回门 (Huímén)**: 婚后 3天 或 7天,新娘回娘家(俗称"三朝回门"或"双回门")。新郎陪同时探望岳父母。
- **红色主题**: 红盖头/红衣裳/红花轿/红对联/双喜字 (囍) — 红色 = 喜庆 (hóngxǐ)。
- **禁忌**: 新人见面不说"分开/倒霉";孕妇/守孝者忌入新房;忌送钟/伞/梨。

## Cross-language Connections

- **한국어**: 한국 혼인 의례 (혼례) 와 비교. 둘 다 따뜻한 colorful, 红包 와 礼金 모으기. 한국은 礼床 + 帛 + 舅礼/婚시给; 중국은 聘礼 + 敬茶. 현대 한국 혼인 는 中国 影响 받았는지 모습 较少, 家庭 중심 값 은 비슷.
- **Japonés**: 日本 結婚式 — 神前式 (with shrine) + 杯交わし +披露宴. 中国 婚礼 의 茶礼 + 改口 와 少し 類似的 부분. 그러나 中国 拜堂 / 闹洞房 는 일본 에 없음. 색 도 红色 (china) vs 白色 (japan).
- **Inglés**: Western wedding: white dress + church + bride's family pays. vs Chinese: red dress + banquet + groom's family pays. 핵심 차이: 颜色 / 비용 부담 / 仪式 规模.

## Ejemplos

「婚礼那天,新娘一身红盖头龙凤褂,新郎胸前戴大红花,两人在司仪的引导下完成三拜之礼。」— 三拜 = 拜天地 / 高堂 / 夫妻.

「闹洞房时,姐妹们把新娘的鞋子藏起来,逼新郎唱歌跳舞才能找回来。」— 闹洞房 + 藏鞋 是 经典 仪式.

「第二天回门,我妈准备了一桌丰盛的菜,岳父岳母给新人包大红包。」— 回门 + 红包.
