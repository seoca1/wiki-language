# 端午节 (Duānwǔ Jié) — Dragon Boat Festival

**Overview:** 端午节 (Duānwǔ Jié) 是农历五月初五 (음력 5월 5일),与韩国 단오 / 日本 端午 同期。2009 年起 列入 UNESCO 非物质文化遗产。核心:屈原 (Qū Yuán) 纪念 + 龙舟 (lóngzhōu) 竞渡 + 粽子 (zòngzi)。

## Key Points

- **日期**: 农历 5月 5日,公历 5월 말 - 6월 초。2024 = 2024-06-10, 2025 = 2025-05-31。
- **屈原 (Qū Yuán, 约公元前 340-278)**: 楚国 (Chǔ guó) 诗人、政治家,被放逐后于五月初五投汨罗江 (Mìluó Jiāng) 自尽。《离骚》(Lí Sāo)、《天问》(Tiān Wèn) 等楚辞 (Chǔ Cí) 代表作。
- **粽子 (Zòngzi)**: 糯米 (nuòmǐ) + 馅 (咸/甜) 用 粽叶 (箬竹叶/苇叶) 包裹,三角形/四角形。北方偏甜 (红枣、豆沙),南方偏咸 (猪肉、咸蛋黄)。量词:一**个**粽子。
- **龙舟 (Lóngzhōu)**: 龙头龙尾长舟,20+ 人划桨,鼓手击鼓指挥。起源:渔民划船救屈原,后演变为竞渡比赛。
- **雄黄酒 (Xiónghuáng jiǔ)**: 传统饮雄黄酒辟邪 (现代多为黄酒 huángjiǔ)。儿童额头点雄黄 "王" 字。
- **五色丝线 (Wǔsè sīxiàn)**: 五色 (青赤黄白黑) 丝线系手腕/脖子,驱五毒 (五毒:蛇/蝎/蜈蚣/蟾蜍/壁虎)。
- **艾草/菖蒲 (Àicǎo / Chāngpú)**: 挂门口辟邪,中草药。
- **别名**: 重五 (Chóngwǔ)、端阳 (Duānyáng)、午日节 (Wǔrì jié)、龙舟节 (Lóngzhōu jié)。
- **诗词**: "路漫漫其修远兮,吾将上下而求索" (屈原《离骚》),仍常引用。

## Cross-language Connections

- **한국어**: 한국 단오 (음력 5월 5일) 와 같은 날. 둘 다 五毒/厄除け 의식. 한국은 菖蒲湯 (창포탕) + 祭 + 端午绳 (단오끈); 중국은 雄黄酒 + 五色丝线 + 龙舟竞渡. 일본 端午 の ǔ蒲風呂 와 유사.
- **Japonés**: 日本 端午 (こどもの日 이전, 5월 5일) — 菖蒲 (しょうぶ) + 柏餅 (かしわもち) + 武者人形. 중국 端午 와 같은 시기에 ǔ蒲 共同 symbolism (菖蒲 = 尚武 / 勝負 谐音). 현대 일본 端午 는 男兒 の 祝日.
- **Inglés**: 없음; Western culture 에 직접 대응 없음. 단, Western 의 boat race + athletic competition 의 맥락은 龙舟赛 와 부분 유사.

## Ejemplos

「端午节那天,我们一家人会一起包粽子。妈妈包肉粽,爸爸包红枣粽,我包豆沙粽。」— 粽子 是 家庭 활동.

「每年端午,广州珠江上都会举行国际龙舟邀请赛,二十多支队伍激烈角逐。」— 龙舟赛 是 现代 大都市 公共 活动.

「'路漫漫其修远兮,吾将上下而求索' — 这是屈原《离骚》里最著名的诗句,激励了无数后人。」— 屈原 精神 在 现代 仍被 引用.
