## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 연애 어휘를 배울 때 흔히 마주치는 함정

1. **4-방향 형제 호칭의 한국 고유성**:
   - 한국어는 형제 호칭에 4가지 (오빠/누나/형/언니) — 다른 4개 언어에 없는 시스템. 영어 "older brother" 단순, 일본어 兄/弟/姉/妹, 중국어 哥哥/弟弟.
   - **함정**: 한국어 학습자가 영어 "older brother" 를 오빠/형 으로 단순 매핑 → 한국에서는 화자 성별에 따라 다름 (여성→남자 = 오빠, 남성→남자 = 형).
   - **훈련법**: 4-방향 호칭 매트릭스 — 화자 여성 → 남자 연상 = 오빠, 여자 연상 = 언니 / 화자 남성 → 남자 연상 = 형, 여자 연상 = 누나. 영어 단순화 (older brother/sister) 와 구분.

2. **"썸(sseom)" 의 한국 고유성**:
   - 한국어 "썸" = 모호한 호감 단계 (그것 = 호감?) — 다른 언어에 직접 대응 없음. 영어 "talking stage" / 일본어 ちょっと気になる / 중국어 暧昧 모두 부분 대응.
   - **함정**: "썸" 을 영어 "some" 으로 단순 번역 → 발음 유사하지만 의미 다름. "we're in some" 같은 표현 영어에 없음.
   - **훈련법**: 썸 의 단계 어휘 — 썸 타다 / 썸 끝나다 / 썸 탈피 / 썸 연습. 영어 "talking stage" / 일본어 いい雰囲気 (ii fun'iki) / 중국어 暧昧期 매핑.

3. **고백(告白/gobaek) 문화의 강도**:
   - 한국어/일본어 모두 명시적 고백 (고백/gobaku) 문화 — 다른 4개 언어보다 의례화. 영어 "The Talk" (DTR), 스페인어는 "novios" 동의, 중국어는 "在一起吧" 명시.
   - **함정**: 한국어 학습자가 영어 연애에서 "I confess my love" 같은 직접적 고백 → 영어 문화에서 과도하게 무거움. "I like you. Want to date?" 가 더 자연스러움.
   - **훈련법**: 고백 단계 매핑 — JP 告白 (kokuhaku) + KR 고백 (gobaek) 의 동등 의례화 / EN "I like you" (덜 격식) / ES "Me gustas" (덜 격식) / CH "我喜欢你" (덜 격식). 문화별 격식 차이 학습.

4. **"100일(baek-il)" 기념일의 한국 특수성**:
   - 한국어는 "100일" = 연애 100일 = 매우 중요한 기념일 (커플 반지, 여행) — 다른 언어에 없는 단위. 영어 "100 days" = 단순 일수, 일본어 100日 는 없음, 중국어 100天 도 덜 강조.
   - **함정**: 한국어 학습자가 다른 언어에서 "100일" 기념일을 기대 → 상대가 이해 못함.
   - **훈련법**: 한국 기념일 시스템 — 100일/200일/300일/1주년/매월 N일 — 다른 문화에서는 anniversary (연 1회) 위주.

5. **"여보(yeobo)" 의 결혼 후 사용**:
   - 한국어 "여보" 는 기혼 부부 사이의 애칭 — 비기혼 커플에게 사용하면 결혼 압박. 영어 "honey/babe" 는 미혼/기혼 모두 사용. 중국어 老公/老婆 (lǎogōng/lǎopó) 도 기혼 한정.
   - **함정**: 한국어 학습자가 영어 연인에게 "여보" 직접 번역 → 결혼 가정. 일본어 ダーリン/ハニー 는 미혼/기혼 모두 사용.
   - **훈련법**: 미혼 커플용 (자기/jagi) vs 기혼 커플용 (여보/yeobo, 당신/dangsin) 구분 학습. 영어/일본어와 다름.

### 학습 전략

1. **우선순위 1**: 한국어 4-방향 형제 호칭 (오빠/누나/형/언니) 마스터 + 화자 성별 매핑.
2. **우선순위 2**: 고백/썸/연애/전속/이별 5단계 어휘 + 5언어 매핑.
3. **우선순위 3**: 한국 기념일 (100일, 200일, 300일, 1주년) 시스템 학습.
4. **우선순위 4**: 디지털 연애 슬랭 (고스팅/썸/어장관리/러브바밍) 의 5언어 매핑.
5. **우선순위 5**: 한국 문화의 고백 의례화 (고백/告白) 학습 — 다른 문화의 "The Talk" 와 차이.
