# 시제-상 시스템 — 다국어 비교 (한국어판)

> 원본: [[tense-aspect-systems]] (English) | 작성일: 2026-08-20 | ADR-0006
> **5개 언어 시제 + 상 (aspect) 인코딩 비교**

---

## 빠른 참조 표

### 시제 시스템 비교

| 언어 | 과거 | 현재 | 미래 | 상 구분 |
|---|---|---|---|---|
| Spanish | preterite/imperfect/perfect/pluperfect | present | future/conditional | rich (perfective/imperfective) |
| English | simple past/present perfect/pluperfect | present | will + verb | simple (perfective only) |
| Japanese | た形/ていた/ていた/てしまう | 常体/辞等 | ます形/だろう | 매우 풍부 (完了, 経験, 進行) |
| Korean | 았/었/었었/겠 | 다/는다 | 겠/을 것 | 풍부 (完了, 経験, 進行, 持続) |
| Chinese | 了/过/曾经 | present | 会/要/将 | 최소 (了=completed, 过=experienced) |

### 상 시스템 비교

| 상 | English | Spanish | Japanese | Korean | Chinese |
|--------|---------|---------|----------|--------|---------|
| **단순 (무표지)** | I eat | Como | 食べる | 먹다 | 吃 |
| **진행** | I am eating | Estoy comiendo | 食べている | 먹고 있다 | 在吃 |
| **완료** | I have eaten | He comido | 食べた | 먹었다 | 吃了 |
| **습관** | I used to eat | Comía (imperfect) | 食べていた | 먹었다 | 吃过 |
| **경험** | I have eaten before | He comido alguna vez | 食べたことがある | 먹어 봤다 | 吃过 |
| **개시** | I'm starting to eat | Empiezo a comer | 食べ始める | 먹기 시작하다 | 开始吃 |
| **결과상** | I have it eaten | Está comido | 食べてある | 먹어 있다 | 吃了 (state) |
| **예정** | I'm about to eat | Voy a comer | 食べようとする | 먹으려고 하다 | 快要吃 |

| 시제 | English | Spanish | Japanese | Korean | Chinese |

## 핵심 대조 (종합)

| 대조 | 통찰 |
|----------|---------|
| **스페인어** 과거 완전 (pretérito) vs 과거 미완전 (imperfecto) — **독특한 과거 시제 시스템** |
| **일본어와 한국어** 시제 적고 상 풍부 — 완료(完了) vs 진행(進行) vs 경험(経験) 상을 동사 활용으로 인코딩 |
| **중국어** 가장 최소 — 상 조사 (了, 过) + 양태 동사 (会, 要) 사용, 동사 활용 없음 |
| Romance vs CJK | 로망스어 (스페인어) 시제 형태론; CJK (JP/KR) 상 형태론; 중국어는 가장 최소 |
| 동아시아 상 | JP와 KR 유사한 상 시스템 (完了/経験/進行); 종종 유사 형태 사용 |

## 학습자 의사결정 가이드

> **시제 시스템 매트릭스**:
> - **영어**: 시제 2 (과거/현재) + 미래 via 모달. 가장 단순.
> - **스페인어**: 시제 3 (preterite/imperfect/future) + 조건법 + pluperfect. 가장 풍부.
> - **일본어**: 시제 2 (과거/현재-미래) + 상 매우 풍부.
> - **한국어**: 시제 2 (과거/현재) + 상 풍부 + 경어 단계.
> - **중국어**: 시제 0 + 상 최소 (了, 过, 在) + 양태 부사.

> **5개 언어 상 시스템 매트릭스**:
> - **진행**: I am eating / Estoy comiendo / 食べている / 먹고 있다 / 在吃
> - **완료**: I have eaten / He comido / 食べた / 먹었다 / 吃了
> - **경험**: I have eaten before / He comido alguna vez / 食べたことがある / 먹어 봤다 / 吃过
> - **습관**: I used to eat / Comía (imperfect) / 食べていた / 먹었다 / 吃过

## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 시제-상 시스템을 학습할 때 흔히 마주치는 함정

1. **스페인어 preterite vs imperfect 의 시제 형태론**:
   - 스페인어: preterite (완료) = Comí, imperfect (미완료/습관) = Comía. **동사 어미로 구분**.
   - 영어: "I ate" 단일 형태. 한국어/일본어/중국어: 동사 활용 + 상 조사.
   - **함정**: 한국어 학습자가 영어/한국어 단순 과거 ("I ate" / "먹었어") 를 스페인어로 단순 매핑 → "Comí" 만 사용, "Comía" (습관/배경) 누락.
   - **훈련법**: 스페인어 2개 과거 시제 명시 학습 — preterite (완료 사건) / imperfect (배경/습관). 한국어 학습자 가장 큰 스페인어 도전 중 하나.

2. **일본어/한국어 시제-상 풍부성**:
   - 한국어: -았/었 (과거) + -고 있다 (진행) + -어 보다 (경험) + -고 싶다 (의도) + -(으)려고 (의도) — **5개 상/태 동사 활용**.
   - 일본어: た形 + ている + たことがある + たい + ようとする — **5개 상/태 동사 활용**.
   - 영어: 시제 2 + 모달 — **시제 빈약**.
   - 중국어: 了 + 过 + 在 + 要/会 — **상 조사/양태 부사**.
   - **함정**: 한국어 학습자가 영어 학습 시 한국어 상 시스템을 영어에 적용 → 영어 "I have eaten" (현재 완료) vs "I ate" (과거) 구분 어려움. 한국어 "먹었다" 가 양자 모두 가능.
   - **훈련법**: 시제-상 5개 언어 매트릭스 — 한국어/일본어 시제 2 + 상 풍부, 영어 시제 2 + 상 빈약, 중국어 시제 0 + 상 최소. **상 시스템 4가지 메커니즘 비교**.

3. **중국어 了/过 의 상 표지 사용**:
   - 중국어: 了 (완료) / 过 (경험) / 在 (진행) — 명시적 상 조사.
   - 한국어: 동사 어간 + 어미 변화.
   - **함정**: 한국어 학습자가 중국어 3개 상 조사 무지 → "我吃饭" (X) vs "我吃了饭" (O, 완료) / "我吃过饭" (O, 경험) / "我在吃饭" (O, 진행). **상 조사 필수**.
   - **훈련법**: 중국어 상 조사 3개 명시 학습 — 了/过/在. 한국어 학습자 가장 큰 중국어 도전 중 하나.

4. **한자 한자어 시제 어휘 발음 차이**:
   - 같은 한자 시제 어휘가 3개국에서 발음 다름. 예: 完了: 한국 한자음 "완료" vs 일본 "かんりょう (kanryō)" vs 중국 "wánliǎo". 한자 一 글자당 3개국 발음.
   - **함정**: 한국어 한자음 "완료" 다른 한자권 발음 추정 → "かんりょう" / "wánliǎo" 와 다름.
   - **훈련법**: 시제/상 한자 한자어 3개국 발음 매트릭스 — 完了/완료/wánliǎo, 経験/경험/jīngyàn, 進行/진행/jìnxíng. 한자 1글자 = 3개국 발음.

5. **스페인어/중국어 漢 = 동사 시제/상 vs 한국어 명사형**:
   - 스페인어: 동사 시제/상 직접 활용 (Comí, Comía, Comería).
   - 중국어: 시제/상 + 명사/동사 조합. 예: "吃了饭" (식사 완료) / "吃完饭" (식사 완료 + 결과).
   - 한국어: 명사 + 동사 활용, 시제/상 동사 어미.
   - **함정**: 한국어 학습자가 스페인어/중국어 시제-상 동사 어미 무지 → "Comí" (X) vs "Comer" (동사원형) vs "Comeré" (미래) 단순 매핑 오류.
   - **훈련법**: 5개 언어 시제-상 동사 활용 명시 매트릭스 — 스페인어 6 시제 활용 vs 한국어/일본어 시제 2 + 상 풍부 vs 중국어 시제 0 + 상 조사 vs 영어 시제 2 + 모달. **5개 메커니즘 명시적 비교**.

### 학습 전략

1. **우선순위 1**: 5개 언어 시제-상 시스템 매트릭스 — 한국어/일본어 시제 2 + 상 풍부, 영어 시제 2 + 상 빈약, 스페인어 시제 3-6, 중국어 시제 0 + 상 최소. **5개 메커니즘 비교**.
2. **우선순위 2**: 스페인어 preterite vs imperfect 명시 학습 — preterite (완료) / imperfect (배경/습관). **한국어 학습자 가장 큰 스페인어 도전**.
3. **우선순위 3**: 중국어 상 조사 了/过/在 명시 학습 — **한국어 학습자 가장 큰 중국어 도전**.
4. **우선순위 4**: 한자 시제-상 한자어 3개국 발음 매트릭스 — 完了/완료/wánliǎo, 経験/경험/jīngyàn, 進行/진행/jìnxíng.
5. **우선순위 5**: 상 시스템 4가지 메커니즘 — 한국어/일본어 동사 어미, 영어 모달, 스페인어 시제, 중국어 상 조사. **메커니즘별 명시적 비교**.
