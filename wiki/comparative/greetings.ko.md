## 빠른 참조 표

### 인사 디테일

### 🇬🇧 영어 (English)
- **시간대별**: Good morning (~12시), Good afternoon (12-17시), Good evening (17시+), Good night (작별 시에만)
- **격식**: Hi/Hey (캐주얼) → Hello (중립) → Good morning/afternoon/evening (격식)
- **Phatic**: "How are you?" = 인사 (진짜 질문 아님). 응답: "Good, you?" / "Fine, thanks."
- **몸짓**: 악수 (비즈니스), 손 흔들기 / 고개 끄덕임 (캐주얼), 포옹 (친밀)
- **출처**: `[English/vocabulary/basic-vocabulary]`, `[English/culture/english-dating-culture]`

### 🇪🇸 스페인어 (Spanish)
- **시간대별**:
  - *Buenos días* (새벽–14:00)
  - *Buenas tardes* (14:00–일몰/20:00)
  - *Buenas noches* (해 진 후 — 인사 & 작별 모두)
- **격식**: *Hola* (보편) + 시간 표현; *Buenos días/tardes/noches* 더 격식적
- **지역 변이**:
  - 스페인: *¿Qué tal?*, *¿Cómo vas?*
  - 멕시코: *¿Qué onda?*, *¿Cómo estás?*
  - 아르헨티나: *¿Cómo andás?*
- **키스 인사**: *Dos besos* (스페인, 일부 라틴 아메리카) — 여성/여성 & 여성/남성; 남성/남성은 악수 or 포옹
- **전화**: *¿Diga?*, *¿Aló?*, *Bueno* (멕시코)
- **출처**: `[Spanish/vocabulary/basic-vocabulary]`, `[Spanish/culture/espana-vs-latinoamerica-registro]`

### 🇯🇵 일본어 (Japanese)
- **시간대별**:
  - *Ohayou gozaimasu* (~10:00/11:00)
  - *Konnichiwa* (11:00~17:00)
  - *Konbanwa* (17:00~)
- **격식**:
  - 캐스니얼: *Ohayou*, *Yaa*, *Ossu* (남성)
  - 정중: *Ohayou gozaimasu*, *Konnichiwa*, *Konbanwa*
  - 비즈니스: *Ohayou gozaimasu* (일부 사무실에서는 하루종일)
- **절 (Bowing)**: 각도 = 존경 (15° 캐스니얼, 30° 표준, 45° 깊은 사과/존경)
- **전화**: *Moshi moshi* (캐스니얼) / *Hai, [Name] desu* (비즈니스)
- **출처**: `[Japanese/vocabulary/basic-vocabulary]`, `[Japanese/culture/japanese-dating-culture]`

### 🇰🇷 한국어 (Korean)
- **시간대별**: 시간 구분 인사 없음 — *Annyeonghaseyo* 하루종일 사용
- **격식**:
  - *Annyeong* (해체) — 친한 친구, 아이들
  - *Annyeonghaseyo* (해요체) — 기본 정중 (모든 연령, 모르는 사람, 직장 동료)
  - *Annyeonghasimnikka* (합쇼체) — 격식 (군대, 방송, 매우 격식적)
- **절**: 30-45° 표준; 90° (큰절) — 새해, 결혼식, 장례식
- **전화**: *Yeoboseyo* (여보세요) — 보편
- **연령 체크**: 첫 만남 → "연세가 어떻게 되세요?" / "몇 살이세요?" 가 말투 결정
- **출처**: `[Korean/vocabulary/basic-vocabulary]`, `[Korean/sources/daily-life-basics]`

### 🇨🇳 중국어 (Chinese)
- **시간대별**:
  - *Zǎoshang hǎo* (早上好) — 5:00-10:00
  - *Xiàwǔ hǎo* (下午好) — 12:00-18:00
  - *Wǎnshang hǎo* (晚上好) — 18:00+
- **격식**:
  - *Nǐ hǎo* (중립)
  - *Nín hǎo* (您好) — 어른, 상급자, 격식
  - 직함 + *hǎo*: *Lǎoshī hǎo* (老师好), *Jīnglǐ hǎo* (经理好)
- **Phatic**: *Chī le ma?* (吃了? — "밥 먹었어요?") — 고전 인사, 특히 older 세대
- **몸짓**: 고개 끄덕임 / 살짝 고개 숙임 (역사적); 악수 (비즈니스); 뺨 키스 없음
- **전화**: *Wéi* (喂) — 응답; *Nín hǎo* — 격식 응답
- **출처**: `[Chinese/vocabulary/body-zh]`, `[Chinese/sources/greetings-zh]`

## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 인 인을를 배울 때 흔히 마주치는 함정

1. **시간대별 인사 의 한국어 결여**:
   - 한국어 "안녕하세요" 하루종일 사용 → 학습자가 영어/스페인어/일본어/중국어 에서도 시간대별 인사 구분 없이 "Hello/Hola/こんにちは/你好" 만 사용하게 됨.
   - **함정**: 한국어 학습자가 영어 14:00-17:00 에 "Good morning" 사용 → 어색. 영어 응답 ("Good afternoon" / "Buenas tardes" / "こんにちは (Konnichiwa)" / "下午好 (Xiàwǔ hǎo)" 사용) 의식 필요.
   - **훈련법**: 24시간 중 14:00-17:00 에는 *Good afternoon* / *Buenas tardes* / *こんにちは (Konnichiwa)* / *下午好 (Xiàwǔ hǎo)* 사용 — 의식적 연습.

2. **"안녕" 캐스니얼 사용 위치**:
   - *안녕* 은 해체 (친한 친구, 아이들). 직장/비즈니스/어른에게 부적절.
   - **함정**: 캐스니얼함이 자연스러운 영어 (Hi/Hey) 와 동일시 → 어른/직장 에게 "안녕" 사용 → 매우 부적절.
   - **훈련법**: 모든 초기 학습에서 *안녕하세요* 만 사용, 친한 친구 (또는 명시 허락 후) 만 *안녕*.

3. **"절 (Bowing) 의 부재"**:
   - 한국어 학습자는 인사에 절 을 동반 — JP/KR 의 절 문화 를 일반화.
   - **함정**: 영어/스페인어/중국어 비즈니스 에서 절 은 부자연스러움. 악수 또는 가벼운 고개 숙임 사용.
   - **훈련법**: 비즈니스 컨텍스트에서 악수 + 가벼운 미소 (EN/CH), 뺨 키스 모방 (ES, 여성 only).

4. **"Phatic vs 진짜 질문 구분"**:
   - 한국어 "잘 지내세요?" 는 진짜 질문이거나 가벼운 인사 모두 가능.
   - 영어 "How are you?" 는 거의 항상 가벼운 인사 — "Good, you?" 응답 의무.
   - **훈련법**: 영어 응답 패턴 ("Good, thanks. You?" / "Not bad, thanks.") 자동화.

5. **"연령 확인 (KR-only)"**:
   - 한국어는 첫 만남 시 연령 확인 필수 (말투 결정) — 다른 4개 언어는 연령 무관.
   - **훈련법**: KR 연령 확인 문화 존중, EN/JP/ES/CH 에서는 연령 확인 스킵.

### 학습 전략

1. **우선순위 1**: 한국어 시간 구분 없는 인사 패턴 마스터 (안녕하세요 하루종일) + 다른 4개 언어의 시간대별 구분 학습.
2. **우선순위 2**: 5개 언어 인사 매트릭스 — Hello/Hola/こんにちは/你好/안녕하세요 매핑.
3. **우선순위 3**: 문화별 인사 의례 (악수/뺨 키스/절/끄덕임) 의 매트릭스 학습.
4. **우선순위 4**: phatic 표현의 문화별 차이 (영어 How are you? 가 인사 vs 한국어/일본어/중국어에서 진짜 질문 가능) 학습.
5. **우선순위 5**: 격식 단계 캐스니얼/중립/격식 매핑 — 5언어 격식 시스템 비교.
