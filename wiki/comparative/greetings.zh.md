## 各语言详情

### 🇬🇧 英语 (English)
- **按时段**: Good morning (~12点), Good afternoon (12-17点), Good evening (17点+), Good night (仅告别)
- **语域**: Hi/Hey (随意) → Hello (中性) → Good morning/afternoon/evening (正式)
- **寒暄性**: "How are you?" = 问候 (并非真正的提问). 回答: "Good, you?" / "Fine, thanks."
- **肢体语言**: 握手 (商务), 挥手 / 点头 (随意), 拥抱 (亲密)
- **来源**: `[English/vocabulary/basic-vocabulary]`, `[English/culture/english-dating-culture]`

### 🇪🇸 西班牙语 (Spanish)
- **按时段**:
  - *Buenos días* (黎明–14:00)
  - *Buenas tardes* (14:00–日落/20:00)
  - *Buenas noches* (日落后 — 问候和告别)
- **语域**: *Hola* (通用) + 时段表达; *Buenos días/tardes/noches* 更正式
- **地区变体**:
  - 西班牙: *¿Qué tal?*, *¿Cómo vas?*
  - 墨西哥: *¿Qué onda?*, *¿Cómo estás?*
  - 阿根廷: *¿Cómo andás?*
- **亲吻问候**: *Dos besos* (西班牙, 部分拉美) — 女性/女性 & 女性/男性; 男性/男性握手或拥抱
- **电话**: *¿Diga?*, *¿Aló?*, *Bueno* (墨西哥)
- **来源**: `[Spanish/vocabulary/basic-vocabulary]`, `[Spanish/culture/espana-vs-latinoamerica-registro]`

### 🇯🇵 日语 (Japanese)
- **按时段**:
  - *Ohayou gozaimasu* (~10:00/11:00)
  - *Konnichiwa* (11:00~17:00)
  - *Konbanwa* (17:00~)
- **语域**:
  - 随意: *Ohayou*, *Yaa*, *Ossu* (男性)
  - 礼貌: *Ohayou gozaimasu*, *Konnichiwa*, *Konbanwa*
  - 商务: *Ohayou gozaimasu* (部分办公室全天使用)
- **鞠躬**: 角度 = 敬意 (15° 随意, 30° 标准, 45° 深深道歉/敬意)
- **电话**: *Moshi moshi* (随意) / *Hai, [Name] desu* (商务)
- **来源**: `[Japanese/vocabulary/basic-vocabulary]`, `[Japanese/culture/japanese-dating-culture]`

### 🇰🇷 韩语 (Korean)
- **按时段**: 无时段区分 — *Annyeonghaseyo* 全天使用
- **语域**:
  - *Annyeong* (해체) — 亲近朋友, 儿童
  - *Annyeonghaseyo* (해요체) — 标准礼貌 (所有年龄, 陌生人, 同事)
  - *Annyeonghasimnikka* (합쇼체) — 正式 (军队, 广播, 非常正式)
- **鞠躬**: 30-45° 标准; 90° (큰절) — 新年, 婚礼, 葬礼
- **电话**: *Yeoboseyo* (여보세요) — 通用
- **年龄确认**: 初次见面 → "연세가 어떻게 되세요?" / "몇 살이세요?" 决定敬语级别
- **来源**: `[Korean/vocabulary/basic-vocabulary]`, `[Korean/culture/korean-dating-culture]`

### 🇨🇳 中文 (Chinese)
- **按时段**:
  - *Zǎoshang hǎo* (早上好) — 5:00-10:00
  - *Xiàwǔ hǎo* (下午好) — 12:00-18:00
  - *Wǎnshang hǎo* (晚上好) — 18:00+
- **语域**:
  - *Nǐ hǎo* (你好) (中性)
  - *Nín hǎo* (您好) — 长辈, 上级, 正式
  - 头衔 + *hǎo*: *Lǎoshī hǎo* (老师好), *Jīnglǐ hǎo* (经理好)
- **寒暄性**: *Chī le ma?* (吃了吗？— "吃饭了吗？") — 经典问候, 尤其年长一辈
- **肢体语言**: 点头 / 微微鞠躬 (历史性); 握手 (商务); 无脸颊亲吻
- **电话**: *Wéi* (喂) — 接听; *Nín hǎo* — 正式接听
- **来源**: `[Chinese/vocabulary/body-zh]`, `[Chinese/sources/greetings-zh]`

## 关键对比 (综合)

| 对比 | 对学习者的启示 |
|------|----------------|
| **分时段 vs 全天** — EN/ES/JP/CH 有时段区别; KR 全天使用 *annyeonghaseyo* | KR 不必担心时段。JP 下午3点说 *ohayou* 会不自然。 |
| **寒暄性 "How are you?"** — EN/ES 期待仪式性回答; JP/KR/CH 较少 | EN: "Good, you?" 是必须的。JP: *お元気ですか* = 真正的提问 (常省略)。KR: *잘 지내세요?* = 真正的。CH: *吃了吗？* = 仪式性但逐渐消亡。 |
| **鞠躬层级** — JP (15°/30°/45°) vs KR (30°/45°/90°) vs CH (微微点头) | JP: 与对方匹配 + 5°。KR: 年龄差 = 更深的鞠躬。CH: 商务 = 握手 + 微微点头。 |
| **亲吻 vs 鞠躬 vs 握手** — ES (亲吻), JP/KR (鞠躬), EN/CH (握手) | ES: 模仿对方 (1亲? 2亲?)。JP/KR: 鞠躬, 不要先主动握手 (除非对方先)。 |
| **电话问候** — *Moshi moshi* (JP) vs *Yeoboseyo* (KR) vs *Wei* (CH) vs *Diga/Aló* (ES) vs *Hello* (EN) | 商务电话中绝不用 *moshi moshi*。*Yeoboseyo* 在 KR 通用。*Wei* 可能听起来突兀 — 加上 *您好*。 |

## 🇨🇳 中文学习者笔记 (Chinese Learner Notes)

> 本节是面向中文母语学习者的额外学习指南。

### 中文母语者在学习其他4种语言问候时的常见陷阱

1. **时间问候的过度简化**:
   - 中文 *你好* 通用全天 → 学员初期对英语/西班牙语/日语/韩语也只用 "Hello/Hola/こんにちは/안녕하세요"。
   - **训练法**: 14:00-17:00 之间使用 *Good afternoon* / *Buenas tardes* / *こんにちは (Konnichiwa)* / *안녕하세요 (全时段)*。

2. **敬语层级假设错误**:
   - 中文敬语相对简单 (您/你 + 头衔) → 学员假设其他语言也有相似简化结构。
   - **陷阱**: 日语有5层敬语 (casual/polite/honorific/humble/respectful), 韩语有3层 (해체/해요체/합쇼체), 英语只有2层 (casual/formal)。
   - **训练法**: 每个语言的敬语层级用映射表整理 (CN 2层 vs EN 2层 vs KR 3层 vs JP 5层 vs ES tú/usted 2层)。

3. **寒暄性 vs 真正问题的混淆**:
   - 中文 *吃了吗？* 是传统问候 (较少使用) → 学员假设其他语言的问候也是真正的提问。
   - **陷阱**: 英语 "How are you?" 是仪式性问候, 长篇回答不自然。
   - **训练法**: 英语回答模式 ("Good, thanks. You?" / "Not bad, thanks.") 自动化。

4. **身体语言跨文化误用**:
   - 中文 (尤其大陆) 商务用握手 + 微微点头 → 学员在其他语言中也尝试同样动作。
   - **陷阱**: 西班牙语区用脸颊亲吻 (女性间), 日语/韩语用鞠躬。握手在欧洲和部分拉美已普及但仍非所有情况都适用。
   - **训练法**: 各文化问候身体语言单独学习 (握手/鞠躬/亲吻/拥抱)。

5. **电话应答差异**:
   - 中文 *喂* 接电话 → 其他语言使用不同表达。
   - **陷阱**: 日语 *もしもし* 在商务中过时 (使用 *はい、[名前]です*), 英语 "Hello" / 韩语 *여보세요* 通用, 西班牙语 *¿Diga?/¿Aló?/Bueno* 因地区而异。
   - **训练法**: 5种语言电话应答分别记忆。
