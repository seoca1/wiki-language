## 언어별 상세

### 🇪🇸 스페인어 (España castellano)
- **핵심 변이**: 스페인어의 표준 (castellano) — 2인칭 복수 vosotros 보편.
- **발음 변이**: s/θ 구분 (스페인 castellano: casa = "kaθa" vs 라틴아메리카: "kasa"), yeísmo (ll/y 모두 [ʝ]), seseo (s/c 전부 [s]).
- **어휘 변이**: 자동차 = coche (스페인) / carro (멕시코) / auto (라틴아메리카 일부).
- **문법 변이**: vosotros 보편, voseo 없음, leísmo (스페인: le instead of lo for 남성 직접 목적어), ustedes (사용 안함).

### 🇲🇽 멕시코 스페인어
- **핵심 변이**: ustedes 사용 (vosotros 없음), voseo 없음.
- **발음 변이**: s 발음 (seseo), yeísmo, "coger" 금기.
- **어휘 변이**: carro (자동차), 잘 시간 표현 ("¿Qué onda?" 등 슬랭).
- **문법 변이**: ustedes (2인칭 복수), voseo 없음.

### 🇦🇷 아르헨티나 스페인어 (rioplatense)
- **핵심 변이**: voseo 보편 (tú 대신 vos), ustedes (2인칭 복수).
- **발음 변이**: shibilante 변이 (ll/y 모두 [ʃ]), intonation 특유.
- **어휘 변이**: auto (자동차), reiverbol (리버플레이트 영어 변형어).
- **문법 변이**: voseo 활용 변화 (vos tenés instead of tú tienes).

### 카리브 스페인어
- **핵심 변이**: ustedes 사용, voseo 일부 (칠레 등).
- **발음 변이**: s/c 변이 (특히 쿠바, 푸에르토리코), 어미 -s 발음 약화.
- **어휘 변이**: carro (자동차), "Qué bolá" (쿠바 슬랭).
- **문법 변이**: ustedes 보편, 일부 지역 voseo.

## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 스페인어 방언 변이를 배울 때 흔히 마주치는 함정

1. **"vosotros vs ustedes" 의 스페인어 vs 라틴아메리카 차이**:
   - 스페인 (castellano) 만 vosotros 사용, 라틴아메리카 전 지역 ustedes. 한국어 학습자는 처음에 vosotros = ustedes 동일 가정 → 사실 문법/형태 다름.
   - **함정**: 한국어 학습자가 스페인에서 ustedes 사용 → 라틴아메리카 동료에게 부자연스러움 (그러나 이해됨). 스페인에서 vosotros 생략 → 매너 위반.
   - **훈련법**: vosotros 활용 마스터 — vosotros tenéis/sois/vais (현재), vosotros tuvisteis (단순 과거), vosotros habréis (미래) — 5인칭 변화형. ustedes 는 3인칭 변화형 사용.

2. **"voseo (vos)" 의 아르헨티나 특화**:
   - 아르헨티나 (rioplatense) 만 vos 사용 (tú 대체) — 한국어 학습자는 거의 학습 안함. 그러나 아르헨티나 문화 이해에 필수.
   - **함정**: vos 를 tú 와 동일시 → 아르헨티나 활용 변화 무시 (vos tenés/sos/querés vs tú tienes/eres/quieres).
   - **훈련법**: voseo 활용 변화 — vos tenés (가직), vos sos (이), vos querés (원한다), vos venís (온다) — vos 동사 활용 마스터.

3. **"coche/carro/auto" 의 3개 단어 = 동일 의미 (자동차)**:
   - 스페인 coche / 멕시코 carro / 아르헨티나 auto — 한국어 학습자는 단일 "coche" 만 학습 → 라틴아메리카에서 이해 불가 (그러나 소통은 됨).
   - **함정**: 한국어 학습자가 멕시코에서 "coche" 사용 → 정상 이해되나 지역 slang 차이.
   - **훈련법**: 자동차 어휘 5언어 매핑 — ES coche/carro/auto / EN car / KR 자동차 / JP 車 (くるま) / CH 汽车. 지역별 차이 학습.

4. **"coger" 의 금기 (스페인 외 지역)**:
   - 스페인 "coger" = 잡다 (문법적으로 정상). 그러나 라틴아메리카에서는 성적 의미 (매우 모욕).
   - **함정**: 한국어 학습자가 멕시코/아르헨티나에서 "coger" 사용 → 매우 무례하게 해석.
   - **훈련법**: coger / tomar / agarrar 매핑 — ES coger (보편) / LatAm agarrar (잡다) / EN take/grab. 지역별 어휘 차이 학습.

5. **"vosotros vs usted" 의 친밀도 차이**:
   - 스페인 vosotros = 친밀/동료, usted = 격식/상급자. 한국어 합쇼체 vs 해요체 의 친밀도와 유사.
   - **함정**: 한국어 학습자가 스페인 비즈니스에서 vosotros 사용 → 부적절 (그러나 동료 사이에서는 정상).
   - **훈련법**: 친밀도 매핑 — ES vosotros (친밀) / usted (격식) / KR 해요체 (정중) / 합쇼체 (격식) / EN casual/친밀 / formal/격식. 맥락별 사용 학습.

### 학습 전략

1. **우선순위 1**: 스페인어 표준 (castellano) vos + vosotros 활용 마스터 — 스페인어 핵심.
2. **우선순위 2**: 라틴아메리카 ustedes + voseo (아르헨티나) 기본 활용 — 지역별 차이 인식.
3. **우선순위 3**: 어휘 변이 (coche/carro/auto, coger/tomar/agarrar) 의 5개 지역 매핑.
4. **우선순위 4**: 발음 변이 (s/θ 구분, yeísmo, seseo, shibilante) 의 청각 훈련.
5. **우선순위 5**: 식사 시간/문화 변이 (cena 19:00-22:00) 의 문화적 맥락 학습.
