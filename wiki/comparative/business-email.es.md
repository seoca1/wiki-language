## Detalle de saludos

### 🇬🇧 Inglés (English)

| Relación | Saludo |
|----------|--------|
| Formal (nombre desconocido) | Dear Sir/Madam, / To Whom It May Concern, |
| Formal (nombre conocido) | Dear Mr./Ms./Dr. [Last], |
| Colega/conocido | Hi [First], / Hello [First], |
| Equipo/grupo | Dear Team, / Hi All, |

### 🇪🇸 Español (Spanish)

| Relación | Saludo |
|----------|--------|
| Formal (desconocido) | Estimado Señor/Señora: / Muy señor mío: |
| Formal (conocido) | Estimado/a Sr./Sra./Dr./Dra. [Apellido]: |
| Contacto conocido | Estimado/a [Nombre]: |
| Menos formal | Hola [Nombre]: / Querido/a [Nombre]: |

**Regional**: *Estimado* (España) vs *Estimado/a* (LatAm con concordancia de género); *Usted* implícito en formal

### 🇯🇵 Japonés (Japanese)

| Relación | Saludo |
|----------|--------|
| Externo (estándar) | 株式会社〇〇 〇〇部 〇〇様 |
| Externo (nombre conocido) | 〇〇株式会社 〇〇様 |
| Interno (superior) | 〇〇部長 / 〇〇課長 / 〇〇様 |
| Interno (par) | 〇〇さん |
| Respuesta a externo | 〇〇様 いつもお世話になっております。 |

**Clave**: Empresa → Departamento → Título/Nombre → 様 — nunca solo nombre-sama para externos

### 🇰🇷 Coreano (Korean)

| Relación | Saludo |
|----------|--------|
| Externo (estándar) | ㈜○○ ○○팀 ○○님 / ○○부장님 |
| Externo (conocido) | ○○님 |
| Interno (superior) | ○○팀장님 / ○○부장님 / ○○선배님 |
| Interno (par) | ○○님 / ○○씨 |
| Respuesta a externo | ○○님, 항상 수고가 많으십니다. |

**Clave**: Empresa → Equipo → Título + 님 — *님* obligatorio por respeto; *씨* solo para pares/subordinados

### 🇨🇳 Chino (Chinese)

| Relación | Saludo |
|----------|--------|
| Formal (desconocido) | 尊敬的先生/女士： |
| Formal (conocido) | 尊敬的 [职称] [姓]： (经理/总监/教授) |
| Contacto conocido | 尊敬的 [姓] [职称]： |
| Menos formal | [姓] [职称] 你好： / 各位同事： |

**Clave**: El título sigue al apellido (王经理, 李总监) — nunca el nombre de pila en negocios

## Fórmulas de despedida

### 🇬🇧 Inglés (English)

| Formalidad | Cierre |
|------------|--------|
| Muy formal | Respectfully, / Yours faithfully, (UK: destinatario desconocido) |
| Formal | Sincerely, / Yours sincerely, (UK: destinatario conocido) |
| Profesional estándar | Best regards, / Kind regards, / Regards, |
| Cálido/conocido | Best, / Warm regards, / All the best, |
| Casual/interno | Thanks, / Cheers, (UK/AU) |

### 🇪🇸 Español (Spanish)

| Formalidad | Cierre |
|------------|--------|
| Muy formal | Atentamente, / Muy atentamente, |
| Formal | Cordialmente, / Un cordial saludo, |
| Profesional estándar | Saludos cordiales, / Atentamente, |
| Cálido/conocido | Un abrazo, / Un saludo afectuoso, |
| Casual/interno | Saludos, / Hasta luego, |

**LatAm**: *Quedo a su disposición* común antes del cierre

### 🇯🇵 Japonés (Japanese)

| Formalidad | Cierre |
|------------|--------|
| Externo estándar | よろしくお願いいたします。 |
| Solicitando acción | ご検討のほど、よろしくお願いいたします。 |
| Después de reunión | お会いできましたら幸いです。よろしくお願いいたします。 |
| Interno (superior) | 以上、よろしくお願いいたします。 |
| Interno (par) | よろしくお願いします。 / 以上です。 |

**Nunca omitir** — incluso correos internos terminan con *yoroshiku onegaishimasu*

### 🇰🇷 Coreano (Korean)

| Formalidad | Cierre |
|------------|--------|
| Externo estándar | 잘 부탁드립니다. / 감사합니다. |
| Solicitando acción | 검토 부탁드립니다. / 확인 부탁드립니다. |
| Después de reunión | 뵙기를 희망합니다. 잘 부탁드립니다. |
| Interno (superior) | 이상입니다. 잘 부탁드립니다. |
| Interno (par) | 잘 부탁해요. / 수고하세요. |

**Nota**: *수고하세요* (a quien se queda) vs *수고하십시오* (a quien se va) — el cierre de correo usa *수고하세요*

### 🇨🇳 Chino (Chinese)

| Formalidad | Cierre |
|------------|--------|
| Muy formal | 顺颂商祺 / 此致 敬礼 |
| Formal | 此致 敬礼 / 顺祝 工作顺利 |
| Profesional estándar | 祝好 / 顺祝 安好 |
| Contacto conocido | 祝好 / 期待回复 |
| Casual/interno | 谢谢 / 祝顺利 |

## Normas culturales y tabúes

| Cultura | Norma | Tabú |
|---------|-------|------|
| **Inglés (US/UK)** | Tratamiento de nombre propio después de 1-2 intercambios | Lenguaje excesivamente rígido con pares |
| **Español (España)** | *Usted* por defecto; *tú* después de invitación | *Tú* con desconocidos; omitir *Estimado* |
| **Español (Latinoamérica)** | *Usted* por más tiempo; títulos importantes | Nombre de pila sin título |
| **Japonés** | *Yoroshiku* obligatorio; responder el mismo día | Omitir *yoroshiku*; cc sin avisar |
| **Coreano** | *님* obligatorio; jerarquía en orden de cc | *씨* para superiores; responder por encima del superior |
| **Chino** | Título + apellido; *qing* (请) para solicitudes | Nombre de pila; omitir fórmula de cierre |

## Guía de decisión para estudiantes

> **Do / Don't por idioma**:
> | Idioma | ✅ Sí | ❌ No |
> |----------|------|-------|
> | **Inglés** | Usar "please" y "thank you"; ser conciso | Sobre-disculparse; usar "kindly" (anticuado) |
> | **Español** | Usar *usted* hasta que inviten a *tú*; incluir *Estimado* | Omitir saludo; usar *tú* con clientes |
> | **Japonés** | Siempre *yoroshiku onegaishimasu*; firma completa | Omitir *yoroshiku*; responder sin contexto |
> | **Coreano** | Usar *님*; cc consciente de jerarquía; cierre *수고하세요* | Usar *씨* para superiores; reply-all sin pensar |
> | **Chino** | Título + apellido; *qing* para solicitudes; fórmula de cierre | Solo nombre de pila; omitir cierre; solicitudes directas |

## 🇪🇸 Notas para estudiantes de español (Spanish Learner Notes)

> Esta sección es una guía de aprendizaje adicional para hispanohablantes.

### Trampas comunes para hispanohablantes al escribir correos profesionales en otros idiomas

1. **Sobreutilización del "Estimado/a"**:
   - En español, *Estimado/a* es la fórmula estándar para casi todo → en inglés *Dear* es menos formal en contextos internos (se prefiere *Hi*); en japonés es *Name + 様*; en coreano *님*; en chino *尊敬的*.
   - **Trampa**: usar fórmulas demasiado formales en contextos donde se prefiere brevedad.
   - **Entrenamiento**: calibrar el nivel de formalidad según la relación (interno vs externo, conocido vs desconocido).

2. **Subutilización del contexto inicial**:
   - En español se tiende a ir directo al grano → en japonés/coreano/chino se espera un preámbulo de contexto (いつもお世話になっております / 辛苦了).
   - **Trampa**: omitir el contexto y parecer abrupto.
   - **Entrenamiento**: memorizar las fórmulas de apertura para iniciar correos con el contexto apropiado.

3. **Gestión del *tú* vs *usted***:
   - En español *tú* y *usted* marcan jerarquía → en inglés no hay equivalente claro (todos usan "you"); en JP/KR se usa el nombre + sufijo honorífico.
   - **Trampa**: traducir literalmente "tú" cuando en otros idiomas la formalidad se marca con sufijos.
   - **Entrenamiento**: aprender que la formalidad se codifica en el nombre + sufijo, no en pronombres.

4. **Firmas demasiado breves**:
   - En español, la firma con nombre + cargo es suficiente → en japonés/coreano se espera una estructura jerárquica (empresa → departamento → título → nombre).
   - **Trampa**: omitir la jerarquía organizacional en las firmas en CJK.
   - **Entrenamiento**: usar la plantilla de firma jerárquica al escribir en JP/KR/CN.

5. **Frases de cierre inconsistentes**:
   - En español el cierre "Saludos" o "Atentamente" es estándar → en JP/KR/CN se esperan fórmulas específicas que varían según el contexto.
   - **Trampa**: usar una fórmula genérica para todos los casos.
   - **Entrenamiento**: practicar cierres diferenciados (solicitando acción, agradeciendo, etc.) en cada idioma.

2. **Practicar aperturas contextualizadas** (en JP/KR/CN, más largas que en ES)
3. **Aprender la estructura jerárquica de la firma** en JP/KR/CN
4. **Comparar estructuras de correo** en los 5 idiomas con el mismo contenido
5. **Practicar solicitudes corteses** con el nivel apropiado de formalidad
