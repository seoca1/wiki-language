## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 학습 자료를 선택할 때 흔히 마주치는 함정

1. **한국어 학습 자료의 풍부함 (영어/일본어 다음 수준)**:
   - 한국어 학습 자료는 TTMIK, HowtoStudyKorean, LingoDeer, KoreanClass101 등 풍부 — 영어/일본어 다음으로 가장 많은 자료 보유. 그러나 중국어 학습 자료보다 적음.
   - **함정**: 한국어 학습자가 다른 4개 언어 학습 자료 검색 시 영어/일본어 자료가 너무 많아 선택 어려움. TTMIK 류 추천 자료 우선.
   - **훈련법**: 언어별 TOP 3 자료 매핑 — KR (TTMIK + Anki + LingoDeer) / JP (WaniKani + Genki + Cure Dolly) / CH (Pleco + HSK + Mandarin Corner) / EN (Anki + English with Lucy + All Ears English) / ES (Dreaming + SpanishDict + Notes in Spanish).

2. **"LingoDeer" 의 한국어 특화 가치**:
   - LingoDeer 는 한국어 학습에 매우 효과적 (한국 개발사 + 한국어 구조 최적화) — 다른 4개 언어 학습에는 다른 앱 추천.
   - **함정**: 한국어 학습자가 일본어/중국어 학습에도 LingoDeer 사용 → 효과 낮음. JP/CH 는 LingoDeer 미지원 또는 약함.
   - **훈련법**: 언어별 최적 앱 매핑 — KR LingoDeer / JP WaniKani (한자) + Genki + Bunpo / CH Pleco + HelloChinese + Du Chinese / EN Duolingo + Elsa Speak / ES SpanishDict + LingQ.

3. **"한글 (한글) 마스터 = 한국어 학습의 게이트웨이"**:
   - 한글 (Hangul) 은 수 시간 내 마스터 가능 (가장 배우기 쉬운 문자) — 그러나 다른 4개 언어는 복잡. JP (히라가나+가타카나+한자) / CH (병음+한자) 는 수 년 필요.
   - **함정**: 한국어 학습자가 한글 마스터 후 다른 언어 학습 시 같은 기대 → 한자 학습 부담.
   - **훈련법**: 문자 학습 시간 매트릭스 — KR 한글 (수 시간) / EN (이미 알음) / ES (이미 알음) / JP 히라가나+가타카나 (수 주) + 한자 (수 년) / CH 병음 (수 주) + 한자 (수 년).

4. **"K-드라마 + Viki/Kocowa 자막" 의 몰입 학습 가치**:
   - K-드라마 + Netflix/Viki/Kocowa 자막 → 한국어 학습자에게 매력적이나 다른 4개 언어 학습에는 다른 몰입 매체 (EN 영화, ES 텔레노벨라, JP 애니메이션, CH C-드라마).
   - **함정**: K-드라마 몰입 학습이 다른 언어 학습보다 효율적이라고 가정 → 사실 모든 문화 몰입 학습 가능.
   - **훈련법**: 몰입 자료 매핑 — KR K-드라마 + Viki / EN 영화 + Netflix / ES 텔레노벨라 + Netflix / JP 애니메이션 + Crunchyroll / CH C-드라마 + iQiyi.

6. **"TTMIK Level 1-9" 의 한국어 특화 깊이**:
   - TTMIK Level 1-9 는 가장 인기 있고 체계적인 한국어 교재 — 그러나 다른 4개 언어에는 동등한 깊이의 교재 부족.
   - **함정**: 한국어 학습자가 다른 4개 언어 학습 시 TTMIK 같은 깊이의 교재 기대 → A2 레벨 이상은 자료 부족.
   - **훈련법**: 언어별 교재 비교 — KR TTMIK (가장 인기/체계) / JP Genki I & II (가장 인기) / CH HSK Standard Course (가장 인기) / EN Headway (클래식) / ES Aula Internacional (가장 인기).

### 학습 전략

1. **우선순위 1**: TTMIK + Anki + LingoDeer — 한국어 학습의 "삼종 세트".
2. **우선순위 2**: 한국어 유튜브 채널 (TTMIK + Go! Billy Korean + Korean with Grace) + 팟캐스트 (IYAGI + Hallyu Noona) 추가.
3. **우선순위 3**: 한글 마스터 (1-2일) 후 발음/받침/삼중 폐쇄음 별도 연습.
4. **우선순위 4**: K-드라마 + Viki 자막 + Language Reactor 브라우저 확장 으로 몰입.
5. **우선순위 5**: TOPIK 시험 준비 — Korean Grammar in Use + TOPIK Essential Grammar.
