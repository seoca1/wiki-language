## 학습자 의사결정 가이드

> **부탁**: お願いします (onegaishimasu) · 주세요 (juseyo) · 请 (qǐng) · por favor
> **감사**: ありがとう (arigatō) · 감사합니다 (gamsahamnida) · 谢谢 (xièxiè) · gracias
> **사과**: すみません (sumimasen) · 죄송합니다 (joesonghamnida) · 对不起 (duìbuqǐ) · lo siento
> **천만에요**: どういたしまして · 천만에요 · 不客气 · de nada

> **5개 언어 공손 표현 매트릭스 — 핵심 10개**:
> - 부탁: please / por favor / お願いします / 주세요 / 请
> - 감사: thank you / gracias / ありがとう / 감사합니다 / 谢谢
> - 사과: sorry / lo siento / すみません / 죄송합니다 / 对不起
> - 실례: excuse me / disculpe / すみません / 실례합니다 / 不好意思
> - 천만에요: you're welcome / de nada / どういたしまして / 천만에요 / 不客气
> - 좋은 아침: good morning / buenos días / おはようございます / 좋은 아침입니다 / 早上好
> - 좋은 저녁: good evening / buenas tardes / こんばんは / 안녕하세요 / 晚上好
> - 작별: goodbye / adiós / さようなら / 안녕히 가세요 / 再见
> - 만나서 반가워요: nice to meet you / mucho gusto / はじめまして / 만나서 반갑습니다 / 幸会
> - 예/아니오: yes/no / sí/no / はい/いいえ / 네/아니요 / 是/不是

## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 공손 표현을 학습할 때 흔히 마주치는 함정

1. **한국어 경어 6단계 vs 다른 4개 언어 2-3단계**:
   - 한국어 공손: 하소서체/합쇼체/해요체/해체/반말 + 존경/겸양/평어 = 6-12단계 가능. 가장 세밀한 시스템.
   - 영어/중국어/스페인어: 2-3단계. 일본어 3-4단계.
   - **함정**: 한국어 학습자가 다른 4개 언어에 한국어 정밀도 기대 → 단일 정중 vs 캐주얼 구분 없음 (특히 영어).
   - **훈련법**: **한국어가 가장 세밀** — 다른 4개 언어는 단순화. 영어 "please + thank you + excuse me" 3개로 대부분의 공손 커버.

2. **"주세요 (juseyo)" 의 한국어 특수성**:
   - 한국어 "주세요" = "~를 주세요" (~please give me). 1단어 의존 명사 패턴.
   - 일본어 "kudasai" 도 같은 패턴. 스페인어 "por favor" / 영어 "please" / 중국어 "请 qǐng" 모두 동사 + 부사 결합.
   - **함정**: "주세요"를 다른 언어 1단어로 번역 → 영어 "give me" (X) vs "please give me" (O). 어순 차이.
   - **훈련법**: "주세요" 패턴 — 한국어/일본어 ~주세요 vs 영어/스페인어/중국어 please + 동사. 5개 언어 부탁 표현 어순 매트릭스.

3. **"죄송합니다" vs "미안합니다" 구분**:
   - 한국어: 죄송합니다(격식 사과) vs 미안합니다(정중 사과) vs 미안해(캐주얼). 3단계.
   - 일본어: すみません (방해 + 사과 겸용) vs 申し訳ありません (격식 사과).
   - 스페인어: lo siento (사과) vs perdón (관용). 영어: sorry (사과) vs excuse me (방해).
   - **함정**: 일본어 "sumimasen"이 사과 + 방해 겸용 — 한국어 "죄송합니다" / "실례합니다" 구분과 다름. 한국어 학습자가 일본어 sumimasen을 한 가지 용도로만 사용 → 매너 위반.
   - **훈련법**: 사과 vs 방해 구분 — 한국어 죄송/실례, 영어 sorry/excuse me, 스페인어 lo siento/disculpe, 일본어 すみません (겸용), 중국어 对不起/不好意思. **5개 언어 사과-방해 구분 매트릭스**.

4. **"천만에요" vs "아니에요" 캐주얼 차이**:
   - 한국어: 천만에요(격식) vs 아니에요(캐주얼) vs 아닙니다(매우 격식).
   - 영어: you're welcome (격식) vs no problem (캐주얼).
   - 스페인어: de nada (캐주얼) vs con mucho gusto (격식).
   - 일본어: どういたしまして (격식) vs いいえ (캐주얼) vs いえいえ.
   - **함정**: 캐주얼 "no problem" / "아니에요" 를 격식 상황에서 사용 → 부적절.
   - **훈련법**: "천만에요" 5개 언어 단계 매트릭스 — 격식/캐주얼 별도 학습.

5. **"네/예" vs "응" (yes) 의 캐주얼 구분**:
   - 한국어: 네 (정중) / 예 (매우 격식, 격식 문어) / 응 (캐주얼) / 어 (매우 캐주얼, 남성).
   - 영어: yes (캐주얼/정중) / yeah/yep (캐주얼) / yes sir/ma'am (격식).
   - 스페인어: sí (캐주얼/정중) / señor's no (격식).
   - 일본어: はい (정중) / うん (캐주얼) / ええ (오사카 캐주얼).
   - **함정**: 캐주얼 "응" / "어" 를 격식 상황 (비즈니스/어른) 에 사용 → 부적절.
   - **훈련법**: "예/네" 단계 매트릭스 — 한국어 4단계(예/네/응/어) vs 영어 2단계(yes/yeah) vs 일본어 2단계(はい/うん). **한국어 세분화 명시 학습**.

### 학습 전략

1. **우선순위 1**: 5개 언어 공손 표현 10개 × 5언어 매트릭스 — 부탁/감사/사과/실례/천만에요/인사 × 5언어. **가장 빈도 높은 10개 표현 마스터**.
2. **우선순위 2**: 사과 vs 방해 구분 5개 언어 — 한국어 죄송/실례 vs 영어 sorry/excuse me vs 스페인어 lo siento/disculpe vs 일본어 すみません (겸용) vs 중국어 对不起/不好意思. **매너 위반 방지**.
3. **우선순위 3**: 격식/캐주얼 단계 5개 언어 — 한국어 4단계(예/네/응/어) vs 영어 2단계 vs 일본어 2단계. **한국어 세분화 명시 학습**.
4. **우선순위 4**: "천만에요" 응답 단계 — 한국어 천만에요/아니에요/아닙니다 vs 영어 you're welcome/no problem vs 스페인어 de nada/con mucho gusto vs 일본어 どういたしまして/いいえ. **상황별 응답 단계 학습**.
5. **우선순위 5**: 한국어 부탁 "주세요" 패턴 — 한국어/일본어 ~주세요/kudasai vs 영어/스페인어/중국어 please + 동사. **5개 언어 부탁 표현 어순 매트릭스**.
