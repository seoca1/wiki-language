## 速查表: 发音错误

### 英语使用者常见错误

#### 在西班牙语
| 错说 | 正说 | 原因 |
|------|------|------|
| "Hespañol" | "Español" (ehs-pah-nyohl) | 英语 "e" = "ee", 西语 "e" = "eh" |
| "Gracias" 作 "GRAH-see-as" | "GRAH-syahs" | "c" 在 "e/i" 前 = "s" |

#### 在日语
| 错说 | 正说 | 原因 |
|------|------|------|
| "Hai" 作英语 "Hi" | "Hah-ee" | "ai" = "ah-ee" (2 拍) |
| "Desu" 作 "Day-su" | "Des" (s 轻) | "u" 有时无声 |
| "Ri" 作 "ree" | "Ree" | "i" 不发 "ee" |

#### 在韩语
| 错说 | 正说 | 原因 |
|------|------|------|
| "Annyeonghaseyo" 含 "th" | "An-nyeong-ha-se-yo" | 无 "th" 音 |
| "Kimchi" 作 "Kim-chee" | "Kim-chi" | "i" 短, 无 "ee" |

#### 在中文
| 错说 | 正说 | 原因 |
|------|------|------|
| "Ni hao" 作 "Nee how" | "Nǐ hǎo" (3声好) | 声调重要 |
| "Xie xie" 作 "She she" | "Syè-syè" | "x" = "s" (拼音) |

### 中文使用者常见错误

#### 在英语
| 错说 | 正说 | 原因 |
|------|------|------|
| "TH" 作 "s/z" | "TH" 作 θ/ð | 中文无 "th" |
| "R" 作中文 ɻ | "R" 作卷舌 ɹ | 舌位置不同 |
| "V" 作 "w" | "V" 作唇齿音 | 中文无 "v" (用 唯) |

## 速查表: 语法错误

### 时态/完句错误

| L1 → L2 | 常见错误 | 原因 |
|---------|----------|------|
| **EN → ES** | "If I **will go**" → "*Si **iré***" | 西语 si 从句不用未来 → *Si **voy*** |
| **EN → JP** | "I **have gone**" → "I **go**" | 日语无现在完成时 |
| **EN → KR** | "I **will go** tomorrow" → "I **go** tomorrow" | 韩语常省略未来时 |
| **EN → CH** | "I **am eating**" → "I **eat**" | 中文用完句, 不用时态 |
| **JP → EN** | "Yesterday **go**" → "Yesterday **went**" | 英语要求过去时 |
| **KR → EN** | "Yesterday **go**" → "Yesterday **went**" | 同上 |
| **CH → EN** | "Yesterday **go**" → "Yesterday **went**" | 同上 |

### 礼貌/语域错误

| L1 → L2 | 常见错误 | 原因 |
|---------|----------|------|
| **EN → ES** | 对陌生人用 "tú" | 拉美默认用 *usted* |
| **EN → JP** | 对陌生人用 plain form | 日语默认用 *desu/masu* |
| **EN → KR** | 对长辈用 plain form | 韩语默认用 *haeyo/hapsyo* |
| **EN → CH** | 对长辈无敬语 | 中文用 您 + 头衔 |

### 冠词错误

| L1 → L2 | 常见错误 | 原因 |
|---------|----------|------|
| **JP/KR/CH → EN** | "I saw **car**" | 英语要求 "a car" 或 "the car" |
| **EN → JP/KR/CH** | "I saw **a cat**" → "I saw **cat**" | 目标语言无冠词 |

## 🇨🇳 中文学习者笔记 (Chinese Learner Notes)

> 本节是面向中文母语学习者的额外学习指南。

### 中文母语者在学习其他4种语言时的常见陷阱

1. **西语 *embarazada* = 怀孕, 非尴尬**:
   - 中文 *尴尬* 听感相似 → 学员对西语 *embarazada* 错误联想。
   - **陷阱**: 在西语文化中, 误用 *embarazada* = "我尴尬" 实际意为"我怀孕"。
   - **训练法**: 记忆时把 *embarazada* 联想到"embarazada (mbarazada) = bebé (baby)"。

2. **西语 *realizar* = 实现, 非认知**:
   - 中文 *realize* = "意识到" → 学员对西语 *realizar* 类比英语感到困惑。
   - **陷阱**: 西语 *realizar* = 实现/执行, 类似英语 *achieve*; *darse cuenta* = 意识到。
   - **训练法**: 把 *realizar* 当作 achieve, 不要当 realize。

3. **西语 *discutir* = 争吵, 非讨论**:
   - 中文 *discuss* = 讨论 → 学员对西语 *discutir* 感到困惑。
   - **陷阱**: 西语 *discutir* = 争吵, 类似 argue; *debatir* = 讨论 debate。
   - **训练法**: 商务场合永远用 *debatir*; *discutir* 只用于吵架。

4. **韩语 *서비스 (freebie)* ≠ service**:
   - 中文 *服务* = 服务 → 学员对韩语 *서비스* 翻译感到困惑。
   - **陷阱**: 韩语 *서비스* 在口语中 = "免费赠品", "on the house"。正式需用 *서비스 (formal)* 还是 *서비스 (slang)*。
   - **训练法**: 在韩餐厅听到 *서비스* = 老板送的, 不收钱。

5. **日语 *マンション (apartment)* ≠ mansion**:
   - 中文 *mansion* = 大房子 → 学员对日语 *マンション* 误译。
   - **陷阱**: 日语 *マンション* = 公寓楼 (apartment), 不是 mansion。
   - **训练法**: 日语 *マンション* = 美国公寓大楼; 真正 mansion = 邸宅/豪邸。

6. **日语 *パンツ (underwear)* ≠ pants**:
   - 中文 *pants* = 裤子 → 学员对日语 *パンツ* 感到震惊。
   - **陷阱**: 日语 *パンツ* = 内裤 (underwear), 裤子 = *ズボン (zubon)*。
   - **训练法**: 日语 *ズボン* = 裤子; *パンツ* = 内裤。避免在日语中用 *パンツ* 指裤子。

7. **汉字文化圈的"假朋友"**:
   - 中文 *书=shū* → 学员对日语 *書 (sho/ku)* / 韩语 *서 (seo)* 感到困惑。
   - **陷阱**: 汉字形似但读音完全独立, 学习时切勿用汉字读音推导。
   - **训练法**: 每汉字记忆 5 语言独立发音; 用例句测试。

8. **同形异音日韩汉字**:
   - 中文 *人 (rén)* → 学员假设日语 *人* 读 "rén" → 实际日语 *hito/jin* 完全不同。
   - **陷阱**: 日韩汉字有两种以上读音 (音读/训读, 한자/순우리말)。
   - **训练法**: 学习汉字时, 标注目标语言至少 2 个读音。
