## 速查表

### 否定结构概览

| 特征 | English | Spanish | Japanese | Korean | Chinese |
|------|---------|---------|----------|--------|---------|
| **句子否定** | 助动词 + not | *no* + 动词 | 动词后缀 *-nai* / *-masen* | 动词后缀 *-ji anta* / *-ji anhseumnida* | *bù* (不) / *méi* (没) + 动词 |
| **成分否定** | *not* + 成分 | *no* + 成分 | *wa* + *nai* / *dewa nai* | *an(i)* + 动词 / *mot* + 动词 | *bù* + 形容词/动词; *wú* (无) + 名词 |
| **否定一致** | **否** (双重否定 = 肯定) | **是** (双重否定 = 否定) | **否** (单重否定) | **否** (单重否定) | **否** (单重否定) |
| **否定极性项** | any, ever, anymore | *nadie, nada, nunca* | *dare mo...nai, nani mo...nai* | *amudo...an(i), amugeotdo...an(i)* | *shéi dōu...bù, shénme dōu...bù* |

### 句子否定

#### English
- **结构**: 助动词 + *not* (*n't*)
- **现在**: I **do not** / **don't** know. She **does not** / **doesn't** go.
- **过去**: I **did not** / **didn't** go.
- **将来**: I **will not** / **won't** go.
- **语气**: I **cannot** / **can't** / **could not** / **couldn't** go.
- **Be**: I **am not** / **'m not** / **is not** / **isn't** / **are not** / **aren't** ready.
- **Have (助动词)**: I **have not** / **haven't** seen it.
- **Have (主要, 英式)**: I **haven't** a car. (美式: I **don't have** a car.)

#### Spanish
- **结构**: *no* + 动词 (动词前)
- **现在**: *No sé.* / *No voy.*
- **过去**: *No supe.* / *No fui.* / *No he ido.* (完成)
- **将来**: *No iré.* / *No voy a ir.*
- **虚拟式触发**: *No creo que venga.* (虚拟), *No es verdad que venga.*
- **双重否定**: *No vi **nada**.* (我没看到任何东西。) *Nadie **no** vino.* → *Nadie vino.* (没人来。)

#### Japanese
- **普通否定**: 动词干 + *nai* (ない) — *tabenai* (食べない = 不吃)
- **礼貌否定**: 动词干 + *masen* (ません) — *tabemasen* (食べません)
- **过去否定**: *tabenakatta* (食べなかった) / *tabemasen deshita* (食べませんでした)
- **形容词**:
  - *i-adj*: *takai* → *takakunai* (高くない) / *takaku arimasen*
  - *na-adj/noun*: *kirei* → *kirei dewa nai* (綺麗ではない) / *kirei dewa arimasen*
- **存在**: *aru* → *nai* (ない) / *arimasen*; *iru* → *inai* (いない) / *imasen*
- **禁止**: *taberu na* (食べるな) — 普通; *tabenaide kudasai* (食べないでください) — 礼貌请求

#### Korean
- **短形 (普通)**: 动词干 + *ji anta* (지 않다) — *meokji anta* (먹지 않다)
- **长形 (礼貌)**: 动词干 + *ji anhseumnida* (지 않습니다) — *meokji anhseumnida*
- **过去**: *meokji anatda* (먹지 않았다) / *meokji anhasseumnida*
- **形容词**: 相同模式 — *yeppeuji anta* (예쁘지 않다)
- **存在**: *itda* (있다) → *eopda* (없다) — 单独的否定动词!
- **禁止**: *meokji maseyo* (먹지 마세요) / *meokjima* (먹지 마)
- **不能 (能力)**: *mot* (못) + 动词 — *mot meokda* (못 먹다) — 不同于 *an(i)*

#### Chinese
- **标准否定**: *bù* (不) + 动词/形容词 — *bù chī* (不吃), *bù hǎo* (不好)
- **完成/经验否定**: *méi* (没) / *méiyǒu* (没有) + 动词 — *méi chī* (没吃), *méiyǒu qù* (没有去)
- **将来/意志否定**: *bù* — *bù qù* (不去 = 不去)
- **祈使否定**: *bié* (别) + 动词 — *bié chī* (别吃 = 别吃)
- **形容词**: *bù* — *bù dà* (不大), *bù cōngming* (不聪明)
- **存在**: *méiyǒu* (没有) — *méiyǒu qián* (没有钱 = 没有钱)

### 成分否定

#### English
- *Not* + NP: **Not** John but Mary came.
- *Not* + PP: I saw him **not** in Paris but in London.
- *Not* + Adv: He drove **not** carefully but recklessly.
- *No* + N: **No** student passed. (限定词)

#### Spanish
- *No* + 成分: *No Juan, sino María vino.*
- *Ningún* + N (否定限定词): *Ningún estudiante aprobó.*
- *Ni*... *ni* (既不...也不): *Ni Juan ni María vinieron.*

#### Japanese
- *Wa* + 否定: *Jon wa konakatta.* (对John来说, 他没来 — 对比)
- *De wa nai* (判断否定): *Jon de wa nai.* (不是John。)
- *Mo* 在否定: *Dare mo konakatta.* (没人来。)

#### Korean
- *An(i)* / *mot* + 动词: *an(i) meokda* (안/못 먹다)
- *An(i)* = 不 (don't/won't); *mot* = 不能 (can't)
- *Ani* 作为 判断否定: *Jon-i aniya.* (존이 아니야 = 不是John)

#### Chinese
- *Bù* + VP/Adj: *bù shì* (不是 = 不是), *bù xǐhuan* (不喜欢)
- *Méi* + V (完成): *méi qù* (没去)
- *Wú* (无) + N (正式/书面): *wú rén* (无人 = 没人), *wú fǎ* (无法 = 不可能)

## 特殊否定结构

#### English
| 结构 | 示例 |
|------|------|
| **否定疑问** | *Don't you like it?* / *Isn't she coming?* |
| **反意疑问** | *You're coming, **aren't you**?* / *You're not coming, **are you**?* |
| **否定祈使** | *Don't go.* / *Let's not go.* |
| **否定不定式** | *I told him **not to go**.* |
| **否定动名词** | ***Not knowing** what to do, I waited.* |
| **既不/也不** | *I don't like it. **Neither do I**.* / ***Neither** John **nor** Mary came.* |

#### Spanish
| 结构 | 示例 |
|------|------|
| **否定疑问** | *¿No vienes?* / *¿No te gusta?* |
| **反意疑问** | *Vienes, **¿verdad?** / **¿no?** / **¿verdad que sí?** |
| **否定祈使** | *No vayas.* / *No te vayas.* (虚拟) |
| **否定不定式** | *Le dije **que no fuera**.* (虚拟) / *Le dije **no ir**.* |
| **Ni...ni** | ***Ni** Juan **ni** María vinieron.* |
| **Tampoco** (也不) | *Yo **tampoco** quiero ir.* |

#### Japanese
| 结构 | 示例 |
|------|------|
| **否定疑问** | *Tabemasen ka?* (食べませんか？= 你不想吃吗？) |
| **反意疑问** | *Taberu deshou?* (食べるでしょう？) / *Tabenai deshou?* |
| **否定请求** | *Tabenaide kudasai.* (食べないでください = 请不要吃。) |
| **否定て形** | *Tabenakute* (食べなくて = 不吃, 而且...) |
| **否定条件** | *Tabenakereba* (食べなければ = 如果不吃) |
| **Mo...nai** (甚至不) | *Ichido mo ikanai.* (一度も行かない = 从来没去过。) |
| **Wa...nai** (对比) | *Kore wa tabenai.* (これは食べない = 这个我不吃。) |

#### Korean
| 结构 | 示例 |
|------|------|
| **否定疑问** | *An meogeoyo?* (안 먹어요? = 你不吃吗？) / *Meokji anayo?* |
| **反意疑问** | *Meogeoyo, geureochji?* (먹어요, 그렇죠?) |
| **否定请求** | *Meokji maseyo.* (먹지 마세요 = 请不要吃。) |
| **否定连接** | *Meokji anko* (먹지 않고 = 不吃, 而且...) |
| **否定条件** | *Meokji aneumyeon* (먹지 않으면 = 如果不吃) |
| **Aniya** (判断否定) | *Jon-i aniya.* (존이 아니야 = 不是John。) |
| **Mot** (不能) vs **An** (不做) | *Mot meokda* (못 먹다 = 不能吃) vs *An meokda* (안 먹다 = 不吃) |

#### Chinese
| 结构 | 示例 |
|------|------|
| **否定疑问** | *Bù chī ma?* (不吃吗? = 不吃?) / *Méi chī ma?* (没吃吗?) |
| **反意疑问** | *Nǐ qù, duì ba?* (你去，对吧?) / *Nǐ bù qù, shì ba?* |
| **否定祈使** | *Bié chī!* (别吃! = 别吃!) / *Bù yào chī!* (不要吃!) |
| **否定目的** | *Wèile bù chī* (为了不吃 = 为了不吃) |
| **否定条件** | *Bù chī de huà* (不吃的话 = 如果不吃) / *Yào bù chī* (要不吃) |
| **Bù... yě** (甚至不) | *Yī cì yě méi qù.* (一次也没去 = 一次都没去。) |
| **Lián... dōu bù/méi** (甚至不) | *Lián tā dōu bù zhīdào.* (连他都不知道 = 连他都不知道。) |
| **Wú** (无) 正式 | *Wú fǎ* (无法 = 不可能), *wú rén* (无人 = 没人) |

## 否定范围与歧义

#### English
- *I didn't go because he called.* → 歧义: (1) 我没去的原因是他叫我了。 (2) 我去了, 但不是因为。
- *All that glitters is not gold.* → 传统读法: 不是所有闪光的东西都是金。 (范围: ¬∀)

#### Spanish
- *No fui porque me llamó.* → 同样歧义。 区分: *No fui **porque** me llamó* (原因) vs *Fui, **pero no** porque me llamó.*
- *No todo lo que brilla es oro.* (不是所有闪光的东西都是金 — 清晰 ¬∀)

#### Japanese
- *Kare ga yonda kara ikanakatta.* (彼が呼んだから行かなかった) — 范围歧义。
- *Zenbu ga kin dewa nai.* (全部が金ではない = 不是所有都是金。) — 清晰 ¬∀。

#### Korean
- *Geu-ga bulleoseo an gasseo.* (그가 불러서 안 갔어) — 歧义。
- *Modeum ge keum-i aniya.* (모두가 금이 아니야 = 不是所有都是金。)

#### Chinese
- *Wǒ bù qù shì yīnwèi tā jiào wǒ.* (我不去是因为他叫我 = 我不去的原因是他叫我了。) — 范围通过 *shì...de* 焦点结构澄清。
- *Bù shì yīqiè shǎnshǎn de dōu shì jīn.* (不是一切闪闪的都是金 = 不是所有闪光的东西都是金。)

## 🇨🇳 中文学习者笔记 (Chinese Learner Notes)

> 本节是面向中文母语学习者的额外学习指南。

### 中文母语者在学习其他4种语言否定时的常见陷阱

1. **不 vs 没 的区分**:
   - 中文 不 (bù) 一般 / 没 (méi) 过去/完成 → 学员假设其他语言也对应。
   - **陷阱**: 日语只有 -nai (普通) / -masen (礼貌); 韩语 -지 않다 (一般) / 못 (不能); 西语 no (通用); 英语 not (通用)。中文的不/没 在其他语言中需要词语配合或副词表达。
   - **训练法**: 制作"时态否定"对照表 — 中 不/没 = 英 not/didn't = 日 -nai/-nakatta = 韩 -지 않다/-지 않았다 = 西 no/no。

2. **别 vs 不要 的语域**:
   - 中文 别 (bié) 短促口语 / 不要 (bùyào) 正式 → 学员假设其他语言也对应。
   - **陷阱**: 日语 命令形 (食べない な / 食べないで ください); 韩语 -지 마 (非正式) / -지 마세요 (礼貌); 西语 no + 虚拟式; 英语 don't + 原形。
   - **训练法**: 区分正式/非正式否定请求 — 使用场景明确时选择正确级别。

3. **部分否定 vs 全部否定**:
   - 中文 "不全是" (部分) / "都不" (全部) → 学员假设其他语言也对应。
   - **陷阱**: 英语 "All... not" 双重否定可能歧义; 日语 NPI (否定极性项) 需与否定词共现; 韩语 -도 (也) 与否定词配合。
   - **训练法**: 学习每种语言的 NPI (否定极性项) — 谁/什么/哪儿 + 否定词。

4. **不能 vs 不想 混淆**:
   - 中文 "不能" (不能) vs "不想" (不想) → 学员假设其他语言只用一个词。
   - **陷阱**: 韩语 못 (不能) vs 안 (不); 日语 -できない (不能) vs -nai (不); 英语 can't (不能) vs don't want (不想); 西语 no puedo (不能) vs no quiero (不想)。
   - **训练法**: 区分 "能力否定" (不能) vs "意志否定" (不) — 5种语言各自的标记。

5. **否定极性项的差异**:
   - 中文 "什么/谁/哪儿 + 都不/也没" → 学员假设其他语言对应。
   - **陷阱**: 日语 誰も...ない (谁也...不); 韩语 아무도...안 (谁也...不); 英语 anyone...not; 西语 nadie...no (双重否定)。
   - **训练法**: 制作 NPI 对照表 — every的否定、某的否定、全部的否定 各自对应。
