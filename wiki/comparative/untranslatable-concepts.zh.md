## 速查表

### 英语 (英语独有的概念)

| 词 | 释义 | 文化背景 |
|------|-------|------------------|
| **Awkward** | 社交不适, 尴尬, 缺乏优雅 | 高度重视社交圆滑; "awkward turtle" 模因 |
| **Serendipity** | 幸运意外, 愉悦惊讶发现 | Horace Walpole 造词 (1754); 创新文化珍视 |
| **Bureaucracy** | 过度行政程序 | 韦伯遗产; "red tape" 作为独特概念 |
| **Privacy** | 不被干扰的权利, 个人信息控制 | 法律权利 (宪法第四修正案); "隐私期望" |
| **Accountability** | 对行动/结果负责 | 企业/政治文化; "问责" |
| **Empowerment** | 给予他人权威/信心 | 管理/自助话语; "赋予女性权力" |
| **Multitasking** | 同时做多个任务 | 重视的技能; 源自计算机术语 (1960s) |
| **Proactive** | 预防问题地行动 | 商业术语 (Covey 1989); 反义词 reactive |
| **Burnout** | 慢性工作压力疲劳 | WHO ICD-11 (2019); "安静辞职" 相关 |
| **Imposter syndrome** | 尽管有证据仍感觉欺诈 | 高成就者文化; Clance & Imes (1978) |

### 韩语 (韩语独有的概念)

| 词 | 谚文 | 释义 | 文化背景 |
|------|---------|-------|------------------|
| **한** | 한 (han) | 深深的悲伤, 怨恨, 未解的悲痛 | 集体创伤 (殖民, 战争, 分裂); *han-puri* (释放) |
| **정** | 정 (jeong) | 深深的感情, 依恋, 随时间建立的纽带 | *Jeong-i deulda* (依恋); *jeong-i meolda* (疏远); 不仅是爱 |
| **눈치** | 눈치 (nunchi) | 社交能力, 读懂情境, 揣摩情绪 | *Nunchi boida* (有眼色); *nunchi eopda* (无眼色); 生存技能 |
| **효도** | 효도 (hyodo) | 孝道, 伺候父母 | 儒家核心; *hyodo-hada*; 政府补贴照顾者 |
| **체면** | 체면 (chemyeon) | 面子, 尊严, 公众声誉 | *Chemyeon seuda* (保面子); *chemyeon gujjida* (丢面子) |
| **우정** | 우정 (ujeong) | 深厚友谊, 超越便利的忠诚 | *Ujeong-i dupeotda* (友谊加深); 不同于 *chingu* |
| **맛** | 맛 (mat) | 味道, 品味, 但也是 "感觉/氛围" | *Mat-eopda* (无味); *mat-jip* (美食店) |
| **소확행** | 소확행 (so-hwak-haeng) | 小而确定的幸福 | 2010s 趋势 (日语 *shōkōfuku*); 咖啡, 散步, 书 |
| **케렌시아** | 케렌시아 (kerensia) | 个人避难所, 充电的安全空间 | 西班牙语 *querencia* 借词; *nae kerensia* (我的避难所) |
| **인연** | 인연 (inyeon) | 因缘, 命中注定的关系 | 佛教起源; *inyeon-iilda* (命中注定); *inyeon-i eopda* |
| **손님** | 손님 (sonnim) | 客人, 顾客 — 受到最高尊重 | *Sonnim-eun wang-ida* (客人是王); 服务文化 |
| **미안하다** | 미안하다 (mianhada) | 抱歉 + 感谢 + 亏欠 (多功能) | *Mianhamnida* = 道歉, 感谢, 不好意思 |
| **고맙다** | 고맙다 (gomapda) | 感谢 + 认可努力/好意 | *Gomapseumnida* 比 *gamsahamnida* 更深 |
| **빨리빨리** | 빨리빨리 (ppali-ppali) | 快点快点, 速度文化 | 经济奇迹驱动; *ppali-ppali munhwa* |
| **정들다** | 정들다 (jeong-deulda) | 随时间变得情感依恋 | *Jeong-deureo himdeulda* (难以离开因为依恋) |

## 🇨🇳 中文学习者笔记 (Chinese Learner Notes)

> 本节是面向中文母语学习者的额外学习指南。

### 中文母语者在学习其他4种语言不可译概念时的常见陷阱

1. **汉字桥梁导致概念混淆**:
   - 中文 缘分/面子/关系 与日韩相似概念共享汉字 → 学员以为意思相近。
   - **陷阱**: 韩语 인연 (inyeon) 与中文 "缘分" 同字不同音; 日语 縁 (en) 与中文 "缘" 同字不同义。
   - **训练法**: 利用汉字桥梁先理解概念, 然后严格训练读音 — 不要假设同汉字 = 同概念。

2. **"关系" Guanxi 的特殊性**:
   - 中文 关系 (guānxi) = 商业文化 → 学员假设其他语言有类似。
   - **陷阱**: 韩语 인맥 (inmaek) / 줄 (jul) = 人脉; 日语 コネ (kone) / 人脈 (jinmyaku) = 人脉; 英语 "networking" = 社交; 西语 enchufe = 关系。
   - **训练法**: 区分"商业关系" vs "一般社交网络" — 中文 Guanxi 是综合文化, 其他语言较窄。

3. **"面子" 的不同表达**:
   - 中文 面子 (miànzi) = 重要 → 学员假设其他语言也有类似。
   - **陷阱**: 韩语 체면 (chemyeon) 与中文 "体面" 同字; 日语 面目 (menboku) / 体面 (teimen) 类似; 英语 "face" 没有完全等价; 西语 "imagen" 不同。
   - **训练法**: 区分"东亚面子文化" vs "西方face" — 中韩日共享面子观念, 西方较弱。

4. **孝道文化的差异**:
   - 中文 孝顺 (xiàoshùn) 核心儒家 → 学员假设其他语言也有类似。
   - **陷阱**: 韩语 효도 (hyodo) 同样重要; 日语 親孝行 (oyakoukou) 较弱 (战后); 英语 "filial piety" 学术词; 西语 "respeto a padres" 弱。
   - **训练法**: 区分"东亚孝道文化" vs "西方独立" — 中韩仍有强孝道, 西方较弱。

5. **"没办法"的文化差异**:
   - 中文 没办法 (méi bànfǎ) = 接受 → 学员假设其他语言也有类似。
   - **陷阱**: 日语 しょうがない (shou ga nai) 同样表达; 韩语 어쩔 수 없다 (eojjeol su eopda) 类似; 英语 "it is what it is" 类似; 西语 "qué le vamos a hacer" 类似。
   - **训练法**: 区分"接受命运" vs "积极改变" — 东亚文化较接受, 西方更积极。
