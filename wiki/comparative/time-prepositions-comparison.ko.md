## 핵심 대조 (종합)

| 대조 | 학습자 함의 |
|----------|--------------------------|
| **전치 vs 후치** | EN/ES/CH는 전치사 (명사 앞); JP/KR는 후치사 (명사 뒤) — 반대 논리 |
| **정적 vs 행동** | JP/KR는 に/에서 and 에/에서 구분; EN 둘 다 "in/at"로 통합 |
| **시간 조사** | EN "at/in/on" 암기 필수; JP/KR/CH는 공간 논리 시간에 재사용 |
| **수단/도구** | EN "by"; ES "en"; JP/KR "で/로"; CH "用 (yòng)" — 모두 다른 형태 |

## 학습자 의사결정 가이드

> **시간**: at 5 (5時に) · in May (5月に) · on Monday (月曜日に)

> **수단**: by bus (バスで) · with pen (ペンで)
> **부터/까지**: from home (うちから → うちへ) · until 5 (5時まで)

> - in (월/년): in May / en mayo / 5月に / 5월에 / 五月
> - on (요일): on Monday / el lunes / 月曜日に / 월요일에 / 周一
> - in (아침): in the morning / por la mañana / 朝に / 아침에 / 早上
> - at (장소): at the station / en la estación / 駅で / 역에서 / 在车站
> - in (내부): in the box / en la caja / 箱の中に / 상자 안에 / 在盒子里
> - to: to school / a la escuela / 学校へ / 학교로 / 去学校
> - from: from home / desde casa / うちから / 집에서 / 从家

## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 전치사/조사를 학습할 때 흔히 마주치는 함정

1. **한국어 후치사 vs 영어 전치사**:
   - 한국어: 조사 = 명사 **뒤**. 예: "학교에 (hakgyo-e)" / "학교에서 (hakgyo-eseo)" — 명사 뒤.
   - 영어/스페인어/중국어: 전치사 = 명사 **앞**. 예: "at school" / "en la escuela" / "在学校" — 명사 앞.
   - **함정**: 한국어 학습자가 영어/스페인어 전치사를 명사 뒤에 위치 → "school at" (X) vs "at school" (O).
   - **훈련법**: 한국어 후치사 vs 영어/스페인어/중국어 전치사 **위치 비교** — 한국어/일본어 = 후치, 나머지 3개 = 전치. **위치 차이 명시 학습**.

2. **한국어 에 vs 에서 의 정적 vs 행동 구분**:
   - 한국어: 에 (정적) / 에서 (행동/부터). 예: "학교에 가요" (to school) vs "학교에서 공부해요" (at school).
   - 영어: 단일 "in/at". 예: "go to school" vs "study at school" — at/to로 구분.
   - 스페인어: en (정적) vs a (방향). 예: "estudiar en la escuela" vs "ir a la escuela".
   - 중국어: 在 (정적) vs 去 (방향). 예: "在学校" vs "去学校".
   - **함정**: 한국어 학습자가 영어/스페인어/중국어 단일 "at/in" 사용 시 "정적 vs 행동" 무시.
   - **훈련법**: 에 vs 에서 매트릭스 — 정적(에/in/at) vs 행동(에서/동사/에). **4개 언어 메커니즘 비교**.

3. **시간 전치사 at/in/on 의 한국어 무지**:
   - 영어: at 5 (시), in May (월), on Monday (요일) — **3개 필수 구분**.
   - 한국어: 시/월/요일 모두 **에** 조사 사용. "5시에" / "5월에" / "월요일에".
   - 일본어: 시/월/요일 모두 **に** 조사. "5時に" / "5月に" / "月曜日に".
   - 중국어: 전치사 없음, 단순 시간 명사. "五点" / "五月" / "周一".
   - **함정**: 한국어 학습자가 영어 at/in/on 3개 구분 어려움 → "at Monday" (X) vs "on Monday" (O). **한국어는 단일 에로 통합**.
   - **훈련법**: at/in/on 3개 vs 한국어 에 1개 — **한국어 단순화 인지**. 다른 4개 언어 (특히 영어) 3개 구분 학습.

4. **수단/도구 5개 언어 매트릭스**:
   - 한국어: "로/으로". 예: "버스로" / "펜으로" (수단 + 조사).
   - 일본어: "で (de)". 例: "バスで" / "ペンで".
   - 중국어: "用 (yòng)" 동사 또는 "坐/骑 + 명사" 구조. 예: "坐公交" / "用笔".
   - 영어: "by + 명사" 또는 "with + 명사". 例: "by bus" / "with a pen".
   - 스페인어: "en + 명사" 또는 "con + 명사". 例: "en autobús" / "con un bolígrafo".
   - **함정**: 한국어 학습자가 영어 "by bus" 단순 매핑 → "by 버스" (X) vs "버스로" (O). 수단 조사 다름.
   - **훈련법**: 수단/도구 5개 언어 매트릭스 — KR 로/으로 / JP で / CH 用 / EN by/with / ES en/con. **5개 메커니즘 비교**.

5. **부터/까지 시간 한정**:
   - 한국어: "부터/까지". 예: "3시부터" / "5시까지".
   - 일본어: "から/まで". 例: "3時から" / "5時まで".
   - 중국어: "从...到" 구조. 例: "从3点到5点".
   - 영어: "from...to" 또는 "until". 例: "from 3 to 5" / "until 5".
   - 스페인어: "desde...hasta". 例: "desde las 3 hasta las 5".
   - **함정**: 한국어 학습자가 다른 4개 언어에 "부터/까지" 단순 매핑 → 영어 "from" / "to" / "until" 매핑 시 다수 단어 사용.
   - **훈련법**: 부터/까지 5개 언어 매트릭스 — KR 부터/까지 / JP から/まで / CH 从/到 / EN from/to/until / ES desde/hasta. **5개 메커니즘 비교**.

### 학습 전략

1. **우선순위 1**: 한국어 후치사 vs 영어/스페인어/중국어 전치사 **위치 비교** — 한국어/일본어 = 후치, 나머지 3개 = 전치. **위치 차이 명시 학습**.
2. **우선순위 2**: 에 vs 에서 매트릭스 — 정적(에/in/at) vs 행동(에서/동사/에). **4개 언어 메커니즘 비교**.
3. **우선순위 3**: at/in/on 3개 vs 한국어 에 1개 — **한국어 단순화 인지**. 다른 4개 언어 (특히 영어) 3개 구분 학습.
4. **우선순위 4**: 수단/도구 5개 언어 매트릭스 — KR 로/으로 / JP で / CH 用 / EN by/with / ES en/con. **5개 메커니즘 비교**.
5. **우선순위 5**: 부터/까지 5개 언어 매트릭스 — KR 부터/까지 / JP から/まで / CH 从/到 / EN from/to/until / ES desde/hasta. **5개 메커니즘 비교**.
