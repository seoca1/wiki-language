## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 예술·공예 어휘를 배울 때 흔히 마주치는 함정

1. **"미술" 의 다의성**:
   - 한국어 "미술" = fine art (회화, 조각) + art education (초등학교미술, 중학교미술). 영어 "art" 와 스페인어 "arte" 도 비슷한 광범위 의미.
   - **함정**: 그러나 일본어 美術 (bijutsu) 와 중국어 美术 (měishù) 는 순수 예술에에에 한정 — — "미술 교육" 은은 図画工作 (zuga kōsaku, JP) / 美术教育 (měishù jiàoyù, CN) 처럼 별도.
   - **훈련법**: 한국어 "미술" 맥락별 매핑 학습 — 갤러리/박물관 맥락 = "fine art", 학교 교과 = "art education", 일상 "그림 그리기" = "drawing/art".

2. **한자 공유 예술 어휘의 다의 매핑**:
   - 藝(예)/艺(yì) - "art" 한자가 JP/KR/CN 공유 → 그러나 術(術)/术(shù) - "skill/technique" 와 결합 시 다른 의미 (藝術 vs 術語 = 용어).
   - **함정**: 한국어 학습자가 일본어 芸術 (geijutsu) 를 "예술" 로 직역 → 의미는 같으나 術 의 일본어 독음 (jutsu) 와 한국어 (sul) 다름.
   - **훈련법**: 한자 결합 단위 학습 — 藝 + 術 = art, 美 + 術 = fine art, 書 + 道 = calligraphy (JP/KR/CN 공유), 工 + 芸/艺 = craft.

3. **"서예(書道/書法/서예)" 의 문화적 지위**:
   - 한국어 학습자에게 서예는 동아시아 공유 예술 — 그러나 일본어 書道 (shodō) 와 중국어 书法 (shūfǎ) 의 강조점이 다름.
   - **함정**: 일본어 書道 (書 + 道 = 글씨의 도) 는 다도/화도와 같은 道 (michi) 의 맥락 — 중국어 书法 (書 + 法 = 글씨의 법) 는 법/규범 강조. 한국어 "서예" 는 "書藝" 였다가 "서예" 로 단순화.
   - **훈련법**: 書道/書法/서예 의 문화적 뉘앙스 학습 — 일본은 道 (도/길), 중국은 法 (법/규범), 한국은 藝 (예/기술).

4. **"한복/韓服/汉服/和服/kimono" 의 문화별 구분**:
   - 한국어 "한복" = 한국 전통 의상. 중국어 韩服 (한복 발음) ≠ 한국 한복; 중국어 汉服 (Han Chinese 의상) 와 한국 한복 (Korean traditional) 은 다른 의상.
   - **함정**: 중국어 韩服 (hánfú, 중국식 발음) vs 한국 한복 (hanbok) — 한자 한 (韓/韩) 의 두 형태 매칭.
   - **훈련법**: 韓服 (hánfú, 중국식) vs 한복 (한국) / 汉服 (hànfú, 중국) / 和服 (héfú, 일본) / kimono (일본) 4개 구분 매핑.

5. **"공예 어휘의 토착 vs 한자 패턴"**:
   - 한국어 공예 어휘는 한자어 (도자=陶磁, 칠기=漆器, 자수=刺繡) + 토착어 (종이접기, 한지) 혼합. 일본어/중국어 와 다름.
   - **함정**: 종이접기 = origami 라고 단일 단어 사용 (영어/스페인어), 그러나 중국어 折纸 (zhézhǐ) 는 2글자.
   - **훈련법**: 한국어 토착어 공예 어휘 (한지, 매듭, 나전칠기 등) 는 일본어/중국어 한자어 매핑 필요. 공예품별 한자 매칭 학습 — 陶磁/陶瓷, 漆器/漆器, 刺繡/刺绣.

### 학습 전략

1. **우선순위 1**: 한국 공예 전통 (한지, 나전칠기, 분청사기, 매듭) 의 어휘 학습 — 한국 고유 전통.
2. **우선순위 2**: 한자 공유 예술 어휘 마스터 — 藝/术/美/書/画/彫/塑 의 JP/KR/CN 결합 단위.
3. **우선순위 3**: 전통 의상 매핑 — 한복/漢服/和服/kimono 의 4개 문화별 구분.
4. **우선순위 4**: 미술 도구 어휘 (붓/筆/笔/筆/pincel/brush) 의 언어별 어순과 양사 패턴.
5. **우선순위 5**: 한자 문화 공유 (CJK) 의 서예 지위 학습 — EN/ES 와 매우 다른 문화적 맥락.
