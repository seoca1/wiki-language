## 各语言详情

### 🇬🇧 英语 (English)
- **关键词**: "Game" vs "Match" — Game = 计划赛事, Match = 对抗
- **模式**: 强区分 "sport" (组织化竞争) 与 "recreation" (休闲活动)
- **语阶笔记**: 随意 — "Let's ball" (informal for "let's play"); 正式 — "shall we engage in athletic activity"
- **来源**: `[[sports-vocabulary]]`

### 🇪🇸 西班牙语 (Spanish)
- **关键词**: "Fútbol" (通用术语); "Fútbol americano" = 美式足球, "Fútbol sala" = 室内足球
- **模式**: -ar 动词变位 for sports (jugar, practicar, entrenar)
- **地区差异**: 西班牙 "fútbol" = LatAm "fútbol" (一致); 拳击手套 "guante" 因国家而异
- **来源**: `[[sports-and-hobbies]]`

### 🇯🇵 日语 (Japanese)
- **关键词**: スポーツ vs 運動 (undō = 运动/体力活动); 部活 (bukatsu = 俱乐部活动)
- **模式**: 动词词尾: 〜する (suru = 做), 〜をやる (wo yaru = 玩)
- **敬语 / 礼貌级别**: 随意 — "野球やる?" (yakyū yaru?); 礼貌 — "野球をなさいますか?"; 谦逊 — "野球をいたします"
- **来源**: `[[sports-vocabulary]]`

### 🇰🇷 韩语 (Korean)
- **关键词**: 체육 (cheyuk = 体育) vs 스포츠 (seupocheu = 运动)
- **模式**: 动词: 〜하다 (hada = 做), 〜을 하다 (eul hada = object+做)
- **语阶**: 随意 — "야구해?" (yaguhae?); 礼貌 — "야구를 해요" (yagueul haeyo); 正式 — "야구를 합니다" (yagueul hamnida)
- **来源**: `[[sports-vocabulary]]`

### 🇨🇳 中文 (Chinese)
- **关键词**: 体育 (tǐyù = 体育) vs 运动 (yùndòng = 运动/锻炼)
- **模式**: 动词: 〜进行 (jìnxíng = 执行), 〜打 (dǎ = 玩球类运动)
- **语阶 / 敬语**: 随意 — "打球吗?" (dǎ qiú ma?); 礼貌 — "我们一起打球吧" (wǒmen yìqǐ dǎ qiú ba)
- **来源**: N/A — 中文 wiki 暂无 sports 主题

## 关键对比 (综合)

| 对比 | 洞察 |
|------|------|
| **借词模式** | 所有语言借用英语体育术语 ("baseball", "basketball", "golf") — 但日/韩加本土读音, 中用 棒球/篮球/golf 音译 |
| **动词表达** | 英用轻动词 ("play", "do"); 西用 -ar 变位; 日/韩/中用名词+助动词 (をやる/을 하다/打) |
| **文化权重** | 运动承载强文化身份 — 拉丁美洲足球, 日/韩棒球, 中国篮球 — 不同运动 = 不同文化锚 |
| **学校整合** | 日/韩有强制 部活/체육 在学校; 英/中较少整合进正式教育 |

## 🇨🇳 中文学习者笔记 (Chinese Learner Notes)

> 本节是面向中文母语学习者的额外学习指南。

### 中文母语者在学习其他4种语言运动术语时的常见陷阱

1. **汉字桥梁导致运动术语混淆**:
   - 中文 运动/体育/篮球 与日韩运动词汇共用汉字 → 学员以为读音相近。
   - **陷阱**: 韩语 운동 (undong) 与中文 "运动" (yùndòng) 同字不同音; 日语 野球 (yakyū) 与中文 "野球" (yěqiú, 古语) 现代不同音。
   - **训练法**: 利用汉字桥梁先理解概念, 然后严格训练读音。

2. **球类运动"打" vs "玩" 的差异**:
   - 中文 用 "打" + 球 (打球/打篮球) → 学员假设其他语言也对应。
   - **陷阱**: 英语 "play" (play basketball); 日语 をする (suru) / をやる (wo yaru); 韩语 ~을 하다 (eul hada); 西语 jugar (jugar al baloncesto)。
   - **训练法**: 区分"打" vs "玩" — 5种语言各自的运动动词模式。

3. **运动文化的差异**:
   - 中国 篮球/乒乓球 普及 → 学员假设其他语言也有类似文化。
   - **陷阱**: 拉丁美洲 足球狂热; 日本 棒球 = 国民运动; 韩国 棒球/足球并重; 美国 多种(basketball/football/baseball)。
   - **训练法**: 了解目的地运动文化 — 谈论运动是社交好方法。

4. **武术借词的差异**:
   - 中文 武术 (wǔshù) / 跆拳道 (táiquándào) → 学员假设其他语言也有对应。
   - **陷阱**: 日语 柔道 (jūdō) / 空手 (karate) / 剣道 (kendo); 韩语 유도 / 가라테 / 검도 / 태권도; 西语 yudo/kárate/kendo/taekwondo; 英语 拉丁化直接借用。
   - **训练法**: 区分东亚"项目" vs 西方"全能" — 中文有 武术 总称, 其他语言按项目区分。

5. **职业 vs 业余的差异**:
   - 中文 职业体育 (zhíyè tǐyù) 与 业余体育 → 学员假设其他语言也对应。
   - **陷阱**: 日语 プロ (puro) vs アマ (ama); 韩语 프로 (peuro) vs 아마추어 (amachwi); 西语 profesional vs amateur; 英语 professional vs amateur。
   - **训练法**: 区分"职业" vs "业余" — 5种语言各自的对应词。
