## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 교육 어휘를 배울 때 흔히 마주치는 함정

1. **"수능(Su-neung)" 의 한국 특수성**:
   - 한국어 "수능" 은 11월 둘째 주 목요일 하루에 모든 대학 진학이 결정되는 단일 시험 — 1989년 제도. 일본어 センター試験 (2006-2020) 와 중국어 高考 (1952-현재) 와 같은 시스템.
   - **함정**: 한국어 학습자가 영어 "SAT" 와 동일시 → SAT 는 다수 응시 가능 / 스페인어 Selectividad 도 다수 응시 / 수능 은 하루 원샷. 같은 "입시 시험" 이지만 압박 강도 매우 다름.
   - **훈련법**: 단일 고위험 시험 매핑 — KR 수능 / JP センター試験 / CH 高考 / ES Selectividad (덜 원샷) / EN SAT (다수 응시). 압박 강도 학습.

2. **"학원(Hakwon)" 의 한국 특수성**:
   - 한국어 "학원" = 사설 학원/학원 — 한국에서 보편적 사교육. 일본어 塾 (juku) 와 중국어 补习班 (buxiban) 와 유사.
   - **함정**: 한국어 학습자가 영어 "academy" 를 "학원" 으로 번역 → 영어 academy 는 학교/연구기관 의미. 학원 = cram school.
   - **훈련법**: 사교육 어휘 매핑 — KR 학원 (hakwon) / JP 塾 (juku) / CH 补习班 (buxiban) / EN cram school / ES academia. 학원 의 한국적 의미 (세계 최고 사교육 비율) 학습.

3. **"SKY" / "인서울" 의 한국 대학 서열**:
   - 한국어 "SKY" = 서울대(S) + 고려대(K) + 연세대(Y) — 비공식 톱 3. "인서울" = 서울 소재 명문대.
   - **함정**: 일본어 旧帝大 (7개 제국대학) / 중국어 985/211 (정책 명칭) 와 다른 시스템.
   - **훈련법**: 대학 서열 어휘 학습 — KR SKY/인서울 / JP 旧帝大 (東京, 京都, 大阪, 名古屋, 東北, 九州, 北海道) / CH 985/211 / EN Ivy League / ES universidad de prestigio. 문화적 의미 학습.

4. **"선생님(Seonsaengnim)" 의 -님 존경**:
   - 한국어 "선생님" 은 -님 호칭으로 존경 표시 — 일본어 先生 (sensei) 도 존경, 중국어 老师 (lǎoshī) 는 단일, 영어 teacher 단순.
   - **함정**: 한국어 학습자가 영어에서 "Teacher-nim" 같은 직접 결합 시도 → 어색. 일본어 先生 는 단일 단어 자체가 존경.
   - **훈련법**: 교사 호칭 비교 — KR 선생님 (-님 존경) / JP 先生 (단어 자체 존경) / CH 老师 (단일) / EN Mr./Ms. Smith (호칭) / ES Profesor/a (직함).

5. **"입시지옥(Ipsi Jiog)" 의 한국 고유성**:
   - 한국어 "입시지옥" = 입시 (입학시험) + 지옥 (hell) — 한국 입시 문화의 극한 압박 표현. 일본어 受験戦争 (juken sensō = 입시 전쟁) 와 유사하나 한국은 더 격함.
   - **함정**: 일본어 受験戦争 (juken sensō) 와 중국어 高考工厂 (gāokao gōngchang) 와 비슷하지만 한국 입시지옥 의 문화적 무게는 다름.
   - **훈련법**: 입시 압박 문화 비교 — KR 입시지옥 / JP 受験戦争 / CH 高考工厂 / EN test pressure (덜 강조) / ES selectividad stress.

### 학습 전략

1. **우선순위 1**: 한국어 학교 시스템 (초등학교/중학교/고등학교/대학교/대학원) 마스터 + 학년 (1학년, 2학년...) 어휘.
2. **우선순위 2**: 수능 + 학원 + SKY + 인서울 의 한국 고유 어휘 학습.
3. **우선순위 3**: 한자 학교 어휘 매핑 (小学校/초등학교/小学, 中学校/중학교/중, 大学).
4. **우선순위 4**: 선생님 호칭 시스템 (KR -님 / JP 先生 / CH 老师) 의 존경법 비교.
5. **우선순위 5**: 시험 어휘 (수능/SAT/高考/) 의 문화적 압박 강도 학습.
