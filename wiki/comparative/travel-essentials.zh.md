## 🇨🇳 中文学习者笔记 (Chinese Learner Notes)

> 本节是面向中文母语学习者的额外学习指南。

### 中文母语者在学习其他4种语言旅行短语时的常见陷阱

1. **汉字桥梁导致短语混淆**:
   - 中文 旅行词汇与日韩大量共享汉字 (例: 旅行/旅行/여행, 飞机/飛行機/비행기) → 学员以为读音相近。
   - **陷阱**: 韩语 여행 (yeohaeng) 与中文 "旅行" (lǚxíng) 同字不同音; 日语 旅行 (ryokō) 与中文发音差异巨大。
   - **训练法**: 利用汉字桥梁先理解概念, 然后严格训练读音 — 不要假设同汉字 = 同读音。

2. **小费文化的差异**:
   - 中国 小费罕见 → 学员假设其他语言也类似。
   - **陷阱**: 美国 15-20% 小费常态; 西班牙 5-10% 小费; 日本/韩国小费罕见甚至失礼。
   - **训练法**: 出境前确认目的国小费文化 — 避免失礼或花费不足。

3. **支付方式的差异**:
   - 中国 移动支付 (微信/支付宝) 几乎全民 → 学员假设其他语言也类似。
   - **陷阱**: 日本 现金仍主导; 韩国 T-money 集成; 西班牙 信用卡 + 现金; 英语 信用卡。
   - **训练法**: 携带信用卡 + 当地货币 + 移动支付工具 — 全球化准备。

4. **用餐时间的差异**:
   - 中文 早餐 7-8 / 午餐 12 / 晚餐 18-19 → 学员假设其他语言国家也类似。
   - **陷阱**: 西班牙 早餐 9-10 / 午餐 14-15 / 晚餐 21-22 (晚); 日本 早餐 7 / 午餐 12 / 晚餐 19-20。
   - **训练法**: 制作"5种语言用餐时间"对照表 — 旅行时调整作息。

5. **紧急求助的差异**:
   - 中文 报警 110 / 救护车 120 / 火警 119 → 学员假设其他语言国家也类似。
   - **陷阱**: 英语 911 (美国) / 999 (英); 日语 110 (警察), 119 (救护车/火警); 韩语 112 (警察), 119 (救护车/火警); 西语 112 (欧洲通用), 091 (墨西哥)。
   - **训练法**: 旅行前查询目的地紧急号码 — 生命攸关。
