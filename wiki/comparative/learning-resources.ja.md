## 🇯🇵 日本語学習者ノート (Japanese Learner Notes)

> 本セクションは日本語学習者向けの追加学習ガイドです。

### 日本語話者が他の4言語の学習リソースを選ぶ際の一般的な落とし穴

1. **日本語学習リソースの優位性を見落とし**:
   - 日本語は非ネイティブ学習者の歴史が長く、リソースが豊富 → 他の言語学習時にも同じ品質の期待は禁物。
   - **練習法**: 他の言語 (KR, CH, ES) も良質リソースがあるが、日本語ほどではない; 早めに質を見極める。

2. **「教科書」文化の差**:
   - 日本語学習は「教科書 + クラス」が標準 → KR/CH も同様だが、英語/スペイン語学習は「アプリ + 会話」中心の場合が多い。
   - **練習法**: 学習スタイルに合わせてリソースを組み合わせる (Genki + italki for JP; Anki + iTalki for KR)。

3. **「ネイティブ コンテンツ」依存の罠**:
   - 日本語学習は Anime/J-Drama が中心 → KR は K-Drama/K-Pop; CH は C-Drama; ES は Telenovela。
   - **練習法**: 文化的興味を学習に活用; コンテンツを通じて自然な語彙・表現を獲得。

4. **SRS (Anki) 過信**:
   - 日本語学習で Anki が普及 → KR/CH でも有効だが、EN/ES は他のアプリ (Quizlet, Memrise) も効果的。
   - **練習法**: L1 に応じた SRS を選択; 日本語学習者は Anki の流儀を KR/CH に応用可能。

5. **「チューター (italki)」利用の文化差**:
   - 日本語学習では italki が普及 → KR/CH 学習でも同様; ただしチューターの質は言語により異なる。
   - **練習法**: トライアル レッスン (30 分 / 5-15 USD) を活用; 自分に合ったチューターを見つける。
