## 言語間転移難易度マトリクス

| L1 → 目標 | 最も難しい機能 | 理由 |
|-------------|------------------------|-----|
| **EN → ES** | Trill, β/ð/ɣ, 5 vowels | No trill; no spirantization; more vowels |
| **EN → JP** | Pitch accent, mora timing, ɸ, Q, N | No stress; mora-timed; new consonants |
| **EN → KR** | Three-way stops, batchim rules, ɯ | No aspiration contrast; complex coda |
| **EN → CH** | **Tones**, retroflex/palatal, no clusters | No tone; no aspiration contrast |
| **ES → EN** | θ/ð, 12+ vowels, stress, reduction | 5 vowels → 14; unpredictable stress |
| **ES → JP** | Pitch accent, mora, Q, N | No stress; mora-timed |
| **ES → KR** | Three-way stops, batchim | No three-way; no complex coda |
| **ES → CH** | Tones, retroflex, no codas | No tone; no codas except n/s |
| **JP → EN** | Stress, reduction, θ/ð, r/l, clusters | No stress; no θ/ð; no r/l; no clusters |
| **JP → CH** | Tones, retroflex, no pitch accent | Pitch accent ≠ tone; no retroflex |
| **KR → EN** | Stress, θ/ð, r/l, clusters, reduction | No stress; no θ/ð; no r/l |
| **KR → JP** | Pitch accent type, mora vs syllable | Seoul accent ≠ Tokyo; syllable vs mora |
| **KR → CH** | Tones, retroflex, no batchim | No tone; no retroflex; no coda clusters |
| **CH → EN** | Stress, clusters, θ/ð, r/l, reduction | No stress; no clusters; no θ/ð |
| **CH → JP** | Pitch accent, no tones, mora | Tone ≠ pitch accent; syllable vs mora |
| **CH → KR** | Three-way stops, batchim, no tones | No three-way; no tones |

## 🇯🇵 日本語学習者ノート (Japanese Learner Notes)

> 本セクションは日本語学習者向けの追加学習ガイドです。

### 日本語話者が他4言語の発音を学ぶ際の一般的な落とし穴

1. **英語の TH (θ/ð) 音**:
   - 日本語には TH 音なし → 学習初期に "this" を「ディス」、「think」を「トンク」と発音しがち。
   - **落とし穴**: ネイティブは「dis」「tink」と発音が異なり、理解できない可能性。
   - **練習法**: 舌を軽く上下の歯に挟んで "th" 音を 5分間/日 練習 (ミラー前で)。

2. **スペイン語 Trill (r) と Tap (ɾ)**:
   - 日本語の「ら」行は flap (ɾ) → スペイン語の r (tap) は OK だが、rr (trill) は難しい。
   - **落とし穴**: 「perro」(dog) と「pero」(but) のように、trill で意味が変わる。
   - **練習法**: 舌を口蓋に近づけて振動させる訓練 (1日 10分)。

3. **中国語 4 トーン**:
   - 日本語は高低アクセント (2-3 区別) → 中国語 4 トーンは より細かい区別。
   - **落とし穴**: 「妈/麻/马/骂」(mā/má/mǎ/mà) を聞き分けられない + 発話も区別できない。
   - **練習法**: 毎日 5分間、ネイティブ音声を聞いて 4 トーンを mimic (模倣)。

4. **韓国語 3-way stops (ㅂ/ㅃ/ㅍ)**:
   - 日本語は無気音/有気音区別が薄い → 韓国語 3 区別 (plain/tense/aspirated) は新規。
   - **落とし穴**: 「밥/빱/팝」 (bap/ppap/pap) のような 3 区別が困難。
   - **練習法**: ネイティブ音声の mimic + 韓国語ハングル教材で 3 区別を集中訓練。

5. **ピッチアクセント vs 声調 (Tone)**:
   - 日本語のピッチアクセント (nihon pitch accent) と中国語の声調 (Chinese tones) は音が似て非なるもの。
   - **落とし穴**: 日本語話者が中国語の mā (妈) と日本語高橋 (Takahashi) の両方が "高→低" パターンと思いがち → 異なる構造。
   - **練習法**: 中国語の 4 トーン + 軽声 を意識的に「声調」と認識し、ピッチアクセントと分けて訓練。
