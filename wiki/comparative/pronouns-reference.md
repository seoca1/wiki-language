## Key Structural Differences

| Feature | English | Spanish | Japanese | Korean | Chinese |
|---------|---------|---------|----------|--------|---------|
| **Obligatory?** | Yes (subject required) | No (pro-drop) | No (pro-drop, context-heavy) | No (pro-drop) | No (pro-drop) |
| **Gender in 3rd sg** | Yes (he/she/it) | Yes (él/ella) | No (kare/kanojo = he/she but rarely used) | No (geu/geunyeo = he/she but rare) | Yes (tā/tā/tā — same sound, diff char) |
| **Politeness encoded** | No (lexical only) | Yes (tú/usted/vos) | Yes (pronoun choice = register) | Yes (pronoun choice = register) | Yes (nǐ/nín) |
| **Inclusive/exclusive we** | No | No | No (wareware = formal we) | No (uri = inclusive default) | **Yes** (zánmen = inclusive, wǒmen = exclusive) |
| **Zero pronoun (pro-drop)** | No | **Yes** (standard) | **Yes** (standard) | **Yes** (standard) | **Yes** (standard) |

## Per-Language Detail

### English
- **Mandatory subjects**: Every finite clause requires overt subject
- **Case system**: I/me, he/him, she/her, we/us, they/them
- **Generic "you"**: Singular and plural identical
- **Singular "they"**: Standard for unknown/nonbinary gender
- **Reflexives**: myself, yourself, himself, herself, itself, ourselves, yourselves, themselves
- **Possessives**: my/mine, your/yours, his, her/hers, its, our/ours, their/theirs
- **Sources**: `[[wiki/English/vocabulary/basic-vocabulary]]`

### Spanish
- **Pro-drop**: Subject pronouns routinely omitted (*hablo* = "I speak")
- **Tú/Usted/Vos**: Three-way singular informal/formal split (regional
- **Vosotros (Spain only)**: Plural informal; *ustedes* = plural formal (Spain) / plural both (LatAm)
- **Gender**: All pronouns gendered (*nosotros/nosotras*, *ellos/ellas*)
- **Clitic pronouns**: me/te/se/nos/os/le/les/lo/la/los/las — pre-verbal or attached to infinitive/gerund
- **Reflexive**: *se* (3rd person all numbers/genders)
- **Sources**: `[[wiki/Spanish/vocabulary/basic-vocabulary]]`, `[[wiki/Spanish/culture/espana-vs-latinoamerica-registro]]`

### Japanese
- **Pronoun = register choice**: No neutral "I/you" — every choice marks relationship
- **First person**:
  - *watashi* (私) — neutral polite (default)
  - *watakushi* (私) — formal
  - *boku* (僕) — masculine casual
  - *ore* (俺) — masculine rough/intimate
  - *atashi* (あたし) — feminine casual
  - *uchi* (うち) — feminine Kansai
- **Second person**:
  - *anata* (あなた) — polite but distant (spouses use)
  - *kimi* (君) — superior→inferior, male peer
  - *omae* (お前) — masculine rough/intimate
  - *kisama* (貴様) — hostile
  - *name-san* — **preferred** (use name + honorific)
- **Third person**: *kare/kanojo* exist but sound translated; *ano hito* (that person) preferred
- **Plural**: *-tachi* (neutral), *-ra* (casual/masculine), *-gata* (honorific)
- **Zero pronoun**: Standard — context determines referent
- **Sources**: `[[wiki/Japanese/index]]`, `[[wiki/Japanese/culture/japanese-dating-culture]]`

### Korean
- **Pronoun = register choice**: Like Japanese, no neutral forms
- **First person**:
  - *na* (나) — casual (해체)
  - *jeo* (저) — humble (해요체/합쇼체)
  - *uri* (우리) — "we" inclusive (default); *jeohui* (저희) — humble we
- **Second person**:
  - *neo* (너) — casual (close friends, children)
  - *dangsin* (당신) — **avoid** (argumentative or poetic/spousal)
  - *name-ssi/nim* — **preferred** (name + title)
  - *seonsaengnim* (선생님) — generic respectful address
- **Third person**: *geu/geunyeo* (그/그녀) — written/formal; *geu bun* (그분) — honorific
- **Zero pronoun**: Standard — subject/object routinely dropped
- **Reflexive**: *jagi* (자기) — self; *jagijasin* (자신) — oneself
- **Sources**: `[[wiki/Korean/index]]`, `[[wiki/Korean/culture/korean-dating-culture]]`

### Chinese
- **Pro-drop**: Subjects/objects freely omitted
- **Inclusive/Exclusive we**: 
  - *zánmen* (咱们) — inclusive (you + me + others)
  - *wǒmen* (我们) — exclusive (me + others, not you)
- **Politeness**: *nǐ* (你) vs *nín* (您) — 2nd sg respectful
- **Plural**: *-men* (们) suffix — *wǒmen, nǐmen, tāmen*
- **Gender in writing only**: 他/她/它 all *tā* spoken
- **Demonstratives as pronouns**: *zhè* (这), *nà* (那) — this/that person
- **Reflexive**: *zìjǐ* (自己) — self
- **Sources**: `[[wiki/Chinese/sources/greetings-zh]]`, `[[wiki/Chinese/vocabulary/family-zh]]`

## Demonstrative Pronouns

| Distance | English | Spanish | Japanese | Korean | Chinese |
|----------|---------|---------|----------|--------|---------|
| **Proximal (this)** | this | este/esta/esto | これ (kore) | 이거 / 이것 | 这 / 这个 |
| **Medial (that near you)** | that | ese/esa/eso | それ (sore) | 그거 / 그것 | 那 / 那个 |
| **Distal (that over there)** | that over there | aquel/aquella/aquello | あれ (are) | 저거 / 저것 | 那个 (far) |
| **Place (here/there)** | here/there | aquí/allí/allá | ここ/そこ/あそこ | 여기/거기/저기 | 这里/那里/那儿 |

### Usage Notes
- **Spanish**: Three-way distance (*este/ese/aquel*) — *aquel* = far from both speaker and listener
- **Japanese**: *kore/sore/are* = object; *koko/soko/asoko* = place; *kochira/sochira/achira* = direction/person (polite)
- **Korean**: *igeo/geugeo/jeogeo* (object) vs *yeogi/geogi/jeogi* (place); *ireon/geureon/jeoreon* (kind)
- **Chinese**: *zhè/zhège* vs *nà/nàge* — two-way spoken; *zhèr/nàr* (North) vs *zhèlǐ/nàlǐ* (South) for place

## Zero Pronoun / Pro-Drop Behavior

| Language | Subject Drop | Object Drop | Possessor Drop | Notes |
|----------|--------------|-------------|----------------|-------|
| **English** | ❌ | ❌ | ❌ | Mandatory subjects |
| **Spanish** | ✅ (standard) | ❌ (clitics required) | ❌ | *Hablo español* = "I speak Spanish" |
| **Japanese** | ✅ (standard) | ✅ (standard) | ✅ (standard) | Context-recovery mandatory |
| **Korean** | ✅ (standard) | ✅ (standard) | ✅ (standard) | Topic/comment structure aids recovery |
| **Chinese** | ✅ (standard) | ✅ (standard) | ✅ (standard) | Topic-prominent; null anaphora pervasive |

### Recovery Strategies
- **Spanish**: Verb morphology encodes person/number (*hablo/hablas/habla/hablamos/habláis/hablan*)
- **Japanese/Korean**: Topic marker (*wa/は* vs *ga/が* vs *eun/은* vs *i/이*) + honorifics + context
- **Chinese**: Topic-comment structure + aspect markers + lexical context

## Cross-Language Interference Map

| Learner L1 → Target L2 | Typical Error | Why |
|------------------------|---------------|-----|
| **EN → ES/JP/KR/CH** | Overt pronouns everywhere ("I think that he...") | L1 requires subjects; target allows zero |
| **ES → JP/KR** | Using *tú* equivalent (*anata/neo*) with strangers | *Tú* = peer default; *anata/neo* = intimate |
| **JP/KR → CH** | Overusing *nín* (您) like *anata/nan* | *Nín* = specific respect; Chinese uses titles more |
| **CH → ES** | Using *tú* universally (no *nín* equivalent) | Chinese *nǐ* default; Spanish requires *usted* choice |
| **EN → JP/KR** | Translating "you" → *anata/neo* | No neutral "you" in JP/KR |
