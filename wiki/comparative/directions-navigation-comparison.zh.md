## 各语言详情

### 🇬🇧 英语 (English)
- **核心**: "Turn left" / "Turn right" / "Go straight"; "North" / "South"
- **模式**: 介词: "on" (on the left); "to the" (to the left)
- **来源**: `[[directions-vocabulary]]`

### 🇪🇸 西班牙语 (Spanish)
- **核心**: "Norte/Sur/Este/Oeste" (常大写); "a la izquierda/derecha"
- **模式**: 性一致: "izquierdo" / "izquierda"; "Gire" (正式命令) vs "gira" (非正式)
- **来源**: N/A — 西班牙语暂缺方向专题

### 🇯🇵 日语 (Japanese)
- **核心**: 北東 (hokutō) / 北西 (hokusai) / 南東 (nantō) / 南西 (nansai); 交差点 (kōsaten = 十字路口)
- **模式**: 动词: 〜を曲がる (wo magaru); 助词: 〜に (方向); "左に" (hidari ni)
- **来源**: `[[directions-vocabulary]]`

### 🇰🇷 韩语 (Korean)
- **核心**: 방위 (bangwi = 方位); 동서남북 (dong-seo-nam-buk = 基本方向)
- **模式**: 动词: 〜을/를 돌다 (eul/reul dolida); 助词: 〜으로 (euro = 朝向)
- **来源**: `[[directions-vocabulary]]`

### 🇨🇳 中文 (Chinese)
- **核心**: 方向 (fāngxiàng), 东南西北 (dōng-nán-xī-běi); 十字路口 (shízì lùkǒu = 十字路口)
- **模式**: 动词: 〜转 (zhuǎn); 助词: 向 (xiàng = 朝向)
- **来源**: N/A — 中文暂缺方向专题

## 🇨🇳 中文学习者笔记 (Chinese Learner Notes)

> 本节是面向中文母语学习者的额外学习指南。

### 中文母语者在学习其他4种语言方向时的常见陷阱

1. **东亚方位顺序**:
   - 中文习惯 *东南西北* (东→南→西→北, 顺时针) → 学员假设其他东亚语言也如此。
   - **陷阱**: 日语读法 *東西南北 (higashi-nishi-minami-kita)* (东南西北 — 但日语用顺时针但字面有变化)。韩语 *동서남북 (东-西-南-北)* 顺序不同。
   - **训练法**: 各语言方位默写测试 (用中文谐音或助记)。

2. **方向助词**:
   - 中文用 *往 / 向 / 朝* → 学员混淆目标语言的助词。
   - **陷阱**: 韩语 *-(으)로 (giro)* 表 "朝向"; 日语 *に (ni)* 表方向; 英语 *to* 表方向。
   - **训练法**: 助词单独练习, 例如 "向左走" = "go to the left" = 日语 *左に歩く* = 韩语 *왼쪽으로 걷다* = 中文 *往左走*。

3. **地址格式差异**:
   - 中文地址 = 国家→省→市→区→街→号; 学员假设其他语言都按此层级。
   - **陷阱**: 英语地址 = 数字→街道→城市→州→邮编 (反向层级); 日语 = 都→市→区→町→号; 韩语 = 道→市→区→洞→番地。
   - **训练法**: 各国地址格式模板准备, 写自己地址用 5 语言练习。

4. **敬语命令式**:
   - 中文没有命令形式 vs 礼貌命令的区分 → 学员困惑于西语 *Gire/Gira*。
   - **陷阱**: 西班牙语正式 *Gire (您)* vs 非正式 *gira (你)*。日语命令形 *曲がれ* 常避免, 用 *曲がってください* (请转)。
   - **训练法**: 学习时优先礼貌形式, 避免命令语气。

5. **导航的"远/近"概念**:
   - 中文 *远/近* → 学员对韩语的 *멀리/가깝게* 感到混淆。
   - **陷阱**: 韩语 *멀다 (远, 形容)* vs *멀리 (远, 副词)*; 中文 *远/近* 形容词副词同形。
   - **训练法**: 形容词/副词形式对比 (尤其韩语有区别形态)。
