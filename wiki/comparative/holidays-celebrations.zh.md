## 文化描述

### 🇨🇳 中国新年 (春节)

**Chinese (CN)**: 春节 / 新年 (Chūnjié / Xīnnián) — "Spring Festival"
**When**: 农历 (1月/2月)
**Duration**: 7-15 天
**活动**:
- 团圆饭 (年夜饭)
- 红包 (红包 hóngbāo)
- 鞭炮 (鞭炮 biānpào)
- 春联 (春联 chūnlián)
- 舞龙舞狮

**食物**: 饺子 (饺子), 鱼 (鱼 — 余), 年糕 (年糕 — 一年比一年高), 橘子

### 🇰🇷 韩国新年 (설날)

**Korean (KR)**: 설날 (Seollal) — "New Year"
**When**: 农历 (1月/2月)
**Duration**: 3 天
**活动**:
- 세배 (Sebae) — 正式向长辈鞠躬
- 떡국 (Tteokguk) — 年糕汤 (强制!)
- 한복 (Hanbok) — 传统服装
- �놀이 (Yut nori) — 传统游戏
- 차례 (Jarye) — 祖先祭祀

**食物**: 떡국 (年糕汤), 전 (煎饼), 약과 (药果), 한과 (韩果)

### 🇯🇵 日本新年 (正月)

**Japanese (JP)**: お正月 (Oshōgatsu) / 正月 (Shōgatsu)
**When**: 1月1-3日
**Duration**: 3-7 天
**活动**:
- 初詣 (Hatsumode) — 首次神社参拜
- おせち料理 (Osechi ryori) — 传统料理
- お年玉 (Otoshidama) — 给孩子的红包
- 初売り (Hatsu-nyu) — 年初首卖

**食物**: おせち, 年越しそば (跨年荞麦面), お雑煮 (杂煮)

### 🇪🇸 西班牙/拉丁新年

**Spanish (ES)**: Año Nuevo / Nochevieja
**When**: 12月31日 - 1月1日
**Duration**: 1 天庆祝
**活动**:
- 12 颗葡萄 (12 uvas) — 钟声每响一颗
- 西班牙 Nochevieja (吃 12 颗葡萄)
- 拉美 Año Nuevo (家庭聚会)

**食物**: 12 颗葡萄, 各地区传统菜

### 🇬🇧 英语/西方新年

**English (EN)**: New Year's Day / New Year's Eve
**When**: 1月1日 / 12月31日
**活动**:
- 倒计时 (10...9...8...)
- Auld Lang Syne (苏格兰起源)
- First-footing (英国传统)
- 时报广场球落 (Times Square, 美)
- 烟花

## 🇨🇳 中文学习者笔记 (Chinese Learner Notes)

> 本节是面向中文母语学习者的额外学习指南。

### 中文母语者在学习其他4种语言节日文化时的常见陷阱

1. **"新年" 的双重含义**:
   - 中文 *新年* = 春节 (农历) 或 元旦 (公历) → 学员对其他文化新年感到困惑。
   - **陷阱**: 西方 "New Year" = 公历 1月1日; 中国/韩国 "설날/春节" = 农历 1月1日; 日本 *正月* = 1月1日 (公历)。
   - **训练法**: 整理 5 国新年 (CN 春节 / KR 설날 / JP 正月 / ES Año Nuevo / EN New Year)。

2. **"春节" 的汉字假朋友**:
   - 中文 *春节* → 学员对日语 *春節 (しゅんせつ)* / 韩语 *춘절 (chunjeol)* 感到陌生。
   - **陷阱**: 日韩 春节 与中国 春节 含义不完全同; 日韩春节淡化, 仪式性弱。
   - **训练法**: 整理 5 国春节文化对比 (CN 最隆重 / KR 次 / JP 较淡 / 西/EN 1月1日)。

3. **"中秋节" 的跨文化差异**:
   - 中文 *中秋节* → 学员对韩 *추석* / 日 *中秋の名月* / 西 *Mid-Autumn Festival* 感到相似。
   - **陷阱**: 中/韩 *中秋/추석* = 农历 8月15日; 日本 *中秋* 较少庆祝; 西 *中秋* 主要为华人社区。
   - **训练法**: 整理 5 国中秋 (CN 隆重 / KR 隆重 / JP 较淡 / 西 仅华人 / EN 仅华人)。

4. **"佛诞" 的日期差异**:
   - 中文 *浴佛节* → 学员对日 *花祭り* / 韩 *석가탄신일* 感到相似但日期不同。
   - **陷阱**: 中/韩/日 佛诞 = 农历 4月8日 (韩/日) 或 4月初8 (中); 部分国家 5月。
   - **训练法**: 整理 5 国佛诞日期与庆祝方式。

5. **"红包" 的跨文化**:
   - 中文 *红包 (hóngbāo)* → 学员对日 *お年玉 (otoshidama)* / 韩 *세�돈 (sebaetdon)* 感到相似但形式不同。
   - **陷阱**: 日韩 *お年玉/세뱃돈* 仅给小孩; 中国 *红包* 给所有长辈/小孩。
   - **训练法**: 整理 5 国红包文化 (CN 给所有亲属 / JP/KR 仅小孩 / 西/英 无)。

6. **"情人节" 的文化专属**:
   - 中文 *情人节* (双向) → 学员对日 *情人节* (女→男 巧克力) / 韩 *情人节* (类似) 感到困惑。
   - **陷阱**: 日韩 *情人节* 是女→男单向; *白色节* (3月14日) 男→女回报; 西/英双向。
   - **训练法**: 整理 5 国情人节流程 (CN 双向 / JP 女→男 / KR 女→男 / 西/EN 双向)。

7. **"圣诞节" 的非宗教化**:
   - 中文 *圣诞节* = 商业 + 情侣 → 学员对日韩 *圣诞节* 类似感到熟悉。
   - **陷阱**: 日韩 *圣诞节* 与西方相似 (情侣 + 商业); 中国圣诞节商业化更甚, 宗教较弱。
   - **训练法**: 整理 5 国圣诞节文化 (CN 商业化 / JP 商业化 / KR 商业化 / ES 宗教 + 商业 / EN 宗教 + 商业)。
