## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 문학을 접할 때 흔히 마주치는 함정

1. **한자 어원 공유의 과신**:
   - 한국어 한자어(小説, 文學, 作家)와 일본어 한자(小説, 文学, 作家), 중국어 한자(小说, 文学, 作者)는 시각적으로 같아 보이지만 **발음과 의미 미묘차가 큼**.
   - **함정**: 한자어 어휘 같다고 의미 동일 가정 → "小説"가 한국어로는 "소설"이지만 일본어로는 "しょうせつ(쇼우세쓰)"로 발음, 중국어로는 "xiǎoshuō(샤오슈어)"로 발음.
   - **훈련법**: 한자 문자 동일 ≠ 의미/발음 동일 — 항상 표음(발음) 확인. **한국어 한자음 ≠ 일본/중국 한자 발음**.

2. **순수 한국어 vs 한자어 구분 미숙**:
   - 한국어는 한자어 외에 순우리말 어휘가 풍부: "글(글씨)", "책", "지은이", "독자", "읽다" 모두 고유어.
   - **함정**: 일본어/중국어 학습 시 모든 어휘를 한자로 매핑하려 함 → 일본어 作家(sakka) ↔ 한국어 "작가"는 OK이지만, 友達(tomodachi, 친구) ↔ 한국어 "벗/친구"처럼 한자 없는 어휘는 한자 매핑 불가.
   - **훈련법**: 고유어/한자어 구분 — 순우리말(글, 책, 벗, 노래)은 한자 매핑 안 됨.

3. **장르 문화 번역의 차이**:
   - "武侠 (wuxia)" / "무협" / "武侠" → 모두 같은 한자지만 한국에서는 "무협 소설"로, 중국에서는 "武侠小说"로 발음.
   - **함정**: "武侠"가 한국어/중국어/일본어 모두에 존재하지만 실제 장르 풍경은 다름 — 중국 무협은 "의협(義俠)" 중심, 한국 무협은 "무림(武林)" 중심, 일본 무협(武侠小説)은 시장 작위 중심.
   - **훈련법**: 같은 한자 장르라도 문화적 강조점이 다름 — 실제 작품 비교 학습.

4. **"소설" 어원 오해**:
   - "소설"은 한국어 순수 단어 같지만 사실 한자 小説의 한국어 음차(國漢混用語). 순한국어로는 "이야기책"이 더 정확.
   - **함정**: "소설"을 순우리말로 착각 → 영어 "novel"의 어원(Italian "novella" = new)과 혼동.
   - **훈련법**: 한자어의 한국어 음차와 순우리말 구분 — "글(글씨)", "책", "이야기(說話, 이야기)", "지은이" 등.

5. **저자 이름 표기 관행 차이**:
   - 한국: 성명 (예: 한강)
   - 일본: 성+명 (例: 村上 春樹)
   - 중국: 성+명 (例: 鲁迅)
   - 서양: 이름+성 (예: Shakespeare, William)
   - 스페인: 이름+성 두 성 (예: García Márquez)
   - **함정**: 한국어/일본어/중국어 저자 이름을 서양식으로 first-last 뒤집어 인용 → 인명 색인 오류.
   - **훈련법**: **동아시아 인명 = 성(姓) + 이름(名) 순서 유지** — 무조건 성 먼저.

### 학습 전략

1. **우선순위 1**: 한자 한자어의 동아시아 3개국 공유 — 作家/작가/作者, 文學/문학/文学, 小説/소설/小说 같은 어휘의 한자 동일성 인지하되 발음과 의미 미세 차이를 별도 학습.
2. **우선순위 2**: 고유어 vs 한자어 구분 — 한국어 "책(冊)", "글", "벗", "노래"는 일본어/중국어에 직접 매핑 안 됨. 일본어 友達(ともだち, 친구), 中国語 朋友(péngyǒu, 친구)와 별도 학습.
3. **우선순위 3**: 장르 어휘의 문화별 변이 — 무협/武侠은 한자 같지만 중국(의협), 한국(무림), 일본(무술 액션)으로 분화. 같은 한자 장르라도 문화적 강조점 비교 학습.
4. **우선순위 4**: 동아시아 인명 표기 순서 — 성(姓) → 이름(名) 순서 유지. 영문 번역 시 family name first, given name last.
5. **우선순위 5**: 동아시아 고전 (한문) — 한국/일본/중국이 공유하는 한문(漢文) 전통 학습. 시조, 와카(和歌), 唐詩(당시)가 모두 한문 기반.
