## 各言語詳細

### 🇬🇧 英語 (English)
- **主要用語**: "Trail" (marked path), "Summit" (reached peak), "Base camp" (start point)
- **パターン**: "Go hiking" / "Go camping" — 動詞 + gerund 構文が一般的
- **出典**: `[[adventure-vocabulary]]`, `[[travel-essentials]]`

### 🇪🇸 スペイン語 (Spanish)
- **主要用語**: "Senderismo" (Spain), "Andinismo" (Andes region); "Refugio" = 山小屋
- **パターン**: -ismo 名詞; "hacer senderismo" = ハイキングに行く
- **出典**: Spanish には adventure テーマ未投入

### 🇯🇵 日本語 (Japanese)
- **主要用語**: 登山 (tozan = 登山), 縦走 (jūsō = 尾根伝い縦走), 山小屋 (yamagoya = 山小屋)
- **パターン**: 動詞: 〜をする; 敬語: 気をつけて (ki wo tsukete = 気をつけて)
- **出典**: `[[adventure-vocabulary]]`

### 🇰🇷 韓国語 (Korean)
- **主要用語**: 등산 (deungsan), 등산로 (deungsanno), 등산객 (deungsangaek = 登山者)
- **パターン**: 動詞: 〜을/를 가다 (go do); 산 (san) が多くの複合語に出現
- **出典**: `[[adventure-vocabulary]]` (現在 EN/JP のみ — KR 計画中)

### 🇨🇳 中国語 (Chinese)
- **主要用語**: 登山 (dēngshān), 徒步 (túbù), 户外 (hùwài = アウトドア)
- **パターン**: 動詞: 〜去 (qù = 行く); 量詞: 座山 (zuò shān = 山の量詞)
- **出典**: 中国語には adventure テーマ未投入

## 主要な対比 (総合)

| 対比 | 学習者への示唆 |
|------|----------------|
| **山岳文化** | KR は最も強い現代ハイキング文化; JP は富士山巡礼 tradition; CN は仏教の山岳遺産 |
| **用語** | 全言語が "trekking", "hiking", "camping" を借用 — 基本アウトドア語彙は国際共通 |
| **動詞パターン** | EN: 動詞+ing; ES: hacer+n名詞; JP/KR/ZH: 名詞+助動詞 |
| **緊急用語** | 助けて/도와주세요/救命 (助けて) — 全5言語共通パターン |

## 学習者決定ガイド

> **アウトドア安全フレーズ**:
> - "助けて" (tasukete) / "도와주세요" (dowa juseyo) / "救命" (jiùmìng) = HELP
> - "山に登る" (yama ni noboru) / "산을 타다" (saneul tada) = 登山
> - 地図 (chizu) / 지도 (jido) / 地图 (dìtú) = 地図 (全5言語で使用)

## 🇯🇵 日本語学習者ノート (Japanese Learner Notes)

> 本セクションは日本語学習者向けの追加学習ガイドです。

### 日本語話者が他の4言語のアウトドア用語を学ぶ際の一般的な落とし穴

1. **外来語と和製英語の混同**:
   - 日本語は "ハイキング (haikingu)", "キャンプ (kyanpu)", "トレッキング (torekkingu)" を使用 → 英語話者はネイティブと同じと想定しがちだが、日本語の発音は微妙に異なる。
   - **落とし穴**: 英語で "ハイキング" のように発音してしまう; 英語ネイティブには通じない。
   - **練習法**: 英語では "hiking", "camping", "trekking" の正しい発音をマスター。

2. **動詞パターンの転移失敗**:
   - 日本語 "〜をする" (suru) → 英語では "to hike" (do+名詞ではなく動詞); スペイン語では "hacer + 名詞"。
   - **落とし穴**: 日本語話者が "hacer hiking" と言ってしまう (英語ネイティブは "go hiking")。
   - **練習法**: "go + V-ing" パターン (go hiking, go camping) を定型化。

3. **敬語使用の過剰一般化**:
   - 日本語は山岳ガイドにも敬語を使う → 英語圈/や・西語圈では不要。
   - **練習法**: 英語圏のアウトドア会話では casual な命令形 ("Watch out!") が一般的。

4. **山のサイズ感の差**:
   - 日本語の "山" は低山 (200m) も含めるが、英語の "mountain" は通常 1000m 以上。
   - **落とし穴**: 英語ネイティブに低山を "mountain" と紹介すると誇張と受け取られる。
   - **練習法**: 英語では "hill" (低山), "mountain" (高山), "peak" (頂上) を適切に使い分け。

5. **緊急時の呼びかけ**:
   - 日本語 "助けて" → 英語 "Help!"; スペイン語 "¡Ayuda!"; 韓国語 "도와주세요"; 中国語 "救命!"。
   - **練習法**: 緊急時の5言語フレーズを反射的に言えるよう訓練 (現地の山岳救助で必須)。
