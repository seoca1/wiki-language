## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 명절을 배울 때 흔히 마주치는 함정

1. **"설날(Seollal) vs 春节(Chūnjié)" 의 동아시아 음력 신년**:
   - 한국어 설설 + 중국어 春节 + 베트남 Tết + 일본어 (旧正月, 이제 거의 사용 안함) — 모두 음력 1월 1일 동아시아 신년. 그러나 한국은 양력 1월 1일 "새해" 와 구분.
   - **함정**: 한국어 학습자가 영어 "Lunar New Year" 를 단순 매핑 → 설설 (KR) 과 春节 (CN) 의 차이 (음식, 의례, 가족 구조).
   - **훈련법**: 음력 명절 매핑 — KR 설설 / JP 旧正月 / CH 春节 / VT Tết — 동아시아 음력 명절의 공통점 (차례/제사) 과 차이 학습.

2. **"추석(Chuseok) / 中秋节(Zhōngqiūjié)" 의 추수/중추 명절**:
   - 한국어 추석 + 중국어 中秋节 + 일본어 (旧)中秋 + 베트남 Tết Trung Thu — 음력 8월 15일 추수/중추 명절. 한국 송편 vs 중국 월병 vs 베트남 반각 등 음식 차이.
   - **함정**: 한국어 학습자가 영어 "Mid-Autumn Festival" 단순 매핑 → 한국 추석 은 송편/차례 강조, 중국 中秋节 은 달/구름 명절 강조.
   - **훈련법**: 추석/中秋 매핑 — KR 송편/차례 / CH 月饼/团圆. 문화적 강조점 차이 학습.

3. **"설설 vs 섣달그믐" 의 한국 시간 구분**:
   - 한국어 "설설" = 음력 1월 1일 (New Year's Day), "섣달그믐" = 음력 12월 마지막 날 (New Year's Eve). 영어 "New Year's Day" vs "New Year's Eve" 와 동일 구분.
   - **함정**: 한국어 학습자가 영어 New Year 와 단순 매핑 → 한국은 양력+음력 2개 신년 시스템.
   - **훈련법**: 양력 vs 음력 신년 매핑 — KR 양력 신년 (1/1) / KR 음력 설설 (음력 1/1) / CH 春节 (음력 1/1) / JP お正月 (양력 1/1, 과거 음력). 시스템 차이 학습.

4. **"밑줄/위계" 의 한국 명절 강조점**:
   - 한국 명절은 "차례/제사" (조상 의례) 강조 — 일본 お盆 (Obon) 과 중국 祭祖 (jìzǔ) 와 유사. 영어/스페인어 명절은 종교/상업 강조.
   - **함정**: 한국어 학습자가 영어 "holiday" 를 단순 매핑 → 한국 명절의 가족/조상/계열 강조 무시.
   - **훈련법**: 명절의 문화적 의미 매핑 — KR 차례/제사 (조상) / JP お盆 (영혼 귀환) / CH 祭祖 (조상 숭배) / EN Thanksgiving (역사/가족) / ES Día de los Muertos (죽은 자와의 재회).

5. **금기 선물 의 문화별 차이**:
   - 한국어: 녹색 모자 (남자에게), 신발, 시계 회피. 일본어: 분재, 날카로운 물건 회피. 중국어: 시계 (送终), 녹색 모자, 우산, 배 회피. 영어: 큰 제한 없음. 스페인어: 13, 보라 (장례) 회피.
   - **함정**: 한국어 학습자가 영어 명절 선물에서 큰 제한 없이 → 한국에서는 회피해야 할 선물.
   - **훈련법**: 금기 선물 5언어 매트릭스 — KR 녹색 모자/신발/시계 / JP 분재/날카로운 물건 / CH 시계/녹색 모자/우산/배 / EN 큰 제한 없음 / ES 13/보라.

### 학습 전략

1. **우선순위 1**: 한국 주요 명절 10개 (설설/추석/석가탄신일/어버이날/어린이날/성탄절/광복절/한글날/개천절/현충일) 마스터.
2. **우선순위 2**: 동아시아 음력 명절 매핑 — 설설/春节/旧正月/Tết 의 공통점 + 차이.
3. **우선순위 3**: 양력 vs 음력 시스템 매핑 — 한국은 양력 (1/1) + 음력 (설설) 병행.
4. **우선순위 4**: 명절 인사 5언어 (새해 복 많이/あけましておめでとう/Feliz Año Nuevo/新年好) 의 정중함 차이.
5. **우선순위 5**: 금기 선물 5언어 매트릭스 학습.
