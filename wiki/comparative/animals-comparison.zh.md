## 各语言详情

### 🇬🇧 英语 (English)
- **核心**: "Pet" vs "Domestic animal"; "Livestock" (家畜); "Wildlife"
- **模式**: 动物+声音动词 ("the dog barks", "the cat meows")
- **来源**: `[[animals-vocabulary]]`

### 🇪🇸 西班牙语 (Spanish)
- **核心**: "Mascota" (宠物), "Animal doméstico" (家养), "Fauna" (野生动物)
- **模式**: 性一致: gato/gata, perro/perra; -ar 动词变位
- **来源**: `[[animals-vocabulary]]`

### 🇯🇵 日语 (Japanese)
- **核心**: 動物 (dōbutsu = 动物); ペット (petto = 宠物); 野生動物 (yasei dōbutsu = 野生动物)
- **模式**: 动词: 〜が鳴く (ga naku = 动物叫); 名词+の: 猫の鳴き声
- **来源**: `[[animals-vocabulary]]`

### 🇰🇷 韩语 (Korean)
- **核心**: 동물 (dongmur), 반려동물 (baeryu-dongmur = 伴侣动物); 가축 (gachuk = 家畜)
- **模式**: 动词: 〜이/가 울다 (cry); 名词合成: 강아지 (狗 + 幼犬)
- **来源**: `[[animals-vocabulary]]`

### 🇨🇳 中文 (Chinese)
- **核心**: 动物 (dòngwù), 宠物 (chǒngwù), 家畜 (jiāchù = 家畜)
- **模式**: 动词: 〜叫 (jiào = 叫); 名词+名词: 老虎 (lǎohǔ)
- **来源**: N/A — 中文暂无动物专题

## 关键对比 (综合)

| 对比 | 洞察 |
|------|------|
| **汉字/한자 共享词汇** | JP/KR/ZH 共享 ~60% 动物词汇 (犬/개/狗, 馬/말/马, 魚/물고기/鱼) |
| **本土词 vs 汉字** | 韩语常 顺우리말 + 汉字词 (소 vs 牛); 日语类似 (うま vs 馬) |
| **宠物文化** | 所有文化宠物拥有率增加; 流行物种各异 |
| **神话动物** | 东亚文化 (JP/KR/ZH) 共享 龍/용/龙 神话; 西方文化神话不同 |

## 🇨🇳 中文学习者笔记 (Chinese Learner Notes)

> 本节是面向中文母语学习者的额外学习指南。

### 中文母语者在学习其他4种语言动物名时的常见陷阱

1. **汉字/한자 假朋友**:
   - 看到汉字 *马* 学员认为是同词 → 但日语 *馬 (uma)*, 韩语 *말 (mal)* 读音完全陌生。
   - **陷阱**: 字形相近但读音毫无关联, 学习汉字文化圈语言反而忽视发音。
   - **训练法**: 对每汉字动物, 立即记忆 5 语言发音 (犬=いぬ/개/inu/gae).

2. **韩语的"合成词"**:
   - 中文 *猫/狗* 单字 → 学员假设韩语也单字。
   - **陷阱**: 韩语 *고양이 (goyangi)* 多音节; *강아지 (小狗/幼犬)* 与 *개 (狗)* 区别。
   - **训练法**: 背诵 *개 + 아지 = 幼犬* 等合成模式。

3. **性一致 (西班牙语)**:
   - 中文无性 → 学员对 *gato/gata*, *perro/perra* 困惑。
   - **陷阱**: 在西班牙语所有动物名词都需阳性/阴性形式。
   - **训练法**: 每学一动物名, 立即记忆阴阳性。

4. **日语"汉字读音"的两种**:
   - 中文 *龙* → 日语有 *りゅう (音读, on'yomi)* vs *たつ (训读, kun'yomi)*。
   - **陷阱**: 日语 *龍/竜* 读音不固定。
   - **训练法**: 学习日语时每个汉字记忆至少 2 读音。

5. **拟声词的文化差异**:
   - 中文 *汪/喵* 表达猫狗叫声 → 韩语 *멍멍 (meong-meong)*, 日语 *ワン (wan)* 完全不同。
   - **陷阱**: 学员假设拟声词 "通用"。
   - **训练法**: 拟声词单独列表, 不可推导。
