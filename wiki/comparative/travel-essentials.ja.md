## 🇯🇵 日本語学習者ノート (Japanese Learner Notes)

> 本セクションは日本語学習者向けの追加学習ガイドです。

### 日本語話者が他4言語の旅行フレーズを学ぶ際の一般的な落とし穴

1. **「いくらですか」 vs 国別表現**:
   - 日本語の「いくらですか」 → 英語 "How much?" → 韓国語 "얼마예요?" → 中国語 "多少钱?" → スペイン語 "¿Cuánto cuesta?"。
   - **落とし穴**: 日本語話者が中国「多少钱?」(duōshǎo qián?) を「どれだけの金」と直訳 → ネイティブは「金額」を期待。
   - **練習法**: 5言語の「いくら/価格」表現 (どれだけの金) を 5言語対応表で。

2. **チップ不要文化の例外**:
   - 日本語はチップ不要 (失礼) → 英語圏 (米国) は 15-20% チップ必須 → スペイン 5-10%。
   - **落とし穴**: 米国レストランで「カードで」とだけ言ってテーブルを去る → チップ未払いで困惑。
   - **練習法**: 英語圏では 15-20% チップ、スペインでは 5-10% チップをデフォルトに。

3. **「助けて」 vs 各国語表現**:
   - 日本語の「助けて！」 → 英語 "Help!" → 韓国語 "도와주세요!" → 中国語 "救命！" (jiùmìng) / "帮帮我！" → スペイン語 "¡Ayuda!" / "¡Socorro!"。
   - **落とし穴**: 日本語話者が中国語「救命」を「命を救う」と直訳 → ネイティブは「助けて！」の緊急感。
   - **練習法**: 5言語の「help」緊急表現 (助けて / Help / 도와주세요 / 救命 / ¡Ayuda!) を 5言語対応表で。

4. **「食べる」語彙の文化差**:
   - 日本語の「ベジタリアンです」 → 英語 "I'm vegetarian" → 韓国語 "채식주의자예요" → 中国語 "我吃素" → スペイン語 "Soy vegetariano"。
   - **落とし穴**: 中国語「我吃素」(wǒ chī sù) は文字通り「私は菜を食べる」 → ネイティブは「ベジタリアン」理解。
   - **練習法**: 5言語の「ベジタリアン」表現 (ベジタリアン / vegetarian / 채식주의자 / 吃素 / vegetariano) を 5言語対応表で。

5. **「お会計」 vs 国別表現**:
   - 日本語の「お会計お願いします」 → 英語 "Check, please" → 韓国語 "계산서 주세요" → 中国語 "买单" → スペイン語 "La cuenta, por favor"。
   - **落とし穴**: 日本語話者が中国「买单」を「注文」と翻訳 → ネイティブは「会計」理解。
   - **練習法**: 5言語の「会計」表現 (お会計 / check / 계산서 / 买单 / la cuenta) を 5言語対応表で。
