## 🇨🇳 中文学习者笔记 (Chinese Learner Notes)

> 本节是面向中文母语学习者的额外学习指南。

### 中文母语者在学习其他4种语言非语言沟通时的常见陷阱

1. **"召唤" 的方向 (掌向上 vs 向下)**:
   - 中文 *过来 (掌向下)* → 学员对英语掌向上感到困惑。
   - **陷阱**: 英语掌向上弯曲; 中文掌向下摆动。混用可能冒犯。
   - **训练法**: 学习各国召唤手势 (CN 掌向下 / EN 掌向上 / ES 掌向上 / JP 掌向下 / KR 掌向下)。

2. **"OK 手势" 的多义性**:
   - 中文 � = OK → 学员对日语 👌 = 钱感到困惑。
   - **陷阱**: 日语 👌 = 钱 (円); 韩语 👌 = OK / 钱; 西 👌 = OK; BR 👌 = 冒犯。
   - **训练法**: 整理各国 👌 含义 (CN OK / EN OK / ES OK / JP 钱 / KR OK/钱 / BR 冒犯)。

3. **"竖大拇指" 的全球争议**:
   - 中文 👍 = 好 → 学员对部分中东冒犯感到困惑。
   - **陷阱**: 中东/部分欧洲 👍 = 冒犯; 但全球总体正向。
   - **训练法**: 整理 👍 全球含义 (CN 好 / EN 好 / ES 好 / JP 好 / KR 好 / ME 部分冒犯)。

4. **"V 手势" 掌向方向**:
   - 中文 ✌️ = 和平 → 学员对英澳 *掌心向内* 感到困惑。
   - **陷阱**: 英澳 ✌️ *掌心向内* = 侮辱; 中国/美 �️ *掌心向外* = 和平/胜利。
   - **训练法**: 学习 �️ *掌心方向* 含义 (向外 = 和平; 向内 = 部分地区侮辱)。

5. **"眼神接触" 的文化差异**:
   - 中文 *避免上级* → 学员对西方 *直视* 感到困惑。
   - **陷阱**: 日韩中避免长辈眼神; 西方直视 = 诚实。
   - **训练法**: 整理各国眼神文化 (CN 避免 / JP 避免 / KR 避免 / EN 直视 / ES 直视)。

6. **"鞠躬" 的角度**:
   - 中文 *点头* 轻 → 学员对日韩 30°/45°/90° 鞠躬感到夸张。
   - **陷阱**: 日韩鞠躬分层级; 中国商务仅轻微点头。
   - **训练法**: 学习日韩鞠躬角度 (15° 随意 / 30° 商务 / 45° 正式 / 90° 세배)。

7. **"露鞋底" 的禁忌**:
   - 中文 *不露鞋底* → 学员对西方不在意感到困惑。
   - **陷阱**: 中日韩泰 *露鞋底* 极失礼 (脚=脏); 西方不在意。
   - **训练法**: 学习东亚鞋底禁忌 (不露/不指人/不踩家具)。

8. **"数字手势" 的差异**:
   - 中文 1 = 食指 → 学员对日语 *1 = 食指 (折拇指)* 感到熟悉但差异。
   - **陷阱**: 中日韩"数字手势"系统不同; 在市场讨价时易混乱。
   - **训练法**: 学习 5 语言"1-10 数字手势"对照 (CN/EN 食指; JP/KR 折拇指)。
