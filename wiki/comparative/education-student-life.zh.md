### 各国著名考试词汇

**English (SAT/ACT)**:
- "Standardized test"
- "Percentile"

**Spanish (EBAU/Selectividad)**:
- "Selectividad"
- "Nota de corte" (分数线)
- "Carrera" (学位)

**Japanese (センター試験 / 大学入試)**:
- "受験 (juken)" = 考试
- "塾 (juku)" = 补习班
- "浪人 (rōnin)" = 复读生
- "東大 (Tōdai)" = 东京大学 (目标)
- "学歴 (gakureki)" = 学历

**Korean (수능)**:
- "수능 (su-neung)" = 大学修学能力考试
- "학원 (hakwon)" = 私塾
- "입시 (ipsi)" = 大学入学
- "SKY" = 首尔大, 高丽大, 延世大 (三巨头)
- "인서울 (In-Seoul)" = 首尔顶级大学

**Chinese (高考)**:
- "高考 (Gāokǎo)" = 高考
- "985/211" = 顶级大学项目
- "分数线 (Fēn shù xiàn)" = 分数线
- "状元 (Zhuàngyuán)" = 省级第 1 名
- "高考工厂 (Gāokǎo gōngchǎng)" = 考试工厂

### 韩国 Hakwon (학원) 现象

- 韩国拥有世界最高的私塾率
- 70%+ 学生上 Hakwon (补习班)
- 父母每孩每年花费 ~$2,000-10,000
- **"과외 (Gwaoe)"** = 家教
- **"입시 지옥 (Ipsi Jiog)"** = 入学考试地狱
- **深夜学校 (심야 학교)** — 学习到凌晨 2 点

### 中国 高考 (Gaokao) 压力

- 6月7-8 一天考试 (或传说 6/7)
- 每年 9+ 百万学生
- **985/211 工程** = 顶级大学项目
- **省份 (Province)** = 区域分数差异大
- **高考状元 (Provincial #1)** = 名声, 奖学金, 大学 offer
- **考试周禁用手机**

### 日本 受験 (Juken) 文化

- **塾 (Juku)** = 补习班
- **浪人 (Rōnin)** = 失败考生 (gap year)
- **東大 (Tōdai)** = 东京大学 (许多人的目标)
- **多浪 (Taran)** = 多年复读 (负面含义)
- **受験戦争 (Juken sensō)** = "考试战争" — 激烈竞争

> 本节是面向中文母语学习者的额外学习指南。

### 中文母语者在学习其他4种语言教育文化时的常见陷阱

1. **"高考" (gaokao) vs "センター試験" vs "수능" 的文化差异**:
   - 中文 *高考* 已知 → 学员对日韩 *センター試験/수능* 感到相似但有差异。
   - **陷阱**: 3 国都有"一考定终身"概念, 但考试内容/时间/影响不同。中国高考 6月, 韩 *수능* 11月, 日 *センター試験* 1月。
   - **训练法**: 整理 3 国高考对比表; 词汇对照 (CN 高考 / JP センター / KR 수능 / EN SAT / ES Selectividad)。

2. **"补习班" (= 塾 / 학원 / 补习班) 的文化差异**:
   - 中文 *补习班* 普遍 → 学员对日韩 *塾/학원* 感到熟悉但规模差异大。
   - **陷阱**: 韩 Hakwon 是全球最大私塾产业 (~70% 学生); 日 *塾* 历史悠久; 中 *补习班* 当代争议。
   - **训练法**: 整理 5 国补习文化对比 (KR 70% / JP 60% / CN 60% / ES 30% / US 20%)。

3. **"应试教育" vs "素质教育" 的概念**:
   - 中文 *应试教育* 已知 → 学员对日韩 *受験教育* 概念感到相似。
   - **陷阱**: 三国都有应试传统, 但现代改革方向不同。
   - **训练法**: 学习三国教育哲学对比 (CN 应试 vs 素质 / JP 受験 vs ゆとり / KR 입시 vs 교육).

4. **"老师" vs "先生" vs "선생님" 的语义差异**:
   - 中文 *老师* 通用 → 学员对日韩 *先生/선생님* 感到困惑。
   - **陷阱**: 日语 *先生 (sensei)* = 老师 + 医生 + 律师 + 政治家; 韩语 *선생님* 类似。
   - **训练法**: 整理 5 语言 "教师/医生/律师" 称谓对照 (5 语言交叉)。

5. **"985/211" 跨文化不通**:
   - 中文 *985/211* 概念 → 学员对日韩 *旧帝大/SKY* 感到陌生。
   - **陷阱**: 各文化顶尖大学体系不同; 不要直接翻译。
   - **训练法**: 整理 5 语言顶尖大学体系 (CN 清北复交 / JP 旧帝大 / KR SKY / ES UCM / US Ivy)。

6. **课堂发言的文化差异**:
   - 中文 *课上发言* 不强 → 学员对英语 *Speak up* 感到困惑。
   - **陷阱**: 英美课堂强发言; 东亚课堂 (尤其日韩) 推沉默。
   - **训练法**: 跨文化课堂实践; 学习如何在不同文化课堂发言。
