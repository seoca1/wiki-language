## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 음식·식사를 배울 때 흔히 마주치는 함정

1. **"잘 먹겠습니다(Jal meokkesseumnida)" 의 한국 의례화**:
   - 한국어 "잘 먹겠습니다" = 식사 시작 인사 (식사해주시는 분에게 감사) — 일본어 "いただきます" 와 매우 유사하나 한국은 더 강조. 영어 "Bon appétit" / 스페인어 "Buen provecho" / 중국어 "慢慢吃" 와 다른 의미.
   - **함정**: 한국어 학습자가 영어 "Bon appétit" 을 "잘 먹겠습니다" 로 단순 번역 → Bon appétit = "즐기세요" 의 인사, 잘 먹겠습니다 = 감사 인사. 의미 다름.
   - **훈련법**: 식사 인사 어휘 학습 — KR 잘 먹겠습니다/잘 먹었습니다 / JP いただきます/ごちそうさまでした / EN Enjoy / ES Buen provecho / CH 慢慢吃. 인사 의 차이 인지.

2. **"빼주세요(Ppaejuseyo)" 의 한국 정중함**:
   - 한국어 "빼주세요" = 빼다 (제거) + 주세요 (정중 요청) — 식이 제한 표현. 일본語 抜き (nuki) + ください 와 유사. 중국어 不要 (bú yào) / 스페인어 Sin / 영어 Without 와 다름.
   - **함정**: 한국어 학습자가 영어에서 돼지고기 빼주세요 → 한국에서는 자연스러우나 영어에서 "no pork" 더 직접.
   - **훈련법**: 식이 제한 표현 매핑 — KR 빼주세요 / JP 〜抜き / CH 不要 / ES Sin / EN Without. 정중함 비교.

3. **"한정식(Hanjeongsik)" / "코스(Course)" 의 한국 의례**:
   - 한국어 "한정식" = 정해진 코스의 여러 반찬 + 밥 + 국 — 일본 会席料理 (Kaiseki) 와 중국 套餐 (tào cān) 와 유사. 스페인어 menú degustación, 영어 tasting menu.
   - **함정**: 한국어 학습자가 일본 会席 (Kaiseki) 와 동일시 → 한국 한정식 의 반찬 구성/매너 다름.
   - **훈련법**: 코스 요리 어휘 매핑 — KR 한정식 / JP 会席 (Kaiseki) / CH 套餐 (Tào cān) / ES menú degustación / EN tasting menu. 문화적 차이 인지.

4. **"소고기" vs "쇠고기" 의 표기 변이**:
   - 한국어 "소고기" (소+고기) = 쇠고기 의 합성어 — 그러나 맞춤법은 "소고기" (한자 牛肉 의 한자어 자체가 아니라 순우리말+한자어 결합).
   - **함정**: 한국어 학습자가 일본어 牛肉 (gyūniku) 의 음독 그대로 "우육" 으로 매핑 → 한국에서는 "소고기" 사용.
   - **훈련법**: 한자 음식 어휘의 KR/JP 매칭 — 牛肉 (KR 소고기/JP ぎゅうにく/CH niúròu), 豚肉 (KR 돼지고기/JP ぶたにく/CH zhūròu), 鶏肉 (KR 닭고기/JP とりにく/CH jīròu). 한자 의 한국어 토착어 결합 차이 학습.

5. **"밥(Bap)" 의 한국 다의성**:
   - 한국어 "밥" = cooked rice / meal / livelihood — 매우 다의. 일본어 ご飯 (gohan) 와 유사하나 영어 rice 보다 광범위. 중국어 饭 (fàn) 도 비슷.
   - **함정**: 한국어 학습자가 영어 "rice" 만 알면 "밥 먹었어?" 가 "rice ate?" 로 오역 → 사실 "식사 했어?" 의미.
   - **훈련법**: 밥 어휘 학습 — 밥 (cooked rice) / 식사 (meal) / 먹다 (to eat) / 살다 (to live) — 다의성 인지. 일본어 ご飯 (식사=rice) 와 동일 패턴.

### 학습 전략

1. **우선순위 1**: 한국어 식당 흐름 7단계 (입장 → 메뉴 → 추천 → 주문 → 물 → 계산 → 결제) 마스터.
2. **우선순위 2**: 잘 먹겠습니다/잘 먹었습니다 의 한국 의례 + 5언어 매핑.
3. **우선순위 3**: 빼주세요 의 한국 정중함 + 식이 제한 표현 5언어 매핑.
4. **우선순위 4**: 한자 음식 어휘의 KR/JP 매칭 (소고기/牛肉, 돼지고기/豚肉, 닭고기/鶏肉).
5. **우선순위 5**: 밥 의 다의성 (cooked rice/meal/livelihood) 인지 + 5언어 비교.
