# 법 시스템 비교 — 다국어 비교 (한국어판)

> 원본: [[mood-systems]] (English) | 작성일: 2026-08-20 | ADR-0006
> **5개 언어의 법(법무) 시스템 비교 — 직설법 vs 가정법 vs 양태**

---

## 빠른 참조 표

### 언어별 법 시스템 비교

| 언어 | 직설법 (Indicative) | 가정법/양태 (Subjunctive/Modal) | 명령법 (Imperative) | 조건법 (Conditional) |
|---|---|---|---|---|
| Spanish | regular conjugations | subjuntivo (que-clauses) | imperative (tú/usted/vosotros) | condicional |
| English | regular | may/might/would/should | bare infinitive | would |
| Japanese | 常体 (jōtai) | 命令形 (meirei-kei) + たら/ば/と | 命令形 | ば-form |
| Korean | 평서문 | -도록/-다면 | 명령문 | -(으)면 |
| Chinese | 陈述句 | modal adverbs (会, 要) | bare verb | 会/要 + verb |

| 법 종류 | English | Spanish | Japanese | Korean | Chinese |
|-----------|---------|---------|----------|--------|---------|

| **가정법 (의심/소원)** | If I were | Si fuera | だったら (dattara) | -(이)라면 | 如果 (rúguǒ) |

## 핵심 대조 (종합)

| 대조 | 통찰 |
|----------|---------|
| **스페인 가정법** = 영어 양태 + 일본 조건법 + 한국 법 접미사 + 중국 양태 부사 |
| **5개 언어 모두 2인칭 명령법 구분**; 일부 (일본어, 한국어)는 더 많은 경어 단계 |
| **스페인어가 그룹 내 유일하게 진정한 형태론적 가정법 보유**; 나머지는 분석적 구조 사용 |
| **법과 정중함 중첩** — 한국어/일본어 경어법 (경어법/敬語)이 법 기능 일부 담당 |
| **중국어는 부사/어순 사용** — "법-빈약"하나 맥락적으로 풍부 |

### 일반 학습자 오류

| 오류 | 언어 | 이유 |
|-------|-----------|-----|
| 가정법 필요한 곳에 직설법 사용 | EN→ES | 영어 "if I were"가 스페인어 학습자에게 가정법 트리거 안 됨 |
| 가능법 과용 | JP→KR/KR→JP | 둘 다 가능법 보유하지만 사용 양상 다름 |
| 경어 단계 혼용 | All→KR/JP | CJK의 정중함 시스템이 EN/ES보다 엄격 |
| 잘못된 조건법 형태 | All | 각 언어는 2-4 조건법 형태 (실제/비실제/과거) |
| 양태 동사 혼동 | All | 많은 언어에 6+ 양태 동사 (can/could/may/might/will/would) |

## 학습자 의사결정 가이드

> **법 시스템 매트릭스 (5개 언어)**:
> - **소원/희망**: I wish I were / Ojalá fuera / だったらなあ / -(으)면 좋겠다 / 要...就好了
> - **가정 과거**: If I had... / Si hubiera... / だったら... / -(었)다면 / 如果...就
> - **가능성**: might/should / quizás/debería / かもしれない / -을 수도 있다 / 也许/应该
> **소문/풍문**: supposedly / se dice que / そうだ / -(다)고 하다 / 据说/听说
> - **가정**: if I were / si fuera / としたら / -(으)면 / 如果...的话

> **가장 큰 차이**: 스페인어는 진정한 형태론적 가정법 — 나머지 4개 언어는 분석적 구조 또는 양태 부사.

## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 법 시스템을 학습할 때 흔히 마주치는 함정

1. **스페인 가정법 (subjuntivo) 의 진정한 형태론**:
   - 스페인어는 -ra, -se 어미 등 진정한 형태론적 가정법 보유. "Quiero que vengas" (I want you to come) — 동사 어미가 가정법으로 변형.
   - **함정**: 한국어 학습자가 스페인어 가정법 = "가정법 어미"라는 형태론적 트리거를 모르고 영어 "I want you to come" 직역 → 직설법 "vienes" 사용 → 문법 오류.
   - **훈련법**: 스페인어 가정법 트리거 명시적 학습 — WEIRDO (Wishing, Emotion, Influence, Requests, Doubt, Ojalá) — "que" 종속절에서 자동 가정법. 한국어에는 없는 명시적 형태 트리거.

2. **한국어 경어법과 법의 중첩**:
   - 한국어/일본어는 **법과 정중함이 형태론적으로 결합**. 예: "가자" (우리 가자, 해체) vs "가요" (정중) vs "갑시다" (격식) — 같은 "가다" 동사가 법+경어 동시 표현.
   - 스페인어/중국어는 법과 정중함이 분리 (스페인: 직설법 가정법 + 별도 usted 정중; 중국: 부사 정중).
   - **함정**: 한국어 학습자가 스페인어 학습 시 "형태론적 가정법 + usted 정중"을 동시 처리 → 어색.
   - **훈련법**: 한국어 "동사 1개 = 법 + 경어" 단순 구조 vs 스페인어/중국어 "동사 1개 = 법, 별도 정중 단어" 분리 구조 — 다른 메커니즘 학습.

3. **한국어 조건법 (-(으)면) 의 다의성**:
   - 한국어 "-(으)면" = 조건 (if), 시간 (when), 양보 (even if) 모두 표현. 문맥 의존.
   - 스페인어/일본어: si/たら/ば 모두 조건 특화. 한국어만큼 다의성 X.
   - **함정**: 스페인어 "si" (조건)을 한국어 "-(으)면" 단순 매핑 → "시간" 의미 손실. 예: "한국에 가면 친구를 만나요" (when) ≠ "한국에 가면 행복할 거예요" (if).
   - **훈련법**: 한국어 "-(으)면" 4가지 의미 (조건/시간/양보/간접 인용) — 문맥 의존. 스페인어/중국어 별도 어법 학습.

4. **명령법의 경어 단계**:
   - 한국어 명령법: "가! (해체) / 가세요. (정중) / 가십시오. (격식) / 가옵소서. (고문)". 같은 "가다" 동사가 4단계로 분리.
   - 스페인어 명령법: tú/usted/vosotros 별도 형태 (2 단계).
   - **함정**: 스페인어 "ve" (tú 명령) / "vaya" (usted 명령) 단순 매핑 → 한국어 4단계 시스템 무시.
   - **훈련법**: 한국어 명령법 4단계 매트릭스 — 해체 (친한 친구) / 해요체 (정중 기본) / 합쇼체 (격식) / 하소서체 (고문/극격식).

5. **법 부사 vs 형태론 혼동 (중국어/영어)**:
   - 중국어는 부사 (会, 要, 能, 可以, 应该, 必须) + 어순으로 양태 표현. 형태론 없음.
   - 영어는 양태 동사 (may, might, would, should, can, could) 사용.
   - **함정**: 한국어 학습자가 "법 = 동사 어미 변형"으로 학습 → 중국어/영어 양태 동사/부사 시스템 무지.
   - **훈련법**: 한국어 (동사 접미 형태) vs 영어 (양태 동사) vs 중국어 (양태 부사) vs 일본어 (동사 활용) vs 스페인어 (가정법 어미) — **5개 메커니즘 비교** 학습.

### 학습 전략

1. **우선순위 1**: 스페인어 가정법 트리거 학습 — WEIRDO 패턴 (Wishing/Emotion/Influence/Requests/Doubt/Ojalá). 한국어에 없는 명시적 형태 트리거이므로 별도 학습 필수.
2. **우선순위 2**: 한국어/일본어 경어법과 법의 중첩 매트릭스 — 같은 동사 형태가 법+경어 동시 표현. 스페인어/중국어는 분리. **다른 메커니즘** 학습.
3. **우선순위 3**: 한국어 "-(으)면" 다의성 — 조건/시간/양보/간접 인용. 스페인어 si/일본어 たら/중국어 如果/如果的话 와 매핑.
4. **우선순위 4**: 명령법 5개 언어 매트릭스 — 한국어 4단계, 스페인어 3형태, 영어 1형태, 일본어 5형태, 중국어 부사 변형. 명령법 사용 시 경어 단계 매핑 필수.
5. **우선순위 5**: 양태 부사 (중국어) vs 양태 동사 (영어) vs 양태 어미 (스페인어) vs 양태 동사 활용 (일본어/한국어) — **5개 메커니즘 비교** 학습.
