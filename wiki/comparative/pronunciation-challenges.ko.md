## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 발음을 학습할 때 흔히 마주치는 함정

1. **한국어 ɯ (으) 모음의 특수성**:
   - 한국어 ɯ (으)는 후설 고모음 — 영어/스페인어/중국어에 없는 모음. 일본어에도 없음.
   - 영어 학습자: "으" 발음 어려움. 스페인어/중국어 학습자도 ɯ 발음 음소 없음.
   - **함정**: 한국어 학습자가 영어/스페인어 ɯ 발음 시점 인지 부족 → "으"가 "u" 또는 "i"로 발음되는 것 막기 어려움.
   - **훈련법**: ɯ (으) 명시적 연습 — 혀 뒤로 당기고 입술 둥글게. 한국어 모음 8-10개 매트릭스 학습.

2. **삼원 파열 (예사/된소리/거센소리) 의 한국어 특수성**:
   - 한국어 파열음: ㅂ(p)/ㅃ(p͈)/ㅍ(pʰ), ㄷ(t)/ㄸ(t͈)/ㅌ(tʰ), ㄱ(k)/ㄲ(k͈)/ㅋ(kʰ) — **3개 대비** (보통/경음/거센).
   - 영어: p/b (2개). 스페인어: p/b (2개). 일본어: 파열음 무성 (allophonic). 중국어: p/pʰ (2개).
   - **함정**: 한국어 학습자가 영어 TH (θ/ð) 어려움과 비슷하게, 영어 학습자가 한국어 된소리/거센소리 구분 어려움. 그러나 **한국어 학습자가 모국어이기 때문에 자국어 발음 비교 가능**.
   - **훈련법**: 다른 4개 언어 학습 시 **삼원 대비 없음** 인지. 영어 p/b, 중국어 p/pʰ, 일본어 allophonic, 스페인어 p/b — 2개 대비. **3개 대비 (한국어)는 한국어 고유**.

3. **받침 (final consonant) 의 한국어 고유성**:
   - 한국어 받침 (final consonant = batchim) = 영어 cluster 종성 (강세 음절 종성), 중국어 종성 (-n/-ng), 일본어 ん (비음만), 스페인어 종성 (-n/-s/-l/-r/-d).
   - 한국어 받침: 27개 가능 (단일 + 클러스터). 7개 대표 발음 / 11개 음성 규칙 (받침 중화, 경음화, 비음화, 연음, 구개음화).
   - **함정**: 영어 cluster 종성 ("cats", "sixths") vs 한국어 받침 — 영어 클러스터 = 단일 종성 자음, 한국어 받침 = 종성 발음 단순화.
   - **훈련법**: 받침 음성 규칙 명시 학습 — ㄱ/ㄴ/ㄷ/ㄹ/ㅁ/ㅂ/ㅇ 7개 대표 발음. 받침 중화 (값 → 갑), 경음화 (꽃이 → 꼬치), 비음화 (깜짝 → 깜짝), 연음 (한국어 → 한구거).

4. **영어/스페인어/중국어 TH/θ/ð 의 모국어 부재**:
   - 한국어에 θ/ð 없음. 한국어 학습자가 영어/스페인어 TH 발음 어려움.
   - **함정**: 영어 th (think, this) vs 한국어 발음 대체 — "think" → "팅크" (s) / "띵크" (t) / "핑크" (f) — 모두 부정확.
   - **훈련법**: 영어 TH 명시적 연습 — 혀를 윗니 사이 위치. 한국어 학습자 가장 큰 영어 발음 도전 중 하나.

5. **중국어 성조 학습 어려움**:
   - 한국어에 성조 없음 (pitch accent는 있으나 3-단계 대비 vs 중국어 4성조).
   - **함정**: 한국어 학습자가 중국어 4성조 구분 어려움 — 같은 발음 다른 성조 = 다른 의미. mā(어머니) vs má(삼) vs mǎ(말) vs mà(꾸짖다).
   - **훈련법**: 성조 4개 명시적 연습 + 변이 규칙 (3+3 → 2+3, bù + 4 → 2, yī 변이). 한국어 학습자에게 가장 큰 중국어 발음 도전.

### 학습 전략

1. **우선순위 1**: 한국어 ɯ (으) 모음 명시 학습 — 8-10개 모음 매트릭스. 다른 4개 언어에 없는 한국어 고유 모음.
2. **우선순위 2**: 삼원 파열 대비 명시 — 한국어 발음의 핵심. 다른 4개 언어 학습 시 2개 대비 (EN p/b, ES p/b, CH p/pʰ) 인지.
3. **우선순위 3**: 받침 7개 대표 발음 + 5개 음성 규칙 — 값(갑), 꽃이(꼬치), 깜짝(깜짝), 한국어(한구거), 닫히다(다치다).
4. **우선순위 4**: 영어 TH 명시 학습 — 한국어 학습자의 가장 큰 영어 발음 도전. 혀 윗니 사이 위치.
5. **우선순위 5**: 중국어 4성조 변이 규칙 — 3+3 → 2+3, bù + 4 → 2, yī 변이. 한국어 학습자의 가장 큰 중국어 발음 도전.
