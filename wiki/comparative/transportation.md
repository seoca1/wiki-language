## Per-Country Transportation Systems

### United States

| Mode | Description |
|------|-------------|
| **Car** | Primary mode of transportation (~85% of trips) |
| **Airplane** | Long-distance, extensive network |
| **Bus** | Greyhound (long-distance), city buses |
| **Subway** | NYC, Chicago, DC, Boston, SF, LA (limited) |
| **Train** | Amtrak (limited passenger rail) |
| **Rideshare** | Uber, Lyft (dominant in cities) |
| **Bike** | Growing in cities (Citi Bike, Lyft bikeshare) |

**Cultural Notes**:
- Driver's license = identity
- No national transit pass
- Car = freedom symbol (especially in suburbs)

### Spain

| Mode | Description |
|------|-------------|
| **High-speed train (AVE)** | Excellent network (Madrid, Barcelona, Sevilla) |
| **Metro** | Madrid, Barcelona, Bilbao, Valencia |
| **Cercanías** | Suburban rail (commuter) |
| **Bus** | ALSA (long-distance), city buses |
| **Car** | Common but limited in historic city centers |
| **Taxis** | White with green stripe (Madrid), black/yellow (Barcelona) |
| **Rideshare** | Uber, Cabify, FreeNow |

**Cultural Notes**:
- AVE (high-speed) — major cities 2-3 hours apart
- Siesta — some businesses close 14-17 (less common now)
- Tipping taxi: rounding up (no mandatory)
- Driving in Spain = chaotic (locals joke)

### Japan

| Mode | Description |
|------|-------------|
| **Train (Japan Railways)** | JR (6 regional companies), dense network |
| **Subway (chikatetsu)** | Tokyo Metro, Toei, Osaka, Nagoya, etc. |
| **Shinkansen** | High-speed (bullet train) — global gold standard |
| **Bus** | Highway buses (cheaper than train), city buses |
| **Taxi** | Expensive, but reliable (door auto-opens) |
| **Car** | Less common in cities (expensive parking, narrow streets) |
| **Bicycle** | Common (cycling culture), esp. in Kyoto |
| **Airplane** | Domestic flights between major cities |
| **Ferry** | To islands (Okinawa, Hokkaido) |

**Cultural Notes**:
- **IC cards** (Suica, Pasmo, Icoca) — transit + payment, all compatible
- Trains = PUNCTUAL (秒単位 sekigiri — to the second)
- Quiet on trains (no phone calls)
- Tip = nonexistent in taxi
- JR Pass for foreign tourists (7/14/21 days)

### Korea

| Mode | Description |
|------|-------------|
| **Subway** | Seoul (9 lines), Busan, Daegu, Incheon, Gwangju, Daejeon |
| **KTX** | High-speed rail (Seoul-Busan 2 hours) |
| **SRT** | Private high-speed (newer, similar to KTX) |
| **Bus** | Intercity (고속버스), city buses |
| **Taxi** | Color-coded: 일반 (regular) / 모범 (premium) / 대형 (large) |
| **T-money / Cashbee** | Transit cards (all modes compatible) |
| **Car** | Common but Seoul traffic bad |
| **Kakao T** | KakaoTaxi app (dominant rideshare) |

**Cultural Notes**:
- Seoul subway = world class (clean, fast, English signs)
- T-money = essential (taxis, subways, buses, convenience stores)
- Tipping taxi = not done (driver may chase after you!)
- Senior seats = priority (give up even if elderly standing)
- Premium taxi (모범택시) = larger, more expensive

### China

| Mode | Description |
|------|-------------|
| **High-speed rail (CRH)** | World's largest network (40,000+ km) |
| **Subway** | Beijing, Shanghai, Guangzhou, Shenzhen, 40+ cities |
| **Bus** | Extensive network, very cheap |
| **Taxi** | Common in cities |
| **Didi (滴滴)** | Ride-share app (Uber of China) |
| **Car** | Growing middle class |
| **Alipay/WeChat Pay** | Used for ALL transit payment |
| **High-speed Maglev** | Shanghai (pudong airport, world's fastest) |

**Cultural Notes**:
- **Alipay/WeChat Pay** = universal payment (even to street vendors)
- **English signage**: Major cities subway = bilingual
- **Queueing**: Can be chaotic (especially buses)
- **High-speed rail**: Beijing-Shanghai 4.5 hours (vs. flight 2 hours + airport time = similar)
- **Didi**: Install before traveling (foreign card support limited)

## Cultural Travel Norms

### Etiquette

| Behavior | EN | ES | JP | KR | CH |
|----------|----|----|----|----|----|
| **Queue** | Expected | Expected | Less strict | Less strict | Variable |
| **Boarding** | Boarding | Let people off | **Strict order** | Less strict | Push culture |
| **Phone calls** | OK (quiet voice) | OK | **Forbidden** | Discouraged | Discouraged |
| **Eating/drinking** | Allowed (US) | Allowed | **Forbidden** (some lines) | Discouraged | Discouraged |
| **Talking** | Quiet voice | OK | **Whisper** | Quiet | Variable |
| **Priority seats** | For elderly | For elderly, pregnant | **Strict** (yield often) | **Strict** (yield expected) | Expected |

### Specific Cultural Notes

| Country | Quirks |
|---------|--------|
| **EN** | Stand on right of escalator (UK), left (US) |
| **ES** | Siesta still common (2pm-5pm) — shops closed |
| **JP** | **Specific train car for women** (女性専用車) during rush hour |
| **JP** | Trains are **silent** (no phone calls, quiet conversation) |
| **JP** | Wait for green light **even if no cars coming** (social norm) |
| **KR** | **Senior seats (노약자석)** strict — give up easily |
| **KR** | Subway cars have **special priority for pregnant women** (pink seats) |
| **CH** | **Pushing is normal** during rush hour (especially Beijing/Shanghai) |
| **CH** | Subways often have **separate men/women cars** (off-peak) |
| **CN** | **Mobile payment** = universal (no IC card needed) |
| **CN** | Drivers often **honk** to warn pedestrians |

## Driving & Car

### Driver's License (Age, Process)

| Country | Min Age | Process |
|---------|---------|---------|
| **US** | 16 (each state) | Permit → license (test) |
| **Spain** | 18 | Theory + practical test |

| **Korea** | 18 (1종 보통) | Theory + practical + course |
| **China** | 18 (C1) | Theory + practical (varies by region) |

| Country | IDP Needed? | Notes |

| **Japan** | **Yes** (Geneva 1949 + translation) | Strict |
| **Korea** | **Yes** (Geneva 1949) | Required + Korean license |
| **China** | **Yes** (Geneva 1949) | Required + temporary license |
