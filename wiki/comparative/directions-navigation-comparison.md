## Per-Language Detail

### English
- **Key terms**: "Turn left" / "Turn right" / "Go straight"; "North" / "South"
- **Patterns**: Preposition: "on" (on the left); "to the" (to the left)
- **Sources**: `[[directions-vocabulary]]`

### Spanish
- **Key terms**: "Norte/Sur/Este/Oeste" (often capitalized); "a la izquierda/derecha"
- **Patterns**: Gender agreement: "izquierdo" / "izquierda"; "Gire" (formal imperative) vs "gira" (informal)
- **Sources**: N/A — Spanish lacks directions theme yet

### Japanese
- **Key terms**: 北東 (hokutō) / 北西 (hokusai) / 南東 (nantō) / 南西 (nansai); 交差点 (kōsaten = intersection)
- **Patterns**: Verb: 〜を曲がる (wo magaru); Particle: 〜に (direction); "左に" (hidari ni)
- **Sources**: `[[directions-vocabulary]]`

### Korean
- **Key terms**: 방위 (bangwi = direction); 동서남북 (dong-seo-nam-buk = cardinal directions)
- **Patterns**: Verb: 〜을/를 돌다 (eul/reul dolida); particle: 〜으로 (euro = direction)
- **Sources**: `[[directions-vocabulary]]`

### Chinese
- **Key terms**: 方向 (fāngxiàng), 东南西北 (dōng-nán-xī-běi); 十字路口 (shízì lùkǒu = intersection)
- **Patterns**: Verb: 〜转 (zhuǎn); particle: 向 (xiàng = towards)
- **Sources**: N/A — Chinese lacks directions theme yet

## Key Contrasts (Synthesis)

| Contrast | Insight |
|----------|---------|
| **Compass directions** | JP uses "kita/minami/higashi/nishi" — single character with multiple readings; CJK use single character |
| **Seniority in routes** | East Asian addresses follow hierarchy (province→city→district→block→number); Western addresses flatter |
| **Left/right** | EN/ES: adjective; CJK: noun or adjective; verb patterns differ |
| **Particle usage** | Korean uses -(으)로 for direction; Japanese uses に; Chinese uses 往/向 |
