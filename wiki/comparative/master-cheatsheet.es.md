## 🇬🇧 Inglés (EN) — Esencial

### Básico
| EN | IPA | Notas |
|----|-----|-------|
| Hello | /həˈloʊ/ | Universal |
| Goodbye | /ɡʊdˈbaɪ/ | Universal |
| Please | /pliːz/ | Universal |
| Thank you | /θæŋk juː/ | Universal |
| Sorry | /ˈsɒri/ | Universal |
| Yes / No | /jɛs/ /noʊ/ | Universal |
| I / You / He/She/It | /aɪ/ /juː/ /hi, ʃi, ɪt/ | 3.ª sg género neutro |

### Frases
- "How are you?" — saludo estándar
- "I'm good, thanks." — respuesta predeterminada
- "Where is the bathroom?" — esencial
- "How much?" — compras
- "I don't understand." — cortesía
- "Could you help me?" — petición cortés indirecta

### Datos gramaticales
- **Orden de palabras**: SVO
- **Artículos**: a/an (indef), the (def)
- **Negación**: do/does + not + verbo
- **Pregunta**: Do/Does/Would/Could + S + V?
- **Pronombres**: He/She + They (singular they = neutro)

### Datos culturales
- Comunicación directa
- Nombres propios rápidamente
- Contacto visual = honestidad
- Propina 15-20 % esperada
- Espacio personal: ~longitud del brazo

## 🇪🇸 Español (ES) — Esencial

### Básico
| ES | Pronunciación | Notas |
|----|---------------|-------|
| Hola | /ˈo.la/ | Universal |
| Adiós | /aˈðjos/ | Universal |
| Por favor | /poɾ faˈβoɾ/ | Universal |
| Gracias | /ˈɡɾa.θjas/ (ES) /ˈɡɾa.sjas/ (LatAm) | Universal |
| Perdón / Disculpe | /peɾˈðon/ /diskulpe/ | Disculpa / Disculpe |
| Sí / No | /si/ /no/ | Universal |
| Yo / Tú / Usted | /jo/ /tu/ /usˈteð/ (ES) | Tú (par) / Usted (formal) |

### Frases
- "¿Qué tal?" — ¿Qué tal?
- "Más o menos" — Más o menos
- "¿Dónde está...?" — ¿Dónde está...?
- "¿Cuánto cuesta?" — ¿Cuánto cuesta?
- "No entiendo" — No entiendo
- "¿Puede ayudarme?" — ¿Puede ayudarme?

### Datos gramaticales
- **Orden de palabras**: SVO (flexible)
- **Artículos**: el/la/los/las (def), un/una/unos/unas (indef)
- **Negación**: no + verbo (preverbal)
- **Pregunta**: entonación + marcas ¿?
- **Pronombres**: género (él/ella), formal vs informal (tú/usted)
- **Subjuntivo**: disparadores WEIRDO

### Datos culturales
- Tío/tía = colega (España)
- Besos (2 España, 1 LatAm)
- Propina 5-10 % (España) / 10 % (LatAm)
- Comidas tardías (almuerzo 14:00+, cena 21:00+)
- Espacio personal: conversación **cercana**

## 🇯🇵 Japonés (JP) — Esencial

### Básico
| JP | Lectura | Notas |
|----|---------|---------|
| こんにちは | Konnichiwa | Hola (de día) |
| さようなら | Sayounara | Adiós (formal) |
| お願いします | Onegaishimasu | Por favor |
| ありがとうございます | Arigatou gozaimasu | Gracias (cortés) |
| すみません | Sumimasen | Disculpe / Perdón (cortés) |
| はい / いいえ | Hai / Iie | Sí / No |
| 私 / あなた | Watashi / Anata | Yo (cortés) / Tú (evitar) |

### Frases
- "お元気ですか?" (Ogenki desu ka?) — ¿Cómo estás?
- "いただきます" (Itadakimasu) — antes de comer
- "ごちそうさまでした" (Gochisousama deshita) — tras comer
- "いくらですか?" (Ikura desu ka?) — ¿Cuánto cuesta?
- "わかりません" (Wakarimasen) — No entiendo
- "助けてください" (Tasukete kudasai) — Ayuda

### Datos gramaticales
- **Orden de palabras**: SOV (verbo al final)
- **Artículos**: NINGUNO
- **Negación**: sufijo verbal -nai (simple) / -masen (cortés)
- **Pregunta**: partícula か (ka) al final
- **Pronombres**: evitar; usar nombres + san/kun/chan
- **Keigo**: sistema honorífico (sonkeigo/kenjougo/teineigo)
- **Contadores**: obligatorios (個/人/本/枚/台/匹...)

### Datos culturales
- Inclinarse 15°/30°/45° según respeto
- Dar/recibir con dos manos
- Sin propina (¡grosero!)
- Silencio en transporte
- *Kuuki o yomu* (leer el ambiente)
- *Omotenashi* (servicio anticipativo)

## 🇰🇷 Coreano (KR) — Esencial

### Básico
| KR | Hangul | Notas |
|----|--------|---------|
| 안녕하세요 | Annyeonghaseyo | Hola (cortés por defecto) |
| 안녕히 가세요 / 계세요 | Annyeonghi gaseyo / gyeseyo | Adiós (al que se va / al que se queda) |
| 주세요 | Juseyo | Por favor, dame |
| 감사합니다 | Gamsahamnida | Gracias (cortés) |
| 미안합니다 / 죄송합니다 | Mianhamnida / Joesonghamnida | Disculpa / Disculpa (formal) |
| 네 / 아니요 | Ne / Aniyo | Sí / No |
| 저 / 저희 | Jeo / Jeohui | Yo / Nosotros (humilde) |

### Frases
- "잘 지내세요?" (Jal jinaeseyo?) — ¿Cómo estás?
- "잘 먹겠습니다" (Jal meokkesseumnida) — antes de comer
- "잘 먹었습니다" (Jal meogeosseumnida) — tras comer
- "얼마예요?" (Eolmayeyo?) — ¿Cuánto cuesta?
- "이해 못 해요" (Ihae mot haeyo) — No entiendo
- "도와주세요" (Dowajuseyo) — Ayuda

### Datos gramaticales
- **Orden de palabras**: SOV (verbo al final)
- **Artículos**: NINGUNO
- **Negación**: sufijo verbal -지 않다 (corto) / -지 않습니다 (cortés)
- **Pregunta**: entonación + ~까? (~gga?, formal)
- **Niveles de habla**: 해체 (casual) / 해요체 (cortés) / 합쇼체 (formal)
- **Pronombres**: evitar; usar nombres + 님/씨
- **Contadores**: obligatorios (개/명/마리/장/대...)
- **No puedo vs No quiero**: 못 vs 안/안

### Datos culturales
- Inclinarse 30°/45°/90° (Año Nuevo = 큰절)
- Dar/recibir con dos manos (obligatorio)
- Sin propina (raro)
- Palillos metálicos (específico de Corea)
- *Nunchi* (tacto social) esencial
- *Jeong* (vínculo profundo) con el tiempo

## 🇨🇳 Chino (CH) — Esencial

### Básico
| CH | Pinyin | Notas |
|----|--------|---------|
| 你好 | Nǐ hǎo | Hola |
| 再见 | Zàijiàn | Adiós |
| 请 | Qǐng | Por favor |
| 谢谢 | Xièxie | Gracias |
| 对不起 / 不好意思 | Duìbuqǐ / Bù hǎoyìsi | Disculpa / Disculpe |
| 是 / 不是 | Shì / Bù shì | Sí / No |
| 我 / 你 / 您 | Wǒ / Nǐ / Nín | Yo / Tú / Usted (respetuoso) |

### Frases
- "你好吗?" (Nǐ hǎo ma?) — ¿Cómo estás?
- "吃了吗?" (Chī le ma?) — ¿Has comido? (saludo cultural)
- "多少钱?" (Duōshǎo qián?) — ¿Cuánto cuesta?
- "我不懂" (Wǒ bù dǒng) — No entiendo
- "请帮帮我" (Qǐng bāng bang wǒ) — Por favor, ayuda
- "没事" (Méi shì) — Sin problema

### Datos gramaticales
- **Orden de palabras**: SVO (flexible, prominencia de tópico)
- **Artículos**: NINGUNO
- **Negación**: 不 (bù) general / 没 (méi) pasado; 别 (bié) imperativo
- **Pregunta**: 吗 (ma) al final / patrón A-no-A
- **Tonos**: 4 tonos + neutro (mā má mǎ mà)
- **Clasificadores**: obligatorios (个/位/只/条/张...)
- **Partículas aspectuales**: 了 / 过 / 着

### Datos culturales
- *Guanxi* (relaciones) = moneda
- *Mianzi* (cara) = crítico
- Título + apellido (王老师, 张经理)
- Banquetes = cultura del trago (干杯 gānbēi)
- Regalos (sin relojes, sin sombreros verdes)
- Pago móvil = WeChat/Alipay por defecto

## 🇪🇸 Notas para estudiantes de español (Spanish Learner Notes)

> Esta sección es una guía de aprendizaje adicional para hispanohablantes.

### Trampas comunes para hispanohablantes al aprender los otros 4 idiomas

1. **Asumir universalidad del español**:
   - El español tiene ventajas (ortografía transparente, sin tonos) pero劣势 en otros: sistema de tildes complejo, *ser/estar*, subjuntivo obligatorio.
   - **Trampa**: pensar que el español es "fácil" para angloparlantes/asiáticos y subestimar las dificultades propias al aprender otros idiomas.
   - **Entrenamiento**: reconocer que cada idioma tiene su propia complejidad.

2. **Olvidar la riqueza del español regional**:
   - *Tú* vs *vos*, *cena* vs *comida*, *plata* vs *pasta*, *coche* vs *carro*... hay variantes.
   - **Trampa**: usar una variante como universal.
   - **Entrenamiento**: practicar variantes regionales según el interlocutor.

3. **Sobreconfianza con 5 vocales vs. fonemas más amplios**:
   - Español tiene 5 vocales puras; inglés tiene 11-14. CJK tiene sistemas propios.
   - **Trampa**: pensar que la fonética española es "completa" (no lo es — faltan sonidos como θ/ð, ɹ).
   - **Entrenamiento**: estudiar la fonética del idioma objetivo explícitamente.

4. **Olvidar las preposiciones a/de/en en su forma y función**:
   - El español las usa preverbalmente; CJK usa posposiciones/partículas.
   - **Entrenamiento**: al aprender partículas japonesas/coreanas, recordar la lógica posposicional.

5. **Olvidar la lógica cultural**:
   - Cada idioma codifica valores distintos (respeto en JP/KR, guanxi en CN, inmediacy en ES/LatAm).
   - **Entrenamiento**: estudiar el contexto cultural, no solo vocabulario.

1. **Tarjeta de referencia rápida** (esta página) — impresión y memorización
2. **Practicar las 10 frases universales** en cada idioma
3. **Elegir UN idioma objetivo** y profundizar con las páginas detalladas (politeness, números, tiempo)
4. **Combinar con aplicación cultural** (viaje, película, libro)
5. **Revisar cada 6 meses** para mantener dominio
