## 発音混同ポイント

### 🇬🇧 英語話者の一般的誤り

#### スペイン語
| 英語話者 | 正しくは | 理由 |
|----------------------|------------|-----|
| "Hespañol" | "Español" (ehs-pah-nyohl) | 英語の "e" = "ee", スペイン語の "e" = "eh" |
| "Gracias" を "GRAH-see-as" | "GRAH-syahs" | "c" の前 "e/i" = "s" 音 |
| "Hola" を TH で | "OH-lah" | スペイン語の "h" は無音 |

#### 日本語
| 英語話者 | 正しくは | 理由 |
|----------------------|------------|-----|
| "Hai" を英語の "Hi" | "Hah-ee" | "ai" = "ah-ee" (2 モーラ) |
| "Desu" を "Day-su" | "Des" (s 軽い) | ある文脈で "u" が無声化 |
| "Ri" を "ree" | "Ree" | "i" は "ee" ではない — 日本語に "ee" なし |
| "Kun" を "Coon" | "Koon" | "u" は "oo" ではない |

#### 韓国語
| 英語話者 | 正しくは | 理由 |
|----------------------|------------|-----|
| "Annyeonghaseyo" をはっきり TH で | "An-nyeong-ha-se-yo" | "th" 音なし |
| "Korean" を "Koh-ree-an" | "Korean" (2 音節) | "ree" なし |
| "Kimchi" を "Kim-chee" | "Kim-chi" (グリードなし) | "i" 短い、 "ee" なし |
| "Bulgogi" を "Bul-go-gee" | "Bul-go-gi" | "gi" は "gee" ではない |

#### 中国語
| 英語話者 | 正しくは | 理由 |
|----------------------|------------|-----|
| "Ni hao" を "Nee how" | "Nee how" (hao は第3声上昇) | 声調重要 |
| "Xie xie" を "She she" | "Syeh-syeh" (第3声 + 中性) | "x" = "s" (拼音) |
| "Zai jian" を "Zai jee-an" | "Zai jian" (中性声調) | 拼音にグリードなし |

### 🇯🇵 日本語話者の一般的誤り

#### 英語
| 日本語話者 | 正しくは | 理由 |
|----------------------|------------|-----|
| "R" を日本語 flap | "R" をそり舌 ɹ | 異なる調音 |
| "L" を日本語の "r" | "L" を明確な側面音 | 日本語に明確な "l" なし |
| "V" を "b" | "V" を唇歯音 | 日本語に "v" なし (ヴ vu を使用) |
| "TH" を "s" | "TH" を θ/ð | "th" 音欠如 |

#### 韓国語
| 日本語話者 | 正しくは | 理由 |
|----------------------|------------|-----|
| ㅈ を "ch" | ㅈ を "j" (tɕ) | 韓国語 ㅈ = 歯茎硬口蓋音 |
| ㄷ を "d" | ㄷ を "t" (語頭で有気音) | 三方向破裂音区別 |

## 文法混同ポイント

### 時制・アスペクト誤り

| L1 → L2 | 一般的誤り | 理由 |
|---------|--------------|-----|
| **EN → ES** | "If I **will go**" → "*Si **iré***" (誤り) | スペイン語は si 節で未来形を使用しない → *Si **voy*** |
| **EN → ES** | "I'm **boring**" → "*Estoy aburrido*" (人称誤り) | スペイン語は *aburrir* = to bore; *Estoy aburrido* = 退屈している (受動的感覚) |
| **EN → JP** | "I **have gone**" → "I **go**" | 日本語に現在完了形なし; 過去形 (*itta*) のみ |
| **EN → KR** | "I **will go** tomorrow" → "I **go** tomorrow" | 韓国語は未来形省略多い; *내일 갈게* は未来 |
| **EN → CH** | "I **am eating**" → "I **eat**" | 中国語はアスペクト; *我在吃* (進行) vs *我吃* (習慣) |
| **JP → EN** | "Yesterday **go**" → "Yesterday **went**" | 英語は過去形必須 |
| **KR → EN** | "Yesterday **go**" → "Yesterday **went**" | 同じ |
| **CH → EN** | "Yesterday **go**" → "Yesterday **went**" | 同じ |

### ポライトネス/レジスタ誤り

| L1 → L2 | 一般的誤り | 理由 |
|---------|--------------|-----|
| **EN → ES** | 見知らぬ人に "tú" | スペイン語はデフォルトで *usted* (ラ米) |
| **EN → JP** | 見知らぬ人に plain form | 日本語はデフォルトで *desu/masu* |
| **EN → KR** | 年上に plain form | 韓国語はデフォルトで *haeyo/hapsyo* |
| **EN → CH** | 年上に敬語なし | 中国語は 您 + 役職 |
| **ES → JP** | 上位者に "Tú" form | 日本語は *sonkeigo* 必須 |
| **JP → CH** | 日本語敬語のような過度な (您) | 中国語敬語は役職 + お願いします程度 |

### 冠詞誤り

| L1 → L2 | 一般的誤り | 理由 |
|---------|--------------|-----|
| **JP/KR/CH → EN** | "I saw **car**" (冠詞なし) | 英語は "a car" または "the car" 必須 |
| **CH → EN** | "I have **book**" (冠詞なし) | 同じ |
| **EN → JP/KR/CH** | "I saw **a cat**" → "I saw **cat**" | 目的語に冠詞なし |

### 性・数誤り

| L1 → L2 | 一般的誤り | 理由 |
|---------|--------------|-----|
| **EN → ES** | "la problema" (性誤り) | スペイン語 *problema* は -a だが男性 |
| **EN → ES** | "the book**s**" → "el libro" (複数なし) | スペイン語は複数必須 |
| **JP → EN** | "I have book" (複数なし) | 英語は複数必須 |
| **KR → EN** | "I saw dog" (冠詞なし) | 英語は冠詞必須 |

## 文化的混同 (無礼の事故)

### タブー話題/行動

| 文化 | タブー | 回避法 |
|---------|-------|--------------|
| **EN** | 面接で給料を聞く | オファーまで待つ |
| **ES** | 年長者に *Tú* | デフォルトで *usted* |
| **JP** | チップを渡す | 日本ではチップ不要 (失礼) |
| **JP** | 指で指す | 開いた手を使用 |
| **JP** | ご飯に箸を突き立てる | 平らに置く |
| **JP** | 公共の場で鼻をかむ | トイレ使用 |
| **KR** | 年長者が自分の酒を注ぐ | 年長者のために注ぐ |
| **KR** | 名前を赤インクで書く | 黒/青を使用 (赤 = 死) |
| **KR** | 年長者より先に食べ始める | 待つ |
| **CH** | 時計をギフトとして贈る | "送钟" は 送終 (死) と同音 |
| **CH** | 男性に緑の帽子を贈る | "cuckold" を意味 |
| **CH** | 梨を分ける | "分梨" は 分离 (分離) と同音 |
| **CH** | 足の裏を人に見せる | 非常に失礼 |

## 🇯🇵 日本語学習者ノート (Japanese Learner Notes)

> 本セクションは日本語学習者向けの追加学習ガイドです。

### 日本語話者が他の4言語を学ぶ際の一般的な落とし穴

1. **漢字依存の過信**:
   - 日本語の漢字は中国語と似ているが、韓国語は漢字 (Hanja) を日常語では使わず固有語を使用。
   - **落とし穴**: 韓国語の漢字語彙 (犬=견, 馬=마) を覚えても実際の会話では使われない。
   - **練習法**: 韓国語は固有語を先に覚える; 中国語は漢字 + 拼音の両方が必要。

2. **敬語の中国語/英語への過剰転移**:
   - 日本語の敬語システム (尊敬語/謙譲語/丁寧語) は韓国語にも部分的にあるが、中国語・英語にはない。
   - **落とし穴**: 中国語/英語で過度に丁寧な言葉を使用 → 不自然に。
   - **練習法**: 中国語は 您 + 役職; 英語は "Please" + "Thank you" 程度。

3. **音読み/訓読みの漢字差**:
   - 日本語の漢字は音読みと訓読みがある (山=やま, さん)。
   - **落とし穴**: 中国語では山=shān (1 読み) のみ、日本語音読みの "san" は中国語では使用されない。
   - **練習法**: 中国語の漢字は 1 文字 1 音と理解、日本語音読みは固定熟語でのみ使用。

4. **カタカナ語の英語への誤転用**:
   - 日本語の「マンション」= アパート (英語 "mansion" = 大邸宅ではない)。
   - **練習法**: 日本語カタカナ語を英語に翻訳する前に元の意味を確認。

5. **擬音語の翻訳不可能性**:
   - 日本語の擬音語 (ゴロゴロ = purr, ワンワン = woof) は韓国語・中国語に翻訳できない。
   - **練習法**: 言語ごとに擬音語を別に覚える; 翻訳に固執しない。
