## Marco de puntuación de dificultad

| Puntuación | Etiqueta | Descripción |
|------------|----------|-------------|
| **1** | Trivial | Igual que L1 o aprendizaje mínimo |
| **2** | Fácil | Nuevo pero transparente, pocas excepciones |
| **3** | Moderado | Concepto nuevo, algunas excepciones |
| **4** | Difícil | Paradigma complejo, muchas excepciones |
| **5** | Muy Difícil | Concepto ajeno, omnipresente, alta tasa de error |

| **Marcación de caso** | Ninguna (solo pronombres) | Ninguna | **Partículas** (が/を/に/で/へ/と/の) | **Partículas** (이/가/을/를/에/에서/와/과/의) | Ninguna |

| **Negación** | Aux + not | Pre-verbal *no* | Sufijo *-nai/-masen* | Sufijo *-ji anta* | Pre-verbal *bù/méi* |
| **Preguntas** | Inversión aux / do-support | Entonación / *¿?* | Partícula *ka* / entonación | Entonación / partícula *nya* | Partícula *ma* / *A-not-A* |
| **Cláusulas relativas** | Pronombres relativos (who/which) | Pronombres relativos (que/quien) | **Pre-nominal** (sin pronombre relativo) | **Pre-nominal** (sin pronombre relativo) | **Pre-nominal** (的) |

| **Adverbios** | sufijo -ly, posición flexible | sufijo -mente, flexible | **sufijos -ku / -ni** | **sufijos -ge / -i** | **Posición pre-verbal** |
| **Comparativos** | -er/more + than | *más/menos + que* | **Yori / hodo** | **Boda / de** | **Bi / gen / hai** |
| **Posesión** | 's / of / pronombres posesivos | *de* + adjetivo posesivo | **No** (の) | **의** | **的** |
| **Reflexivos** | pronombres -self | **se** (clítico) | **自分 (jibun)** | **자기 (jagi)** | **自己 (zìjǐ)** |
| **Recíprocos** | each other | *el uno al otro* | *otagai* | *seoro* | *huxiang / bici* |

## Perfil de error por L1

| L1 → Objetivo | Errores fosilizados | Por qué |
|----------------|---------------------|---------|
| **EN → ES** | *yo voy a voy* (verbo doble), concordancia de género, ser/estar, evitación del subjuntivo | L1 carece de género, subjuntivo |
| **EN → JP** | Omisión de partículas (wa/ga), forma simple con mayores, acento plano | Sin partículas, sin honoríficos |
| **EN → KR** | Errores de batchim, forma simple con mayores, colapso de parada de tres vías | Sin batchim, sin tres vías |
| **EN → CH** | Errores de tono (esp. 3º), sin partículas aspectuales, SVO en cláusulas incrustadas | Sin tono, sin aspecto, incrustación diferente |
| **ES → EN** | *I am agree*, *I have 25 years*, sin sujeto, reducción vocálica, verbos frasales | Pro-drop, sin verbos frasales |
| **JP → EN** | Sin artículos, *he go*, entonación plana, sin reducción acentual, *the* overuse | Sin artículos, sin acento |
| **KR → EN** | Sin artículos, *he go*, entonación plana, *the* overuse, errores de preposición | Sin artículos, sin acento |
| **CH → EN** | Sin artículos, *he go*, entonación plana, *the* overuse, errores de tiempo, errores de preposición | Sin tiempo, sin artículos |
| **JP ↔ KR** | Desajuste de honoríficos, tono vs plano, errores de batchim | Sistemas diferentes |

## Recomendaciones de secuencia de aprendizaje

### Para hispanohablantes → Inglés
1. **Pronunciación** (5 vocales, trino, reglas de acento)
2. **Presente indicativo** (todos los verbos)
3. **Concordancia género/número** (sustantivos, adjetivos)
4. **Ser vs Estar** + adjetivos básicos
5. **Tiempos pasados** (pretérito vs imperfecto)
6. **Disparadores del subjuntivo** (WEIRDO)
6. **Formas del subjuntivo** (presente → imperfecto → perfecto)
7. **Pronombres** (DO/IO/Reflexivo)
8. **Avanzado** (condicional, futuro, pasiva *se*)

### Para hispanohablantes → Japonés
1. **Hiragana/Katakana** (alfabetización)
2. **Pronunciación** (5 vocales, introducción al tono, tiempo moraico)
3. **Partículas básicas** (wa, ga, o, ni, de, no)
4. **Grupos verbales** (ru/u/irregular) + forma masu
5. **Adjetivos básicos** (i/na) + conjugación
6. **Te-form** (peticiones, conexiones)
7. **Pasado/negativo** (todas las formas)
7. **Kanji básico** (100-200 Jōyō)
8. **Formas casuales/simples** (forma diccionario)
9. **Keigo intro** (sonkeigo/kenjougo)
10. **Avanzado** (pasiva, causativa, condicionales, 2000+ kanji)

### Para hispanohablantes → Coreano
1. **Hangul** (alfabetización en horas)
2. **Pronunciación** (batchim, paradas de tres vías, liaison)
3. **Partículas básicas** (이/가, 을/를, 에/에서, 의, 와/과)
4. **Conjugación verbal** (해요체 → 합쇼체 → 해체)
5. **Adjetivos básicos** (verbos descriptivos)
6. **Pasado/negativo/futuro** (todos los niveles de habla)
7. **Honoríficos** (존댓말/반말, 시/으시, 드리다/잡수시다)
8. **Contadores** (núcleo 20+)
9. **Gramática avanzada** (pasiva, causativa, condicionales, ~게/~아/어도)
10. **Hanja** (opcional, 1800 básico)

### Para hispanohablantes → Chino
1. **Pinyin + Tonos** (practicar diariamente)
2. **Radicales básicos** (50 más comunes)
3. **300 caracteres esenciales** (HSK 1-2)
4. **SVO + estructura tema-comentario**
5. **Partículas aspectuales** (了/过/着/的/得/地)
6. **Clasificadores** (núcleo 30)
7. **Comparativos** (比/更/最/跟/一样)
8. **Partículas modales** (吧/呢/啊/吗/啦)
9. **Avanzado** (把/被/让/叫, 成语, 3000+ caracteres)

## 🇪🇸 Notas para estudiantes de español (Spanish Learner Notes)

> Esta sección es una guía de aprendizaje adicional para hispanohablantes.

### Trampas comunes para hispanohablantes al aprender los otros 4 idiomas

1. **Sobreutilización del subjuntivo en español**:
   - El español usa mucho el subjuntivo (presente, imperfecto, futuro) → otros idiomas tienen formas limitadas o ninguna.
   - **Trampa**: buscar equivalentes del subjuntivo donde no existen.
   - **Entrenamiento**: aprender expresiones equivalentes (verbos modales en EN, partículas modales en CH, verbos conjugados en JP/KR).

2. **Concordancia de género como ventaja**:
   - El español tiene concordancia de género (el libro / la mesa) → otros idiomas no.
   - **Trampa**: aplicar concordancia donde no existe.
   - **Entrenamiento**: aceptar que solo el español tiene este sistema entre los 5 idiomas.

3. **Subutilización del orden SOV**:
   - El español es SVO → JP/KR son SOV.
   - **Trampa**: olvidar el verbo al final en frases largas.
   - **Entrenamiento**: practicar estructuras SOV desde el inicio en JP/KR.

4. **Confusión con el voseo**:
   - El voseo es único del español (Argentina, Chile) → otros idiomas no tienen equivalente.
   - **Trampa**: usar "vos" como si fuera universal.
   - **Entrenamiento**: aprender el sistema pronominal completo del español antes de traducir.

5. **Diferencias en partículas**:
   - El español tiene preposiciones (a, de, en, con, por, para) → otros idiomas tienen partículas más específicas (に, 을/를, 에).
   - **Trampa**: usar preposiciones españolas donde se esperan partículas específicas.
   - **Entrenamiento**: aprender las partículas específicas en cada idioma.

### Flujo de aprendizaje recomendado

1. **Identificar la distancia tipológica** entre tu L1 y el idioma objetivo
2. **Priorizar las características más difíciles** según el perfil de error típico
3. **Seguir una secuencia de aprendizaje** estructurada
4. **Practicar la característica de acceso** (la "puerta" al idioma)
5. **Cuidar los errores fosilizados** específicos de tu L1
