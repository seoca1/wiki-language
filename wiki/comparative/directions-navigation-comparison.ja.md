## 各言語詳細

### 🇬🇧 英語 (English)
- **主要用語**: "Turn left" / "Turn right" / "Go straight"; "North" / "South"
- **パターン**: 前置詞: "on" (on the left); "to the" (to the left)
- **出典**: `[[directions-vocabulary]]`

### 🇪🇸 スペイン語 (Spanish)
- **主要用語**: "Norte/Sur/Este/Oeste" (often capitalized); "a la izquierda/derecha"
- **パターン**: 性一致: "izquierdo" / "izquierda"; "Gire" (formal imperative) vs "gira" (informal)
- **出典**: スペイン語には directions テーマ未投入

### 🇯🇵 日本語 (Japanese)
- **主要用語**: 北東 (hokutō) / 北西 (hokusai) / 南東 (nantō) / 南西 (nansai); 交差点 (kōsaten = 交差点)
- **パターン**: 動詞: 〜を曲がる (wo magaru); 助詞: 〜に (方向); "左に" (hidari ni)
- **出典**: `[[directions-vocabulary]]`

### 🇰🇷 韓国語 (Korean)
- **主要用語**: 방위 (bangwi = 方向); 동서남북 (dong-seo-nam-buk = 基本方位)
- **パターン**: 動詞: 〜을/를 돌다 (eul/reul dolida); 助詞: 〜으로 (euro = 方向)
- **出典**: `[[directions-vocabulary]]`

### 🇨🇳 中国語 (Chinese)
- **主要用語**: 方向 (fāngxiàng), 东南西北 (dōng-nán-xī-běi); 十字路口 (shízì lùkǒu = 交差点)
- **パターン**: 動詞: 〜转 (zhuǎn); 助詞: 向 (xiàng = towards)
- **出典**: 中国語には directions テーマ未投入

## 主要な対比 (総合)

| 対比 | 学習者への示唆 |
|----------|---------|
| **コンパス方向** | JP は "kita/minami/higashi/nishi" を使用 — 単一文字に複数の読み; CJK は単一文字 |
| **ルートでの階層性** | 東アジアの住所は階層に従う (province→city→district→block→number); 西洋の住所はフラット |
| **左/右** | EN/ES: 形容詞; CJK: 名詞または形容詞; 動詞パターンは異なる |
| **助詞使用** | 韓国語は方向 -(으)로 を使用; 日本語は に; 中国語は 往/向 |

## 🇯🇵 日本語学習者ノート (Japanese Learner Notes)

> 本セクションは日本語学習者向けの追加学習ガイドです。

### 日本語話者が他の4言語の方向表現を学ぶ際の一般的な落とし穴

1. **方位の多読みの困難 (韓国語・中国語)**:
   - 日本語の漢字「東」= ひがし / 東 (East) → 韓国語は 동, 中国語は dōng (1 音)。
   - **練習法**: 中国語の漢字は 1 音と理解; 韓国語の漢字語 (東=동) を覚える。

2. **住所の階層性 (英語)**:
   - 日本の住所は都道府県→市区町村→番地の階層 (Post code 7桁)。
   - 英語圈では逆順 (Number, Street, City, State, Zip)。
   - **練習法**: 英語表記では逆順、郵便番号は ZIP code (5-9 桁) を使用。

3. **「左」「右」の翻訳**:
   - 日本語の「左」「右」= 単語; 英語 "left" / "right" (形容詞兼名詞)。
   - **練習法**: 英語では "turn left" / "on the left" / "to the left" のように使用。

4. **「交差点」の翻訳差**:
   - 日本語「交差点 (kōsaten)」= intersection; 韓国語「교차로」; 中国語「十字路口 (shízì lùkǒu)」。
   - **練習法**: 道路標識や地図で現地の単語を確認。

5. **敬語と方向**:
   - 日本語の「左に曲がってください」は丁寧; 英語 "Turn left" は命令形 (通常 OK)。
   - **練習法**: 英語圈では "Could you turn left?" のような polite 形も使える; 中国語は "请左转" を使用。
