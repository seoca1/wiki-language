## 언어별 상세

### 🇬🇧 영어 (English)
- **핵심 용어**: "Apparel" (격식), "Clothes" (일반), "Outfit" (특정 의상)
- **패턴**: "Wear" + 명사; "Dress" as 동사 vs 명사 (다른 의미)
- **출처**: `[[clothing-vocabulary]]`

### 🇪🇸 스페인어 (Spanish)
- **핵심 용어**: "Ropa" (일반 의류), "Indumentaria" (격식/산업)
- **패턴**: -ar 동사: usar (입다); 재귀: "vestirse" (스스로 입다)
- **출처**: `[[clothing-vocabulary]]` (테마 존재하나 제한적)

### 🇯🇵 일본어 (Japanese)
- **핵심 용어**: 服 (fuku = 의류), 服飾 (fukushoku = 의류), 衣類 (irui = 의류)
- **패턴**: 동사: 〜を着る (wo kiru); 동사: 〜を履く (wo haku = 발에 신다)
- **출처**: `[[clothing-vocabulary]]`

### 🇰🇷 한국어 (Korean)
- **핵심 용어**: 옷 (ot = 의류), 의류 (eoryu = 의류/패션), 한복 (한복 = 전통)
- **패턴**: 동사: 입다 (ipda = 상의 입다); 신다 (sinda = 발에 신다); 쓰다 (sseuda = 머리에 쓰다)
- **출처**: `[[clothing-vocabulary]]`

### 🇨🇳 중국어 (Chinese)
- **핵심 용어**: 衣服 (yīfu), 服装 (fúzhuāng = 의류), 汉服 (hànfú)
- **패턴**: 동사: 穿 (chuān); 양사: 件 (jiàn) for 의류
- **출처**: N/A — 중국어 의류 테마 미정

## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 의류·패션 어휘를 배울 때 흔히 마주치는 함정

1. **의류 입기 동사 구분 (한국어/일본어 vs 다른 4개 언어)**:
   - 한국어 학습자는 상의 (입다) / 발 (신다) / 머리 (쓰다) 를 구분 — 일본어 (着る/履く/被る) 와 동일. 영어/스페인어/중국어는 단일 "wear/llevar/穿" 동사.
   - **함정**: 한국어 학습자가 영어에서 "I wear shoes on my feet" → 영어에서는 "wear shoes" 자동.
   - **훈련법**: 의류 입기 동사 매핑 — KR 입다/신다/쓰다 / JP 着る/履く/被る / EN wear / ES llevar/usar / CH 穿. 5언어 동사 패턴 비교.

2. **"한복/漢服/和服/kimono" 의 문화별 구분**:
   - 한국어 "한복" = 한국 전통 의상. 중국어 韩服 (한복 발음) ≠ 한국 한복; 중국어 汉服 (Han Chinese 의상) 와 한국 한복 (Korean traditional) 은 다른 의상.
   - **함정**: 중국어 韩服 (hánfú, 중국식 발음) vs 한국 한복 (한복) — 한자 한 (韓/韩) 의 두 형태 매칭.
   - **훈련법**: 韓服 (hánfú, 중국식) vs 한복 (한국) / 汉服 (hànfú, 중국) / 和服 (héfú, 일본) / kimono (일본) 4개 구분 매핑.

3. **"청바지/Denim/牛仔裤" 의 차용어 변형**:
   - 한국어 "청바지" (靑+바지) = 일본어 ジーンズ 차용 후 한자어 결합. 영어 "jeans" / 중국어 牛仔裤 (niúzǎikù, 牛+仔+裤) = "소+아기+바지" 직역.
   - **함정**: 한국어 학습자가 중국어 牛仔裤 를 "청바지" 와 직접 매칭 → 사실 한자 차용 경로 다름.
   - **훈련법**: Jeans 의 언어별 매핑 — EN jeans / JP ジーンズ (jeans 차용) / KR 청바지 (靑+바지) / CH 牛仔裤 (牛仔+裤, 牛=소). 문화별 어휘화 학습.

4. **"양말/Socks/袜子" 의 한자 공유**:
   - 袜 (KR 양말 / JP 靴下 / CH 袜) — 한국어 한자 末 (마지막) 의 합성어 vs 일본어 靴下 (신발+아래) vs 중국어 袜 (단일 한자).
   - **함정**: 한국어 학습자가 일본어 靴下 와 중국어 袜 의 어휘 구조 차이 인지 부족.
   - **훈련법**: 양말 어휘 매핑 — KR 양말 (양+末) / JP 靴下 (kutsushita) / CH 袜 (wà) / EN socks. 구조 차이 학습.

5. **"치마(Skirt)/裙子" 의 한자 공유**:
   - 裙 (KR 치마 / CH qúnzi) — 한국어 한자 차용어 vs 중국어 裙子 (qún+zi 양사 결합).
   - **함정**: 한국어 학습자가 중국어 裙子 를 발음 유사성으로 "치마" 와 동일시 → 사실 중국어 裙 는 명사 단독, 裙子 는 양사 결합.
   - **훈련법**: 치마 어휘 매핑 — KR 치마 (한자) / CH 裙 (qún) + 子 (zi 양사) / JP スカート (skirt 차용) / EN skirt / ES falda. 문화별 어휘화 학습.

### 학습 전략

1. **우선순위 1**: 한국어 의류 입기 동사 구분 (입다/신다/쓰다) 마스터 — 일상 의류 어휘.
2. **우선순위 2**: 의류 기본 어휘 30개 마스터 — 셔츠/바지/신발/재킷/모자/장갑/가방 등.
3. **우선순위 3**: 한자 의류 어휘 매칭 — 衫/裤/鞋/帽/袜/裙 의 JP/KR/CN 발음 + 한국어 토착어 결합 차이.
4. **우선순위 4**: 전통 의상 매핑 — 한복/韓服/和服/kimono 의 4개 문화별 구분.
5. **우선순위 5**: 패션 어휘 (사이즈/색깔/스타일/패션/브랜드) 의 5언어 매핑.
