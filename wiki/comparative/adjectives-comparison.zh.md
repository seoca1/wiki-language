## 语言学特征

| 模式 | English | Spanish | Japanese | Korean | Chinese |
|------|---------|---------|----------|--------|---------|
| **性数一致** | 无 (除了 this/that) | 必须 (bueno/buena) | 无 | 无 | 无 |
| **复数形式** | -s/-es (books) | -s/-es (libros); 形容词不变 | 无 | 无 | 无 (的) |
| **位置 (默认)** | 名前 (big house) | 名后 (casa grande) | 名前 (大きい家) | 名前 (큰 집) | 名前, 常+的 (大的房子) |
| **形容词形** | 无屈折 (good book) | -o/-a 必须一致 | -i (い-adj) / -na (な-adj) | -ㄴ/-은 (辅音/元音) | 裸形 (好书) 或 的 (好的书) |
| **比较级** | -er / more (bigger) | más + adj (más grande) | より (yori) | 더 (deo) | 更 (gèng) / 比 (bǐ) |
| **最高级** | -est / most (biggest) | el más + adj | 一番 (ichiban) | 가장 (gajang) | 最 (zuì) |

## 各语言详情

### 🇬🇧 英语 (English)
- **核心**: 等级化 (big, very big) vs 非等级化 (perfect, *very perfect ✗); 定语 vs 表语
- **模式**: 顺序规则: opinion-size-age-shape-color-origin-material (例: "big old red wooden box")
- **来源**: `[[adjectives-vocabulary]]`

### 🇪🇸 西班牙语 (Spanish)
- **核心**: 形容词与名词性数一致; "bueno/buena", "malo/mala"; "grande" 单数名短缩为 "gran"
- **模式**: 位置取决于含义 (默认名后; 部分名前表强调: "pobre hombre" = 不幸的人)
- **来源**: `[[adjectives-vocabulary]]`

### 🇯🇵 日语 (Japanese)
- **核心**: い形容词 (白い shiroi) と な形容词 (静かな shizuka na); 两者都按时态变化
- **模式**: 形容词直接修饰名词无需助词; 过去形 -かった (katta); 否定 -くない (kunai)
- **来源**: N/A — 日语 wiki 暂无形容词专题

### 🇰🇷 韩语 (Korean)
- **核心**: 描述性动词 (형용사, hyeong-yongsa) 像动词一样变化; 좋다 → 좋은 / 좋습니다 / 좋아요
- **模式**: 过去 -았/었-; 否定 -지 않다; 名词修饰用 -(으)ㄴ: 좋은 사람 (good person)
- **来源**: N/A — 韩语 wiki 暂无形容词专题

### 🇨🇳 中文 (Chinese)
- **核心**: 单音节 vs 双音节; 的 (de) 对短形容+名可选
- **模式**: 无屈折; 程度副词 很 (hěn) 常用即使不是 "very": 很好 = "好"
- **来源**: N/A — 中文 wiki 暂无形容词专题

## 关键对比 (综合)

| 对比 | 洞察 |
|------|------|
| **性数一致** | 唯独西班牙语要求; EN/JP/KR/ZH 无 |
| **位置** | 西班牙语默认名后; 其他4语言名前 |
| **形容词作动词** | JP/KR 像动词一样变化 (时态); EN/ES/ZH 作名词修饰 |
| **程度词** | ZH 很 (hěn) 频繁使用 → 近似语法助词; EN/ES/JP/KR 需明确 "very" |
| **比较级** | EN 用屈折 (-er/-est); ES/JP/KR/ZH 用独立词 (más/より/더/更) |

## 🇨🇳 中文学习者笔记 (Chinese Learner Notes)

> 本节是面向中文母语学习者的额外学习指南。

### 中文母语者在学习其他4种语言形容词时的常见陷阱

1. **无屈折假设**:
   - 中文 *好的/坏的* 无变化 → 学员假设其他语言也如此。
   - **陷阱**: 西班牙语 bueno/buena 性数一致; 韩语 좋다→좋은/좋습니다/좋아요; 日语 いい→良い/良かった/よくない。
   - **训练法**: 每日 5 形容词变位练习 (5 语言轮换)。

2. **"很 (hěn)" 是程度词还是默认助词**:
   - 中文 *很好* 实际含义 = "好" (常省略 much) → 学员在其他语言也跳过 very。
   - **陷阱**: 英语 "I'm good" 不加 very; 但 "I'm very good" 含义不同。日语 *いい* 也常独立使用。
   - **训练法**: 整理 *很 在中文是默认助词* vs *其他语言需要明确 very* 的对比。

3. **性的不一致**:
   - 中文无性 → 学员对西班牙语形容词阴阳性感到困惑。
   - **陷阱**: *bueno/buena*, *rojo/roja*, *alto/alta* 数百对必须记忆。
   - **训练法**: 每学一个形容词记忆阳性-阴性-单数-复数4个形式。

4. **比较级 (比) 的多义**:
   - 中文 *比 X 更 Y* → 学员假设其他语言用同一结构。
   - **陷阱**: 英语 "X is bigger than Y" 或 "X is more big than Y"; 日语 *X より Y* (X compared to Y); 韩语 *X 보다 Y* (X over Y)。
   - **训练法**: 比较级结构对比表 (CN 比 vs EN -er than vs ES más + adj que vs JP X より Y vs KR X 보다 Y)。

5. **完成时 vs 进行体形容词**:
   - 中文 *吃了 / 正在吃* → 学员对日韩动词性形容词困惑。
   - **陷阱**: 日语 *食べた (eaten)* 形容词变化; 韩语 *먹은 (eaten)* 与 *먹고 있는 (eating)* 都需要修饰形式。
   - **训练法**: 学习 -ㅂ/-은 (过去修饰) vs -는 (现在修饰) 在 KR/JP 的用法。
