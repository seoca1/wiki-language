## 언어별 상세

### 🇬🇧 영어 (English)
- **핵심 용어**: "Hue", "Tint", "Shade", "Tone"; 1차 (red/yellow/blue) vs 2차 (orange/green/purple)
- **출처**: `[[colors-vocabulary]]`

### 🇪🇸 스페인어 (Spanish)
- **핵심 용어**: "Rojo" / "Roja" (성 일치); "Anaranjado" (오렌지색) vs "Naranja"
- **패턴**: 형용사는 명사 성별 일치 필수 (rojo/roja, blanco/blanca)
- **출처**: N/A — 스페인어 색상 테마 미정

### 🇯🇵 일본어 (Japanese)
- **핵심 용어**: 色 (iro = 색); 色彩 (shikisai); 色合い (iroai = 색조)
- **패턴**: 형용사: 〜い (kurompai); 명사+の: 赤の (aka no)
- **출처**: `[[colors-vocabulary]]` (제한적 — 기본만)

### 🇰🇷 한국어 (Korean)
- **핵심 용어**: 색깔 (saekkka), 색 (saek = 색); 노란색/빨간색 (색 + 접미사)
- **패턴**: 형용사가 명사 직접 수식 (성 일치 없음)
- **출처**: `[[colors-vocabulary]]`

### 🇨🇳 중국어 (Chinese)
- **핵심 용어**: 颜色 (yánsè), 色彩 (sècǎi); 五色 (wǔsè = 전통 5색)
- **패턴**: 형용사 + 的 (de) + 명사: 红色的书
- **출처**: N/A — 중국어 색상 테마 미정

## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 색상을 배울 때 흔히 마주치는 함정

1. **일본어 青 (ao) 의 파랑+초록 포괄**:
   - 한국어 학습자는 파랑/초록 구분 명확 → 일본어 青 가 두 색을 모두 뜻한다는 점이 매우 낯설.
   - **함정**: 일본어 青信号 = "green light" (초록불), 青い空 = "blue sky" (파란 하늘) — 한국어 사고로 "青 = 파랑/초록 무엇?" 혼란.
   - **훈련법**: 일본어 색상 어휘의 맥락 의존성 학습 — 신호등, 하늘, 바다(青) vs 풀, 채소(緑) 의 맥락별 청/녹 사용. 또한 ブルー (burū) 와 グリーン (guriin) 도 각각 존재 — 외래어 색상 사용 가능.

2. **스페인어 성 일치 (rojo/roja, blanco/blanca)**:
   - 한국어 학습자에게 "rojo vs roja" 의 성별 구분은 매우 낯설 — 한국어 색상 형용사는 성별 무관 (빨간, 검은 모두 성별 없음).
   - **함정**: "Libro rojo" (남성 명사 libro = 빨간) vs "Casa roja" (여성 명사 casa = 빨간) — 명사 성별에 따라 형용사 어미 변경.
   - **훈련법**: 스페인어 12개 기본 색상의 4형태 암기 (남성단수/여성단수/남성복수/여성복수). 빨강: rojo/roja/rojos/rojas, 검정: negro/negra/negros/negras, 흰색: blanco/blanca/blancos/blancas.

3. **한국어 색상 접미사 (-ㄴ/은 + 색) vs 다른 언어**:
   - 한국어 색상 형용사는 "빨간/파란/노란" 처럼 -ㄴ/-은 패턴. 중국어는 红色 (hóngsè) 처럼 "색 + sòng" — 다른 구조.
   - **함정**: 한국어 학습자가 중국어 红色 를 "빨강-색" 으로 단순 분해 — 의미는 같으나 구조 다름. 영어 red (단일 단어), 일본어 赤 (단일 한자) 와 더 가까움.
   - **훈련법**: 색상 어휘의 구조 차이 학습 — EN 단일 단어 (red) / ES 성별 변화 (-o/-) / JP 단일 한자 + い / KR -ㄴ 형용사 + 색 명사 / CH 색 + 的.

4. **문화적 상징성 (백 = 상(喪) in JP/KR/CN)**:
   - 한국어 학습자에게 백색은 전통 상복 (한복 흰색) — 일본/중국과 공유. 그러나 서양에서는 wedding dress.
   - **함정**: 영어 wedding → white dress 정상. 그러나 일본/중국/한국 전통 결혼식 → 빨간/금색 의상; 백색은 장례.
   - **훈련법**: 문화별 색상 상징 학습 — 백색 (KR wedding dress 아님, JP funeral) / 적색 (KR CN 행운) / 청색 (JP 영적) / 황색 (CN royal). weddings/funerals/임신/luck 의 색상 코드 차이.

5. **합성 색색의의 한자 매칭 (남색/남색 藍/靛蓝)**:
   - 한국어 "남색" = dark blue (靛蓝 diànlán 의 한자어). 일본어 藍 (ai) = indigo. 중국어 靛蓝 (diànlán) = indigo.
   - **함정**: 한국어 학습자가 남색 을 "남+색" 으로 분해 (남자+색?) — 실제로는 藍 + 色. 일본어 藍 (ai) 의 독음을 모르면 藍色 발음 어려움.
   - **훈련법**: 한자 색상 어휘 학습 — 紅(홍)/赤(적)/青(청)/藍(남)/綠(녹)/黃(황)/白(백)/黑(흑)/紫(자)/粉(분)/金(금)/銀(은) 의 JP/KR/CN 발음 매칭.

### 학습 전략

1. **우선순위 1**: 한국어 색상 형용사 -ㄴ/-은 패턴 마스터 (빨간/파란/노란) + 색 명사 결합 (빨강/파랑/노랑).
2. **우선순위 2**: 스페인어 색상 12개 × 4형태 (성별/수) 암기 — rojo/roja/rojos/rojas.
3. **우선순위 3**: 일본어 青 (ao) 의 파랑/초록 포괄 + 맥락별 사용 (青信号 vs 緑信号 외 없음).
4. **우선순위 4**: 한자 색상 어휘 JP/KR/CN 매칭 (10개 기본 한자 × 3언어).
5. **우선순위 5**: 문화적 색상 상징 (결혼/장례/행운/불운) 의 문화별 차이 학습.
