# Grammar Cross-Language Comparison

**Languages**: English · Spanish · Japanese · Korean · Chinese
**Last updated**: 2026-08-11

> High-level grammatical architecture across the 5 languages: word order, tense/aspect, articles, politeness markers.

| Feature | English | Spanish | Japanese | Korean | Chinese |
|---------|---------|---------|----------|--------|---------|
| **Word order** | SVO | SVO | SOV | SOV | SVO |

| **Aspect system** | Progressive (-ing), perfect (have+V-ed) | Progressive (-ndo), perfect (-ado) | -te iru (progressive), -te shimau (completive) | -고 있다 (progressive), -아/어 있다 (state) | 着 (progressive), 了 (completive), 过 (experiential) |
| **Articles** | a / an / the | el / la / un / una | None | None | None |
| **Gender** | None (natural gender) | Masculine / Feminine | None | None | None |

| **Pronoun dropping** | Required | Required | Common (zero-pronoun) | Common | Common |

## Per-Language Detail

### English
- **Key terms**: SVO, articles (a/an/the), tense-aspect, do-support
- **Patterns**: Tense obligatory; articles required on singular count nouns
- **Sources**: `[[wiki/English/grammar/grammar-overview]]`

### Spanish
- **Key terms**: SVO, gender agreement, ser vs estar, subjunctive mood
- **Patterns**: Verb conjugates for person/number; subjunctive for doubt/desire/emotion
- **Regional variations**: Voseo (Rioplatense); vosotros (Spain) vs ustedes (LatAm)
- **Sources**: `[[wiki/Spanish/grammar/grammar-overview]]`

### Japanese
- **Key terms**: SOV, particles (は/が/を/に/で/へ), keigo
- **Patterns**: Topic-comment (は/が); verb always final
- **Keigo / politeness level**: 尊敬語 (respect), 謙譲語 (humble), 丁寧語 (polite)
- **Sources**: `[[wiki/Japanese/grammar/grammar-overview]]`

### Korean
- **Key terms**: SOV, particles (은/는/이/가/를/을), speech levels
- **Patterns**: Topic 는/은, subject 가/이; verb always final
- **Speech level**: 합쇼체 formal / 해요체 polite / 해체 plain / 하소서체 literary
- **Sources**: `[[wiki/Korean/grammar/grammar-overview]]`

### Chinese
- **Key terms**: SVO, aspect particles (了/过/着), measure words
- **Patterns**: Verbs don't conjugate; aspect particles mark time-flow
- **Register / honorifics**: 您 (nín) honorific; measure words mandatory (个/本/杯/张)
- **Sources**: `[[wiki/Chinese/grammar/grammar-overview-zh]]`

## Key Contrasts (Synthesis)

| Contrast | Implication for Learners |
|----------|--------------------------|
| **Word order family** | EN/ES/CH = SVO; JP/KR = SOV. SOV learners can directly map to JP/KR |
| **Articles** | EN/ES require articles on count nouns; JP/KR/CH have none |
| **Politeness depth** | JP/KR have full verb-based politeness; EN/ES/CH rely on pronouns/word choice |
| **Tense vs aspect** | EN/ES mark tense morphologically; CH uses aspect particles; JP/KR mix both |
