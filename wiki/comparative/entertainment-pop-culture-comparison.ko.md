- **출처**: N/A — 스페인어 오락 테마 미정

### 🇯🇵 일본어 (Japanese)
- **핵심 용어**: "Anime" = 일본 애니메이션; "Manga" = 일본 만화
- **패턴**: 산업 수직 통합 (manga → anime → merchandise); 성우 (声優 = seiyū) 가 유명인
- **출처**: `[[entertainment-vocabulary]]`

### 🇰🇷 한국어 (Korean)
- **핵심 용어**: "K-drama", "K-pop", "Webtoon" (디지털 만화); "Manhwa" = 한국 만화
- **패턴**: 스트리밍 중심 산업; 정주행 (전편 일괄 시청) 문화 개념
- **출처**: `[[entertainment-vocabulary]]`

- **패턴**: 장르 혼합 흔함 (드라마 + 예능 + 게임); 饭圈 (fànquān = 팬덤) 문화

## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 오락 어휘를 배울 때 흔히 마주치는 함정

1. **"정주행(Jeonghaeng)" 의 한국 고유성**:
   - 한국어 "정주행" = TV 시리즈를 밤새/연속으로 전편 시청 — 다른 4개 언어에 직접 대응 없음. 영어 binge-watching, 일본어 一気見 (ikimi), 중국어 刷剧 (shuājù) 모두 부분 대응.
   - **함정**: 한국어 학습자가 영어 "binge-watching" 을 "정주행" 으로 단순 번역 → 정주행 의 한국적 의미 (K-드라마/웹툰/웹소설 문화와 결합) 무시.
   - **훈련법**: 정주행 어휘화 — 정주행하다 / 정주행 추천 / 정주행 각오. 5언어 매핑 (binge-watching/一気見/정주행/刷剧/maratón de series) 의 문화적 강조점 비교.

2. **"K-드라마/K-pop"의 글로벌 글로벌 수출**:
   - 한국어 "K-드라마" "K-pop" 은 이미 글로벌 어휘 — 다른 4개 언어에서 차용. 영어 K-drama/K-pop, 일본어 韓流 (kanryū), 중국어 韩流 (hánliú).
   - **함정**: 한국어 학습자가 일본어/중국어에서 한류 (韓流/韩流) 의 "한" = 한국 의미 인지 부족 → 중국 한자 한 (韓/韩) 의 발음 차이.
   - **훈련법**: 한류 어휘 매핑 — KR 한류 (hallyu) / JP 韓流 (kanryū) / CH 韩流 (hánliú) / EN Korean Wave / ES Ola coreana. 한자 한 (韓/韩) 의 두 형태 매칭.

3. **"웹툰(Webtoon)" 의 한국 디지털 만화**:
   - 한국어 "웹툰" = 웹 + 만화 (cartoon) 의 결합 — 한국 발 신조어. 영어 "webtoon" 으로 글로벌 차용. 일본어 ウェブトゥーン, 중국어 网络漫画 (wǎngluò mànhuà).
   - **함정**: 한국어 학습자가 영어 webtoon 을 단순 "webcomic" 으로 번역 → 한국 웹툰 의 세로 스크롤/모바일 최적화/플랫폼 특성 무시.
   - **훈련법**: 웹툰 어휘 학습 — KR 웹툰 (Web + cartoon) / JP ウェブトゥーン (외래어) / CH 网络漫画 (web cartoon) / EN webtoon (직접 차용). 일본어 만화 漫画 와 구분.

4. **"한국 만화 manhwa vs 일본 만화 manga"**:
   - 한국어 "만화" = 일본어 漫画 (manga) 의 한자어 차용 — 그러나 한국에서는 "manhwa" (한국 발음) 와 "manga" (일본) 구분 사용. 중국어 漫画 (mànhuà).
   - **함정**: 한국어 학습자가 일본어 漫画 를 한국어 "만화" 로 단순 번역 → 한국 만화 vs 일본 만화 의 문화적 구분 무시.
   - **훈련법**: 한자 漫画 의 3개 언어 발음 — KR 만화 (manhwa) / JP 漫画 (manga) / CH 漫画 (mànhuà). 문화적 매체 차이 (KR 웹툰 강세, JP 인쇄 만화 강세, CH 漫画 인쇄+웹 혼재).

5. **"팬덤(Fandom) 의 한국의 차용"**:
   - 한국어 "팬덤" = 영어 "fandom" 의 차용 — 그러나 일본어 推し活 (oshikatsu) 와 중국어 饭圈 (fànquān) 는 각자 고유한 팬덤 어휘 보유.
   - **함정**: 한국어 학습자가 일본어 推し活 를 "팬덤" 으로 단순 번역 → 推し (oshi, 좋아하는 사람) + 活 (katsu, 활동) 의 고유 일본 팬덤 문화 무시.
   - **훈련법**: 팬덤 어휘 비교 — KR 팬덤 (영어 차용) / JP 推し活 (일본 고유) / CH 饭圈 (fan circle, 중국 고유) / EN fandom / ES fandom. 팬 문화의 차이 인식.

### 학습 전략

1. **우선순위 1**: 한국어 K-드라마/K-pop/Webtoon/한류 어휘 마스터 — 한국 대중문화 수출 관련 핵심 어휘.
2. **우선순위 2**: 정주행 의 한국 고유 의미 + 5언어 매핑 (binge-watching/一気見/정주행/刷剧/maratón).
3. **우선순위 3**: 한자 오락 어휘 매칭 (映/漫/音/劇/楽 의 JP/KR/CN 발음 + 결합 단위.
4. **우선순위 4**: 장르 어휘 (액션/코미디/로맨스/공포/SF/판타지) 의 5언어 매핑.
5. **우선순위 5**: 팬덤 어휘 5언어 (팬덤/推し活/饭圈/fandom/fandom) 의 문화적 강조점 비교.
