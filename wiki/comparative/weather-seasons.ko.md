## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 날씨/계절을 학습할 때 흔히 마주치는 함정

1. **한자 한자어 날씨 어휘 발음 차이**:
   - 같은 한자 날씨 어휘가 한국어/일본어/중국어에서 발음 다름. 예: 雨: 한국 한자음 "우" vs 일본 "あめ (ame)" vs 중국 "yǔ". 한자 一 글자당 3개국 발음.
   - **함정**: 한국어 한자음 "춥다" (寒冷) 다른 4개 언어 발음 추정 → "samui" / "lěng" 와 다름.
   - **훈련법**: 날씨 한자 한자어 3개국 발음 매트릭스 — 雨/우/yǔ, 雪/눈/xuě, 寒/춥다/lěng, 熱/덥/rè, 風/바람/fēng. 한자 1글자 = 3개국 발음.

2. **한국어 "덥다/춥다" vs 다른 4개 언어 어미 변화**:
   - 한국어: 덥다 → 더워요 (해요체) / 덥습니다 (합쇼체) / 덥 (해체). ㄷ 불규칙 활용.
   - 영어: hot (단일).
   - 스페인어: caliente (단일).
   - 일본어: 暑い (단일) / 暑かった (과거).
   - 중국어: 热 (단일).
   - **함정**: 한국어 학습자가 다른 4개 언어에 한국어 ㄷ 불규칙 활용 적용 → 영어 "hot" / 스페인어 "caliente" 단순 매핑 어색.
   - **훈련법**: ㄷ 불규칙 활용 매트릭스 — 덥다/춥다/돕다/짓다 등. **한국어 고유 활용 학습**.

3. **계절 표현 한자 한자어 3개국 + 영어 매트릭스**:
   - 한국어/일본어/중국어: 春/봄/chūn, 夏/여름/xià, 秋/가을/qiū, 冬/겨울/dōng. **한자 1글자 = 3개국**.
   - 영어: spring/summer/autumn/winter. 게르만.
   - 스페인어: primavera/verano/otoño/invierno. 라틴.
   - **함정**: 한국어 학습자가 영어 "spring" 단순 매핑 → 스페인어 primavera / 일본어 はる (haru) / 중국어 chūn 다름.
   - **훈련법**: 계절 5개 언어 매트릭스 — 한자 3개국 + 라틴/게르만 2개국. **5개 어원 시스템 비교**.

4. **"장마 (Jangma)" 의 한국어 고유성**:
   - 한국어 "장마" = 한국 **비철 (rainy season, June-August)**. 동아시아 문화 (일본 梅雨 tsuyu, 중국 梅雨 méiyǔ, 한국 장마 jangma) 모두 비슷한 현상.
   - 영어 "rainy season" / 스페인어 "temporada de lluvias" — 단순.
   - **함정**: 한국어 학습자가 영어 "rainy season" 단순 매핑 → 한국 장마의 **계절풍 + 동아시아 특성** 손실.
   - **훈련법**: **동아시아 3개국 비철** — 한국 장마 / 일본 梅雨 / 중국 梅雨. **한자 1글자 = 3개국 + 계절풍**.

5. **"황사 (Hwangsa)" 의 한국어 고유성**:
   - 한국어 "황사" = 중국에서 부는 **황사 (Yellow Dust)**. 한국어 "황사" (hwangsa) / 일본어 "黄砂 (kōsa)" / 중국어 "沙尘暴 (shāchénbào)".
   - **함정**: 한국어 학습자가 영어 "yellow dust" 단순 매핑 → 한국 황사 / 일본 黄砂 / 중국 沙尘暴 한자 한자어 매트릭스.
   - **훈련법**: **동아시아 3개국 황사** — 한국 황사 / 일본 黄砂 / 중국 沙尘暴. **한자 1글자 = 3개국 + 동일 자연 현상**.

6. **"꽃가루 알레르기" 의 한국어 특이성**:
   - 한국어 "꽃가루 알레르기" = 한국 **봄 꽃가루 알레르기** 매우 일반. 일본 花粉症 (kafunshō) / 중국 花粉过敏 (huāfěn guòmǐn) / 한국 꽃가루 알레르기 모두 비슷.
   - 영어 "hay fever" / "pollen allergy" — 단순.
   - **함정**: 한국어 학습자가 영어 "hay fever" 단순 매핑 → "꽃가루 알레르기" 의 한국 문화적 강조도 손실.
   - **훈련법**: **동아시아 3개국 꽃가루 알레르기** — 한국 꽃가루 알레르기 / 일본 花粉症 / 중국 花粉过敏. **3개국 매트릭스**.

### 학습 전략

1. **우선순위 1**: 날씨 한자 한자어 3개국 발음 매트릭스 — 雨/우/yǔ, 雪/눈/xuě, 寒/춥다/lěng, 熱/덥/rè, 風/바람/fēng. **한자 1글자 = 3개국 발음**.
2. **우선순위 2**: 한국어 ㄷ 불규칙 활용 — 덥다/춥다/돕다/짓다. **한국어 고유 활용 학습**.
3. **우선순위 3**: 계절 5개 언어 매트릭스 — 한자 3개국 (春/夏/秋/冬) + 라틴/게르만 2개국. **5개 어원 시스템 비교**.
4. **우선순위 4**: 동아시아 3개국 자연 현상 — 비철 (장마/梅雨/梅雨) / 황사 (황사/黄砂/沙尘暴) / 꽃가루 알레르기. **동아시아 한자 자연 현상 매트릭스**.
5. **우선순위 5**: 한국어 날씨 관용구 — "폭우가 내린다" (倾盆大雨) / "몸이 안 좋다" (不舒服) / "찻잔 속의 폭풍" (茶杯里的风波). **5개 언어 관용구 매트릭스**.
