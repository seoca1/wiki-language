# 방언 변이 패턴 — Cross-Language Comparison (한국어판)

## 빠른 참조 표

### 방언 변이 패턴 (5언어 비교)

| 언어 | 주요 방언 그룹 | 발음 | 어휘 | 문법 |
|---|---|---|---|---|
| **Spanish** | castellano, mexicano, rioplatense, andino, caribeño | s/θ 구분, yeísmo, seseo | 지역 어휘 (coche/carro/auto) | voseo, leísmo, ustedes |
| **English** | RP, General American, Australian, Indian 등 | rhoticity, 모음 품질 | 지역 슬랭 (sub/bus) | tag questions, y'all |
| **Japanese** | 東京弁, 関西弁, 広島弁, 博多弁 | 모음 피치 액센트 | 関西弁 어휘 | 敬語 단계 |
| **Korean** | 서울, 부산, 제주 방언 | ㄹ/l 실현 | 지역 어휘 | 경어 변이 |
| **Chinese** | 普通话, 粤语, 闽南语, 吴语 | 성조 시스템, 후치경음 | 지역 어휘 | 문장 종결 조사 |

| **Japanese** | 가장 층위화된 격식 시스템 (敬語) + 지역 액센트 (方言). |

| **Korean** | 가장 중앙화된 표준 (서울말) + 지역 변이는 덜 위신적. |

## 언어별 상세

### 🇪🇸 스페인어 방언

| 측면 | 상세 |
|------|------|
| **주요 변이** | 스페인 vs 멕시코 vs 리오플라텐세 vs 안디노 vs 카리브 |
| **발음 변이** | s/θ 구분 (스페인 castellano: casa = "kaθa" vs 라틴아메리카: "kasa"), yeísmo (ll/y 모두 [ʝ]), seseo (s/c 전부 [s]) |
| **어휘 변이** | 자동차 = coche (스페인) / carro (멕시코) / auto (라틴아메리카 일부) |
| **문법 변이** | voseo (아르헨티나: vos tenés instead of tú tienes), leísmo (스페인: le instead of lo for 남성 직접 목적어), ustedes (라틴아메리카 vosotros 대체) |

### 🇬🇧 영어 방언

| 측면 | 상세 |
|------|------|
| **주요 변이** | RP (Received Pronunciation), General American, Australian, Indian, Scottish, Irish 등 |
| **발음 변이** | rhoticity (r 발음: 미국 우세, RP 비우세), 모음 품질 (cot/caught 미국 합류 vs 영국 구분) |
| **어휘 변이** | 서브/버스 (US/UK), 엘리베이터/리프트 (US/UK) |
| **문법 변이** | tag questions (UK 흔함), y'all (Southern US), ain't (UK 일부, US South) |

### 🇯🇵 일본어 방언

| 측면 | 상세 |
|------|------|
| **주요 변이** | 東京弁 (도쿄), 関西弁 (오사카/교토), 広島弁 (히로시마), 博多弁 (하카타/후쿠오카) |
| **발음 변이** | 모음 피치 액센트 (東京 = 헤보네, 京都 = 京都, 大阪 = 大阪) |
| **어휘 변이** | 関西弁 "食べへん/食べやん" vs 표준 "食べない" / "違うやん" vs "違うよ" |
| **문법 변이** | 敬語 (sonkeigo, kenjongo, teineigo) 의 지역 차이 — 京都/오사카 여성 敬語 변화 |

### 🇰🇷 한국어 방언

| 측면 | 상세 |
|------|------|
| **주요 변이** | 서울 (표준), 부산/경남, 제주, 강원 (영동/영서), 충청, 전라도 |
| **발음 변이** | ㄹ/l 실현 (부산: "사람" = "사람", 표준: "사람"), ㄱ/ㅋ 변이 (전라도: "코" = "고"), ㅓ/ㅡ 변이 (강원: "말" = "믈") |
| **어휘 변이** | 서울 "아이고" / 부산 "에이그" / 제주 "헤이" / 전라도 "아따" |
| **문법 변이** | 경어 변이 (서울 표준 vs 부산/전라도 더 격식 약함), 종결 어미 변이 |

### 🇨🇳 중국어 방언

| 측면 | 상세 |
|------|------|
| **주요 변이** | 普通话 (북방 만다린), 粤语 (광둥/홍콩), 闽南语 (대만 일부), 吴语 (상하이), 湘语, 赣语 등 |
| **발음 변이** | 성조 시스템 (만다린 4성 vs 광둥 6-9성), 후치경음 (만다린 zh/ch/sh vs 광둥 없음) |
| **어휘 변이** | "밥" = 饭 (fàn) 만다린 / 飯 (faahn) 광둥 / 兮 (ê) 일부 변이 |
| **문법 변이** | 문장 종결 조사 변이 (광둥 喎 wo3, 嘅 ge3, 嚟 lei4) |

## 학습자 의사결정 가이드

- **마스터해야 할 첫 10 표현 (각 언어 표준 변종)**:
  - Spanish: coche (스페인) / carro (멕시코) / auto (라틴아메리카 일부)
  - English: sub (US) / bus (UK)
  - Japanese: 食べる (taberu) 표준 / 食べへん (tabehen) 関西弁
  - Korean: 사람 (saram) 표준 / 사랄 (saral) 부산
  - Chinese: 吃饭 (chī fàn) 만다린 / 食飯 (sik faahn) 광둥

## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 방언 변이를 배울 때 흔히 마주치는 함정

1. **"서울말" 의 표준 = 위신 언어 신호**:
   - 한국어 학습자는 "서울말" 을 표준으로 학습 → 부산/전라도/제주 방언을 "비표준/시골" 로 인식. 그러나 다른 4개 언어에서도 표준 변종 우세.
   - **함정**: 한국어 학습자가 부산 사투리 (예: "뭐하노" "안심이니")를 "틀린 한국어" 로 이해 → 부산/전라도 자존심 손상.
   - **훈련법**: 한국 방언 존중 학습 — 부산/경남/전라도/제주/강원 방언의 독립적 미덕 (외래어 차용 다름, 억양 특징). 사투리 매체 (영화, 드라마) 활용 학습.

2. **스페인어 voseo 의 한국어 매핑 부재**:
   - 스페인어 voseo (아르헨티나: vos tenés) 는 한국어에 없는 2인칭 대명사 변종. 한국어 너/당신/그쪽 3종도 변이이나 시제 변화 없음.
   - **함정**: 한국어 학습자가 스페인어 voseo 를 "너" (tú) 와 동일시 → "vos" 의 활용 변화 무시.
   - **훈련법**: 스페인어 voseo 활용 — vos tenés (네가 가지고 있다) / vos sos (네가 이다) / vos querés (네가 원한다) — tú 와 다른 굴곡. 아르헨티나/파라과이/우루과이 한정 사용.

3. **중국어 粤语 (광둥어) vs 普通话 의 상호 이해 불가**:
   - 한국어 학습자가 중국어 普通话 만 학습 → 粤语 (홍콩) 만나면 거의 이해 불가. 한국어 방언도 차이 있으나 (서울 vs 부산) 상호 이해 가능.
   - **함정**: "중국어 알아" 가 普通话 만 의미 → 粤语 사용자와 의사소통 실패.
   - **훈련법**: 중국어 변종 학습 — 普通话 (4성, 8-9천 한자) vs 粤语 (6-9성, 1천+ 어휘 차이) vs 闽南语 vs 吴语. 한자는 공유하나 발음/어휘 매우 다름.

4. **일본어 関西弁 의 "부정" 어미**:
   - 일본어 関西弁 "食べへん/食べやん" (먹지 않아) vs 표준 "食べない" — 한국어 "안 먹어요" vs "먹지 않아요" 의 격식 차이와 유사.
   - **함정**: 한국어 학습자가 関西弁 을 "틀린 일본어" 로 이해 → 関西 자존심 문화 (도쿄 우월 의식에 대한 반발) 무시.
   - **훈련법**: 関西弁 의 어미 변이 — ない → -へん (오사카) / -やん (교토) / -ん (고베). 食べてる → 食べとる (관서) — 진행형 변이.

5. **영어 방언 = "비표준" 인지의 위험**:
   - 한국어 학습자가 영어 RP/BBC 영어 = 표준으로 학습 → 미국/호주/인도 영어 변이 무시. 그러나 모든 영어 변종이 동등하게 위신.
   - **함정**: "Black English" / "Indian English" / "Australian English" 를 "비표준" 으로 무시.
   - **훈련법**: 영어 변종의 동등성 학습 — RP (영국, 위신) / General American (미국) / Australian / Scottish / Indian / Singaporean. 영화/드라마로 다양한 변종 노출.

### 학습 전략

1. **우선순위 1**: 한국어 표준 (서울말) 마스터 + 부산/전라도/제주 기본 인사 어휘 — 최소한의 지역 이해.
2. **우선순위 2**: 스페인어 voseo 변종 (아르헨티나/파라과이) — vos 활용 변화 마스터.
3. **우선순위 3**: 중국어 변종 인식 — 普通话 vs 粤语 vs 吴语 — 1개 이상 기본 어휘 학습.
4. **우선순위 4**: 일본어 関西弁 기본 어미 (-へん, -やん) — 최소한의 오사카 문화 이해.
5. **우선순위 5**: 영어 변종 다양성 인식 — RP/GA/Australian/Indian 동등성 학습.
