## 언어별 상세

### 🇬🇧 영어 (English)
- **핵심 용어**: "Trail" (표시된 길), "Summit" (도달한 봉우리), "Base camp" (출발점)
- **패턴**: "Go hiking" / "Go camping" — 동사 + gerund 일반적
- **출처**: `[[adventure-vocabulary]]`, `[[travel-essentials]]`

### 🇪🇸 스페인어 (Spanish)
- **핵심 용어**: "Senderismo" (스페인), "Andinismo" (안데스 지역); "Refugio" = 산장
- **패턴**: -ismo 명사; "hacer senderismo" = 하이킹하다
- **출처**: N/A — 스페인어 모험 테마 미정

### 🇯🇵 일본어 (Japanese)
- **핵심 용어**: 登山 (tozan = 산악 등반), 縦走 (jūsō = 능선 횡단), 山小屋 (yamagoya = 산장)
- **패턴**: 동사: 〜をする; 존경어: 気をつけて (ki wo tsukete = 조심하세요)
- **출처**: `[[adventure-vocabulary]]`

### 🇰🇷 한국어 (Korean)
- **핵심 용어**: 등산 (deungsan), 등산로 (deungsanno), 등산객 (deungsangaek = 등산인)
- **패턴**: 동사: 〜을/를 가다 (하러 가다); 산 (san) 이 많은 복합어에 등장
- **출처**: `[[adventure-vocabulary]]` (현재 EN/JP only — KR 예정)

### 🇨🇳 중국어 (Chinese)
- **핵심 용어**: 登山 (dēngshān), 徒步 (túbù), 户外 (hùwài = 야외)
- **패턴**: 동사: 〜去 (qù = 가다); 양사: 座山 (zuò shān = 산의 분류사)
- **출처**: N/A — 중국어 모험 테마 미정

## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 야외/모험 어휘를 배울 때 흔히 마주치는 함정

1. **"등산(deungsan)" 문화의 의역 함정**:
   - 한국어 화자에게 "등산" 은 거의 국민 활동 (주말 등산, 100대 명산, 북한산/한라산) → 영어 "hiking" 이나 중국어 "徒步" 가 등산과 동일하다고 가정.
   - **함정**: 영어 "hiking" 은 비교적 캐주얼한 트레일 워크를, "mountain climbing" 은 본격 등반을 뜻함 — 한국어 "등산" 의 폭과 다름. 일본어 登山 (tozan) 도 한국어 "등산" 처럼 광범위하나 더 격식적.
   - **훈련법**: "등산" 의 맥락별 대응 학습 — 캐주얼 산행 = hiking / 트레킹, 본격 등반 = mountaineering / alpinismo (스페인어) / tozan (일본어) 구분.

2. **"산(san)" 한자어 vs 순우리말 혼동**:
   - 한국어 학습자는 산 관련 한자어 (山脈=산맥, 山頂=정상) 를 익히지만, 순우리말 어휘 (오르다, 내리다, 고개, 재) 와의 결합을 어려워함.
   - **함정**: 일본어 도 유사 (山=yama, 登る=noboru) — 그러나 중국어는 山 (shān) + 동사 결합이 다름 (爬山=pá shān = 산에 오르다).
   - **훈련법**: "산을 타다/오르다" vs 중국어 "爬(pá) + 산" 의 동사 결합 차이 학습. 일본어 "山に登る (yama ni noboru)" 의 조사 패턴 숙지.

3. **응급 호출 어휘 (도와주세요 패턴)**:
   - 한국어 "도와주세요" 는 보편적 도움 요청 → 중국어 "救命 (jiùmìng = 살려주세요)" 는 생명 위험 시에만, 영어 "Help!" 는 단순 도움, 스페인어 "¡Ayuda!" / "¡Socorro!" 둘 다 사용.
   - **함정**: 중국어 "救命" 을 일반 도움 요청에 사용하면 과장됨. 영어 "Help" 는 캐주얼, 비즈니스 호출엔 "Could you help me?".
   - **훈련법**: 긴급도별 어휘 매핑 — 생명 위험 = 救命/助けて(tasukete)/도와주세요 / 일반 도움 = help / ¿me ayuda? / 帮帮我 (bāng bang wǒ).

4. **장비 어휘의 외래어 vs 토착어 패턴**:
   - 한국어 "텐트/캠핑/백패킹/트레킹" 은 모두 영어 차용어 → 다른 언어에서 같은 차용 패턴이 흔하지 않음 (일본어: テント/キャンプ, 스페인어: tienda/camping, 중국어: 帐篷/露营).
   - **함정**: 한국어 학습자가 일본어 テント (tento) 를 보고 "텐트" 와 같다고 생각하기 쉬우나, 스페인어 "tienda de campaña" / 중국어 "帐篷" 은 한 단어가 아님.
   - **훈련법**: 차용어의 언어별 형태 학습 — テント (텐트) vs tienda (스페인어) / 帐篷 (중국어 1단어) 비교.

5. **"길(gil)" 어휘의 다의성**:
   - 한국어 "길" 은 길거리/도로/방법 모두 뜻함 → 등산 맥락 "등산로" 와 일상 "길" 의 구분 어려움.
   - **함정**: 영어 "way/path/route/road" 모두 별도 단어, 스페인어 "camino/sendero/vía" 도 구분. 일본어 "道(michi)/路(ji)/登山道(tozandō)" 도 다의.
   - **훈련법**: 등산 맥락의 "길" = trail/path/sendero/登山道/小径 매핑. 일상 "길" = road/street/calle 의 구분 학습.

### 학습 전략

1. **우선순위 1**: 한국어 등산 문화 (주말 산행, 100대명산) 의 어휘 마스터 — 이미 한국인 학습자에게 친숙.
2. **우선순위 2**: 영어 hiking vs mountaineering vs trekking 구분 (캐주얼/중간/본격 등급).
3. **우선순위 3**: 일본어 登山(tozan)/山(yama)/山小屋(yamagoya) 의 한자어 + 訓読(읽기) 패턴.
4. **우선순위 4**: 중국어 동사 결합 (爬+pá/走+zǒu/登+dēng) + 산 패턴 — 한국어와 다른 어순.
5. **우선순위 5**: 응급 호출 어휘 (위급도별) 와 손짓 (SOS, 손 흔들기).
