### 🇰🇷 한국어 (Korean) — 필수

| KR | 발음 | 비고 |
|----|--------|-------|
| 안녕하세요 | Annyeonghaseyo | 안녕 (캐주얼) |
| 안녕히 가세요 / 계세요 | Annyeonghi gaseyo / gyeseyo | 작별 (떠남/머묾) |
| 주세요 | Juseyo | 주세요 (요청) |
| 감사합니다 | Gamsahamnida | 감사 (격식) |
| 미안합니다 / 죄송합니다 | Mianhamnida / Joesonghamnida | 미안 (캐주얼) / 죄송 (격식) |
| 네 / 아니요 | Ne / Aniyo | 예 / 아니오 |
| 저 / 저희 | Jeo / Jeohui | 저 (겸양) / 저희 (겸양 우리) |

#### 한국어 문법 핵심

- **어순**: SOV (서술어 끝)
- **관사**: 없음
- **부정**: 동사 접미 -지 않다 (단형) / -지 않습니다 (정중형)
- **의문**: 어미 + ~까? (~gga?, 격식) 또는 억양 (해요체)
- **경어 단계**: 해체 (친구) / 해요체 (-요, 정중 기본) / 합쇼체 (-ㅂ니다, 격식)
- **대명사**: 자제; 이름 + 님/씨 사용
- **수량사**: 필수 (개/명/마리/장/대...)
- **못 vs 안**: 능력(못) vs 의지(안)

#### 한국 문화 핵심

- 30°/45°/90° 절 (새해 = 큰절)
- 두 손으로 주고받기 (필수)
- 팁 없음 (드물게)
- 금속 젓가락 (한국 고유)
- 눈치 (사회적 tact) 필수
- 정 (깊은 유대) — 시간 경과 후 형성

## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 마스터 치트시트를 활용할 때 흔히 마주치는 함정

1. **"안녕" 캐주얼 오용**:
   - "안녕"은 해체 — 친한 친구, 아이들만. 직장/어른/비즈니스에서 "안녕" 사용 = 부적절.
   - **함정**: 영어 "Hi"처럼 "안녕"을 어른/직장에도 사용 → 매무례.
   - **훈련법**: 모든 초기 학습에서 **"안녕하세요"만 사용**, 친한 친구 (또는 명시 허락 후)만 "안녕".

2. **수량사 혼동**:
   - 한국어 수량사는 "하나, 둘, 셋" (고유어) vs "일, 이, 삼" (한자어) — **사용 범위가 다름**. 시/분/년 = 한자어, 개/명/대 = 고유어.
   - **함정**: "두 시" (O), "둘 시" (X) / "두 명" (O), "이 명" (X) / "이 분" (O) vs "두 분" (O) 혼동.
   - **훈련법**: 시간(시/분/년)=한자어, 사람/동물/사물(개/명/마리)=고유어 — 수량사 매트릭스 암기.

3. **경어 단계 불일치**:
   - 같은 문장 내 주어(상대)/객체(자기) / 청자(상대) 모두 다른 경어 가능. 예: "선생님께서 저를 칭찬하셨다" — "선생님" 존경, "저" 겸양, "칭찬하셨다" 존경 동사.
   - **함정**: 영문 SVO 어순의 단일 동사 활용으로 한국어 다중 경어 적용 시도 → 잘못된 문법.
   - **훈련법**: 한국어는 주어 + 목적어 + 동사 각자 다른 경어 가능 — 4단계 4조합 (해체/해요체/합쇼체/하소서체) 연습.

4. **한자어 vs 고유어 어휘 혼재**:
   - 한국어 "책" (고유어) vs "書籍" (한자어, 격식) / "글" (고유어) vs "文字" (한자어).
   - **함정**: 일본어/중국어 학습자가 모든 어휘를 한자로 매핑 → 한자 없는 한국어 어휘 매핑 실패. 예: 일본어 "友達" → 한국어 "벗/친구" (한자 X).
   - **훈련법**: 한국어 어휘를 고유어 vs 한자어로 분류 — 한자 매핑 가능 여부 사전에 표시.

5. **로마자/발음 표기 차이**:
   - 한국어 로마자는 "Revised Romanization" (2000) — 예: "Hangul, Seoul". McCune-Reischauer는 구식 — 예: "Han'gŭl, Sŏul".
   - **함정**: McCune-Reischauer 표기 (Sŏul)을 보고 발음 추론 → 발음 혼동. 구 어표기 노출 시 혼란.
   - **훈련법**: **Revised Romanization (2000)만 사용**. 학술 자료도 2000년 이후는 Revised 위주.

### 학습 전략

1. **우선순위 1**: 5개 언어 매트릭스 — Hello/Hola/こんにちは/안녕하세요/你好 매핑 + Goodbye/Adiós/さようなら/안녕히 가세요/再见 등 핵심 50개 표현 5언어 동시 암기.
2. **우선순위 2**: 경어 시스템 매트릭스 — ES tú/usted, JP タメ口/丁寧語/敬語, KR 반말/해요체/합쇼체, CH 你/您 매핑. **한국어가 가장 세밀한 6단계 시스템**.
3. **우선순위 3**: 숫자 매트릭스 — KR은 이중 시스템 (고유어 1-99 + 한자어 100+). EN/ES 단일, JP 단일 (단 1-10 별도 발음), CH 단일 (단 2 = 二/两).
4. **우선순위 4**: 대명사 자제 매트릭스 — JP/KR/CH는 대명사 자제 + 이름+호칭. EN/ES는 대명사 필수. "당신/あなた" = "you" 단순 매핑 X (둘 다 부적절).
5. **우선순위 5**: 에티켓/문화 매트릭스 — 팁 (EN/ES 필수, JP/KR/CH 없음), 인사 (악수/뺨키스/절/끄덕임), 흥정 가능 시장, 음료 따르기 (상대에게 vs 자기가), 식사 인사.
