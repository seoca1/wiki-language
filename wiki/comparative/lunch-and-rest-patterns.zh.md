## 跨文化模式

### 文化模式总结

- **东亚午餐时间更早** (11:30-13:00) 相比南欧 (14:00-15:30)。
- **饭后休息普遍**但时长不同 (0-60 分钟)。
- **职场午睡文化** (日本 居眠り、中国 午休) 在现代办公室越来越被接受。
- **西班牙午睡** 是该群体中唯一"官方"文化实践; 其他都是务实适应。

## 🇨🇳 中文学习者笔记 (Chinese Learner Notes)

> 本节是面向中文母语学习者的额外学习指南。

### 中文母语者在学习其他4种语言午休文化时的常见陷阱

1. **午休时间的跨文化差异**:
   - 中文常见的"午休"在11:30-13:00之间 → 学员假设其他文化也类似。
   - **陷阱**: 西班牙午餐14:00-15:30, 学员认为是"晚餐"; 西班牙文化下午还有 "merienda" 5-7点的小餐。
   - **训练法**: 整理 5种文化工作时间表 — 中国 11:30午餐 / 西班牙 14:00午餐 / 日本 12:00午餐 / 韩国 12:00午餐 / 美国 12:00午餐。

2. **午睡 vs 疗愈文化的差异**:
   - 中文"午休" = 午餐 → 短暂休息 → 继续工作 → 学员假设其他语言同样。
   - **陷阱**: 西班牙 siesta = 真正的长午睡 (90-120分钟), 不仅是短暂休息; 日本 inemuri 是在办公室/公共交通工具上打盹, 文化被允许。
   - **训练法**: 记忆每个国家午休的**核心文化功能** — 西班牙 siesta = 避暑 + 家庭时间; 日本 inemuri = "虽然在工作但很努力" 的姿态; 韩国 낮잠 = 儿童/老人; 中国 午休 = 普遍职场。

3. **斋月与午餐文化混淆**:
   - 中文"斋月"特指伊斯兰教 → 学员假设与午餐文化无关。
   - **陷阱**: 斋月期间穆斯林国家的午餐完全改变 — 禁食 30 天; 但西班牙曾经被穆斯林统治 800 年, 留下饮食文化痕迹。
   - **训练法**: 学习每种语言时考虑其宗教/历史背景 — 西班牙午睡与伊斯兰教斋月节律可能存在关联。

4. **merienda vs 加餐文化**:
   - 中文 "下午茶" 5-7点 → 学员假设其他语言都对应。
   - **陷阱**: 西班牙/阿根廷 merienda 是 5-7点小餐 (含巧克力 + churros); 韩国/中国/日本 没有严格的下午茶对应; 英国 afternoon tea 是从下午 4-5 点不同的传统。
   - **训练法**: 区分 "snack" (零食) / "tea" (茶点) / "merienda" (西班牙小餐) — 不同文化不同时段。

5. **午休 vs 下午茶 vs 晚餐时间混淆**:
   - 中文下午 6-7 点晚餐 → 学员假设其他文化同样时间。
   - **陷阱**: 西班牙晚餐 21:00-22:00 是日常; 日本晚餐 19:00-20:00; 韩国晚餐 18:00-19:00; 美国晚餐 18:00-19:00; 中国晚餐 18:00-19:00。
   - **训练法**: 制作 5文化工作时间表 — 早餐/午餐/晚餐各自时间 + 午休时长。

### 学习工作流程推荐

1. **整理 5文化时间表** (早餐/午餐/晚餐/午休时间)
2. **明确功能差异** (午睡 = 休息 vs 社交 vs 工作)
3. **地域差异** (中国 北方 vs 南方 / 西班牙 北部 vs 南部 / 日本 都市 vs 农村)
4. **历史背景** (宗教/战争/经济如何影响饮食时间)
5. **实战场景** (到访该国家时记住当地饮食时间, 调整自己的作息)
