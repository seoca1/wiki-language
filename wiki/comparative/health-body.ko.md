## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 건강·신체 어휘를 배울 때 흔히 마주치는 함정

1. **"배(Bae)" 의 한국어 다의성**:
   - 한국어 "배" = stomach/belly + pear + ship — 매우 다의. 일본어 腹/胃/梨 와 구분됨. 중국어 肚子/胃/梨/船 도 구분.
   - **함정**: 한국어 학습자가 영어에서 stomach/belly 단순 매핑 → 영어에서 stomach = 위 (내부 장기) vs belly = 배 (외부 부위) 구분.
   - **훈련법**: 배 어휘 매핑 — KR 배 (3가지 의미) / EN stomach/belly/pear/ship / ES estómago/barriga/pera/barco / JP 胃/腹/梨/船 / CH 胃/肚子/梨/船. 맥락별 의미 학습.

2. **한자 공유 신체 어휘 (JP/KR/CN)**:
   - 骨(뼈/ほね/gǔ), 心(마음/こころ/xīn), 目(눈/め/yǎn) 등 한자 공유 — 그러나 한국어는 일부만 한자어, 나머지 토착어 (예: 배/배/위 다의).
   - **함정**: 한국어 학습자가 한자 신체 어휘를 매핑 시 혼란 — 머리 (토착) vs 頭 (한자) / 눈 (토착) vs 目 (한자).
   - **훈련법**: 한자 신체 부위 매칭 — 頭/眼/耳/口/手/足/心/骨 의 JP/KR/CN 발음 + 한국어 토착어 결합 차이.

3. **"선생님" 의 의료 맥락 사용**:
   - 한국어 "선생님" = 의사/치과 의사/약사 등 의료 전문가 — 일본어 先生 (sensei) 와 동일. 영어 doctor/스페인어 doctor/중국어 医生 (yīshēng) 와 다름.
   - **함정**: 한국어 학습자가 영어에서 "teacher-nim" 같은 직접 결합 시도 → 어색. 일본어 先生 (단일 단어 자체가 존경).
   - **훈련법**: 의료 호칭 비교 — KR 선생님 (존경) / JP 先生 (존경) / CH 医生 (단일) / EN Dr. / ES Doctor. 맥락별 사용.

4. **통증 표현의 한자 공유**:
   - 痛(통/tòng), 疼(통/téng), 痛症 (KR 한자어) — 한국어/일본어/중국어 한자 공유. 영어 pain, 스페인어 dolor 와 다름.
   - **함정**: 한국어 학습자가 일본어 痛い (itai) 를 "동사" 의 동사화 학습 어려움. 그러나 한국어 "아프다" 도 동사 활용 (예: 아파요, 아팠어요).
   - **훈련법**: 통증 어휘 매핑 — 痛 (KR 통/JP いた/CH tòng) + 형용사 활용 (KR 아프다/JP いたい/CH 痛) 매칭.

5. **"변비(Constipation)" vs "감기(Cold)" 의 한국 한자어**:
   - 한국어 "변비" = 한자어 (변비) — 그러나 일상에서 잘 사용 안함. "안 맵게" 처럼 한자어 일반화. 중국어 便秘 (biànmì) 와 동일.
   - **함정**: 한국어 학습자가 영어 "constipation" 를 변비로 단순 매핑 → 일상 표현 "뻣뻣하다" "뚱뚱하다" 등 토착 표현과 결합 어려움.
   - **훈련법**: 한자 의학 어휘 학습 — 感氣(감기)/便秘(변비)/糖尿病(당뇨병)/高血壓(고혈압) 매칭. 한자 매칭으로 5언어 의학 어휘 통합 학습.

### 학습 전략

1. **우선순위 1**: 한국어 기본 신체 부위 (머리/눈/귀/입/손/발) 마스터 — 일상 의료 어휘.
2. **우선순위 2**: 일반 증상 어휘 (아프다/열/기침/콧물/설사) 5언어 매핑.
3. **우선순위 3**: 한자 의료 어휘 매칭 — 痛/胃/肝/肺/心/骨/血/糖尿病 매핑.
4. **우선순위 4**: 의료 호칭 시스템 (KR 선생님/JP 先生/CH 医生) 의 존경법 비교.
5. **우선순위 5**: 응급 번호 (KR 119/J 119/CH 120/ES 112/US 911) 국가별 암기.
