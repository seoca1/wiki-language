## 速查卡

### 🇬🇧 英语 (EN) — 精华

#### 基础

| EN | IPA | 备注 |
|----|-----|------|
| Hello | /həˈloʊ/ | 通用 |
| Goodbye | /ɡʊdˈbaɪ/ | 通用 |
| Please | /pliːz/ | 通用 |
| Thank you | /θæŋk juː/ | 通用 |
| Sorry | /ˈsɒri/ | 通用 |
| Yes / No | /jɛs/ /noʊ/ | 通用 |
| I / You / He/She/It | /aɪ/ /juː/ /hi, ʃi, ɪt/ | 第三人称单数无性别 |

#### 短语

- "How are you?" — 标准问候
- "I'm good, thanks." — 默认回答
- "Where is the bathroom?" — 必备
- "How much?" — 购物
- "I don't understand." — 礼貌
- "Could you help me?" — 间接礼貌请求

#### 语法速记

- **语序**: SVO
- **冠词**: a/an (不定), the (定)
- **否定**: do/does + not + 动词
- **疑问**: Do/Does/Would/Could + S + V?
- **代词**: He/She + They (单数 they = 中性)

#### 文化速记

- 直接沟通风格
- 快速使用名字
- 眼神交流 = 诚实
- 小费 15-20%
- 个人空间: 约一臂距离

### 🇪🇸 西班牙语 (ES) — 精华

#### 基础

| ES | 发音 | 备注 |
|----|------|------|
| Hola | /ˈo.la/ | 通用 |
| Adiós | /aˈðjos/ | 通用 |
| Por favor | /poɾ faˈβoɾ/ | 通用 |
| Gracias | /ˈɡɾa.θjas/ (ES) /ˈɡɾa.sjas/ (LatAm) | 通用 |
| Perdón / Disculpe | /peɾˈðon/ /diskulpe/ | 对不起 / 打扰一下 |
| Sí / No | /si/ /no/ | 通用 |
| Yo / Tú / Usted | /jo/ /tu/ /usˈteð/ (ES) | Tú (同辈) / Usted (正式) |

#### 短语

- "¿Qué tal?" — 最近怎么样？
- "Más o menos" — 马马虎虎
- "¿Dónde está...?" — 在哪里？
- "¿Cuánto cuesta?" — 多少钱？
- "No entiendo" — 我不懂
- "¿Puede ayudarme?" — 能帮我吗？

#### 语法速记

- **语序**: SVO (灵活)
- **冠词**: el/la/los/las (定), un/una/unos/unas (不定)
- **否定**: no + 动词 (动词前)
- **疑问**: 语调 + ¿? 标记
- **代词**: 性别 (él/ella), 正式 vs 非正式 (tú/usted)
- **虚拟式**: WEIRDO 触发条件

#### 文化速记

- Tío/tía = 哥们 (西班牙)
- 两吻 (西班牙), 一吻 (LatAm)
- 小费 5-10% (西班牙) / 10% (LatAm)
- 晚食 (午餐 14:00+, 晚餐 21:00+)
- 个人空间: **近** 距离

### 🇯🇵 日语 (JP) — 精华

#### 基础

| JP | 读音 | 备注 |
|----|------|------|
| こんにちは | Konnichiwa | 你好 (白天) |
| さようなら | Sayounara | 再见 (正式) |
| お願いします | Onegaishimasu | 拜托 |
| ありがとうございます | Arigatou gozaimasu | 谢谢 (礼貌) |
| すみません | Sumimasen | 对不起 / 打扰一下 (礼貌) |
| はい / いいえ | Hai / Iie | 是 / 否 |
| 私 / あなた | Watashi / Anata | 我 (礼貌) / 你 (避免) |

#### 短语

- "お元気ですか?" (Ogenki desu ka?) — 你好吗？
- "いただきます" (Itadakimasu) — 饭前说
- "ごちそうさまでした" (Gochisousama deshita) — 饭后说
- "いくらですか?" (Ikura desu ka?) — 多少钱？
- "わかりません" (Wakarimasen) — 我不懂
- "助けてください" (Tasukete kudasai) — 请帮忙

#### 语法速记

- **语序**: SOV (动词在最后)
- **冠词**: 无
- **否定**: 动词后缀 -nai (普通) / -masen (礼貌)
- **疑问**: 句尾助词 か (ka)
- **代词**: 避免; 用名字 + san/kun/chan
- **敬语**: 敬语系统 (尊敬語/謙譲語/丁寧語)
- **量词**: 强制 (個/人/本/枚/台/匹...)

#### 文化速记

- 鞠躬 15°/30°/45° (基于敬意)
- 双手递交/接收
- 无小费 (失礼!)
- 交通安静
- *Kuuki o yomu* (读空气)
- Omotenashi (预见性服务)

### 🇰🇷 韩语 (KR) — 精华

#### 基础

| KR | 韩文 | 备注 |
|----|------|------|
| 안녕하세요 | Annyeonghaseyo | 你好 (礼貌默认) |
| 안녕히 가세요 / 계세요 | Annyeonghi gaseyo / gyeseyo | 再见 (离开/留下) |
| 주세요 | Juseyo | 请给我 |
| 감사합니다 | Gamsahamnida | 谢谢 (礼貌) |
| 미안합니다 / 죄송합니다 | Mianhamnida / Joesonghamnida | 对不起 / 对不起 (正式) |
| 네 / 아니요 | Ne / Aniyo | 是 / 否 |
| 저 / 저희 | Jeo / Jeohui | 我 / 我们 (谦辞) |

#### 短语

- "잘 지내세요?" (Jal jinaeseyo?) — 你好吗？
- "잘 먹겠습니다" (Jal meokkesseumnida) — 饭前说
- "잘 먹었습니다" (Jal meogeosseumnida) — 饭后说
- "얼마예요?" (Eolmayeyo?) — 多少钱？
- "이해 못 해요" (Ihae mot haeyo) — 不懂
- "도와주세요" (Dowajuseyo) — 请帮忙

#### 语法速记

- **语序**: SOV (动词在最后)
- **冠词**: 无
- **否定**: 动词后缀 -지 않다 (短) / -지 않습니다 (礼貌)
- **疑问**: 语调 + ~까? (~gga?, 正式)
- **语阶**: 해체 (非正式) / 해요체 (礼貌) / 합쇼체 (正式)
- **代词**: 避免; 用名字 + 님/씨
- **量词**: 强制 (개/명/마리/장/대...)
- **不能 vs 不做**: 못 vs 안/안

#### 文化速记

- 鞠躬 30°/45°/90° (新年 = 큰절)
- 双手递交/接收 (强制)
- 无小费 (罕见)
- 金属筷子 (韩语特有)
- 眼色 (社交 tact) 必要
- 정 (深情) 随时间积累

### 🇨🇳 中文 (CH) — 精华

#### 基础

| CH | 拼音 | 备注 |
|----|------|------|
| 你好 | Nǐ hǎo | 你好 |
| 再见 | Zàijiàn | 再见 |
| 请 | Qǐng | 请 |
| 谢谢 | Xièxie | 谢谢 |
| 对不起 / 不好意思 | Duìbuqǐ / Bù hǎoyìsi | 对不起 / 不好意思 |
| 是 / 不是 | Shì / Bù shì | 是 / 否 |
| 我 / 你 / 您 | Wǒ / Nǐ / Nín | 我 / 你 / 您 (敬) |

#### 短语

- "你好吗?" (Nǐ hǎo ma?) — 你好吗？
- "吃了吗?" (Chī le ma?) — 吃了吗？(文化问候)
- "多少钱?" (Duōshǎo qián?) — 多少钱？
- "我不懂" (Wǒ bù dǒng) — 我不懂
- "请帮帮我" (Qǐng bāng bang wǒ) — 请帮帮我
- "没事" (Méi shì) — 没事

#### 语法速记

- **语序**: SVO (灵活, 主题突出)
- **冠词**: 无
- **否定**: 不 (bù) 一般 / 没 (méi) 过去; 别 (bié) 祈使
- **疑问**: 句尾 吗 (ma) / A不A 形式
- **声调**: 4声 + 轻声 (mā má mǎ mà)
- **量词**: 强制 (个/位/只/条/张...)
- **体助词**: 了 / 过 / 着

#### 文化速记

- 关系 (guānxi) = 货币
- 面子 (miànzi) = 关键
- 头衔 + 姓 (王老师, 张经理)
- 宴会 = 酒文化 (干杯 gānbēi)
- 送礼 (不送钟, 不送绿帽)
- 移动支付 = 微信/支付宝默认

## 🇨🇳 中文学习者笔记 (Chinese Learner Notes)

> 本节是面向中文母语学习者的额外学习指南。

### 中文母语者使用本速查表的陷阱

1. **汉字桥梁作为"陷阱"**:
   - 中文与日韩共享汉字, 学员常误以为同汉字词读音相近。
   - **陷阱**: 日文 勉強 (benkyō) ≠ 中文 "勉强" (miǎnqiǎng); 强烈不同源。
   - **训练法**: 本速查表统一标注罗马音 — 训练时严格按罗马音读, 不要按汉字猜。

2. **声调 vs 音高重音 vs 重音**:
   - 中文 4声 + 1轻声是声调语言, 改变声调=改变意思。
   - **陷阱**: 日语 东京型音高重音 (高低模式) **不等于**声调 (类似西语重音); 韩语首尔音高重音正在消失; 英语重音不可预测。
   - **训练法**: 区分 "声调" (变调=变意) vs "重音" (只强调) vs "音高重音" (音高模式) — 5种语言各自不同。

3. **量词的必要性**:
   - 中文/日语/韩语都有强制量词, 英语/西语没有。
   - **陷阱**: 中文 "一本书" (本 = book classifier) 必须; 西语 "un libro" (没有量词) 自然。
   - **训练法**: 本速查表已列出量词 (个/位/只/条/张...) — 实际使用中养成"先想量词再说"的习惯。

4. **敬语多样性的统一性**:
   - 中文敬语相对简单 (您/你 + 头衔)。学员面对 5 种语言时容易混淆。
   - **陷阱**: 日语 5层敬语 + 韩语 7个 speech level + 西语 2层 tú/usted + 英语 2-3层 formal/informal。
   - **训练法**: 制作"敬语层级对照表" — 把中文的 您/你 映射到 5种语言各自的对应项。

5. **代词省略 vs 强制**:
   - 中文/日语/韩语/西语都可以省略代词 (pro-drop); 英语强制。
   - **陷阱**: 中文 "我走了" 不一定每次说 "我"; 学员在英语中也省略 → 错句 "Went to store"。
   - **训练法**: 实际使用时记住 "英语说代词, 4种语言可省略" — 反向训练时强制加代词。
