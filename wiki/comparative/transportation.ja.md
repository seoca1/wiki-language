### 国別交通システム

#### 🇺🇸 米国

| 手段 | 説明 |
|------|-------------|
| **Car** | 主要交通手段 (移動の ~85%) |
| **Airplane** | 長距離、拡張ネットワーク |
| **Bus** | Greyhound (長距離), 市内バス |
| **Subway** | NYC, シカゴ, DC, ボストン, SF, LA (限定的) |
| **Train** | Amtrak (限定的旅客鉄道) |
| **Rideshare** | Uber, Lyft (都市で支配的) |
| **Bike** | 都市で成長中 (Citi Bike, Lyft バイクシェア) |

**文化ノート**:
- 運転免許証 = アイデンティティ
- ナショナル transit パスなし
- 車 = 自由の象徴 (郊外で特に)

#### 🇪🇸 スペイン

| 手段 | 説明 |
|------|-------------|
| **高速鉄道 (AVE)** | 優れたネットワーク (Madrid, Barcelona, Sevilla) |
| **Metro** | Madrid, Barcelona, Bilbao, Valencia |
| **Cercanías** | 郊外鉄道 (commuter) |
| **Bus** | ALSA (長距離), 市内バス |
| **Car** | 一般だが歴史的中心部で限定的 |
| **Taxis** | 白に緑のストライプ (Madrid), 黒/黄 (Barcelona) |
| **Rideshare** | Uber, Cabify, FreeNow |

**文化ノート**:
- AVE (高速) — 主要都市 2-3 時間圏
- Siesta — 一部ビジネス 14-17 閉鎖 (現在は減少)
- タクシーへのチップ: 切り上げ (必須ではない)
- スペインの運転 = 混沌 (地元ジョーク)

#### 🇯🇵 日本

| 手段 | 説明 |
|------|-------------|
| **Train (JR)** | JR (6 地方会社), 密度の高いネットワーク |
| **Subway (chikatetsu)** | Tokyo Metro, Toei, 大阪, 名古屋, 等 |
| **Shinkansen** | 高速 (新幹線) — 世界のゴールドスタンダード |
| **Bus** | 高速バス (鉄道より安い), 市内バス |
| **Taxi** | 高価だが信頼性高い (ドア自動) |
| **Car** | 都市で少ない (高い駐車場、狭い道路) |
| **Bicycle** | 一般 (自転車文化), 京都で特に |
| **Airplane** | 主要都市間の国内便 |
| **Ferry** | 島へ (沖縄、北海道) |

**文化ノート**:
- **IC カード** (Suica, Pasmo, Icoca) — 交通 + 決済、すべて互換
- 列車 = 正確 (秒単位 sekigiri)
- 電車で静か (電話なし)
- チップ = タクシー含め皆無
- JR パス (外国人観光客; 7/14/21 日)

#### 🇰🇷 韓国

| 手段 | 説明 |
|------|-------------|
| **Subway** | ソウル (9 号線), 釜山, 大邱, 仁川, 光州, 大田 |
| **KTX** | 高速鉄道 (ソウル-釜山 2 時間) |
| **SRT** | 民間高速 (新, KTX 類似) |
| **Bus** | 高速 (고속버스), 市内バス |
| **Taxi** | 色分け: 일반 (regular) / 모범 (premium) / 대형 (large) |
| **T-money / Cashbee** | トランジットカード (全交通機関互換) |
| **Car** | 一般だがソウルの交通は悪い |
| **Kakao T** | Kakao Taxi アプリ (支配的ライドシェア) |

**文化ノート**:
- ソウル地下鉄 = ワールドクラス (清潔、速い、英語サイン)
- T-money = 必須 (タクシー、地下鉄、バス、コンビニ)
- タクシーのチップ = しない (運転手が追いかけてくる!)
- シニア席 = 優先 (立っていても高齢者に譲る)
- プレミアムタクシー (모범택시) = 大型、高価

#### 🇨🇳 中国

| 手段 | 説明 |
|------|-------------|
| **High-speed rail (CRH)** | 世界最大のネットワーク (40,000+ km) |
| **Subway** | 北京, 上海, 広州, 深圳, 40+ 都市 |
| **Bus** | 拡張ネットワーク、とても安い |
| **Taxi** | 都市で一般的 |
| **Didi (滴滴)** | ライドシェア アプリ (中国の Uber) |
| **Car** | 中流階級増加中 |
| **Alipay/WeChat Pay** | すべての交通決済に使用 |
| **High-speed Maglev** | 上海 (浦東空港, 世界最速) |

**文化ノート**:
- **Alipay/WeChat Pay** = 普遍的決済 (露店にも)
- **英語表示**: 主要都市の地下鉄 = バイリンガル
- **整列**: 混沌とすることがある (特にバス)
- **高速鉄道**: 北京-上海 4.5 時間 (vs 飛行機 2 時間 + 空港時間 = 同等)
- **Didi**: 旅行前にインストール (foreign card サポート限定的)

|---------|------|----------------|

## 🇯🇵 日本語学習者ノート (Japanese Learner Notes)

> 本セクションは日本語学習者向けの追加学習ガイドです。

### 日本語話者が他4言語の交通用語を学ぶ際の一般的な落とし穴

1. **車線 (左 vs 右)**:
   - 日本は左車線 → 英語圏/スペイン/韓国/中国は右車線。
   - **落とし穴**: 日本語話者が右車線国で左側通行 → 事故リスク。
   - **練習法**: 海外で運転する前に車線を確認、最初はレンタカーより公共交通。

2. **新幹線 vs 高速鉄道名**:
   - 日本語の「新幹線」 (Shinkansen) → 韓国語「KTX」 → スペイン語「AVE」 → 中国語「高铁」。
   - **落とし穴**: 日本語話者が「新幹線」を他言語に「shinkansen」とそのまま → ネイティブは「AVE/KTX/高铁」と呼ぶ。
   - **練習法**: 各国の高速鉄道名 (Shinkansen / KTX / AVE / 高铁) を 5言語対応表で。

3. **チップ不要文化**:
   - 日本語はタクシー含む チップ不要 (失礼) → 英語圏 (米国) はタクシー 15-20% チップ必須。
   - **落とし穴**: 米国タクシーで「カードで」とだけ言ってテーブルを去る → チップ未払いで困惑。
   - **練習法**: 英語圏ではタクシー 15-20% チップをデフォルトに。

4. **IC カード普及率**:
   - 日本は Suica/Pasmo 普及 → 韓国は T-money/Cashbee 普及 → 中国は モバイル決済 (Alipay/WeChat Pay) のみ。
   - **落とし穴**: 日本語話者が中国で IC カード使用 → 中国は基本的にモバイル決済のみ。
   - **練習法**: 中国旅行で Alipay/WeChat Pay をインストール、韓国の T-money カードも購入。

5. **運転文化差**:
   - 日本語の「信号無視しない」「譲り合い」文化 → スペインの「ローカル運転は混沌」、中国の「クラクション多い」文化。
   - **落とし穴**: 日本語話者が海外で「譲り合い」を期待 → スペインや中国では逆。
   - **練習法**: 運転文化を国別に事前学習 (スペイン: 譲らない、中国: クラクション)。
