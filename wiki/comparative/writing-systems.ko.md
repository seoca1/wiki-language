### 영어 & 스페인어: 라틴 알파벳

#### 영어 (26자)
| 기능 | 상세 |
|---------|--------|
| **문자** | 26 (A-Z) |
| **이합자** | ch, sh, th, ph, wh, ng, ck, qu, 등 |
| **분음 기호** | 드물다 (차용어: *café, naïve, résumé*) |
| **대소문자** | 대/소 (bicameral) |
| **음소-문자** | **깊은 직교법** — 44 음소, 250+ 철자 |
| **구두점** | 표준 라틴 (. , ? ! : ; " ' ( ) [ ] { } ...) |

#### 스페인어 (27자 + ñ)
| 기능 | 상세 |
|---------|--------|
| **문자** | 27 (A-Z + Ñ) — *ch, ll* deprecated as letters (2010) |
| **이합자** | ch, ll, rr, gu, qu |
| **분음 기호** | **강세 (´)** — 강세, 명확화 (*sí* vs *si*); **트레마 (¨)** — *pingüino, vergüenza*; **물결 (˜)** — *ñ* only |
| **대소문자** | 대/소 |
| **음소-문자** | **얕은 직교법** — 거의 1:1 (5 모음, 19 자음) |
| **구두점** | **역 ¿ ¡** — 스페인어 고유 |

### 한국어: 한글 (한글) — 음소 알파벳

#### 설계 원칙 (1443, 세종대왕)

| 원칙 | 구현 |
|-----------|----------------|
| **음소적** | 문자 모양이 조음 위치 인코딩 (혀, 입술, 목구멍) |
| **음절 블록** | 문자가 정사각형 음절로 결합 (CV, CVC, CVCC) |
| **체계적** | 19 자음 × 21 모음 = 11,172 가능한 음절 |
| **음소적** | 거의 1:1 문자-소리 |

#### 자음 (19: 14 기본 + 5 경음)

| 기본 | ㄱ | ㄴ | ㄷ | ㄹ | ㅁ | ㅂ | ㅅ | ㅇ | ㅈ | ㅊ | ㅋ | ㅌ | ㅍ | ㅎ |
|-------|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 소리 | g/k | n | d/t | r/l | m | b/p | s | ng/∅ | j/ch | ch' | k' | t' | p' | h |
| 경음 | ㄲ | ㄸ | ㅃ | ㅆ | ㅉ | | | | | | | | | |
| 소리 | kk | tt | pp | ss | jj | | | | | | | | | |

**조음 음소적 모양**:
- ㄱ (g/k) — 혀 뒤 들림
- ㄴ (n) — 혀끝 치조
- ㅁ (m) — 입술 닫힘
- ㅅ (s) — 이빨 모양
- ㅇ (ng/∅) — 목구멍 윤곽

#### 모음 (21: 10 기본 + 11 이중모음)

| 기본 | ㅏ | ㅑ | ㅓ | ㅕ | ㅗ | ㅛ | ㅜ | ㅠ | ㅡ | ㅣ |
|-------|---|---|---|---|---|---|---|---|---|---|
| 소리 | a | ya | eo | yeo | o | yo | u | yu | eu | i |

| 이중 | ㅐ | ㅒ | ㅔ | ㅖ | ㅘ | ㅙ | ㅚ | ㅝ | ㅞ | ㅟ | ㅢ |
|-----------|---|---|---|---|---|---|---|---|---|---|---|
| 소리 | ae | yae | e | ye | wa | wae | oe | wo | we | wi | ui |

#### 음절 블록 구조

```
CV:    가 (ga) = ㄱ + ㅏ
CVC:   감 (gam) = ㄱ + ㅏ + ㅁ
CVCC:  값 (gaps) = ㄱ + ㅏ + ㄱ + ㅅ (종성 클러스터)
```

**받침** — 종성 자음: 27 가능 (단일 + 클러스터)

#### 직교법 규칙

| 규칙 | 예 |
|------|---------|
| **초성 ㅇ 없음** | *아* (a) not *이아* |
| **받침 중화** | *값* [갑] — ㅅ→ㄷ; *닭* [닥] — ㄹ 무성 |
| **경음화** | *꽃이* [꼬치] — ㅊ 경음화 후 받침 |
| **비음화** | *깜짝* [깜짝] — ㅁ+ㅈ→ㄴㅉ |
| **연음** | *한국어* [한구거] — ㄱ→ㅇ 모음 사이 |

| 시스템 | 예 | 사용 |
|--------|---------|-----|
| **개정 로마자 (2000)** | *Hangul, Seoul, Gimpo* | 공식 (대한민국), 도로 표지판 |

### 중국어: 한자 (汉字/漢字) — 표의

#### 간체 vs 번체

| 측면 | 간체 (简体) | 번체 (繁體) |
|--------|------------------|-------------------|
| **지역** | 대륙, 싱가포르, 말레이시아 | 대만, 홍콩, 마카오, 해외 |
| **문자** | ~2,500 감소 획 | ~4,500+ 완전 형태 |
| **감소 방법** | 필기체 → 표준; 동음이의 합병; 부수 감소 | 어원 보존 |

## 학습자 의사결정 가이드

> **쓰기 시스템 매트릭스 (5개 언어)**:
> - EN: 라틴 알파벳 (26자), LTR, 깊은 직교법
> - ES: 라틴 알파벳 + 분음 (27자), LTR, 얕은 직교법
> - JP: 한자 + 히라가나 + 가타카나 (혼합), LTR/TTB, 가나 = 1:1 + 한자 = 불규칙
> - KR: 한글 (음소 알파벳, 40 자음, 음절 블록), LTR/TTB, **가장 음소적 (1:1)**
> - CH: 한자 (3,000-5,000자, 표의), LTR/TTB, 가장 음소 투명성 낮음

> **5개 언어 학업 부담 비교**:
> - EN/ES: 알파벳 26-27자 (가장 빠름)
> - JP: 가나 100 + 한자 2,136 (가장 느림, 한자 메모리 집약)
> - KR: 자음 40 + 음절 블록 (음소적 1:1, 비교적 빠름)
> - CH: 한자 3,000-5,000 (가장 느림, 어휘 집약)

## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 쓰기 시스템을 학습할 때 흔히 마주치는 함정

1. **한글 (음소 알파벳) 의 한국어 고유성**:
   - 한글: 1443 세종대왕 신조. **음소적 (featural) + 음절 블록 + 거의 1:1**.
   - 라틴 알파벳 (EN/ES): 자음+모음 결합, 표음적이나 음소적 부재.
   - 가나 (JP): 음절 문자 (syllabary), 1:1.
   - 한자 (CN/JP): 표의, 불규칙 발음.
   - **함정**: 한국어 학습자가 라틴/가나/한자와 한글 비교 시 한글 우위 인식 어려움. **한글은 세계에서 가장 과학적인 문자 중 하나**.
   - **훈련법**: 한글 음소성 명시 학습 — **자음+모음 + 음절 블록 + 1:1**. 다른 4개 언어와 비교. 한글 우위 학습.

2. **한자 한자어 쓰기 시스템 한자 비교**:
   - 한자 (한자 한자어, 漢字): 한자 1자 (CJK 공유) + 발음 다름.
   - 한국어: 한자 + 한글 혼용. 일본어: 한자 + 가나 혼용. 중국어: 한자 + 병음 보조.
   - **함정**: 한국어 학습자가 일본어 한자 한자어 단순 매핑 → "한자 = 3개국 공유, 발음만 다름" 학습.
   - **훈련법**: 한자 한자어 3개국 한자 동일 + 발음 다름 매트릭스 학습. **한자 = 3개국 공통 문자**.

3. **한자 한자어 외래어 vs 한국어 외래어 매트릭스**:
   - 한국어: 한자어 (漢字語, 한자 차용) + 외래어 (영어/일본어/중국어 차용). 혼재.
   - 영어: 라틴 어원 + 고유어 + 차용어 (라틴/그리스/게르만).
   - 스페인어: 라틴 어원 + 아랍어 차용.
   - 일본어: 한자 한자어 (한자) + 와카와 (고유어) + 가타카나 차용어.
   - **함정**: 한국어 학습자가 한자 한자어 (漢字語) 단순 매핑 → 다른 4개 언어에 한자어 ≠ 한자 한자어 (영어 한자어 없음).
   - **훈련법**: 한자어 (漢字語) 한국어/일본어/중국어 매트릭스 — **한자 1글자 = 3개국 공유 외래어**. 영어/스페인어 한자어 없음.

4. **세로 쓰기 vs 가로 쓰기**:
   - 한국어/일본어/중국어: 전통 TTB (위에서 아래) + 현대 LTR (왼쪽에서 오른쪽). 혼재.
   - 영어/스페인어: LTR만. TTB 불가.
   - **함정**: 한국어 학습자가 영문 소설 TTB 읽기 시도 → 불가. **TTB = CJK 전통**.
   - **훈련법**: **LTR vs TTB 매트릭스** — CJK 전통 TTB + 현대 LTR / EN/ES LTR만. **5개 언어 쓰기 방향 매트릭스**.

5. **입력 방법 (IME) 의 한국어 vs 다른 4개 언어**:
   - 한국어: 한글 IME (자음→음절 블록) — **음소적 1:1 입력**.
   - 일본어: 가나 IME (가나→한자 선택).
   - 중국어: 병음 IME (병음→한자 선택).
   - 영어/스페인어: 직접 타이핑 (IME 없음).
   - **함정**: 한국어 학습자가 일본어/중국어 IME 무지 → "한글 = 다른 4개 언어보다 쉬운 입력".
   - **훈련법**: **IME 매트릭스** — KR 자음→음절 (1:1) / JP 가나→한자 / CH 병음→한자 / EN/ES 직접. **한글 입력의 우위 학습**.

### 학습 전략

1. **우선순위 1**: **한글 음소성 명시 학습** — 자음+모음 + 음절 블록 + 1:1. 한글은 세계에서 가장 과학적인 문자 중 하나. **한글 우위 학습**.
2. **우선순위 2**: 한자 한자어 3개국 한자 동일 + 발음 다름 매트릭스 — 한자 (CJK 공유 문자) + 한국어 한자음/일본 음/중국 음. **한자 1글자 = 3개국 발음**.
3. **우선순위 3**: IME 매트릭스 — KR 자음→음절 (1:1) / JP 가나→한자 / CH 병음→한자 / EN/ES 직접. **5개 언어 입력 방법 비교**.
4. **우선순위 4**: LTR vs TTB 매트릭스 — CJK 전통 TTB + 현대 LTR / EN/ES LTR만. **5개 언어 쓰기 방향 비교**.
5. **우선순위 5**: 한자 외래어 (漢字語) 매트릭스 — 한자 1글자 = 3개국 공유 외래어. 영어/스페인어 한자어 없음.
