### 언어학적 특성

| Pattern | English | Spanish | Japanese | Korean | Chinese |
|---------|---------|---------|----------|--------|---------|
| **성/수 일치** | None (this/that 예외) | 필수 (bueno/buena, grande 양수) | 없음 | 없음 | 없음 |
| **복수형** | -s/-es (books) | -s/-es (libros); 형용사 불변 | 없음 | 없음 | 없음 (的) |
| **배치 (기본)** | 명사 앞 (big house) | 명사 뒤 (casa grande) | 명사 앞 (大きい家) | 명사 앞 (큰 집) | 명사 앞, 흔히 의 동반 (大的房子) |
| **형용사 형태** | 굴곡 없음 (good book) | -o/-a 명사 성별 일치 | -i (い형용사) / -na (な형용사) | -ㄴ/-은 (자음/모음) | 단독 (好书) 또는 의 (好的书) |

| **최고급** | -est / most (biggest) | el más + 형용사 | 一番 (ichiban) | 가장 (gajang) | 最 (zuì) |

## 언어별 상세

### 🇬🇧 영어 (English)
- **핵심 용어**: 등급화 가능 (big, very big) vs 비등급화 (perfect, *very perfect ✗); 한정적 vs 서술적 용법
- **패턴**: 형용사 배열 규칙 — opinion-size-age-shape-color-origin-material 순 (예: "big old red wooden box")
- **출처**: `[[adjectives-vocabulary]]`

### 🇪🇸 스페인어 (Spanish)
- **핵심 용어**: 형용사는 명사와 성·수 일치 필수; "bueno/buena", "malo/mala"; "grande"는 단수명사 앞에서 "gran"으로 축약
- **패턴**: 기본은 명사 뒤에 배치; 강조 시 앞에 (예: "pobre hombre" = 불쌍한 남자)
- **출처**: `[[adjectives-vocabulary]]`

### 🇯🇵 일본어 (Japanese)
- **핵심 용어**: い형용사 (白い shiroi) 와 な형용사 (静かな shizuka na); 모두 시제에 따라 활용
- **패턴**: 조사를 사용하지 않고 직접 명사 수식; 과거형 -かった (katta); 부정형 -くない (kunai)
- **출처**: N/A — 일본어 wiki 에 형용사 테마 미정

### 🇰🇷 한국어 (Korean)
- **핵심 용어**: 형용사 (hyeong-yongsa) 가 동사처럼 활용; 좋다 → 좋은 / 좋습니다 / 좋아요
- **패턴**: 과거 -았/었-; 부정 -지 않다; 명사 수식 시 -(으)ㄴ 사용 (좋은 사람)
- **출처**: N/A — 한국어 wiki 에 형용사 테마 미정

### 🇨🇳 중국어 (Chinese)
- **핵심 용어**: 단음절 (monosyllabic) vs 쌍음절 (disyllabic); 짧은 형용사+명사에서는 의 (de) 생략 가능
- **패턴**: 굴곡 없음; 정도 부사 很 (hěn) 가 "very" 가 아니어도 흔히 사용됨 (很好 = "좋다")
- **출처**: N/A — 중국어 wiki 에 형용사 테마 미정

## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 형용사를 배울 때 흔히 마주치는 함정

1. **"동사적 활용" 의 일반화 오류**:
   - 한국어는 형용사가 동사처럼 활용됨 (좋다 → 좋은/좋습니다/좋아서) → 학습자가 일본어의 い형용사 활용 (-かった/-くない) 은 자연스럽게 받아들이지만, 영어 "good/better/best" 의 불규칙 비교급이나 스페인어 성·수 일치 (-o/-a) 를 단순한 "동사 변화" 로 오인.
   - **함정**: EN/ES 는 형용사가 명사 수식어, 굴곡/일치가 핵심임을 명시. JP/KR 처럼 동사 활용이라고 가정하지 말 것.
   - **훈련법**: EN/ES 는 형용사 활용 매트릭스 — bueno → buena → buenos → buenas (성별+수 4형태) + good → better → best (불규칙 비교급) 학습. JP/KR 와 다른 구조 명시.

2. **성·수 일치 부재 에서의 "비일치 실수"**:
   - 한국어에는 성·수 일치가 없음 (좋은 책/좋은 책들 모두 같은 형용사) → 스페인어 학습 시 "buena libro" 같은 성별 오류 빈번.
   - **함정**: 스페인어 학습 초기 -o/-a 성별 표지 의식 부족 → 형용사 12개 기본 (rojo/roja/blanco/blanca 등) 4형태 암기 미흡.
   - **훈련법**: 스페인어 색깔/크기/좋음/나쁨 같은 기본 형용사 12개의 성별형 암기 + 적용 자동화.

3. **배치 (어순) 차이**:
   - 한국어는 항상 형용사가 명사 앞 (큰 집, 좋은 사람) → 일본어도 같아서 친숙. 그러나 스페인어는 기본이 명사 뒤 (casa grande) 이므로 어순 역전 발생.
   - **함정**: 스페인어 학습 시 "grande casa" (✗) 사용. 한국어 학습자가 일본어 와 유사 패턴 기대 → 스페인어 어순 역전.
   - **훈련법**: 스페인어 학습 시 "명사 먼저 → 형용사" 패턴 자동화. 처음부터부터 명사+형용사 순으로 쓰도록 의식적 연습.

4. **비교급 생성 방식 차이**:
   - 한국어는 "더" 라는 부사 추가 (더 큰) → 중국어 "更(gèng) + 형용사" 와 동일. 그러나 영어는 -er/-est 굴곡 (-er 추가), 스페인어는 "más +" + 형용사 (비교급 부사 별도).
   - **함정**: 한국어 학습자가 영어 비교급은 "more + 형용사" (예: more beautiful) 단순 사용 → 1음절 vs 2음절 이상 구분 무시.
   - **훈련법**: 영어 비교급은 "1음절 = -er/-est, 2음절 이상 = more/most" 규칙 학습. 스페인어는 "más + 형용사" 와 "menos + 형용사" (덜) 패턴 모두 숙지. 불규칙 비교급 (good/better/best, bad/worse/worst) 별도 암기.

5. **중국어 "很 (hěn) = very" 의 의미 변화**:
   - 한국어 학습자는 "very" 를 명시해야 한다고 배움 → 중국어 很好 가 그냥 "좋다" 라는 의미일 때 혼란.
   - **함정**: 중국어 很好 를 "매우 좋다" 로 번역 → "그냥 좋다" 의미일 때 오역.
   - **훈련법**: 중국어에서 很 는 종종 의미 없는 문법 조어로 기능. "매우" 강조 시에는 非常 (fēicháng) 또는 真 (zhēn) 사용. 很好 = 단순 "좋다", 非常好 = "매우 좋다" 구분.

### 학습 전략

1. **우선순위 1**: 한국어 형용사 -ㄴ/-은 패턴 마스터 (빨간/파란/노란) + 색 명사 결합 (빨강/파랑/노랑).
2. **우선순위 2**: 스페인어 성/수 일치 (-o/-a, 단수/) 20개 기본 형용사 암기.
3. **우선순위 3**: 영어 비교급 규칙 (-er/-est vs more/most) + 불규칙 (good/better, bad/worse) 학습.
4. **우선순위 4**: 일본어 い/나 분류 + 활용 패러다임 숙지 (한국어 형용사와 가장 유사한 구조).
5. **우선순위 5**: 중국어 의 (de) 생략 규칙 + 很 의 문법 조어화 학습.
