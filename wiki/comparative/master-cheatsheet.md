## English (EN) — Essential

### Basics
| EN | IPA | Notes |
|----|-----|-------|
| Hello | /həˈloʊ/ | Universal |
| Goodbye | /ɡʊdˈbaɪ/ | Universal |
| Please | /pliːz/ | Universal |
| Thank you | /θæŋk juː/ | Universal |
| Sorry | /ˈsɒri/ | Universal |
| Yes / No | /jɛs/ /noʊ/ | Universal |
| I / You / He/She/It | /aɪ/ /juː/ /hi, ʃi, ɪt/ | 3rd sg gender-neutral |

### Phrases
- "How are you?" — Standard greeting
- "I'm good, thanks." — Default reply
- "Where is the bathroom?" — Essential
- "How much?" — Shopping
- "I don't understand." — Politeness
- "Could you help me?" — Indirect polite request

### Grammar Quick Facts
- **Word order**: SVO
- **Articles**: a/an (indef), the (def)
- **Negation**: do/does + not + verb
- **Question**: Do/Does/Would/Could + S + V?
- **Pronouns**: He/She + They (singular they = neutral)

### Cultural Quick Facts
- Direct communication style
- First names quickly
- Eye contact = honesty
- Tipping 15-20% expected
- Personal space: ~arm's length

## Spanish (ES) — Essential

### Basics

| Sí / No | /si/ /no/ | Universal |
| Yo / Tú / Usted | /jo/ /tu/ /usˈteð/ (ES) | Tú (peer) / Usted (formal) |

### Phrases
- "¿Qué tal?" — How's it going?
- "Más o menos" — More or less
- "¿Dónde está...?" — Where is...?
- "¿Cuánto cuesta?" — How much?
- "No entiendo" — I don't understand
- "¿Puede ayudarme?" — Could you help me?

### Grammar Quick Facts
- **Word order**: SVO (flexible)
- **Articles**: el/la/los/las (def), un/una/unos/unas (indef)
- **Negation**: no + verb (pre-verbal)
- **Question**: intonation + ¿? marks
- **Pronouns**: Gendered (él/ella), formal vs informal (tú/usted)
- **Subjunctive**: WEIRDO triggers

### Cultural Quick Facts
- Tío/tía = buddy (Spain)
- Besos (2 kisses Spain, 1 LatAm)
- Tipping 5-10% (Spain) / 10% (LatAm)
- Late meals (lunch 14:00+, dinner 21:00+)
- Personal space: **close** talk

## Japanese (JP) — Essential

### Basics
| JP | Reading | Notes |
|----|---------|-------|
| こんにちは | Konnichiwa | Hello (daytime) |
| さようなら | Sayounara | Goodbye (formal) |
| お願いします | Onegaishimasu | Please |
| ありがとうございます | Arigatou gozaimasu | Thank you (polite) |
| すみません | Sumimasen | Sorry / Excuse me (polite) |
| はい / いいえ | Hai / Iie | Yes / No |
| 私 / あなた | Watashi / Anata | I (polite) / You (avoid) |

### Phrases
- "お元気ですか?" (Ogenki desu ka?) — How are you?
- "いただきます" (Itadakimasu) — Said before eating
- "ごちそうさまでした" (Gochisousama deshita) — Said after eating
- "いくらですか?" (Ikura desu ka?) — How much?
- "わかりません" (Wakarimasen) — I don't understand
- "助けてください" (Tasukete kudasai) — Please help

### Grammar Quick Facts
- **Word order**: SOV (verb last)
- **Articles**: NONE
- **Negation**: Verb suffix -nai (plain) / -masen (polite)
- **Question**: Particle か (ka) at end
- **Pronouns**: Avoid; use names + san/kun/chan
- **Keigo**: Honorific system (sonkeigo/kenjougo/teineigo)
- **Counters**: Mandatory (個/人/本/枚/台/匹...)

### Cultural Quick Facts
- Bow 15°/30°/45° based on respect
- Two hands giving/receiving
- No tipping (rude!)
- Quiet on transport
- *Kuuki o yomu* (read the air)
- Omotenashi (anticipatory service)

## Korean (KR) — Essential

### Basics
| KR | Hangul | Notes |
|----|--------|-------|
| 안녕하세요 | Annyeonghaseyo | Hello (polite default) |
| 안녕히 가세요 / 계세요 | Annyeonghi gaseyo / gyeseyo | Goodbye (to leaving/staying) |
| 주세요 | Juseyo | Please give me |
| 감사합니다 | Gamsahamnida | Thank you (polite) |
| 미안합니다 / 죄송합니다 | Mianhamnida / Joesonghamnida | Sorry / Sorry (formal) |
| 네 / 아니요 | Ne / Aniyo | Yes / No |
| 저 / 저희 | Jeo / Jeohui | I / We (humble) |

### Phrases
- "잘 지내세요?" (Jal jinaeseyo?) — How are you?
- "잘 먹겠습니다" (Jal meokkesseumnida) — Before eating
- "잘 먹었습니다" (Jal meogeosseumnida) — After eating
- "얼마예요?" (Eolmayeyo?) — How much?
- "이해 못 해요" (Ihae mot haeyo) — Don't understand
- "도와주세요" (Dowajuseyo) — Please help

### Grammar Quick Facts
- **Word order**: SOV (verb last)
- **Articles**: NONE
- **Negation**: Verb suffix -지 않다 (short) / -지 않습니다 (polite)
- **Question**: intonation + ~까? (~gga?, formal)
- **Speech levels**: 해체 (casual) / 해요체 (polite) / 합쇼체 (formal)
- **Pronouns**: Avoid; use names + 님/씨
- **Counters**: Mandatory (개/명/마리/장/대...)
- **Cannot vs Don't**: 못 vs 안/안

### Cultural Quick Facts
- Bow 30°/45°/90° (New Year = 큰절)
- Two hands giving/receiving (mandatory)
- No tipping (rare)
- Metal chopsticks (Korean-specific)
- Nunchi (social tact) essential
- Jeong (deep bond) over time

## Chinese (CH) — Essential

### Basics
| CH | Pinyin | Notes |
|----|--------|-------|
| 你好 | Nǐ hǎo | Hello |
| 再见 | Zàijiàn | Goodbye |
| 请 | Qǐng | Please |
| 谢谢 | Xièxie | Thank you |
| 对不起 / 不好意思 | Duìbuqǐ / Bù hǎoyìsi | Sorry / Excuse me |
| 是 / 不是 | Shì / Bù shì | Yes / No |
| 我 / 你 / 您 | Wǒ / Nǐ / Nín | I / You / You (respectful) |

### Phrases
- "你好吗?" (Nǐ hǎo ma?) — How are you?
- "吃了吗?" (Chī le ma?) — Have you eaten? (cultural greeting)
- "多少钱?" (Duōshǎo qián?) — How much?
- "我不懂" (Wǒ bù dǒng) — I don't understand
- "请帮帮我" (Qǐng bāng bang wǒ) — Please help me
- "没事" (Méi shì) — No problem

### Grammar Quick Facts
- **Word order**: SVO (flexible, topic-prominent)
- **Articles**: NONE
- **Negation**: 不 (bù) general / 没 (méi) past; 别 (bié) imperative
- **Question**: 吗 (ma) at end / A-not-A pattern
- **Tones**: 4 tones + neutral (mā má mǎ mà)
- **Measure words**: Mandatory (个/位/只/条/张...)
- **Aspect particles**: 了 / 过 / 着

### Cultural Quick Facts
- Guanxi (relationships) = currency
- Mianzi (face) = critical
- Title + surname (王老师, 张经理)
- Banquets = drinking culture (干杯 gānbēi)
- Gift giving (no clocks, no green hats)
- Mobile pay = WeChat/Alipay default
