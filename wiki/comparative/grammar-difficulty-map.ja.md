## 難易度スコアリング フレームワーク

| スコア | ラベル | 説明 |
|-------|-------|-------------|
| **1** | 些細 | L1 と同じか最小限の新規学習 |
| **2** | 簡単 | 新規だが透明、例外少ない |

| **性** | 自然 (代名詞) | **文法的** (M/F) | なし | なし | なし |
| **数** | 単/複 | 単/複 | **オプション** (複数接尾辞) | **オプション** (들) | なし |
| **冠詞** | **定/不定** (the/a) | **定/不定** (el/la/un/una) | なし | なし | なし |
| **動詞活用** | 最小限 (3rd sg -s) | **豊富** (人/数/時制/法) | **豊富** (ポライトネス/時制/アスペクト) | **豊富** (敬語/時制/アスペクト) | なし |

| **アスペクト** | 進行/完了 | 進行/完了 | **進行/完了/経験** | **進行/完了/経験** | **完了/経験/継続** |
| **法** | 直説/接続 (rare) | **直説/接続/命令** | **直説/命令/条件** | **直説/命令/Propositive** | **モーダル助詞** (吧/呢/啊/吗) |
| **態** | 能動/受動 | 能動/受動/再帰 | **能動/受動/使役** | **能動/受動/使役** | 能動/受動 (被/让/叫) |
| **否定** | 助動 + not | 動詞前 *no* | 接尾辞 *-nai/-masen* | 接尾辞 *-ji anta* | 動詞前 *bù/méi* |
| **疑問** | 助動倒置 / do-support | イントネーション / *¿?* | 助詞 *ka* / イントネーション | イントネーション / 助詞 *nya* | 助詞 *ma* / *A-not-A* |
| **関係節** | 関係代名詞 (who/which) | 関係代名詞 (que/quien) | **名詞前置** (関係代名詞なし) | **名詞前置** (関係代名詞なし) | **名詞前置** (的) |
| **形容詞** | 名詞前、一致なし | **名詞後、一致** | **i-adj / na-adj** (活用) | **描写動詞** (活用) | **状態動詞** (一致なし) |
| **副詞** | -ly 接尾辞、位置柔軟 | -mente 接尾辞、柔軟 | **-ku / -ni** 接尾辞 | **-ge / -i** 接尾辞 | **動詞前** 位置 |
| **比較級** | -er/more + than | *más/menos + que* | **Yori / hodo** | **Boda / de** | **Bi / gen / hai** |
| **所有** | 's / of / 所有代名詞 | *de* + 所有形容詞 | **No** (の) | **의** | **的** |
| **再帰** | -self 代名詞 | **se** (clitic) | **自分 (jibun)** | **자기 (jagi)** | **自己 (zìjǐ)** |
| **相互** | each other | *el uno al otro* | *otagai* | *seoro* | *huxiang / bici* |

## 学習順序推奨

### 英語話者 → スペイン語
1. **発音** (5 母音、trill、ストレス ルール)
2. **現在直説法** (全動詞)
3. **性/数一致** (名詞、形容詞)
4. **Ser vs Estar** + 基本形容詞
5. **過去時制** (preterite vs imperfect)
6. **接続法トリガー** (WEIRDO)
6. **接続法形** (現在 → 不完了 → 完了)
7. **代名詞** (DO/IO/再帰配置)
8. **上級** (条件法、未来、受動 *se*)

### 英語話者 → 日本語
1. **ひらがな/カタカナ** (リテラシー)
2. **発音** (5 母音、ピッチ導入、モーラ timing)
3. **基本助詞** (wa, ga, o, ni, de, no)
4. **動詞グループ** (ru/u/不規則) + ます形
5. **基本形容詞** (i/na) + 活用
6. **て形** (依頼、接続)
7. **過去/否定** (全形)
7. **基本漢字** (100-200 常用)
8. **カジュアル/plain forms** (辞書形)
9. **敬語入門** (尊敬語/謙譲語)
10. **上級** (受動、使役、条件、2000+ 漢字)

### 英語話者 → 韓国語
1. **ハングル** (数時間でリテラシー)
2. **発音** (バッチム、3 方向破裂音、liaison)
3. **基本助詞** (이/가, 을/를, 에/에서, 의, 와/과)
4. **動詞活用** (해요체 → 합쇼체 → 해체)
5. **基本形容詞** (描写動詞)
6. **過去/否定/未来** (全 speech level)
7. **敬語** (존댓말/반말, 시/으시, 드리다/잡수시다)
8. **助数詞** (主要 20+)
9. **上級文法** (受動、使役、条件、~게/~아/어도)
10. **ハンジャ** (オプション、1800 基本)

### 英語話者 → 中国語
1. **拼音 + 声調** (毎日 drill)
2. **基本部首** (50 主要)
3. **核心 300 文字** (HSK 1-2)
4. **SVO + トピック-コメント** 構造
5. **アスペクト助詞** (了/过/着/的/得/地)
6. **量詞** (主要 30)
7. **比較級** (比/更/最/跟/一样)
8. **モーダル助詞** (吧/呢/啊/吗/啦)
9. **上級** (把/被/让/叫, 成語, 3000+ 字)

## 🇯🇵 日本語学習者ノート (Japanese Learner Notes)

> 本セクションは日本語学習者向けの追加学習ガイドです。

### 日本語話者が他の4言語を学ぶ際の難易度ポイント

1. **SOV → SVO への切り替え (英語/スペイン語/中国語)**:
   - 日本語の SOV 構文 (「私はりんごを食べる」) → 英語 "I eat apples" / スペイン語 "Como manzanas" / 中国语 "我吃苹果"。
   - **練習法**: 機械的に SVO 構文を練習; 文の主語と動詞を先に置く習慣をつける。

2. **冠詞の獲得 (英語/スペイン語)**:
   - 日本語に冠詞なし → 英語 "a book" / スペイン語 "un libro" の冠詞を忘れる。
   - **練習法**: 不定冠詞 (a/an) と定冠詞 (the) の使い分けを反復練習。

3. **中国語声調の取得**:
   - 日本語はピッチ アクセント → 中国語は声調 (4 声 + 中性)。
   - **練習法**: 毎日のピンイン + 声調練習; ネイティブ音声を模倣。

4. **スペイン語性一致の克服**:
   - 日本語に性なし → スペイン語の tía/tío, libro/libra のような性一致を忘れる。
   - **練習法**: 名詞の性を「el/la」+ 名詞でペア暗記; 文を書く際にも常に意識。

5. **韓国語バッチムと 3 方向破裂音**:
   - 日本語にバッチムなし、3 方向破裂音なし → 韓国語の複雑な子音体系に苦労。
   - **練習法**: ハングルをまず完璧に; バッチム ルールを体系的に学習; ネイティブ音声模倣。
