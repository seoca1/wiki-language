# Grammar Difficulty Map — Cross-Language Comparison

**Languages**: English · Spanish · Japanese · Korean · Chinese
**Last updated**: 2026-07-19

> Feature-by-feature difficulty ranking for learners. Based on typological distance, acquisition research, and teaching experience.

---

## Difficulty Scoring Framework

| Score | Label | Description |
|-------|-------|-------------|
| **1** | Trivial | Same as L1 or minimal new learning |
| **2** | Easy | New but transparent, few exceptions |
| **3** | Moderate | New concept, some exceptions |
| **4** | Hard | Complex paradigm, many exceptions |
| **5** | Very Hard | Alien concept, pervasive, high error rate |

## Morphosyntax Feature Matrix

| Feature | English | Spanish | Japanese | Korean | Chinese |
|---------|---------|---------|----------|--------|---------|
| **Word Order** | SVO (rigid) | SVO (flexible) | **SOV** (rigid) | **SOV** (rigid) | SVO (flexible) |
| **Case Marking** | None (pronouns only) | None | **Particles** (が/を/に/で/へ/と/の) | **Particles** (이/가/을/를/에/에서/와/과/의) | None |
| **Gender** | Natural (pronouns) | **Grammatical** (M/F) | None | None | None |
| **Number** | Singular/Plural | Singular/Plural | **Optional** (plural suffixes) | **Optional** (들) | None |
| **Articles** | **Def/Indef** (the/a) | **Def/Indef** (el/la/un/una) | None | None | None |
| **Verb Conjugation** | Minimal (3rd sg -s) | **Rich** (person/number/tense/mood) | **Rich** (politeness/tense/aspect) | **Rich** (honorific/tense/aspect) | None |
| **Tense** | Past/Present (periphrastic future) | **Past/Present/Future** (synthetic) | **Past/Non-past** | **Past/Present/Future** | **Aspect-only** (了/过/着) |
| **Aspect** | Progressive/Perfect | Progressive/Perfect | **Progressive/Perfect/Experiential** | **Progressive/Perfect/Experiential** | **Perfective/Experiential/Durative** |
| **Mood** | Indicative/Subjunctive (rare) | **Indicative/Subjunctive/Imperative** | **Indicative/Imperative/Conditional** | **Indicative/Imperative/Propositive** | **Modal particles** (吧/呢/啊/吗) |
| **Voice** | Active/Passive | Active/Passive/Reflexive | **Active/Passive/Causative** | **Active/Passive/Causative** | Active/Passive (被/让/叫) |
| **Negation** | Aux + not | Pre-verbal *no* | Suffix *-nai/-masen* | Suffix *-ji anta* | Pre-verbal *bù/méi* |
| **Questions** | Aux inversion / do-support | Intonation / *¿?* | Particle *ka* / intonation | Intonation / particle *nya* | Particle *ma* / *A-not-A* |
| **Relative Clauses** | Relative pronouns (who/which) | Relative pronouns (que/quien) | **Pre-nominal** (no relative pronoun) | **Pre-nominal** (no relative pronoun) | **Pre-nominal** (的) |
| **Adjectives** | Pre-nominal, no agreement | **Post-nominal, agreement** | **i-adj / na-adj** (conjugate) | **Descriptive verbs** (conjugate) | **Stative verbs** (no agreement) |
| **Adverbs** | -ly suffix, flexible position | -mente suffix, flexible | **-ku / -ni** suffixes | **-ge / -i** suffixes | **Pre-verbal** position |
| **Comparatives** | -er/more + than | *más/menos + que* | **Yori / hodo** | **Boda / de** | **Bi / gen / hai** |
| **Possession** | 's / of / possessive pron | *de* + possessive adj | **No** (の) | **의** | **的** |
| **Reflexives** | -self pronouns | **se** (clitic) | **自分 (jibun)** | **자기 (jagi)** | **自己 (zìjǐ)** |
| **Reciprocals** | each other | *el uno al otro* | *otagai* | *seoro* | *huxiang / bici* |

## Error Profile by L1

| L1 → Target | Fossilized Errors | Why |
|-------------|-------------------|-----|
| **EN → ES** | *yo voy a voy* (double verb), gender agreement, ser/estar, subjunctive avoidance | L1 lacks gender, subjunctive |
| **EN → JP** | Particle omission (wa/ga), plain form with seniors, pitch accent flat | No particles, no honorifics |
| **EN → KR** | Batchim errors, plain form with seniors, three-way stop collapse | No batchim, no three-way |
| **EN → CH** | Tone errors (esp. 3rd), no aspect particles, SVO in embedded clauses | No tone, no aspect, different embedding |
| **ES → EN** | *I am agree*, *I have 25 years*, no subject, vowel reduction, phrasal verbs | Pro-drop, no phrasal verbs |
| **JP → EN** | No articles, *he go*, flat intonation, no stress reduction, *the* overuse | No articles, no stress |
| **KR → EN** | No articles, *he go*, flat intonation, *the* overuse, preposition errors | No articles, no stress |
| **CH → EN** | No articles, *he go*, flat intonation, *the* overuse, tense errors, preposition errors | No tense, no articles |
| **JP ↔ KR** | Honorific mismatch, pitch vs flat, batchim errors | Different systems |

## Learning Sequence Recommendations

### For English Speakers → Spanish
1. **Pronunciation** (5 vowels, trill, stress rules)
2. **Present indicative** (all verbs)
3. **Gender/number agreement** (nouns, adjectives)
4. **Ser vs Estar** + basic adjectives
5. **Past tenses** (preterite vs imperfect)
6. **Subjunctive triggers** (WEIRDO)
6. **Subjunctive forms** (present → imperfect → perfect)
7. **Pronouns** (DO/IO/Reflexive placement)
8. **Advanced** (conditional, future, passive *se*)

### For English Speakers → Japanese
1. **Hiragana/Katakana** (literacy)
2. **Pronunciation** (5 vowels, pitch intro, mora timing)
3. **Basic particles** (wa, ga, o, ni, de, no)
4. **Verb groups** (ru/u/irregular) + masu-form
5. **Basic adjectives** (i/na) + conjugation
6. **Te-form** (requests, connections)
7. **Past/negative** (all forms)
7. **Basic kanji** (100-200 Jōyō)
8. **Casual/plain forms** (dictionary form)
9. **Keigo intro** (sonkeigo/kenjougo)
10. **Advanced** (passive, causative, conditionals, 2000+ kanji)

### For English Speakers → Korean
1. **Hangul** (literacy in hours)
2. **Pronunciation** (batchim, three-way stops, liaison)
3. **Basic particles** (이/가, 을/를, 에/에서, 의, 와/과)
4. **Verb conjugation** (해요체 → 합쇼체 → 해체)
5. **Basic adjectives** (descriptive verbs)
6. **Past/negative/future** (all speech levels)
7. **Honorifics** (존댓말/반말, 시/으시, 드리다/잡수시다)
8. **Counters** (core 20+)
9. **Advanced grammar** (passive, causative, conditionals, ~게/~아/어도)
10. **Hanja** (optional, 1800 basic)

### For English Speakers → Chinese
1. **Pinyin + Tones** (drill daily)
2. **Basic radicals** (50 most common)
3. **Core 300 characters** (HSK 1-2)
4. **SVO + topic-comment** structure
5. **Aspect particles** (了/过/着/的/得/地)
6. **Measure words** (core 30)
7. **Comparatives** (比/更/最/跟/一样)
8. **Modal particles** (吧/呢/啊/吗/啦)
9. **Advanced** (把/被/让/叫, 成语, 3000+ chars)
