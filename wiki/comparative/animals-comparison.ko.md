## 언어별 상세

### 🇬🇧 영어 (English)
- **핵심 용어**: "Pet" vs "Domestic animal"; "Livestock" (농장 동물); "Wildlife"
- **패턴**: 동물 + 울음 동사 ("the dog barks", "the cat meows")
- **출처**: `[[animals-vocabulary]]`

### 🇪🇸 스페인어 (Spanish)
- **핵심 용어**: "Mascota" (애완동물), "Animal doméstico" (가축), "Fauna" (야생동물)
- **패턴**: 성 일치: gato/gata, perro/perra; -ar 동사 활용
- **출처**: `[[animals-vocabulary]]`

### 🇯🇵 일본어 (Japanese)
- **핵심 용어**: 動物 (dōbutsu = 동물); ペット (petto = 애완동물); 野生動物 (yasei dōbutsu = 야생동물)
- **패턴**: 동사: 〜が鳴く (ga naku = 동물이 울다); 명사+の: 猫の鳴き声
- **출처**: `[[animals-vocabulary]]`

### 🇰🇷 한국어 (Korean)
- **핵심 용어**: 동물 (dongmur), 반려동물 (baeryu-dongmur = 반려 동물); 가축 (gachuk = 가축)
- **패턴**: 동사: 〜이/가 울다 (울다); 명사 결합: 강아지 (개 + 강아지)
- **출처**: `[[animals-vocabulary]]`

### 🇨🇳 중국어 (Chinese)
- **핵심 용어**: 动物 (dòngwù), 宠物 (chǒngwù), 家畜 (jiāchù = 가축)
- **패턴**: 동사: 〜叫 (jiào = 울다); 명사 + 명사: 老虎 (lǎohǔ)
- **출처**: N/A — 중국어 동물 테마 미정

## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 동물 어휘를 배울 때 흔히 마주치는 함정

1. **한자어 vs 순우리말 패턴 학습**:
   - 한국어는 한자어 (사자=獅子, 호랑이=虎) 와 순우리말 (고양이, 물고기) 가 공존 → 학습자가 일본어/중국어와 매칭 시 혼란.
   - **함정**: "호랑이/虎/老虎" 처럼 한자어 매칭은 자명하지만, "고양이/猫/猫" 처럼 한국어만 순우리말인 경우 한자 매핑이 어려움.
   - **훈련법**: JP/KR/ZH 공유 한자 동물 (犬/개/狗, 馬/말/马, 魚/물고기/鱼, 牛/소/牛, 羊/양/羊, 鹿/사슴/鹿, 虎/호랑이/虎) 7개 먼저 마스터. 한국어 토착어만 있는 동물 (고양이/오징어/문어/게/새우) 은 별도 학습.

2. **음절 수 차이**:
   - 한국어 동물 어휘는 평균 2-3음절 (고양이=3, 토끼=2, 문어=2) → 중국어는 단음절 (猫=1, 兔=1, 章鱼=2) 인 경우가 많음.
   - **함정**: 중국어 학습 시 한 글자 동물을 한국어 2음절로 변환하는 데 시간 걸림 (호랑이 ↔ 老虎 2글자, 사자 ↔ 狮子 2글자).
   - **훈련법**: 한국어 학습자는 한자 단독 발음 (shī=狮, hǔ=虎, lóng=龙) 을 먼저 익히고 결합 학습. 일본어 음독 (inu, neko, uma) 도 같은 방식.

3. **성·수 일치 (스페인어) 의 어려움**:
   - 스페인어 gato/gata (남성/여성), perro/perra — 한국어에는 성별이 없음 → 학습자가 동물 성별 무시.
   - **함정**: "perro" 는 수컷 개, "perra" 는 암컷 개 → 일반적으로 "개" 만 쓸 때 perro 도 사용하나, 암컷을 강조해야 할 때 perra 필수.
   - **훈련법**: 스페인어 동물 어휘는 암수쌍을 동시에 학습 (gato/gata, perro/perra, caballo/yegua, toro/vaca) — 12쌍 기본 암기.

4. **복수형 처리 (스페인어/영어)**:
   - 영어 dogs/cats, 스페인어 perros/gatos — 한국어는 복수형이 없음 ("개들" 은 "들" 접사).
   - **함정**: 한국어 학습자가 스페인어 복수형 (-s/-es) 를 잊은 채 "los perro" (✗) 사용.
   - **훈련법**: 스페인어 정관사 (el/los, la/las) + 단수/복수 명사 일치를 동시에 학습. 영어는 단순 -s/-es 와 불규칙 (mouse/mice, fish/fish) 분리.

5. **신화 동물의 동아시아 공유성**:
   - 한국어 화자는 龍(용) / 鳳凰(봉황) / 虎(호랑이) 의 한자 신화를 익히지만, 영어 "dragon" 이 서양 신화 (용, fire-breathing) 와 동아시아 신화 (龍, 물/구름 관련) 가 다르다는 점 인지 부족.
   - **함정**: 영어 "dragon" 을 東洋龍 과 동일시 → 서양 신화 이해 부족.
   - **훈련법**: 동아시아 공유 신화 동물 (龍/용/龙, 鳳凰/봉황/凤凰, 麒麟/기린/麒麟, 龜/거북/龟) 의 문화적 맥락 학습. 서양 신화 (dragon, phoenix, unicorn) 와 구분.

### 학습 전략

1. **우선순위 1**: 한국어 기축 동물 어휘는 이미 친숙 → JP/CN 매칭 한자어 7개 먼저 마스터 (犬/馬/牛/羊/鹿/虎/魚).
2. **우선순위 2**: 스페인어 동물 성별쌍 (gato/gata, perro/perra 등) 12쌍 암기.
3. **우선순위 3**: 영어 동물 불규칙 복수형 (mouse/mice, fish/fish, sheep/sheep) 학습.
4. **우선순위 4**: 중국어 양사 (量詞) — 1隻狗 (yī zhī gǒu) / 1条鱼 (yī tiáo yú) / 1匹马 (yī pǐ mǎ) — 양사가 동물이 따라 다름.
5. **우선순위 5**: 신화 동물 동아시아 vs 서양 차이 인식.
