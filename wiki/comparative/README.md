## What's Inside

This directory contains **24 cross-language comparison pages** organized into 6 categories:

1. **Core Linguistic Systems** — Politeness, greetings, numbers, pronouns, negation
2. **Situational / Thematic** — Travel, food, business, dating, shopping, health, time
3. **Cultural Concepts** — Untranslatables, values, gestures, idioms, slang
4. **Learning Strategy** — Writing systems, pronunciation, grammar difficulty, cheatsheet
5. **Modern / Contemporary** — Tech & internet, literature & media

## Conventions

- **Source citations**: Every cell links to per-language wiki source pages via `[[wiki/{Language}/...]]` wikilinks
- **5-language matrix**: Each comparison table has columns for EN, ES, JP, KR, CH
- **Synthesis sections**: Each page includes "Key Contrasts" and "Quick Reference Card" for actionable insights
- **L1 transfer awareness**: Pages note common learner errors based on first language

## Cross-Project Notes

The comparative wiki is a **reference resource** derived from the per-language wikis. It does not modify them. When the per-language wikis are updated, the comparative pages may need corresponding updates to maintain accuracy.
