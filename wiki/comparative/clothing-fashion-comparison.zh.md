## 各语言详情

### 🇬🇧 英语 (English)
- **核心**: "Apparel" (正式), "Clothes" (一般), "Outfit" (具体套装)
- **模式**: "Wear" + 名词; "Dress" 作动词 vs 名词 (不同含义)
- **来源**: `[[clothing-vocabulary]]`

### 🇪🇸 西班牙语 (Spanish)
- **核心**: "Ropa" (服装), "Indumentaria" (正式/工业)
- **模式**: -ar 动词: usar (穿); 反身: "vestirse" (穿衣)
- **来源**: `[[clothing-vocabulary]]` (主题存在但内容有限)

### 🇯🇵 日语 (Japanese)
- **核心**: 服 (fuku = 衣服), 服飾 (fukushoku = 时装), 衣類 (irui = 服装)
- **模式**: 动词: 〜を着る (wo kiru); 动词: 〜を履く (wo haku = 穿下身)
- **来源**: `[[clothing-vocabulary]]`

### 🇰🇷 韩语 (Korean)
- **核心**: 옷 (ot = 衣服), 의류 (eoryu = 服装), 한복 (hanbok = 传统)
- **模式**: 动词: 입다 (ipda = 穿上身); 신다 (sinda = 穿鞋); 쓰다 (sseuda = 戴头上)
- **来源**: `[[clothing-vocabulary]]`

### 🇨🇳 中文 (Chinese)
- **核心**: 衣服 (yīfu), 服装 (fúzhuāng = 服装), 汉服 (hànfú)
- **模式**: 动词: 穿 (chuān); 量词: 件 (jiàn) 用于服装
- **来源**: N/A — 中文暂无服装专题

## 关键对比 (综合)

| 对比 | 洞察 |
|------|------|
| **动词区分** | JP/KR 有上身/下身/鞋的分立动词; EN/ES/ZH 用单一 "wear/穿" 动词 |
| **传统服饰** | JP/KR/ZH 保留独立传统服装 (kimono/hanbok/hàn fú) — 现代时尚更全球化 |
| **借词** | 所有语言都借 "jeans" (ジーンズ/청바지/牛仔裤) — 但翻译不同 |
| **尺寸/颜色** | EN/ES 用拉丁词; JP/KR/ZH 用本土或 한자/汉字 词 |

## 🇨🇳 中文学习者笔记 (Chinese Learner Notes)

> 本节是面向中文母语学习者的额外学习指南。

### 中文母语者在学习其他4种语言服装词汇时的常见陷阱

1. **汉字共享但发音不同**:
   - 中文 *帽子/手套/外套* 与日语 *帽子 (bōshi)* / *手袋 (tebukuro)* / *外套 (gaibako?)* 汉字相似但发音不同。
   - **陷阱**: 学员期望看到汉字就能读, 但日语发音完全不同。
   - **训练法**: 服装词 5 语言发音表 (帽子/靴/靴下/手袋 — 各自发音)。

2. **韩语"穿"根据身体部位区分**:
   - 中文 *穿鞋/穿衣服* 同一动词 → 学员对韩语不同动词困惑。
   - **陷阱**: 韩语 *신다 (穿鞋)*, *입다 (穿衣服)*, *쓰다 (戴帽子)*, *끼다 (戴戒指)*, *걸치다 (披外套)* 多动词。
   - **训练法**: 韩语"穿"动词表 (按身体部位分类 — 5+ 动词)。

3. **日语"穿"根据产品类型区分**:
   - 与韩语类似, 日语 *着る (穿衣服)* vs *履く (穿下身/鞋)* vs *被る (戴帽)*。
   - **陷阱**: 日语 *履く* 用于裤子、鞋、袜子; *穿* 不分。
   - **训练法**: 日语"穿"动词分类 (上身/下身/头上/手 — 5 动词)。

4. **西班牙语性一致**:
   - 中文 *裤子/鞋* 无性 → 学员对西班牙语 *los pantalones (m.)* / *las zapatillas (f.)* 困惑。
   - **陷阱**: 西班牙语服装名词多为阳性, 但 *las zapatillas* (f.), *las sandalias* (f.) 等为阴性。
   - **训练法**: 服装名词性别表 (男性 vs 女性 — 50 词)。

5. **"和服/韩服/汉服"的现代使用**:
   - 中文 *汉服* 复兴运动 → 学员假设和服/韩服也是日常服装。
   - **陷阱**: 日韩 *和服/韩服* 主要在仪式/婚礼使用; 现代人日常穿西式服装。
   - **训练法**: 区分 *传统服饰保留度* (JP/KR 文化习惯 vs CN 当代复兴运动)。
