## 各言語詳細

### 🇬🇧 英語 (English)
- **Key terms**: "Fiction" vs "Non-fiction"; "Genre fiction" (genre-specific vs literary)
- **Patterns**: "Read a book" / "Write a novel"; past participle as adjective common
- **出典**: `[[literature-passages]]` (EN-only source)

### 🇪🇸 スペイン語 (Spanish)
- **Key terms**: "Realismo mágico" (magical realism); "Novela picaresca" (picaresque novel — Spanish-origin genre)
- **Patterns**: -ista nouns for authors (Garcia Marquez = el escritor); "leer" (to read)
- **出典**: `[[literatura-hispana]]` (Spanish source)

### 🇯🇵 日本語 (Japanese)
- **Key terms**: ライトノベル (light novel); 漫画 (manga); 文学 (bungaku = literature)
- **Patterns**: Verb: 〜を読む (wo yomu); "作家になる" = become a writer
- **出典**: `[[literature-vocabulary]]`

### 🇰🇷 韓国語 (Korean)
- **Key terms**: 웹소설 (web novel), 웹툰 (webtoon), 문학 (literature)
- **Patterns**: Verb: 〜을 읽다 (eul ikda); "소설가" = novelist
- **出典**: `[[literature-vocabulary]]`

### 🇨🇳 中国語 (Chinese)
- **Key terms**: 武侠 (wuxia), 仙侠 (xianxia), 言情 (romance); 古典 (classical); 现代 (modern)
- **Patterns**: Verb: 〜阅读 (yuèdú); "作家" (jiā = family); classifier: 一本 (yī běn = one book)
- **出典**: N/A — Chinese lacks explicit literature theme yet

## 主要な対比 (総合)

| 対比 | 学習者への示唆 |
|----------|---------|
| **Reading culture** | KR has highest per-capita reading rate; JP has manga as mainstream literature; CN has web novel dominance |
| **Modern genres** | 武侠/仙侠 (CN-origin, KR/JP adopted as 무협/仙侠); Light Novel (JP-origin, exported as 轻小说) |
| **Formality** | All languages have formal/informal literature distinction; classical vs modern universal |
| **Translation conventions** | All 5 languages use "translator" + name format; honorifics preserved in formal translations |

## 学習者決定ガイド

> **Literary vocabulary**:
> - 作家 (sakka) / 작가 (jakga) / 作者 (zuòzhě) = author (all 3 CJK use single-char 作家/작가/作家 variants)
> - Novel: 小説/소설/小说 — all share 한자 小说 origin
> - Genre: ジャンル/장르/类型 — JP/KR borrowed EN "genre"

## 🇯🇵 日本語学習者ノート (Japanese Learner Notes)

> 本セクションは日本語学習者向けの追加学習ガイドです。

### 日本語話者が他4言語の文学を学ぶ際の一般的な落とし穴

1. **漢字文化の過信**:
   - 日本語は漢字 (kanji) を共有するが、繁体字/簡体字、両国音読み/国音読みの差で混同しがち。
   - **落とし穴**: 日本語の「小説」をそのまま中国語の「小说」だと理解する — 音読みは「しょうせつ」、北京語拼音では「xiǎoshuō」と大きく異なる。
   - **練習法**: 漢字語の翻訳は「日本語漢字 → 中国語繁体字 → 簡体字」変換の練習を日次で。

2. **ライトノベル/Web小説の文化差**:
   - 日本語話者はライトノベル → 中国語に「轻小说」と訳すが、Web小説文化は韓国発 → 「웹소설」。
   - **落とし穴**: 日本語の「なろう系」を他言語に直接翻訳しても概念が通じない (文化的背景が異なる)。
   - **練習法**: 各言語の代表的Web小説・ライトノベルを 1作品ずつ原語で読む (日: 『転生したらスライムだった件』、韓: 웹소설 플랫폼、中: 起点中文网)。

3. **古典文学の翻訳理解**:
   - 日本語は古文 (こぶん) 才能を古典と共有するが、現代中国語話者は文語 (wényǔ) を直接読めないことが多い。
   - **落とし穴**: 日本語の「源氏物語」を中国語に翻訳する際、「紫式部」を作家名と思ってしまう (実際は「紫式部」が女性作家の雅号)。
   - **練習法**: 古典文学の原語対訳 (原文+現代語訳) を目標言語で読む習慣。

4. **アルファベット文化の文学用語**:
   - 英語・スペイン語圏では「Novel」「Novela」「Genre」「Género」とラテン語系用語が支配的。
   - **落とし穴**: 日本語・韓国語・中国語圏でもカタカナ/ハングル/簡体字 translation が増えており、「ミステリー」「로맨스」「言情」を混同しがち。
   - **練習法**: 各言語の文学用語集を3言語対訳で暗記 (例: Mystery＝ミステリー＝미스터리＝推理＝misterio)。

5. **翻訳書のタイトル処理**:
   - 日本語は翻訳書名に「〜」 (原作タイトル) + 「〜」 (副題) 形式が一般的。
   - **落とし穴**: 韓国語の翻訳書名は原語そのまま (예: 『채식주의자』) なのに、日本語では「菜食主義者」と意訳することが多い。
   - **練習法**: 各言語のベストセラーリストを月次で確認、原語タイトルを覚える。
