## 언어별 상세

### 🇬🇧 영어 (English)
- **핵심 용어**: eat, sleep, work, exercise, study, walk, run, read, write, talk
- **패턴**: 약동사 (work-worked-worked) vs 강동사 (eat-ate-eaten); 진행형 uses "be + V-ing"
- **격식 메모**: 동사 자체에 격식 표지 없음; 대명사와 억양으로 격식 표현
- **출처**: `[[wiki/English/vocabulary/daily-life-basics]]`

### 🇪🇸 스페인어 (Spanish)
- **핵심 용어**: comer, dormir (o→ue), trabajar, estudiar, hacer ejercicio
- **패턴**: 3가지 활용 유형 (-ar/-er/-ir); 어미 변동 동사 (dormir → duermo)
- **지역 변이**: Vosotros (스페인) vs ustedes (라틴아메리카) for "you all"; *vos* in Rioplatense
- **출처**: `[[wiki/Spanish/vocabulary/daily-life-basics]]`

### 🇯🇵 일본어 (Japanese)
- **핵심 용어**: 食べる (taberu), 寝る (neru), 働く (hataraku), 運動する (undō), 勉強する (benkyō)
- **패턴**: 동사 그룹: 1그룹 (godan: 食べる→食べた) and 2그룹 (ichidan: 寝る→寝た); て形 for progressive
- **Keigo / 경어**: ます形 (중립 정중) → plain form (캐주얼); 비즈니스용 尊敬語/謙譲語
- **출처**: `[[wiki/Japanese/vocabulary/daily-life-basics]]`

### 🇰🇷 한국어 (Korean)
- **핵심 용어**: 먹다 (meokda), 자다 (jada), 일하다 (ilhada), 운동하다, 공부하다
- **패턴**: 하다 (hada) 가 한자어 명사에 결합 (공부 + 하다); 모음 조화 과거 (았/었)
- **말투 단계**: 해요체 (-yeo, 정중 캐주얼) / 합쇼체 (-seumnida, 격식) / 해체 (비격식)
- **출처**: `[[wiki/Korean/vocabulary/daily-life-basics]]`

### 🇨🇳 중국어 (Chinese)
- **핵심 용어**: 吃 (chī), 睡 (shuì), 工作 (gōngzuò), 锻炼 (duànliàn), 学习 (xuéxí)
- **패턴**: 상(相) 조사 了 (le = 완료) 와 过 (guò = 경험) 로 한정; 着 (zhe) for progressive
- **격식 / 존경**: 您 (nín) ) 존경 "you"; 동사 자체 굴곡 없음
- **출처**: `[[wiki/Chinese/vocabulary/daily-life-basics]]`

| **과거 시제 표지** | EN/ES/JP/KR 모두 명확한 과거 형태 보유; CH 는 동사 뒤 了 (le) 조사 사용 |
| **진행** | EN "be+V-ing"; JP/KR 보조 동사 사용 (ている/고 있다); CH 는 着 (zhe) |
| **동사 격식** | JP/KR 는 동사 형태에 격식 활용; EN/ES/CH 는 대명사/어휘로 격식 |

## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 일상 동사를 배울 때 흔히 마주치는 함정

1. **"-하다" 동사 패턴의 일반화 오류**:
   - 한국어 학습자는 "공부하다/운동하다/일하다" 의 -하다 동사 패턴을 자연스럽게 사용 → 영어 "to study" / 스페인어 "estudiar" / 중국어 "学习" 와 매칭 시 -하다 구조 기대.
   - **함정**: 그러나 영어 "to study" / 스페인어 "estudiar" 는 독립 동사 (-하다 없음), 일본어 勉強する (benkyō suru) 는 "する" 결합이지만 한국어 -하다 와 다른 구조. 중국어 学习 는 명사/동명사 겸용.
   - **훈련법**: 동사 유형 분류 — EN/ES 독립 동사 (study/estudiar) / JP する 결합 (勉強する) / KR -하다 결합 (공부하다) / CH 名동사 겸용 (学习). 어순 차이 의식.

2. **시제 활용의 깊이 차이**:
   - 한국어는 과거 (-았/었) + 미래 (-겠/을 거) 활용 보유 → 영어 학습 시 과거/현재/미래 시제 일관 사용. 그러나 중국어는 "내일 먹어 (will eat)" 처럼 시제 생략 가능.
   - **함정**: 한국어 학습자가 중국어 회화에서 "I will eat tomorrow" 시제 일관 사용 → 중국어 화자는 "明天吃" 으로 충분하다고 느낌.
   - **훈련법**: 시제 표지 비교 매트릭스 — EN 필수 (eat/ate/will eat) / ES 필수 (como/comí/comeré) / JP 활용 (食べる/食べた/食べる+だろう) / KR 활용 (먹어/먹었다/먹을 거) / CH 상(相) 조사 (了/过/会).

3. **진행형 ("-고 있다") 의 언어별 차이**:
   - 한국어 "공부하고 있다" = 진짜 진행 중. 영어 "I'm studying" 도 같음. 그러나 중국어 我在学习 (wǒ zài xuéxí) 는 "habitual" 의미 가능 (현재 학습 중).
   - **함정**: 한국어 학습자가 중국어 我在学习 를 "지금 공부하는 중" 으로만 번역 → 중국어 화자는 "학습 중 (습관적)" 의미일 수 있음.
   - **훈련법**: 진행/습관 구분 학습 — EN I'm studying (진행) vs I study (습관) / KR -고 있다 (진행) vs -한다 (습관) / CH 我在学习 (진행+습관) / JP 勉強している (진행) vs 勉強する (습관).

4. **"자다/잤다" 와 寝る/寝た 의 시제 표지**:
   - 한국어 자다 / 잰다 는 활용 변화 (모음조화 적용) → 영어 sleep/slept, 스페인어 dormir/dormí, 일본어 寝る/寝た 모두 명확한 시제 표지. 중국어 睡/睡了 는 동사 + 了 조사.
   - **함정**: 한국어 학습자가 중국어 회화에서 "I slept yesterday" 에서 了 (le) 를 생략 → 과거 명확성 부족.
   - **훈련법**: 과거 시제 표지 비교 — EN -ed 불규칙/규칙 / ES -é (1인칭) / JP た形 / KR -았/었- / CH 了 (le) + 위치 의존 (동사 후 or 문장말).

5. **모음 조화 (-았/었) 와 일본어 た형 활용의 차이**:
   - 한국어 과거형은 모음조화 (가+았 = 갔, 먹+었 = 먹었) → 일본어 た形 (食べ+た = 食べた) 도 어미 변동이지만 한국어와 다른 모음 변화.
   - **함정**: 한국어 학습자가 일본어 た형 적용 시 한국어 모음조화 규칙 적용 → 잘못된 활용.
   - **훈련법**: 한국어 모음조화 vs 일본어 た형 변동 매트릭스 — 行く (iku, 1그룹) → 行った (itta, 행+았 처럼 っ+た) / 食べる (taberu, 2그룹) → 食べた (tabeta, 먹+었 처럼 べ+た). 두 언어의 활용 규칙 별도 학습.

### 학습 전략

1. **우선순위 1**: 한국어 -하다 동사 패턴 마스터 (공부, 운동, 일, 요리, 청소, 전화, 산책, 독서, 영화, 게임 등) — 30개 이상.
2. **우선순위 2**: 시제 활용 표지 비교 — EN/ES 활용 vs JP/KR 활용 vs CH 상(相) 조사.
3. **우선순위 3**: 진행형 5언어 매핑 — be+-ing / estar+-ndo / て+いる / -고 있다 / 在+동사.
4. **우선순위 4**: 모음 조화 (-았/었) 와 일본어 た형의 어미 변동 비교.
5. **우선순위 5**: 시제 생략 가능성 (CH/KR) vs 시제 필수 (EN/ES) — 미래/과거 명시.
