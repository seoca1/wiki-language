## 各语言详情

### 🇬🇧 英语 (English)
- **核心**: "Blockbuster", "Cult classic", "Indie film"
- **模式**: "Movie" vs "Film" — 正式/非正式区分
- **来源**: `[[entertainment-vocabulary]]`

### 🇪🇸 西班牙语 (Spanish)
- **核心**: "Telenovela" (拉美电视支柱, 100+ 集常见), "Cortometraje" (短片)
- **模式**: 强烈配音传统; 西班牙配音常与字幕不同
- **来源**: N/A — 西班牙语暂无娱乐专题

### 🇯🇵 日语 (Japanese)
- **核心**: "Anime" = 特指日本动画; "Manga" = 日本漫画
- **模式**: 产业垂直整合 (漫画 → 动画 → 周边); 声优 (声優 = seiyū) 是名人
- **来源**: `[[entertainment-vocabulary]]`

### 🇰🇷 韩语 (Korean)
- **核心**: "K-drama", "K-pop", "Webtoon" (数字漫画); "Manhwa" = 韩漫画
- **模式**: 流媒体驱动产业; 정주행 (全程马拉松观看) 文化概念
- **来源**: `[[entertainment-vocabulary]]`

### 🇨🇳 中文 (Chinese)
- **核心**: "武侠" (wǔxiá = 武侠), "仙侠" (xiānxiá = 仙侠), "古风" (gǔfēng = 古风)
- **模式**: 类型融合常见 (剧 + 综艺 + 游戏); 饭圈 (fànquān) 文化
- **来源**: N/A — 中文暂无娱乐专题

## 关键对比 (综合)

| 对比 | 洞察 |
|------|------|
| **产业垂直** | JP 动漫/漫画有独特漫画优先流水线; KR 有 webtoon 优先; CN 有网络小说 → 剧 |
| **饭圈词汇** | 推し活 (JP), 팬덤 (KR 借词), 饭圈 (CN) — 同概念不同文化词汇 |
| **字幕 vs 配音** | JP/EN 偏好字幕; ES/KR 强配音传统; CN 字幕标准 |
| **类型混合度** | C-剧常融合历史 + 奇幻; JP 动漫类型纯粹性更高 |

## 🇨🇳 中文学习者笔记 (Chinese Learner Notes)

> 本节是面向中文母语学习者的额外学习指南。

### 中文母语者在学习其他4种语言娱乐词汇时的常见陷阱

1. **"anime" 的语用专属**:
   - 中文 *动画* = general animation → 学员对日语 *アニメ* = 专属日本动画感到困惑。
   - **陷阱**: 在日语 *アニメ* 特指日本动画, 其他国家动画需用 *アニメーション*。
   - **训练法**: 日语 *アニメ* 不通用; 其他国家动画用 *アニメーション*。

2. **"K-pop" / "J-pop" 的文化专属**:
   - 中文 *K-pop / J-pop* 已普及 → 学员对韩语 *케이팝* / 日语 *J-POP* 感到熟悉。
   - **陷阱**: 这些是国际标签, 本国常用 *K-pop/J-pop* 借词, 但口语也用 *アイドル / 아이돌*。
   - **训练法**: 国际标签 vs 本国用法区分 (K-pop = 国际, 아이돌 = 国内常用)。

3. **西班牙语 telenovela 的文化等价**:
   - 中文 *电视连续剧* 短 (20-40 集) → 学员对 telenovela 100+ 集剧本感到困惑。
   - **陷阱**: 拉美 telenovela 是单独类型, 与美剧/日剧不同。文化上是日常家庭活动。
   - **训练法**: 区分 telenovela (拉美) vs soap opera (英语) vs mini-series (韩剧)。

4. **汉字文化圈的"古装剧"**:
   - 中文 *古装剧* → 学员对日韩 *時代劇 (jidaigeki)* / *사극 (sageuk)* 感到陌生。
   - **陷阱**: 日韩古装剧呈现历史故事; 中国"古装剧"更广 (含历史 + 仙侠)。
   - **训练法**: 各国古装剧范围对比 (CN 古装: 含仙侠; JP 時代劇: 历史为主; KR 사극: 历史)。

5. **"配音 vs 字幕" 的文化偏好**:
   - 中文 *看字幕* 是默认 → 学员对日语 *字幕 vs 吹替* 区分感到困惑。
   - **陷阱**: 日语 *字幕* (原声+字幕) 是默认; *吹替 (ふきかえ)* (配音) 较少用。中文/韩语优先配音。
   - **训练法**: 各国配音/字幕文化偏好对比 (CN/KR 配音; JP/EN 字幕)。
