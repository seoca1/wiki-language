## 各言語詳細

### 🇬🇧 英語 (English)
- **主要用語**: "Apparel" (フォーマル), "Clothes" (general), "Outfit" (specific ensemble)
- **パターン**: "Wear" + 名詞; "Dress" は動詞と名詞で意味が異なる
- **出典**: `[[clothing-vocabulary]]`

### 🇪🇸 スペイン語 (Spanish)
- **主要用語**: "Ropa" (general clothing), "Indumentaria" (フォーマル/産業)
- **パターン**: -ar 動詞: usar (to wear); 再帰: "vestirse" (to dress oneself)
- **出典**: `[[clothing-vocabulary]]` (テーマ存在、内容は限定的)

### 🇯🇵 日本語 (Japanese)
- **主要用語**: 服 (fuku = 衣服), 服飾 (fukushoku = apparel), 衣類 (irui = garments)
- **パターン**: 動詞: 〜を着る (wo kiru); 動詞: 〜を履く (wo haku = 腰下に履く)
- **出典**: `[[clothing-vocabulary]]`

### 🇰🇷 韓国語 (Korean)
- **主要用語**: 옷 (ot = clothes), 의류 (eoryu = clothing/apparel), 한복 (hanbok = 伝統)
- **パターン**: 動詞: 입다 (ipda = 上半身に着る); 신다 (sinda = 履物を履く); 쓰다 (sseuda = 頭に着用)
- **出典**: `[[clothing-vocabulary]]`

### 🇨🇳 中国語 (Chinese)
- **主要用語**: 衣服 (yīfu), 服装 (fúzhuāng = clothing), 汉服 (hànfú)
- **パターン**: 動詞: 穿 (chuān); 量詞: 件 (jiàn) for garments
- **出典**: 中国語には clothing テーマ未投入

## 主要な対比 (総合)

| 対比 | 学習者への示唆 |
|------|----------------|
| **動詞の区別** | JP/KR は上/下/履物の着用動詞が別; EN/ES/ZH は単一 "wear/穿" 動詞 |
| **伝統衣装** | JP/KR/ZH はすべて独特の伝統衣装を保存 (kimono/hanbok/hàn fú) — 現代ファッションは世界共通化 |
| **借用語** | 全言語が "jeans" を採用 (ジーンズ/청바지/牛仔裤) — 翻訳は異なる |
| **サイズ/色** | EN/ES はラテン語系; JP/KR/ZH は固有または 漢字/汉字 語 |

## 🇯🇵 日本語学習者ノート (Japanese Learner Notes)

> 本セクションは日本語学習者向けの追加学習ガイドです。

### 日本語話者が他の4言語の衣服用語を学ぶ際の一般的な落とし穴

1. **動詞の過剰区別**:
   - 日本語は「着る (kiru)」と「履く (haku)」を明確に区別 (上 vs 下) → 英語・中国語は単一 "wear/穿"。
   - **落とし穴**: 英語話者が "wear pants" と言わず "put on pants" を使用。
   - **練習法**: 言語ごとに動詞の適用範囲を確認; 英語は "wear shoes" (靴) / "wear pants" (ズボン) / "wear a shirt" (シャツ) すべて "wear"。

2. **「下着」の翻訳失敗**:
   - 日本語の「下着」/「パンツ」 → 英語 "underwear" / 韓国語 "속옷" / 中国語 "内衣"。
   - **落とし穴**: 英語 "pants" = ズボン; 日本語「パンツ」= 下着 → 笑い話に。
   - **練習法**: 旅行時は "underwear" (英) / "속옷" (韓) / "内衣" (中) を使用。

3. **サイズ表記の文化差**:
   - 日本語・韓国語・中国語のサイズ表記 (S/M/L) は欧米と微妙に異なる。
   - **練習法**: 国際サイズ基準を確認し、試着を必ず行う。

4. **靴の履き方**:
   - 日本語の靴文化は玄関で脱ぐ → 欧米/中国/韓国では玄関で脱がない。
   - **練習法**: 訪問先の靴文化を確認 (日本式家屋では靴を脱ぐ、中国の一部でもスリッパに履き替え)。

5. **伝統衣装の現代化**:
   - 日本語の「着物」、韓国語の「한복」、中国語の「汉服」は現代 revival 進行中。
   - **練習法**: 観光時はレンタル着物・漢服・韓服体験が可能; 写真撮影時のマナーを確認。
