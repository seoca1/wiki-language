## Quick Reference Table

| Feature | English | Spanish | Japanese | Korean | Chinese |
|---------|---------|---------|----------|--------|---------|
| **Grammatical encoding** | Lexical only (vocabulary choice) | Pronoun (tú/usted) + verb morphology | Verb morphology (keigo) + vocabulary | Verb endings (speech levels) + honorific nouns/verbs | Lexical choice + honorific titles + 您 (nín) |

## Per-Language Detail

### English
- **Key terms**: formal vs informal register, "please/thank you," titles (Mr/Ms/Dr/Prof), hedging (could/would/might)
- **Patterns**: No grammatical honorifics. Politeness = vocabulary choice + syntactic distancing (past tense for present requests: "I was wondering if...") + modal verbs + indirectness
- **Register notes**: 
  - Formal: "Would you be so kind as to...", "I would appreciate it if..."
  - Neutral: "Could you please...", "Please..."
  - Informal: "Can you...", "Hey, ..."
- **Sources**: `[English/vocabulary/basic-vocabulary]`, `[English/culture/english-dating-culture]`

### Spanish
- **Key terms**: tú / usted / vosotros / ustedes, *don/doña*, *usted* verb forms (3rd person), *tuteo* vs *ustedeo*
- **Patterns**: 
  - **Tú**: friends, family, children, peers (default for young people in Spain)
  - **Usted**: strangers, elders, formal situations, authority (default in LatAm)
  - **Vosotros** (Spain only): plural informal
  - **Ustedes**: plural formal (Spain) / plural both (LatAm)
- **Regional variations**:
  - **Spain**: tú/usted distinction strong; vosotros used
  - **Mexico/Colombia/Peru**: usted default even among young people in some contexts
  - **Argentina/Uruguay/Paraguay**: *vos* replaces *tú* (voseo) — distinct conjugation
  - **Caribbean**: *usted* more frequent, *tú* reserved for close intimacy
- **Sources**: `[Spanish/vocabulary/polite-expressions-vocabulary]`, `[Spanish/culture/espana-vs-latinoamerica-registro]`

### Japanese
- **Key terms**: 
  - **丁寧語 (teineigo)**: です/ます — default polite
  - **尊敬語 (sonkeigo)**: honorific — elevate listener (いらっしゃる, 召し上がる, ご存知)
  - **謙譲語 (kenjougo)**: humble — lower self (参る, いただく, 拝見する)
  - **美化語 (bikago)**: お/ご prefixes (お茶, ご飯)
- **Patterns**: Verb conjugation changes entirely by register. *Uchi* (in-group) vs *soto* (out-group) determines which keigo to use. Default interaction with strangers = teineigo. Business = sonkeigo/kenjougo mix.
- **Keigo / politeness level**:
  - Casual (タメ口): 行く, 食べる, 知ってる — close friends, family, younger
  - Polite (丁寧語): 行きます, 食べます, 知っています — strangers, colleagues, default
  - Honorific (尊敬語): いらっしゃいます, 召し上がります, ご存知です — customers, superiors, elders
  - Humble (謙譲語): 参ります, いただきます, 拝見します — talking about self to superiors
- **Sources**: `[Japanese/vocabulary/business-vocabulary]`, `[Japanese/culture/japanese-dating-culture]`

### Korean
- **Key terms**: 
  - **해체 (haeche)**: plain/formal written — close friends, children, self-talk
  - **해요체 (haeyoche)**: polite informal — daily life, coworkers, acquaintances (default spoken)
  - **합쇼체 (hapsyoche)**: formal polite — presentations, broadcasts, military, customers
  - **하소서체 (hasoseoche)**: extremely formal — historical, religious, royalty
  - **존댓말 (jondaetmal)**: umbrella for polite levels
  - **반말 (banmal)**: casual (해체/해요체 mixed)
- **Patterns**: 
  - Verb ending changes: 가다 → 가/가요/갑니다/가시옵소서
  - Honorific nouns: 밥 → 진지, 집 → 댁, 이름 → 성함, 생일 → 생신
  - Honorific verbs: 먹다 → 잡수시다, 자다 → 주무시다, 계시다 (있다/계시다)
  - Subject honorific marker: ~(으)시 (가시다, 드시다)
- **Speech level selection**: Age difference of 1+ year → honorifics expected. Same age → negotiate (언제 반말 할까요?). Workplace: title + 님 (팀장님, 매니저님)
- **Sources**: `[Korean/vocabulary/emotions-personality-vocabulary]`, `[Korean/culture/korean-dating-culture]`

### Chinese
- **Key terms**: 
  - **您 (nín)**: respectful "you" (vs 你 nǐ)
  - **尊称 (zūnchēng)**: respectful titles — 先生, 女士, 老师, 总经理, 姐/哥
  - **敬语 (jìngyǔ)**: honorific vocabulary — 贵姓, 请教, 拜访, 敬请, 承蒙
  - **谦辞 (qiāncí)**: self-deprecating — 拙作, 拙见, 献丑, 不敢当
- **Patterns**: 
  - No verb morphology change for politeness
  - Politeness = lexical substitution + titles + sentence-final particles (请, 麻烦您, 劳驾)
  - **您 (nín)** used for elders, superiors, strangers in formal contexts
  - **Title + 姓**: 王先生, 李老师, 张总 — default address in professional settings
  - **Guanxi (关系)** modulates register: closer relationship → drop 您, use first name / nickname
- **Register / honorifics**:
  - Neutral: 你, 叫什么名字?, 去
  - Respectful: 您, 贵姓?, 请去 / 麻烦您去
  - Formal written: 阁下, 尊驾, 惠顾, 光临 (business correspondence)
- **Sources**: `[Chinese/vocabulary/body-zh]`, `[Chinese/sources/greetings-zh]`

## Key Contrasts (Synthesis)

| Contrast | Implication for Learners |
|----------|--------------------------|
| **Grammatical vs lexical** — JP/KR/ES encode politeness in grammar; EN/CH use vocabulary | JP/KR learners must master verb paradigms early; EN/CH learners can communicate with basic grammar + polite words |
| **Default stranger register** — ES: *usted* (LatAm) / *tú* (Spain youth); JP: *desu/masu*; KR: *haeyoche*; CH: *nín* + title | Choose default based on target region: Mexico → *usted*; Tokyo → *desu/masu*; Seoul → *haeyoche*; Beijing → *nín* + title |
| **In-group/out-group (uchi/soto, 내사람/남)** — Central to JP/KR; weak in EN; moderate in ES/CH | In JP/KR, using wrong register with in-group = cold/distant; with out-group = rude. Learn group boundaries first. |
| **Age as primary vs title-based address** — KR/CH require title+님/先生; JP uses-san/様; ES uses Don/Doña + usted; EN uses Mr/Ms | In KR/CH, calling someone by bare name = rude. Memorize titles for every role (팀장님, 王老师, 部長様, Don Juan). |
| **Negotiation of register** — KR explicit ("우리 반말 해요"); JP implicit (drop keigo); ES explicit ("tuteame"); CH implicit (drop 您) | KR learners: practice "언제 반말 할까요?" script. JP learners: watch for keigo drop signals. ES learners: "¿Puedo tutearte?" |

## Learner Decision Guide

> "If your goal is X, prioritize Y in Language Z because..."

- **Goal: Basic survival / travel** → 
  - EN: "Please/Thank you/Excuse me" + modal verbs
  - ES: *usted* forms + *por favor/gracias* (works everywhere)
  - JP: *desu/masu* + *sumimasen/arigatou* (covers 90% of interactions)
  - KR: *haeyoche* (-요 endings) + *juseyo/mianhamnida* (safe default)
  - CH: *nín* + *qing/xiexie/duibuqi* + titles (服务员, 师傅)

- **Goal: Business / professional** →
  - EN: Hedging, passive voice, "I would appreciate," titles
  - ES: *ustedeo* + *usted* verb forms + *Don/Doña* + formal closings (*Atentamente, Cordialmente*)
  - JP: Full *keigo* (sonkeigo/kenjougo/bikago) + *keigo* email templates + *meishi* exchange etiquette
  - KR: *hapsyoche* (-ㅂ니다) + honorific nouns/verbs + title+님 + bowing depth
  - CH: *nín* + 贵姓/请教/拜访 + titles (总监, 经理, 老师) + 请/麻烦您

- **Goal: Social / friendship / dating** →
  - EN: First-name basis quickly, phrasal verbs, slang
  - ES: *tuteo* negotiation (*¿Puedo tutearte?*) → regional norms vary
  - JP: *tameguchi* transition (usually after 3rd meeting / drinking) — wait for senior to propose
  - KR: *banmal* negotiation (*우리 반말 해요*) — usually younger asks older after closeness established
  - CH: Drop *nín* → *nǐ*, use given name / nickname / 哥/姐 — follows *guanxi* deepening

- **Goal: Academic / formal writing** →
  - EN: Passive, nominalization, hedging, citation style
  - ES: *ustedeo*, impersonal *se*, subjunctive in formal contexts
  - JP: *dearu/da* (plain) for papers; *desu/masu* for presentations; *kanbun* legacy forms
  - KR: *hapsyoche* + honorifics + Sino-Korean vocabulary (한자어)
  - CH: Written register (书面语) — 之/其/乃/乎, 4-char chengyu, passive 被/由
