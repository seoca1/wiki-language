## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 슬랭을 학습할 때 흔히 마주치는 함정

1. **한국어 MZ 세대 슬랭의 빠른 진화**:
   - 한국어 슬랭: "존맛탱" (2010s 후반), "갓생" (2010s), "오운완" (2010s), "스불재" (2020s) — **3-5년 주기 변화**.
   - 일본어 슬랭: "やばい" (2000s~), "ぴえん" (2020), "それな" (2010s), "エモい" (2010s) — 약간 더 안정.
   - 영어 슬랭: "lit" (2010s), "sus" (2020), "no cap" (2010s) — 빠른 변화.
   - **함정**: 한국어 학습자가 5년 전 슬랭 사용 → 시대착오적. 또는 2024 슬랭 2030년 사용 시 노화.
   - **훈련법**: 슬랭 시의성 명시 — 한국어 MZ 슬랭 매트릭스. **"현재" 슬랭 (2024-2026) 별도 학습**.

2. **한글 자음 약어 (ㅇㅇ, ㄱㄱ, ㅋㅋ) 의 한국어 고유성**:
   - 한국어: 한글 자음 단독으로 단어 대체. ㅇㅇ=응, ㄱㄱ=가자, ㅋㅋ=크크크, ㅎㅇ=하이, ㅂㅂ=바이.
   - 일본어: w (笑 = わらい) 반복 = www. 일본어의 w = laugh. "草" = www에서 파생.
   - 영어: lol, lmao, rofl. 반복형.
   - 중국어: 2333 (BBS 웃음 코드), 哈哈.
   - **함정**: 한국어 학습자가 한글 자음 약어 (ㅇㅇ) 를 다른 4개 언어에 단순 매핑 → 일본어 w 반복, 중국어 2333, 영어 lol 다름.
   - **훈련법**: 5개 언어 문자/타이핑 슬랭 매트릭스 — 한글 자음 약어는 **한국어 고유**. 다른 4개 언어 문자 체계 다름.

3. **"Fighting" 의 한국어 → 영어 글로벌 차용**:
   - 한국어 "화이팅 (hwaiteing)" = "Go for it!" / "Cheer up!". 영어로 차용 → "Fighting!".
   - 일본어 "頑張れ (ganbare)" = "Hang in there".
   - 중국어 "加油 (jiāyóu)" = "Add oil!" (직역).
   - **함정**: "Fighting" 영문 맥락에서 폭력/싸움 의미 → 한국어 맥락에서 "힘내!" 의미. 영어 원어 화자에게는 혼란.
   - **훈련법**: "Fighting" / "화이팅" / "加油" 매트릭스 — 동아시아 3개국 (KR/JP/CN) 응원 표현 글로벌화. **문화별 응원 표현 학습**.

4. **"Service" 의 한국어 캐주얼 사용**:
   - 한국어 "서비스" = "freebie" / "on the house". 식당/카페에서 추가 제공.
   - 영어 "service" = 직업/서비스 일반.
   - **함정**: 영어권 "service" 단순 매핑 → "서비스" 의미 다름. 한국어 학습자가 영어 식당에서 "service" 요청 → 부적절.
   - **훈련법**: "서비스" 한국어 고유 의미 학습 — 추가 무료 제공. 다른 4개 언어에 동등 표현 없음. **한국어 차용 의미 매트릭스**.

5. **"N포세대", "내로남불", "극혐" 의 한국어 고유성**:
   - 한국어: N포세대 (N-give-up generation), 내로남불 (내로라하다 + 남 불리하다), 극혐 (극한 + 혐오).
   - 일본어/중국어/영어: 동등 표현 없음.
   - **함정**: 한국어 학습자가 다른 4개 언어에 동등 표현 기대 → "N포세대" 단순 번역 어려움.
   - **훈련법**: 한국어 고유 신조어 매트릭스 — 사회적 맥락이 강한 슬랭. **문화적 맥락 의존 슬랭 별도 학습**.

### 학습 전략

1. **우선순위 1**: 5개 언어 슬랭 15개 × 5언어 매트릭스 — Cool/LOL/Awesome/OK/Thanks/Noob/Pro/Cute/Boring/Annoying/Tired/Bad/Friend/Money. **가장 빈도 높은 15개 슬랭 동시 학습**.
2. **우선순위 2**: 한글 자음 약어 (ㅇㅇ, ㄱㄱ, ㅋㅋ) — **한국어 고유**. 일본어 w 반복, 중국어 2333, 영어 lol — 5개 메커니즘 비교.
3. **우선순위 3**: 동아시아 3개국 응원 표현 — "Fighting" (KR 차용) / "頑張れ" (JP) / "加油" (CN) / 영어 "Go for it!" — 4개 언어 응원 매트릭스.
4. **우선순위 4**: 한국어 고유 신조어 — N포세대, 내로남불, 극혐, 갓생, 맛집. **문화적 맥락 의존** 슬랭 별도 학습.
5. **우선순위 5**: MZ 세대 슬랭 (2010s-20s) — 시의성 명시. **"현재" 슬랭** 별도 학습 (3-5년 주기 갱신).
