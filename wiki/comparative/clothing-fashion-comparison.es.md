## Detalle por idioma

### 🇬🇧 Inglés (English)
- **Términos clave**: "Apparel" (formal), "Clothes" (general), "Outfit" (conjunto específico)
- **Patrones**: "Wear" + sustantivo; "Dress" como verbo vs sustantivo (diferentes significados)
- **Fuentes**: `[[clothing-vocabulary]]`

### 🇪🇸 Español (Spanish)
- **Términos clave**: "Ropa" (ropa general), "Indumentaria" (formal/industria)
- **Patrones**: Verbo -ar: usar (usar); reflexivo: "vestirse" (vestirse)
- **Fuentes**: `[[clothing-vocabulary]]` (tema existe pero contenido limitado)

### 🇯🇵 Japonés (Japanese)
- **Términos clave**: 服 (fuku = ropa), 服飾 (fukushoku = indumentaria), 衣類 (irui = prendas)
- **Patrones**: Verbo: 〜を着る (wo kiru); Verbo: 〜を履く (wo haku = usar debajo de la cintura)
- **Fuentes**: `[[clothing-vocabulary]]`

### 🇰🇷 Coreano (Korean)
- **Términos clave**: 옷 (ot = ropa), 의류 (eoryu = ropa/indumentaria), 한복 (hanbok = tradicional)
- **Patrones**: Verbo: 입다 (ipda = usar parte superior); 신다 (sinda = usar calzado); 쓰다 (sseuda = usar en la cabeza)
- **Fuentes**: `[[clothing-vocabulary]]`

### 🇨🇳 Chino (Chinese)
- **Términos clave**: 衣服 (yīfu), 服装 (fúzhuāng = ropa), 汉服 (hànfú)
- **Patrones**: Verbo: 穿 (chuān); clasificador: 件 (jiàn) para prendas
- **Fuentes**: N/A — el wiki chino aún carece de un tema de ropa

## Contrastes clave (síntesis)

| Contraste | Implicación para estudiantes |
|-----------|------------------------------|
| **Distinciones verbales** | JP/KR tienen verbos separados para parte superior/inferior/calzado; EN/ES/ZH usan un solo verbo "wear/穿" |
| **Vestimenta tradicional** | JP/KR/ZH conservan prendas tradicionales distintas (kimono/hanbok/hàn fú) — la moda moderna está más globalizada |
| **Términos prestados** | Todos los idiomas adoptan "jeans" (ジーンズ/청바지/牛仔裤) — pero con traducciones diferentes |
| **Talla/color** | EN/ES usan palabras latinas; JP/KR/ZH usan términos nativos o 한자/汉字 |

---

## Guía de decisión para estudiantes

> **Verbos de uso según el idioma**:
> - Parte superior: wear / llevar / 着る (kiru) / 입다 (ipda) / 穿 (chuān)
> - Parte inferior: wear / llevar / 履く (haku) / 입다 (ipda) / 穿 (chuān)
> - Calzado: wear / calzar / 履く (haku) / 신다 (sinda) / 穿 (chuān)

## 🇪🇸 Notas para estudiantes de español (Spanish Learner Notes)

> Esta sección es una guía de aprendizaje adicional para hispanohablantes.

### Trampas comunes para hispanohablantes al aprender los otros 4 idiomas

1. **Sobreutilización del verbo "llevar"**:
   - En español, "llevar" cubre todos los contextos de uso de ropa → en japonés y coreano hay verbos distintos para cada parte del cuerpo.
   - **Trampa**: intentar decir "llevar zapatos" en japonés como 靴を着る ✗ (incorrecto; lo correcto es 靴を履く).
   - **Entrenamiento**: memorizar los tres verbos en japonés: 着る (parte superior), 履く (parte inferior/calzado), 被る (cabeza); en coreano: 입다 (parte superior), 신다 (calzado), 쓰다 (cabeza).

2. **Subutilización del pronombre reflexivo**:
   - En español "vestirse" usa el pronombre reflexivo (se) → en JP/KR/CN no hay equivalente, simplemente se usa el verbo.
   - **Trampa**: añadir pronombres reflexivos donde no existen.
   - **Entrenamiento**: usar simplemente 着る (kiru), 입다 (ipda), 穿 (chuān) sin pronombres.

3. **Falsos amigos con "ropa"**:
   - "Ropa" en español = 衣服 (yīfu) en chino; en japonés 服 (fuku) es más general; en coreano 옷 (ot) es el término común.
   - **Trampa**: confundir 服 (fuku) con 服飾 (fukushoku = indumentaria formal) o 衣類 (irui = prendas).
   - **Entrenamiento**: aprender 服 como término general y 衣服 como más específico.

4. **Confusión con vestimenta tradicional**:
   - El español no tiene equivalente actual a kimono, hanbok o hanfu → en las culturas CJK estas vestimentas siguen siendo culturalmente relevantes.
   - **Trampa**: usar "traje típico" como traducción única, perdiendo la riqueza cultural.
   - **Entrenamiento**: aprender 着物 / 한복 / 汉服 como términos propios con su contexto cultural.

5. **Diferencias regionales en español**:
   - España usa "pantalones vaqueros" o "vaqueros"; LatAm usa "jeans" o "bluyines".
   - **Trampa**: asumir que todos los hispanohablantes usan los mismos términos.
   - **Entrenamiento**: aprender las variantes regionales desde el inicio (pantalones / vaqueros / jeans).

3. **Practicar el vocabulario de accesorios** (sombrero, bufanda, guantes)
4. **Estudiar materiales** (algodón, seda, lana, cuero)
5. **Investigar vestimenta tradicional** (kimono, hanbok, hanfu) y sus contextos culturales
