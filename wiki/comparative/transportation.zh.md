### 按国家交通系统

#### 美国

| 方式 | 描述 |
|------|-------------|
| **小汽车** | 主要交通方式 (~85% 出行) |
| **飞机** | 长距离, 广泛网络 |
| **公交车** | Greyhound (长途), 城市公交 |
| **地铁** | 纽约, 芝加哥, 华盛顿, 波士顿, 旧金山, 洛杉矶 (有限) |
| **火车** | Amtrak (有限客运铁路) |
| **网约车** | Uber, Lyft (城市主导) |
| **自行车** | 城市增长 (Citi Bike, Lyft bikeshare) |

**文化笔记**:
- 驾照 = 身份
- 无全国交通卡
- 汽车 = 自由象征 (尤其郊区)

#### 西班牙

| 方式 | 描述 |
|------|-------------|
| **高铁 (AVE)** | 优秀网络 (马德里, 巴塞罗那, 塞维利亚) |
| **地铁** | 马德里, 巴塞罗那, 毕尔巴鄂, 瓦伦西亚 |
| **Cercanías** | 郊区铁路 (通勤) |
| **公交车** | ALSA (长途), 城市公交 |
| **小汽车** | 常见但历史市中心有限 |
| **出租车** | 白色带绿条 (马德里), 黑色/黄色 (巴塞罗那) |
| **网约车** | Uber, Cabify, FreeNow |

**文化笔记**:
- AVE (高铁) — 主要城市 2-3 小时
- Siesta — 部分商家 14-17 关闭 (现在较少)
- 出租车小费: 凑整 (非强制)
- 西班牙开车 = 混乱 (当地玩笑)

#### 日本

| 方式 | 描述 |
|------|-------------|
| **火车 (JR)** | JR (6 个地区公司), 密集网络 |
| **地铁 (chikatetsu)** | 东京地铁, 都营, 大阪, 名古屋 等 |
| **新干线** | 高铁 (子弹头列车) — 全球黄金标准 |
| **公交车** | 高速巴士 (比火车便宜), 城市公交 |
| **出租车** | 贵, 但可靠 (门自动开) |
| **小汽车** | 城市较少 (停车贵, 街道窄) |
| **自行车** | 常见 (骑行文化), 尤其京都 |
| **飞机** | 国内城市间航班 |
| **渡轮** | 岛屿 (冲绳, 北海道) |

**文化笔记**:
- **IC 卡** (Suica, Pasmo, Icoca) — 交通 + 支付, 全部兼容
- 火车 = 准时 (秒単位)
- 火车上安静 (无电话)
- 出租车小费 = 不存在
- JR Pass 外国游客 (7/14/21 天)

#### 韩国

| 方式 | 描述 |
|------|-------------|
| **地铁** | 首尔 (9 条线), 釜山, 大邱, 仁川, 光州, 大田 |
| **KTX** | 高铁 (首尔-釜山 2 小时) |
| **SRT** | 私人高铁 (最新, 与 KTX 类似) |
| **公交车** | 城际 (고속버스), 城市公交 |
| **出租车** | 颜色编码: 일반 (普通) / 모범 (高级) / 대형 (大型) |
| **T-money / Cashbee** | 交通卡 (所有方式兼容) |
| **小汽车** | 常见但首尔交通拥堵 |
| **Kakao T** | KakaoTaxi 应用 (网约车主导) |

**文化笔记**:
- 首尔地铁 = 世界级 (干净, 快, 英文标识)
- T-money = 必需 (出租车, 地铁, 公交, 便利店)
- 出租车小费 = 不做 (司机可能追你!)
- 老年座位 = 优先 (让座即使老人站着)
- 高级出租车 (모범택시) = 更大, 更贵

#### 中国

| 方式 | 描述 |
|------|-------------|
| **高铁 (CRH)** | 世界最大网络 (40,000+ 公里) |
| **地铁** | 北京, 上海, 广州, 深圳, 40+ 城市 |
| **公交车** | 广泛网络, 非常便宜 |
| **出租车** | 城市常见 |
| **滴滴 (滴滴)** | 网约车应用 (中国 Uber) |
| **小汽车** | 中产阶级增长 |
| **支付宝/微信支付** | 用于所有交通支付 |
| **高速磁浮** | 上海 (浦东机场, 全球最快) |

**文化笔记**:
- **支付宝/微信支付** = 通用支付 (甚至街头小贩)
- **英文标识**: 主要城市地铁 = 双语
- **排队**: 可能混乱 (尤其公交车)
- **高铁**: 北京-上海 4.5 小时 (vs 飞机 2 小时 + 机场时间 = 相似)
- **滴滴**: 旅行前安装 (外卡支持有限)

## 🇨🇳 中文学习者笔记 (Chinese Learner Notes)

> 本节是面向中文母语学习者的额外学习指南。

### 中文母语者在学习其他4种语言交通时的常见陷阱

1. **驾驶侧的差异**:
   - 中国 靠右行驶 → 学员假设其他语言国家都靠右。
   - **陷阱**: 日本 靠左行驶 (右舵车); 韩国/西班牙/美国 靠右。
   - **训练法**: 出行前确认目的地驾驶侧 — 避免交叉路口突然反向。

2. **高铁网络的差异**:
   - 中国 高铁 全球最发达 (40,000+ km) → 学员假设其他语言国家有类似高铁网络。
   - **陷阱**: 日本 新干线 发达 (2,800 km); 韩国 KTX 较新 (1,200 km); 西班牙 AVE 发达 (3,900 km); 美国 Acela 有限 (735 km)。
   - **训练法**: 区分"高铁发达国家" vs "高铁有限国家" — 旅行时选择不同交通工具。

3. **支付方式的差异**:
   - 中国 移动支付 (微信/支付宝) 几乎全民 → 学员假设其他语言国家也类似。
   - **陷阱**: 日本 现金仍主导; 韩国 T-money 集成; 西班牙 信用卡 + 现金; 美国 信用卡.
   - **训练法**: 出境前准备 — 信用卡 + 现金 + 当地移动支付。

4. **交通卡的差异**:
   - 中国 无需交通卡 (用手机) → 学员假设其他语言国家也类似。
   - **陷阱**: 日本 Suica/Pasmo 必需; 韩国 T-money 必需; 西班牙 每城市有限; 美国 每城市有限。
   - **训练法**: 了解目的地交通卡 — Suzuya/T-money 提前购买。

5. **出租车招呼的差异**:
   - 中国 网约车 (滴滴) 主导 → 学员假设其他语言国家也类似。
   - **陷阱**: 日本 路边招手 (Uber 有限); 韩国 Kakao T 主导; 美国 Uber/Lyft 城市主导; 西班牙 路边 + Uber。
   - **训练法**: 区分"路边招手" vs "网约车" — 5种语言各自的出租车方式。
