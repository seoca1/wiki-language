## 各语言详情

### 🇬🇧 英语 (English)

**动词形式**:
- **Be + adjective**: I am happy / sad / angry
- **Feel + adjective**: I feel sad / anxious / happy

**强度副词**:
- **Very + adj**: very happy, very tired
- **So/Really + adj**: so tired, really happy
- **Adjective + -er/-est**: happier (比较级), happiest (最高级)

**常见短语**:
- **"I'm feeling..."** — 更柔和, 反思性
- **"I'm so..."** — 随意的强调
- **"I get..."** — 习惯性 (I get nervous)

### 🇪🇸 西班牙语 (Spanish)

**动词形式**:
- **Estar + adjective** (临时状态): Estoy feliz = "我高兴"
- **Ser + adjective** (永久): Soy nervioso = "我神经质"
- **Sentir + noun**: Siento alegría = "我感觉喜悦"

**强度**:
- **Muy + adj**: muy feliz
- **-ísimo/a**: contentísimo = "非常开心"
- **Tan + adj**: tan cansado = "这么累"

**地区变体**:
- **西班牙**: agobiado (overwhelmed)
- **拉美**: estresado (stressed)
- **阿根廷**: al horno (饥饿)
- **墨西哥**: bien contento (非常开心)

### 🇯🇵 日语 (Japanese)

**动词形式**:
- **形容词 (i-adj/na-adj) + です**: 嬉しいです (Ureshii desu)
- **动词 + たい**: 食べたい = "我想吃" (愿望)
- **形容词 + なる**: 寒くなる = "变冷"

**形容词类型**:
- **i-adjectives**: 嬉しい (ii-结尾): 嬉しい, 楽しい, 悲しい, 辛い
- **na-adjectives**: 好き (na-结尾): 好き, 嫌い, 綺麗

**特殊情感表达**:
- **〜たい (tai)**: 想要做 X
- **〜がる (garu)**: 外在表现情感 (3rd 人称): 怖がっている
- **寂しい (sabishii)**: 孤独 — 独特的日语情感概念

### 🇰🇷 韩语 (Korean)

**动词形式**:
- **形容词 + -다 (da)**: 기쁘다 = "高兴" (陈述)
- **形容词 + -어요 (eoyo)**: 기뻐요 = "我高兴" (礼貌)
- **形容词 + -ㅂ니다 (seumnida)**: 기쁩니다 = "我高兴" (正式)
- **名词 + 이/가 + 形容词**: 슬프다, 좋다

**特殊情感表达**:
- **정 (jeong)**: 深厚关系 (无英语等价)
- **눈치 (nunchi)**: 社会意识 (无英语等价)
- **한 (han)**: 集体悲伤 (文化概念)
- **그리움 (gereum)**: 思念 (不仅是 "想念", 是情感状态)

**情绪强度**:
- **너무 (neomu)**: 太多
- **진짜 (jinjja)**: 真的
- **완전 (wanjeon)**: 完全

### 🇨🇳 中文 (Chinese)

**动词形式**:
- **形容词 + 了 (le)**: 高兴了 = "变高兴了" (状态变化)
- **很 + adjective**: 很高兴 = "非常高兴"
- **不 + adjective**: 不高兴 = "不高兴"

**特殊情感表达**:
- **舒服 (shūfu)**: 舒适 (身体 + 情感)
- **累 (lèi)**: 累 (身体 + 心理)
- **羡慕 (xiànmù)**: 羡慕 (不同于 嫉妒 "jealous")
- **开心 (kāixīn)**: 开心 (敞开的心)
- **伤心 (shāngxīn)**: 伤心
- **担心 (dānxīn)**: 担心 (字面 "担心")

**完句助词**:
- **了 (le)**: 状态变化
- **过 (guò)**: 过去经历
- **着 (zhe)**: 持续状态

## 速查表: 文化表达规则

### 文化表达规则 (面子, Nunchi 等)

| 文化 | 表达规则 | 例子 |
|------|----------|------|
| **English (US)** | 中度表达 OK | "I'm sad" 直接 OK |
| **English (UK)** | 轻描淡写 ("I'm a bit tired" = 疲惫) | "Not bad" = 好 |
| **Spanish** | 表达 OK | "¡Estoy loco!" (我疯了!) = "我很沮丧!" |
| **Japanese** | 謙遜 (kenson) — 轻描淡写 | "大丈夫です" (daijōbu = "我没事") = 可能含义压力大 |
| **Korean** | 눈치 + 정 — 克制 + 温情 | "괜찮아요" (gwaenchanayo) = "我没事" (可能含义不是) |
| **Chinese** | 面子 (miànzi) — 维护面子 | "还行" (hái xíng) = "还行" (可能含义不太好) |

| 情绪 | US 直接 | UK 轻描淡写 | JP/KR 克制 | CN 务实 |
|------|---------|-------------|------------|--------|
| **不同意** | "No" | "I'm not sure" | "難しいです" / "어려워요" | "不太方便" (不方便) |
| **累** | "I'm exhausted" | "I'm a bit tired" | "疲れた" / "피곤해" (诚实) | "有点累" (有点) |

| **生气** | "I'm so mad" | "I'm a bit upset" | "怒ってる" (诚实) | "我很生气" (直接) |

## 速查表: 表达爱

### "我爱你" 跨语言

| 语言 | 随意 | 标准 | 强烈 | 文化注解 |
|------|------|------|------|----------|
| **EN (US)** | "I like you a lot" | "I love you" | "I love you so much" | 直接, 早期 |
| **EN (UK)** | "I really like you" | "I love you" (较少) | "I love you with all my heart" | 保留 |
| **ES** | "Me gustas mucho" | "Te quiero" / "Te amo" | "Te amo con todo mi corazón" | Te quiero = 家人/伴侣, Te amo = 浪漫深爱 |
| **JP** | "好きです (Suki desu)" | "好きです (Suki desu)" (相同!) | "愛してる (Aishiteru)" (罕见/重) | Suki = 喜欢, Aishiteru = 爱 (大跨步) |
| **KR** | "좋아해 (Joahae)" | "좋아해요 (Joahaeyo)" / "사랑해 (Saranghae)" | "너무 사랑해 (Neomu saranghae)" | Joahae = 喜欢, Saranghae = 爱 (大跨步) |
| **CH** | "我喜欢你 (Wǒ xǐhuān nǐ)" | "我喜欢你 (Wǒ xǐhuān nǐ)" | "我爱你 (Wǒ ài nǐ)" | 相同; 喜欢 = 喜欢, 爱 = 爱 (大跨步) |

### 文化模式: EN/ES 直接 > CN 直接 > JP/KR 渐进

- **EN**: 爱情表达快 (通常早期约会)
- **ES**: Te quiero (非常常见); Te amo (深爱/婚姻)
- **JP**: Suki → Aishiteru (大跨步, 通常在告白或婚后)
- **KR**: Joahae → Saranghae (类似日语, 渐进)
- **CH**: 喜欢 → 爱 (类似日韩, 渐进但比日韩直接)

## 🇨🇳 中文学习者笔记 (Chinese Learner Notes)

> 本节是面向中文母语学习者的额外学习指南。

### 中文母语者在学习其他4种语言情绪词汇时的常见陷阱

1. **"我爱你" 的重量**:
   - 中文 *我爱你* 较直接 → 学员对日语 *愛してる (aishiteru)* 感到困惑。
   - **陷阱**: 日语 *愛してる* 极重, 接近"我愿意嫁给你"; 常用 *好きです* 替代。
   - **训练法**: 学习日语 *好き → 愛する* 渐进; 韩语 *좋아해 → 사랑해* 同样渐进。

2. **"生气" 的不同强度**:
   - 中文 *生气 / 愤怒* 二档 → 学员对日语多个等级感到困惑。
   - **陷阱**: 日语 *怒り (ikari)* (情绪) vs *怒っている (okotte iru)* (状态) vs *激怒 (gekido)* (狂怒); 韩语 *화나다 / 짜증나다 / 분노* 三档。
   - **训练法**: 整理 5 语言 "生气" 强度表 (微恼/恼/怒/狂怒 — 5 语言各 4 词)。

3. **"孤独" 的深度**:
   - 中文 *孤独 / 寂寞* 较中性 → 学员对日语 *寂しい (sabishii)* 的深度感困惑。
   - **陷阱**: 日语 *寂しい* 是深层情感, 类似 "深刻的孤独"; 韩语 *외롭다* 同样。
   - **训练法**: 整理 5 语言 "孤独" 词汇 (CN 孤独/寂寞 / KR 외롭다 / JP 寂しい / EN lonely / ES solo) — 各自的深度。

4. **"害羞" vs "尴尬" 的概念**:
   - 中文 *害羞 (害羞)* ≈ *尴尬* → 学员对日语 *恥ずかしい (hazukashii)* 感到困惑。
   - **陷阱**: 日语 *恥ずかしい* = 尴尬 (被关注时的不适), 不是 "害羞 (shy)"。
   - **训练法**: 整理 "shy" vs "embarrassed" 5 语言表 (CN 害羞/尴尬 / JP 恥ずかしい / KR 부끄럽다 / EN shy/embarrassed / ES tímido/avergonzado)。

5. **"好好" (hěn hǎo) 的双重含义**:
   - 中文 *好好* 通常 = "好" (无需 very) → 学员对日韩 *大丈夫 (daijōbu) / 괜찮다* (gwaenchana) 类似感到困惑。
   - **陷阱**: 日语 *大丈夫* / 韩语 *괜찮다* 常是 "敷衍" 而非 "真的没事"; 中文 *好好* 类似。
   - **训练法**: 学习"礼貌"句 *还好/還好/괜찮아요/大丈夫* 含义深度。

6. **"心" (xīn) 的中文概念**:
   - 中文 *心* = 心 + 意 (心-意合一) → 学员对英语 heart-mind 分离感到困惑。
   - **陷阱**: 英语 "heart" (情感) vs "mind" (理智); 中文 *心* 不分。
   - **训练法**: 整理 5 语言 "心" 概念 (CN 心 = 心意合一 / EN heart/mind / JP 心 (kokoro) / KR 마음 (maeum) / ES corazón/mente)。
