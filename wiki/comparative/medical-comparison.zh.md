## 各语言详情

### 🇬🇧 英语 (English)
- **关键词**: "Patient" / "Doctor" / "Physician" 区分; "ER" (急诊室) vs "A&E" (英国)
- **模式**: 借词 "doctor" 通用; 医学术语常希腊/拉丁 (cardiology, neurology)
- **来源**: N/A — 英语 wiki 暂无显式 medical 主题

### 🇪🇸 西班牙语 (Spanish)
- **关键词**: "Médico" (physician) vs "Doctor"; "Enfermo" (病) vs "Enfermedad" (疾病); "Salud" (健康)
- **模式**: "Estoy enfermo" = I am sick; 性别一致: médico/médica, enfermo/enferma
- **来源**: N/A — 西语 wiki 暂无显式 medical 主题

### 🇯🇵 日语 (Japanese)
- **关键词**: 病院 (byōin = 医院); 医院 (iin = 诊所); 診療所 (shinryōjo = 诊所/诊所)
- **模式**: 医者 (isha) 随意; 医師 (ishi) 正式; "お大事に" (odaiji ni) = "保重" — 常见告别语
- **来源**: N/A — 日语 wiki 暂无显式 medical 主题

### 🇰🇷 韩语 (Korean)
- **关键词**: 병원 (byeongwon = 医院); 의원 (uiwon = 诊所); 환자 (hwanja = 病人)
- **模式**: 아프다 (apeuda = 病/痛); 固有词身体部位 + 아프다 模式 (배가 아파요 = 胃痛)
- **来源**: N/A — 韩语 wiki 暂无显式 medical 主题

### 🇨🇳 中文 (Chinese)
- **关键词**: 医院 (yīyuàn = 医院); 诊所 (zhěnsuǒ = 诊所); 大夫 (dàifu) = 医生 (口语, 尤其北方)
- **模式**: 看 (kàn) 用于 "看 (医生)": 看病 = 看医生; 中医 (zhōngyī) = 传统中医
- **来源**: N/A — 中文 wiki 暂无显式 medical 主题

## 关键对比 (综合)

| 对比 | 洞察 |
|------|------|
| **本土词 vs 借词 医生** | 英 "doctor" (拉丁), 西 "médico" (拉丁), 但日 医者 / 韩 의사 / 中 医生 是本土/汉字合成 — 没有拉丁借词 |
| **汉字共享** | 日/韩/中 共享医疗术语字符 (医, 病院/医院, 内科/내과/内科) — 同书写根, 不同发音 |
| **专科命名** | CJK 常用合成: 内科 (内科 + 部门); 英/西用拉丁/希腊 (cardiology / cardiología) |
| **传统医学** | 中有 中医 (zhōngyī); 韩有 한의학 (hanuihak); 日有 漢方 (kanpō); 西/英 缺乏综合传统系统 |
| **身体部位 + 아프다** | 韩语独特模式: 名词 + 아프다 (例: 배가 아파요 = 胃痛); 其他语言用 "have a [名词] ache" |

## 🇨🇳 中文学习者笔记 (Chinese Learner Notes)

> 本节是面向中文母语学习者的额外学习指南。

### 中文母语者在学习其他4种语言医疗时的常见陷阱

1. **汉字桥梁导致发音混淆**:
   - 中文医疗词汇与日韩大量共享汉字 (例: 医生/醫師/의사, 医院/病院/병원) → 学员以为读音相近。
   - **陷阱**: 韩语 의사 (uisa) 与中文 "医生" (yīshēng) 同字不同音; 日语 病院 (byōin) 与中文 "病院" (bìngyuàn, 古语) 现代不同音。
   - **训练法**: 利用汉字桥梁先理解概念, 然后严格训练读音 — 不要假设同汉字 = 同读音。

2. **"医生" vs "大夫" 的语域混淆**:
   - 中文 "医生" 通用 / "大夫" 口语 (尤其北方) → 学员假设其他语言也对应。
   - **陷阱**: 日语 医者 (isha) 随意 vs 医師 (ishi) 正式; 韩语 의사 (uisa) 通用; 西语 médico (随性别变化) 通用; 英语 doctor 通用。
   - **训练法**: 区分正式/非正式场合 — 医院/诊所使用正式词, 朋友聊天用口语词。

3. **身体部位疼痛的句式差异**:
   - 中文 "我胃痛" / "我头痛" → 学员假设其他语言对应。
   - **陷阱**: 韩语独特模式 "배가 아파요" (胃 + 아프다); 英语 "I have a stomachache"; 西语 "me duele el estómago"; 日语 "胃が痛い" (胃 + 痛い)。
   - **训练法**: 5种语言疼痛句式逐一对比 — 重点训练韩语的名词+아프다 模式。

4. **中西医概念的差异**:
   - 中文有 中医 (TCM) 完整体系 → 学员假设其他语言也有对应。
   - **陷阱**: 韩语 한의학 (韩医), 日语 漢方 (汉方) 是传统医学体系, 但与中医略有差异; 西语/英语没有对应综合传统系统。
   - **训练法**: 在跨文化医疗场景中, 明白"中医"≠"韩医"≠"汉方" — 各自有传统医学体系。

5. **药店/药房词义区分**:
   - 中文 "药店" (售药) vs "药房" (医院内) → 学员假设其他语言也对应。
   - **陷阱**: 英语 pharmacy (综合) / drugstore (美国售药+日用品); 西语 farmacia (综合); 日语 薬局 (售药) vs ドラッグストア (drugstore); 韩语 약국 (综合)。
   - **训练法**: 区分"医院内药房" vs "街角药店" — 不同语言有不同词汇。
