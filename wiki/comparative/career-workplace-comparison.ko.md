## 언어별 상세

### 🇬🇧 영어 (English)
- **핵심 용어**: "Promotion" (위로), "Lateral move" (옆으로), "Termination" (나감); "Cubicle" (작은 사무실)
- **패턴**: 경량 동사: "I'm in charge of..." (책임); 수동태 흔함
- **격식 메모**: 캐주얼 — "Hey boss"; 격식 — "Dear Mr./Ms. [Last name]"
- **출처**: `[[career-vocabulary]]`

### 🇪🇸 스페인어 (Spanish)
- **핵심 용어**: "Trabajo" (일/직업) vs "Empleo" (고용); "Curro" = 일 slang (스페인)
- **패턴**: -ar 동사: trabajar (일하다); 재귀: "se me hace tarde" (늦어지다)
- **지역 변이**: 스페인: "curro" (slang); 라틴아메리카: "chamba" (멕시코, slang); "laburo" (아르헨티나, slang)
- **출처**: N/A — 스페인어 career-vocabulary 테마 미정

### 🇯🇵 일본어 (Japanese)
- **핵심 용어**: 仕事 (shigoto = 일), 業務 (gyōmu = 업무), 職 (shoku = 직/직위)
- **패턴**: 동사: 〜をする (wo suru); 존경어: お疲れ様です (otsukaresama desu = 수고하셨습니다)
- **Keigo / 경어**: 尊敬語 (sonkeigo = 상급자 존경); 謙譲語 (kenjōgo = 겸양); 丁寧語 (teineigo = 정중)
- **출처**: `[[career-vocabulary]]` (EN/JP/KO 테마; ES/ZH 미정)

### 🇰🇷 한국어 (Korean)
- **핵심 용어**: 직장 (jikjang = 직장), 직업 (jigeop = 직업), 업무 (eomu = 업무)
- **패턴**: 동사: 〜을/를 하다 (eul/reul hada); 직함 + 님: 과장 (나gwajangnim = 과장)
- **말투 단계**: 캐주얼 — "야, 이거 해" (비격식); 정중 — "이거 해요"; 격식 — "이거 합니다" / "이거 하겠습니다"
- **출처**: `[[business-vocabulary]]`, `[[career-vocabulary]]`

### 🇨🇳 중국어 (Chinese)
- **핵심 용어**: 工作 (gōngzuò = 일), 职业 (zhíyè = 직업), 公司 (gōngsī = 회사)
- **패턴**: 동사: 〜进行 (jìnxíng = 진행하다); 在 + 동사 패턴 (在工作中 = 일하는 중)
- **격식 / 존경어**: 您 (nín = 격식 당신); "您辛苦了" (nín xīnkǔle = 수고하셨습니다)
- **출처**: N/A — 중국어 career-vocabulary 테마 미정

## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 직장 어휘를 배울 때 흔히 마주치는 함정

1. **말투 단계 시스템의 한국어 고유성**:
   - 한국어는 6단계 말투 (합쇼체/해요체/해체/하십시오체/하게체/해라체) 보유 — 직장에서는 합쇼체 (격식) + 해요체 (정중) 가 핵심. 영어/스페인어는 2-tier (formal/informal), 일본어는 3-tier (丁寧/普通/カジュアル), 중국어는 您 vs 你 2-tier.
   - **함정**: 학습자가 6단계 전체를 학습하려 하나, 실무에서는 합쇼체 + 해요체 만 사용 — 다른 단계는 혼동.
   - **훈련법**: 한국어 직장 필수 2단계 (합쇼체 + 해요체) 만 마스터. 일본어 3단계 매핑 — 丁寧語 = 합쇼체 / 普通 = 해요체 / カジュアル = 해체. 영어/스페인어 2-tier 매핑 — formal = 합쇼체, informal = 해요체.

2. **"직함 + 님" 의 문화 의존성**:
   - 한국어 "과장님/부장님/팀장님/사장님" — 직함에 -님 을 자동 결합. 영어 Mr./Ms. + 성 + First name 흔함. 일본어 課長/部長/社長 + 様 또는 さん. 중국어 老师/经理/总裁 + 성.
   - **함정**: 학습자가 영어에서 "Manager-nim" 같은 직접 결합 시도 또는 일본어 先生 를 모든 직함에 사용하면 과잉 존경.
   - **훈련법**: 직함 호칭 매핑 — KR 직함 + 님 (외부) / 직함 (내부) / JP 직함 + 様 (외부) / 직함 + さん (동료) / EN Mr./Ms. + 성 (격식) / First name (캐주얼) / ES Profesor(a) / CN 老师/经理 + 성.

3. **"회식(hoesik)" / "飲み会(nomikai)" 의 한국 고유성**:
   - 한국어 "회식" = 회사聚餐 (대부분 의무) — 일본어 "飲み会" 와 유사. 영어 happy hour/team outing 은 자발적.
   - **함정**: 영어 비즈니스 매뉴얼에서 "회식 = team dinner" 단순 번역 → 회식의 강제성/계급의 무시.
   - **훈련법**: 문화 개념 학습 — KR 회식 (강제, 2차/3차, 노래방) / JP 飲み会 (상급자 주도로 건배) / EN happy hour (자발적, 가벼움) / ES después-trabajo 자조적 / CN 团建 (조직화, 일부 강제).

4. **"야근(yageun) / 残業(zangyō) / 加班(jiābān)" 의 문화적 강조점**:
   - 한국어 "야근" 은 일상적 표현, 일본어 "残業" 는 보통 시간 외 근무, 중국어 "加班" 는 노동법상 보상 받을 수 있는 개념. 영어 "overtime" 은 명료.
   - **함정**: 한국어 학습자가 일본어 残業 를 "남은 일"로로 단순 이해 — 잔업의 강도 무시. 중국어 加班 에 대한 보상 기대 무시.
   - **훈련법**: 야근 개념 매핑 — KR 야근 (일상, 보상 없는 경우 많음) / JP 残業 (サービス残業 — 무보수 무보수 흔함) / CN 加班 (1.5배 보상 법정) / EN overtime (1.5배 보상 법정) / ES horas extras (보상 법정).

5. **"직함 명단의 한자어 매칭"**:
   - 課長(かちょう)=과장 / 部長(ぶちょう)=부장 / 社長(しゃちょう)=사장 / 重役=중역 / 社員=사원 / 従業員=종업원 — 한국어와 일본어 한자 직함은 1:1 매핑 거의 가능. 중국어도 유사 (经理/总监/总裁).
   - **함정**: 한국어 "사원" (신입 사원)은 일본어 社員 (모든 직원)과 다름 — 일본에서는 신입도 사원, 부장도 사원.
   - **훈련법**: 한자 직함 매칭 + 의미 차이 학습 — 社員 (전체 직원, JP) vs 사원 (신입만, KR) / 課長 (JP) = 과장 (KR, JP에는 없음) / 部長 (JP/KR 동일) / 社長 (JP) = 사장 (KR, 모두 회사 대표).

### 학습 전략

1. **우선순위 1**: 한국어 직장 필수 2단계 말투 (합쇼체 + 해요체) 마스터 — 비즈니스 이메일 + 회의 + 보고서.
2. **우선순위 2**: 직함 + 님 시스템 + 5언어 매핑 (님/様/さん/Mr.+성/직함+성).
3. **우선순위 3**: 한자 직함 매칭 (課長=과장, 部長=부장, 社長=사장) + 한국어 고유 직함 (과장, 차장, 부장, 팀장).
4. **우선순위 4**: 문화 개념 (회식/残業/야근/加班/team outing) 의 강제성·보상·맥락 차이 학습.
5. **우선순위 5**: 야근/잔업/加班 의 노동법적 차이 + 비즈니스 매너 학습.
