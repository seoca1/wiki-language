## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 문법 기능별 난이도를 마주칠 때 흔히 있는 함정

1. **삼중 폐쇄음 (한국어 고유, 5/5 난이도)**:
   - 한국어 ㄱ/ㅋ/ㄲ (평지/격음/된소리) + ㅂ/ㅍ/ㅃ + ㄷ/ㅌ/ㄸ — 영어/스페인어/일본어/중국어 모두 이 구분 없음. 한국어 화자만 보유.
   - **함정**: 다른 언어 학습자가 한국어 삼중 폐쇄음을 정확히 발음하기 매우 어려움 (한국어 화자는 모어라서 자동).
   - **훈련법**: 삼중 폐쇄음의 한국어 모어 화자 우위 활용 — 다른 4개 언어 학습 시 같은 발음 시스템이 없음을 인정하고 한국어 발음 청각 능력 활용.

2. **존경어 시스템 (한국어 + 일본어, 5/5 난이도)**:
   - 한국어 합쇼체/해요체/해체 + 시/으시 + 드리다/잡수시다 + 이름 호칭 — 영어/스페인어/중국어에 없는 완전 문법화 시스템. 일본어와 가장 유사.
   - **함정**: 한국어 학습자가 영어 비즈니스 이메일에서 "Sincerely yours" 같은 격식 표현 시도 → 그러나 영어에는 동사 활용 격식 없음. "Please + thank you" + 격식 어휘 정도.
   - **훈련법**: 한국어 존경어 5단계 → 영어 (limited usted-like) / 스페인어 (usted/tú) / 일본어 (keigo) / 중국어 (您) 매핑. 각 언어의 격식 깊이 차이 학습.

3. **받침 (한국어 고유, 4/5 난이도)**:
   - 한국어 받침 (음절말 자음) + 음절말 중화 (예: "읽다" → "익다") — 영어/스페인어/일본어/중국어 모두 받침 없음 (일본어/중국어는 모음으로 끝).
   - **함정**: 다른 언어 학습자가 받침 + 음절말 중화 어려움. 한국어 화자는 모어라서 자동.
   - **훈련법**: 받침 규칙 한국어 모어 화자 우위 활용 — 다른 4개 언어 학습 시 음절말 자음 없음을 인식.

4. **시제 vs 상(相) 의 차이 (중국어 특수)**:
   - 한국어 시제 (과거/현재/미래) vs 중국어 상(相) 조사 (了/过/着) — 매우 다른 시스템. 한국어 학습자가 중국어 학습 시 가장 혼란.
   - **함정**: 한국어 학습자가 중국어에서 "I ate" 을 "我吃了" 로 단순 매핑 → 사실 "吃了" 는 완료 상(相), 단순 과거 아님. 반복/미래도 "了" 로 표현 가능.
   - **훈련법**: 시제 vs 상(相) 명확화 매트릭스 — 한국어 시제 / 영어 시제 / 스페인어 시제 / 일본어 시제 / 중국어 상(相) 조사 별도.

5. **어순 변환 (SOV ↔ SVO)**:
   - 한국어 SOV 어순 vs 영어/스페인어/중국어 SVO 어순 — 동사 위치 다름. 일본어는 SOV 로 한국어와 동일.
   - **함정**: 한국어 학습자가 영어/스페인어/중국어 문장에서 "I apple eat" 같은 잘못된 어순.
   - **훈련법**: SOV ↔ SVO 변환 학습 → 같은 문장을 한국어 (SOV) + 영어/스페인어/중국어 (SVO) 양방향 변환. 일본어 (SOV) 와는 직접 매핑 가능.

### 학습 전략

1. **우선순위 1**: 한국어 문법 시스템 (SOV + 조사 + 말투 + 시제) 완전 마스터 — 다른 4개 언어 학습의 토대.
2. **우선순위 2**: 어순 변환 (SOV ↔ SVO) 자동화 — 영어/스페인어/중국어 학습 시 필수.
3. **우선순위 3**: 시제 vs 상(相) 의 차이 명확화 — 중국어 학습 시 상(相) 조사 의식.
4. **우선순위 4**: 존경어/격식 시스템의 한국어/일본어 vs 영어/스페인어/중국어 차이 학습.
5. **우선순위 5**: 관사/성/양사/피치액센트 등 신규 개념 학습 — 영어/스페인어 학습 시.
