## 언어별 상세

### 🇬🇧 영어 (English)
- **동사 형태**: Be + 형용사 (I am happy / sad / angry); Feel + 형용사 (I feel sad / anxious / happy)
- **강도 부사**: Very + adj, So/Really + adj, Adjective + -er/-est
- **공통 표현**: "I'm feeling..." (부드러움), "I'm so..." (캐주얼 강조), "I get..." (습관적)

### 🇪🇸 스페인어 (Spanish)
- **동사 형태**: Estar + 형용사 (일시적): Estoy feliz = "나는 행복해"; Ser + 형용사 (영구적): Soy nervioso = "나는 신경질적 사람"; Sentir + 명사: Siento alegría
- **강도**: Muy + adj, -ísimo/a (contentísimo = 매우 행복), Tan + adj
- **지역 변이**: 스페인: agobiado (압도됨); 라틴아메리카: estresado (스트레스); 아르헨티나: al horno (굶주림)

### 🇯🇵 일본어 (Japanese)
- **동사 형태**: 형용사 (i-adj/na-adj) + です: 嬉しいです; 동사 + たい: 食べたい = "먹고 싶다"; 형용사 + なる: 寒くなる = "추워지다"
- **형용사 유형**: i형용사 (嬉しい, 楽しい, 悲しい, 辛い), na형용사 (好き, 嫌い, 綺麗)
- **특수 표현**: 〜たい (tai) = 하고 싶다, 〜がる (garu) = 외부 표시 (3인칭): 怖가っている, 寂しい (sabishii) = 외로움 — 일본 고유 감정

### 🇰🇷 한국어 (Korean)
- **동사 형태**: 형용사 + -다 (da): 기쁘다 = "행복하다 (서술)"; 형용사 + -어요 (eoyo): 기뻐요 = "행복해요 (정중)"; 형용사 + -ㅂ니다 (seumnida): 기쁩니다 = "행복합니다 (격식)"
- **특수 감정 표현**: 정 (jeong) = 깊은 관계적 유대 (영어 대응 없음); 눈치 (nunchi) = 사회적 인식 (영어 대응 없음); 한 (han) = 집단적 슬픔 (문화 개념); 그리움 (gereum) = 그리워함 (단순 그리움 이상의 감정 상태)
- **감정 강도**: 너무 (neomu) = 너무; 진짜 (jinjja) = 진짜; 완전 (wanjeon) = 완전히

### 🇨🇳 중국어 (Chinese)
- **동사 형태**: 형용사 + 了 (le) = 상태 변화: 高兴了; 很 + 형용사: 很高兴; 不 + 형용사: 不高兴
- **특수 감정 표현**: 舒服 (shūfu) = 편안함 (신체 + 감정); 累 (lèi) = 피곤함 (신체 + 정신); 羡慕 (xiànmù) = 부러움 (嫉妒 "질투" 와 다름); 开心 (kāixīn) = 행복 (마음 열림); 伤心 (shāngxīn) = 마음 상함; 担心 (dānxīn) = 걱정 (literally "마음 걱정")
- **동사 조사**: 了 (le) 상태 변화, 过 (guò) 과거 경험, 着 (zhe) 연속 상태

## 🇰🇷 한국어 학습자 노트 (Korean Learner Notes)

> 본 섹션은 한국어 학습자 대상의 추가 학습 가이드입니다.

### 한국어 화자가 다른 4개 언어 감정 어휘를 배울 때 흔히 마주치는 함정

1. **"정(Jeong)" 의 한국 고유성**:
   - 한국어 "정" 은 시간이 지나며 깊어지는 인간적 유대 — 다른 4개 언어에 직접 대응 없음. 영어 "love/affection/bond" 모두 부분.
   - **함정**: 한국어 학습자가 영어 love/친구 에 "정" 을 직접 매핑 → "친구 사이의 정" = "friendship love" 단순화.
   - **훈련법**: 정 의 어휘화 — 정이 들다/생기다/깊다/묵다/떨지다/좋다. 한자 情 의 JP (jō/nasake) / CH (qíng) 매칭 + 한국 정 의 미묘한 차이 학습.

2. **"한(Han)" 의 집단적 슬픔**:
   - 한국어 "한" = 민족적/공동체적 슬픔·한 — 분단 역사·사회적 억압에서 비롯된 깊은 감정. 일본어 物の哀れ 와 중국어 悲 모두 부분 대응.
   - **함정**: 한국어 학습자가 영어 sadness/melancholy 로 "한" 단순 번역 → 한의 집단성·역사성 무시.
   - **훈련법**: 한 의 매체 (한승원 소설, 한국 영화, K-드라마) + 일본어 物の哀れ (mono no aware, 일시적 아름다움 인식) 와의 차이. 중국어 悲 (bēi, 슬픔) 와의 깊이 차이.

3. **"눈치(Nunchi)" 의 사회적 인식**:
   - 한국어 "눈치" = 상대 표정/분위기 빠르게 파악 → 일본어 空気を読む (kuuki o yomu) 와 매우 유사. 영어 "tact/awareness" 모두 부분.
   - **함정**: 한국어 학습자가 영어 "common sense" 로 번역 → 매우 다른 개념 (실용적 상식 ≠ 사회적 맥락).
   - **훈련법**: 눈치 의 시나리오 — 상사 표정 보고 말 삼가기/자리 양보/분위기 파악 — 5언어 매핑.

4. **"그리움(Gereum)" 의 깊이**:
   - 한국어 "그리움" = 그리워하는 감정 상태 — 단순 "miss" 가 아닌 깊은 정서적 그리움. 일본어 懐かしい (natsukashii) 와 유사하나 다름.
   - **함정**: 한국어 학습자가 영어 I miss you / 중국어 我想你 (wǒ xiǎng nǐ) 로 그리움 단순 번역 → 그리움 의 깊이·시간성 무시.
   - **훈련법**: 그리움 어휘화 — 그립다/그리워하다/그리움/보고 싶다/생각이 나다. 일본어 懐かしい (과거) vs 恋しい (현재 그리움) 구분.

5. **"괜찮아요(Gwaenchana)" 의 다의성**:
   - 한국어 "괜찮아요" = OK/괜찮다/사양 (3가지 의미). 영어 "I'm fine" 도 비슷하나 한국어의 눈치 문화에서 "괜찮아요" 가 부정 의미를 가질 수 있음.
   - **함정**: 한국어 학습자가 영어 "I'm fine" 을 "괜찮아요" 로 직접 번역 → 영어 화자는 문자 그대로 이해. 그러나 한국에서 "괜찮아요" 가 "OK 아님" 의미일 수 있음.
   - **훈련법**: 괜찮아요 의 3가지 의미 — 진짜 OK / 부정 (눈치) / 사양 (정중 거절). 맥락별 사용 학습. 일본어 大丈夫 (daijōbu) 도 같은 다의성.

### 학습 전략

1. **우선순위 1**: 한국어 고유 감정 어휘 (정/한/눈치/그리움/체면) 의 어휘화 — 다른 4개 언어에 직접 번역 어려운 개념.
2. **우선순위 2**: 감정 강도 부사 (조금/꽤/매우/진짜/너무) 의 5단계 매트릭스.
3. **우선순위 3**: 사랑/좋아함 단계 (좋아해 → 사랑해) 의 5언어 매핑.
4. **우선순위 4**: 감정 의성어/감탄사 (ㅎㅎ/엉엉/한숨) 의 5언어 매핑.
5. **우선순위 5**: 정신 건강 어휘 (불안/우울증/번아웃) + 위기 핫라인 번호.
