# Confusion Hotspots — Cross-Language Comparison

**Languages**: English · Spanish · Japanese · Korean · Chinese
**Last updated**: 2026-07-19

> **The error magnet**: things learners (and native speakers!) commonly confuse, mistranslate, or mix up across languages. Critical for avoiding embarrassment and accidents.

## False Friends (Cognates that Mean Different Things)

| English word | English meaning | Spanish similar word | **Actual Spanish meaning** | Example |

## Pronunciation Confusion Points

### English Speakers Common Errors

#### In Spanish
| English speaker says | Should say | Why |
|----------------------|------------|-----|
| "Hespañol" | "Español" (ehs-pah-nyohl) | English "e" = "ee", Spanish "e" = "eh" |
| "Gracias" as "GRAH-see-as" | "GRAH-syahs" | "c" before "e/i" = "s" sound |
| "Vaya" as "VAY-ah" | "BAH-yah" (soft b/v) | b/v = same sound (b/v) between vowels |
| "Hola" with TH | "OH-lah" | Spanish "h" silent |

#### In Japanese
| English speaker says | Should say | Why |
|----------------------|------------|-----|
| "Hai" as English "Hi" | "Hah-ee" | "ai" = "ah-ee" (2 morae) |
| "Desu" as "Day-su" | "Des" (s light) | "u" devoiced in some contexts |
| "Ri" as "ree" | "Ree" | "i" not "ee" — Japanese has no "ee" |
| "Kun" as "Coon" | "Koon" | "u" not "oo" |
| "San" as "Sahn" | "Sahn" (short a) | no "saen" sound |

#### In Korean
| English speaker says | Should say | Why |
|----------------------|------------|-----|
| "Annyeonghaseyo" with clear TH | "An-nyeong-ha-se-yo" | no "th" sound |
| "Korean" as "Koh-ree-an" | "Korean" (2 syllables) | no "ree" |
| "Kimchi" as "Kim-chee" | "Kim-chi" (no glide) | "i" short, no "ee" |
| "Bulgogi" as "Bul-go-gee" | "Bul-go-gi" | "gi" not "gee" |

#### In Chinese
| English speaker says | Should say | Why |
|----------------------|------------|-----|
| "Ni hao" as "Nee how" | "Nee how" (rising 3rd tone on hao) | tones matter |
| "Xie xie" as "She she" | "Syeh-syeh" (3rd + neutral) | "x" = "s" (in pinyin) |
| "Zai jian" as "Zai jee-an" | "Zai jian" (neutral tones) | no glide in pinyin |

## Grammar Confusion Points

### Tense/Aspect Mistakes

| L1 → L2 | Common Error | Why |
|---------|--------------|-----|
| **EN → ES** | "If I **will go**" → "*Si **iré***" (wrong) | Spanish doesn't use future in si clauses → *Si **voy*** |
| **EN → ES** | "I'm **boring**" → "*Estoy aburrido*" (wrong person) | Spanish uses *aburrir* = to bore; *Estoy aburrido* = I'm bored (passive sense) |
| **EN → JP** | "I **have gone**" → "I **go**" | Japanese has no present perfect; just past (*itta*) |
| **EN → KR** | "I **will go** tomorrow" → "I **go** tomorrow" | Korean often omits future tense; *내일 갈게* can be future |
| **EN → CH** | "I **am eating**" → "I **eat**" | Chinese aspect, not tense; *我在吃* (progressive) vs *我吃* (habitual) |
| **JP → EN** | "Yesterday **go**" → "Yesterday **went**" | English requires past tense |
| **KR → EN** | "Yesterday **go**" → "Yesterday **went**" | Same |
| **CH → EN** | "Yesterday **go**" → "Yesterday **went**" | Same |

### Politeness/Register Mistakes

| L1 → L2 | Common Error | Why |
|---------|--------------|-----|
| **EN → ES** | "tú" with strangers | Spanish requires *usted* by default in LatAm |
| **EN → JP** | Plain form with strangers | Japanese requires *desu/masu* by default |
| **EN → KR** | Plain form with elders | Korean requires *haeyo/hapsyo* by default |
| **EN → CH** | No honorific for elders | Chinese uses 您 + titles |
| **ES → JP** | "Tú" form with superiors | Japanese requires *sonkeigo* |
| **JP → CH** | Over-honorific (您) like JP keigo | Chinese honorific is more about titles + please |

### Article Mistakes

| L1 → L2 | Common Error | Why |
|---------|--------------|-----|
| **JP/KR/CH → EN** | "I saw **car**" (no article) | English requires "a car" or "the car" |
| **CH → EN** | "I have **book**" (no article) | Same |
| **EN → JP/KR/CH** | "I saw **a cat**" → "I saw **cat**" | No articles in target |

### Gender/Number Mistakes

| L1 → L2 | Common Error | Why |
|---------|--------------|-----|
| **EN → ES** | "la problema" (wrong gender) | Spanish *problema* is masculine despite -a |
| **EN → ES** | "the book**s**" → "el libro" (no plural) | Spanish plurals required |
| **JP → EN** | "I have book" (no plural) | English requires plural |
| **KR → EN** | "I saw dog" (no article) | English requires article |

## Register & Style Confusion

### Polite Forms Mistake

| Context | Wrong (casual) | Right (polite) |
|---------|----------------|----------------|
| English (in business) | "Yo" | "Hello" |
| Spanish (in business) | "Tío" (buddy) | "Estimado Sr." |
| Japanese (in business) | Plain form | *-masu* form + keigo |
| Korean (in business) | *Banmal* | *Haeyoche* or *hapsyoche* |
| Chinese (in business) | 你 | 您 + title |

### Pronoun Confusion

| English | Spanish | Japanese | Korean | Chinese |
|---------|---------|----------|--------|---------|
| **You (singular)** | tú/usted/vos | あなた/名前+さん | 너/당신/(name)-님/씨 | 你/您 |
| **Pitfall** | "Tú" with strangers = rude | "Anata" with stranger = cold | "Neo" with elder = rude | "Ni" with elder = rude |
| **Workaround** | Use *usted* | Use name + *san* | Use name + *nim/ssi* | Use 您 + title |

## Common Spelling/Grammar Typos

### Frequently Confused Pairs

| Language | Pair | Mnemonic |
|----------|------|----------|
| **EN** | there/their/they're | "there" has "here" inside |
| **EN** | your/you're | "you're" = "you are" |
| **EN** | its/it's | "it's" = "it is" |
| **EN** | affect/effect | "affect" = verb; "effect" = noun (usually) |
| **ES** | por/para | *por* = by/for (cause); *para* = for (purpose) |
| **ES** | a ver / haber | *a ver* = let's see; *haber* = to have (aux) |
| **ES** | si/sí | *si* = if; *sí* = yes |
| **JP** | いる/ある | *iru* = animate; *aru* = inanimate |
| **JP** | 場合/ように | *baai* = case; *youni* = like |
| **JP** | こと/の | nominalization particles |
| **KR** | 을/를 | object markers (after consonant/vowel) |
| **KR** | 이/가 | subject markers (after consonant/vowel) |
| **KR** | 은/는 | topic markers (after consonant/vowel) |
| **CH** | 的/得/地 | *的* (de = adj marker), *得* (dé = complement), *地* (dì = adv) |
| **CH** | 在/再 | *zài* = at/in; *zài* (tone 4) = again |
| **CH** | 做/作 | *zuò* (both, but different uses) |
