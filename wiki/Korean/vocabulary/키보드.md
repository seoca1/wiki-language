# 키보드

**Part of Speech:** 명사 (noun)

**Definition:** Keyboard — 타이핑하는 입력 장치.

**Etymology:** 외래어 (keyboard, 영어에서 차용)

**Romaja:** kibodeu

---

## Examples

- **키보드로 타이핑해요.** — I type with the keyboard.
- **키보드가 깨졌어요.** — The keyboard is broken.
- **새 키보드를 샀어요.** — I bought a new keyboard.
