# Education (교육) - Korean Perspective

한국인이 한국어 교육 어휘를 학습할 때 + 일본어 번역 비교. 각 어휘의 일어 번역 · 한자 · IPA · 한국 문화 맥락.

**참고:** 본 페이지는 `wiki/Korean/vocabulary/education-vocabulary.md` 의 한국어 관점 + 일본어 번역 페이지.

---

## 학교 (Schools)

### 학교 (학교)

**일어:** 学校 (がっこう, 가쿠우) — 한국어 "학교" / 일어 "学校(がっこう, 가쿠우)" 동일.

**IPA:** /hak̚.kjo/ / 일어 /ɡak.koː/

#### 예문

- 저는 학교에 갑니다. — 저는 학교에 갑니다. (캐주얼)
- 学校に行きます (가쿠우니 이키마스) — 학교에 갑니다. (일어)

#### 한국어 학습 노트

**학교 (hakgyo)** = 일어 "学校 (がっこう)" 의미. **音읽 學 (がく, 학) + 校 (こう, 교)** 어원 비교.

---

### 학생 (학생)

**일어:** 学生 (がくせい, 가쿠세이) — 한국어 "학생" / 일어 "学生(がくせい, 가쿠세이)" 동일.

**IPA:** /hak̚.ɕɛŋ/ / 일어 /ɡak.seː/

#### 한국어 학습 노트

**학생 (haksaeng)** = 일어 "学生 (がくせい)" 의미. **音읽 學 (がく, 학) + 生 (せい, 생)** 어원 비교.

---

### 선생님 (선생님)

**일어:** 先生 (せんせい, 센세이) — 한국어 "선생님" / 일어 "先生(せんせい, 센세이)" 동일.

**IPA:** /sʌn.ɕɛŋ.nim/ / 일어 /sen.seː/

#### 한국어 학습 노트

**선생님 (seonsaengnim)** = 일어 "先生 (せんせい)" 의미. **漢字 先輩 (せんぱい, 선배)** 와 어원 비교. **선생님 (Korea)** = 존칭 (-님 접미사) + **先生 (Japan)** = 교사/의사/변호사 의미.

---

**일어:** 本 (ほん, 혼) — 한국어 "책" / 일어 "本(ほん, 혼)" 의미.

**IPA:** /tɕʰɛk̚/ / 일어 /hon/

#### 한국어 학습 노트

**책 (chaek)** = 일어 "本 (ほん)" 의미. **音읽 本 (ほん, 본)** = 한국어 "본" 의 어원 비교.

---

### 대학교 (대학교)

**일어:** 大学 (だいがく, 다이ガ쿠) — 한국어 "대학교" / 일어 "大学(だいがく, 다이ガ쿠)" 의미.

**IPA:** /tɛ.ha.kʰjo/ / 일어 /da.i.ɡakɯ/

#### 한국어 학습 노트

**대학교 (daehakgyo)** = 일어 "大学 (だいがく)" 의미. **大学 (だいがく)** = 한국어 "대학" 의 어원 비교. **日本の大学 (だいがく)** = 학부 과정.

## 교실 (Classroom)

### 칠판 (칠판)

**일어:** 黒板 (こくばん, 코쿠반) — 한국어 "칠판" / 일어 "黒板(こくばん, 코쿠반)" 의미.

**IPA:** /tɕʰil.pʰan/ / 일어 /ko.kɯ.ban/

#### 한국어 학습 노트

**칠판 (chilpan)** = 일어 "黒板 (こくばん)" 의미. **한국어 "칠판"** 의 어원: 칠 (7) + 판 (판) = 7개 색 = 칠판 (의역). **日本の 黒板 = 검 (검정) + 판 (판)** = 검은 판 (직역).

---

### 책상 (책상)

**일어:** 机 (つくえ, 츠쿠에) — 한국어 "책상" / 일어 "机(つくえ, 츠쿠에)" 의미.

**IPA:** /tɕʰɛk̚.ɕaŋ/ / 일어 /t͡sɯ.ke/

#### 한국어 학습 노트

**책상 (chaeksang)** = 일어 "机 (つくえ)" 의미. **机 (한자)** = 한국어 "꺼" 의 어원 비교.

---

### 의자 (의자)

**일어:** 椅子 (いす, 이스) — 한국어 "의자" / 일어 "椅子(いす, 이스)" 의미.

**IPA:** /ɯi.dʑa/ / 일어 /i.sɯ/

#### 한국어 학습 노트

**의자 (uija)** = 일어 "椅子 (いす)" 의미. **音읽 椅 (い, 의)** = 한국어 "의" 의 어원 비교.

---

### 가방 (가방)

**일어:** 鞄 (かばん, 카반) — 한국어 "가방" / 일어 "鞄(かばん, 카반)" 의미.

**IPA:** /ka.baŋ/ / 일어 /ka.ban/

#### 한국어 학습 노트

**가방 (gabang)** = 일어 "鞄 (かばん)" 의미. **音읽 鞄 (かく, 혁)** = 한국어 "혁" 의 어원 비교.
