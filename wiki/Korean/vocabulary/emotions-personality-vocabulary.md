# Korean Emotions & Personality Vocabulary

이 페이지는 한국어 emotions-personality 어휘를 통합합니다. 각 항목은 품사, 한자(한자어), 존댓말/반말 구분, 발음(받침), 어원, 실제 예문, 문화적 맥락을 포함합니다.

---

## 1. 기본 감정 (Basic Emotions)


### 기쁨 (gippeum)

**Part of Speech:** 명사 (noun)

**Hanja:** 喜悅 (기쁠 희 + 기쁠 환) — 고유어 '기쁘다'의 명사형

**Definition:** happiness, joy, delight

**Romaja / IPA:** gippeum / [ɡipɯm]

**Etymology:** 고유어 '기쁘다' (기쁘- + -ㅁ) → '마음이 흐뭇하고 즐거운 상태'. 한자어 '희열(喜悅)', '환희(歡喜)'와 구별됨.

**Honorific Note:** 명사이므로 존댓말/반말 구분 없음. 동사 '기쁘다' 활용 시 어미에 따라 구분.

#### Examples

- **기쁨**이 넘칩니다. (존댓말) — 기쁨이 가득하다
- 큰 **기쁨**을 주셔서 감사해요. (존댓말) — 고마움 표현
- **기쁨**보다 슬픔이 더 크네. (반말) — 대비

#### Related Terms

- [[emotions-personality-vocabulary#기쁘다|기쁘다 (형용사: happy)]]
- [[emotions-personality-vocabulary#즐거움|즐거움 (noun: enjoyment/fun)]]
- [[emotions-personality-vocabulary#행복|행복 (noun: happiness/blessed)]]

#### Cultural Notes

한국어에서 '기쁨'은 '행복(幸福)'보다 가볍고 순간적인 감정. '기쁨조' = 북한 용어(예술단). '기쁨은 나누면 배가 된다' = 속담. 경조사에서 '기쁨' = 축하할 일(결혼, 출산, 합격).

#### Sources

- [[emotions-personality-vocabulary]]
- 표준국어대사전
- 국립국어원 한국어 기초사전


### 기쁘다 (gippeuda)

**Part of Speech:** 형용사 (adjective) — ㅂ 불규칙 활용

**Hanja:** 喜 (기쁠 희) — 한자어 어근

**Definition:** to be happy, glad, pleased

**Romaja / IPA:** gippeuda / [ɡipɯda] (기쁘다) → 기뻐요 [ɡipʰoj] (활용)

**Batchim Note:** 어간 '기쁘-' (받침 ㅂ) → 모음 어미 앞에서 '우'로 변함 (기뻐요, 기쁘니). 자음 어미 앞에서는 '기쁩-' (기쁩니다).

**Honorific Forms:**
- 하소서체: 기쁘시오
- 하오체: 기쁘오
- 하게체: 기쁘네
- 해라체: 기쁘다
- 해요체: 기뻐요
- 해체: 기뻐

#### Examples

- 시험에 합격해서 **기뻐요**. (해요체) — 결과에 대한 기쁨
- **기쁘**게 맞이했어요. (해요체 + 부사형) — 기쁜 마음으로
- **기쁘**지 않습니다. (해요체 부정) — 기쁘지 않다

#### Related Terms

- [[emotions-personality-vocabulary#기쁨|기쁨 (명사: joy)]]
- [[emotions-personality-vocabulary#즐겁다|즐겁다 (형용사: enjoyable)]]
- [[emotions-personality-vocabulary#행복하다|행복하다 (형용사: happy/blessed)]]

#### Cultural Notes

'기쁘다'는 주관적 감정 표현으로, 타인의 기쁨을 말할 때 '기뻐하시다'(존경법) 사용. "기쁘게 생각합니다" = 공식적 수락/감사 표현. '기쁜 소식' = 경사.

#### Sources

- [[emotions-personality-vocabulary]]
- 표준국어대사전


### 슬픔 (seulpeum)

**Part of Speech:** 명사 (noun)

**Hanja:** 悲傷 (슬플 비 + 상할 상) — 고유어 '슬프다'의 명사형

**Definition:** sadness, sorrow, grief

**Romaja / IPA:** seulpeum / [sɯlpɯm]

**Etymology:** 고유어 '슬프다' (슬프- + -ㅁ) → '마음이 아프고 괴로운 상태'. 한자어 '비애(悲哀)', '애도(哀悼)'와 구별.

#### Examples

- **슬픔**을 견디기 힘들어요. (존댓말) — 슬픔 극복
- **슬픔**이 밀려와요. (존댓말) — 감정 파도
- **슬픔**도 기쁨도 다 지나가네. (반말) — 인생 무상

#### Related Terms

- [[emotions-personality-vocabulary#슬프다|슬프다 (형용사: sad)]]
- [[emotions-personality-vocabulary#비통|비통 (명사: bitter grief, 한자어)]]
- [[emotions-personality-vocabulary#애도|애도 (명사: mourning, 한자어)]]

#### Cultural Notes

한국 문화에서 슬픔 표현은 '참는 것'이 미덕(인내). '슬픔을 삼키다' = 억누르다. 장례식에서 '슬픔' 공유 = 공동체 결속. '한(恨)' = 풀리지 않은 깊은 슬픔/원한(한국 고유 정서).

#### Sources

### 슬프다 (seulpeuda)

**Part of Speech:** 형용사 (adjective) — ㅂ 불규칙 활용

**Hanja:** 悲 (슬플 비)

**Definition:** to be sad, sorrowful

**Romaja / IPA:** seulpeuda / [sɯlpɯda] → 슬퍼요 [sɯlpʰojo]

**Honorific Forms:** 슬프시오 / 슬프오 / 슬프네 / 슬프다 / 슬퍼요 / 슬퍼

#### Examples

- 이별이 **슬퍼요**. (해요체)
- **슬픈** 영화예요. (관형형 + 명사) — 슬픔을 주는 영화

#### Cultural Notes

타인의 슬픔: '슬퍼하시다'(존경법). '슬픈 척하다' = 위선. '슬픈 예감' = 불길한 예감. 공식적 조문: "삼가 고인의 명복을 빕니다" (슬프다 직접 사용 안 함).

### 화남 (hwanam)

**Part of Speech:** 명사 (noun)

**Hanja:** 怒 (성낼 노) — 동사 '화나다'의 명사형

**Definition:** anger, rage

**Romaja / IPA:** hwanam / [hwanam]

**Etymology:** 고유어 '화나다' (화 + 나다) → '화가 나다' → 명사화 '화남'. '화(火)' = 불/분노. 한자어 '노여움', '격노(激怒)'.

#### Examples

- **화남**을 참을 수 없어요. (존댓말)
- **화남**이 풀렸어요. (존댓말) — 분노 해소
- **화남** 때문에 실수했어. (반말)

#### Related Terms

- [[emotions-personality-vocabulary#화나다|화나다 (동사: get angry)]]
- [[emotions-personality-vocabulary#노여움|노여움 (명사: 한자어, 더 격식)]]
- [[emotions-personality-vocabulary#분노|분노 (명사: rage, 한자어)]]

#### Cultural Notes

'화남'은 일상어, '노여움/분노'는 격식/문어. 한국 문화에서 분노 직접 표출은 금기시됨('참는다', '삭인다'). '화병(火病)' = 억눌린 분노로 인한 신체화 증상(한국 문화 증후군).

#### Sources

### 화나다 (hwanada)

**Part of Speech:** 동사 (verb) — 자동사

**Hanja:** 火 (불 화) + 나다

**Definition:** to get angry, to become angry

**Romaja / IPA:** hwanada / [hwanada] → 화나요 [hwanajo]

**Batchim Note:** '화' (받침 ㅎ) + '나-' → 연음 '화나-' [hwana-]. 과거 '화났다' [hwanatta].

**Honorific Forms:** 화나시오 / 화나오 / 화나네 / 화나다 / 화나요 / 화나

#### Examples

- 사장님이 **화나셨어요**. (존경법: 화나시다)
- **화나**서 말이 안 나와요. (연결어미 -아/어)
- **화나**지 마세요. (부정 명령)

#### Related Terms

#### Cultural Notes

윗사람에게: '성나시다', '노하시다'(존경법). '화내다' = 의도적 분노 표출(투정). '화풀다' = 분노 해소(술, 운동 등). "화가 치밀다" = 분노가 솟구치다.

### 두려움 (dureoum)

**Hanja:** 恐懼 (두려울 공 + 두려워할 구) — 동사 '두렵다'의 명사형

**Romaja / IPA:** dureoum / [turʌum]

#### Examples

- **두려움**을 극복했어요. (존댓말)
- **두려움** 없이 도전했다. (문어/반말)

- [[emotions-personality-vocabulary#공포|공포 (명사: 공포증, 한자어)]]

#### Cultural Notes

'두려움' = 내면적 심리 상태(격식). '무서움' = 구체적 대상에 대한 두려움(일상). '두려워하다' = 타인 주관. 한국에서 '겁 많다' = 소심함(부정적). '겁없다' = 용감/무모(양면성).

'놀람' = 문어/격식. 일상: '깜짝 놀랐다'. '놀라운 일' = 긍정/부정 모두 가능. '놀라 자빠지다' = 관용구(매우 놀라다). 한국 예능 '몰래카메라' = 놀람 유도 오락.

### 기뻐하다 (gippeohada)

**Part of Speech:** 동사 (verb) — 기쁘다(형용사) + -어하다(타인 심리 동사화)

**Definition:** to be glad, to rejoice (about someone else's good fortune or one's own)
