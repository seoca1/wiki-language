# Clothing (의류) - Korean Perspective

## 하의 (Bottoms)

### 바지 (baji)

**일어:** ズボン (zubon) — 한국어 "바지" / 일어 "ズボン" 의미.

**IPA:** /pa.dʑi/ / 일어 /dz�.boɴ/

**어원:** 한국어 "바지" 순우리말 vs 일어 "ズボン" 프랑스어 jupon 음역.

#### 한국어 학습 노트

**바지 (baji)** = 일어 "ズボン (zubon)" 의미. **어원 다름**: 한국 순우리말 vs 일어 서양어 음역. 발음: 바지 (ba-ji) vs ズボン (zu-bon) — ㅂ 발음 위치.

## 신발 (Footwear)

## 액세서리 (Accessories)

### 모자 (moja)

**일어:** 帽子 (ぼうし, bōshi) — 한국어 "모자" / 일어 "帽子" 의미.

**IPA:** /mo.dʑa/ / 일어 /boː.ɕi/

**한자 비교:** 帽 (한자어 "모", 일어 음독 ぼう) — 한자 동일.

#### 한국어 학습 노트

**모자 (moja)** = 일어 "帽子 (bōshi)" 의미. **한자어 동일 어원**. 발음: 모자 (mo-ja) vs ぼうし (bō-shi, 장음) — 한국어 화자는 장음 + ㅎ→ㅅ 발음 연습.

---

### 양말 (yangmal)

**일어:** 靴下 (くつした, kutsushita) — 한국어 "양말" / 일어 "靴下" 의미.

**IPA:** /jaŋ.mal/ / 일어 /kɯ.tsɯ.ɕi.ta/

**한자 비교:** 襪/袜 (한자어 "말", 일어 음독 べつ) / 下 (한자어 "하", 일어 음독 か) — 일어는 합성어 "靴 + 下".

#### 한국어 학습 노트

**양말 (yangmal)** = 일어 "靴下 (kutsushita)" 의미. **어원 다름**: 한국 한자어 단일 vs 일어 합성어 (靴 + 下). 발음 패턴 매우 다름.

---

### 장갑 (janggap)

**일어:** 手袋 (てぶくろ, tebukuro) — 한국어 "장갑" / 일어 "手袋" 의미.

**IPA:** /tɕaŋ.�ap/ / 일어 /te.bɯ.kɯ.ɾo/

**한자 비교:** 手 + 袋 (한자어 "수 + 대", 일어 음독 て + ふくろ) — 일어는 합성어 "手 + 袋".

#### 한국어 학습 노트

**장갑 (janggap)** = 일어 "手袋 (tebukuro)" 의미. **어원 다름**: 한국 한자어 단일 vs 일어 합성어. 발음: 장갑 (jang-gap) vs てぶくろ (te-bu-ku-ro, 4음절) — 패턴 매우 다름.

---

### 목도리 (mogdori)

**일어:** マフラー (mafurā) — 한국어 "목도리" / 일어 "マフラー" 의미.

**IPA:** /mok.to.ɾi/ / 일어 /ma.fɯ.ɾaː/

**어원:** 한국어 "목 + 도리" 합성 / 일어 영어 muffler 음역.

#### 한국어 학습 노트

**목도리 (mogdori)** = 일어 "マフラー (mafurā)" 의미. 어원 합성/음역 차이. 발음 패턴 매우 다름.

## 소재 (Materials)

### 면 (myeon)

**일어:** 綿 (めん, men) / 木綿 (もめん, momen) — 한국어 "면" / 일어 "綿" 의미.

**IPA:** /mjʌn/ / 일어 /men/

**한자 비교:** 綿 (한자어 "면", 일어 음독 めん) — 한자/음 동일.

#### 한국어 학습 노트

**면 (myeon)** = 일어 "綿 (men)" 의미. **한자어 완전 동일** (드문 케이스). 발음: 면 (myeon) vs めん (men) — 거의 동일.

---

### 니트 (niteu)

**일어:** ニット (nitto) — 한국어 "니트" / 일어 "ニット" 의미.

**IPA:** /ni.tɯ/ / 일어 /ɲit.to/

**어원:** 영어 knit → 한일 동일 음역 + 일어 촉음.

#### 한국어 학습 노트

**니트 (niteu)** = 일어 "ニット (nitto)" 의미. 일어 촉음 (ッ) 추가. 발음 차이 연습 필요.

---

### 가죽 (gajuk)

**일어:** 革 (かわ, kawa) — 한국어 "가죽" / 일어 "革" 의미.

**IPA:** /ka.dʑuk/ / 일어 /ka.wa/

**한자 비교:** 革 (한자어 "혁", 일어 음독 かく) — 한자 동일.

#### 한국어 학습 노트

**가죽 (gajuk)** = 일어 "革 (kawa)" 의미. **한자어 어원 동일**. 발음: 가죽 (ga-juk, ㄱ+ㅏ+ㅈ+ㅜ+ㄱ) vs かわ (ka-wa) — 패턴 차이.

---

### 명주 (myeongju)

**일어:** 絹 (きぬ, kinu) — 한국어 "명주" / 일어 "絹" 의미.

**IPA:** /mjʌŋ.dʑu/ / 일어 /ki.nɯ/

**한자 비교:** 絹 (한자어 "견", 일어 음독 けん) — 한자 동일.

#### 한국어 학습 노트

**명주 (myeongju)** = 일어 "絹 (kinu)" 의미. **어원 다름**: 한국 한자어 단일 vs 일어 和語 "きぬ". 발음: 명주 (myeong-ju) vs きぬ (ki-nu) — 패턴 차이.

---

### 빨간 드레스 (ppalkan deureseu)

**일어:** 赤いドレス (あかいドレス, akai doresu) — 한국어 "�간 드레스" / 일어 "赤いドレス" 의미.

**IPA:** /ppal.ɡan dɯ.ɾe.sɯ/ / 일어 /a.ka.i do.ɾe.sɯ/

**구문 비교:** 한국어 형용사 + 명사 / 일어 형용사 (い형용사) + 명사.

#### 한국어 학습 노트

**빨간 드레스** = 일어 "赤いドレス (akai doresu)" 의미. **형용사 위치 + 활용**: 한국어 형용사 (높은/긴/빨간) + 명사 vs 일어 い형용사 (赤い/白い/長い) + 명사. 색상/크기 형용사 활용 패턴 동일.
