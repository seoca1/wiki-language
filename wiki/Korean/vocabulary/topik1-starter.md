# TOPIK 1 Starter Vocabulary — 한국어 입문 어휘

> **Source:** [[topik1-starter]]
> **Category:** topik1
> **Level:** TOPIK 1

TOPIK 1급 필수 어휘 32개 + 짧은 문장 3개. 국립국어원 표준국어대사전 및 TOPIK 1급 기출 어휘 목록 기반. 학습 순서: 인사 → 숫자 → 가족/사람 → 음식/사물 → 시간 → 학교 → 문장.

> **Note**: 4번 카테고리(음식/사물)의 '시간' 항목은 5번 카테고리(시간)와 의미가 중복됩니다. 원본 자료(raw/Korean/topik1-starter.md)의 배치를 그대로 유지했습니다.

## 발음 변동 노트 (한국어 입력 시 주의)

| 패턴 | 예시 | 입력 시 주의 |
| --- | --- | --- |
| ㄷ + ㅣ/ㅕ → ㅊ | 같이 → gachi | ㄷㄷ가 아니라 ㅊ |
| ㅂ + ㄴ → ㅁ | 감사합니다 → gamsahamnida | 합ㄴ → 함 |
| ㅎ + 모음 → 모음 | 좋아요 → joayo | ㅎ 생략 |
| ㅅ + ㅇ → ㄴ | 있어요 → isseoyo | ㅅㅇ → ㅆ + ㅇ |
| ㄱ + ㄴ/ㅁ/ㄹ → ㅇ | 한국 → hangug | 받침 연음 |
| ㄹ + 모음 → ㄹㄹ (격음) | 사람 → salam | ㄹㄹ 발음되지만 표기는 salam |

> **게임 코퍼스 영향**: 위 발음 변동은 `Game/typing_language/raw/kr_words.md` 의 자모 직접 입력 모드에서 정확히 처리되어야 합니다 (받침 연음, 비음화 등). `hangug` (한국), `gachi` (같이), `gamsahamnida` (감사합니다) 같은 표기는 국립국어원 로마자 표기법에 따른 것이며 한국어 자판 입력 시 다른 결과가 나올 수 있습니다.
