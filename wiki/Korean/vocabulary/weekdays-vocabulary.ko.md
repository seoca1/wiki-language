# Weekdays (요일) - Korean Perspective

## 요일 (Weekdays)

| 한국어 | 일어 | 일어 IPA |
|---|---|---|
| 월요일 (woryoil) | 月曜日 (げつようび, getsuyōbi) | /get.tsɯ.joː.bi/ |
| 화요일 (hwayoil) | 火曜日 (かようび, kayōbi) | /ka.joː.bi/ |
| 수요일 (suyoil) | 水曜日 (すいようび, suiyōbi) | /sɯ.i.joː.bi/ |
| 목요일 (mogyoil) | 木曜日 (もくようび, mokuyōbi) | /mo.kɯ.joː.bi/ |
| 금요일 (geumyoil) | 金曜日 (きんようび, kin'yōbi) | /kiɴ.joː.bi/ |
| 토요일 (toyoil) | 土曜日 (どようび, doyōbi) | /do.joː.bi/ |
| 일요일 (iryoil) | 日曜日 (にちようび, nichiyōbi) | /ni.tɕi.joː.bi/ |
| 평일 (pyeongil) | 平日 (へいじつ, heijitsu) | /heː.dʑi.tsɯ/ |
| 주말 (jumal) | 週末 (しゅうまつ, shūmatsu) | /ɕɯː.mat.tsɯ/ |
| 오늘 (oneul) | 今日 (きょう, kyō) | /kjoː/ |

## 한국어 학습 노트

**한국어 요일 + 일어 요일 비교**: 월/火/水/木/金/土/日 어원 동일 (한자어 차용). **Korean 月 = 일어 月 (한자음)** 어원 비교. **발음 변이**: 韓 화요일 vs 日 火曜日 (kayōbi) / 韓 목요일 vs 日 木曜日 (mokuyōbi) / 韓 금요일 vs 日 金曜日 (kin'yōbi).
