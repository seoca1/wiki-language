# Colors (색깔) - Korean Perspective

한국인이 한국어 색깔 어휘를 학습할 때 + 일본어 번역 비교. 각 색깔의 일어 번역 · 한자 · IPA · 한국 문화 맥락.

**참고:** 본 페이지는 `wiki/Korean/vocabulary/colors-vocabulary.md` 의 한국어 관점 + 일본어 번역 페이지.

---

## 기본 색깔 (Basic Colors)

### 빨강 (빨강)

**일어:** あか (赤) / 빨강 — 한국어 "빨강" / 일어 "赤(あか, 아카)" / 한자어 "적(赤)" 동일.

**IPA:** /p̚.p͈aɭ.ɡaŋ/ / 일어 /a.ka/

#### 예문

- 사과가 빨강이에요. (예문) — 사과는 빨강입니다. (캐주얼)
- リンゴは赤い (링고와 아카이) — 사과는 빨강입니다. (일어)

#### 한국어 학습 노트

**빨강 (ppalgang)** = 한국어 "빨강" / 일어 "赤 (あか)" / 한자어 "적(赤)" 동일 어원. 한국어 발음 "빨강" vs 일어 "아카" 차이. 한자 赤 (적, せき) = 한국어 "빨강" 의 어원.

---

### 파랑 (파랑)

**일어:** 青 (あお, 아오) — 한국어 "파랑" / 일어 "青(あお, 아오)" 의미.

**IPA:** /pʰa.ɾaŋ/ / 일어 /a.o/

#### 예문

- 하늘이 파랑이에요. — 하늘이 파랗습니다. (캐주얼)
- 空は青い (소라와 아오이) — 하늘은 파랗습니다. (일어)

#### 한국어 학습 노트

**파랑 (parang)** = 일어 "青 (あお)" 의미. **일어 青 (あ오)** = 한국어 "파랑" + "초록" 의 어원 (한국어 "파랑/파랗다" 와 다름). **日本の 青信号 (あおしんごう, 파란불) = 한국어 "파란불" (퍼런불 종이 通常 사용)** 어원 비교.

---

### 초록 (초록)

**일어:** 緑 (みどり, 미도리) — 한국어 "초록" / 일어 "緑(みどり, 미도리)" 동일.

**IPA:** /tɕʰo.ɾok̚/ / 일어 /mi.do.ɾi/

#### 예문

- 풀은 초록이에요. — 풀은 초록입니다. (캐주얼)
- 草は緑 (쿠사와 미도리) — 풀은 초록입니다. (일어)

#### 한국어 학습 노트

**초록 (chorok)** = 일어 "緑 (みどり)" 의미. **일어 緑 (みどり)** = 한국어 "초록" 의 어원. 한국어 발음 "초록" vs 일어 "미도리" 차이. 발음: みどり (mi-do-ri) — 촉음 っ + ㄹ 발음 연습.

---

### 노랑 (노랑)

**일어:** 黄色 (きいろ, 키이로) — 한국어 "노랑" / 일어 "黄色(きいろ, 키이로)" 동일.

**IPA:** /no.ɾaŋ/ / 일어 /kiː.i.ɾo/

#### 예문

- 해는 노랗습니다. — 해는 노랗습니다. (캐주얼)
- 太陽は黄色い (타이요와 키이로이) — 태양은 노랗습니다. (일어)

#### 한국어 학습 노트

**노랑 (norang)** = 일어 "黄色 (きいろ)" 의미. **黄色 (오우쇼쿠)** = 한국어 "황색" 어원. 발음: きいろ (ki-i-ro) — 장음 ㅇ + ㄹ 발음 연습.

---

### 흰색 (흰색)

**일어:** 白 (しろ, 시로) — 한국어 "흰색" / 일어 "白(しろ, 시로)" 동일.

**IPA:** /hɯin.ɕɛk̚/ / 일어 /ɕi.ɾo/

#### 한국어 학습 노트

**흰색 (huin-saek)** = 일어 "白 (しろ)" 의미. **白 (はく / しろ)** = 한국어 "백" 의 어원 비교.

---

### 검은색 (검은색)

**일어:** 黒 (くろ, 쿠로) — 한국어 "검은색" / 일어 "黒(くろ, 쿠로)" 동일.

**IPA:** /kɯm.ɯn.ɕɛk̚/ / 일어 /ku.ɾo/

#### 한국어 학습 노트

**검은색 (geom-eun-saek)** = 일어 "黒 (くろ)" 의미. **音읽 黒 (こく, 곡)** = 한국어 "흑" 의 어원.

---

### 빨간색 (빨간색)

**일어:** 赤色 (あかいろ, 아카이로) — 한국어 "빨간색" / 일어 "赤色(あかいろ, 아카이로)" 동일.

**IPA:** /p̚.p͈aɭ.ɡan.ɕɛk̚/ / 일어 /a.ka.i.ɾo/

#### 한국어 학습 노트

**빨간색 (ppal-gan-saek)** = 일어 "赤色 (あかいろ)" 의미. **색 (いろ)** = 한국어 "색" 의 어원.

---

### 파란색 (파란색)

**일어:** 青色 (あおいろ, 아오이로) — 한국어 "파란색" / 일어 "青色(あおいろ, 아오이로)" 동일.

**IPA:** /pʰa.ɾan.ɕɛk̚/ / 일어 /a.o.i.ɾo/

#### 한국어 학습 노트

**파란색 (paran-saek)** = 일어 "青色 (あおいろ)" 의미. **青 (あお)** = 한국어 "청" 의 어원.

---

### 초록색 (초록색)

**일어:** 緑色 (みどりいろ, 미도리이로) — 한국어 "초록색" / 일어 "緑色(みどりいろ, 미도리이로)" 동일.

**IPA:** /tɕʰo.ɾok̚.ɕɛk̚/ / 일어 /mi.do.ɾi.i.ɾo/

#### 한국어 학습 노트

**초록색 (chorok-saek)** = 일어 "緑色 (みどりいろ)" 의미. 발음: みどりいろ (mi-do-ri-i-ro) — 촉음 っ + ㄹ 발음 연습.

---

### 노란색 (노란색)

**일어:** 黄色 (きいろ, 키이로) — 한국어 "노란색" / 일어 "黄色(きいろ, 키이로)" 동일.

**IPA:** /no.ɾan.ɕɛk̚/ / 일어 /kiː.i.ɾo/

#### 한국어 학습 노트

**노란색 (noran-saek)** = 일어 "黄色 (きいろ)" 의미. 발음: 黄色 (ki-i-ro) — 장음 ㅇ + ㄹ 발음 연습.

## 형용사 (Adjective Forms)

### 빨갛다 (빨갛다)

**일어:** 赤い (あかい, 아카이) — 한국어 "빨갛다" / 일어 "赤い(あかい, 아카이)" 의미.

**IPA:** /p̚.p͈aɡ.ɾa.ta/ / 일어 /a.ka.i/

#### 한국어 학습 노트

**빨갛다 (ppalgata)** = 일어 "赤い (あかい)" 의미. **赤 + い** = 형용사화. 일어 촉음 っ + ㅇ + ㅣ 발음 비교.

---

### 파랗다 (파랗다)

**일어:** 青い (あおい, 아오이) — 한국어 "파랗다" / 일어 "青い(あおい, 아오이)" 의미.

**IPA:** /pʰa.ɾa.ta/ / 일어 /a.o.i/

#### 한국어 학습 노트

**파랗다 (parata)** = 일어 "青い (あおい)" 의미. **青 + い** = 형용사화.

---

### 초록 (different)

**일어:** 緑の (みどりの, 미도리노) — 일어 한자어 형용사 변형.

**IPA:** /tɕʰo.ɾok̚/ / 일어 /mi.do.ɾi.no/

#### 한국어 학습 노트

絵 (みどり) + 속격 조사 (の) = 일어 緑の (green 앞 수식). **한국어 "초록의" (관형사)** 와 일어 緑の (속격 조사) 비교.
