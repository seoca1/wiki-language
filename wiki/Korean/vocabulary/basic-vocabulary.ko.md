#### 한국어 학습 노트

**한국어 인사 (annyeong)** 어원 = 패(安) + 녕(寧) = 평안. **일어 인사 (konnichiwa)** 어원 = 今日は (こんにちは) = 오늘은. **한국어 안녕 (annyeong)** vs **일어 今日 (konnichiwa)** 의 어원 차이 비교.

## 한국어 학습자 핵심 노트 (Basic Vocabulary 종합)

### 1. 한국어 / 일어 어휘 차이

| 한국어 | 일어 | 어원 차이 |
|---|---|---|
| 하나 | ひとつ (hitotsu) | 한자어 차용 X |
| 일 | いち (ichi) | 한자어 차용 / 日 발음 다름 |
| 아니다 | ちがう (chigau) | 어원 비교 |
| 좋다 | いい (ii) / よい (yoi) | 어원 비교 |

### 2. 한국어 화자 일본어 발음 함정

- **장음 (お/う long vowel)**: おばさん (o-ba-san) = [oːba-san]
- **촉음 (っ, geminate)**: 学校 (がっこう, gakkō) = [gakkoː]
- **요음 (ょう, よう-on)**: 旅行 (りょこう, ryokō) = [ɾjo.koː]
- **撥音 (ん)**: 専門 (せんもん, senmon) = [sen.mon]

### 3. 한자 일어 음독 (오음) vs 훈독 (くんよみ)

**음독 (おんよみ, on-yomi)**: 한자어 (중국어) 차용 — 한국어 학습자 친숙.
- 예: 学校 (がっこう, 학교) / 中国 (ちゅうごく, 중국) / 電話 (でんわ, 전화)

**훈독 (くんよみ, kun-yomi)**: 일어 고유어 — 한국어 학습자 어려움.
- 例: 水 (みず, 물) / 山 (やま, 산) / 人 (ひと, 사람)

### 4. 한국어 학습 전략

- **한자어 우선 학습**: 한국어 한자어 = 일어 한자어 어원 동일 (80%) — 가장 효율적 학습
- **일어 음독 (은) 위주**: 한국어 한자어 차용 (음) + 일본 음독 (음) 일치 패턴
- **일어 발음 주의**: 촉음 / 장음 / 요음 / 撥音
