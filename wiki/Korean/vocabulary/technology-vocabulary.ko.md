# Technology (기술) - Korean Perspective

한국인이 한국어 기술 어휘를 학습할 때 + 일본어 번역 비교. 10 entries (IT/디지털) 와 한자어·외래어 비교.

## 기술 (Technology)

| 한국어 | 일어 | 일어 IPA |
|---|---|---|
| 컴퓨터 (keompyuteo) | コンピュータ (konpyūta) | /kom.pjuː.ta/ |
| 전화 (jeonhwa) | 電話 (でんわ, denwa) | /den.wa/ |
| 인터넷 (inteonet) | インターネット (intānetto) | /in.taː.net.to/ |
| 이메일 (imeil) | メール (mēru) | /meː.ɾɯ/ |
| 웹사이트 (wep-saiteu) | ウェブサイト (webu-saito) | /we.bɯ.sa.i.to/ |
| 앱 (aep) | アプリ (apuri) | /a.pɯ.ɾi/ |
| 비밀번호 (bimilbeonho) | パスワード (pasuwādo) | /pa.sɯ.waː.do/ |
| 마우스 (mauseu) | マウス (mausu) | /ma.ɯ.sɯ/ |
| 키보드 (kibodeu) | キーボード (kībōdo) | /kiː.boː.do/ |
| 화면 (hwamyeon) | 画面 (がめん, gamen) | /ga.meɴ/ |

## 한국어 학습 노트

**한국어 IT 어휘 = 일어 IT 어휘 동일 외래어**: 컴퓨터/컴퓨터, 인터넷/インターネット, 앱/アプリ. **Korean 발음 (컴퓨터)** vs **Japanese 발음 (コンピュータ, konpyūta)** 차이: 한국어 ㄴ+ㅍ / 일어 ㄴ+ㅍ 비교. **韓 조사는 조사 (격조사)** 와 **日 助詞 (조격조사)** 어원 비교.
