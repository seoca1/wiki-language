# Greetings (인사) - Korean Perspective

한국인이 한국어 인사 어휘를 학습할 때 + 일본어 번역 비교. 각 어휘의 일어 번역 · 한자 · IPA · 한국 문화 맥락.

**참고:** 본 페이지는 `wiki/Korean/vocabulary/greetings-vocabulary.md` 의 한국어 관점 + 일본어 번역 페이지.

---

## 기본 인사 (Basic Greetings)

### 안녕하세요 (annyeonghaseyo)

**일어:** こんにちは (konnichiwa) — 한국어 "안녕하세요" / 일어 "こんにちは" 의미.

**IPA:** /an.njʌŋ.ha.ɕɛ.jo/ / 일어 /kon.ni.tɕi.wa/

#### 예문

- 안녕하세요? — 안녕하세요? (인사)
- こんにちは (곤니치와) — 안녕하세요. (일어)

#### 한국어 학습 노트

**안녕하세요 (annyeonghaseyo)** = 일어 "こんにちは (konnichiwa)" 의미. **한국어 助 (안, 安)** = 일어 (安) 동일. **韓国어 패녕 (安宁)** 의 어원 동일.

---

### 안녕 (annyeong)

**일어:** やあ (yaa) / おす (osu) — 한국어 "안녕" / 일어 캐주얼 인사 의미.

**IPA:** /an.njʌŋ/ / 일어 /jaː/ / /o.sɯ/

#### 한국어 학습 노트

**안녕 (annyeong)** = 일어 "こんにちは (konnichiwa)" 캐주얼 변형. **한국어 助 (안, 安)** = 일어 (安) 동일.

---

### 처음 뵙겠습니다 (cheoeom boepseumnida)

**일어:** 初めまして (hajimemashite) — 한국어 "처음 뵙겠습니다" / 일어 "初めまして" 의미.

**IPA:** /tɕʰʌ.ɯm bwe̞p.ɕɯmnida/ / 일어 /ha.dʑi.me.ma.ɕi.te/

#### 한국어 학습 노트

**처음 뵙겠습니다 (cheoeom-boep-seumnida)** = 일어 "初めまして (hajimemashite)" 의미. **韓 뵙다 (보다의 합쇼체)** = 일어 まして (相逢時の 경어) 어원 비교.

---

### 만나서 반가워요 (mannaseo bangawoyo)

**일어:** お会いできて嬉しいです (oai dekite ureshii desu) — 한국어 "만나서 반가워요" / 일어 "お会いできて嬉しいです" 의미.

**IPA:** /man.na.sʌ pan.ka.wʌ.jo/ / 일어 /o.aː.i.de.ki.te ɯ.ɾe.ɕiː.de.sɯ/

#### 한국어 학습 노트

**만나서 + 반갑다 (반갑다)** = 일어 "お会いできて + 嬉しい" 의미. **韓 반갑다 (喜ばしい)** = 일어 嬉しい (uretai) 어원 비교.

---

### 안녕히 가세요 (annyeonghi gaseyo)

**일어:** さようなら (sayounara) / いってらっしゃい (itterasshai) — 한국어 "안녕히 가세요" / 일어 "さようなら" 의미.

**IPA:** /an.njʌŋ.ɦi ka.ɕɛ.jo/ / 일어 /sa.joː.na.ɾa/ / /it.te.ɾas.ɕa.i/

#### 한국어 학습 노트

**안녕히 가세요 (annyeonghi-gaseyo)** = 일어 "いってらっしゃい (itterasshai)" 의미. **韓 보내는 사람 (送人) 의 인사** = 일어 **위 (送) +5 + + 이떠 + 라** 의 어원 비교.
