# Body & Family (신체·가족) - Korean Perspective

한국인이 한국어 신체·가족 어휘를 학습할 때 + 일본어 번역 비교. 신체 부위 + 가족 관계 어휘 통합.

**참고:** 본 페이지는 `wiki/Korean/vocabulary/body-family.md` 의 한국어 관점 + 일본어 번역 페이지.

#### 한국어 학습 노트

**韓 머리 (meori)** vs **日 頭 (あたま, atama)** 어원 비교. **韓 눈 (nun)** vs **日 目 (め, me)** 어원 비교. **韓 귀 (gwi)** vs **日 耳 (みみ, mimi)** 어원 비교. 韓어 일본어 발음 차이 큼.

#### 한국어 학습 노트

**韓 손 (手)** = 일어 手 (て, te) 어원 비교. **韓 발 (足)** vs **韓 다리 (脚)** = 일어 足 (あし, ashi) / 脚 (あし, ashi) 어원 비교. **韓 팔 (腕)** = 일어 腕 (うで, ude) 어원 비교.

### 형제 (Siblings)

| 한국어 | 일어 | 일어 IPA |
|---|---|---|
| 형 (hyeong) | 兄 (あに, ani) | /a.ni/ |
| 오빠 (oppa) | お兄 (おにい, oniː) | /o.niː/ |
| 누나 (nuna) | 姉 (あね, ane) | /a.ne/ |
| 언니 (eonni) | お姉 (おねえ, onē) | /o.neː/ |
| 남동생 (namdongsaeng) | 弟 (おとうと, otōto) | /o.toː.to/ |
| 여동생 (yeodongsaeng) | 妹 (いもうと, imōto) | /i.moː.to/ |
| 형제 (hyeongje) | 兄弟 (きょうだい, kyōdai) | /kjoː.da.i/ |
| 자매 (jamae) | 姉妹 (しまい, shimai) | /ɕi.ma.i/ |

#### 한국어 학습 노트

**韓 형 (兄)** vs **韓 오빠 (お兄)** 의 어원 차이: 성별/나이 비교. **日 兄弟 (きょうだい)** = 양쪽 남자 (총칭) / 양쪽 = 兄妹 (남매). **韓 형제 (兄제)** = 양쪽 (성별 무관) 어원 비교.
