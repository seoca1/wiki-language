# Nature (자연) - Korean Perspective

한국인이 한국어 자연 어휘를 학습할 때 + 일본어 번역 비교. 20+ 어휘 (천체/기상/지형/물/자연현상) 와 일본어 한자어 비교.

**참고:** 본 페이지는 `wiki/Korean/vocabulary/nature-vocabulary.md` 의 한국어 관점 + 일본어 번역 페이지 (concise aggregator).

## 천체 (Celestial Bodies)

### 태양 (taeyang)

**일어:** 太陽 (たいよう, taiyō) — 한국어 "태양" / 일어 "太陽" 의미.

**IPA:** /tʰɛ.jaŋ/ / 일어 /ta.i.joː/

**한자 비교:** 太陽 (한자어 "태양", 일어 음독 たいよう) — 한자/음 모두 동일 (드문 케이스).

#### 한국어 학습 노트

**태양 (taeyang)** = 일어 "太陽 (taiyō)" 의미. **한자/음 완전 일치** (한국 한자음 "태양" / 일어 한자음 "たいよう"). 발음: 태양 (tae-yang) vs 太陽 (ta-i-yō) — 일어 장음 + 3음절.

---

### 달 (dal)

**일어:** 月 (つき, tsuki) — 한국어 "달" / 일어 "月" 의미.

**IPA:** /tal/ / 일어 /tsɯ.ki/

**어원 비교:** 한국어 순우리말 "달" vs 일어 和語 "つき" vs 한자어 "月" (한자어 공통).

#### 한국어 학습 노트

**달 (dal)** = 일어 "月 (tsuki)" 의미. **어원 다름**: 한국 순우리말 vs 일어 和語 (한자어 月 동일). 발음: 달 (dal, ㄷ+ㅏ+ㄹ) vs つき (tsu-ki, 촉음 시작) — 한국어 화자는 촉음 연습 필요.

---

#### 한국어 학습 노트

## 기상 (Weather)

### 비 (bi)

**일어:** 雨 (あめ, ame) — 한국어 "비" / 일어 "雨" 의미.

**IPA:** /pi/ / 일어 /a.me/

**어원 비교:** 한국어 순우리말 "비" vs 일어 和語 "あめ" vs 한자어 "雨" (한자어 공통).

#### 한국어 학습 노트

**비 (bi)** = 일어 "雨 (ame)" 의미. **어원 다름**: 한국 순우리말 vs 일어 和語. 발음: 비 (bi, ㅂ+ㅣ) vs あめ (a-me, 2음절) — 매우 짧음.

---

### 눈 (nun) — weather context

**일어:** 雪 (ゆき, yuki) — 한국어 "눈" / 일어 "雪" 의미 (참고: 한국어 "눈" = 신체 부위와 동음).

**IPA:** /nun/ / 일어 /jɯ.ki/

**어원 비교:** 한국어 순우리말 "눈" vs 일어 和語 "ゆき" vs 한자어 "雪" (한자어 공통).

#### 한국어 학습 노트

**눈 (nun)** = 일어 "雪 (yuki)" 의미. **한국어 동음어 함정**: "눈" = 신체 부위(eye) + 날씨(snow). 일어 "ゆき" 는 단일 의미. 발음: 눈 (nun) vs ゆき (yu-ki) — 매우 짧음.

---

**어원 비교:** 한국어 순우리말 "바람" vs 일어 和語 "かぜ" vs 한자어 "風" (한자어 공통).

#### 한국어 학습 노트

**바람 (baram)** = 일어 "風 (kaze)" 의미. **어원 다름**: 한국 순우리말 vs 일어 和語. 발음: 바람 (ba-ram) vs かぜ (ka-ze) — 패턴 유사.

---

### 폭풍 (pokpung)

**일어:** 嵐 (あらし, arashi) / 暴風 (ぼうふう, bōfū) — 한국어 "폭풍" / 일어 "嵐" 의미.

**IPA:** /pʰok.pʰuŋ/ / 일어 /a.ɾa.ɕi/

**한자 비교:** 風 (한자어 "풍", 일어 음독 ふう) / 暴 (한자어 "폭", 일어 음독 ぼう) — 한자 동일 어원.

#### 한국어 학습 노트

**폭풍 (pokpung)** = 일어 "嵐 (arashi)" 의미. **어원 다름**: 한국 한자어 단일 vs 일어 和語 (한자어 동일). 발음 패턴 매우 다름.

---

### 천둥 (cheondung)

**일어:** 雷 (かみなり, kaminari) — 한국어 "천둥" / 일어 "雷" 의미.

**IPA:** /tɕʰʌn.duŋ/ / 일어 /ka.mi.na.ɾi/

**어원 비교:** 한국어 순우리말 "천둥" (의성어) vs 일어 和語 "かみなり" (신앙어 "神 + 成り").

#### 한국어 학습 노트

**천둥 (cheondung)** = 일어 "雷 (kaminari)" 의미. **어원 매우 다름**: 한국 의성어 vs 일어 신앙어 (かみ = 신, なり = 됨). 발음: 천둥 (cheon-dung) vs かみなり (ka-mi-na-ri, 4음절) — 패턴 매우 다름.

### 호수 (hosu)

**일어:** 湖 (みずうみ, mizuumi) — 한국어 "호수" / 일어 "湖" 의미.

### 나무/숲 (namu/sup)

**일어:** 木 (き, ki) / 森 (もり, mori) — 한국어 "나무" / 일어 "木" 의미 / "숲" = 일어 "森".

**IPA:** /na.mu/ / 일어 /ki/ / 일어 /mo.ɾi/

**어원 비교:** 한국어 순우리말 "나무/숲" vs 일어 和語 "き/もり" vs 한자어 "木/森" (한자어 공통).

#### 한국어 학습 노트

**나무/숲** = 일어 "木 (ki)" / "森 (mori)" 의미. **어원 다름**: 한국 순우리말 vs 일어 和語. 발음 패턴 매우 다름. 한자어는 韓日 동형 동음.

---

**IPA:** /tɛ.jaŋ/ / 일어 /ta.i.joː/

**한자 비교:** 大洋 (한자어 "대양", 일어 음독 たいよう) — 한자/음 동일.

#### 한국어 학습 노트

**대양 (daeyang)** = 일어 "大洋 (taiyō)" 의미. **한자어 완전 동일**. 발음: 대양 (dae-yang) vs たいよう (ta-i-yō, 장음) — 일어 장음 + 3음절.
