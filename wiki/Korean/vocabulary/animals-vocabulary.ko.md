# Animals (동물) - Korean Perspective

한국인이 한국어 동물 어휘를 학습할 때 + 일본어 번역 비교. 18+ 어휘 (반려동물/가축/야생동물/조류/곤충) 와 일본어 한자어 비교.

**참고:** 본 페이지는 `wiki/Korean/vocabulary/animals-vocabulary.md` 의 한국어 관점 + 일본어 번역 페이지 (concise aggregator).

## 반려동물 / 가축

### 개 (gae)

**일어:** 犬 (いぬ, inu) — 한국어 "개" / 일어 "犬" 의미.

**IPA:** /ɡɛ/ / 일어 /i.nɯ/

**한자 비교:** 犬 (한자어 "구" 음독 ぎゅう/くん, 한국 한자어 "구") — 한자 동일, 한국/일본 한자음 모두 ㄱ 계열.

#### 한국어 학습 노트

**개 (gae)** = 일어 "犬 (inu)" 의미. **한자어 어원 비교**: 한국 "구(犬)" / 일어 "いぬ" — 한국 한자음은 음독(音讀) "구(gyu)", 일어는 훈독(訓讀) "いぬ". 발음: 개 (gae, ㅋ+ㅐ) vs いぬ (i-nu, 이+누) — 한국어 화자는 い 발음 연습 필요.

### 고양이 (goyangi)

**일어:** 猫 (ねこ, neko) — 한국어 "고양이" / 일어 "猫" 의미.

**IPA:** /ko.jaŋ.i/ / 일어 /ne.ko/

**한자 비교:** 猫 (한자어 "묘", 일어 음독 びょう) — 한자 동일 어원.

#### 한국어 학습 노트

**고양이 (goyangi)** = 일어 "猫 (neko)" 의미. 발음 차이: 고양이 (ko-yang-i, 3음절) vs ねこ (ne-ko, 2음절) — 일어 촉음/장음 없음. 일본어 "ニャン (ニャン, nya-n)" = 한국어 "야옹" (동물 울음소리) 비교.

---

### 말 (mal)

**일어:** 馬 (うま, uma) — 한국어 "말" / 일어 "馬" 의미.

**IPA:** /mal/ / 일어 /ɯ.ma/

**한자 비교:** 馬 (한자어 "마", 일어 음독 ば/め) — 한자 동일.

#### 한국어 학습 노트

**말 (mal)** = 일어 "馬 (uma)" 의미. **순우리말 말** vs **한자어 마(馬)** 이중 표현 (한국어 특징). 일어는 和語 "うま" / 한자음 "ば (ba)" / "め (me)" 3종. 발음: 말 (mal) vs うま (u-ma) — ㅁ 발음 위치 유사.

---

### 소 (so)

**일어:** 牛 (うし, ushi) — 한국어 "소" / 일어 "牛" 의미.

**IPA:** /so/ / 일어 /ɯ.ɕi/

**한자 비교:** 牛 (한자어 "우", 일어 음독 ぎゅう) — 한자 동일.

#### 한국어 학습 노트

**소 (so)** = 일어 "牛 (ushi)" 의미. 한국어 순우리말 "소" vs 한자어 "우(牛)" 이중 표현. 일어 和語 "うし" / 한자음 "ぎゅう (gyu)" — 음역 패턴 동일 (한국/일본 모두 한자음 사용 가능).

---

### 돼지 (doeji)

**일어:** 豚 (ぶた, buta) — 한국어 "돼지" / 일어 "豚" 의미.

**IPA:** /dwɛ.dʑi/ / 일어 /bɯ.ta/

**한자 비교:** 豚 (한자어 "돈", 일어 음독 とん) — 한자 동일.

#### 한국어 학습 노트

**돼지 (doeji)** = 일어 "豚 (buta)" 의미. 한국어 "돼지" 는 순우리말 (ㄷ + ㅚ + ㅈ). 일어 "ぶた" 와 豚 한자음 "とん (ton)" 모두 가능. 발음: 돼지 (doe-ji, 2음절) vs ぶた (bu-ta, 2음절) — 패턴 유사.

---

### 닭 (dalg)

**일어:** 鶏 (にわとり, niwatori) — 한국어 "닭" / 일어 "鶏" 의미.

**IPA:** /talk/ / 일어 /ni.wa.to.ɾi/

**한자 비교:** 鶏 (한자어 "계", 일어 음독 けい) — 한자 동일.

#### 한국어 학습 노트

**닭 (dalg)** = 일어 "鶏 (にわとり, niwatori)" 의미. 한국어 "닭" / "암탉" / "병아리" 어휘 풍부. 일어 にわとり (4음절) vs 한국어 닭 (1음절) — 어휘 길이 차이. **닭 vs 鶏** 발음: � (talk, ㄷ+ㅏ+ㄺ) vs けい (kei, ケ+イ) — 한국어 ㅋ 발음 함정.

## 야생동물

### 사자 (saja)

**일어:** 獅子 (しし, shishi) — 한국어 "사자" / 일어 "獅子" 의미.

**IPA:** /sa.dʑa/ / 일어 /ɕi.ɕi/

**한자 비교:** 獅子 (한자어 "사자", 일어 음독 しし) — 한자/음 모두 동일 (드문 케이스).

#### 한국어 학습 노트

**사자 (saja)** = 일어 "�子 (shishi)" 의미. **한자어 + 한자음 완전 일치** (드문 케이스, 韓日 동形 동음). 발음: 사자 (sa-ja) vs しし (shi-shi) — ㅅ/ㅆ 발음 차이만 존재.

**한자 비교:** 虎 (한자어 "호", 일어 음독 こ) — 한자 동일.

#### 한국어 학습 노트
