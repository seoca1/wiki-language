# Expressions: Complaints (한국어)

> **Theme:** Complaints & Customer Service
> **Level:** A2-B1
> **Standard:** 표준어 (Pyojuneo, Standard Korean)

Korean complaint expressions. 일상·서비스·고객센터에서 쓰는 문제 제기·교환·환불·불만 패턴 모음. 정중도 단계 (가벼운 불만 ↔ 공식 항의) 변별에 초점.

---

## ~가 안 돼서 불편합니다 (~ga an dweseo bulpyeonhamnida, it doesn't ~ and it's inconvenient)

**직역:** "~ doesn't work and it's inconvenient."

**의미:** 가장 일반적인 정중한 불만 표현. 서비스·제품·환경 문제 시 1차 항의.

**사용 맥락:** 합쇼체 (formal). 고객센터·전화 응대·공식 항의 — 격식 유지.

**문형:** Subject + 가/이 + 안 되다 + 아/어서 + 불편합니다.
- 환불이 안 돼서 불편합니다. — "The refund isn't happening and it's inconvenient."
- 앱이 안 돼서 불편합니다. — "The app doesn't work and it's inconvenient."

### 예문

- **이 제품이 작동이 안 돼서 불편합니다 (I jepum-i jakdongi an dweseo bulpyeonhamnida)** — "This product doesn't work and it's inconvenient." (고객센터)
- **인터넷이 안 돼서 불편합니다 (Inteones-i an dweseo bulpyeonhamnida)** — "The internet isn't working and it's inconvenient." (숙소·카페)
- **주차가 안 돼서 불편합니다 (Juchagi an dweseo bulpyeonhamnida)** — "Parking isn't available and it's inconvenient." (상가·건물)

### 문화적 배경

- 불편하다 (不便, bulpyeonghada) = "inconvenient". 한자어 "不便" + 하다.
- 한국 항의의 표준 표현 — "불편합니다" = "inconvenient"는 직접 "화나요"보다 정중.
- "불편을 드려 죄송합니다" = "Sorry for the inconvenience"의 한국형 표현으로 서비스 측 응답.

## 교환/환불 부탁드립니다 (gyohwan/hwanbul butak deurimnida, please exchange/refund)

**직역:** "Please exchange / refund."

**의미:** 구매 후 문제 발생 시 교환·환불을 정중히 요청하는 표준 표현.

**사용 맥락:** 합쇼체 (formal). 매장·고객센터·온라인 쇼핑 CS — 격식 최고 단계.

**문형:** 교환 (exchange) / 환불 (refund) + 부탁드립니다. / + 해 주시겠습니까?
- 교환 부탁드립니다. (Gyohwan butak deurimnida.) — "Please exchange it."
- 환불 부탁드립니다. (Hwanbul butak deurimnida.) — "Please refund it."

### 예문

- **이거 교환 부탁드립니다 (Igeo gyohwan butak deurimnida)** — "Please exchange this." (의류 매장)
- **환불 가능한지 확인 부탁드립니다 (Hwanbul ganeunghanji hwag-in butak deurimnida)** — "Please check if a refund is possible." (온라인 쇼핑)
- **교환 사유는 사이즈가 안 맞아서요 (Gyohwan sayu-neun saijeu-ga an majaseoyo)** — "The reason for exchange is the size doesn't fit." (매장)

### 문화적 배경

- 교환 (交換, 한자어) / 환불 (還拂, 한자어) — 모두 한자어, 비즈니스·공식 표현에 적합.
- 한국 전자상거래 (쿠팡·네이버 스마트스토어·G마켓) — 교환/환불은 7일 이내 일반적.
- 매장·고객센터에서 "교환 부탁드립니다" = "I'd like to exchange" — 정중한 표현.

## ~에 문제가 있습니다 (~e munjega isseumnida, there is a problem with ~)

**직역:** "There is a problem with ~."

**의미:** 정중하고 사실 전달형 항의. "~이 잘못됐어요"보다 격식 높음.

**사용 맥락:** 합쇼체 (formal). 공식 항의·전화·이메일·계약 분쟁.

**문형:** Noun + 에 (locative) + 문제 + 가 있습니다. / + 가 있어요.
- 제품에 문제가 있습니다. — "There is a problem with the product."
- 주문에 문제가 있습니다. — "There is a problem with the order."

### 예문

- **주문한 상품에 문제가 있습니다 (Jumuhan sangpum-e munjega isseumnida)** — "There is a problem with the ordered product." (온라인 쇼핑)
- **청구서에 문제가 있습니다 (Cheong-guseo-e munjega isseumnida)** — "There is a problem with the bill." (고객센터)
- **이 부분에 문제가 있습니다 (I bubun-e munjega isseumnida)** — "There is a problem with this part." (비즈니스)

### 문화적 배경

- 문제 (問題, munjega) = "problem, question". 한자어.
- "문제가 있습니다" = 정중한 "There is an issue". 직접 "잘못됐어요"보다 격식.
- 한국 비즈니스·공식 항의의 표준 도입부. "~에 문제가 있습니다" → 이어서 해결책·요청.

## 불만 있습니다 (bulman isseumnida, I have a complaint)

**직역:** "I have a complaint."

**의미:** 공식 항의 선언. 서비스·제품·관공서 응대에서 직접적 항의.

**사용 맥락:** 합쇼체 (formal). 고객센터·공식 항의서·소비자 분쟁.

**문형:** 불만 (명사) + 이/가 있습니다. / 있어요.
- 환불에 대해 불만 있습니다. — "I have a complaint about the refund."

### 예문

- **서비스에 대해 불만 있습니다 (Seobiseu-e daehae bulman isseumnida)** — "I have a complaint about the service." (식당·카페)
- **이 부분은 불만이 있습니다 (I bubun-eun bulmani isseumnida)** — "I have a complaint about this part." (계약·협상)
- **제품 품질에 불만 있습니다 (Jepum pumjil-e bulman isseumnida)** — "I have a complaint about the product quality." (고객센터)

### 문화적 배경

- 불만 (不滿, 한자어) = "dissatisfaction, complaint". 한자어, 격식적 표현.
- "불만 있습니다" = "I have a complaint" — 직접적 항의 선언.
- 한국 소비자 보호원·공식 항의 시 표준 표현.

## 개선 요청드립니다 (gaeseon yocheong deurimnida, I request an improvement)

**직역:** "I request an improvement."

**의미:** 격식 있는 개선 요청. 단순 불만을 넘어 구체적 조치 요구.

**사용 맥락:** 합쇼체 (formal). 고객센터·정부 민원·상사·경영진 — 정중 + 구체적 요청.

**문형:** 개선 (명사) + 요청 (명사) + 드립니다.
- 서비스 개선 요청드립니다. — "I request a service improvement."
- 매장 청결 개선 요청드립니다. — "I request store cleanliness improvement."

### 예문

- **매장 위생 개선 요청드립니다 (Maejang wisaeng gaeseon yocheong deurimnida)** — "I request improvement in store hygiene." (식당·카페)
- **환불 처리 속도 개선 요청드립니다 (Hwanbul cheori sokdo gaeseon yocheong deurimnida)** — "I request improvement in refund processing speed." (온라인 쇼핑)
- **앱 사용성 개선 요청드립니다 (Aep sayongseong gaeseon yocheong deurimnida)** — "I request improvement in app usability." (앱 CS)

### 문화적 배경

- 개선 (改善, gaeseon) + 요청 (要請, yocheong) = 한자어 복합. 모두 한자어 — 격식·공식 표현.
- "개선 요청드립니다" = "I'd like to request an improvement" — 한국 비즈니스·민원의 정중한 표현.
- 단순 불만보다 한 단계 더 적극적 — 행동 요청이 포함.

## 이거 잘못된 것 같은데요 (igeo jalmotdoen geot gateundeyo, this seems wrong)

**직역:** "This seems wrong, I think."

**의미:** 부드럽고 간접적 문제 제기. 일상·캐주얼 항의의 기본.

**사용 맥락:** 해요체 (polite informal). 일상·매장·친구·동료 — 직접 항의보다 부드럽게.

**문형:** 이거/저거 + (잘못된 것 같은데요) / (맞나요?).
- 이거 잘못된 것 같은데요. — "This seems wrong."
- 이거 맞나요? — "Is this right?"

### 예문

- **계산이 잘못된 것 같은데요 (Gyesan-i jalmotdoen geot gateundeyo)** — "I think the bill is wrong." (식당·카페)
- **주문한 거랑 다른 것 같은데요 (Jumuhan georang dareun geot gateundeyo)** — "I think this is different from what I ordered." (식당)
- **주소 잘못된 것 같은데요 (Juso jalmotdoen geot gateundeyo)** — "I think the address is wrong." (배달)

### 문화적 배경

- ~것 같다 (auxiliary) = "seems, looks like". 직접 단언을 회피 — 한국 커뮤니케이션의 정중 전략.
- "잘못된 것 같은데요" = "It seems wrong" — "잘못됐어요"보다 정중. "~것 같다"가 부드러움의 핵심.
- 한국 일상·서비스 현장에서 가장 흔한 캐주얼 정중 항의 패턴.

## 죄송하지만 다시 한번 확인해 주시겠어요? (joesonghajiman dasi hanbeon hwagin hae jusigesseoyo, sorry but could you check again?)

**직역:** "Sorry, but could you please check again?"

**의미:** 사과 + 확인 요청. 문제 제기 + 정중한 재확인 요청 결합.

**사용 맥락:** 해요체 (polite informal) + 정중 의뢰형. 매장·서비스·전화 응대 — 정중도 높음.

**문형:** 죄송하지만 / 죄송합니다만 + 다시 + 한 번 + Verb + ~해 주시겠어요?
- 죄송하지만 다시 확인해 주시겠어요? — "Sorry, but could you check again?"

### 예문

- **죄송하지만 주문 다시 한번 확인해 주시겠어요? (Joesonghajiman jumun dasi hanbeon hwag-in hae jusigesseoyo?)** — "Sorry, but could you check the order again?" (식당)
- **죄송하지만 계산 다시 한번 확인해 주시겠어요? (Joesonghajiman gyesan dasi hanbeon hwag-in hae jusigesseoyo?)** — "Sorry, but could you check the bill again?" (매장)
- **죄송하지만 배달 시간 확인해 주시겠어요? (Joesonghajiman baedal sigan hwag-in hae jusigesseoyo?)** — "Sorry, but could you check the delivery time?" (배달 앱 CS)

### 문화적 배경

- 죄송하지만 (apology connector) + 다시 한번 (once again) + 확인하다 (to confirm) + ~해 주시겠어요? (polite request).
- 한국 항의의 표준 결합 패턴 — 사과 → 문제 제기 → 해결 요청. 세 단계 구조.
- 캐주얼 정중 — 상점·식당·배달 CS에서 가장 흔한 패턴.

## 이거 안 되는데요 (igeo an dwenneundeyo, this isn't working / this is no good)

**직역:** "This isn't working / this is unacceptable."

**의미:** 캐주얼·직접적 항의. 정중도 한 단계 낮은 일상 표현.

**사용 맥락:** 해요체 (polite informal) + 직접. 매장·서비스·동료 — 부드럽지만 직접적.

**문형:** 이거/저거 + 안 되다/안 되는데요. / 안 되겠는데요.
- 이거 안 되는데요. — "This won't do."
- 이거 안 되겠는데요. — "This isn't going to work."

### 예문

- **이거 안 되는데요, 다른 거 있어요? (Igeo an dwenneundeyo, dareun geo isseoyo?)** — "This won't do, do you have another one?" (의류·신발)
- **환불 안 되는데요? (Hwanbul an dwenneundeyo?)** — "Refund isn't possible?" (고객센터)
- **이 시간 안 되는데요 (I sigan an dwenneundeyo)** — "This time doesn't work." (약속·회의)

### 문화적 배경

- 안 되다 (verb) = "won't do, can't, isn't working". 구어·일상 표현.
- "이거 안 되는데요" = 캐주얼 정중 항의 — 매장·동료에게 사용. 상사·공식 자리에는 부적합.
- 한국 캐주얼 항의의 기본 패턴. 직접 "잘못됐어요"보다 부드럽지만, 격식 자리에서는 "문제 있어요"가 정중.

## 조금 더 신경 써 주세요 (jogeum deo singyeong sseo juseyo, please pay a little more attention)

**직역:** "Please pay a little more attention."

**의미:** 개선 요청의 부드러운 표현. 직접 항의보다 건설적.

**사용 맥락:** 해요체 (polite informal). 매장·서비스·동료·상사 — 부드럽지만 정중.

**문형:** 조금 더 + Verb + ~아/어 주세요. / ~아/어 주시겠어요?
- 조금 더 신경 써 주세요. — "Please pay more attention."
- 조금 더 신경 써 주시겠어요? — "Could you pay more attention?"

### 예문

- **서비스가 좀 부족한 것 같아요, 조금 더 신경 써 주세요 (Seobiseu-ga jom bujokhan geot gatayo, jogeum deo singyeong sseo juseyo)** — "The service seems a bit lacking, please pay more attention." (식당·카페)
- **음식 나오는데 조금 더 빨리 해 주세요 (Eumsik naoneunde jogeum deo ppalli hae juseyo)** — "For the food coming out, please make it a little faster." (식당)
- **청결에 조금 더 신경 써 주시겠어요? (Cheong-gyeol-e jogeum deo singyeong sseo jusigesseoyo?)** — "Could you pay a little more attention to cleanliness?" (매장·숙소)

### 문화적 배경

- 신경 (神經, 한자어) = "nerves, attention". 쓰다 = "use, pay (attention)".
- 한국 항의의 정중 패턴 — "~가 부족해요" (lacking) + "조금 더 신경 써 주세요" (please pay more attention) = 부드러운 개선 요청.
- 직접 "잘못됐어요"보다 정중. 매장·식당·서비스에서 가장 흔한 부드러운 항의.
