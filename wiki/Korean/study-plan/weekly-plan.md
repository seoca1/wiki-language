# 한국어 주간 학습 계획 (Korean Weekly Study Plan)

**Level:** TOPIK 4-5 (고급)
**Weekly commitment:** 3-4 hours (weekday 30min × 5 + weekend 60min × 2)
**Started:** 2026-08-19
**Cycle:** 4-week rotation (one grammar axis + one vocabulary theme + one output per cycle)

---

## Plan philosophy

- **Microlearning on weekdays**: 30 min sessions minimize friction
- **Deep work on weekends**: 1-hour focused sessions
- **4-week rotation**: one grammar axis + one vocab theme + one output per cycle
- **Output obligation**: every Sunday, ship a 5-sentence Korean summary to blog
- **Speech level awareness**: 해요체 ↔ 합쇼체 토글이 자연스러운 학습 목표

## Weekly distribution

### 월-금 (Mon-Fri · 30 min each day)

| Day | Block 1 (10 min) | Block 2 (10 min) | Block 3 (10 min) |
|---|---|---|---|
| 월 | 어휘 (Anki 15 new) | 표현 1개 분석 | 가벼운 읽기 (뉴스 1쪽) |
| 화 | 어휘 복습 (Anki) | 문법 1포인트 | 청취 (Podcast 5-10분) |
| 수 | 어휘 (Anki 15 new) | 표현 1개 분석 | 가벼운 읽기 |
| 목 | 어휘 복습 (Anki) | 문법 1포인트 | 청취 |
| 금 | 주간 어휘 총복습 | 표현 1개 분석 | 자유 읽기/시청 (YouTube) |

**Tools:**
- 어휘: Anki (TOPIK-tagged decks)
- 표현: 1 entry/day to `expressions/`
- 읽기: 한강, 박민규, 김영하 (light chapters)
- 청취: *TalkToMeInKorean*, *KBS World Radio*, *TTMIK Iyagi*

### 토요일 (Saturday · 60 min · deep session)

1. **심화 읽기 (25 min)**: 한국 원서 1챕터 or 긴 에세이 1편
   - 모르는 단어를 `vocabulary/` 에 1-3개 추가 (over-collection 금지)
2. **문법 정리 (20 min)**: 그 주 축이 되는 문법 포인트
   - `grammar/` 페이지 업데이트
3. **표현 노트 (15 min)**: 그 주 모은 표현 5개 사용 예문과 함께 정리

### 일요일 (Sunday · 60 min · output + review)

1. **작문/회화 (25 min)**: 한국어로 짧은 글 5-8문장
   - Optional: italki / Preply 25-min session (주 1회)
2. **주간 복습 (20 min)**: Anki 전체 복습 + 표현 총정리
3. **블로그 발행 (15 min)**: wiki 내용 → markdown → 블로그 publish
4. **다음 주 계획 (with LLM)**:
   ```
   "이번 주 학습한 표현과 문법을 바탕으로 다음 주 계획을 세워줘.
   부족한 부분 3가지와 보강 자료 추천도 함께."
   ```

## 4-week rotation

### Block A · 연결어미 + 조사 심화 (1-4주)

- **문법 axis**: -아/어도, -거든, -(으)면서, -(으)니까
- **어휘 axis**: 연결 + 원인/양보
- **읽기**: 단편 (*Korean short stories*)
- **Output**: 자기소개 확장 (200자)
- **문법 페이지**: `grammar/korean-connecting-endings.md`

### Block B · 경어법 + 호칭 (5-8주)

- **문법 axis**: 해요체/합쇼체/하소서체, 높임법 (경어)
- **어휘 axis**: 비즈니스/공식 표현, 이메일 어휘
- **읽기**: *82년생 김지영* (조남주) 1-3장
- **Output**: 비즈니스 이메일 1통 + 번역 해설
- **문법 페이지**: `grammar/korean-honorifics-detail.md`

### Block C · 시제 + 피동/사동 (9-12주)

- **문법 axis**: 시제 (과거/현재/미래) + 피동/사동
- **어휘 axis**: 보고/지시/명령
- **읽기**: *종의 기원* (정유정) 발췌
- **Output**: 과거 회상 단편 (300자)
- **문법 페이지**: `grammar/korean-cases-advanced.md`

### Block D · 통합 · 자유 프로젝트 (13-16주)

- **문법 axis**: 복합 (연결 + 시제 + 경어)
- **어휘 axis**: 자유 (사용자 관심 분야)
- **읽기**: 사용자 선택
- **Output**: 자유 주제 에세이 or 동영상 스크립트
- **문법 페이지**: 사용자 선택
