- **주간 사이클**: 평일(∼30분) 마이크로러닝 + 주말(∼60분) 딥워크
- **4주 로테이션**: 문법 축 1 + 어휘 주제 1 + 산출물 1개를 4주 단위로 완성
- **Output obligation**: 매주 일요일, 배운 내용을 한국어 5문장으로 블로그 드래프트에 정리
- **레벨 표시**: A1~C2 를 파일 머리에 명시
