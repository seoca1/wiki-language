# 동물 어휘 (Korean)

**Type:** vocabulary list  
**Date Added:** 2026-08-08  
**Language Level:** TOPIK 1-2 / A1-B1

## Summary

한국어 동물 어휘 (19개 항목) — 반려동물/가축 (7), 야생동물 (6), 조류/어류 (2), 곤충 (3). 출처: TOPIK N4-N5 동물 어휘, 국립국어원.

## Key Takeaways

- 한국 학습자가 가장 먼저 만나는 기본 동물 어휘 중심
- 한자어(한자)와 고유어 구분 표기 (개/犬, 소/牛 등)
- 다국어 대응표 포함 (EN/ES/JP) — 비교 학습 가능
- 문화적 배경: 단군신화(곰/호랑이), 십이지신, 속담/관용구

## Expressions Extracted

- "개팔자 상팔자" = 팔자 좋은 개처럼 편안함
- "소 잃고 외양간 고친다" = 사후 대책
- "닭 쫓던 개 지붕 쳐다본다" = 기회 놓침
- "호랑이 담배 피우던 시절" = 아주 옛날
- "원숭이도 나무에서 떨어진다" = 전문가도 실수
- "토끼와 거북이" = 꾸준함이 이김
- "개미와 베짱이" = 부지런 vs 게으름
- "말벌집 건드리기" = 위험한 일 벌이기

## Cultural Insights

- 단군신화: 곰(웅녀)과 호랑이 — 한국 건국 신화
- 십이지신: 쥐/소/호랑이/토끼/용/뱀/말/양/원숭이/닭/개/돼지
- 한우 = 한국 토종 소 브랜드, 반달가슴곰 = 복원 사업
- 반려동물 문화 급증, 길고양이 돌봄 확산
