# Korean Speech Levels Reference (경어법)

**Source:** speech-levels-ko
**Theme:** 경어법 (격식체)
**Level:** TOPIK 2-3

한국어 화자-청자 관계에 따른 동사 어미 변화 경어법. 일본어 敬語와 비슷하지만 더 체계적이고 필수적.

## 4 Major Speech Levels (4대 격식 체계)

### 1. 합쇼체 (Formal / 격식체)
- **용도:** 비즈니스, 공식 발표, 뉴스, 군대
- **종결 어미:** -(으)ㅂ니다 / -습니다
- **예:** "저는 학생입니다." "회의를 시작하겠습니다."

### 2. 해요체 (Polite / 일상 존댓말)
- **용도:** 일상 대화, 직장 상사, 친구 부모
- **종결 어미:** -아/어요 / -이에요/예요
- **예:** "저는 학생이에요." "밥 먹었어요?"

### 3. 해체 (Plain / 반말)
- **용도:** 친구, 가족, 동생, 자기 일기
- **종결 어미:** -는다 / -다 / -아/어
- **예:** "나는 학생이다." "밥 먹었어?"

### 4. 하소서체 (Literary / 문어)
- **용도:** 매우 격식적 문어, 기도, 고문서
- **종결 어미:** -옵 / -사옵 / -나이다
- **예:** "저옵은 학생이옵니다." (현대 한국어에서는 거의 사용 안 함)

## Notes

한국어 학습 시 격식 선택 필수. 잘못된 격식 = 무례/부자연스러움. 해요체가 가장 무난 (일상 기본). 합쇼체 = 비즈니스/격식. 해체 = 친한 사이/어린 자녀에게만. 하소서체 = 현대 회화에서 거의 불필요.
