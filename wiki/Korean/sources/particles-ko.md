## Summary

한국어 조사 12종 종합 레퍼런스. 받침 有/無 에 따른 2/3종 변형 표, 한국어 학습자 주의 포인트(은/는 vs 이/가, 에 vs 에서, 로/으로 발음) 포함. 한국어 학습자가 가장 헷갈리는 조사 구분을 한국어 학습자 관점에서 정리.

## Key Takeaways

- **12 핵심 조사**: 이/가, 은/는, 을/를, 의, 에, 에서, 로/으로, 와/과, 만, 도, 처럼, (이)라
- **받침 有/無 에 따른 2/3종 변형**: 주격(이/가), 보조사(은/는), 목적격(을/를), 동반(와/과) 4대 쌍
- **학습자 핵심 혼동**: 은/는 vs 이/가(주제 vs 정보), 에 vs 에서(정적 vs 동적), 로/으로 발음 차이
- **구어 생략**: 비격식/구어에서는 일부 조사 생략 가능 ("나 간다" = 나**가** 간다)

## 12 Core Particles (12 대 핵심 조사)

### 1. 이/가 (주격, nominative)
- 받침 有 + **이** (학생**이**, 책**이**, 사람**이**)
- 받침 無 / ㄹ 받침 + **가** (사과**가**, 컴퓨터**가**, 물**가**)
- 용도: 주어 표시, 강조, 가능/능력 표현

### 2. 은/는 (보조사, topic / contrast)
- 받침 有 + **은** (학생**은**, 책**은**, 사람**은**)
- 받침 無 / ㄹ 받침 + **는** (사과**는**, 컴퓨터**는**, 물**는**)
- 용도: 주제 (전체 진술의 대상), 대조, 부정

### 3. 을/를 (목적격, accusative)
- 받침 有 + **을** (책**을**, 물**을**, 사람**을**)
- 받침 無 / ㄹ 받침 + **를** (사과**를**, 컴퓨터**를**)
- 용도: 타동사의 직접 목적어

### 4. 의 (관형격, genitive)
- 명사 + **의** + 명사
- 용도: 소유격, 수식

### 5. 에 (다기능, locative / temporal / directional / dative)
- 장소(귀착): 학교**에** 갑니다
- 시간: 3시**에** 만납시다
- 방향: 한국**에** 옵니다
- 간접 목적: 친구**에**게

### 6. 에서 (출발 / 행동의 장소)
- 출발 (spatial): 서울**에서** 부산**으로**
- 출발 (temporal): 9시**에서** 10시 (덜 사용, **부터/까지** 권장)
- 행동의 장소: 도서관**에서** 공부해요

### 7. 로/으로 (방향 / 수단)
- 받침 無 + **로** (학교**로**, 집**로**)
- 받침 有 (ㄹ 제외) + **으로** (학교**으로**, 집**으로**)
- ㄹ 받침 + **로** (서울**로**)
- 용도: 방향, 수단, 변화 (얼음 → 물**로**)

### 8. 와/과 (동반 / 비교)
- 받침 有 + **과** (친구**과**, 책**과**)
- 받침 無 / ㄹ 받침 + **와** (친구**와**, 나**와**)
- 용도: 동반, 비교

### 9. 만 (제한, restriction)
- 명사 + **만**
- 용도: "~만", "~뿐"

### 10. 도 (부정 포함 / 추가)
- 명사 + **도**
- 용도: "~도" (also / too / either)

### 11. 처럼 (비교 / 유사)
- 명사 + **처럼**
- 용도: "~처럼", "~같이"

### 12. (이)라 (인용 / 인지)
- 받침 有 + **이라** (학생**이라**, 책**이라**)
- 받침 無 / ㄹ 받침 + **라** (사과**라**, 컴퓨터**라**)
- 용도: "~이라고 / 라고", "(이름이) ~"

## 받침 有/無 결정 표

| 받침 | 주격 | 보조사 | 목적격 | 동반 |
|---|---|---|---|---|
| 有 (학생, 책) | **이** | **은** | **을** | **과** |
| 無 (사과, 나) | **가** | **는** | **를** | **와** |
| ㄹ (물, 서울) | **이/가** (둘 다) | **은/는** (둘 다) | **을/를** (둘 다) | **와** |

## Korean Learner Key Points (한국어 학습자 주의)

1. **받침에 따른 조사 변형**: 받침 有/無 에 따라 2종 (이/가, 은/는, 을/를, 과/와) 또는 3종 (라/이라, 로/으로)
2. **은/는 vs 이/가**: 은/는 = 주제 (already known), 이/가 = 정보 (new)
3. **에 vs 에서**: 에 = 정적 (위치/존재), 에서 = 동적 (행동/출발)
4. **로/으로 발음**: 발음 동일하지만 표기 다름. ㄹ 받침 = 로, 받침 無 = 로, 받침 有(ㄹ 제외) = 으로
5. **생략 가능**: 구어/비격식에서 조사 생략 가능 ("나 간다" = 나**가** 간다)
