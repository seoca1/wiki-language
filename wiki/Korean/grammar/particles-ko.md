# 한국어 조사 (Particles)

**Type:** 문법
**Level:** TOPIK 1-2
**Date Added:** 2026-08-08

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 한국어 조사 12 종 (이/가 / 은/는 / 을/를 / 의 / 에 / 에서 / 로/으로 / 와/과 / 만 / 도 / 처럼 / (이)라) — 명사 / 대명사 사이의 문법 관계 표시.
> - **특징:** 받침 有/無 에 따라 조사 변형 (2 종 또는 3 종). 영어 / 중국어에는 없는 시스템.
> - **학습자 우선순위:** 이/가 / 은/는 → 을/를 → 에/에서 → 나머지.
> - **한국어 학습자 주의:** "은/는" vs "이/가" 가 가장 빈번한 실수 원인. 받침 有/無 에 따른 조사 변형 필수.

---

## 12 대 핵심 조사

### 1. 이/가 (주격, nominative)
- 받침 有 + **이** (학생**이**, 책**이**)
- 받침 無 / ㄹ + **가** (사과**가**, 물**가**)
- **용도**: 주어 표시, 강조, 가능 / 능력
- **예**:
  - "학생**이** 옵니다." (The student comes.)
  - "나**가** 할게요." (I will do it.)

### 2. 은/는 (보조사, topic / contrast)
- 받침 有 + **은** (학생**은**, 책**은**)
- 받침 無 / ㄹ + **는** (사과**는**, 컴퓨터**는**)
- **용도**: 주제, 대조, 부정 강조
- **예**:
  - "저**는** 학생입니다." (I am a student — topic)
  - "이 사과는 달**지만** 저 사과는 안 달**아요**." (대조)

### 3. 을/를 (목적격, accusative)
- 받침 有 + **을** (책**을**, 물**을**)
- 받침 無 / ㄹ + **를** (사과**를**, 컴퓨터**를**)
- **용도**: 타동사의 직접 목적어
- **예**:
  - "책**을** 읽습니다." (I read a book.)

### 4. 의 (관형격, genitive)
- **용도**: 소유격, 수식
- **예**: "나**의** 책" (my book)

### 5. 에 (다기능)
- **용도**: 장소 (귀착), 시간, 방향, 간접 목적
- **예**: "학교**에** 갑니다." (I go to school.)

### 6. 에서 (출발 / 행동의 장소)
- **용도**: 행동의 장소
- **예**: "도서관**에서** 공부해요." (I study at the library.)

### 7. 로/으로 (방향 / 수단)
- 받침 無 / ㄹ + **로** (학교**로**, 서울**로**)
- 받침 有 (ㄹ 제외) + **으로** (친구**으로**)
- **용도**: 방향, 수단, 변화
- **예**:
  - "집**으로** 가요." (I'm going home.)
  - "버스**로** 와요." (I'm coming by bus.)

### 8. 와/과 (동반 / 비교)
- 받침 有 + **과** (친구**와**, 책**과**)
- 받침 無 / ㄹ + **와** (친구**와**, 나**와**)
- **용도**: 동반, 비교
- **예**: "친구**와** 영화를 봤어요." (I watched a movie with a friend.)

### 9. 만 (제한)
- **용도**: "~만", "~뿐"
- **예**: "저는 물**만** 마셔요." (I only drink water.)

### 10. 도 (부정 포함 / 추가)
- **용도**: "~도" (also / too)
- **예**: "저도 가요." (I also go.)

### 11. 처럼 (비교 / 유사)
- **용도**: "~처럼", "~같이"
- **예**: "사람**처럼** 행동해요." (act like a human)

### 12. (이)라 (인용 / 인지)
- 받침 有 + **이라** (학생**이라**)
- 받침 無 / ㄹ + **라** (사과**라**)
- **용도**: "~이라고 / 라고", "(이름이) ~"
- **예**: "학생이**라**..." (because I am a student...)

## 받침 有/無 결정 표

| 받침 | 주격 | 보조사 | 목적격 | 동반 |
|---|---|---|---|---|
| 有 (학생, 책) | **이** | **은** | **을** | **과** |
| 無 (사과, 나) | **가** | **는** | **를** | **와** |
| ㄹ (물, 서울) | **이/가** (둘 다 발음) | **은/는** (둘 다 발음) | **을/를** (둘 다 발음) | **와** |

---

## 핵심 구분: 은/는 vs 이/가

가장 어려운 구분. 둘 다 주어 표시하지만 용도가 다름.

| 상황 | 사용 | 예 |
|---|---|---|
| 처음 / 정보 | 이/가 | "학생**이** 왔어요." (A student came.) |
| 이미 알려진 / 주제 | 은/는 | "학생**은** 공부해요." (The student studies.) |
| 강조 / 신문 / 문어 | 이/가 | "한국**이** 이겼어요." (Korea won.) |
| 대조 | 은/는 | "이것**은** 좋**지만** 저것**은** 안 좋아요." (This is good but that is not.) |
| 부정 강조 | 은/는 | "저**는** 안 먹어요." (I don't eat.) |
| 의문사 + | 이/가 | "누**가** 왔어요?" (Who came?) |

---

## 핵심 구분: 에 vs 에서

장소 표시의 핵심 구분.

| 상황 | 사용 | 예 |
|---|---|---|
| 정적 (위치) | 에 | "집**에** 있어요." (I am at home.) |
| 동적 (행동의 장소) | 에서 | "집**에서** 일해요." (I work at home.) |
| 출발 (공간) | 에서 | "서울**에서** 부산으로." (From Seoul to Busan.) |
| 시간 | 에 | "3시**에** 만나요." (meet at 3.) |

## 한국어 학습자 실수 패턴

1. **관사 오인**: 한국어에는 a / the 같은 관사 없음. 영어 학습자는 한국어 조사 = 영어 관사로 오인.
2. **받침 有/無 혼동**: 초급자에게 가장 빈번한 실수. 발음 + 표기 모두 주의.
3. **은/는 vs 이/가**: 고급자도 혼동. 맥락 + 의미 의존.
4. **에 vs 에서**: 정적 vs 동적 구분. "집에 있다" (정적, 위치) vs "집에서 공부한다" (동적, 행동).
5. **로/으로**: 발음 동일하지만 표기 다르다. ㄹ 받침 = 로, 받침 無 = 로, 받침 有 = 으로.
6. **생략**: 구어 / 비격식에서 일부 조사 생략 가능 (예: "나 간다" — 나**가** 간다).

## Ejemplos

«저는 학생이고, 제 친구는 의사입니다.» — 은/는 (보조사) + 이/가 (주격) 결합.

«도서관에서 책을 읽어요.» — 에서 (장소) + 을 (목적격).

«친구와 함께 영화관에 갔어요.» — 와 (동반) + 에 (방향).

«커피 말고 물만 마셔요.» — 말고 (대조) + 만 (제한).

«저는 한국 사람이에요.» — 는 (주제) + 이 (주격 강조) + 에요 (격식 종결).

## Cross-language Connections

- **일본어**: 조사 ~9 종 (は/が/を/に/で/へ/から/まで/より). 한국어 조사 (~30 종) 의 1/3. 받침 변형 없음 (일본어는 발음 영향 없음).
- **스페인어**: 전치사 ~25 종 (a, de, en, con, por, para, sin, hasta, desde, hacia 등). 한국어와 비슷한 시스템.
- **영어**: 전치사 ~150 종. 가장 많음. 한국어 / 일본어 / 스페인어보다 정교.
- **중국어**: 조사 없음. 단어 순서 + 양사 (量詞) 로 문법 관계 표시.
