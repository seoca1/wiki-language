# 한국어 수사 체계 — 순 우리말 vs 한자어

**Type:** grammar
**Level:** TOPIK 1-2
**Date Added:** 2026-08-11

> �🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 한국어 숫자는 **순 우리말** (하나/둘/셋) 과 **한자어** (일/이/三) 두 체계가 공존. 양수(개수) + 서수(순서) + 고유어/한자어 혼용 규칙.
> - **한국어 차이:** 영어/스페인어/중국어와 달리 두 계기가 동시에 작동. 일본어 日本語에서도 ひ vs いち 유사 이원 체계 존재.
> - **학습자 우선순위:** 순 우리말 1~10 (시간·나이·월) → 한자어 1~10 (날짜·전화·가격·주소) → 서수 (첫째/첫 번째/제일).
> - **한국어 학습자 주의:** 시간/나이는 순 우리말 + 한자어 단위가 섞여 (한 시 = 1시 = 1 o'clock), 받침 有/無 단위 명사 (개/명/마리) 별도 숙지.

---

## Two Numeral Systems (이원 수사 체계)

### 1. 순 우리말 (Sino-Native / Pure Korean) — 하나, 둘, 셋...

- **Range:** 1~99 (limited forms above 99). Used for: hours, age, months, native counter compatibility.
- **Pattern:** 하나 → 둘 → 셋 → 넷 → 다섯 → 여섯 → 일곱 → 여덟 → 아홉 → 열 → 열하나 → 열둘 → 스물 → 서른 → 마흔 → 쉰 → 예순 → 일흔 → 여든 → 아흔.
- **Tens + units:** 스물하나 (21), 서른셋 (33), 마흔둘 (42). Note: 하나 → 열하나 (not *열일*), 둘 → 스물하나 (not *스물일*).
- **Special pronunciation:** 하나 = [하나], but in compounds: 한 시, 한 명, 한 개, 한 잔 (받침 無 탈락). 둘 = [둘] → 두 시, 두 명, 두 개.
- **Examples:**
  - 한 명**만** 왔어요. — "Only one person came."
  - 저**는** 스물다섯**살**이에요. — "I'm 25 years old."
  - 아홉 시**에** 만납시다. — "Let's meet at 9 o'clock."

### 2. 한자어 (Sino-Korean) — 일, 이, 삼, 사...

- **Range:** 1~infinity (unlimited). Used for: dates, phone numbers, prices, addresses, math.
- **Pattern:** 일 → 이 → 삼 → 사 → 오 → 육 → 칠 → 팔 → 구 → 십 → 백 → 천 → 만 → 억 → 조.
- **Compounds:** 11 = 십일 (vs 열하나), 100 = 백 (vs pure Korean 없음), 1,000 = 천, 10,000 = 만, 100,000,000 = 억.
- **Pure Korean only:** 하나/둘/셋 have no Sino equivalents for tens (스물하나 vs 이십일 — 이십일 is formal/literary, 스물하나 = natural speech).
- **Examples:**
  - 2026**년** 팔월 십일일. — "August 11, 2026."
  - 전화번호: 010-일이삼사-오육칠팔. — "Phone: 010-1234-5678."
  - 만 오천 원**입니다**. — "It's 15,000 won."

## 양수 (Cardinals) vs 서수 (Ordinals)

| 양수 Cardinal | 서수 Ordinal (순 우리말) | 서수 Ordinal (한자어) | Meaning |
|---|---|---|---|
| 하나 (1) | 첫째 / 하나째 | 제일 | 1st |
| 둘 (2) | 둘째 / 두째 | 제이 | 2nd |
| 셋 (3) | 셋째 | 제삼 | 3rd |
| 넷 (4) | 넷째 | 제사 | 4th |
| 다섯 (5) | 다섯째 | 제오 | 5th |
| 열 (10) | 열째 | 제십 | 10th |
| 스물하나 (21) | 스물한째 | 제이십일 | 21st |

### Notes
- **첫째** = native ordinal (most common); **제일** = Sino ordinal (formal/math).
- **첫 번째 / 둘째 번째** is also correct (more explicit).
- 일요일 (Sunday) = Sino + 일 (1+day) vs 월요일 (Monday, 月+曜+日).

## Native vs Sino Mixing (혼용 규칙)

| Category | System | Examples |
|---|---|---|
| 시간 (time/hours) | 순 우리말 | 한 시, 두 시, 열한 시 |
| 나이 (age) | 순 우리말 | 스물다섯 살 |
| 월 (months) | 한자어 | 일월 (Jan), 이월 (Feb) |
| 일 (date/day) | 한자어 | 십일일 (11th), 이십오일 (25th) |
| 전화번호 | 한자어 | 010-일이삼사-5678 |
| 가격 (price) | 한자어 | 만 원, 삼만 오천 원 |
| 주소 (address) | 한자어 | 서울특별시 강남구 일호로 일번지 |
| 사람 수 | 순 우리말 + 단위 | 한 명, 두 명, 스무 명 |
| 물건 수 | 순 우리말 + 단위 | 한 개, 두 개, 세 개 |
| 동물 수 | 순 우리말 + 마리 | 두 마리, 열 마리 |

## Number + Counter Nouns (수량 명사)

| Counter | Usage | 받침 변화 |
|---|---|---|
| **명** (people, polite) | 학생 두 명 (two students) | 받침 有 |
| **사람** (people, casual) | 세 사람 (three people) | 받침 無 |
| **개** (things, general) | 사과 한 개 (one apple) | 받침 無 |
| **마리** (animals) | 고양이 두 마리 (two cats) | 받침 無 |
| **병** (bottles) | 물 한 병 (one bottle of water) | 받침 無 |
| **잔** (cups) | 커피 두 잔 (two cups of coffee) | 받침 無 |
| **권** (books) | 책 세 권 (three books) | 받침 無 |
| **대** (vehicles/machines) | 자전거 한 대 (one bicycle) | 받침 無 |
| **장** (sheets/papers) | 종이 다섯 장 (five sheets) | 받침 無 |
| **번** (times/occurrences) | 세 번 (three times) | 받침 無 |

> All counters combine with **하나→한, 둘→두, 셋→세, 넷→네, 스물→스무** 받침-drop forms.

## Key Points

- **이원 체계 (dual system):** 모든 한국어 숫자는 순 우리말/한자어 중 하나를 선택해야 함. 잘못된 매칭 = 부자연.
- **받침 변형 (number stem changes):** 하나→한, 둘→두, 셋→세, 넷→네, 스물→스무 (받침 drop before unit/counter).
- **시간 = 순 우리말, 날짜 = 한자어** (가장 빈번한 혼용 패턴).
- **서수 (ordinals):** 첫째/둘째/셋째 (받침 有 → 받침 無: 첫째, BUT 둘째·셋째·넷째 keep form).
- **큰 수:** 만/억/조 = 만 = 10⁴ (vs English thousand = 10³). 만 단위로 끊어 읽기.
- **연령/월 특수:** 스물다섯 살 (age, pure), 일월 (Jan, Sino). 둘 다 자연스러우나 영역 구분 명확.

## Cross-language Connections

- **Japanese:** ひ/ふ/み/よ/む/な/や/ここの/お (和語) vs いち/に/さん (漢語) — 동일 이원 체계. いちがつ 一月 vs ひとつ — 1월 vs 1개.
- **English:** Two-way (cardinal/ordinal only). 단일 어순 (one, two, three). No 받침 drop.
- **Spanish:** Uno/dos/tres... 단일 계기. Primero/segundo = ordinal. No dual system.
- **Chinese:** 漢字 一/二/三/四/五 단일 계기. 韓보다 단순. 만 = 萬 = 10⁴ (CJK 공유).
- **Korean uniqueness:** 이원 체계 + 받침 기반 단위 명사 (개/명/마리/잔) — 동일 동아시아에서 일본만 부분 공유.

## Ejemplos

«저**는** 스물다섯**살**이고, 서울**의** 이천이십육**년** 오월**에** 한국**에** 왔**습니다**.' — Sino (date: 2026 May) + pure (age: 25).

«커피 두 **잔**이랑 빵 세 **개** 주세요.' — counters 잔 (cups) + 개 (things).

«둘째**째** 아니고 셋째**째**예요.' — ordinal 둘째/셋째 (받침 변화 X).

«오백만**만** 삼천원**원**짜리 노트북**을** 사**였**어요.' — 만 단위 끊기 + Sino (price).

«아홉 시**에** 백화점**에서** 만나**요**.' — pure (hour) + Sino (百貨店).
