# 한국어 조사 심화 — 여격 + 부사격

**Type:** grammar
**Level:** TOPIK 2-4
**Date Added:** 2026-08-11

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** [[particles-ko]] 가 12개 핵심 조사를 다룬다면, 본 페이지는 **여격 (Dative / Indirect Object)** 조사 3종 (에게/한테/께) 과 **부사격 (Adverbial)** 조사 심화 (에서/부터/까지/도) 의 받침 有/無 결정법.
> - **한국어 차이:** 영어/스페인어의 단일 "to + person" 대비 한국어는 **격식 (격식 격 = 격)** + **상대 (격식 = 격)** 으로 분화. 일본어 に honorific 분화와 유사.
> - **학습자 우선순위:** 에게/한테 (비격식) → 께 (격식 honorific) → 에서 (장소/출발) → 부터/까지 (시점/종점).
> - **한국어 학습자 주의:** 격식/격식 격 (에게 vs 께) + 받침 有/無 (학생에게 vs 사하님께) + 사람/사하/동물 대상 구분.

---

## 여격 (Dative) Particles — 에게 / 한테 / 께

### 1. 에게 (ege) — Standard dative (Standard / Polite)
- **용도:** Standard dative to **person, animal, thing**. 격식 speech (해요체/합쇼체).
- **받침 변화:** 받침 有 → 에게 (학생에게, 책에게 — 비인간 가능). 받침 無/ㄹ → 에게 (사과에게, 물에게).
- **예문:**
  - 친구**에게** 편지**를** 보냈어요. — "I sent a letter to a friend."
  - 강아지**에게** 밥**을** 줬어요. — "I gave food to the puppy."

### 2. 한테 (hante) — Casual dative (Plain / 해체)
- **용도:** 해체 speech (친구/가족). 동사 + 한테 (action recipient).
- **받침 변화:** 받침 有 → 한테, 받침 無/ㄹ → 한테. 받침 변형 없음.
- **Examples:**
  - 누나**한테** 책**을** 받았다. — "I got a book from my older sister." (해체)
  - 친구**한테** 전화**해**라. — "Call your friend." (command, 해체)

### 3. 께 (kke) — Honorific dative (Honorific Recipient)
- **용도:** 격식 + honorific recipient (윗사람/손님/할머님). 상대높임 + 주체높임 결합.
- **받침 변화:** 받침 有 → 께 (할머님**께**, 교수님**께**, 손님**께**). 받침 無 → 분 (사람 분, but 분 is honorific NOUN, not particle).
- **Restrictions:** 께 ONLY for honorific people. 받침 無 honorific noun → 분 (e.g., 아버지 = 받침 有 → 아버지께, but 손님 = 받침 無 → 손님께 [still valid], 동생 = 받침 無 → 동생에게 [no honorific]).
- **Examples:**
  - 할머님**께** 인사**드렸**어요. — "I greeted grandmother." (격식 + honorific recipient)
  - 교수님**께** 질문**드렸**어요. — "I asked the professor."

## 부사격 (Adverbial) Particles — 에서 / 부터 / 까지

### 4. 에서 (eseo) — Source / Action Location
- **용도:** (1) 동작 장소 (study at library), (2) 출발 (from Seoul), (3) 행위자 (subject).
- **받침 변화:** No 변형 (에서 fixed).
- **Examples:**
  - 도서관**에서** 공부해요. — "I study at the library." (동작 장소)
  - 서울**에서** 부산**으로** 갔어요. — "I went from Seoul to Busan." (출발점)

### 5. 부터 (buteo) — Start Point / Origin
- **용도:** 시점/장소 시작점 (from 9 o'clock, from today, from this point).
- **받침 변화:** No 변형 (부터 fixed).
- **Examples:**
  - 9시**부터** 일해요. — "I work from 9 o'clock."
  - 오늘**부터** 시작해요. — "Starting today."
  - 이**부터** 저쪽**까지** — "From here to there."

### 6. 까지 (kkaji) — End Point / Limit
- **용도:** 종점/장소 (until 6 o'clock, until Seoul, even/including).
- **받침 변화:** No 변형 (까지 fixed).
- **Examples:**
  - 6시**까지** 일해요. — "I work until 6 o'clock."
  - 부산**까지** 갔어요. — "I went all the way to Busan." (강조: even to Busan)

### 부터 + 까지 Combination
- 9시**부터** 6시**까지** 일해요. — "I work from 9 to 6."
- 시작**부터** 끝**까지** 봐주세요. — "Please review from start to end."

### 에서 vs 부터 (출발점)
- **에서** = spatial/dynamic source (서울에서 부산으로). Motion context.
- **부터** = temporal/abstract starting point (9시부터, 오늘부터). Sequence/continuation context.
- Both can mean "from" but **부터** emphasizes continuation, **에서** emphasizes origin.

## 받침 有/無 결정법 (Batchim Decision Rules)

### Rule 1: 받침 有 (학생, 책, 사람, 강아지)
- Subject: 이
- Topic: 은
- Object: 을
- With: 과
- Dative: 에게 (or 께 for honorific)

### Rule 2: 받침 無 (사과, 나, 물, 서울)
- Subject: 가
- Topic: 는
- Object: 를
- With: 와
- Dative: 에게

### Rule 3: ㄹ 받침 (물, 서울, 말)
- Subject: 이/가 (both OK)
- Topic: 은/는 (both OK)
- Object: 을/를 (both OK)
- Dative: 에게

## Key Points

- **에게 vs 한테:** 격식 speech → 에게, 해체 speech → 한테. 혼용 시 부자연.
- **께 = 격식 + honorific recipient:** "할머님께" (격식+honorific) ≠ "할머님에게" (격식). "할머님한테" = 해체 (격식 X).
- **에게 + 비인간 가능:** "책에게" / "컴퓨터에게" (비인간 dative) 가능. 단 "물한테" = 구어/구식 (피하는 편).
- **에서 = 동작 장소/출발점** (동사 필수). **에 = 정지 위치/목적지**.
- **부터 vs 에서:** 부터 = 시점/abstract 시작, 에서 = 공간 출발 (동작).
- **까지 = 종점 OR 강조 (even up to):** "부산까지" = "all the way to Busan" 강조.
- **Honorific dative (께) vs 에게:** 받을 수 있는 honorific 명사 = 분/성함/연세 (사람) + 댁 (집) + 진지 (밥). 받침 有 honorific noun → 께.

## Cross-language Connections

- **Japanese:** に (dative, location, time) — 한국어 에게/에 통합. には (target) vs にも (also). 께 대응 = honorific recipient (no particle change but いらっしゃる etc.).
- **English:** to/for (dative, all persons). Preposition uniform. No honorific distinction.
- **Spanish:** a (to, person) / para (for, recipient). A + personal a (animate). 받침 有/無 무관.
- **Chinese:** 给 (give to) / 对 (toward) / 在 (at). Honorific recipient: 給您 (give you honorific). 동사 활용 없음.
- **Korean uniqueness:** 받침 有/無 변형 + 격식/격식/격식 (격식 격) 분화 (에게/한테/께) — 동아시아 최고 정밀.

## Ejemplos

«어머니**께** 꽃다발**을** 드렸어요.' — 격식 + honorific recipient (께).

«친구**에게** 이메일**을** 보냈어요.' — 격식, 동등 (에게).

«강아지**한테** 물**을** 줘.' — 해체, 동물 (한테).

«도서관**에서** 친구**에게** 책**을** 빌려줬어요.' — 에서 (동작 장소) + 에게 (격식 dative).

«9시**부터** 6시**까지** 회사**에서** 일해요.' — 부터/까지 (시점) + 에서 (장소).

«서울**에서** 부산**까지** KTX**를** 탔어요.' — 에서 (출발) + 까지 (종점).
