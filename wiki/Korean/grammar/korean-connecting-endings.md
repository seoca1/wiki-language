# 한국어 연결어미 — -아/어/여 / -고 / -지만 / -면 / -니까

**Type:** grammar
**Level:** TOPIK 1-3
**Date Added:** 2026-08-11

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 한국어 **연결어미 (Connective Endings)** 는 두 절을 잇는 접착제. -아/어/여 (并列, sequence), -고 (and then), -지만 (but/however), -면 (if/when), -니까 (because/since) — 5종이 사용 빈도의 90 %.
> - **한국어 차이:** 영어/중국어/일본어 대비 한국어는 **연결어미가 매우 빈번**. 일본어 て/たら/ても 와 유사하나 더 세분화.
> - **학습자 우선순위:** -고 (가장 빈번) → -아/어/여 (동시/순차) → -지만 (대조) → -면 (조건) → -니까 (이유).
> - **한국어 학습자 주의:** 받침 有 동사 → -**아** (가**아** = 가), 받침 無 동사 → -**어** (마시**어** = 마셔), 하다 → -**여** (하**여** = 해). 모음 축약 필수.

---

## 5 Major Connective Endings

### 1. -아/어/여 (Sequence / And) — 동시/순차
- **용도:** 두 동작의 연속 (sequence), 동시 (simultaneous), 또는 단어 연결.
- **받침 변화 규칙 (vowel harmony):**
  - **�/ㅗ + -아**: 가**아** → 가 (ga), 읽**어** → 읽어 (ilk-eo, but 읽**어** — vowel ㅓ → -어).
  - **ㅓ/ㅜ/ㅡ/ㅣ + -어**: 마시**어** → 마셔 (masyeo), 주**어** → 줘 (jwo).
  - **하- + -여**: 하**여** → 해 (hae). Special: 하 + 여 = **해**.
- **Examples:**
  - 밥**을** 먹**고** 공부했어요. (X — use -고 for sequence)
  - 밥**을** 먹**어** 봤어요? — "Have you tried eating?" (시도)
  - 영희**가** 오**고** (X) 영희**가** 와**서** (O — 와 + 아 = 와).
  - **읽** + 어 → **읽어** (eulgeo, eo suffix, 받침 ㄱ → silent in reading but kept in spelling).
- **Conjugation (verb + -아/어/여):**
  | 동사 (Verb) | -아/어/여 form | Note |
  |---|---|---|
  | 가다 (to go) | 가**서** | ㅏ → -아 + 서 |
  | 오다 (to come) | 와**서** | ㅗ → -아 + 와 |
  | 마시다 (to drink) | 마셔**서** | ㅣ → -어 + 마셔 |
  | 먹다 (to eat) | 먹어**서** | ㅓ → -어 + 먹어 |
  | 공부하다 (to study) | 공부해**서** | 하다 → -여 |
  | 주다 (to give) | 줘**서** | ㅜ → -어 + 주 → 줘 |

---

### 2. -고 (And / Sequence) — 단순 연결
- **용도:** 단순 sequence (action1 + action2). 가장 빈번한 연결어미.
- **받침 변화:** 없음 (모든 동사에 -고).
- **Examples:**
  - 밥**을** 먹**고** 공부했어요. — "I ate and then studied."
  - 한국어**를** 배우**고** 일본어**도** 배워요. — "I'm learning Korean and Japanese too."
  - 손**을** 씻**고** 음식**을** 만졌어요. — "I washed my hands and touched food." (sequence)

---

### 3. -지만 (But / Although) — 대조
- **용도:** 대조 (contrast), 양보 (concession: "although X, Y").
- **받침 변화:** 없음.
- **Examples:**
  - 비싸**지만** 좋아요. — "It's expensive but good."
  - 한국어**가** 어렵**지만** 재밌**어요**. — "Korean is difficult but interesting."
  - 자**지만** 피곤**해**요. — "Although I slept, I'm tired."

---

### 4. -면 (If / When) — 조건
- **용도:** 조건 (conditional), 가정 (hypothetical). 받침 有 → -으면, 받침 無 → -면.
- **받침 변화:**
  - 받침 有: 먹**으면** (meok-eumyeon), 읽**으면** (ilk-eumyeon)
  - 받침 無: 가**면** (gamyeon), 마시**면** (masimyeon)
  - ㄹ 받침: 살**면** (salmyeon — ㄹ drops before -면)
  - 하다: 하**면** (hamyeon)
- **Examples:**
  - 비**가** 오**면** 집**에** 있을게요. — "If it rains, I'll stay home."
  - 시간**이** 있**으면** 만나요. — "If you have time, let's meet."
  - 더우**면** 에어컨**을** 켜세요. — "If it's hot, turn on the air conditioner."

---

### 5. -니까 (-nikka) — 이유/원인 (Because / Since)
- **용도:** 이유/원인 (causal). -아/어서 (vs -니까): -니까 stronger speaker conviction. -아/어서 = cause, -니까 = reason + speaker emphasis.
- **받침 변화:** 없음.
- **Examples:**
  - 피곤하**니까** 쉬세요. — "Because you're tired, please rest."
  - 약속했**으니까** 가야 해요. — "Because I made a promise, I have to go."
  - 늦었**으니까** 빨리 가요. — "Since it's late, let's hurry."

## Connective Ending Decision Table

| Meaning | Ending | 받침 有 | 받침 無 | Examples |
|---|---|---|---|---|
| Sequence (then) | -고 | 먹**고** | 가**고** | 먹고 공부해요 |
| Simultaneous | -아/어/여 | 먹**어서** | 마시**어서** | 먹어서 (eaten already → because) |
| Contrast | -지만 | 비싸**지만** | 좋**지만** | 비싸지만 좋아요 |
| Conditional | -면 | 먹**으면** | 가**면** | 먹으면 더 좋아요 |
| Cause (strong) | -니까 | 피곤하**니까** | 좋**으니까** | 피곤하니까 자요 |

## Key Points

- **모음 조화 (vowel harmony):** -아/어/여 의 선택. ㅏ/ㅗ → -아 (가+아, 오+아), 그 외 → -어 (마시+어, 먹+어). 하다 → -여.
- **ㅂ 불규칙 (ㅂ irregular):** 곱다 → 고와서 (not 곱+아서 = 곱아서). Examples: 곱다/춥다/더럽다 → 어간 + -워서 (X -아서).
- **ㄷ 불규칙 (ㄷ irregular):** 듣다 → 들어서 (not 듣+아서 = 듣아서). ㄷ 동사: 듣다, 걷다, 묻다 (some 묻다) → 어간 + -어서.
- **ㅅ 불규칙 (ㅅ irregular):** 낫다 → 나아서 (X 낫+아서 = 낫아서). 낫다/붓다/짓다 → ㅅ drop before vowel.
- **르 불규칙 (르 irregular):** 부르다 → 불러서 (X 부르+어서). 르 동사: 부르다/빠르다/고르다 → 어간 + -러서.
- **-아/어서 vs -니까:** -아/어서 = cause (chronological, natural). -니까 = reason (speaker's emphasis, often followed by command/request).
- **-지만 vs -는데:** -지만 = pure contrast. -는데 = background/contrast (more narrative).
- **받침 有 + -면 → -으면:** 먹으면, 살면 (BUT 살 = ㄹ 받침 → 살면, ㄹ drop before -면).

## Cross-language Connections

- **Japanese:** て形 (te-form) sequence = -고 + -아/어 (가장 가까움). たら = -면 (if/when). ても = -아/어도 (even if). から = -아/어서 OR -니까 (because).
- **English:** and/then/but/if/because — 단일 단어 연결. 동사 변형 없음 (한국어의 받침/모음 조화 무관).
- **Spanish:** y (and) / pero (but) / si (if) / porque (because) — 단일 단어. 동사 시제/인칭 활용 필수 (한국어의 받침 변화 무관).
- **Chinese:** 和/而且/但是/如果/因为 — 단일 단어. 동사 활용 없음. 받침 변형 없음.
- **Korean uniqueness:** 받침 有/無 + 모음 조화 + 불규칙 (�/ㄷ/ㅅ/르) + 시제 통합 — 동사 어간 변형 동아시아 최고 복잡.

## Ejemplos

«한국**에** 가**서** 한국어**를** 배울 거예요.' — -아/어서 (sequence, 받침 無).

«책**을** 읽**고** 영화**를** 봤어요.' — -고 (sequence, 받침 無).

«비싸**지만** 살 거예요.' — -지만 (contrast).

«돈**이** 있**으면** 여행**을** 가겠**어요**.' — -면 (받침 有 → -으면).

«피곤하**니까** 먼저 자**겠**어요.' — -니까 (reason, 받침 有 → -으니까).

«한국어**가** 어렵**지만** 재미있**어요**.' — -지만 + 종결어미 결합.
