# 한국어 존댓말 — 6단계 + 말높임법 3축

**Type:** grammar
**Level:** TOPIK 3-6
**Date Added:** 2026-08-11

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 존댓말 = (1) 종결어미 (경어법 6단계) + (2) 말높임법 3축 (상대/주체/객체) 의 **이중 시스템**. [[speech-levels-ko]] 가 종결어미만 다룬다면, 본 페이지는 말높임법 3축을 심화.
> - **한국어 차이:** 일본어 敬語 (keigo) 와 구조 유사 (존경어/겸양어/丁寧語)지만 한국어는 **상대높임 종결어미** 가 독립 축. 중국어 您/请 와 단순 이원 대비 정밀.
> - **학습자 우선순위:** 종결어미 4단계 (합쇼/해요/해/하소서) → 상대높임 → 주체높임 (시/-(으)시-) → 객체높임 (드리다/여쭙다).
> - **한국어 학습자 주의:** 한 문장 안에 상대높임 종결어미 + 주체높임 시 honorific + 객체높임 동사 **동시 적용** 가능. 혼용 시 부자연.

---

## 6 Speech Levels (경어법 종결어미)

> 종결어미 = 문장 끝의 상대높임 marker. [[speech-levels-ko]] 가 4단계를 다룬다면, 여기서는 6단계 전체 + 특수 변형.

### 1. 합쇼체 (Hapsyo-che) — Formal 격식체
- **종결어미:** -(으)ㅂ니다 / -습니다 / -(으)ㅂ니까
- **용도:** 뉴스, 공식 발표, 비즈니스 이메일, 군대, 공문
- **예문:**
  - 회의 시작하**겠습니다**. — "Let me begin the meeting." (합쇼체 + 의향)
  - 결과 보고하**였습니다**. — "I reported the result."

### 2. 해요체 (Haeyo-che) — Polite 일상 존댓말
- **종결어미:** -아/어요 / -이에요/예요 / -어요 / -(으)세요
- **용도:** 일상 회화 (부모, 상사, 처음 만난 사람), TV 일반 방송
- **예문:**
  - 날씨 좋**네요**. — "Nice weather, isn't it?"
  - 저**는** 학생**이에요**. — "I am a student." (받침 有 → 이에요)

### 3. 해체 (Hae-che) — Plain 반말
- **종결어미:** -는다 / -다 / -아/어 / -(으)ㄴ다 / -냐 / -지
- **용도:** 친구, 가족, 어린아이, 독백/일기
- **예문:**
  - 밥 먹었**어**? — "Have you eaten?" (plain question)
  - 날씨 좋**다**. — "The weather is good."

### 4. 하소서체 (Hasoseo-che) — Literary 격식 문어
- **종결어미:** -옵 / -사옵 / -나이다 / -옵니다
- **용도:** 기도문, 역사 문서, 공식 축사 (현대 회화 거의 안 씀)
- **예문:**
  - 저희 회사에 오신 것 환영하**옵나이다**. — 격식 (거의 안 씀)

### 5. 하십시오체 (Hasipsio-che) — 명령형 격식체
- **종결어미:** -(으)십시오 / -십시오 / -아/어 주십시오
- **용도:** 격식 명령 (공식 요청, 안내 방송), 청자 우대
- **예문:**
  - 말씀해 주**십시오**. — "Please speak."
  - 입장해 주**십시오**. — "Please enter."

### 6. 하네체 (Hane-che) — Familiar 해체 변형
- **종결어미:** -네 / -구나 / -(으)ㄴ가
- **용도:** 친한 사이의 부드러운 평서, 감탄, 독백
- **예문:**
  - 날씨 좋**네**. — "The weather is nice." (soft plain)
  - 벌써 왔**구나**. — "You've arrived already." (recognition)

## 말높임법 3축 (Three Dimensions of Speech Politeness)

### Axis 1: 상대높임 (Listener-Honorific / 상대경어)
- **정의:** 청자에 대한 존대 — 문장 종결어미로 표시.
- **Markers:** 합쇼체/해요체/해체/하소서체/하십시오체/하네체 선택.
- **예문:**
  - 학**생입니다** (합쇼체) — 청자 우대
  - 학**생이에요** (해요체) — 청자 중간 우대

### Axis 2: 주체높임 (Subject-Honorific / 주체경어)
- **정의:** 문장의 주어 (행위자) 에 대한 존대 — 동사 어간에 honorific marker 부착.
- **Markers:**
  - **-(으)시-** (verb stem honorific): 가다 → 가**시**다 (honorific subject)
  - **Honorific nouns (존대 명사):** 사람 → **분**, 집 → **댁**, 이름 → **성함**, 밥 → **진지**
  - **께서** (subject honorific particle): 교수**님께서** 오**셨다** (subject-honorific 가셨다)
- **Conjugation (가다 honorific):**
  | Tense | 합쇼체 | 해요체 | 해체 |
  |---|---|---|---|
  | Present | 가**십니다** | 가**세요** | 가**신다** |
  | Past | 가**셨습니다** | 가**셨어요** | 가**셨다** |
- **예문:**
  - 할머님**께서** 오**셨다**. — "Grandmother has come." (주체높임 + 합쇼체)
  - 교수님**이** 말씀하**셨다**. — "The professor spoke." (주체높임)

### Axis 3: 객체높임 (Object-Honorific / 객체경어)
- **정의:** 행위의 **대상** (목적어/청자) 에 대한 겸양 — 동사를 humble form 으로 대체.
- **Markers (겸양 동사 / Honorific humble verbs):**
  | 일반 동사 (normal) | 객체높임 동사 (humble) | Meaning |
  |---|---|---|
  | 주다 | **드리다** | to give (humble) |
  | 묻다 | **여쭙다** | to ask (humble) |
  | 먹다 | **잡수시다** | to eat (honorific subject/object) |
  | 말하다 | **말씀드리다** | to speak (humble) |
  | 가다 | **모시다** | to accompany (humble) |
  | 보다 | **뵙다** | to see (honorific subject) |
  | 있다 | **계시다** | to be (honorific subject) |
- **예문:**
  - 선생님께 말씀**드렸**습니다. — "I told the teacher." (객체높임 + 합쇼체)
  - 할머님 진지 **모실**까요? — "Shall I serve grandmother's meal?" (객체+주체)

## Three-Axis Combination (3축 동시 적용)

**"교수님께 선물을 드렸어요."**
- 상대높임 = 해요체 (-드렸**어요**)
- 객체높임 = 드리다 (humble give) → 교수님에게 → **교수님께** 받침-drop
- 주체높임 = 없음 (내가 일차 행위자)

**"할머님께서 진지 잡수셨습니다."**
- 상대높임 = 합쇼체 (-**습니다**)
- 주체높임 = -(으)시- → 잡수**시**다 + -께서 (할머님 + honorific particle)
- 객체높임 = 없음 (진지 = honorific noun for 밥)

## Key Points

- **이중 시스템 (dual system):** 종결어미 (상대높임) + 동사 변형 (주체/객체 높임) **동시 적용** 가능. 종결어미만으로는 부적절할 때 동사 honorific 추가.
- **-(으)시- honorific stem:** 받침 有 → 으시 (가 + 시 → 가시, BUT 먹 + 으시 → **먹으시**). 받침 無 → 시 (자다 → 자시, 마시다 → 마시).
- **Honorific nouns (분/댁/성함/진지):** 사람 → 분, 집 → 댁, 이름 → 성함, 밥 → 진지. 받침 有 명사 → 분/댁, 받침 無 → 진지.
- **Humble verbs (드리다/여쭙다/모시다/뵙다):** 동사 자체를 교체. "주다" → "드리다" (humble give to elder).
- **께서 vs 이/가:** 주어가 honorific 인 경우 **께서** (받침 無/ㄹ 변형 없음). 일반 주어 → 이/가 (받침 有/無).
- **Mixing pitfall:** 해요체 + -(으)시- + 객체높임 동사 = "선생님, 제가 말씀**드릴**게**요**" (해요체 + 드리다). 같은 축 유지 필수.

## Cross-language Connections

- **Japanese:** 敬語 3-layer (尊敬語 sonkeigo / 謙譲語 kenjougo / 丁寧語 teineigo) — 한국어 3축과 1:1 대응 (주체=sonkeigo, 객체=kenjougo, 상대=teineigo). 단 일본어는 동사 형태 자체가 교체 (いらっしゃる = honorific go).
- **English:** No grammatical honorifics. Register via vocabulary (would you, please, could you). Honorific nouns (分/댁) 대응 없음.
- **Spanish:** Usted/Tú (2-way pronoun). 동사 활용 변화 (3인칭 usted = 3인칭 동사 활용). 종결어미 honorific 없음.
- **Chinese:** 您 (honorific you) vs 你. 令尊/令堂 (honorific 您的 father/mother) — 한국어 분/성함과 유사. 동사 활용 없음.
- **Korean uniqueness:** 종결어미 honorific (4-6 단계) + 동사 honorific (-시-/드리다) **이중** — 동아시아 최고 정밀.

## Ejemplos

«교수님**께서** 연구실**에** 계**십니다**.' — 주체높임 (께서 + 시 + 계시다) + 합쇼체 (-ㅂ니다).

«선생님, 이거 좀 봐 **주세요**.' — 해요체 + 일반 동사 (대상 낮음).

«할머님**께** 진지 **드리겠**어요.' — 객체높임 (드리다 = humble give) + 주체높임 (께) + 해요체.

«사장님, 보고서 검토**해** 주**시겠**어요?' — 합쇼체 질문형 (시 + 겠 + 습니까) + 주체높임.

«여러분, 입장해 주**십시오**.' — 하십시오체 (격식 명령) + 일반 동사.
