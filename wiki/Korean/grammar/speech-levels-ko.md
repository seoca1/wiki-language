# 한국어 경어법 (Speech Levels)

**Type:** 문법
**Level:** TOPIK 2-3
**Date Added:** 2026-08-08

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 한국어는 화자-청자 관계에 따라 동사 어미가 변하는 **경어법** 보유. 4 대 격식체: 합쇼체 (격식) / 해요체 (일상 존댓말) / 해체 (반말) / 하소서체 (문어).
> - **특징:** 일본어 敬語 (keigo) 와 비슷하지만 더 체계적 + 필수적. 영어 / 스페인어는 경어법 없음.
> - **학습자 우선순위:** 해요체 (가장 빈번) → 합쇼체 (비즈니스) → 해체 (친구 / 가족).
> - **하소서체:** 현대 한국어에서 거의 사용 안 함 (문어 / 종교 텍스트).

---

## 4 대 격식 체계

### 1. 합쇼체 (Formal — 격식체)
- **용도**: 비즈니스, 공식 발표, 뉴스, 군대, 이메일 (격식)
- **종결 어미**: -(으)ㅂ니다 / -습니다
- **예**:
  - "저는 학생**입니다**." (격식 소개)
  - "회의를 시작하**겠습니다**." (격식 발표)
  - "결과를 보고하**였습니다**." (격식 과거)
  - "내일 또 만나**겠습니**다." (격식 미래)

### 2. 해요체 (Polite — 일상 존댓말)
- **용도**: 일상 대화, 친구 부모, 직장 상사,陌生人, 일반 TV / 유튜브
- **종결 어미**: -아/어요 / -어요 / -이에요/예요
- **예**:
  - "저는 학생**이에요**." (일상 소개)
  - "회의를 시작할게**요**." (일상 발표)
  - "밥 먹었**어요**?" (일상 질문)
  - "날씨가 좋**네요**." (일상 감탄)

### 3. 해체 (Plain — 반말)
- **용도**: 친구, 가족, 동생, 자기 일기 / 메모
- **종결 어미**: -는다 / -다 / -아/어 / -(느)ㄴ다 / -냐 / -지
- **예**:
  - "나는 학생**이다**." (반말 소개)
  - "회의를 시작**하자**." (반말 제안)
  - "밥 먹었**어**?" (반말 질문)
  - "날씨가 좋**다**." (반말 진술)

### 4. 하소서체 (Literary — 문어)
- **용도**: 매우 격식적 문어, 기도, 고문서 (현대 한국어 거의 사용 안 함)
- **종결 어미**: -옵 / -사옵 / -나이다 / -옵소서
- **예**:
  - "저**옵**은 학생이옵니다." (격식 문어)
  - "회의를 시작하겠**사옵니**다." (격식 문어)

## 시제 + 경어 결합

각 격식은 과거/현재/미래 시제 결합.

### 합쇼체 + 시제

| 시제 | 형태 |
|---|---|
| 현재 | 학생**입니다** |
| 과거 | 학생**이었습니다** |
| 미래 | 학생**이겠습니다** |

### 해요체 + 시제

| 시제 | 형태 |
|---|---|
| 현재 | 학생**이에요** |
| 과거 | 학생**이었어요** |
| 미래 | 학생**이겠어요** |

### 해체 + 시제

| 시제 | 형태 |
|---|---|
| 현재 | 학생**이다** |
| 과거 | 학생**이었다** |
| 미래 | 학생**이겠다** |

## 동사 활용 예시 (가다 = to go)

| 격식 | 현재 | 과거 | 미래 |
|---|---|---|---|
| 합쇼체 | 가**습니다** | 가**았습니다** | 가**겠습니다** |
| 해요체 | 가**요** | 갔**어요** | 가겠**어요** |
| 해체 | 가**ㄴ다** | 가**았다** | 가**겠다** |

## 인사 (인사하다 = to greet)

| 격식 | 현재 | 과거 |
|---|---|---|
| 합쇼체 | 인사**합니다** | 인사**했습니다** |
| 해요체 | 인사**해요** | 인사**했어요** |
| 해체 | 인사**한다** | 인사**했다** |

---

## 격식 선택 가이드

| 상대 | 격식 | 예 |
|---|---|---|
| 처음 만난 사람 / 고객 | 해요체 | "안녕하**세요**" |
| 회사 상사 / 비즈니스 | 합쇼체 | "안녕하**십니까**" / "보고하**겠습니다**" |
| 친구 (같은 나이) | 해체 | "안녕" |
| 부모 / 어른 | 해요체 | "안녕하**세요**" |
| 연인 (친밀) | 해체 | "오빠, 나 왔**어**" |
| 강의 / 발표 | 합쇼체 | "설명하**겠습니다**" |
| 군대 / 위계 조직 | 합쇼체 | "보고**합니다**" |
| 일기 / 메모 (자기) | 해체 | "오늘은 좋**았다**" |

---

## 한국어 학습자 주의

1. **격식 선택 필수**: 거의 모든 문장에서 화자-청자 관계 명시. 잘못된 격식 = 무례 / 부자연스러움.
2. **해요체 기본**: 대부분의 외국인 학습자는 해요체로 충분. 합쇼체는 비즈니스 / 격식 / 뉴스.
3. **해체 (반말) 조심**: 친한 사이 또는 어린 자녀에게만. 처음 보는 사람에게 해체 = 매우 무례.
4. **음성 변화**: "습니다" 의 연속 발음 "슴니" (자연스러움) vs "습니 다" (부자연).
5. **종결 어미 일관성**: 한 문장 안에서 같은 격식 유지. 격식 혼용 = 부자연 / 촌스러움.

## Ejemplos

«저는 김민수입니다. 서울에서 왔습니다.» — 격식 자기소개 (합쇼체).

«저는 김민수예요. 서울에서 왔어요.» — 일상 자기소개 (해요체).

«나는 김민수야. 서울에서 왔어.» — 친구 / 가족 (해체).

«회의를 시작하겠습니다. 먼저 자료를 검토하겠습니다.» — 비즈니스 발표 (합쇼체).

«회의 시작할게요. 먼저 자료 볼까요?» — 일상 회의 (해요체).

## Cross-language Connections

- **일본어**: 敬語 (경어) 시스템 — 丁寧語 (ていねいご) / 尊敬語 (そんけいご) / 謙譲語 (けんじょうご) / 丁寧語. 한국어 경어법보다 더 복잡 (대상 + 화자 + 청자 모두 고려). 한국어는 화자 + 청자만.
- **스페인어**: tú (반말) / usted (존댓말) 2 단계. usted 는 일부 지역 (콜롬비아, 코스타리카) 에서 일상. 한국어 4 단계보다 단순.
- **영어**: 경어법 없음 (you 하나). 격식 표현은 어조 / 어휘 선택 ("Can I help you?" 격식 vs "What's up?" 비격식).
