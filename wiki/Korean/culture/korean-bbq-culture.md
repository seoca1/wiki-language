# 한국 BBQ 문화 (Korean BBQ Culture)

**Overview:** 한국 BBQ (Korean BBQ) = 한국 고기 (고기) 구이 (구이) 문화. 삼겹살 (삼겹살, samgyeopsal) + 돼지 (돼지) + 소고기 (소고기) + 양념 (양념) + 쌈 (쌈) + 소주 (소주). 한국인은 1인당 연간 약 45 kg 육류 소비. 고기 굽기 + 쌈 싸기 + 회식 (회식) + 모임 (모임) 의 중심.

## Key Points

- **삼겹살 (삼겹살, Samgyeopsal)**: 돼지 등심 (等深) + 삼겹 (三, fat) + 살 (肉, meat). 한국 BBQ 의 상징. 두께 5mm 슬라이스 + 숯불 (炭火) + 된장 (된장) + 고추장 (고추장) + 깻잎 (깻잎). 한자 三 (삼) + 겹 (겹) + 肉 (육) = 삼겹살.
- **돼지 (돼지) BBQ**: 삼겹살 (삼겹살) + 목살 (목살) + 갈비 (갈비) + 항정살 (항정살). 항정살 (항정살) = 돼지 목 부위, 쫄깃쫄깃한 식감. 목살 = 돼지 어깨 부위, 부드러운 식감.
- **소고기 (소고기)**: 꽃등심 (꽃등심) + 안심 (안심) + 등심 (등심) + 차돌박이 (차돌박이) + 육회 (육회). 한우 (한우, Korean beef) = 한국 토종 소. 1인당 약 9 kg 연간 소비.
- **양념 (양념)**: 양념 갈비 (양념 갈비) + 불고기 (불고기) + 돼지 갈비 (돼지 갈비) + 양념장 (양념장) (간장+설탕+마늘+생강). 한자 醬 (장) + 料 (료) = 양념장.
- **쌈 (쌈) 문화**: 상추 (상추) + 깻잎 (깻잎) + 쌈채소 (쌈菜蔬) + 고기 (고기) + 쌈장 (쌈醬) + 마늘 (마늘) + 쌈 싸기. 쌈 = 한국 식사 (食事) 고기 먹는 표준.
- **회식 (회식)**: 직장 (직장) + 동료 (同僚) + 회사 (회사) + 저녁 (저녁) + 고기 (고기) + 술 (술) + 노래 (노래) + 2차 (2차) (bar hopping). 한국 직장 문화의 핵심.
- **식사 방식**: 숯불 (炭火) + 그릴 (그릴) + 손수 (手數) 굽기 + 익힘 (익힘) + 자르기 (자르기) + 젓가락 (젓가락) + 접시 (접시) + 반찬 (반찬) + 밥 (밥) + 비빔밥 (비빔밥).

## Cross-language Connections

- **Coreano**: 한국 BBQ ≈ 한국 치킨 (치킨) + 한국 커피 (커피) — 한국의 핵심 외식 (外食) 산업. 2024년 한국 외식 (外食) 시장 약 100조 원. BBQ 시장 (市場) 약 30조 원.
- **Japonés**: 일본 焼肉 (やきにく, yakiniku) ≈ 한국 BBQ — 동아시아 고기 구이 (肉グリル) 문화. 차이: 일본은 단독 (calm) + 일식 (和食) + 쌈 (쌈) 약함, 한국은 숯불 (숯불) + 쌈 (쌈) + 양념 (양념) + 회식 (회식). 한자 焼 (소) + 肉 (육) = 焼肉 (yakiniku).
- **Chino**: 중국 烤肉 (烤肉, kǎoròu) ≈ 한국 BBQ — 동아시아 고기 양념 (양념) + 구이 (구이). 차이: 한국은 돼지 (돼지) + 쌈 (쌈) + 회식 (회식), 중국은 양 (羊, 양고기) + 양꼬치 (yang-ggochi) + 북방 (北方) 카오로우. 한자 烤 (고) = 火 (화) + 考 (고) = 火 (화) + 양념 (양념).

## 예문 (Ejemplos)

«한국 직장에서 회식 (회食) 은 BBQ + 술 + 장소 (場所) 가 표준. 삼겹살 (삼겹살) + 된장찌개 (된장찌개) + 소주 (소주) + 2차 (다음) 노래방 (노래방) 이 한국 직장인의 표준 야간 코스다.»
(In Korean workplaces, hoesik (company dinner) follows the standard: BBQ + drinks + next venue. Samgyeopsal + doenjang-jjigae + soju + second round at noraebang is the standard Korean worker's evening course.)

«한국 BBQ 의 핵심은 쌈 (쌈) 싸기. 상추 (상추) + 깻잎 (깻잎) + 고기 (고기) + 쌈장 (쌈醬) + 마늘 (마늘) + 밥 (飯) + 들기름 (들기름) 을 본인이 직접 싸서 먹는다. 한 손에 가족 (家族) + 사회 (社會) + 습관 (習慣) 의 결합 (結合).»
(The core of Korean BBQ is wrapping ssam. You wrap lettuce + perilla + meat + ssam paste + garlic + rice + perilla oil yourself. It is the union of family + society + habit in one hand.)

«삼겹살 (삼겹살) 을 숯불 (숯불) 에 구울 때, 처음에는 강 (강) 한 불 (불) + 나중 (나중) 에는 약 (약) 한 불 (불). 익힘 (익힘) = 한쪽 (한쪽) 70% + 반대편 (반대편) 100%. 한국인은 익힘 (익힘) 정도 (정도) 를 직감 (직감) 으로 안다.»
(When grilling samgyeopsal on charcoal, start with strong heat and finish with weak heat. Done = 70% on one side + 100% on the other. Koreans know the doneness intuitively.)
