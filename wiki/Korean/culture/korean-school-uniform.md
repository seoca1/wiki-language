# 한국 교복 문화 (Korean School Uniform)

**Overview:** 한국 교복 (校服, gyobok) = 중학교 (中學校) + 고등학교 (高等學校) 학생 (學生) 의 표준 (標準) 복장 (服裝). 1980년대 의무화 (義務化), 2021년 자율화 (自律化) 전환. 한국 학교 (學校) = 졸업앨범 (卒業冊) + 군복 (軍服) 과의 관계 + 사회 진입 (社會 進入) + 한복 (韓服) + K-패션 (K-fashion) + 한류 (韓流) 의 시작.

## Key Points

- **교복 (校服, Gyobok)**: 한국 학생 (學生) 의 표준 (標準) 복장 (服裝). 중학교 (中學校) + 고등학교 (高等學校) + 사립 (私立) + 2021년 자율화 (自律化). 한자 校 (교) + 服 (복) = 교복.
- **남자 (男子) 교복**: 상의 (上衣) + 하의 (下衣) + 넥타이 (necktie) + 서츠 (shirt) + 자켓 (jacket) + 바지 (pants). 봄·가을·여름·겨울 + 반팔 셔츠 + 점퍼 + 코트 + 목도리 + 장갑.
- **여자 (女子) 교복**: 상의 (上衣) + 하의 (下衣) + 치마 (치마) + 블라우스 (blouse) + 리본 (ribbon) + 넥타이 (necktie) + 자켓 (jacket) + 봄·가을·겨울 + 카디건 (cardigan) + 점퍼 (jumper) + 스타킹 (stocking) + 구두 (구두).
- **졸업앨범 (卒業冊)**: 한국 고등학교 (高等學校) 3학년 (3年) 졸업 (卒業) 앨범 (album) + 사진 (寫眞) + 단체 (團體) + 사진관 (寫眞館) + 흑백 (黑白) + 컬러 (color) + 인생 (人生) + 추억 (追憶) + 연인 (戀人) + 친구 (親舊) + 가족 (家族) + 사회 (社會) + 인생 (人生).
- **군복 (軍服) 과의 관계**: 교복 (校服) + 군복 (軍服) = 표준 (標準) 복장 (服裝) + 사회 (社會) 단계 (段階) + 학교 (學校) → 직장 (職場) → 인생 (人生) 의식 (意識). 한국 남성은 교복 → 군복 → 사회 진출의 표준 의상 계기.
- **문화 (文化) 영향 (影響)**: 교복 (校服) + K-드라마 (K-Drama) + 영화 (映畵) + 한류 (韓流) + 해외 (海外) + 한복 (韓服) + K-패션 (K-fashion) + K-컬처 (K-Culture) + 일본 (日本) + 대만 (臺灣) + 동남아 (東南亞) + 한류 (韓流) + 한복 (韓服) + K-POP.

## Cross-language Connections

- **Coreano**: 한국 교복 (校服) ≈ 한국 졸업앨범 (卒業冊) + K-드라마 (K-Drama) — 한국 학교 (學校) + 사회 (社會) + 한류 (韓流) + K-패션 (K-fashion) + K-드라마 (K-Drama) 의 시작 (始作). 한국 현대사 (現代史) + 사회 (社會) + K-POP 의 영향 (影響).
- **Japonés**: 일본 制服 (せいふく, seifuku) ≈ 한국 교복 (校服) — 동아시아 학교 (學校) 표준 (標準) 의상 (衣裳). 차이: 일본은 더 다양한 디자인, 한국은 1980~2020 표준 화이트 셔츠 + 네이비 자켓. 한자 制 (제) + 服 (복) = 制服 (制服).
- **Chino**: 중국 校服 (校服, xiàofú) ≈ 한국 교복 (校服) — 동아시아 학교 (學校) 표준 (標準) 의상 (衣裳). 차이: 중국 = 운동복 (track suit) + 두꺼운 폴로 셔츠, 한국 = 자켓 + 셔츠 + 넥타이 + 치마/바지. 한자 校 (교) + 服 (복) = 校服 (校服).

## 예문 (Ejemplos)

«한국 고등학교 (高等學校) 학생 (學生) 은 교복 (校服) + 군복 (軍服) + 사회 진출 (社會 進出) 의 표준 의상 (衣裳) 계기 (契機) 를 경험한다. 졸업 (卒業) 후 군 (軍) + 직장 (職場) + 인생 (人生) 에서 표준 (標準) 복장 (服裝) 유지 (維持).»
(Korean high school students experience the standard clothing transition of school uniform + military uniform + entering society. After graduation, they maintain standard clothing in military, workplace, and life.)

«한국 졸업앨범 (卒業冊) 은 흑백 (黑白) + 컬러 (colour) + 인생 (人生) + 추억 (追憶) 의 사진 (寫眞) 들. 3학년 (3年) + 친구 (親舊) + 연인 (戀人) + 가족 (家族) + 졸업 (卒業) 의 시기 (時期) 의 상징 (象徵).»
(Korean yearbooks are black-and-white + color + life + memory photos. They symbolize the graduation period among 3rd-year students, friends, lovers, and family.)

«K-드라마 (K-Drama) + 영화 (映畵) 에 한국 교복 (校服) + 한복 (韓服) + 군복 (軍服) 이 등장 (登場) 하면, 세계 (世界) 의 시청자 (視聽者) 들에게 한국 학교 (學校) + 사회 (社會) + 인생 (人生) 을 보여준다. 한류 (韓流) 의 상징 (象徵).»
(When Korean school uniform + hanbok + military uniform appear in K-drama + film, they show Korean school + society + life to world viewers. A symbol of the Korean Wave.)
