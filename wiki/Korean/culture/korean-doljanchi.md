# 돌잔치 (Doljanchi — First Birthday)

**Overview:** 돌잔치 (一周年 宴, Doljanchi) = 아기 첫 생일 (1년) 잔치. 한국 잔치 중 가장 큰 규모. 돌잡이 (一周年 抓, doljabi) 라는 미래 예측 의식이 핵심. 2024년 기준 호텔 돌잔치 평균 비용 200~500만 원.

## Key Points

- **돌잔치 (一周歲 宴, Doljanchi)** — 아기가 태어난 지 1년 (한국 나이 2세) 잔치. 한자 "一周年 (돌) + 宴 (잔치)". 양력/음력 모두 가족이 결정. 보통 양력 부모 생일과 가까이.
- **돌잡이 (一周年 抓, Doljabi)** — 아기 앞에 여러 상징 물건 (책, 돈, 쌀, 붓, 실, 가위, 청동잔, 저울, 인형, 청동 거울, 활, 청동 정화기) 을 놓고 아기가 먼저 잡는 것으로 장래 직업·성공 예측. 책 = 학자, 돈 = 부자, 쌀 = 농부, 붓 = 화가·작가, 청동잔 = 부농.
- **상차림 (상차림)**: 떡 (떡) + 한과 (韓果) + 다식 (茶食) + 과일 (과일) + 식혜 (식혜, rice punch) + 갈비찜 (갈비찜) + 잡채 (잡채) + 미역국 (미역국) 등 20~30가지. 일부는 4대 반찬 (4대 반찬) 으로 축소.
- **한복 (韓服)**: 아기 + 부모 + 조부모 모두 한복 착용. 아기 두루마기 (두루마기) + 갓 (갓, 갓) + 긴 저고리. 매우 화려.
- **돈 (돈) + 금반지**: 친척이 아기에게 금반지 (금반지) + 현금 (10~50만 원) 선물. 봉투 (돈 봉투) 사용.
- **현대 변화**: 호텔 돌잔치 (호텔 돌잔치) + 사진·영상 촬영 + 유튜브 라이브 송출. 결혼식 수준의 화려한 행사. 웨딩홀·호텔 대관 + 스튜디오 사진 + 영상. 2024년 기준 평균 비용 200~500만 원.

## Cross-language Connections

- **Coreano**: 돌잔치 ≈ 백일 (100일). 차이: 백일 = 생존 의식, 돌잔치 = 성장 + 미래 (돌잡이) 의식. 둘 다 잔치이지만 돌잔치 = 더 큰 축하.
- **Japonés**: 일본 初節句 (はつぜく, hatsuzeku, 男児 5/5 / 女児 3/3) ≈ 한국 돌잔치 — 첫 명절. 차이: 일본은 성별별 첫 명절 (탄고노섣쿠 / 히나마쓰리), 한국은 성별 무관. 일본 初誕生 (はつたんじょう, 1st birthday) 은 한국보다 작은 규모.
- **Chino**: 중국 抓週 (抓週, zhuāzhōu) = 한국 돌잡이 — 같은 미래 예측 의식. 차이: 한국은 돌잔치 + 돌잡이 = 종합, 중국은 抓週 의식만 (현대 거의 사라짐). 한자문화권 돌잡이 - 책, 돈, 쌀 같은 상징.

## 예문 (Ejemplos)

«한국 돌잔치에서 가장 주목받는 순간은 돌잡이다. 아기가 책 을 집으면 학자, 돈 을 집으면 부자, 쌀 을 집으면 농부라고 해석한다.»
(The most-watched moment at a Korean first birthday is the doljabi. If the baby grabs a book, it means scholar; if money, it means rich; if rice, it means farmer.)

«현대 한국에서 돌잔치는 호텔·웨딩홀 에서 열린다. 한복 + 화려한 상차림 + 친척 100명 + 영상 촬영. 비용은 200~500만 원 정도다.»
(In modern Korea, first birthday parties are held at hotels or wedding halls. Hanbok + elaborate table + 100 relatives + videography. Costs run 2,000,000-5,000,000 won.)

«아기가 부적 (부적) + 금반지 (금반지) + 가발 (가발, 가체) + 한복 + 갓 (갓) 을 차려입고 가족 앞에서 앉는다. 친척들이 줄을 서서 돈을 놓고 간다.»
(The baby wears a talisman + gold ring + wig top-knot + hanbok and sits before the family. Relatives line up to give money.)
