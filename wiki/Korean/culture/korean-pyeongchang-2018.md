# 2018 평창 동계올림픽 (PyeongChang 2018 Winter Olympics)

**Overview:** 2018년 2월 9~25일 평창 (平昌) 동계올림픽 (冬季 奧林匹克, 2018 PyeongChang Winter Olympics) 개최. 강원도 평창 (平昌) + 강릉 (江陵) + 정선 (旌善) 8개 종목 (snowboard, ski, bobsled, ice hockey, etc.). 통일 응원 (統一 應援) + 태극기 (太極旗) + 남북 (南北) + 금메달 (金牌) = 한국 현대사 (現代史) 의 통일 (統一) 의식 (意識) 최고조.

## Key Points

- **평창 (平昌, Pyeongchang)**: 강원도 (江原道) 평창 (平昌) + 강릉 (江陵) + 정선 (旌善) 3개 시 (市) 협동 대회. 8개 종목 (項目) + 15개 세부 (細部) + 102개 메달 (medal) 결정. 한자 平 (평) + 昌 (창) = 평창 (평화 + 창성).
- **개최 (開催) 일정**: 2018년 2월 9일 (금) ~ 25일 (일). 17일간 (日間). 91개국 (NOCs) 2,920명 (名) 선수 (選手) + 3억 (億) 시청 (視聽). 한국 브랜드 (brand) + 한류 (韓流) 의 정점.
- **남북 (南北) 응원 (應援)**: 2018년 1월 20일 남북 (南北) 합의 (合意) + 통일 (統一) 응원 (應援) + 태극기 (太極旗). 2월 9일 개회식 (開會式) 에 남북 (南北) 팀 합동 (合動) 입장 (入場) + 태극기 (太極旗) 게양. 통일 (統一) 상징 (象徵) 최고.
- **한국 (韓國) 메달 (medal)**: 2018년 한국 (韓國) 17개 메달 (medal) = 금 (金) 5 + 은 (銀) 8 + 동 (銅) 4. 쇼트트랙 (short track) + 스피드 스케이팅 (speed skating) + 스노보드 (snowboard) + 컬링 (curling). 김다현 (金다현) + 최민정 (崔珉晶) + 빙상 (氷上) 메달 (medal).
- **북 (North) 한국 (Korea) 선수 (選手)**: 북한 (北韓) 22명 (名) + 응원단 (應援團) + 여자 아이스 하키 데모 (demo) + 통일 (統一) 의식 (意識). 평창 (平昌) 동계올림픽 (冬季 奧林匹克) 의 가장 감동적인 순간 (瞬間) 중 하나.
- **문화 (文化) 효과 (效果)**: 평창 (平昌) = 한국 (韓國) 브랜드 (brand) + 한류 (韓流) + K-POP + K-문화 (文化) + 사례 (實例) 세계 (世界) 3위 (位) + 관광 (觀光) + 한복 (韓服) + 케이크 (cake) + K-뷰티 (K-Beauty).

## Cross-language Connections

- **Coreano**: 2018년 평창 (平昌) 동계올림픽 (冬季 奧林匹克) ≈ 1988년 서울 올림픽 (奧林匹克) + 2002년 월드컵 (World Cup) — 한국 3대 스포츠 축제 (祝祭) + 통일 (統一) 의식 (意識) 정점 (頂點).
- **Japonés**: 일본 나가노 (長野, 1998) 동계올림픽 ≈ 한국 평창 (平昌, 2018) 동계올림픽 — 동아시아 동계올림픽 사례 (事例). 차이: 나가노는 일본 단독 (單獨) + 일본 만 (万) 우승 (優勝), 평창은 한일 (韓日) + 남북 (南北) 통일 (統一) 응원 (應援). 한자 冬 (동) + 季 (계) = 冬季 (동계, winter).
- **Chino**: 중국 베이징 (北京) 2022년 동계올림픽 (北京 冬奧) ≠ 한국 평창 (平昌) 2018 — 중국은 단독 (單獨) + 중국 (中國) 만 (萬) 개최 (開閉). 한국은 남북 (南北) + 한일 (韓日) + 통일 (統一) 응원 (應援). 한자 南 (남) + 北 (북) + 統 (통) + 一 (일) = 남북 통일 (南北 統一).
