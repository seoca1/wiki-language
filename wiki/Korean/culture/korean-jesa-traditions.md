# 차례 (Jesa — Ancestral Memorial Rites)

**Overview:** 차례 (茶禮, Charye/Jesa) = 한국 전통 조상 (祖先) 의식. 제사 (祭祀) 의 가장 일반적 형태. 한자 茶 (茶) + 禮 (禮) = 차례 (charye, tea ceremony). 한국 명절 (설날·추석) + 음력 1·15일 + 사망일 (忌日) 마다 진행. 차례상 (茶禮床) 에 음식 진설 (陳設).

## Key Points

- **차례 (茶禮, Charye)**: 음력 1일 (설날), 15일 (추석), 忌日 (기일, 사망일) 에 가족이 신위 (神位) 앞에서 진행하는 의식. 명절 = 차례 (charye), 사망일 = 제사 (jesa). 같은 의식, 이름 다름.
- **차례상 (茶禮床, Charyesang)**: 제물 (祭物) 을 진설 (陳設) 한 식탁. 진설 (陳設) 순서 엄격: 神位 (神位) → 제사주 (祭酒, 막걸리) → 제수 (祭需) → 국 (국) → 반찬 (반찬) → 떡 (떡) → 과일 (과일). 한자 茶 (차) + 禮 (례) + 床 (상) = 차례상.
- **음식 진설 (陳設)**: 설날 = 떡국 (떡국) + 전 (전) + 약과 (약과) + 과일. 추석 = 송편 (송편) + 약과 (약과) + 배 (배) + 감 (감) + 밤 (밤) + 대추 (대추) + 술 (술). 제사 = 국 (국) + 반찬 + 생선 + 고기 + 과일.
- **식순 (式順)**: 제사 시작 = 제사주 (祭酒) 따르는 의식. 아버지가 主禮 (주례, master of ceremony). 아들·며느리·딸 순서로 절 (제). 절 = 큰절 (跪拜) + 합장 (合掌). 漢 (한) + 家 (가) = 漢家 (한가, Korean-style ancestral).
- **성묘 (省墓)**: 제사 후 조상 묘 (墓) 방문. 매주 (毎週) 잘 가는 가족 = 마당 (家) 직계 (直系). 한자 省 (성) + 墓 (묘) = 성묘 (省墓) - 허술 (虛) 묘 (墓) 손질 (손질).
- **현대 변화**: 2024년 도시 가족은 종갓집 (宗家) 또는 큰아버지 (큰아버지) 집에서 차례. 손녀 (손녀) 가 차례 여성 · 제수 (祭需) 관리. 친척 (親戚) + 가족 (家族) 4~5세대 모여 진행.

## Cross-language Connections

- **Coreano**: 차례 ≈ 제사 — 둘 다 같은 의식. 차이: 차례 = 명절, 제사 = 음력 忌日 (사망일). 같은 진설 (陳設) + 같은 식순 (式順). 한자 茶 (茶) + 禮 (禮) = 차례.
- **Japonés**: 일본 お盆 (おぼん, o-bon, 8/13~15) ≈ 한국 차례 — 둘 다 조상 (祖先) 의식. 차이: 일본 お盆 = 도시락 (精霊馬) + 불꽃 (花火), 한국 차례 = 神位 (神位) + 차례상 (茶禮床) + 진설 (陳設). 일본 お盆 (お盆) 의 단어와 의식은 한국과 차이.
- **Chino**: 중국 祭祖 (祭祖, jìzǔ) ≈ 한국 차례 — 같은 조상 의식. 차이: 한국 = 차례 (茶禮) + 진설 (陳設) + 절 (제), 중국 = 祭祖 + 牌位 (牌位) + 烧纸 (소지, 소지). 한자 祭 (제, ancestral) + 祖 (조, ancestor) = 모두 조상 의식.

## 예문 (Ejemplos)

«한국 추석 차례 상에는 송편 (松片) + 약과 (藥果) + 배 (梨) + 감 (柿) + 밤 (栗) + 대추 (大棗) + 술 (酒) 을 진설 (陳設) 한다. 아버지가 주례 (主禮) 를 맡는다.»
(Korean Chuseok ancestral tables display songpyeon, yakgwa, pears, persimmons, chestnuts, jujubes, and wine. The father serves as the master of ceremony.)

«도시 가족은 명절에 본가 (娘家) 또는 종갓집 (宗家) 으로 내려가 차례를 지낸다. 손녀 (孫女) + 며느리 (兒婦) 가 차례 음식 (茶禮 飮食) 준비를 맡는다.»
(Urban families go to the family home or head house for ancestral rites on holidays. Granddaughters and daughters-in-law prepare the ritual food.)

«한국 차례의 한자 茶 (茶) + 禮 (禮) 의 어원은 고려 (高麗) 시대부터 '茶 (tea)' 가 제물 (祭物) 의 첫 번째 항목이었기 때문이다. 차 (茶) + 예절 (禮節) = 차례 (茶禮).»
(The Korean rite name charye (茶禮) originates from the Goryeo era, when tea was the first ritual offering. Tea + ritual = charye.)
