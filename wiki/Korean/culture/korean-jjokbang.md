# 한국 찜질방 (Korean Jjimjilbang)

**Overview:** 찜질방 (찜질방, Jjimjilbang) = 한국 전통 목욕탕 (목욕탕) + 사우나 (sauna) + 찜질 (찜질) 복합 (複合) 시설. 한자 汗蒸 (한증) + 方 (방) = 한증방 (찜질방). 1년 약 2000만 명 (2024) 이용. 주요 이용 객체 (對象) = 가족 (家族) + 직장 (직장) + 동호회 (동호회) + 여행자 (旅行者).

## Key Points

- **찜질방 (찜질방, Jjimjilbang)**: 한국 전통 목욕탕 + 사우나 + 한증 (汗蒸) + 헬스 (헬스) + 오락실 (오락실) + 식당 (식당) + 숙박 (숙박) 복합 시설. 24시간 (時間) 영업. 입장료 (입장료) 12,000~18,000원 (2024년). 한자 汗蒸 (한증) + 方 (방) = 한증방.
- **목욕 (목욕)**: 남탕 (남탕) + 여탕 (여탕) 분리. 탈의실 (탈의실) + 사우나 (sauna) + 온천 (溫泉) + 냉천 (冷泉) + 약초탕 (藥草湯) + 숯불 (숯불) + 솔잎 (솔잎) + 버드나무 (버드나무) + 소나무 (소나무) 한증.
- **한증 (汗蒸)**: 건식 (乾式) + 습식 (濕式) + 반석 (반석) + 숯 (숯) + 소금 (소금, 鹽) + 백염 (백염) + 황토 (黃土) + 솔잎 (솔잎) + 옥 (옥) 등 다양한 한증실.
- **복장 (服裝)**: 찜질방 (찜질방) 안 = 잠옷 (잠옷) + 운동복 (운동복) + 한증복 (한증복) + 수건 (수건) + 베개 (베개). 여성 (女性) = 잠옷 (잠옷) + 니트 (니트) + 스카프 (스카프). 남성 (男性) = 잠옷 + 반바지 (반바지).
- **편의 (便宜) 시설**: 식당 (식당) + 카페 (카페) + 헬스 (헬스) + 오락실 (오락실) + PC방 (PC방) + 노래방 (노래방) + 영화 (영화) + 안마 (안마) + 족구 (족구) + 어린이놀이터 (어린이놀이터) + 수면실 (수면실) + 매트 (매트) + 무릎담요 (무릎담요).
- **숙박 (宿泊)**: 새벽 (새벽) + 심야 (심야) + 장거리 (장거리) 여행자 (旅行者) + 술 취한 (술 취한) 친구 (친구) + 돈 (돈) 없는 여행자 (여행자) = 숙박 (宿泊) 으로 이용 (이용). 8~12시간 (時間) 이용 (이용) = 12,000~18,000원 (원).

## Cross-language Connections

- **Coreano**: 한국 찜질방 ≈ 한국 목욕탕 (목욕탕) + 사우나 (sauna) — 한국 욕실 (浴室) 문화의 양대 축. 차이: 목욕탕 = 씻기 (씻기) + 목욕 (목욕) + 온천 (溫泉), 찜질방 = 사우나 (사우나) + 한증 (汗蒸) + 복합 (複合) 시설. 한국 도시 (都市) 의 표준 (標準) 가족 (家族) 여가 (餘暇).
- **Japonés**: 일본 温泉 (おんせん, onsen) + 銭湯 (せんとう, sentō) ≈ 한국 찜질방 — 동아시아 목욕 (沐浴) 문화. 차이: 일본 温泉 (溫泉) = 자연 (自然) 온천 (溫泉) + 露天 (노천) + 목욕 (목욕), 한국 찜질방 (찜질방) = 인공 (人工) + 室内 (실내) + 한증 (汗蒸) + 복합 (複合). 한자 温 (온) + 泉 (천) = 溫泉 (온천).
- **Chino**: 중국 澡堂 (澡堂, zǎotáng) + 桑拿 (桑拿, sāngná) ≈ 한국 찜질방 — 동아시아 목욕 (沐浴) + 사우나 (사우나) 문화. 차이: 중국 = 桑拿 (사우나) + 简易 (간이) + 회사 (公司), 한국 = 汗蒸 (한증) + 複合 (복합) + 가족 (家族) + 旅行 (여행). 한자 澡 (조) + 堂 (당) = 澡堂 (목욕탕).
