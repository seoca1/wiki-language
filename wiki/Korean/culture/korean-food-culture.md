# Korean Food Culture: Banchan and Table Setting

**Overview:** Korean meals are built around banchan (반찬) — small shared side dishes that accompany rice and main courses, creating a communal, abundant table.

## Key Points

- **Banchan (반찬)**: Small side dishes served with every meal. Number varies by restaurant (3-20) and home. Common types:
  - **김치 (gimchi)**: Fermented vegetables (napa cabbage, radish, cucumber) — foundational Korean food
  - **나물 (namul)**: Seasoned vegetables (spinach, bean sprouts, fernbrake)
  - **찌개/국 (jjigae/guk)**: Stew/soup — doenjang jjigae, kimchi jjigae, sundubu jjigae
  - **볶음 (bokkeum)**: Stir-fried dishes — japchae, kimchi bokkeum
  - **전 (jeon)**: Pan-fried pancakes — kimchi jeon, pajeon
- **Ssam (쌈)**: Wraps — meat + lettuce leaf + ssamjang (된장) sauce. Interactive eating style.
- **Table Setting (상차림)**: Multiple small bowls arranged around main dish. Spoon (숟가락) on right, chopsticks (젓가락) on left, both flat.
- **Drinking Etiquette**: Two hands when pouring for elders/seniors. Turn-taking. 받침 (turn) system for senior/junior.
- **Jeong (정)**: Emotional bond expressed through shared meals. Important cultural concept.

## Variantes regionales

- **서울/수도권 (capital)**: 현대적 상차림 + 다양한 음식. 김치 종류 적음 (보관 편의성), 신선한 나물. 프리미엄 한식뷔페 (만원대).
- **경상도 (부산/대구)**: 짜고 매운 음식. 해산물 풍부 (부산). 돼지국밥 (밀양), 콩나물국, 멸치볶음. 신선한 짠지 (마른 반찬) 보존법 발달.
- **전라도 (광주/목포)**: 음식 중심 (정 = emotional bond). 담백하고 깊은 맛. 대표: 콩나물국, 된장찌개, 떡갈비. 음식 축제 (광주 김치축제).
- **제주도**: 해산물 중심. 옥돔구이, 고등어회, 해산물찌개. 해녀 (해산물 채취 여성) 문화. 돼지고기 흑돼지 BBQ.
- **북한**: 한국 전통 음식 보존. 김치 / 된장 의존. 라면 (北韓 라면) 유명. 부족한 식량 → 통조림 의존.

## Cross-language Connections

- **Spanish**: 스페인 tapas (소형 안주) 와 banchan 유사. 점심/저녁 전 tapas + 와인. 음식을 나눠 먹는 문화. 다만 tapas = 1-2개 작은 안주, banchan = 5-20개 반찬.
- **Japanese**: 일본 定食 (teishoku, set meal) — 반찬 (小鉢 kobachi) 작은 접시. 1-3개 반찬. 일본 어법 膳 (zen) = 식기 (식사). 문화적으로 유사하나 양 적음.
- **English**: Western "side dishes" (보통 1-2개) + main course. 한국 banchan 5-20개 와 비교 불가. 가장 적은 양. Korean dinner = banchan + rice + soup + main.

## Ejemplos

1. **일반 가정 식사 (점심)**: 밥 (rice) + 된장찌개 + 계란말이 + 김치 2종 + 멸치볶음 + 콩나물 = 6 반찬. 가족 4명, 정원 테이블. 수저 (숟가락 + 젓가락).
2. **삼겹살 (BBQ) 회식**: 쌈 (lettuce) + 상추 + 깻잎 + 마늘 + 된장 + 쌈장 + 밥 + 여러 반찬 (김치 2-3종, 계란찜, 콩나물, 어묵). 직접 싸서 먹는 interactive eating.
3. **경상도 할매 식당 (부산)**: 돼지국밥 + 깍두기 + 부추무침 + 양념게장. 짠지 (마른 반찬) 5종. 진하고 짠 맛. 할머니 손맛.
