# 한국 소주 문화 (Korean Soju Culture)

**Overview:** 소주 (燒酒, soju) = 한국 전통 증류주 (蒸溜酒). 한국에서 1년 약 90억 병 (瓶) 소비 = 약 22ℓ 1인당. 2024년 진로 (진로, HiteJinro) + 롯데 (Lotte) + 처음처럼 (Cheoeum-cheoreom) = 3대 브랜드. 합성 알코올 (알코올) + 보리 (보리) + 쌀 (쌀) + 감자 (감자) 원료. 소맥 (소맥) = 소주 + 맥주 (맥주) 혼합.

## Key Points

- **소주 (燒酒, Soju)**: 酒 (주) = 술 (술), 燒 (소) = 태우다 (태우다) = 증류 (蒸溜). 한국 전통 증류주 (蒸溜酒). 20~25% 알코올 (alcohol). 진로 (진로, Jinro) + 처음처럼 (처음처럼, Cheoeum-cheoreom) + 좋은데이 (좋은데이, Good Day) + 참이슬 (참이슬, Chamisul). 한자 燒 (소) + 酒 (주) = 소주.
- **소맥 (소맥, somaek)**: 소주 (소주) + 맥주 (맥주) 혼합. 일반 비율 = 소주 1병 + 맥주 1병 (소주 : 맥주 = 5:5). 한국 사람들이 술게임 (술게임) 중 가장 즐겨 마시는 혼합 음료. 한자 燒 (소) + 麥 (맥) = 소맥.
- **술게임 (술게임)**: 한국 술자리 (술자리) 의 필수 진행. 눈치 (눈치) + 능력 (能力) + 제비뽑기 (제비뽑기) + 369 (3·6·9) + 눈치게임 (눈치게임) + 병뚜껑 게임 (병뚜껑 게임) + 진실게임 (진실게임) + 벌칙 (벌칙).
- **술자리 (술자리) 에티켓 (etiquette)**: 어른 (어른) + 연장자 (연장자) + 상사 (상사) + 선배 (선배) 가 먼저 잔 (잔) 따르기 (따르기). 눈치 (눈치) + 격식 (격식) + 반말 (반말) 사용 자제 (자제). 받침 (받침) + 양손 (양손) + 술 따르기.
- **코스 (코스)**: 1차 (1차) 식당 (식당) + BBQ (BBQ) + 2차 (2차) 술집 (술집) + 3차 (3차) 노래방 (노래방) + 4차 (4차) 펍 (펍) + 5차 (5차) 길거리 (길거리) 분식 (분식). 한국 직장 회식 (회식) 의 표준.
- **술 취향 (취향)**: 20대 이하 (이하) = 병 소주 (병 소주) + 음료 (음료) 와 소맥 (소맥) 혼합. 30~40대 = 한잔 (한잔) + 혼자 (혼자) 약 (약) 한 술 (술). 50대+ = 막걸리 (막걸리) + 전통주 (傳統酒) 선호. 여성 (女性) = 소맥 (소맥) + 과일 음료 (fruit drink) + 34% 도수 (도數) 선호.

## Cross-language Connections

- **Coreano**: 한국 소주 ≈ 한국 막걸리 (막걸리) — 한국 전통주 (전통주) 의 양대 축. 차이: 소주 = 증류 (蒸溜) + 20% 도수, 막걸리 = 발효 (醱酵) + 6% 도수. 한국만 (東아시아) 에서 소맥 (소맥) 독특 (獨特) 문화.
- **Japonés**: 일본 焼酒 (しょうちゅう, shōchū) ≈ 한국 소주 — 동아시아 증류주 (蒸溜酒). 차이: 일본 shōchū = 쌀 (米) + 보리 (麦) + 고구마 (芋) + 黑糖 (黒糖) = 多 다 원료, 한국 소주 = 합성 (合成) + 보리 (보리) + 쌀 (쌀) + 감자 (감자). 한자 燒 (소) + 酒 (주) = 같은 어원.
- **Chino**: 중국 白酒 (白酒, báijiǔ) ≠ 한국 소주 — 동아시아 증류주 (蒸溜酒). 차이: 중국 白酒 = 高粱 (고량) + 50% 도수 + 강 (强) 향 (향), 한국 소주 = 合成 (합성) + 20% 도수 + 약 (약) 향 (향). 중국은 小杯 (小杯) + 礼 (禮), 한국은 1병 (1瓶) + 飲食 (음식) + 잔 (잔) 문화.
