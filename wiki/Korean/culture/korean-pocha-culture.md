# 한국 포장마차 문화 (Korean Pocha Culture)

**Overview:** 포장마차 (포장마차, pocha) = 포장 (包裝) + 마차 (馬車). 한국 식당 + 거리 (거리) 에서 야간 (夜間) + 소주 (소주) + 안주 (안주) + 분식 (分食) + 매력 (魅力) + 인생 (人生) 의 냄새 (냄새) 가 나는 떠다니는 식당 (食堂) + 술집 (술집). 2024년 한국 포장마차 (포장마차) = 약 30,000+ 개 (개). 야간 (夜間) + 어르신 (어르신) + 청년 (靑年) + 외국인 (外國人) + 1인 (1人) + 회식 (회食) + 술자리 (술자리).

- **환경 (環境)**: 포장마차 (포장마차) = 자동차 (自動車) + 트럭 (트럭) + 휴대 (휴대) + 천막 (천막) + 테이블 (테이블) + 의자 (의자) + 조명 (照明) + 간판 (간판) + 족자 (족자) + 메뉴 (메뉴) + 어묵 (어묵) + 꼬치 (꼬치) + 라면 (라면) + 맥주 (맥주) + 소주 (소주).
- **메뉴 (메뉴)**: 어묵 (어묵) + 꼬치 (꼬치) + 라면 (라면) + 만두 (만두) + 떡볶이 (떡볶이) + 순대 (순대) + 어패류 (어패류) + 김 (김) + 조개 (조개) + 맥주 (맥주) + 소주 (소주) + 동동주 (동동주) + 막걸리 (막걸리) + 헛개수 (헛개수).

## Cross-language Connections

- **Coreano**: 한국 포장마차 (포장마차) ≈ 한국 술집 (술집) + 식당 (식당) + 노점상 (노점상) + 시장 (시장) — 한국 외식 (外食) + 주류 (酒類) 산업 (產業) 의 핵심 (核心). 한국 직장 (직장) + 회식 (회食) + 술자리 (술자리) 의 표준 (標準).
- **Japonés**: 일본 屋台 (やたい, yatai) ≈ 한국 포장마차 (포장마차) — 동아시아 노점 (露店) + 노상 (路上) + 음식 (飮食) + 술 (술) 문화 (文化). 차이: 일본 屋台 (야타이) = 하카타 (博多) + 1~6席 (席) + 固定 (고정) + 夜 (야) + 豚骨 (돈코쓰) 라멘 (라면), 한국 포장마차 (포장마차) = 이동 (이동) + 5~10席 (席) + 가변 (가변) + 밤 (밤) + 어묵 (어묵) + 라면 (라면). 한자 屋 (옥) + 臺 (대) = 屋台 (야타이).
- **Chino**: 중국 街边 (街邊, jiē biān) + 排档 (排檔, páidàng) ≈ 한국 포장마차 (포장마차) — 동아시아 노점 (露店) + 노상 (路上) + 음식 (飮食) + 술 (술) 문화 (文化). 차이: 중국 排档 (배당) = 街 (거리) + 简 (간) + 焚 (분) + 烤 (구) = 夜 (야) + 簡 (간) + 烤 (구), 한국 포장마차 (포장마차) = 포장 (포장) + 마차 (마차) = 夜 (야) + 移動 (이동) + 親 (친) + 近 (근). 한자 街 (가) + 邊 (변) = 街邊 (거리).
