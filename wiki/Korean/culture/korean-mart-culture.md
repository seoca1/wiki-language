# 한국 마트 문화 (Korean Mart Culture)

**Overview:** 한국 마트 (mart) = 대형마트 (大型mart) + 재래시장 (在來市場) + 슈퍼마켓 (supermarket) + 편의점 (convenience store) + 백화점 (백화점). 2024년 한국 유통 (流通) 시장 약 700조 원. 재래시장 (전통시장) + 대형마트 (대형마트) + 슈퍼마켓 (슈퍼) + 편의점 (편의점) + 백화점 (백화점) = 한국 식료품 (食糧) 구매 (購買) 의 5대 채널.

## Key Points

- **대형마트 (大型mart)**: 이마트 (E-Mart, 신세계) + 홈플러스 (Homeplus, BND) + 코스트코 (Costco) + 트레이더스 (Traders) + 메가마트 (Megamart). 1993년 이마트 (E-Mart) + 1997년 홈플러스 (Homeplus) + 1994년 롯데마트 (Lotte Mart). 1년 (1年) 매출 (賣出) 약 20조 원 (2024). 한자 大 (대) + 型 (형) + mart = 대형마트.
- **재래시장 (在來市場)**: 광장시장 (廣場市場) + 남대문시장 (남대문시장) + 동대문시장 (東大門市場) + 통인시장 (通仁市場) + 망원시장 (망원시장) + 영동시장 (永東市場). 전통 (傳統) 시장 (市場) + 정육 (正肉) + 청과 (靑果) + 의류 (衣類) + 활기 (活氣). 8,000+ 시장 (市場) + 200만 명 (名) 고용 (雇用). 한자 在 (재) + 來 (래) + 市 (시) + 場 (장) = 재래시장.
- **편의점 (便利店)**: GS25 + CU (CU) + 7-Eleven (세븐일레븐) + Emart24 (이마트24). 24시간 (時間) 영업 + 도시 (都市) + 거주 (居住) + 야간 (夜間) + 1인 (1人) + 주말 (주말) + 음료 (음료) + 즉석 (即席) + 도시락 (lunchbox). 약 60,000+ 매장 (매장) (2024). 한자 便 (편) + 利 (이) + 店 (점) = 편의점.
- **슈퍼마켓 (supermarket)**: 노브랜드 (No Brand) + 피코크 (Pikok) + 이마트 에브리데이 (emart everyday) + 홈플러스 익스프레스 (Homeplus Express). 도시 (都市) + 소규모 (小規模) + 가정 (家庭) + 매일 (매일) + 식료품 (食糧).
- **백화점 (百貨店)**: 신세계 (Shinsegae) + 롯데 (Lotte) + 현대 (Hyundai) + 갤러리아 (Galleria) + AK (AK). 명품 (名品) + 의류 (衣類) + 식료품 (食糧) + 5성급 (5星級) + 6급 (6級) 영업 (營業) + 사회 (社會) + 모임 (모임) + 선물 (선물). 1년 (1年) 매출 (매출) 약 30조 원 (2024). 한자 百 (백) + 貨 (화) + 店 (점) = 백화점.
- **차이 (差異)**: 대형마트 = 가격 (價格) + 포장 (包裝) + 의류 (衣類) + 만석 (滿席) + 주차 (駐車). 재래시장 = 정육 (正肉) + 청과 (靑果) + 활기 (活氣) + 신선 (新鮮) + 가격 (價格) + 할부 (割賦) 없음. 편의점 = 24時間 + 1人 + 즉석 (即席) + 도시 (都市). 백화점 = 5星級 + 訪問 (방문) + 贈與 (증여) + 営業 (영업).

## Cross-language Connections

- **Coreano**: 한국 마트 ≈ 한국 쇼핑 (shopping) — 한류 (한류) + 한국 식품 (식품) + 한국 식품 (식품) 산업 (產業) 의 핵심. 한국 가계 (家計) 식품 (食品) 지출 (支出) 약 100조 원 (2024).
- **Japonés**: 일본 コンビニ (こんびに, konbini) + 市場 (いちば, ichiba) + デパート (depaato) ≈ 한국 마트 — 동아시아 유통 (流通) 시스템. 차이: 일본 コンビニ (편의점) = 도시 (도시) + 1인 (1人) + 即食 (即食) + 사회 (社會) + 정시 (定時), 한국 재래시장 (재래시장) = 정육 (正肉) + 활기 (活氣) + 신선 (新鮮) + 사회 (社會) + 전통 (傳統). 한자 市場 (시장) = 市 (시) + 場 (장) = 모두 시장.
- **Chino**: 중국 菜市場 (菜市場, cài shìchǎng) + 超市 (超市, chāoshì) ≈ 한국 마트 — 동아시아 식품 (食品) 시장 (市場). 차이: 중국 菜市場 = 신선 (新鮮) + 청과 (靑果) + 정육 (正肉) + 활기 (活氣), 한국 재래시장 (재래시장) = 활기 (활기) + 음식 (음식) + 활기 (活氣) + 신선 (新鮮). 한자 菜 (채) + 市 (시) + 場 (장) = 菜市場 (菜市場).

## 예문 (Ejemplos)

«한국에서 식료품 (食糧) + 청과 (靑果) + 정육 (正肉) + 활기 (活氣) + 사회 (社會) + 전통 (傳統) 을 구매 (購買) 하려면 재래시장 (재래시장) 을 찾는다. 대부분의 지역 (地域) 에 매주 (毎週) 아침 (아침) + 새벽 (새벽) 활기 (活氣) 가 있다.»
(In Korea, to buy groceries, produce, fresh meat, vitality, community, and tradition, you go to traditional markets. Most regions have vibrant morning and early-morning markets weekly.)

«한국 도시 (都市) 직장 (직장) 인 (人) 의 main (main) 식품 (食品) 구매 (購買) 채널 (channel) = 편의점 (便利店) + 대형마트 (大型mart) + 재래시장 (在來市場). 1인 (1人) + 1주 (1週) + 약 (약) 5만원 (5萬圓) + 식료품 (食糧) + 청과 (靑果) + 음료 (음료) + 즉석 (即席).」
(The main food channels for Korean urban workers are convenience stores + super markets + traditional markets. 1 person + 1 week + about 50,000 won + groceries + produce + drinks + instant food.)

«재래시장 (在來市場) + 대형마트 (大型mart) 의 가격 (價格) 차이 (差異) 는 약 (약) 10~20%. 재래시장 (재래시장) = 신선 (新鮮) + 활기 (活氣) + 사회 (社會) + 정육 (正肉) + 청과 (靑果). 대형마트 (大型mart) = 편리 (便利) + 일관 (一貫) + 상담 (상담) + 가족 (家族) + 주차 (駐車).»
(The price difference between traditional markets and supermarkets is about 10-20%. Traditional markets = fresh + vibrant + community + meat + produce. Supermarkets = convenient + uniform + consultation + family + parking.)
