# Clothing (의류) - Korean Translation

이 페이지는 한국인이 일본어 의류 어휘를 학습할 때 사용하는 한국어 관점 참고 자료입니다. 상의 (シャツ/コート/セーター/ジャケット/ドレス) + 하의 (ズボン/スカート) + 신발 (靴/靴下) + 액세서리 (帽子/マフラー) + 소재 (絹/綿/羊毛) + 색상·소재 형용사 (青い/白い/黒い) 등 21 entries 를 다룹니다. 각 단어의 한국어 정의, 발음 (히라가나/로마자), 한자 어원, 한국어 예문, 한국·일본 의류 문화 비교를 포함합니다.

**참고:** 본 페이지는 `wiki/Japanese/vocabulary/clothing-vocabulary.md` 의 한국어 번역/관점 페이지 입니다. 일본어 원문 표제(見出し)는 한자 + 히라가나(讀み方) 형식으로 표기.

## 상의 (上着 - Tops)

### シャツ

**품사:** 명사 (noun)

**정의:** 셔츠 — 천으로 된 상의 (형태 다양). 한국어 "셔츠" (loanword) 와 의미 동일.

**読み方 (읽는 법):** シャツ (히라가나 カタカナ) / shatsu (로마자) / 漢字: 襯衣 (しんい) / シャツ (가타카나)

**IPA / 발음:** /ɕat͡sɯ/

**어원:** 외래어 (外来語). 네덜란드어 "shert" → 영어 "shirt" → 일본어 カタカナ 転写 **シャツ**. 한국어 **셔츠** — 같은 어원.

#### 예문

- **シャツ**が必要です。 — 셔츠가 필요합니다. (필요, 격식)
- 白い**シャツ**を着ます。 — 흰 셔츠를 입습니다. (의상, 캐주얼)
- **シャツ**の種類: Yシャツ/Tシャツ/ポロシャツ. (의류 분류, 캐주얼)

#### 관련 용어

- シャツ (shatsu) — 「셔츠 (일반)」
- Tシャツ (Tシャ shatsu) — 「티셔츠」
- ワイシャツ (wai shatsu) — 「와이셔츠 (정장)」
- ポロシャツ (poro shatsu) — 「폴로셔츠」
- [[clothing-vocabulary]] — 의류 어휘

#### 문화적 맥락

일본어 **シャツ (shatsu, 셔츠)** 발음 "샤쓰" — 한국어 "샤쓰" (옛말, 속옷) 와 발음 동일. 캐주얼: シャツ. 한국어 "셔츠" (현재) / "사쓰" (옛 단어) / "속옷" (현재) 의 어원 비교. 일본 **ワイシャツ (wai shatsu, 와이셔츠)** = 정장용 흰 셔츠 — 한국어 "와이셔츠" 동일. 회사원: 濃紺 (のうこん, 짙은 남색) suits + 白 (しろ) 와이셔츠 빈번. 발음: シャツ (sha-tsu) — 한국어 ㅅ + ㅅ 발음 연습.

### 青いシャツ

**품사:** 명사 (noun) — 형용사修饰 + 명사

**정의:** 파란 셔츠 — 형용사 (青い) + 명사 (シャツ) 의 합성. 한국어 "파란 셔츠" 의미.

**読み方 (읽는 법):** あおいシャツ (히라가나 カタカナ) / aoi shatsu (로마자) / 漢字: 青いシャツ (あおいシャツ)

**IPA / 발음:** /a.o.i ɕat͡sɯ/

**어원:** 형용사 青い (あおい, 파랑) + 명사 シャツ (셔츠). 어원: 青 (파랑/초록) + 衫 (와복) → 파란 셔츠. 한국어 "파란 셔츠" 와 어원 동일.

#### 예문

- **青いシャツ**が必要です。 — 파란 셔츠가 필요합니다. (필요, 격식)
- **青いシャツ**は購入済です。 — 파란 셔츠는 구매 완료입니다. (구매, 격식)
- **青いシャツ**が似合います。 — 파란 셔츠가 잘 어울립니다. (적합, 캐주얼)

#### 관련 용어

- 青いシャツ (aoi shatsu) — 「파란 셔츠」
- 白いシャツ (shiroi shatsu) — 「흰 셔츠」
- 黒いシャツ (kuroi shatsu) — 「검은 셔츠」
- 赤いシャツ (akai shatsu) — 「빨간 셔츠」
- [[clothing-vocabulary]] — 의류 어휘

#### 문화적 맥락

일본어 **青いシャツ (aoi shatsu, 파란 셔츠)** 발음 "아오이샤쓰" — 한국어 "아오이샤쓰" (의역) 와 발음 동일. 캐주얼: 青いシャツ. 한국어 "파란 셔츠" 동일. **青い (아오이)** = 한국어 "파란" + **초록** 의 어원 (일본어 青 = 한국어 파랑 + 초록). 한국어 "파란 셔츠" 와 동일. 발음: 青い (あおい = a-o-i) — 한국어 ㅇ + ㅗ + ㅇ 발음 연습. 일본어 형용사 + 명사 결합 (青いシャツ) = 한국어 형용사 + 명사 (파란 셔츠) 와 어순 동일.

### コート

**품사:** 명사 (noun)

**정의:** 코트 — 외투 (겨울/봄). 한국어 "코트" (loanword) 와 의미 동일.

**読み方 (읽는 법):** コート (히라가나 カタカナ) / kōto (로마자) / 漢字: 外套 (がいとう, 격식)

**IPA / 발음:** /koː.to/

**어원:** 외래어 (外来語). 영어 "coat" → 일본어 カタカナ 転写 **コート**. 한국어 **코트** — 같은 어원. 한자 표현: 外套 (がいとう).

#### 예문

- 冬は**コート**が必要です。 — 겨울에는 코트가 필요합니다. (계절, 캐주얼)

#### 관련 용어

- コート (kōto) — 「코트 (일반)」

#### 문화적 맥락

### セーター

**품사:** 명사 (noun)

**정의:** 스웨터 — 뜨개질 상의. 한국어 "스웨터" (loanword) 와 의미 동일.

**読み方 (읽는 법):** セーター (히라가나 カタカナ) / sētā (로마자) / 漢字: 毛衣 (もうい, 한자어)

**IPA / 발음:** /seː.taː/

**어원:** 외래어 (外来語). 영어 "sweater" → 일본어 カタカナ 転写 **セーター**. 한국어 **스웨터** — 같은 어원. 한자 표현: 毛衣 (もうい, 털옷).

#### 예문

- 冬は**セーター**を着ます。 — 겨울에는 스웨터를 입습니다. (계절, 캐주얼)

#### 관련 용어

- セーター (sētā) — 「스웨터 (캐주얼)」

**読み方 (읽는 법):** きぬ (히라가나) / kinu (로마자) / 絹 (한자, 音読み: けん ken, 訓読み: きぬ kinu)

**어원:** 漢字 "絹" (음읽 けん, 訓읽 きぬ). 한국어 한자어 "견(絹)" 의미. 어원: 糹 (실, 씨실) + 肙 (고치) → 고치에서 뽑은 실 → 비단.
