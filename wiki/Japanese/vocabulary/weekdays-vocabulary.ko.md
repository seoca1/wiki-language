# Weekdays (요일) - Korean Translation

이 페이지는 한국인이 일본어 요일 어휘를 학습할 때 사용하는 한국어 관점 참고 자료입니다. 7요일 (月/火/水/木/金/土/日) + 평일/주말 (平日/週末) + 오늘 (今日) 을 다룹니다. 각 단어의 한국어 정의, 발음 (히라가나/로마자), 한자 어원, 한국어 예문, 한국·일본 요일 문화 비교를 포함합니다.

**참고:** 본 페이지는 `wiki/Japanese/vocabulary/weekdays-vocabulary.md` 의 한국어 번역/관점 페이지 입니다. 일본어 원문 표제(見出し)는 한자 + 히라가나(讀み方) 형식으로 표기.

## 7요일 (Days of the Week)

### 月曜日 (げつようび)

**품사:** 명사 (noun)

**정의:** 월요일 — 한 주의 첫 번째 평일. 한국어 "월요일" / 한자어 "월요일(月曜日)" 와 의미 동일.

**読み方 (읽는 법):** げつようび (히라가나) / getsuyoubi (로마자) / 月曜日 (한자, 音読み: げつようび getsuyoubi)

**IPA / 발음:** /get͡sɯ.joː.bi/

**어원:** 漢字 "月" (음읽 げつ/がつ, 訓읽 つき) + "曜" (음읽 よう, 訓읽 かがや.く) + "日" (음읽 にち/じつ, 訓읽 ひ/か). 한국어 한자어 "월요일(月曜日)" 동일 한자, 한국어 역음 "월요일". 어원: 月 = 달 (음읽 げつ, 음양력의 달 = 요일의 月) + 曜 = 빛나다 (일곱 요일 명) + 日 = 날.

#### 예문

- 今日は**月曜日**です。 — 오늘은 월요일입니다. (날짜, 격식)
- **月曜日**から仕事が始まります。 — 월요일부터 일이 시작됩니다. (스케줄, 격식)
- 今週の**月曜日**は休みです。 — 이번 주 월요일은 쉽니다. (계획, 캐주얼)

#### 관련 용어

- 月曜日 (げつようび) — 「월요일」
- 月 (げつ) — 「달 (음읽) / 월요일의 약자」
- 月曜 (げつよう) — 「월요일 (줄임말)」
- 月 (つき) — 「달 (훈읽) — 월요일과 다름」
- [[weekdays-vocabulary]] — 요일 어휘

#### 문화적 맥락

일본어 **月曜日 (げつようび)** 발음 "게츠요비" — 한국어 "월요일" (한자어) 와 발음 유사. 한국·일본 모두 **月曜日 (월요일)** = 한 주의 시작. 일본 **月 (げつ)** 는 달 (朔望月) — 음양력의 달 → 7요일 명 (月/火/水/木/金/土/日) 의 어원. 한국어 "월요일" (한자어) + "월 (줄임)" 동일. 발음: げつようび (ge-tsu-yo-bi) — 한국어 ㄱ + ㅅ + ㅇ + ㅂ 발음 연습.

### 今日 (きょう)

**품사:** 명사 (noun)

**정의:** 오늘 — 현재 날짜. 한국어 "오늘" / 한자어 "금일(今日)" 의미.

**読み方 (읽는 법):** きょう (히라가나) / kyou (로마자) / 今日 (한자, 音読み: きょう kyou)

**IPA / 발음:** /kjoː/

**어원:** 漢字 "今" (음읽 こん/きん, 訓읽 いま) + "日" (날). 한국어 한자어 "금일(今日)" 동일 한자, 한국어 역음 "금일". 어원: 今 = 지금, 日 = 날.

#### 예문

- **今日**は祝日です。 — 오늘은 공휴일입니다. (날짜, 격식)
- **今日**の天気は良いです。 — 오늘 날씨는 좋습니다. (날씨, 캐주얼)
- **今日**は何曜日ですか? — 오늘은 무슨 요일입니까? (질문, 격식)

#### 관련 용어

- 今日 (きょう) — 「오늘 (캐주얼)」
- 本日 (ほんじつ) — 「오늘 (격식)」
- 今日は (きょうは) — 「오늘은 (조사)」
- 今日日 (きょうび) — 「요즘 (구식)」
- [[weekdays-vocabulary]] — 요일 어휘

#### 문화적 맥락

일본어 **今日 (きょう)** 발음 "쿄" — 한국어 "교" 와 ㄱ 발음 유사. 캐주얼: きょう / 격식: 本日 (ほんじつ). 한국·일본 모두 **今日 (오늘)** = 현재 날짜. 인사: **こんにちは (konnichiwa, 안녕)** = "오늘은" (오늘 같은 날) 어원. 한국어 "오늘" / "금일" (격식) / "오늘날" (요즘) 의 어원 구분. 발음: きょう (kyo-u) — 한국어 ㅋ + ㅛ 발음 연습.
