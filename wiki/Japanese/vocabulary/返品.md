# 返品

**Part of Speech:** 名詞 (noun)

**Definition:** Return (of goods).

**Romaji:** henpin

---

## Examples

- **返品できますか?** — Can I return this?
- **返品したいのですが。** — I'd like to return this.
- **返品は無料です。** — Returns are free.
