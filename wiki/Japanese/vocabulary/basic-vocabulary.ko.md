### こんにちは (konnichiwa)

**품사:** 감탄사 (인사말)

**정의:** 안녕하세요 — 낮(낮 시간) 인사. 원래 "오늘은" (오늘 같은 날) 어원. 한국어 "안녕" (낮 인사) 와 동일.

**読み方 (읽는 법):** こんにちは (히라가나) / konnichiwa (로마자) / 漢字: 今日は (こんにちは)

**IPA / 발음:** /kon.ni.tɕi.wa/

**어원:** 漢字 "今日 (きょう)" + は (조사). 상형문자적 어원 불명. 일설: 御 (お) + 昼 (ひる) + 挨拶 (あいさつ) = "おひるあいさつ" 라는 설. 한국어 "안녕" (平 + 安) = "평안" 어원.

#### 예문

- **こんにちは**、田中さん。 — 안녕하세요, 다나카 씨. (인사, 격식)
- **こんにちは**、元気ですか? — 안녕하세요, 잘 지내세요? (인사, 캐주얼)
- 先生**こんにちは**。 — 선생님 안녕하세요. (인사, 격식)

#### 관련 용어

- こんにちは (konnichiwa) — 「안녕 (낮)」
- おはよう (ohayou) — 「안녕 (아침)」
- こんばんは (konbanwa) — 「안녕 (저녁)」
- おやすみ (oyasumi) — 「안녕 (잘 자)」
- [[basic-vocabulary]] — 기본 어휘

#### 문화적 맥락

일본어 **こんにちは (konnichiwa)** 발음 "곤니치와" — 한국어 "곤니치와" 와 발음 동일. 캐주얼: こんにちは (kon-ni-chi-wa) / 발음 변이: こんにちわ (오타). 한국어 "안녕" (낮 인사) / "안녕하세요" (격식) 와 의미 동일. **こんにちは** 의 어원 = "今日は" (오늘은) — 한국어 "안녕" 의 어원 (平 + 安 = 평안) 과 다름. 일본 인사 시간대: **おはよう (아침 ~10시) / こんにちは (낮) / こんばんは (저녁)**. 한국어 동일. 발음: こんにちは (kon-ni-chi-wa) — 한국어 ㄴ + ㄷ + ㅊ + ㅇ 발음 연습.

### すみません (sumimasen)

**품사:** 감탄사 (사과+감사)

**정의:** 실례합니다 / 미안합니다 — 사과 또는 가벼운 감사 (감사 표현으로도 사용). 한국어 "실례합니다" / "미안합니다" 의미.

**読み方 (읽는 법):** すみません (히라가나) / sumimasen (로마자) / 漢字: 済いません (すみません)

**IPA / 발음:** /sɯ.mi.ma.sen/

**어원:** 漢字 "済" (음읽 さい/せい, 訓읽 す.む/す.ます) + ま (부정/지속) + せん (부정). 어원: 済む (끝나다) + ません (부정) = "끝나지 않습니다" → "미안합니다". 한국어 "미안" 어원 비교.

#### 예문

- **すみません**、駅はどこですか? — 실례합니다, 역은 어디입니까? (질문, 캐주얼)
- **すみません**、遅れました。 — 미안합니다, 늦었습니다. (사과, 격식)
- どうも**すみません**。 — 정말 미안합니다. (사과, 캐주얼)

#### 관련 용어

- すみません (sumimasen) — 「실례합니다 (캐주얼)」
- すみません (sumimasen) — 「미안합니다 (캐주얼)」
- ごめんなさい (gomen nasai) — 「미안해요 (캐주얼)」
- 申し訳ありません (もうしわけありません) — 「죄송합니다 (격식)」
- [[basic-vocabulary]] — 기본 어휘

#### 문화적 맥락

일본어 **すみません (sumimasen)** 발음 "스미마센" — 한국어 "스미마센" 와 발음 동일. 캐주얼: すみません / 격식: 申し訳ありません (もうしわけありません). 한국어 "미안합니다" / "실례합니다" 와 의미 동일. **すみません** 의 다양한 용법: (1) 사과 (미안합니다), (2) 가벼운 감사 (죄송 = 고마워), (3) 호명 (실례합니다) — 한국어 동일. 한국어 "미안" 어원: 見 (보다) + 顔 (얼굴) = "얼굴 보지 못하다" (중세). 발음: すみません (su-mi-ma-sen) — 한국어 ㅅ + ㅁ + ㅅ + ㄴ 발음 연습.

### さようなら (sayounara)

**품사:** 감탄사 (작별)

**정의:** 안녕히 가세요 — 작별 인사. 영구적 작별에 사용 (잠시 작별은 また明日). 한국어 "안녕히 가세요" / "작별" 의미.

**読み方 (읽는 법):** さようなら (히라가나) / sayounara (로마자) / 漢字: さようなら (한자 X, 漢字: 左様なら)

**IPA / 발음:** /sa.joː.na.ɾa/

**어원:** 漢字 "左様" (さよう, 그러하다) + なら (已然形 의 추측). 어원: "그러한 것이 있다면 (禾 = 인연이 다하면)" → "작별". 한국어 작별 어원: 雀 (참새) + 別 (이별) = "참새처럼 빠르게".

#### 예문

- **さようなら**、また明日。 — 안녕, 또 내일 봐. (작별, 캐주얼)
- **さようなら**、旅立ちの時です。 — 안녕히 가세요, 떠날 시간입니다. (영구 작별, 격식)
- **さようなら**は使わないで、ただ「じゃあね」 — 「さようなら」 사용 안함, 그냥 「잘 가」 (캐주얼)

#### 관련 용어

- さようなら (sayounara) — 「안녕히 가세요 (격식)」
- じゃあね (jaanе) — 「잘 가 (캐주얼)」
- またね (matane) — 「또 봐 (캐주얼)」
- バイバイ (bai bai) — 「바이바이 (구어)」
- [[basic-vocabulary]] — 기본 어휘

#### 문화적 맥락

일본어 **さようなら (sayounara)** 발음 "사요나라" — 한국어 "사요나라" 와 발음 동일. 캐주얼: さようなら (사용 드물음) / 대체: じゃあね / またね. 한국어 "안녕히 가세요" / "잘 가" 와 의미 동일. **さようなら** 의 어원: 左様 (그렇다) + なら (추측) = "그렇다면 (인연이 다한다면)" → "작별". 한국어 "작별" (雀 + 別) 어원 과 다름. **さようなら** 가 영구 작별에만 사용 — 일상 작별은 **じゃあね (jaanе)** 또는 **また (mata)** 빈번. 발음: さようなら (sa-yo-u-na-ra) — 한국어 ㅅ + ㅇ + ㅇ + ㄴ + ㄹ 발음 연습.

### 3. 발음 함정 (한국어 화자)
- カタカナ 外래어 (コーヒー, ビール) — ㄴ + ㅇ + ㅋ + ㅂ 발음
- 촉음 っ (small つ) — 일시 정지 (건반, 시부야)
- 장음 お (long vowel) — 모음 두 배 (도쿄, 오사카)
- ん (鼻音) — ㄴ + ㅇ 사이
- りゃ/りゅ/りょ (요음) — ㄴ + ㅇ + ㄹ + ㅇ 발음

### 4. 한자 어원 (한국어 화자 친숙)
- 한자어 (漢字音) — 한국어 한자어 차용과 동일 어원
- 音読み (おんよみ) vs 訓読み (くんよみ) — 한국어 한자음과 훈독의 차이
- 例: 水 (음읽 すい vs 훈읽 みず) — 한국어 "수" (한자음) vs "물" (의미)
