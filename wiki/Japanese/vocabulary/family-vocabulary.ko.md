# Family (가족) - Korean Translation

이 페이지는 한국인이 일본어 가족 어휘를 학습할 때 사용하는 한국어 관점 참고 자료입니다. 기본 가족 호칭 (母/父/姉妹/兄弟/祖母/祖父/おば/おじ/いとこ/家族) 을 다룹니다. 각 단어의 한국어 정의, 발음 (히라가나/로마자), 한자 어원, 한국어 예문, 한국·일본 가족 문화 비교를 포함합니다.

**참고:** 본 페이지는 `wiki/Japanese/vocabulary/family-vocabulary.md` 의 한국어 번역/관점 페이지 입니다. 일본어 원문 표제(見出し)는 한자 + 히라가나(讀み方) 형식으로 표기.

## 부모 (Parents)

### 母 (はは)

**품사:** 명사 (noun)

**정의:** 어머니 — 친 어머니. 다른 사람의 어머니를 가리킬 때 사용. 한국어 "어머니" / 한자어 "모(母)" 의미.

**読み方 (읽는 법):** はは (히라가나) / haha (로마자) / 母 (한자, 音読み: ぼ bo, 訓読み: はは haha / 母 kaa)

**IPA / 발음:** /ha.ha/

**어원:** 漢字 "母" (음읽 ぼ, 訓읽 はは/かあ). 한국어 한자어 "모(母)" 의미. 어원: 女 (여성) + 毋 (금기어: 어미) → 어머니.

#### 예문

- **母**は先生です。 — 어머니는 선생님입니다. (직업, 격식)
- 私の**母**は料理が上手です。 — 제 어머니는 요리를 잘합니다. (능력, 격식)
- **母**の日はいつですか? — 어머날은 언제입니까? (명절, 격식)

#### 관련 용어

- 母 (はは) — 「어머니 (타인의 어머니)」
- お母さん (おかあさん) — 「어머니 (존칭)」
- ママ (mama) — 「엄마 (구어)」
- (かな 표기: 母 한글 표기 → はは, 발음 "haha")
- [[family-vocabulary]] — 가족 어휘

#### 문화적 맥락

일본어 **母 (はは)** 발음 "하하" — 한국어 "하하" (웃음) 와 발음 동일. 캐주얼: ママ (mama) / 존칭: お母さん (おかあさん). 한국어 "어머니" / "엄마" 동일. **母 (はは)** 는 자신의 어머니를 다른 사람에게 소개할 때 — **母は (haa-wa)** / **私の母 (watashi-no haa)**. 한국어 "어머니" 와 다름 (한국어 "어머니" 는 일반). 발음: はは (ha-ha) — 한국어 ㅎ 발음 연습.

### 父 (ちち)

**품사:** 명사 (noun)

**정의:** 아버지 — 친 아버지. 다른 사람의 아버지를 가리킬 때 사용. 한국어 "아버지" / 한자어 "부(父)" 의미.

**読み方 (읽는 법):** ちち (히라가나) / chichi (로마자) / 父 (한자, 音読み: ふ fu, 訓読み: ちち chichi / 父 tou)

**IPA / 발음:** /tɕi.tɕi/

**어원:** 漢字 "父" (음읽 ふ, 訓읽 ちち/とう). 한국어 한자어 "부(父)" 의미. 어원: 父 (한자) → 아버지.

#### 예문

- **父**は優しいです。 — 아버지는 상냥합니다. (성격, 격식)
- 私の**父**は先生です。 — 제 아버지는 선생님입니다. (직업, 격식)
- **父**の日にプレゼントを買いました。 — 아버지의 날에 선물을 샀습니다. (명절, 격식)

#### 관련 용어

- 父 (ちち) — 「아버지 (타인의 아버지)」
- お父さん (おとうさん) — 「아버지 (존칭)」
- パパ (papa) — 「아빠 (구어)」
- 父親 (ちちおや) — 「아버지 (격식)」
- [[family-vocabulary]] — 가족 어휘

#### 문화적 맥락

일본어 **父 (ちち)** 발음 "치치" — 한국어 "치치" (지청명) 와 발음 동일. 캐주얼: パパ (papa) / 존칭: お父さん (おとうさん). 한국어 "아버지" / "아빠" 동일. **父 (ちち)** 는 타인에게 자기 아버지 소개 / **お父さん (おとうさん)** = 타인의 아버지 (존칭). 한국어 "아버지" (남의 아버지) / "아빠" (구어) 와 의미 매핑. 발음: ちち (chi-chi) — 한국어 ㅊ 발음 연습.

## 형제자매 (Siblings)

### 姉妹 (しまい)

**품사:** 명사 (noun)

**정의:** 여자 형제 — 자매. 한국어 "자매" / 한자어 "자매(姉妹)" 의미.

**読み方 (읽는 법):** しまい (히라가나) / shimai (로마자) / 姉妹 (한자, 音読み: しまい shimai)

**IPA / 발음:** /ɕi.ma.i/

**어원:** 漢字 "姉" (음읽 まい, 訓읽 あね) + "妹" (음읽 まい, 訓읽 いもうと). 한국어 한자어 "자매(姉妹)" 동일 한자, 한국어 역음 "자매". 어원: 姉 = 누나/언니, 妹 = 여동생.

#### 예문

- **姉妹**が一人います。 — 자매가 한 명 있습니다. (가족, 격식)
- 私の**姉妹**は医者です。 — 제 자매는 의사입니다. (직업, 격식)
- **姉妹**で買い物に行きます。 — 자매와 쇼핑하러 갑니다. (활동, 캐주얼)

#### 관련 용어

- 姉妹 (しまい) — 「자매 (총칭)」
- 姉 (あね) — 「누나 (남자) / 언니 (여자)」
- 妹 (いもうと) — 「여동생」
- 兄弟 (きょうだい) — 「남자 형제 (총칭) / 형제 (양쪽)」
- [[family-vocabulary]] — 가족 어휘

#### 문화적 맥락

일본어 **姉妹 (しまい)** 발음 "시마이" — 한국어 "시마이" (島 + 伊) 와 발음 동일. 캐주얼: 姉妹 (si-mai) / 격식: 姉妹 (동일). 한국어 "자매" / 한자어 "자매" 동일. **姉妹 (자매)** + **兄弟 (형제)** 의 어원 비교: 姉妹 = 姉 (누나) + 妹 (여동생), 兄弟 = 兄 (오빠) + 弟 (남동생). 한국어 동일. 발음: しまい (shi-mai) — 한국어 ㅇ + ㅁ + ㅇ 발음 연습.

### 兄弟 (きょうだい)

**품사:** 명사 (noun)

**정의:** 형제 — 남자 형제 (오빠/형/남동생). 한국어 "형제" / "남자 형제" / 한자어 "형제(兄弟)" 의미.

**読み方 (읽는 법):** きょうだい (히라가나) / kyoudai (로마자) / 兄弟 (한자, 音読み: きょうだい kyoudai / けいてい keitei)

**IPA / 발음:** /kjoː.da.i/

**어원:** 漢字 "兄" (음읽 けい/きょう, 訓읽 あに) + "弟" (음읽 てい/だい, 訓읽 おとうと). 한국어 한자어 "형제(兄弟)" 동일 한자, 한국어 역음 "형제". 어원: 兄 = 오빠/형, 弟 = 남동생.

#### 예문

- **兄弟**が年上です。 — 형제가 연상입니다. (가족, 격식)
- 彼には**兄弟**がいますか? — 그에게는 형제가 있습니까? (질문, 격식)
- **兄弟**で一緒に住んでいます。 — 형제와 함께 살고 있습니다. (생활, 캐주얼)

#### 관련 용어

- 兄弟 (きょうだい) — 「형제 (총칭, 남자만) / 형제 (양쪽)」
- 兄 (あに) — 「오빠 (여자) / 형 (남자)」
- 弟 (おとうと) — 「남동생」
- 姉妹 (しまい) — 「자매」
- 兄妹 (けいまい) — 「남매 (남자 + 여자)」
- [[family-vocabulary]] — 가족 어휘

#### 문화적 맥락

일본어 **兄弟 (きょうだい)** 발음 "쿄다이" — 한국어 "교대" (交代) 와 발음 동일. 캐주얼: 兄弟 (kyou-dai) / 격식: 兄弟 (동일). 한국어 "형제" 와 동일. **兄弟 (형제)** 의 의미: 엄밀히 "남자 형제" / 양쪽 = 兄妹 (남매) / 姉弟 (여매). 한국어 "형제" 는 양쪽 모두. 발음: きょうだい (kyou-dai) — 한국어 ㅋ + ㅇ + ㄷ + ㅇ 발음 연습.

## 조부모 (Grandparents)

### 祖母 (そぼ)

**품사:** 명사 (noun)

**정의:** 할머니 — 친 할머니. 다른 사람의 할머니를 가리킬 때. 한국어 "할머니" / 한자어 "조모(祖母)" 의미.

**読み方 (읽는 법):** そぼ (히라가나) / sobo (로마자) / 祖母 (한자, 音読み: そぼ sobo)

**IPA / 발음:** /so.bo/

**어원:** 漢字 "祖" (음읽 そ, 訓읽 おや) + "母" (음읽 ぼ, 訓읽 はは). 한국어 한자어 "조모(祖母)" 동일 한자, 한국어 역음 "조모". 어원: 祖 = 할, 母 = 어머니.

#### 예문

- **祖母**はキムチを作ります。 — 할머니는 김치를 만듭니다. (음식, 캐주얼)
- 私の**祖母**は84歳です。 — 제 할머니는 84세입니다. (나이, 격식)
- **祖母**の家に行きます。 — 할머니 댁에 갑니다. (방문, 캐주얼)

#### 관련 용어

- 祖母 (そぼ) — 「할머니 (타인)」
- お祖母さん (おばあさん) — 「할머니 (존칭)」
- 婆 (ばば) — 「할머니 (구어)」
- 祖母 (おばあちゃん) — 「할머니 (구어)」
- [[family-vocabulary]] — 가족 어휘

#### 문화적 맥락

## 친척 (Relatives)

### おば

**품사:** 명사 (noun)

**정의:** 고모/이모 — 아버지/어머니의 여자 형제. 한국어 "고모" (아버지의 누이) / "이모" (어머니의 누이) 의미.

**読み方 (읽는 법):** おば (히라가나) / oba (로마자) / 漢字: 叔母 (おば) / 姑母 (おば)

**IPA / 발음:** /o.ba/

**어원:** 漢字 "叔" (음읽 しゅく, 訓읽 お.じ) + "母" (음읽 ぼ, 訓읽 はは). 한국어 한자어 "숙모(叔母)" 의미. 어원: 叔 = 같은 항렬의 어른 남자 형제, 母 = 어머니.

#### 예문

- **おば**はソウルに住んでいます。 — 이모는 서울에 살고 있습니다. (거주, 캐주얼)
- **おば**の家に行きます。 — 이모 댁에 갑니다. (방문, 캐주얼)
- **おば**に会いたいです。 — 이모를 만나고 싶습니다. (감정, 캐주얼)

#### 관련 용어

- おば (ob) — 「고모/이모 (캐주얼)」
- 叔母 (おば) — 「숙모 (한자어)」
- おばさん (obasan) — 「이모 (존칭)」
- 伯母 (おば) — 「고모 (한자어)」
- [[family-vocabulary]] — 가족 어휘

#### 문화적 맥락

일본어 **おば (oba)** 발음 "오바" — 한국어 "오바" (할머니, 옛말) 와 발음 동일. 캐주얼: おば / 존칭: おばさん (obasan). 한국어 "고모" / "이모" 동일. **おば (親等)** — 한국어 "고모" (아버지) / "이모" (어머니) 의 어원 비교. 일상 회화: **おばちゃん (obachan)** = 친근한 존칭. 발음: おば (o-ba) — 한국어 ㅇ + ㅂ 발음 연습.

### いとこ

**정의:** 사촌 — 부모의 형제자매의 자녀. 한국어 "사촌" 의미.

**読み方 (읽는 법):** いとこ (히라가나) / itoko (로마자) / 漢字: 從兄/從弟 (じゅうけい/じゅうてい, 격식)

**IPA / 발음:** /i.to.ko/

**어원:** 고유어 (和語). 어원: 上代 일본어 "위(い)" (위) + "子(と)" (자) → 위의 자식 (cousin). 한국어 "사촌" 의 어원: 한자어 沙村 (고려) → 속음 "사촌".

- **いとこ**と遊びます。 — 사촌과 놉니다. (활동, 캐주얼)

## 가족 (Family)

### 家族 (かぞく)

**품사:** 명사 (noun)

**정의:** 가족 — 친족 집단. 한국어 "가족" / 한자어 "가족(家族)" 의미.

**読み方 (읽는 법):** かぞく (히라가나) / kazoku (로마자) / 家族 (한자, 音読み: かぞく kazoku)

**IPA / 발음:** /ka.zo.kɯ/

**어원:** 漢字 "家" (음읽 か/け, 訓읽 いえ/や/う) + "族" (음읽 ぞく, 訓읽 やから). 한국어 한자어 "가족(家族)" 동일 한자, 한국어 역음 "가족". 어원: 家 = 집, 族 = 겨레.

#### 예문

- **家族**を愛しています。 — 가족을 사랑합니다. (감정, 격식)
- **家族**と一緒に住んでいます。 — 가족과 함께 살고 있습니다. (생활, 격식)
- **家族**は何人ですか? — 가족은 몇 명입니까? (질문, 격식)

#### 관련 용어

- 家族 (かぞく) — 「가족 (총칭)」
- 家庭 (かてい) — 「가정 (가정환경)」
- 家族旅行 (かぞくりょこう) — 「가족 여행」
- 大家族 (だいかぞく) — 「대가족」

#### 문화적 맥락

일본어 **家族 (かぞく)** 발음 "카조쿠" — 한국어 "카조쿠" (외래어, 가문) 와 발음 동일. 캐주얼: 家族 (ka-zo-ku) / 격식: 家族 (동일). 한국어 "가족" / 한자어 "가족" 동일. **家族 (가족)** + **家庭 (가정)** 의 어원 구분: 家族 = 친족, 家庭 = 가정환경. 한국어 "가족" / "가정" 의 어원 비교. 발음: かぞく (ka-zo-ku) — 한국어 ㅋ + ㅈ + ㅋ 발음 연습.
