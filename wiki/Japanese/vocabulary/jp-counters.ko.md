# Counters (일본어 양사 助数詞) - Korean Translation

이 페이지는 한국인이 일본어 양사 (카운터) 어휘를 학습할 때 사용하는 한국어 관점 참고 자료. JLPT N5 핵심 카운터 (一つ, 一つ, 人, 本, 枚, 個, 匹, 台, 冊, 回, 度, 階, 羽, 冊, 階 등) 를 다룹니다. 각 단어의 한국어 정의, 발음 (히라가나/로마자), 한국어 예문, 한국·일본 양사 문화 비교를 포함합니다.

**참고:** 본 페이지는 `wiki/Japanese/vocabulary/jp-counters.md` 의 한국어 번역/관점 페이지. 원문은 1 entry (一つ) 만 포함하는 aggregator 페이지.

## 한국어 학습자 핵심 노트 (Japanese Counters 핵심)

### 1. 한국어와 일본어 양사 (助数詞) 차이

한국어 양사 (조사):
- **개 (동물의 다리 수)**: 한 마리, 두 마리, 세 마리
- **명 (사람)**: 한 명, 두 명, 세 명
- **권 (책)**: 한 권, 두 권, 세 권
- **대 (자동차)**: 한 대, 두 대, 세 대

일본어 양사 (카운터):
- **匹 (ひき)**: 일반 동물 (개, 고양이)
- **頭 (とう)**: 큰 동물 (말, 소) — 4 마리 초과
- **羽 (わ)**: 새 (鳥)
- **台 (だい)**: 기차/자동차
- **冊 (さつ)**: 책
- **枚 (まい)**: 종이/티켓
- **個 (こ)**: 작은 것 일반
- **本 (ほん)**: 긴 물건 (병, 펜)
- **杯 (はい)**: 음료 (잔)
- **階 (かい)**: 건물 층

→ 한국어 양사가 4개 (개/명/권/대) 인데, 일본어 카운터는 10+ 가지 — 한국어 화자 학습 부담 큼.

### 2. 숫자 + 카운터 변이 (숫자 발음 변이)

| 숫자 | 발음 변이 | 카운터 결합 시 음변 |
|---|---|---|
| 1 (一) | いち (음읽) / ひと (훈읽) | 카운터 카운터 결합 시 변이 |
| 2 (二) | に (음읽) | 無변 |
| 3 (三) | さん (음읽) | 無변 |
| 4 (四) | し/よん (음읽) | 無변 |
| 5 (五) | ご (음읽) | 無변 |
| 6 (六) | ろく (음읽) | 無변 |
| 7 (七) | しち/なな (음읽) | 無변 |
| 8 (八) | はち (음읽) | 無변 |
| 9 (九) | く/きゅう (음읽) | 無변 |
| 10 (十) | じゅう (음읽) | 無변 |

### 3. 한국어 화자 주의 음운 변이 (연음/촉음)

**연음 (連濁)**: 카운터 첫 음절이 か행/は行/あ행 일 때, 숫자 끝 + 카운터 첫 음절 사이에서 발음 변이 발생.
- 一本 (いっぽん, ippon) — 한자음 一本 (いちほん) → 促音 (x) + 본 (x)
- 三本 (さんぼん, sanbon) — 三本 (さんほん) → 연음 (h → b)

**촉음 (促音)**: 카운터 첫 음절이 か행/は行/あ행 일 때, 숫자 끝 + 카운터 사이에서 촉음 변이 발생.
- 一個 (いっこ, ikko) — 一個 (いちこ) → 촉음 (x) + 코 (x)
- 一回 (いっかい, ikkai) — 一回 (いちかい) → 촉음 (x) + 카이 (x)

### 4. 한국어 양사 매핑 (한자어 차용)

| 한국어 | 일본어 | 비고 |
|---|---|---|
| 한 마리 | 一匹 (いっぴき) | 동물의 다리 수 |
| 한 명 | 一人 (ひとり) | 사람 |
| 한 권 | 一冊 (いっさつ) | 책 |
| 한 대 | 一台 (いちだい) | 자동차/기계 |
| 한 잔 | 一杯 (いっぱい) | 음료 |
| 한 개 | 一つ (ひとつ) | 일반 |
| 한 채 | 一軒 (いっけん) | 집/가게 |
| 한 쌍 | 一対 (いっつい) | 쌍 |

### 5. 단일 카운터 (一つ) — 가장 기본

**一つ (ひとつ)** — 한국어 "한 개" (일반). 한국어 양사 "개/명/권/대" 와 같은 어원.

- **一 (いち)** × **つ (ひとつ)** = ひとつ (한 개) — ㄴ (n) + ㅅ (ts) + ㅅ (u) 발음 연습
- **三つ (みっつ)** — 한국어 "세 개" — 촉음 っ 2개 발음 연습
- **八つ (やっつ)** — 한국어 "여덟 개" — 촉음 っ 1개 발음 연습
