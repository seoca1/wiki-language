## 공항 (空港 - Airport)

### パスポート (pasupōto)

**품사:** 명사 (noun)

**정의:** 여권 — 해외 여행 신분증명서. 한국어 "여권" / 한자어 "여권(旅券)" 의미.

**読み方 (읽는 법):** パスポート (히라가나 カタカナ) / pasupōto (로마자) / 漢字: 旅券 (りょけん, 격식)

**IPA / 발음:** /pa.sɯ.poː.to/

**어원:** 외래어 (外来語). 영어 "passport" → 일본어 カタカナ 転写 **パスポート**. 한국어 **여권** (한자어) — 다른 어원 (旅券 → 속음 여권). 영어 passport와 한국어 "여권" 어원 다름.

#### 예문

- **パスポート**を見せます。 — 여권을 보여줍니다. (제시, 격식)
- **パスポート**の番号を教えてください。 — 여권 번호를 알려주세요. (질문, 격식)
- **パスポート**を更新します。 — 여권을 갱신합니다. (갱신, 격식)

#### 관련 용어

- パスポート (pasupōto) — 「여권 (외래어)」
- 旅券 (りょけん) — 「여권 (한자어)」
- ビザ (biza) — 「비자」
- ビザ申請 (biza shinsei) — 「비자 신청」
- [[travel]] — 여행 어휘

#### 문화적 맥락

일본어 **パスポート (pasupōto, 여권)** 발음 "파스포-토" — 한국어 "여권" (한자어) 와 발음 비교. 캐주얼: パスポート / 한자어: 旅券 (りょけん). 한국어 "여권" 동일. **パスポート (파스포트)** = 영어 passport → 한국어 パスポート (외래어) or 여권 (한자어). 일본어 발음의 お (long vowel) — 한국어 화자에게 연음 처리 연습. 발음: パスポート (pa-su-po-o-to) — 장음 お + ㅅ 발음 연습.

**정의:** 짐 — 가지고 있는 물건. 한국어 "짐" / 한자어 "하물(荷物)" 의미.

**読み方 (읽는 법):** にもつ (히라가나) / nimotsu (로마자) / 荷物 (한자, 音読み: にもつ nimotsu)

**IPA / 발음:** /ni.mo.t͡sɯ/

**어원:** 漢字 "荷" (음읽 か, 訓읽 に) + "物" (음읽 ぶつ/もつ, 訓읽 もの). 한국어 한자어 "하물(荷物)" 동일 한자, 한국어 역음 "하물". 어원: 荷 (싣다) + 物 (물건) = 싣는 물건 → 짐.

#### 예문

- **荷物**を持ちます。 — 짐을 듭니다. (행위, 격식)
- **荷物**を預けます。 — 짐을 맡깁니다. (보관, 격식)
- 大きい**荷物**があります。 — 큰 짐이 있습니다. (상태, 캐주얼)

#### 관련 용어

- 荷物 (にもつ) — 「짐 (캐주얼)」

- 預け荷物 (あずけにもつ) — 「위탁 수하물」
- 機内持ち込み手荷物 (きないもちこみてにもつ) — 「기내 반입 수하물」
- [[travel]] — 여행 어휘

#### 문화적 맥락

일본어 **荷物 (にもつ)** 발음 "니모쓰" — 한국어 "하물" (한자어) 와 발음 동일. 캐주얼: 荷物 (ni-mo-tsu). 한국어 "짐" (구어) / "하물" (한자어) 의미. **荷物 (にもつ)** + **에** 조사 (助詞) 의 결합: **に + もつ (짐)** + つ = 荷物. 한국어 "짐" 의 어원 불명. 발음: にもつ (ni-mo-tsu) — 촉음 っ + ㅅ 발음 연습.

**정의:** 방 — 건물 내의 호실. 한국어 "방" 의미.

**読み方 (읽는 법):** へや (히라가나) / heya (로마자) / 部屋 (한자, 音読み: べや heya, 訓読み: へや heya)

**IPA / 발음:** /he.ja/

**어원:** 漢字 "部" (음읽 ぶ, 訓읽 べ) + "屋" (음읽 おく, 訓읽 や). 한국어 한자어 "부옥(部屋)" 의미. 어원: 部 (부분) + 屋 (집) = 부분집 → 방.

#### 예문

- ホテルの**部屋**に入ります。 — 호텔 방에 들어갑니다. (행위, 캐주얼)
- **部屋**の番号は305です。 — 방 번호는 305입니다. (정보, 격식)
- この**部屋**はいかがですか? — 이 방은 어떠세요? (질문, 격식)

#### 관련 용어

- 部屋 (へや) — 「방 (캐주얼)」
- 部室 (ぶしつ) — 「부실 (동아리방)」
- 客室 (きゃくしつ) — 「객실 (호텔)」
- 部屋着 (へやぎ) — 「실내복」
- [[travel]] — 여행 어휘

#### 문화적 맥락

일본어 **部屋 (へや)** 발음 "헤야" — 한국어 "방" (한자어) 와 발음 비교. 캐주얼: 部屋 (he-ya) / 격식: 客室 (きゃくしつ). 한국어 "방" / 한자어 "부옥(部屋)" 의미. 일본 호텔 **号室 (ごうしつ, 방번호)** = 한국어 "호실" (예: 305号室 = 305호실). 발음: へや (he-ya) — 한국어 ㅎ + ㅇ 발음 연습.

**어원:** 漢字 "幾" (음읽 き, 訓읽 いく/いく.つ) + ら (접미) + です (격식) + か (의문). 한국어 "얼마" 의 어원: 어원 불명 (고유어).

#### 예문

- **いくらですか**? — 얼마예요? (질문, 캐주얼)
- 全部で**いくらですか**? — 전부 얼마예요? (질문, 캐주얼)

#### 관련 용어

- いくら (ikura) — 「얼마 (가격)」
- 高い (takai) — 「비싸다」
- 安い (yasui) — 「싸다」
- 値 (ne) — 「값」

### わかりません (wakarimasen)

**품사:** 명사 (동사)

**정의:** 모르겠습니다 — 이해 못함. 한국어 "모르겠습니다" 의미.

**読み方 (읽는 법):** わかりません (wakari-masen)

**IPA / 발음:** /wa.ka.ɾi.ma.sen/

**어원:** 漢字 "分" (음읽 ぶん/ぶん, 訓읽 わ.かる/わ.ける) + ります (정중) + ません (부정). 한국어 한자어 "이해(理解) 안 함" 어원. **わかる (わかる)** = 한국어 "알다" 와 어원 비교.

#### 예문

- **わかりません**。 — 모르겠습니다. (거절, 캐주얼)
- 日本語は**わかりません**。 — 일본어는 모르겠습니다. (한계, 캐주얼)

#### 관련 용어

- わかります (wakarimasu) — 「알겠습니다 (정중)」

#### 문화적 맥락
