# JLPT N5 핵심 한자: 읽기와 뜻 70자

**Language:** Japanese  
**Theme:** Kanji  
**Level:** JLPT N5  
**Source:** `.openclaw/workspace/wiki/japanese/lessons/Kanji_N5_100.md` (immutable original)

OpenClaw의 N5 한자 목록에서 숫자, 시간, 위치, 신체, 가족, 자연, 동작, 상태를 나타내는 핵심 70자를 골랐다. 각 글자의 대표 음독과 훈독을 함께 보되, 실제 단어에서는 읽기가 달라질 수 있음을 기억한다.

---

## 숫자

### 一

**Reading:** いち / ひと (ichi / hito)  
**Meaning:** 하나, 일  
**Note:** 一人에서는 ひとり로 읽는다.

### 二

**Reading:** に / ふた (ni / futa)  
**Meaning:** 둘, 이  
**Note:** 二人에서는 ふたり로 읽는다.

### 三

**Reading:** さん / み (san / mi)  
**Meaning:** 셋, 삼  
**Note:** 三月은 さんがつ다.

### 四

**Reading:** し / よん (shi / yon)  
**Meaning:** 넷, 사  
**Note:** 四時는 よじ, 四月은 しがつ로 읽는다.

### 五

**Reading:** ご / いつ (go / itsu)  
**Meaning:** 다섯, 오  
**Note:** 五つ는 いつつ다.

### 六

**Reading:** ろく / む (roku / mu)  
**Meaning:** 여섯, 육  
**Note:** 六本은 ろっぽん으로 소리가 변한다.

### 七

**Reading:** しち / なな (shichi / nana)  
**Meaning:** 일곱, 칠  
**Note:** 양사에 따라 しち와 なな를 구별한다.

### 八

**Reading:** はち / や (hachi / ya)  
**Meaning:** 여덟, 팔  
**Note:** 八つ는 やっつ다.

### 九

**Reading:** きゅう / ここの (kyū / kokono)  
**Meaning:** 아홉, 구  
**Note:** 九時는 くじ로 읽는다.

### 十

**Reading:** じゅう / とお (jū / tō)  
**Meaning:** 열, 십  
**Note:** 十日는 とおか다.

---

## 시간과 달력

### 年

**Reading:** ねん / とし (nen / toshi)  
**Meaning:** 해, 년  
**Note:** 연도와 기간을 나타낸다.

### 月

**Reading:** げつ / つき (getsu / tsuki)  
**Meaning:** 달, 월  
**Note:** 달력의 월에서는 がつ로 읽는다.

### 日

**Reading:** にち / ひ (nichi / hi)  
**Meaning:** 날, 해  
**Note:** 날짜와 요일에서 여러 불규칙 읽기가 나타난다.

### 時

**Reading:** じ / とき (ji / toki)  
**Meaning:** 시, 때  
**Note:** 시각과 때를 나타낸다.

### 分

**Reading:** ふん / わける (fun / wakeru)  
**Meaning:** 분, 나누다  
**Note:** 시간 단위에서는 ふん이나 ぷん으로 읽는다.

### 半

**Reading:** はん (han)  
**Meaning:** 반, 절반  
**Note:** 三時半은 세 시 반이라는 뜻이다.

### 今

**Reading:** こん / いま (kon / ima)  
**Meaning:** 지금  
**Note:** 今月은 こんげつ, 단독으로는 いまだ.

### 毎

**Reading:** まい (mai)  
**Meaning:** 매, 매번  
**Note:** 毎日, 毎週처럼 반복 주기를 나타낸다.

### 火

**Reading:** か / ひ (ka / hi)  
**Meaning:** 불, 화  
**Note:** 火曜日는 화요일이다.

### 水

**Reading:** すい / みず (sui / mizu)  
**Meaning:** 물, 수  
**Note:** 水曜日는 수요일이다.

### 木

**Reading:** もく / き (moku / ki)  
**Meaning:** 나무, 목  
**Note:** 木曜日와 나무를 나타낼 때 모두 쓰인다.

### 金

**Reading:** きん / かね (kin / kane)  
**Meaning:** 금, 돈  
**Note:** 金曜日는 금요일이다.

### 土

**Reading:** ど / つち (do / tsuchi)  
**Meaning:** 흙, 토  
**Note:** 土曜日는 토요일이다.

## 방향과 위치

### 上

**Reading:** じょう / うえ (jō / ue)  
**Meaning:** 위, 올리다  
**Note:** 위치와 상승을 나타낸다.

### 下

**Reading:** か / した (ka / shita)  
**Meaning:** 아래, 내리다  
**Note:** 위치와 하강을 나타낸다.

### 中

**Reading:** ちゅう / なか (chū / naka)  
**Meaning:** 안, 가운데  
**Note:** 범위 안이나 중앙을 나타낸다.

### 外

**Reading:** がい / そと (gai / soto)  
**Meaning:** 밖, 외부  
**Note:** 外出은 외출이라는 뜻이다.

### 前

**Reading:** ぜん / まえ (zen / mae)  
**Meaning:** 앞, 이전  
**Note:** 공간의 앞과 시간의 이전을 나타낸다.

### 後

**Reading:** ご / うしろ (go / ushiro)  
**Meaning:** 뒤, 이후  
**Note:** 공간의 뒤와 시간의 이후를 나타낸다.

## 사람과 신체

### 人

**Reading:** じん / ひと (jin / hito)  
**Meaning:** 사람  
**Note:** 국적이나 직업을 나타내는 복합어에도 쓴다.

### 私

**Reading:** し / わたし (shi / watashi)  
**Meaning:** 나, 사적인 것  
**Note:** わたし는 기본적인 일인칭 표현이다.

### 体

**Reading:** たい / からだ (tai / karada)  
**Meaning:** 몸  
**Note:** 신체나 전체 형태를 나타낸다.

### 手

**Reading:** しゅ / て (shu / te)  
**Meaning:** 손  
**Note:** 동작, 기술, 사람을 나타내는 복합어에도 쓰인다.

### 目

**Reading:** もく / め (moku / me)  
**Meaning:** 눈  
**Note:** 시각 기관과 순서를 나타낸다.

### 口

**Reading:** こう / くち (kō / kuchi)  
**Meaning:** 입, 입구  
**Note:** 사람 수나 출입구를 나타내는 말에도 쓰인다.

### 耳

**Reading:** じ / みみ (ji / mimi)  
**Meaning:** 귀  
**Note:** 듣는 기관을 나타낸다.

## 가족과 관계

### 父

**Reading:** ふ / ちち (fu / chichi)  
**Meaning:** 아버지  
**Note:** 자기 아버지를 말할 때 ちち를 쓴다.

### 母

**Reading:** ぼ / はは (bo / haha)  
**Meaning:** 어머니  
**Note:** 자기 어머니를 말할 때 はは를 쓴다.

### 子

**Reading:** し / こ (shi / ko)  
**Meaning:** 아이, 자식  
**Note:** 사람이나 작은 대상을 나타내는 복합어에 자주 쓰인다.

### 友

**Reading:** ゆう / とも (yū / tomo)  
**Meaning:** 친구  
**Note:** 友達은 ともだち다.

## 자연

### 山

**Reading:** さん / やま (san / yama)  
**Meaning:** 산  
**Note:** 산 이름에서는 읽기가 달라질 수 있다.

### 川

**Reading:** せん / かわ (sen / kawa)  
**Meaning:** 강, 내  
**Note:** 지명과 성씨에 자주 나타난다.

### 海

**Reading:** かい / うみ (kai / umi)  
**Meaning:** 바다  
**Note:** 해양 관련 복합어에서는 かい가 흔하다.

### 空

**Reading:** くう / そら (kū / sora)  
**Meaning:** 하늘, 비다  
**Note:** 空港에서는 くう로 읽는다.

### 天

**Reading:** てん (ten)  
**Meaning:** 하늘  
**Note:** 날씨와 천상을 나타내는 복합어에 쓰인다.

### 雨

**Reading:** う / あめ (u / ame)  
**Meaning:** 비  
**Note:** 단독으로는 보통 あめ라고 읽는다.

### 花

**Reading:** か / はな (ka / hana)  
**Meaning:** 꽃  
**Note:** 花火에서는 はなび로 읽는다.

## 기본 동작

### 行

**Reading:** こう / いく (kō / iku)  
**Meaning:** 가다, 행하다  
**Note:** 문맥에 따라 おこなう로도 읽는다.

### 来

**Reading:** らい / くる (rai / kuru)  
**Meaning:** 오다  
**Note:** 来月은 らいげつ다.

### 帰

**Reading:** き / かえる (ki / kaeru)  
**Meaning:** 돌아가다  
**Note:** 집이나 원래 장소로 돌아가는 동작을 나타낸다.

### 食

**Reading:** しょく / たべる (shoku / taberu)  
**Meaning:** 먹다, 음식  
**Note:** 食べる와 食事에서 읽기가 다르다.

### 飲

**Reading:** いん / のむ (in / nomu)  
**Meaning:** 마시다  
**Note:** 飲む는 음료나 약을 마시는 동작이다.

### 見

**Reading:** けん / みる (ken / miru)  
**Meaning:** 보다  
**Note:** 시각으로 보거나 의견을 나타낼 때 쓴다.

### 聞

**Reading:** ぶん / きく (bun / kiku)  
**Meaning:** 듣다, 묻다  
**Note:** 듣기와 질문하기에 같은 훈독을 쓴다.

### 話

**Reading:** わ / はなす (wa / hanasu)  
**Meaning:** 말하다, 이야기  
**Note:** 電話와 話す에서 읽기가 다르다.

### 読

**Reading:** どく / よむ (doku / yomu)  
**Meaning:** 읽다  
**Note:** 読書는 どくしょ다.

### 書

**Reading:** しょ / かく (sho / kaku)  
**Meaning:** 쓰다, 글  
**Note:** 글씨나 문서를 쓰는 동작을 나타낸다.

### 買

**Reading:** ばい / かう (bai / kau)  
**Meaning:** 사다  
**Note:** 買い物은 쇼핑이라는 뜻이다.

### 売

**Reading:** ばい / うる (bai / uru)  
**Meaning:** 팔다  
**Note:** 물건을 판매하는 동작을 나타낸다.

### 住

**Reading:** じゅう / すむ (jū / sumu)  
**Meaning:** 살다, 거주하다  
**Note:** 住所는 주소라는 뜻이다.

## 크기와 상태

### 大

**Reading:** だい / おおきい (dai / ōkii)  
**Meaning:** 크다, 큰 것  
**Note:** 大人에서는 おとな로 읽는다.

### 小

**Reading:** しょう / ちいさい (shō / chiisai)  
**Meaning:** 작다, 작은 것  
**Note:** 크기와 중요도가 작은 상태를 나타낸다.

### 高

**Reading:** こう / たかい (kō / takai)  
**Meaning:** 높다, 비싸다  
**Note:** 높이와 가격에 모두 쓴다.

### 安

**Reading:** あん / やすい (an / yasui)  
**Meaning:** 싸다, 편안하다  
**Note:** 가격이 낮거나 마음이 편한 상태를 나타낸다.

### 新

**Reading:** しん / あたらしい (shin / atarashii)  
**Meaning:** 새롭다  
**Note:** 새 물건과 새 상태를 나타낸다.

### 古

**Reading:** こ / ふるい (ko / furui)  
**Meaning:** 오래되다, 옛것  
**Note:** 시간상 오래된 상태를 나타낸다.

### 良

**Reading:** りょう / よい (ryō / yoi)  
**Meaning:** 좋다  
**Note:** 구어에서는 いい라는 형태도 자주 쓴다.

### 悪

**Reading:** あく / わるい (aku / warui)  
**Meaning:** 나쁘다  
**Note:** 상태, 품질, 행동이 좋지 않음을 나타낸다.

### 早

**Reading:** そう / はやい (sō / hayai)  
**Meaning:** 이르다, 빠르다  
**Note:** 시간적으로 이름을 나타낸다.

### 寒

**Reading:** かん / さむい (kan / samui)  
**Meaning:** 춥다  
**Note:** 날씨나 몸이 느끼는 추위를 나타낸다.
