# Directions (방향/위치) - Korean Translation

이 페이지는 한국인이 일본어 방향·위치 어휘를 학습할 때 사용하는 한국어 관점 참고 자료입니다. 기본 방위 (左/右/上下/远近) + 위치 지시 (ここ/そこ/間) 를 다룹니다. 각 단어의 한국어 정의, 발음 (히라가나/로마자), 한자 어원, 한국어 예문, 한국·일본 문화적 맥락을 포함합니다.

**참고:** 본 페이지는 `wiki/Japanese/vocabulary/directions-vocabulary.md` 의 한국어 번역/관점 페이지 입니다. 일본어 원문 표제(見出し)는 한자 + 히라가나(讀み方) 형식으로 표기.

## 기본 방위 (Basic Directions)

### 左 (ひだり)

**품사:** 명사 (noun)

**정의:** 왼쪽 — 신체의 좌측, 또는 우측을 기준으로 한 좌측 방향. 한국어 "왼쪽" / 한자어 "좌(左)" 와 의미 동일.

**読み方 (읽는 법):** ひだり (히라가나) / hidari (로마자) / 左 (한자, 音読み: さ sa, 訓読み: ひだり hidari)

**IPA / 발음:** /hi.da.ɾi/

**어원:** 漢字 "左" (음読み さ, 訓読み ひだり). 한국어 한자어 "좌(左)" 동일 한자, 한국어 역음 "좌". 어원: 上代 일본어 "左" 의 음독은 "사" (左). 훈독 "ひだり" 어원은 "hilati" (古形) → "hidari" (中古). 어원설: 隠語 "ひだり" (tate/sitatari 의 隠語) 또는 "hilati" (직접 어원 불명).

#### 예문

- 角を**左**に曲がってください。 — 모퉁이를 왼쪽으로 돌아 주세요. (길찾기, 캐주얼)
- 私の部屋は**左**側にあります。 — 제 방은 왼쪽에 있습니다. (위치 묘사)
- **左**手を挙げてください。 — 왼손을 들어 주세요. (의료·체육)

#### 관련 용어

- 左側 (ひだりがわ) — 「왼쪽 (측면 강조)」
- 左折 (させつ) — 「좌회전 (음읽)」
- 左右 (さゆう) — 「좌우 (음읽)」
- 左利き (ひだりきき) — 「왼손잡이」
- [[directions-vocabulary]] — 방위 어휘

#### 문화적 맥락

일본·중국·한국 모두 **左 (왼쪽)** 의 자리매김 가벼움 (vs **右** 가 무거움). **左大臣 (사다이지ん)** = 일본 고대 으뜸 관리 (1인자). 한국·일본 모두 **左遷 (좌천, させん)** = 좌천. 일상 회화에서는 **左 (ひだり)** 발음 "히다리" 의 -다리 (다리) 가 한국어 "다리" 와 같이 들림 — 한국어 화자에게 발음 함정. 한국어 "왼쪽" 과 비교.

### 右 (みぎ)

**품사:** 명사 (noun)

**정의:** 오른쪽 — 신체의 우측, 또는 좌측을 기준으로 한 우측 방향. 한국어 "오른쪽" / 한자어 "우(右)" 와 의미 동일.

**読み方 (읽는 법):** みぎ (히라가나) / migi (로마자) / 右 (한자, 音読み: う u / ゆう yuu, 訓読み: みぎ migi)

**IPA / 발음:** /mi.ɡi/

**어원:** 漢字 "右" (음읽 う/ゆう, 訓읽 みぎ). 한국어 한자어 "우(右)" 동일 한자, 한국어 역음 "우". 어원: 上代 일본어 "右" 의 음독은 "우" (右). 훈독 "みぎ" 어원은 "migi" (中期 이후 정착). 의미 어원: 상형文字 손 오른쪽.

#### 예문

- 店は**右**にあります。 — 가게는 오른쪽에 있습니다. (위치 묘사)
- 三つ目の角を**右**に曲がってください。 — 세 번째 모퉁이에서 오른쪽으로 돌아 주세요. (길찾기)
- **右**を向いてください。 — 오른쪽을 봐 주세요. (의료·체육)

#### 관련 용어

- 右側 (みぎがわ) — 「오른쪽 (측면 강조)」
- 右折 (うせつ) — 「우회전 (음읽)」
- 右手 (みぎて) — 「오른손」
- 右利き (みぎきき) — 「오른손잡이」
- [[directions-vocabulary]] — 방위 어휘

#### 문화적 맥락

일본어 **右 (みぎ)** 발음 "미기" 의 -기 (기) 가 한국어 "기" 와 같이 들림 — 한국어 화자에게 비교적 친숙한 발음. **右大臣 (うだいじん)** = 고대 으뜸 관리 (1인자). 일본·한국 모두 **右翼 (우익, うよく)** = 정치 우파. **右に出る者 (右に出る者)** = "제자를 능가하는 자" (한국어 "가슴속" 대비). 발음 학습: みぎ (mi-gi) — 한국어 ㄱ (g) 발음 연습.

### まっすぐ

**품사:** 부사 (adverb)

**정의:** 직진 — 방향 변환 없이 곧장 앞으로. 한국어 "직진" / "곧장" 의미.

**読み方 (읽는 법):** まっすぐ (히라가나) / massugu (로마자) / 漢字: 真っ直ぐ (정자체: 眞直ぐ)

**IPA / 발음:** /mas.sɯ.ɡɯ/

**어원:** 漢字 "真っ直ぐ" (ま "眞" (진실) + っ 강조 + すぐ (곧다/바르다)). "眞" 음읽 しん/ま, 訓읽 ま. "直" 음읽 ちょく/じき, 訓읽 なお.すぐ (곧다) 어원: タ行 カ행 4단 활용 형용사「すぐし」중고 일본어 → 중세.

#### 예문

- 二つブロック**まっすぐ**進んでください。 — 두 블록 직진해 주세요. (길찾기, 격식)
- **まっすぐ**立っている。 — 똑바로 서 있다. (자세, 상태)
- 彼の話は**まっすぐ**だった。 — 그의 말은 정직했다. (인품 묘사)

#### 관련 용어

- 直ぐ (すぐ) — 형용사 「곧다/즉시」
- 直進 (ちょくしん) — 「직진 (음읽)」
- 一直線 (いっちょくせん) — 「일직선」
- 真 (ま / しん) — 「참/진실」
- [[directions-vocabulary]] — 방위 어휘

#### 문화적 맥락

일본어 **まっすぐ (massugu)** 발음의 っ (촉음) 와 す (s) 조합 — 한국어 화자에게 촉음 연습 중요. (suttsu, mattu 등 자음 동족). **真っ直ぐ (じ기에 강조)** 와 **すぐ (기본형)** 의 의미 차이: まっすぐ = "정직한/똑바른/직진" (방향·성격), すぐ = "곧/즉시/직진 (단순)". 한국어 "곧장" 은 부사, "곧다" 는 형용사 — 형태소 대응.

### 上 (うえ)

**품사:** 명사 (noun) — 위치/방향

**정의:** 위 — 수직 상방, 또는 상대적으로 높은 위치. 한국어 "위" / 한자어 "상(上)" 의미. 비유: " 윗사람 (윗자리)" / "초등학교 1학년 (上和)"

**読み方 (읽는 법):** うえ (히라가나) / ue (로마자) / 上 (한자, 音読み: じょう jou / しょう shou / かみ kami, 訓読み: うえ ue / うわ uwa / かみ kami)

**IPA / 발음:** /ɯ.e/

**어원:** 漢字 "上" (음읽 じょう/しょう/かみ, 訓읽 うえ/うわ/かみ). 한국어 한자어 "상(上)" 동일 한자, 한국어 역음 "상". 어원: 상형문자 "ㅡ" (기준선) 위에 "|" (선이 위에 있음) → "위".

#### 예문

- 階段を**上**がります。 — 계단을 올라갑니다. (이동, 캐주얼)
- 机の**上**に本があります。 — 책상 위에 책이 있습니다. (위치)
- **上**を向いてください。 — 위를 봐 주세요. (방향 지시)

#### 관련 용어

- 上に (うえに) — 「위에 (조사 포함)」
- 上手 (じょうず) — 「능숙 (음읽)」
- 上の (うえの) — 「위의 (관형사)」
- 上る (のぼる) — 「오르다 (동사)」
- [[directions-vocabulary]] — 방위 어휘

#### 문화적 맥락

일본어 **上 (うえ)** 는 단순 위치 외 사회적 의미. **上 (かみ)** = 윗사람, 상급자. **上座 (かみざ, 上席)** = 윗자리 (격식 자리배치). 한국·일본 모두 **上 (상)** 이 위계 개념 포함. 일본어 **上を見る (うえをみる)** = "위를 보다 / 가능성을 보다". 한국어 화자에게 うえ (u-e) 와 した (shi-ta) 의 ㄷ 발음 (ta) 대비. 한국어 "위" / "우에" 는 위치 외 사회적 의미 약함.

### 下 (した)

**품사:** 명사 (noun) — 위치/방향

**정의:** 아래 — 수직 하방, 또는 상대적으로 낮은 위치. 한국어 "아래" / 한자어 "하(下)" 의미.

**読み方 (읽는 법):** した (히라가나) / shita (로마자) / 下 (한자, 音読み: か ka / げ ge, 訓読み: した shita / しも shimo / もと moto / さげる sageru)

**IPA / 발음:** /ɕi.ta/

**어원:** 漢字 "下" (음읽 か/げ, 訓읽 した/しも/もと). 한국어 한자어 "하(下)" 동일 한자, 한국어 역음 "하". 어원: 상형문자 "ㅡ" (기준선) 아래 "V" (선이 아래) → "아래".

#### 예문

- エスカレーターで**下**ります。 — 에스컬레이터로 내려갑니다. (이동, 캐주얼)
- 机の**下**に猫がいます。 — 책상 아래에 고양이가 있습니다. (위치)
- **下**を向いてください。 — 아래를 봐 주세요. (방향 지시)

#### 관련 용어

- 下に (したに) — 「아래에 (조사 포함)」
- 下の (したの) — 「아래의 (관형사)」
- 下りる (おりる) — 「내리다 (동사)」
- 下手 (へた) — 「서투름 (음읽)」
- [[directions-vocabulary]] — 방위 어휘

#### 문화적 맥락

일본어 **下 (した)** 는 위치 외 사회적 의미. **下 (しも)** = 아랫사람, 하급자. **下座 (しもざ, 下席)** = 아랫자리 (격식 자리배치). 한국·일본 모두 **下 (하)** 가 위계 개념 포함. **地下鉄 (ちかてつ)** = "지하철" (지하 + 鉄) — 한국어 "지하철" 동일. 발음: した (shi-ta) — 한국어 화자에게 し (shi) 발음 연습 중요. 한국어 "아래" 와 비교.

## 위치 지시 (Location Deixis)

### ここ

**품사:** 부사 / 대명사 (지시대명사)

**정의:** 여기 — 말하는 사람의 바로 옆·근처·현재 위치. 한국어 "여기" 의미.

**読み方 (읽는 법):** ここ (히라가나) / koko (로마자) / 漢字: 此処 (こ) — 고유어, 漢字 표기는 此 / 此處

**IPA / 발음:** /ko.ko/

**어원:** 고유어 (和語). "こ" = "이 (場所)" 의 강조형, "こ" 중첩. 어원: 上代 일본어 "ここ" (古事記 712년 기록). 한국어 "여기" (指小辞 -이 + 곳 어근)와 어원 상이.

#### 예문

- **ここ**はあなたのパスポートです。 — 여기는 당신의 여권입니다. (대조, 격식)
- **ここ**に名前を書いてください。 — 여기에 이름을 써 주세요. (지시, 격식)
- **ここ**から始めましょう。 — 여기서 시작합시다. (이동 지시)

#### 관련 용어

- そこ (soko) — 「저기 (듣는 사람 가까이)」
- あそこ (asoko) — 「저기 (둘 다 먼 곳)」
- どこ (doko) — 「어디 (의문사)」
- こちら (kochira) — 「이쪽 (정중)」
- [[directions-vocabulary]] — 방위 어휘

#### 문화적 맥락

일본어 **ここ (koko)** 발음 "코코" — 한국어 화자에게 한국어 "코코" 와 발음 유사. 일상 회화 빈도 매우 높음. 격식 표현: **こちら (kochira)** + **です**. 캐주얼: **ここ**. 한국어 "여기" / "여" (구어) / "이쪽" (격식) 매핑. **ここ** 와 **こちら** 의 뉘앙스: ここ (식사점/캐주얼) vs こちら (격식·정중 — 미화 표현).

### そこ

**품사:** 부사 / 대명사 (지시대명사)

**정의:** 저기 — 듣는 사람 가까이, 또는 두 사람 모두에게서 약간 먼 위치. 한국어 "저기" 의미.

**読み方 (읽는 법):** そこ (히라가나) / soko (로마자) / 漢字: 其処 — 고유어, 漢字 표기는 其 / 其處

**IPA / 발음:** /so.ko/

**어원:** 고유어 (和語). "そ" = "저 (場所)" 의 강조형, "そ" 중첩. 어원: 上代 일본어 "そこ". 한국어 "저기" (指小辞 -이 + 곳 어근) 와 어원 상이.

#### 예문

- **そこ**に银行があります。 — 저기에 은행이 있습니다. (위치, 격식)
- **そこ**に座ってください。 — 저기에 앉아 주세요. (지시, 격식)
- **そこ**から先は危険です。 — 저기서부터 앞은 위험합니다. (이동 경계)

#### 관련 용어

- ここ (koko) — 「여기 (말하는 사람 가까이)」
- あそこ (asoko) — 「저기 (둘 다 먼 곳)」
- どこ (doko) — 「어디 (의문사)」
- そちら (sochira) — 「저쪽 (정중)」
- [[directions-vocabulary]] — 방위 어휘

#### 문화적 맥락

일본어 **そこ (soko)** 발음 "소코" — 한국어 "소코" 와 발음 유사. **ここ·そこ·あそこ·どこ** 의 4단 거리 시스템 — 한국어의 "여기·저기·저기·어디" 와 매핑. 한국어 "거기" (구어 캐주얼) 와 そこ 동일. 격식: **そちら**. 캐주얼: **そこ**. 발음 연습: そ (so) — 한국어 ㄱ 발음 (g) 와 다소 차이.

### 近く (ちかく)

**품사:** 명사 (noun) / 부사 (adverb)

**정의:** 가까이 — 공간적·시간적으로 가까운 위치. 한국어 "가까이" / "근처" 의미.

**読み方 (읽는 법):** ちかく (히라가나) / chikaku (로마자) / 漢字: 近く (한자, 音読み: きん kin, 訓読み: ちか chika + く 부사화)

**IPA / 발음:** /tɕi.ka.kɯ/

**어원:** 漢字 "近" (음읽 きん, 訓읽 ちか 4단활용형). 부사화 接尾辞 "-く" (くの活用). 한국어 한자어 "근(近)" 동일 한자, 한국어 역음 "근". 한국어 "가까이" 어원: 순 우리말 "가까" + 부사화 "-이".

#### 예문

- 私の家は駅の**近く**です。 — 저의 집은 역 근처입니다. (위치, 명사)
- **近く**に住んでいます。 — 가까이 살고 있습니다. (위치, 명사)
- **近く**で見せてください。 — 가까이서 보여 주세요. (부사, 지시)

#### 관련 용어

- 近くの人 (ちかくのひと) — 「가까운 사람/근처 사람」
- 近くする (ちかくする) — 「가깝게 하다 (복종, 친근)」
- 最も近い (もっともちかい) — 「가장 가까운 (比較)」
- 近い (ちかい) — 형용사 「가깝다」
- [[directions-vocabulary]] — 방위 어휘

#### 문화적 맥락

일본어 **近く (ちかく)** 와 한국어 "가까이/근처" 의 어원 비교: 일본어 한자음 음 + 부사화, 한국어 순 우리말 + 부사화. 일상 회화에서 **近く** (명사) 와 **近くに** (명사 + 조사) 구분. **近く** 의 형용사형 **近い (ちかい)** — 한국어 "가깝다". 발음: ちかく (chi-ka-ku) — 한국어 화자에게 ち (chi) 발음 연습.

### 遠く (とおく)

**품사:** 명사 (noun) / 부사 (adverb)

**정의:** 멀리 — 공간적·시간적으로 먼 위치. 한국어 "멀리" / "먼 곳" 의미.

**読み方 (읽는 법):** とおく (히라가나) / tooku (로마자) / 漢字: 遠く (한자, 音読み: えん en / おん on, 訓読み: とお to + く 부사화)

**IPA / 발음:** /to.o.kɯ/

**어원:** 漢字 "遠" (음읽 えん/おん, 訓읽 とお 4단활용형). 부사화 接尾辞 "-く". 한국어 한자어 "원(遠)" 동일 한자, 한국어 역음 "원". 한국어 "멀리" 어원: 순 우리말 "멀다" + 부사화 "-이".

#### 예문

- 机场はここから**遠く**です。 — 공항은 여기서 멉니다. (위치, 격식)
- **遠く**に住んでいます。 — 멀리 살고 있습니다. (위치, 캐주얼)
- **遠く**から見ても見えます。 — 멀리서 봐도 보입니다. (시점, 부사)

#### 관련 용어

- 遠くの人 (とおくのひと) — 「먼 사람/먼 곳 사람」
- 遠足 (えんそく) — 「소풍 (음읽)」
- 遠い (とおい) — 형용사 「멀다」
- 永遠 (えいえん) — 「영원 (음읽)」
- [[directions-vocabulary]] — 방위 어휘

#### 문화적 맥락

일본어 **遠く (とおく)** 발음 "토오쿠" — 长母音 (long vowel) お + ㄱ 발음 연습. 한국어 "멀리" 와 부사화 어원 비교. 일상 회화: **遠く** (부사) 와 **遠くに** (명사 + 조사) 구분. 형용사 **遠い (とおい)** = "멀다". 일본어 **遠方 (えんぽう, 멀리)** = 격식/문학 표현. 한국어 "멀리" / "먼" 의 어원 비교.

### 間 (あいだ)

**품사:** 명사 (noun)

**정의:** 사이 — 둘 사이의 공간적/시간적 간격. 한국어 "사이" / "동안" 의미.

**読み方 (읽는 법):** あいだ (히라가나) / aida (로마자) / 間 (한자, 音読み: かん kan / げん gen / けん ken, 訓読み: あいだ aida / ま ma)

**IPA / 발음:** /a.i.da/

**어원:** 漢字 "間" (음읽 かん/げん/けん, 訓읽 あいだ/ま). 한자 본래 의미: "두 개의 문의 사이 (gate opening)". 한국어 한자어 "간(間)" 동일 한자, 한국어 역음 "간". 한국어 "사이" 어원: 순 우리말 (어원 미상).

#### 예문

- 银行はホテルと駅の**間**にあります。 — 은행은 호텔과 역 사이에 있습니다. (위치, 격식)
- 2 時の**間**に会いましょう。 — 2시 사이에 만납시다. (시간, 격식)
- 友達の**間**で人気があります。 — 친구들 사이에서 인기가 있습니다. (관계)

#### 관련 용어

- 間に合う (まにあう) — 「제시간에 맞추다 (훈련·시간)」
- 間に (まに) — 「사이에 (음읽)」
- 空間 (くうかん) — 「공간 (음읽)」
- 間違い (まちがい) — 「실수 (음읽, "間" 파생)」
- [[directions-vocabulary]] — 방위 어휘

#### 문화적 맥락

일본어 **間 (あい다)** 의 한글 표기 모순 — 한국어 "사이다" 와 발음 동일. 한국어 "사이" 와 다른 발음. 漢字 "間" 의 다의성: 공간 사이 (あいだ), 시간 동안 (あいだ), 쉬는 시간 (ま), 객간 (げん). 한국어 "간" (한자어) "사이" (고유어) 의 고저 맥락 동일. 일상 회화 多用 — 공간/시간 표현 범용.
