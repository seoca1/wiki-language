# Months (월) - Korean Translation

이 페이지는 한국인이 일본어 월(月) 어휘를 학습할 때 사용하는 한국어 관점 참고 자료입니다. 1月~10月 (일월~시월) 발음 변이 (四/七/九 = しかつ/しちがつ/くがつ) 를 다룹니다. 각 단어의 한국어 정의, 발음 (히라가나/로마자), 한자 어원, 한국어 예문, 한국·일본 월 표현 비교를 포함합니다.

**참고:** 본 페이지는 `wiki/Japanese/vocabulary/months-vocabulary.md` 의 한국어 번역/관점 페이지 입니다. 일본어 원문 표제(見出し)는 한자 + 히라가나(讀み方) 형식으로 표기.

## 월 (Months 1-10)

### 一月 (いちがつ)

**품사:** 명사 (noun)

**정의:** 1월 — 제1월. 한국어 "1월" / 한자어 "일월(一月)" 의미.

**読み方 (읽는 법):** いちがつ (히라가나) / ichigatsu (로마자) / 一月 (한자, 音読み: いちがつ ichigatsu)

**IPA / 발음:** /i.tɕi.gat͡sɯ/

**어원:** 漢字 "一" (음읽 いち) + "月" (음읽 がつ, 訓읽 つき). 한국어 한자어 "일월(一月)" 동일 한자, 한국어 역음 "일월". 어원: 一 = 1, 月 = 달 (음읽 がつ = 음양력의 朔望月).

#### 예문

- **一月**は最初の月です。 — 1월은 첫 번째 달입니다. (서수, 격식)
- **一月**は寒いです。 — 1월은 춥습니다. (계절, 캐주얼)
- **一月**一日 (いちがつ ついたち) — 「1월 1일 (일본 발음 변이)」

#### 관련 용어

- 一月 (いちがつ) — 「1월 (캐주얼)」
- 正月 (しょうがつ) — 「설날 (1월 초)」
- 一月 (いちがつ) — 「1월 (격식 동일)」
- 睦月 (むつき) — 「1월 (옛 이름)」
- [[months-vocabulary]] — 월 어휘

#### 문화적 맥락

일본어 **一月 (いちがつ)** 발음 "이치가쓰" — 한국어 "일월" (한자어) 와 발음 유사. 캐주얼: いちがつ / 발음 변이: ついたち (1일). 한국어 "1월" / 한자어 "일월" 동일. **正月 (しょうがつ, 설날)** = 한국어 "설날" 동일 — 1월 1일. 일본 **お正月 (おしょうがつ)** = "설날" (1월 1일~3일). 한국어 "설날" 과 어원이 다름 (일본 → 正月, 한국 → 설날). 발음: いちがつ (i-chi-ga-tsu) — 한국어 ㅊ + ㄱ + ㅅ 발음 연습.

**어원:** 漢字 "九" (음읽 く) + "月" (음읽 がつ). 한국어 한자어 "구월(九月)" 동일 한자, 한국어 역음 "구월". 어원: 九 = 9, 月 = 달.

#### 예문

- **九月**は秋です。 — 9월은 가을입니다. (계절, 캐주얼)
- **九月**は台風の季節です。 — 9월은 태풍의 계절입니다. (날씨, 격식)
- **九月**に始業式があります。 — 9월에 시업식이 있습니다. (학사, 격식)

#### 관련 용어

- 九月 (くがつ) — 「9월 (캐주얼)」
- 九月 (くがつ) — 「9월 (격식 동일)」
- 長月 (ながつき) — 「9월 (옛 이름)」
- 菊月 (きくづき) — 「9월 (옛 이름, 국화)」
- [[months-vocabulary]] — 월 어휘

#### 문화적 맥락

일본어 **九月 (くがつ)** 발음 "쿠가쓰" — 한국어 "구월" (한자어) 와 발음 유사. 캐주얼: くがつ / 음읽: く (9). 한국어 "9월" / 한자어 "구월" 동일. **九月 (쿠가쓰)** = 일본 **秋 (あき, 가을)** 시작 — 한국어 "가을" (9-11월) 동일. **台風 (たいふう, 태풍)** = 한국어 "태풍" 빈번 (8-9월). **台風の目 (たいふうのめ)** = 한국어 "태풍의 눈" 동일. 발음: くがつ (ku-ga-tsu) — 한국어 ㅋ + ㄱ + ㅅ 발음 연습.

### 十月 (じゅうがつ)

**품사:** 명사 (noun)

**정의:** 10월 — 제10월. 한국어 "10월" / 한자어 "시월(十月)" 의미.

**読み方 (읽는 법):** じゅうがつ (히라가나) / juugatsu (로마자) / 十月 (한자, 音読み: じゅうがつ juugatsu)

**IPA / 발음:** /dʑɯː.gat͡sɯ/

**어원:** 漢字 "十" (音읽 じゅう) + "月" (음읽 がつ). 한국어 한자어 "시월(十月)" 동일 한자, 한국어 역음 "시월". 어원: 十 = 10, 月 = 달.

#### 예문

- **十月**はハロウィンがあります。 — 10월은 할로윈이 있습니다. (명절, 캐주얼)
- **十月**は紅葉の季節です。 — 10월은 단풍의 계절입니다. (계절, 격식)
- **十月**から新年度です。 — 10월부터 새해입니다. (학사, 격식)

#### 관련 용어

- 十月 (じゅうがつ) — 「10월 (캐주얼)」
- 十月 (じゅうがつ) — 「10월 (격식 동일)」
- 神無月 (かんなづき) — 「10월 (옛 이름)」
- ハロウィン (harouin) — 「할로윈 (외래어)」
- [[months-vocabulary]] — 월 어휘

#### 문화적 맥락

일본어 **十月 (じゅうがつ)** 발음 "주-가쓰" — 한국어 "시월" (한자어) 와 발음 유사. 캐주얼: じゅうがつ / 음읽: じゅう (10). 한국어 "10월" / 한자어 "시월" 동일. **十月 (주가쓰)** = 일본 **神無月 (かんなづき, 10월)** = 한국어 "시월" (음력). 일본 학년도 시작 = 4월 / 한국 = 3월. **ハロウィン (harouin, 할로윈)** = 한국어 "할로윈" 동일 (10월 31일). 발음: じゅうがつ (ju-u-ga-tsu) — 장음 お + ㅇ + ㄱ + ㅅ 발음 연습.
