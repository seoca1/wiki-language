# Shopping (쇼핑) - Korean Translation

이 페이지는 한국인이 일본어 쇼핑 어휘를 학습할 때 사용하는 한국어 관점 참고 자료입니다. 가게 (店) + 돈 (お金/現金/カード) + 가격 (価格/安い/高い) + 쇼핑 활동 (割引/返品/買う/売る/試着) + 일본 특유 (コンビニ/お釣り) 등 18 entries 를 다룹니다. 각 단어의 한국어 정의, 발음 (히라가나/로마자), 한자 어원, 한국어 예문, 한국·일본 쇼핑 문화 비교를 포함합니다.

**참고:** 본 페이지는 `wiki/Japanese/vocabulary/shopping-vocabulary.md` 의 한국어 번역/관점 페이지 입니다. 일본어 원문 표제(見出し)는 한자 + 히라가나(讀み方) 형식으로 표기.

## 가게 (店 - Stores)

### 店 (みせ)

**품사:** 명사 (noun)

**정의:** 가게 — 상점. 한국어 "가게" 의미.

**読み方 (읽는 法):** みせ (히라가나) / mise (로마자) / 店 (한자, 音読み: てん ten, 訓読み: みせ mise)

**IPA / 발음:** /mi.se/

**어원:** 漢字 "店" (음읽 てん, 訓읽 みせ). 한국어 한자어 "점(店)" 의미. 어원: 广 (지붕) + 戔 (높다) → 지붕이 높은 집 = 가게.

#### 예문

- 近くに**店**がありますか? — 근처에 가게가 있나요? (질문, 캐주얼)
- **コンビニ**が一番便利です。 — 편의점이 가장 편리합니다. (평가, 캐주얼)
- この**店**は安いです。 — 이 가게는 쌉니다. (평가, 캐주얼)

#### 관련 용어

- 店 (みせ) — 「가게 (한자어)」
- 商店 (しょうてん) — 「상점 (한자어)」
- お店 (おみせ) — 「가게 (존칭)」
- コンビニ (konbini) — 「편의점 (외래어)」
- スーパー (sūpā) — 「슈퍼」
- [[shopping-vocabulary]] — 쇼핑 어휘

#### 문화적 맥략

일본어 **店 (みせ)** 발음 "미세" — 한국어 "미세" 와 발음 동일. 캐주얼: 店 (mi-se) / 음읽: てん (ten). 한국어 "가게" / 한자어 "점(店)" 의미. 일본 가게 종류: コンビニ (편의점) / スーパー (슈퍼) / デパート (백화점) / 药店 (약국) / 100円ショップ (백엔숍) — 한국 비교. 발음: みせ (mi-se) — ㄴ + ㅅ 발음 연습.

## 돈 (Money)

### お金 (おかね)

**품사:** 명사 (noun)

**정의:** 돈 — 화폐. 한국어 "돈" 의미.

**読み方 (읽는 법):** おかね (히라가나) / okane (로마자) / 漢字: 金 (かね/きん, 한자어)

**IPA / 발음:** /o.ka.ne/

**어원:** 和語 — お (honorific, 존칭) + 金 (かね, 돈). 어원: 金 (금속) → 화폐의 어원. 한국어 "돈" 어원: 어원 불명 (한자어 차용 추정).

#### 예문

- **お金**がありません。 — 돈이 없습니다. (부재, 캐주얼)
- **お金**を借りたいです。 — 돈을 빌리고 싶습니다. (요구, 캐주얼)
- **お金**を貯めます。 — 돈을 모읍니다. (저축, 캐주얼)

#### 관련 용어

- お金 (おかね) — 「돈 (존칭)」
- 金 (かね) — 「돈 (구어)」
- 現金 (げんきん) — 「현금」
- 通貨 (つうか) — 「통화 (한자어)」
- [[shopping-vocabulary]] — 쇼핑 어휘

#### 문화적 맥략

일본어 **お金 (おかね)** 발음 "오카네" — 한국어 "오카네" 와 발음 동일. 캐주얼: お金 (o-ka-ne) / 和語: 金 (ka-ne). 한국어 "돈" 동일. **お金 (존칭)** vs **金 (구어)** — 한국어 "돈" (구어) / "금전" (한자어) 의 어원 비교. 한국어 화자가 **金 (카네)** 발음 (k-a-n-e) 연습. 발음: おかね (o-ka-ne) — ㄴ + ㄱ + ㄴ 발음 연습.

## 가격 (Price)

### 価格 (かかく)

**품사:** 명사 (noun)

**정의:** 가격 — 값. 한국어 "가격" / 한자어 "가격(價格)" 의미.

**読み方 (읽는 법):** かかく (히라가나) / kakaku (로마자) / 価格 (한자, 音読み: かかく kakaku)

**IPA / 발음:** /ka.ka.kɯ/

**어원:** 漢字 "価" (음읽 か/け, 訓읽 あたい) + "格" (음읽 かく/こう/しゃく, 訓읽 -.なし). 한국어 한자어 "가격(價格)" 동일 한자, 한국어 역음 "가격". 어원: 価 (값) + 格 (등급) = 값의 등급 = 가격.

#### 예문

- **価格**はいくらですか? — 가격 얼마예요? (질문, 캐주얼)
- **価格**表を見せてください。 — 가격표를 보여주세요. (요청, 격식)
- **価格**が高いです。 — 가격이 비쌉니다. (평가, 캐주얼)

#### 관련 용어

- 価格 (かかく) — 「가격 (한자어)」
- 値段 (ねだん) — 「값 (한자어)」
- 料金 (りょうきん) — 「요금」
- 市場価格 (しじょうかかく) — 「시장 가격」
- [[shopping-vocabulary]] — 쇼핑 어휘

#### 문화적 맥략

일본어 **価格 (かかく)** 발음 "카카쿠" — 한국어 "가격" (한자어) 와 발음 동일. 캐주얼: 価格 (ka-ka-ku) / 음읽: かかく. 한국어 "가격" 동일. **価格 (가격)** vs **値段 (값)** vs **料金 (요금)** — 한국어 "가격" / "값" / "요금" 의 어원 비교. 발음: かかく (ka-ka-ku) — 촉음 っ + ㄱ + ㄱ + ㅋ + ㅇ 발음 연습.

### 安い (やすい)

**품사:** い형용사 (i-adjective)

#### 예문

#### 관련 용어

- [[shopping-vocabulary]] — 쇼핑 어휘

#### 문화적 맥략

- **お釣り**がないです。 — 거스름돈이 없습니다. (상황, 캐주얼)
- お釣りミスは (おつり ミス) — 「거스름돈 실수」

#### 관련 용어

- お釣り (おつり) — 「거스름돈 (구어)」
- 釣銭 (つりせん) — 「거스름돈 (한자어)」
- お釣りミスは (おつり ミス) — 「거스름돈 실수」
- 細かい (こまかい) — 「잔돈」

#### 문화적 맥략

일본어 **お釣り (おつり, 거스름돈)** 발음 "오츠리" — 한국어 "오츠리" 와 발음 동일. 캐주얼: お釣り (o-tsu-ri) / 한자어: 釣銭 (つりせん). 한국어 "거스름돈" 의미. **お釣り (와어 거스름돈)** + **釣銭 (한자어 거스름돈)** + **細かい (와어 잔돈)** — 한국어 "거스름돈" 의 어원 비교. **お釣り (お + 釣り)** 의 어원: お (존칭) + 釣り (낚시/잔돈) → 한국어 "거스름돈" 의 어원 비교. 발음: おつり (o-tsu-ri) — 촉음 っ + ㅅ + ㄹ 발음 연습.
