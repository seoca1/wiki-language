# Numbers (숫자) - Korean Translation

이 페이지는 한국인이 일본어 기수 (cardinal numbers) 어휘를 학습할 때 사용하는 한국어 관점 참고 자료입니다. 一~十 (1~10) + 두 가지 발음 변이 (四: よん/し, 七: なな/しち, 九: きゅう/く) 를 다룹니다. 각 단어의 한국어 정의, 발음 (히라가나/로마자), 한자 어원, 한국어 예문, 한국·일본 숫자 문화 비교를 포함합니다.

**참고:** 본 페이지는 `wiki/Japanese/vocabulary/numbers-vocabulary.md` 의 한국어 번역/관점 페이지 입니다. 일본어 원문 표제(見出し)는 한자 + 히라가나(讀み方) 형식으로 표기.

## 기수 (Cardinal Numbers 1-10)

### 一 (いち)

**품사:** 수 (num)

**정의:** 1 — 한 자리 자연수 첫 번째. 한국어 "하나" (고유어) / "일" (한자어) 의미.

**読み方 (읽는 법):** いち (히라가나) / ichi (로마자) / 一 (한자, 音読み: いち ichi / いつ itsu)

**IPA / 발음:** /i.tɕi/

**어원:** 漢字 "一" (음읽 いち/いつ, 訓읽 ひと.つ). 한국어 한자어 "일(一)" 의미. 어원: 一 (한 획) → 하나.

#### 예문

- 猫を**一**匹飼っています。 — 고양이를 한 마리 키우고 있습니다. (수량, 격식)
- **一**時に会いましょう。 — 1시에 만납시다. (시간, 격식)
- **一**番好きです。 — 가장 좋아합니다. (최상, 캐주얼)

#### 관련 용어

- 一 (いち) — 「1 (음읽)」
- 一つ (ひとつ) — 「하나 (명사)」
- 一 (ひと) — 「하나 (훈읽, 1부)」
- 一人 (ひとり) — 「한 명 (사람)」
- [[numbers-vocabulary]] — 숫자 어휘

#### 문화적 맥락

일본어 **一 (いち)** 발음 "이치" — 한국어 "이치" (道理, 道理) 와 발음 동일. **いち** : 음읽 (숫자) / **いつ** : 음읽 (1월 = 一月 いちがつ vs 일월). 한국어 "하나" / "일" (한자어) / "한" (관형사) 과 동일. 일상 회화: **一つ (ひとつ)** + **一人 (ひとり)** = 한국어 "하나" / "한 명". 한국어 "첫째" (序数) vs 일본어 **一番 (いちばん)** = 한국어 "첫째" 동일. 발음: いち (i-chi) — 한국어 ㅊ 발음 연습.

### 二 (に)

**품사:** 수 (num)

**정의:** 2 — 두 번째 자연수. 한국어 "둘" (고유어) / "이" (한자어) 의미.

**読み方 (읽는 법):** に (히라가나) / ni (로마자) / 二 (한자, 音読み: に ni / じ ji)

**IPA / 발음:** /ni/

**어원:** 漢字 "二" (음읽 に/じ, 訓읽 ふた.つ). 한국어 한자어 "이(二)" 의미. 어원: 二 (두 획) → 둘.

#### 예문

- 木に**二**羽の鳥がいます。 — 나무에 두 마리 새가 있습니다. (수량, 격식)
- **二**時に会いましょう。 — 2시에 만납시다. (시간, 격식)
- **二**人兄弟です。 — 두 형제입니다. (관계, 캐주얼)

#### 관련 용어

- 二 (に) — 「2 (음읽)」
- 二つ (ふたつ) — 「둘 (명사)」
- 二 (ふ) — 「2 (음읽, 단독)」
- 二人 (ふたり) — 「두 명 (사람)」
- [[numbers-vocabulary]] — 숫자 어휘

#### 문화적 맥락

일본어 **二 (に)** 발음 "니" — 한국어 "니" (당신) 와 발음 동일. **に** : 표준 (예: 2시 = にじ) / **ふ** : 단독 발음 (예: 二人 ふたり). 한국어 동일 패턴 (둘 = 2, "두" = 관형사). 한국어 "이(二)" / "두" 의 어원 (한자어/고유어). 발음: に (ni) — 한국어 ㄴ 발음 연습.

### 三 (さん)

**품사:** 수 (num)

**정의:** 3 — 세 번째 자연수. 한국어 "셋" (고유어) / "삼" (한자어) 의미.

**読み方 (읽는 법):** さん (히라가나) / san (로마자) / 三 (한자, 音読み: さん san)

**IPA / 발음:** /san/

**어원:** 漢字 "三" (음읽 さん, 訓읽 みっ.つ). 한국어 한자어 "삼(三)" 의미. 어원: 三 (세 획) → 셋.

#### 예문

- **三**はラッキー番号です。 — 3은 행운의 숫자입니다. (관습, 캐주얼)
- **三**時に電話してください。 — 3시에 전화해 주세요. (시간, 격식)
- **三**人兄弟です。 — 세 형제입니다. (관계, 캐주얼)

#### 관련 용어

- 三 (さん) — 「3 (음읽)」
- 三つ (みっつ) — 「셋 (명사)」
- 三人 (さんにん) — 「세 명 (사람)」
- 三日 (みっか) — 「3일 (날짜)」
- [[numbers-vocabulary]] — 숫자 어휘

#### 문화적 맥락

일본어 **三 (さん)** 발음 "산" — 한국어 "산" (山, 산) 과 발음 동일. 한국어 "삼" / "셋" 동일. 일상 회화: **三つ (みっつ)** = "셋" (명사). 발음: さん (sa-n) — 한국어 ㅅ + ㄴ 발음 연습. **三 (3)** 는 일본어 **敬語 (경어)** 의 기본 호칭 — さん (Mr./Ms.) — 한국어 "씨" 와 유사.

### 四 (よん/し)

**품사:** 수 (num)

**정의:** 4 — 네 번째 자연수. 한국어 "넷" (고유어) / "사" (한자어) 의미. 일본어 발음 변이: よん (캐주얼) / し (격식).

**読み方 (읽는 법):** よん / し (히라가나) / yon / shi (로마자) / 四 (한자, 音読み: し shi, 訓読み: よっ.つ yottsu / よん yon)

**IPA / 발음:** /jon/ / /ɕi/

**어원:** 漢字 "四" (음읽 し, 訓읽 よ/よっ.つ). 한국어 한자어 "사(四)" 의미. 어원: 四 (네 획) → 넷.

#### 예문

- 一年に**四**季があります。 — 일년에 사계절이 있습니다. (시각, 격식)
- **四**時に会いましょう。 — 4시에 만납시다. (시간, 격식)
- **四**人家族です。 — 네 식구입니다. (가족, 캐주얼)

#### 관련 용어

- 四 (よん) — 「4 (캐주얼)」
- 四 (し) — 「4 (격식, 4월 = 四月 しがつ)」
- 四つ (よっつ) — 「넷 (명사)」
- 四人 (よにん) — 「네 명 (캐주얼)」
- 四人 (しにん) — 「네 명 (격식)」
- [[numbers-vocabulary]] — 숫자 어휘

#### 문화적 맥락

일본어 **四 (よん / し)** 발음 변이 — 한국어 "사" (한자어) 는 동일하나 발음 변이: よん (캐주얼, 四人 よにん) / し (격식, 四月 しがつ). **사 (4)** 의 한자어 인연 = "四" (死 죽음) 와 동음 (한국어 "사") — 중국·일본·한국 모두 **4 (사)** 를 불길한 숫자로 인식. 일본어 よん (음) = 회피 발음. 한국어 "사" / "넉" (관형사) 동일. 발음: よん (yon) — 한국어 ㅇ + ㄴ 발음 연습.

**품사:** 수 (num)

**정의:** 5 — 다섯 번째 자연수. 한국어 "다섯" (고유어) / "오" (한자어) 의미.

#### 예문

#### 관련 용어

### 七 (なな/しち)

**품사:** 수 (num)

**정의:** 7 — 일곱 번째 자연수. 한국어 "일곱" (고유어) / "칠" (한자어) 의미. 일본어 발음 변이: なな (캐주얼) / しち (격식).

**IPA / 발음:** /na.na/ / /ɕi.tɕi/

**어원:** 漢字 "七" (음읽 しち, 訓읽 なな). 한국어 한자어 "칠(七)" 의미. 어원: 七 (일곱 획) → 일곱.

- **七**時に会いましょう。 — 7시에 만납시다. (시간, 격식)

#### 관련 용어

- 七 (なな) — 「7 (캐주얼)」

- 七つ (ななつ) — 「일곱 (명사)」
- 七人 (ななにん) — 「일곱 명 (캐주얼)」
- 七人 (しちにん) — 「일곱 명 (격식)」
- [[numbers-vocabulary]] — 숫자 어휘

#### 문화적 맥락

### 十 (じゅう)

**품사:** 수 (num)

**정의:** 10 — 열 번째 자연수. 한국어 "열" (고유어) / "십" (한자어) 의미.

**読み方 (읽는 법):** じゅう (히라가나) / juu (로마자) / 十 (한자, 音読み: じゅう juu / じつ jitsu, 訓読み: とお/と)

**IPA / 발음:** /dʑɯː/

**어원:** 漢字 "十" (음읽 じゅう/じつ, 訓읽 とお/と). 한국어 한자어 "십(十)" 의미. 어원: 十 (십 획) → 열.

#### 예문

- 指が**十**本、足も**十**本あります。 — 손가락이 열 개, 발도 열 개 있습니다. (신체, 캐주얼)
- **十**時に寝ます。 — 10시에 잠듭니다. (시간, 캐주얼)
- **十**時に会いましょう。 — 10시에 만납시다. (시간, 격식)

#### 관련 용어

- 十 (じゅう) — 「10 (음읽)」
- 十 (とお) — 「10 (훈읽, 한 단독)」
- 十人 (じゅうにん) — 「열 명 (사람)」
- 十日 (とおか) — 「10일 (날짜)」
- 十 (と) — 「10 (한자 독음)」
- [[numbers-vocabulary]] — 숫자 어휘

#### 문화적 맥락

일본어 **十 (じゅう)** 발음 "주" — 한국어 "주" (주다) 와 발음 동일. 캐주얼: じゅう / 한자 독음: とお / 単: と. 한국어 "열" / "십" (한자어) 동일. 일상 회화: **十 (じゅう)** + **十日 (とおか)** = 날짜 발음 변이. 발음: じゅう (ji-u) — 장음 + ㅇ 발음 연습. **十 (10)** = 한국·일본 모두 완전한 수 (음양오행의 土).
