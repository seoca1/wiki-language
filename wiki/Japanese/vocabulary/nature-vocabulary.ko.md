# Nature & Weather (자연·날씨) - Korean Translation

한국인이 일본어 자연·날씨 어휘를 학습할 때 사용하는 한국어 관점 참고. 30개 어휘 (날씨/하늘/자연/계절변화) 와 한국어 한자어 비교.

**참고:** 본 페이지는 `wiki/Japanese/vocabulary/nature-vocabulary.md` 의 한국어 번역/관점 페이지 (concise aggregator).

## 날씨 (Weather)

### 天気 (てんき)

**한국어:** 날씨 — 한국어 "날씨" / 한자어 "천기(天氣)" 동일.

**読み方:** てんき (tenki) / 한자: 天気 (음읽 てんき)

#### 예문

- 天気がいいですね。 — 날씨가 좋네요. (평가, 캐주얼)
- 天気を確認します。 — 날씨를 확인합니다. (행위, 격식)

#### 한국어 학습 노트

일본어 天気 (てんき) = 한국어 "날씨". **天 (하늘) + 気 (기운)** = 자연의 기상 상태. **한국어 "일기예보"** 비교.

**한국어:** 감기 — 한국어 "감기" 의미.

**読み方:** かぜ (kaze) / 한자: 風邪 (음읽 ふうじゃ)

#### 한국어 학습 노트

**風邪 (かぜ)** = 한국어 "감기". **한자어 風 (바람) + 邪 (사기)** = 바람의 사기 = 감기 (한자 의역). **風 (바람) + 邪 (사기)** = /**한자어 병명 어원 분석** = 한국어 "감기" 와 어원 일치.
