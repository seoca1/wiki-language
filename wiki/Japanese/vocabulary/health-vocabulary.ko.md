# Health (건강) - Korean Translation

이 페이지는 한국인이 일본어 의료·건강 어휘를 학습할 때 사용하는 한국어 관점 참고 자료입니다. 의료施設 (病院/医者/薬局) + 약 (薬) + 증상 (頭痛/熱/風邪) + 신체部位 (頭/胃) + 예약 (予約) 을 다룹니다. 각 단어의 한국어 정의, 발음 (히라가나/로마자), 한자 어원, 한국어 예문, 한국·일본 의료 문화 비교를 포함합니다.

**참고:** 본 페이지는 `wiki/Japanese/vocabulary/health-vocabulary.md` 의 한국어 번역/관점 페이지 입니다. 일본어 원문 표제(見出し)는 한자 + 히라가나(讀み方) 형식으로 표기.

## 의료시설 (Medical Facilities)

### 病院 (びょういん)

**품사:** 명사 (noun)

**정의:** 병원 — 종합병원. 한국어 "병원" / 한자어 "병원(病院)" 와 의미 동일.

**読み方 (읽는 法):** びょういん (히라가나) / byouin (로마자) / 病院 (한자, 音読み: びょういん byouin)

**IPA / 발음:** /bjoː.in/

**어원:** 漢字 "病" (음읽 びょう/へい, 訓읽 や.む/やまい) + "院" (음읽 いん, 訓읽 いん). 한국어 한자어 "병원(病院)" 동일 한자, 한국어 역음 "병원". 어원: 病 = 병, 院 = 건물/원.

#### 예문

- **病院**は駅の近くです。 — 병원은 역 근처입니다. (위치, 격식)
- **病院**に行きます。 — 병원에 갑니다. (방문, 캐주얼)
- 大きい**病院**で働いています。 — 큰 병원에서 일합니다. (직장, 격식)

#### 관련 용어

- 病院 (びょういん) — 「병원 (종합)」
- 医院 (いいん) — 「의원 (개인)」
- 診療所 (しんりょうしょ) — 「진료소 (소형)」
- 救急病院 (きゅうきゅうびょういん) — 「응급 병원」
- [[health-vocabulary]] — 건강 어휘

#### 문화적 맥락

일본어 **病院 (びょういん)** 발음 "뵤인" — 한국어 "병원" (한자어) 와 발음 유사. 캐주얼: 病院 / 격식: 総合病院 (そうごうびょういん). 한국어 "병원" + "의원" / "한의원" / "한방병원" 의 어원 비교. 일본 의료체계: **保険証 (ほけんしょう, 건강보험증)** 필수 — 한국어 "건강보험증" 동일. 발음: びょういん (byo-u-in) — 한국어 ㅂ + ㅇ + ㄴ 발음 연습.

### 医者 (いしゃ)

**품사:** 명사 (noun)

**정의:** 의사 — 의학 전문가. 한국어 "의사" / 한자어 "의사(醫者)" 의미.

**読み方 (읽는 법):** いしゃ (히라가나) / isha (로마자) / 医者 (한자, 音読み: いしゃ isha)

**IPA / 발음:** /i.ɕa/

**어원:** 漢字 "醫" (음읽 い, 訓읽 い.やす/い.する) + "者" (음읽 しゃ, 訓읽 もの). 한국어 한자어 "의자(醫者)" 의미. 어원: 醫 = 의술, 者 = 사람.

#### 예문

- **医者**に診てもらう必要があります。 — 의사에게 진료를 받아야 할 필요가 있습니다. (치료, 격식)
- **医者**になりたいです。 — 의사가 되고 싶습니다. (직업, 캐주얼)
- **医者**は土曜日も働きます。 — 의사는 토요일에도 일합니다. (근무, 격식)

#### 관련 용어

- 医者 (いしゃ) — 「의사 (일반)」
- 医師 (いし) — 「의사 (격식)」
- 内科医 (ないかい) — 「내과 의사」
- 外科医 (げかい) — 「외과 의사」
- [[health-vocabulary]] — 건강 어휘

#### 문화적 맥락

일본어 **医者 (いしゃ)** 발음 "이샤" — 한국어 "이샤" (伊射) 와 발음 동일. 캐주얼: 医者 / 격식: 医師 (いし). 한국어 "의사" + "한의사" (韓醫師) 의 어원 비교. 일본 **医師 (いし)** 의 국가시험 (医師国家試験) — 한국 "의사 국가시험" 동일. **お医者さん (おいしゃさん)** = 존칭. 발음: いしゃ (i-sha) — 한국어 ㅇ + ㅅ 발음 연습.

### 薬局 (やっきょく)

**품사:** 명사 (noun)

**정의:** 약국 — 약을 파는 곳. 한국어 "약국" / 한자어 "약국(藥局)" 의미.

**読み方 (읽는 법):** やっきょく (히라가나) / yakkyoku (로마자) / 薬局 (한자, 音読み: やっきょく yakkyoku)

**IPA / 발음:** /jak.kjok.kɯ/

**어원:** 漢字 "藥" (음읽 やく, 訓읽 くすり) + "局" (음읽 きょく, 訓읽 つま/つぼね). 한국어 한자어 "약국(藥局)" 동일 한자, 한국어 역음 "약국". 어원: 藥 = 약, 局 = 관청/국.

#### 예문

- **薬局**は遅くまで開いています。 — 약국은 늦게까지 열려 있습니다. (영업시간, 격식)
- **薬局**で薬を買います。 — 약국에서 약을 삽니다. (구매, 캐주얼)
- 近くの**薬局**はどこですか? — 근처 약국은 어디입니까? (위치, 격식)

#### 관련 용어

- 薬局 (やっきょく) — 「약국 (의약품)」
- ドラッグストア (doraggu sutoa) — 「드럭스토어 (생활용품 + 약)」
- 処方箋 (しょほうせん) — 「처방전」
- 薬剤師 (やくざいし) — 「약사」
- [[health-vocabulary]] — 건강 어휘

#### 문화적 맥락

일본어 **薬局 (やっきょく)** 발음 "약쿄쿠" — 한국어 "약국" (한자어) 와 발음 유사. 캐주얼: 薬局 (yak-kyo-ku) / 약자: 薬屋 (くすりや). 한국어 "약국" 동일. 일본 **薬局** vs **ドラッグストア (드럭스토어)** — 한국어 "약국" vs "올리브영" 의 구분. 일본 **処方箋 (しょほうせん, 처방전)** = 한국어 "처방전" 동일. 발음: やっきょく (ya-kkyo-ku) — 촉음 っ + ㄲ + ㅋ 발음 연습.

## 약 (Medicine)

### 薬 (くすり)

**품사:** 명사 (noun)

**정의:** 약 — 의약품. 한국어 "약" 의미.

**読み方 (읽는 법):** くすり (히라가나) / kusuri (로마자) / 薬 (한자, 音読み: やく yaku, 訓読み: くすり kusuri)

**IPA / 발음:** /kɯ.sɯ.ɾi/

**어원:** 漢字 "藥" (음읽 やく, 訓읽 くすり). 한국어 한자어 "약(藥)" 의미. 어원: 艹 (초) + 楽 (풍류) → 풀거름 약초 → 약.

#### 예문

- この**薬**を一日二回飲んでください。 — 이 약을 하루 두 번 드세요. (복용, 격식)
- **薬**は水と一緒に飲んでください。 — 약은 물과 함께 드세요. (복용, 격식)
- **薬**が効きます。 — 약이 듣습니다. (효과, 캐주얼)

#### 관련 용어

- 薬 (くすり) — 「약 (캐주얼)」
- 薬 (くすり) — 「약 (의약품)」
- 飲み薬 (のみぐすり) — 「먹는 약」
- 塗り薬 (ぬりぐすり) — 「바르는 약」
- 薬 (yaku) — 「약 (음읽, 한자어)」
- [[health-vocabulary]] — 건강 어휘

#### 문화적 맥락

일본어 **薬 (くすり)** 발음 "쿠스리" — 한국어 "쿠스리" (クスリ) 와 발음 동일. 캐주얼: くすり / 음읽: 薬 (やく). 한국어 "약" / 한자어 "약" (약) 동일. 일용어: **薬缶 (やかん, 주전자)** = "물주전자" (薬 약 缶 통) — 한국어 "주전자" 와 어원이 다름. **飲む (nomu, 마시다)** = 한국어 "마시다" (음료) / "드시다" (약). 발음: くすり (ku-su-ri) — 한국어 ㅅ + ㄹ 발음 연습.

## 증상 (Symptoms)

### 頭痛 (ずつう)

**품사:** 명사 (noun)

**정의:** 두통 — 머리 통증. 한국어 "두통" / 한자어 "두통(頭痛)" 의미.

**読み方 (읽는 法):** ずつう (히라가나) / zutsuu (로마자) / 頭痛 (한자, 音読み: ずつう zutsuu)

**IPA / 발음:** /zɯt.tsɯː/

**어원:** 漢字 "頭" (음읽 とう/ず, 訓읽 あたま/かしら) + "痛" (음읽 つう, 訓읽 いた.い/いた.む). 한국어 한자어 "두통(頭痛)" 동일 한자, 한국어 역음 "두통". 어원: 頭 = 머리, 痛 = 아프다.

#### 예문

- **頭痛**がします。 — 두통이 있습니다. (증상, 캐주얼)
- **頭痛**がひどい場合は医者に診てもらってください。 — 두통이 심하면 의사에게 진료를 받으세요. (조언, 격식)
- **頭痛**薬 (ずつうぐすり) — 「두통약 (캐주얼)」

#### 관련 용어

- 頭痛 (ずつう) — 「두통 (일반)」
- 偏頭痛 (へんずつう) — 「편두통」
- 頭が痛い (あたまがいたい) — 「머리가 아프다 (캐주얼)」
- 頭痛薬 (ずつうぐすり) — 「두통약」
- [[health-vocabulary]] — 건강 어휘

#### 문화적 맥락

일본어 **頭痛 (ずつう)** 발음 "즈쓰-" — 한국어 "두통" (한자어) 와 발음 유사. 캐주얼: 頭痛 (zu-tsu-u) / 발음 변이: ずつう (촉음 っ). 한국어 "두통" / 한자어 "두통" 동일. **頭痛 (ずつう)** 발음의 촉음 っ (small つ) — 한국어 화자에게 연음 처리 연습. **頭 (あたま)** 발음은 頭 (head) 와 등 (back) 의 어원: 한자음 つ (頭) vs あたま (普通の). 발음: ずつう (zu-tsu-u) — 한국어 ㅈ + ㅅ + ㅜ 발음 연습.

### 熱 (ねつ)

**품사:** 명사 (noun)

**정의:** 열 — 발열. 한국어 "열" (發熱) 의미 (한국어 "열"은 보통 fever).

**読み方 (읽는 법):** ねつ (히라가나) / netsu (로마자) / 熱 (한자, 音読み: ねつ netsu / ねっ netsu, 訓読み: あつ.い atsui)

**IPA / 발음:** /net͡sɯ/

**어원:** 漢字 "熱" (음읽 ねつ, 訓읽 あつ.い). 한국어 한자어 "열(熱)" 의미. 어원: 灬 (불/불볕) + 執 (집) → 불을 모음 → 열.

#### 예문

- 彼女は高い**熱**があります。 — 그녀는 높은 열이 있습니다. (증상, 격식)
- **熱**が下がりました。 — 열이 내렸습니다. (회복, 격식)
- **熱**があります。 — 열이 있습니다. (증상, 캐주얼)

#### 관련 용어

- 熱 (ねつ) — 「열 (발열)」
- 熱 (ねっ) — 「열 (촉음 변이, 단독)」
- 発熱 (はつねつ) — 「발열 (격식)」
- 熱がある (ねつがある) — 「열이 있다 (명사구)」
- [[health-vocabulary]] — 건강 어휘

#### 문화적 맥락

일본어 **熱 (ねつ)** 발음 "네쓰" — 한국어 "네쓰" (熱) 와 발음 동일. 캐주얼: 熱 (ne-tsu) / 격식: 発熱 (はつねつ). 한국어 "열" / 한자어 "열" 동일. **熱 (ねつ)** 와 **熱い (あつい, 뜨겁다)** 의 어원: 같은 한자 (熱) — 음읽 (ねつ) vs 훈읽 (あつい). 한국어 "열" (fever) / "뜨거움" (hot) 와 동일. **熱 (ねつ)** 가 발열, **熱 (あつい)** 가 더위. 발음: ねつ (ne-tsu) — 한국어 ㄴ + ㅅ + ㅅ 발음 연습.

### 風邪 (かぜ)

**품사:** 명사 (noun)

**정의:** 감기 — 코·목 등의 감기. 한국어 "감기" 의미.

**読み方 (읽는 법):** かぜ (히라가나) / kaze (로마자) / 風邪 (한자, 音読み: ふうじゃ fuuja, 訓読み: かぜ kaze)

**IPA / 발음:** /ka.ze/

**어원:** 漢字 "風" (음읽 ふう/ふ, 訓읽 かぜ) + "邪" (음읽 じゃ, 訓읽 よこしま). 한국어 한자어 "풍사(風邪)" 의미. 어원: 風 = 바람, 邪 = 사기/기운.

#### 예문

- **風邪**を引きました。 — 감기에 걸렸습니다. (질병, 캐주얼)
- **風邪**が治りました。 — 감기가 나았습니다. (회복, 캐주얼)
- **風邪**をひいて学校を休みました。 — 감기에 걸려 학교를 쉬었습니다. (결석, 캐주얼)

#### 관련 용어

- 風邪 (かぜ) — 「감기 (캐주얼)」
- 風邪 (ふうじゃ) — 「감기 (격식)」
- 風邪薬 (かぜぐすり) — 「감기약」
- 風邪気味 (かぜぎみ) — 「감기 기미 (살짝)」
- [[health-vocabulary]] — 건강 어휘

#### 문화적 맥락

일본어 **風邪 (かぜ)** 발음 "카제" — 한국어 "카제" (風 + 邪) 와 발음 동일. 캐주얼: 風邪 (かぜ) / 격식: 風邪 (ふうじゃ). 한국어 "감기" (感冒) 의 어원: 중세 한국어 감기 (寒氣). **風邪 (かぜ)** 의 어원: 風 (바람) + 邪 (사기) = "바람의 사기" → 현대 의미 "감기". 한자어 어원 동일. 발음: かぜ (ka-ze) — 한국어 ㅋ + ㅈ 발음 연습. **風邪 (かぜ)** = 한국어 "감기" + **風邪 (かぜ, 바람)** 의 어원 차이.

## 신체 (Body)

### 頭 (あたま)

**품사:** 명사 (noun)

**정의:** 머리 — 신체 머리 부분. 한국어 "머리" 의미.

**読み方 (읽는 법):** あたま (히라가나) / atama (로마자) / 頭 (한자, 音読み: とう tou / ず zu, 訓読み: あたま atama / かしら kashira)

**IPA / 발음:** /a.ta.ma/

**어원:** 漢字 "頭" (음읽 とう/ず, 訓읽 あたま/かしら). 한국어 한자어 "두(頭)" 의미. 어원: 豆 (콩) + 頁 (이마) → 이마 위의 작은 부분 → 머리.

#### 예문

- **頭**が痛みます。 — 머리가 아픕니다. (신체, 캐주얼)
- **頭**を使って考えましょう。 — 머리를 써서 생각해 봅시다. (사고, 격식)
- **頭**がいいです。 — 머리가 좋습니다 (똑똑함). (능력, 캐주얼)

#### 관련 용어

- 頭 (あたま) — 「머리 (캐주얼)」
- 頭 (かしら) — 「머리 (격식)」
- 頭 (ず) — 「머리 (음읽, 단독)」
- 頭部 (とうぶ) — 「두부 (의학)」
- 頭髪 (とうはつ) — 「두발 (머리카락)」
- [[health-vocabulary]] — 건강 어휘

#### 문화적 맥락

## 예약 (Appointment)

### 予約 (よやく)

**품사:** 명사 (noun) / する 동사

**정의:** 예약 — 미리 정함. 한국어 "예약" / 한자어 "예약(予約)" 의미.

**読み方 (읽는 법):** よやく (히라가나) / yoyaku (로마자) / 予約 (한자, 音読み: よやく yoyaku)

**IPA / 발음:** /jo.ja.kɯ/

**어원:** 漢字 "予" (음읽 よ/しゃ, 訓읽 あらかじ.め) + "約" (음읽 やく, 訓읽 つづ.まる/つづ.める). 한국어 한자어 "예약(予約)" 동일 한자, 한국어 역음 "예약". 어원: 予 = 미리, 約 = 정함.

#### 예문

- 医者の**予約**があります。 — 의사 예약이 있습니다. (예약, 격식)
- **予約**をお願いします。 — 예약 부탁합니다. (요청, 캐주얼)
- **予約**をキャンセルします。 — 예약을 취소합니다. (취소, 캐주얼)

#### 관련 용어

- 予約 (よやく) — 「예약 (명사)」

- 予約済み (よやくずみ) — 「예약 완료」
- 予約金 (よやくきん) — 「예약금」

#### 문화적 맥락

일본어 **予約 (よやく)** 발음 "요야쿠" — 한국어 "예약" (한자어) 와 발음 동일. 캐주얼: 予約 (yo-ya-ku) / 동사: 予約する (よやくする). 한국어 "예약" / 한자어 "예약" 동일. 일본 의료 **予約 (예약)** = 한국어 "예약" 동일. **予約 (예약)** 시스템: **ネット予約 (넷 예약)** = 한국어 "온라인 예약" 빈번. 발음: よやく (yo-ya-ku) — 한국어 ㅇ + ㅇ + ㄱ 발음 연습.
