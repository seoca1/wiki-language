# Technology (기술) - Korean Translation

이 페이지는 한국인이 일본어 기술·IT 어휘를 학습할 때 사용하는 한국어 관점 참고 자료입니다. 컴퓨터·전화·인터넷·이메일·웹사이트·앱·비밀번호·마우스·키보드·화면 등 일상에서 자주 사용되는 IT 기본 어휘를 다룹니다. 각 단어의 한국어 정의, 발음 (히라가나/로마자), 한자 어원, 한국어 예문, 한국·일본 IT 문화 비교를 포함합니다.

**참고:** 본 페이지는 `wiki/Japanese/vocabulary/technology-vocabulary.md` 의 한국어 번역/관점 페이지 입니다. 일본어 원문 표제(見出し)는 한자 + 히라가나(讀み方) 형식으로 표기.

## 컴퓨터/디바이스 (Computer/Devices)

### コンピュータ

**품사:** 명사 (noun)

**정의:** 컴퓨터 — 프로그램에 따라 데이터를 처리하는 전자 기기. 한국어 "컴퓨터" (loanword from English) 와 의미 동일.

**読み方 (읽는 법):** コンピュータ (히라가나 カタカナ) / konpyu-ta (로마자) / 漢字: 計算機 (けいさんき, keisanki)

**IPA / 발음:** /kom.pjuː.ta/

**어원:** 외래어 (外来語). 영어 "computer" → 일본어 カタカナ 転写 **コンピュータ**. 한국어 **컴퓨터** — 같은 어원 (영어 직접 차용). 한자 표기 가능: 計算機 (けいさんき, "계산하는 기계") — 격식/문학적 표현.

#### 예문

- 仕事で**コンピュータ**を使います。 — 직장에서 컴퓨터를 사용합니다. (직장, 격식)
- 新しい**コンピュータ**を買いました。 — 새 컴퓨터를 샀습니다. (구매, 캐주얼)
- **コンピュータ**が遅い。 — 컴퓨터가 느리다. (IT 일상)

#### 관련 용어

- PC (ピーシー) — 「PC (퍼스널 컴퓨터)」
- パソコン (pasokon) — 「パソコン (퍼스널 컴퓨터 약어)」
- 電子計算機 (でんしけいさんき) — 「전자 계산기 (격식)」
- ノートパソコン — 「노트북」
- [[technology-vocabulary]] — 기술 어휘

#### 문화적 맥락

일본어 **コンピュータ (konpyu-ta, 컴퓨터)** 발음의 長母音 (long vowel) お (o) + う (u) 조합 — 한국어 화자에게 ㄴ (n) + ㅋ (k) + ㅛ (yo) 발음 연습. 일상 회화에서 **パソコン (파손)** = "퍼스널 컴퓨터" (줄임말) — 더 자주 사용. 한국어 "컴퓨터" (loanword) 와 일본어 コンピュータ (loanword) 는 어원 동일. 일본 IT 업계: **IT (アイティー)** / **ICT (アイシーティー)** 약어 사용.

### 電話 (でんわ)

**품사:** 명사 (noun)

**정의:** 전화 — 음성 통신 장치 또는 통화. 한국어 "전화" / 한자어 "전화(電話)" 와 의미 동일.

**読み方 (읽는 법):** でんわ (히라가나) / denwa (로마자) / 電話 (한자, 音読み: でんわ denwa)

**IPA / 발음:** /den.wa/

**어원:** 漢字 "電" (음읽 でん) + "話" (음읽 わ, 訓읽 はなし/はな.す). 한국어 한자어 "전화(電話)" 동일 한자, 한국어 역음 "전화". 어원: 電 = 전기, 話 = 이야기/말.

#### 예문

- 私の**電話**は新しいです。 — 제 전화는 새 것입니다. (소유, 캐주얼)
- **電話**をかしてください。 — 전화를 끊어 주세요. (통화, 격식)
- **電話**で連絡します。 — 전화로 연락합니다. (커뮤니케이션, 격식)

#### 관련 용어

- 携帯電話 (けいたいでんわ) — 「휴대전화 (격식)」
- スマホ (sumaho) — 「스마트폰 (줄임말)」
- 公衆電話 (こうしゅうでんわ) — 「공중전화」
- 電話番号 (でんわばんごう) — 「전화번호」
- [[technology-vocabulary]] — 기술 어휘

#### 문화적 맥락

일본어 **電話 (でんわ)** 발음 "덴와" — 한국어 "전화" 와 발음 유사. 한국·일본 모두 **電話 (전화)** = 음성 통신. 일본 IT 트렌드: **スマホ (스마트폰)** 가 **携帯電話 (휴대전화)** 대체 — 격식/캐주얼 구분. 한국어 "전화" / "폰" 동일. 발음: でんわ (den-wa) — 한국어 ㄴ + ㄷ 발음 연습. 일본 **固定電話 (유선전화)** vs **携帯電話 (휴대전화)** — 한국어 동일 구분.

### インターネット

**품사:** 명사 (noun)

**정의:** 인터넷 — 전 세계 컴퓨터 네트워크. 한국어 "인터넷" (loanword) 와 의미 동일.

**読み方 (읽는 법):** インターネット (히라가나 カタカナ) / inta-netto (로마자) / 漢字: 互聯網 (일본 한자 X), 만국공용어

**IPA / 발음:** /in.taː.net.to/

**어원:** 외래어 (外来語). 영어 "internet" → 일본어 カタカナ 転写 **インターネット**. 한국어 **인터넷** — 같은 어원 (영어 직접 차용). 한자 표기 어려움 (보통 カタカナ만 사용).

#### 예문

- **インターネット**は速いです。 — 인터넷은 빠릅니다. (속도, 격식)
- **インターネット**で調べます。 — 인터넷으로 검색합니다. (검색, 캐주얼)
- **インターネット**に接続できません。 — 인터넷에 연결할 수 없습니다. (IT 일상)

#### 관련 용어

- ネット (netto) — 「ネット (인터넷, 줄임말)」
- Wi-Fi (ワイファイ) — 「와이파이」
- 回線 (かいせん) — 「회선」
- ブラウザ (bura-uza) — 「브라우저」
- [[technology-vocabulary]] — 기술 어휘

#### 문화적 맥락

일본어 **インターネット (inta-netto, 인터넷)** 발음의 촉음 っ (small つ) + ㄴ (n) + ㅅ (s) 조합 — 한국어 화자에게 촉음 연습. 일상 회화: **ネット (ネット)** = "인터넷" (줄임말) — 한국어 "넷" 동일. 일본 IT 업계: **ネット社会 (네트 사회)** / **ネット依存症 (인터넷 중독)** — 한국어와 동일. 발음: インターネット (in-ta-nnet-to) — 한국어 ㄴ + ㅅ 발음 연습.

### メール

**품사:** 명사 (noun)

**정의:** 이메일 — 전자 우편. 한국어 "이메일" (loanword) 와 의미 동일.

**読み方 (읽는 법):** メール (히라가나 カタカナ) / mēru (로마자) / 漢字: 電子郵便 (격식), Eメール (にゅう모어)

**IPA / 발음:** /meːɾɯ/

**어원:** 외래어 (外来語). 영어 "mail" → 일본어 カタカナ 転写 **メール**. 한국어 **메일** (영어 직접 차용) — 같은 어원. 비교: 영어 "email" → 한국어 "이메일" (직접 차용), 일본어 "Eメール / メール" (단순화).

#### 예문

- 毎日**メール**をチェックします。 — 매일 이메일을 확인합니다. (확인, 격식)
- **メール**を送ってください。 — 이메일을 보내 주세요. (발송, 격식)
- **メール**で連絡します。 — 이메일로 연락합니다. (커뮤니케이션, 격식)

#### 관련 용어

- 電子メール (でんしメール) — 「전자 우편 (격식)」
- メールマガジン — 「메일 매거진 (뉴스레터)」
- スパムメール — 「스팸 메일」
- 添付ファイル (てんぷファイル) — 「첨부 파일」
- [[technology-vocabulary]] — 기술 어휘

#### 문화적 맥락

일본어 **メール (mēru, 메일)** 발음의 長母音 (long vowel) え (e) + ㄹ (r) 조합 — 한국어 화자에게 ㄹ 발음 연습. 격식: **電子メール (でんしメール)** = "전자 메일" (한자어). 캐주얼: **メール** = "메일". 한국어 "이메일" / "메일" / "e-메일" 모두 사용. 일본 비즈니스: **メール** 가 **手紙 (편지)** 의 현대판 — 한국어와 동일 패턴.

### マウス

**품사:** 명사 (noun)

### キーボード

**품사:** 명사 (noun)

**정의:** 키보드 — 컴퓨터 입력 장치. 한국어 "키보드" (loanword) 와 의미 동일.

**読み方 (읽는 법):** キーボード (히라가나 カタカナ) / kī-bōdo (로마자) / 漢字: 鍵盤 (けんばん, 피아노), 計算機用鍵盤 (격식)

**IPA / 발음:** /kiː.boː.do/

**어원:** 외래어 (外来語). 영어 "keyboard" → 일본어 カタカナ 転写 **キーボード**. 한국어 **키보드** — 같은 어원. 한자 표현: 鍵盤 (けんばん) — 피아노/오르간에도 사용.

#### 예문

- メカニカル**キーボード**が好きです。 — 기계식 키보드를 좋아합니다. (취미, 캐주얼)
- **キーボード**で入力します。 — 키보드로 입력합니다. (입력, 격식)
- 日本語の**キーボード**を使います。 — 일본어 키보드를 사용합니다. (디바이스, 격식)

#### 관련 용어

- メカニカルキーボード — 「기계식 키보드」
- ワイヤレスキーボード — 「무선 키보드」
- ショートカット (shōtokatto) — 「단축키」
- タイピング (taipingu) — 「타이핑」
- [[technology-vocabulary]] — 기술 어휘

#### 문화적 맥락

일본어 **キーボード (kī-bōdo, 키보드)** 발음의 長母音 (long vowel) ㅣ (i) + ㅏ (a) + ㅜ (u) + ㅗ (o) 조합 — 한국어 "키-보-도" 발음 연습. 한국·일본 모두 **メカニカルキーボード (기계식 키보드)** 인기가수 — 게이밍/타이피스트. 한국어 "키보드" / "건반" (피아노) 의미 구분. 일본 특유: **JIS配列 (JIS 배열)** vs **US配列 (US 배열)** — 한국어 "한글 키보드" / "영문 키보드" 동일.

### 画面 (がめん)

**품사:** 명사 (noun)

**정의:** 화면 — 디스플레이 표면. 한국어 "화면" / 한자어 "화면(畫面)" 와 의미 동일.

**読み方 (읽는 법):** がめん (히라가나) / gamen (로마자) / 画面 (한자, 音読み: がめん gamen)

**IPA / 발음:** /ɡa.men/

**어원:** 漢字 "畫" (음읽 が/かく, 訓읽 えが.く/え) + "面" (음읽 めん, 訓읽 おも/おもて/つら). 한국어 한자어 "화면(畫面)" 동일 한자, 한국어 역음 "화면". 어원: 畫 = 그리다, 面 = 면.

#### 예문

- **画面**が明るすぎます。 — 화면이 너무 밝습니다. (IT 일상)
- **画面**を見てください。 — 화면을 봐 주세요. (지시, 격식)
- **画面**を閉じました。 — 화면을 닫았습니다. (IT 동작, 격식)

#### 관련 용어

- モニター (monitā) — 「모니터」
- スクリーン (sukuri-n) — 「스크린」
- ディスプレイ (disupurei) — 「디스플레이」
- 画面サイズ (がめんサイズ) — 「화면 크기」
- [[technology-vocabulary]] — 기술 어휘

#### 문화적 맥락

일본어 **画面 (がめん)** 발음 "가멘" — 한국어 "가면" (假面, 가면극) 과 발음 동일. 한국어 "화면" / "가면" 의미 명확히 구분. 한국어 "화면" + "액정" / "모니터" 모두 사용. 일본 IT: **スマホ画面 (스마트폰 화면)** 캐주얼 / **モニター (모니터)** 캐주얼 / **ディスプレイ (디스플레이)** 격식. 발음: がめん (ga-men) — 한국어 ㄱ + ㄴ 발음 연습.
