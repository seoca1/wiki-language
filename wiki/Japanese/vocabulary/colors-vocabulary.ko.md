# Colors (색상) - Korean Translation

이 페이지는 한국인이 일본어 색상 어휘를 학습할 때 사용하는 한국어 관점 참고 자료입니다. 기본 6색 (赤/青/緑/黄色/黒/白) 및 형용사형 (赤い/青い/緑の/黄色い) 을 다룹니다. 각 단어의 한국어 정의, 발음 (히라가나/로마자), 한자 어원, 한국어 예문, 한국·일본 문화적 맥락을 포함합니다.

**참고:** 본 페이지는 `wiki/Japanese/vocabulary/colors-vocabulary.md` 의 한국어 번역/관점 페이지 입니다. 일본어 원문 표제(見出し)는 한자 + 히라가나(讀み方) 형식으로 표기.

## 기본 색상 (Basic Colors - 6色)

### 赤 (あか)

**품사:** 명사 (noun) — 형용사형: 赤い (あかい)

**정의:** 빨강 — 가시광선에서 긴 파장 끝에 위치한 1차 색. 한국어 "빨강" / 한자어 "적(赤)" 과 의미 동일.

**読み方 (읽는 법):** あか (히라가나) / aka (로마자) / 赤 (한자, 音読み: せき seki, 訓読み: あか aka)

**IPA / 발음:** /a.ka/

**어원:** 漢字 "赤" (훈読み あか·音読み せき/しゃく). 한국어 한자어 "적(赤)" 과 같은 어원. 한국어 고유어 "빨강" 의 어원은 명확하지 않으나 형용사 어미 "-ㅎ-" 에서 파생으로 보는 설 있음. 일본어 "赤" 는 고대부터 사용, 奈良時代 문헌에 이미 등장.

#### 예문

- りんごは**赤**いです。 — 사과는 빨강입니다. (과일 색깔 묘사)
- **赤い**信号で止まりました。 — 빨간 신호등에서 멈췄습니다. (교통, 신호)
- 彼女の**赤**い帽子が可愛いです。 — 그녀의 빨간 모자가 귀엽습니다. (의상 묘사)

#### 관련 용어

- 赤い (あかい) — 형용사 「빨강의」
- 赤色 (せきしょく) — 명사 「빨강 (정식 명사)」
- 真っ赤 (まっか) — 부사 「새빨강의」
- [[colors-vocabulary]] — 색상 어휘

#### 문화적 맥락

일본 문화에서 **赤 (あか)** 는 단순한 색 이상. **赤 신사 (赤い鳥居)** 는 신성한 영역의 상징 (벳푸·이쓰쿠시마·기타키쓰 신사 등). 일본 전통 공연 (가부키) 에서 **赤** 은 충의/용기/정의의 상징 — 적장 (赤顔) 분장 사용. 한국·일본 모두 **赤信号 (あかしんごう)** = 정지 신호. 일본어 "あか" 발음은 한국어 "빨강" 과 다르며, あ/え 행 발음은 한국어 화자에게 어려움 (일본어 ㅐ/ㅔ = 한국어 ㅏ/ㅔ 사이).

### 青 (あお)

**품사:** 명사 (noun) — 형용사형: 青い (あおい)

**정의:** 파랑 — 가시광선에서 짧은 파장 쪽에 위치한 1차 색. 한국어 "파랑" / 한자어 "청(靑)" 과 의미 동일. 일본어 "青" 은 "푸른" 의미 외에 "靑" 의 green 의미로도 쓰임 (예: 青信号 = 초록 신호).

**読み方 (읽는 법):** あお (히라가나) / ao (로마자) / 青 (한자, 音読み: せい sei / しょう shou)

**IPA / 발음:** /a.o/

**어원:** 漢字 "青" (훈読み あお·音読み せい/しょう). 한국어 한자어 "청(靑)" 과 같은 한자 (中世 한국 한자음 청). 한국어 "파랑" 의 어원은 고유어 페(파) + -ang (형용사 어미).

#### 예문

- 空は**青**いです。 — 하늘은 파랑입니다. (자연, 하늘)
- **青い**海で泳ぎたいです。 — 파란 바다에서 수영하고 싶습니다. (여행, 바다)
- **青**い服が好きです。 — 파란 옷을 좋아합니다. (의상)

#### 관련 용어

- 青い (あおい) — 형용사 「파랑의」
- 青色 (せいしょく) — 명사 「파랑 (정식 명사)」
- 青信号 (あおしんごう) — 「파란/초록 신호 (일본 특유 의미)」
- 青春 (せいしゅん) — 「청춘」
- [[colors-vocabulary]] — 색상 어휘

#### 문화적 맥락

일본어 **青 (あお)** 은 한국어 "파랑" + "초록" 의 의미를 모두 포함. **青信号 (あおしんごう)** 은 한국어 "초록불" (진행 신호) 에 해당 — 한국어 화자가 가장 혼동하기 쉬운 부분. **青春 (せいしゅん, 청춘)** 은 한자어 그대로 한국어와 동일. **青は藍より出でて藍より青し** (청출어람) 는 일본화 · 한국화 모두 통용. **青森 (あおもり)** 는 지명 (靑森) — 한자음 qing/cheong 의 일본음 あお.

### 緑 (みどり)

**품사:** 명사 (noun) — 형용사형: 緑の (みどりの)

**정의:** 초록 — 청색과 황색 사이의 파장에 위치한 2차 색. 한국어 "초록" / 한자어 "록(綠)" 과 의미 동일.

**読み方 (읽는 법):** みどり (히라가나) / midori (로마자) / 緑 (한자, 音読み: りょく ryoku / ろく roku, 訓読み: みどり midori)

**IPA / 발음:** /mi.do.ɾi/

**어원:** 漢字 "綠" (음読み りょく/ろく, 訓読み みどり). 한국어 한자어 "록(綠)" 과 같은 한자, 고대 한국어 역음 "녹". 訓読み "みどり" 는 고대 "みどり (碧, 푸른빛)" + "り (里, 풍치)" 또는 "みず (水) + とり (鳥)" 설 등 어원 여러 설. 한국어 "초록" 은 초 (草) + 록 (綠).

#### 예문

- 草は**緑**です。 — 풀은 초록입니다. (자연, 풀)
- **緑の**山を見ました。 — 초록山을 보았습니다. (풍경)
- **緑**の茶碗が好きです。 — 초록 찻잔을 좋아합니다. (식기)

#### 관련 용어

- 緑の (みどりの) — 형용사 「초록의」
- 緑色 (りょくしょく) — 명사 「초록 (정식 명사)」
- 抹茶 (まっちゃ) — 「말차 (緑茶)」
- [[colors-vocabulary]] — 색상 어휘

#### 문화적 맥락

일본어 **緑 (みどり)** 는 식물·자연의 푸르름 상징. **抹茶 (まっちゃ, 말차)** 는 "緑茶" 라고도 부름. 신사·절의 신성한 영역에 **緑** 식물 (사당나무, 삼나무) 많이 심음. 한국과 동일한 의미. 일본어 **緑** 의 訓読み "みどり" 와 음読み "りょく" 구분 — 일상 회화에서는 みどり 사용, 학술·공식 명사는 りょく/緑色.

### 黄色 (きいろ)

**품사:** 명사 (noun) — 형용사형: 黄色い (きいろい)

**정의:** 노랑 — 가시광선에서 중간-짧은 파장 영역의 기본 색. 한국어 "노랑" / 한자어 "황(黃)" 과 의미 동일.

**読み方 (읽는 법):** きいろ (히라가나) / ki-iro (로마자) / 黄色 (한자, 音読み: おう ou / こう kou, 訓読み: きいろ kiiro)

**IPA / 발음:** /kiː.i.ɾo/

**어원:** 漢字 "黃" (음読み おう/こう, 訓読み き). 한자어 "황(黃)" + 접미사 "いろ (色, 색)" 합성. 한국어 한자어 "황(黃)" 은 동일 한자, 한국어 역음 "황". 한국어 "노랑" 은 순 우리말, 어원 불명.

#### 예문

- 太陽は**黄色**です。 — 태양은 노랑입니다. (자연, 태양)
- **黄色い**車があります。 — 노란 차가 있습니다. (사물 묘사)
- 秋の**黄色**い葉がきれいです。 — 가을의 노란 잎이 아름답습니다. (계절, 풍경)

#### 관련 용어

- 黄色い (きいろい) — 형용사 「노랑의」
- 黄色 (こうしょく / おうしょく) — 명사 「노랑 (정식 명사)」
- 黄色い声 (きいろいこえ) — 「날카로운/높은 목소리」
- 黄金 (おうごん) — 「황금」
- [[colors-vocabulary]] — 색상 어휘

#### 문화적 맥락

일본어 **黄色 (きいろ)** 는 단순한 색 이상. **黄色い声 (きいろいこえ)** = "날카로운/환호성" (예: 아이돌 콘서트 응원), 한국어 "노란 목소리" 와 다름. **黄色いニュース (きいろいニュース)** = 음란/저질 매체 (한국어 "노란 뉴스" 동일). **銀杏 (いちょう, 은행나무)** 가을에 노랗게 물듦 — 일본 + 한국 동일. 일본어 黄色 발음 "き.い.로" 는 한국어 화자에게 ㅣ/ㅔ 발음 구분 어려움.

### 黒 (くろ)

**품사:** 명사 (noun) — 형용사형: 黒い (くろい)

**정의:** 검정 — 가시광선이 거의 없는 (또는 모든 색을 흡수) 상태의 색. 한국어 "검정" / 한자어 "흑(黑)" 과 의미 동일.

**読み方 (읽는 법):** くろ (히라가나) / kuro (로마자) / 黒 (한자, 音読み: こく koku, 訓読み: くろ kuro)

**IPA / 발음:** /ku.ɾo/

**어원:** 漢字 "黑" (음読み こく, 訓読み くろ). 한국어 한자어 "흑(黑)" 동일 한자, 한국어 역음 "흑". 일본어 黒 발음 "くろ" 와 한국어 "검정" 의 어원은 모두 미상이나, 중세 한국어 "흑-" 계열/고대 일본어 "kuro" 의 인도유럽 어족 연관성도 일부 설 존재.

#### 예문

- 私の猫は**黒**です。 — 우리 고양이는 검정입니다. (동물)
- **黒い**靴を買いました。 — 검정 신발을 샀습니다. (의상)
- **黒**い雲が空を覆っています。 — 검은 구름이 하늘을 덮고 있습니다. (자연, 날씨)

#### 관련 용어

- 黒い (くろい) — 형용사 「검정의」
- 黒色 (こくしょく) — 명사 「검정 (정식 명사)」
- 黒板 (こくばん) — 「흑판」
- 黒字 (くろじ) — 「흑자 (재무)」
- 一日中 (いちにちじゅう / ひび) — 「하루종일 (검정 시간 표현 X)」
- [[colors-vocabulary]] — 색상 어휘

#### 문화적 맥락

일본어 **黒 (くろ)** 는 비공식/사적 영역 상징. **私服 (しふく)** "검정 옷" = 비즈니스·격식 default. 가부키에서 **黒** 분장 = 악역. 신사·절에서 **黒** = 장엄함, 비장함. 한국·일본 동일하게 **흑기사 / 黒い騎士** = 신비주의. 한국어 "검은 머리" (동양인) ↔ 일본어 "黒髪 (こくはつ)" 동일 개념. **黒歴史 (くろれきし)** = "검은 역사" (비유: 창피한 과거) — 한국어 "흑역사" 동일.

### 白 (しろ)

**품사:** 명사 (noun) — 형용사형: 白い (しろい)

**정의:** 하양 — 가시광선의 모든 파장이 반사되는 상태의 색. 한국어 "하양" / 한자어 "백(白)" 과 의미 동일.

**読み方 (읽는 법):** しろ (히라가나) / shiro (로마자) / 白 (한자, 音読み: はく haku / びゃく byaku, 訓読み: しろ shiro)

**IPA / 발음:** /ɕi.ɾo/

**어원:** 漢字 "白" (음読み はく/びゃく, 訓読み しろ). 한국어 한자어 "백(白)" 동일 한자, 한국어 역음 "백". 원시 슬라브어 *bolto 등 인접 어족과의 연관성 추정. 한국어 "하양" 의 어원은 불명.

#### 예문

- 雪は**白**いです。 — 눈은 하양입니다. (자연, 겨울)
- **白い**シャツを着ています。 — 하양 셔츠를 입고 있습니다. (의상)
- **白**い歯を見せる。 — 하얀 이를 보입니다. (외모)

#### 관련 용어

- 白い (しろい) — 형용사 「하양의」
- 白色 (はくしょく) — 명사 「하양 (정식 명사)」
- 白髪 (しらが / はくはつ) — 「흰머리 (訓読み 일상, 音読み 의학)」
- 面白い (おもしろい) — 「재미있는 (말 그대로: "顔が白い" 派生)」
- [[colors-vocabulary]] — 색상 어휘

#### 문화적 맥락

일본어 **白 (しろ)** 는 순수, 결백, 시작의 상징. 신부 의상 = **白無垢 (しろむく)** "하양 속옷" — 한국 한복 (赤色/靑色) 과 의상 색상관 대비. 합창단의 **白いブラウス** = 통일성. **白紙 (はくし)** = "백지" (시작, 재검토). **白髪 (しらが)** = 노년의 상징 — 한국어 "백발" 동일. 한국어 "하얗게 불태우다" ↔ 일본어 "白黒 (しろくろ) つける" (결판을 내다). 발음: しろ (shi-ro) — 한국어 화자에게 し (shi) 발음 연습 필요.

## 형용사 (Adjectives - 색상 + い)

### 赤い (あかい)

**품사:** い형용사 (i-adjective)

**정의:** 빨강의 — 명사 "赤" 에 형용사 어미 "-い" (状態) 결합. 한국어 "빨간 (관형사/형용사)" 과 의미 동일.

**読み方 (읽는 법):** あかい (히라가나) / akai (로마자)

**IPA / 발음:** /a.ka.i/

**어원:** 명사 "赤" + 형용사 어미 "-い". 역접미 "-い" 는 중세 일본어 "くわらひ" (く は 동사연결, ら わたり, ひ 強意) 에서 파생. 한국어 형용사 "빨간" 의 어원 (고유어 "빨강" + 관형사형 어미 "-ㄴ") 과 구조 상이.

#### 예문

- **赤い**車があります。 — 빨간 차가 있습니다. (관형)
- ボールが**赤い**です。 — 공이 빨강입니다. (서술)
- **赤**くなりながら咲く花。 — 빨갛게 피는 꽃. (부사적 용법)

#### 관련 용어

- 赤 (あか) — 명사 「빨강」
- 真っ赤 (まっか) — 부사 「새빨강의 (강조)」
- 赤い顔 (あかいかお) — 「붉은 얼굴 (수치/흥분)」
- [[colors-vocabulary]] — 색상 어휘

#### 문화적 맥락

일본어 **赤い (あかい)** 발음 "아카이" 끝의 -i 는 한국어 형용사 "-다" 와 다름. 한국어 화자는 일본어 형용사 활용 (赤い → 赤くない, 赤かった, 赤くて) 연습 필요. 일상 회화에서 赤い 는 의상, 음식, 자연 묘사 빈번. 한국어 "빨갛다" / "빨간" 둘 다 가능. 일본어 형용사 종결형은 "赤い" + "です" (격식) / "赤い" (캐주얼).

### 青い (あおい)

**품사:** い형용사 (i-adjective)

**정의:** 파랑의 — 명사 "青" 에 형용사 어미 "-い" 결합. 한국어 "파란" / 경우에 따라 "푸른" (자연물) 의미로도 쓰임.

**読み方 (읽는 법):** あおい (히라가나) / aoi (로마자)

**IPA / 발음:** /a.o.i/

**어원:** 명사 "青" + 형용사 어미 "-い". 어원 참조: 青色 형용사형.

#### 예문

- 彼女は**青い**ドレスを着ています。 — 그녀는 파란 드레스를 입고 있습니다. (의상)
- **青い**空がきれいです。 — 파란 하늘이 아름답습니다. (자연)
- **青い**りんごは熟していません。 — 푸른 사과는 익지 않았습니다. (자연 — 未熟)

#### 관련 용어

- 青 (あお) — 명사 「파랑/푸름」
- 青い鳥 (あおいとり) — 「푸른 새 (행복 상징)」
- 青ざめる (あおざめる) — 「창백해지다 (공포·질병)」
- [[colors-vocabulary]] — 색상 어휘

#### 문화적 맥락

일본어 **青い (あおい)** 는 한국어 "파란" + "푸른" 모두 포괄. **青い鳥 (あ오이 토리)** = "푸른 새" (Maeterlinck 동화, 행복 상징) — 한국 번역 "푸른 새" 동일. **青い顔 (あおい かお)** = "창백한 얼굴" (공포·질병) — 한국어 "파랗게 질린" 동일. 발음: あおい の お (o) + い (i) 연속 모음 — 한국어 화자에게 연음 처리 연습.

### 緑の (みどりの)

**품사:** 連体詞 (속성사) — 명사 "緑" + 격조사 "の"

**정의:** 초록의 — 명사 "緑" (みどり) 에 격조사 "の" 를 붙여 관형사(連体詞) 로 사용. 한국어 "초록의" / "초록 (관형사)" 의미.

**読み方 (읽는 법):** みどりの (히라가나) / midori-no (로마자)

**IPA / 발음:** /mi.do.ɾi.no/

**어원:** 緑 (みどり, 명사) + の (격조사). 한국어 "초록 + 의" 구조 동일.

#### 예문

- **緑の**りんごが好きです。 — 초록 사과를 좋아합니다. (음식, 미성숙)
- **緑の**山を見ました。 — 초록 산을 보았습니다. (자연, 풍경)
- **緑の**目をした人。 — 초록 눈을 가진 사람. (외모)

#### 관련 용어

- 緑 (みどり) — 명사 「초록」
- 緑の野菜 (みどりの やさい) — 「초록 채소」
- 緑の季節 (みどりの きせつ) — 「초록 계절 (봄·여름)」
- [[colors-vocabulary]] — 색상 어휘

#### 문화적 맥락

일본어 **緑の (みどりの)** 는 연체사 (連体詞) — 명사 앞에서만 사용. 한국어 "초록의" 동일. 종결 시 형용사형 **緑だ (みどりだ, "초록이다")** 또는 **緑である (みどりである, 격식)** 사용. 일상 회화에서는 **緑の + 명사** 패턴 빈번.

### 黄色い (きいろい)

**품사:** い형용사 (i-adjective)

**정의:** 노랑의 — 명사 "黄色" (きいろ) 에 형용사 어미 "-い" 결합. 한국어 "노란" 의미.

**読み方 (읽는 법):** きいろい (히라가나) / kiiroi (로마자)

**IPA / 발음:** /kiː.i.ɾo.i/

**어원:** 黄色 (きいろ, 黄色 어휘, 명사) + 형용사 어미 "-い". 한국어 "노란" 의 어원 (고유어 "노랗다" + 관형사 어미 "-ㄴ") 과 비교.

#### 예문

- **黄色い**車があります。 — 노란 차가 있습니다. (사물)
- 秋の**黄色い**葉。 — 가을의 노란 잎. (자연, 계절)
- **黄色い**声を出す。 — 날카로운 목소리를 내다. (비유)

#### 관련 용어

- 黄色 (きいろ) — 명사 「노랑」
- 黄色い声 (きいろいこえ) — 「날카로운/높은 목소리 (공포·집중)」
- 黄色いニュース (きいろいニュース) — 「음란/저질 매체 (노란 뉴스)」
- [[colors-vocabulary]] — 색상 어휘

#### 문화적 맥락

일본어 **黄色い (きいろい)** 발음 "키이로이" 끝의 -i 모음 연속 — 한국어 화자에게 연음 처리 연습. 일상 회화에서는 **黄色い 종이** (노란 종이), **黄色い 신호 (きいろい しんごう, 일본은 없음 — 한국·일본 모두 노란불 없음)** 사용 빈번. 한국어 "노란" / "노랗다" 모두 가능. 일본어 형용사 활용 (黄色い → 黄色くない, 黄色かった, 黄色くて) 연습 중요.
