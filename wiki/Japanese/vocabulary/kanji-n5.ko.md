## 한국어 학습자 핵심 노트 (JLPT N5 Kanji 핵심)

### 1. 한자 (漢字) 의 한국어 학습자 우위

한국어 화자는 **일본어 한자의 70-80% 가 한국어 한자어와 동일 어원** — 큰 학습 우위. 단, **음독 (음읽) / 훈독 (일본어 고유 읽기)** 의 차이를 주의.

### 3. 한자 읽기 (읽기) — 음독 vs 훈독

**음독 (おんよみ, on-yomi)** — 한자어 (중국어) 에서 유래:
- **音 (おん)** = 소리, **読 (よみ)** = 읽기
- 한자어 단어 (한국어 차용과 동일 패턴) 에서 사용
- 例: 学校 (がっこう, 학교) / 中国 (ちゅうごく, 중국)

**훈독 (くんよみ, kun-yomi)** — 일본어 고유어 (와어) 에서 유래:
- **訓 (くん)** = 가르침, **読 (よみ)** = 읽기
- 일본어 와어 의미로 사용
- 例: 水 (みず, 물) / 山 (やま, 산) / 人 (ひと, 사람)

### 4. 한국어 화자 발음 주의

- **장음 (お, long vowel)**: お / う / おう = 한국어 "오" 또는 "오-" (장음 마크 ー)
- **촉음 (っ, geminate)**: 자음 동족 (e.g., 学校 がっこう, 일시 정지)
- **요음 (よう, よう-on)**: り + ゃ/ゅ/ょ (e.g., 旅行 りょこう)
- **撥音 (ん, ん)**: ㄴ + ㅇ 사이 (e.g., 勉強 べんきょう)

### 6. 한국어 학습자 학습 노트

- **한자어 차용**: 한국어 한자어 어원의 70-80% = 일본어 한자어 어원 동일
- **발음 변이**: 한국어 화자가 일본어 한자 발음 시 음독 (음읽) vs 훈독 (일본어 고유) 의 차이 익혀야
- **한자 차이**: 한자 형태로 표기되는 한국어 한자어 와 일본어 한자어 의 어원 비교 어려움 (예: 気象, 一日 vs 氣象, 一日)
- **학습 전략**: 한국어 한자어 우선 학습 → 일본어 한자어 확장 (가장 효율적 학습)

### 7. 단일 한자 (一) — JLPT N5 시작

**一 (いち, 일)** — 한국어 "일" (음읽) 와 동일. **一 (ひと, 하나)** — 한국어 "하나" (훈읽) 와 동일.

- **一 (いっ)** — 한국어 "일" (음읽)
- **一人 (ひとり)** — 한국어 "한 명" (訓읽 ひと + り)
- **一日 (ついたち)** — 한국어 "1일" (변형 발음, 촉음)
