# 衣服・ファッション語彙 (Japanese Clothing & Fashion)

**Source:** [[clothing-vocabulary-jp]]
**Theme:** 衣服とファッション
**Level:** JLPT N4-N5 / A2-B1

日本語衣服・ファッション語彙：基本衣類、色/素材の組み合わせ、生地素材、衣類関連動詞/形容詞を網羅。出典：JLPT N4-N5語彙リスト、日本語教科書。

## 基本衣類

### シャツ (shatsu)

**品詞:** 名詞

**定義:** 上半身用の衣類。通常袖、襟、ボタン付き。

**読み / ひらがな / ローマ字:** シャツ (shatsu)

**語源:** 英語 "shirt" から。カタカナ外来語。

#### 例文

- 青い**シャツ**を着ています。 — 描写
- **シャツ**は上の引き出しに。 — 収納

#### 関連語

- ''Tシャツ'' — カジュアルシャツ
- ''ブラウス'' — 女性用シャツ
- ''ポロシャツ'' — 襟付きカジュアル

#### 文化的背景

「シャツを着る」= 準備する。「シャツ一枚」= 身軽な様子。ビジネスではワイシャツ（白無地）が標準。

#### 出典

- [[clothing-vocabulary-jp]]

### ズボン (zubon)

**品詞:** 名詞

**定義:** 各脚を別々に覆う、腰から足首までの衣類。

**読み / ひらがな / ローマ字:** ズボン (zubon)

**語源:** フランス語 *jupon* "ペチコート" → 日本語でズボン。またはポルトガル語 *gibão* "上着" からとも。

#### 例文

- この**ズボン**は長すぎる。 — サイズ
- **ズボン**か**パンツ**か。 — 呼称差

#### 関連語

- ''ジーンズ'' — デニムズボン
- ''スラックス'' — フォーマル用
- ''短パン'' — 短いズボン

#### 文化的背景

日本: 「ズボン」= ズボン全般。「ズボンの紐」= 信頼関係。「ズボラ」= だらしない（ズボンが緩い→だらしないの転訛説）。

#### 出典

- [[clothing-vocabulary-jp]]

### ドレス (doresu)

**品詞:** 名詞

**定義:** 女性/女児用のワンピース衣類。体と脚を覆う。

**読み / ひらがな / ローマ字:** ドレス (doresu)

**語源:** 英語 "dress" から。古フランス語 *drecier* "整える" → ラテン語 *directus*。

#### 例文

- 赤い**ドレス**を着た。 — 場面
- 夏**ドレス**は軽い。 — 季節

#### 関連語

- ''ワンピース'' — 同義語（日常用）
- ''イブニングドレス'' — 夜会服
- ''ウェディングドレス'' — 結婚式用

#### 文化的背景

「リトルブラックドレス」= 定番アイテム。「ドレスコード」= 服装規定。成人式・卒業式で振袖・ドレス着用。

#### 出典

- [[clothing-vocabulary-jp]]

### 靴 (kutsu)

**品詞:** 名詞

**定義:** 足を覆い保護する履物。

**読み / ひらがな / ローマ字:** くつ (kutsu)

**語源:** 古くは「くつ」のみ。漢字「靴」= 「革」+「化」= 革で作ったもの。

#### 例文

#### 関連語

- ''スニーカー'' — 運動靴
- ''ブーツ'' — 長靴
- ''サンダル'' — オープンシューズ

#### 文化的背景

室内では靴を脱ぐ習慣（玄関で脱ぐ）。「人の靴を履く」= 共感。「大きな靴を履く」= 大きな期待。

靴下 = 定番プレゼント（父の日等）。「靴下を履かせる」= 世話を焼く。「穴あき靴下」= 貧乏の象徴。

## 生地素材

### 絹 (kinu)

**品詞:** 名詞

**定義:** 蚕の繭から採れる細く強い繊維。高級織物用。

**読み / ひらがな / ローマ字:** きぬ (kinu)

**語源:** 古くは「きぬ」のみ。漢字「絹」= 「糸」+「系」= 糸の系統。

#### 例文

- **絹**のネクタイ。 — アクセサリー
- **絹**は滑らか。 — 触感

#### 関連語

- ''蚕'' — 由来
- ''絹織物'' — 織物
- ''着物'' — 伝統衣装

#### 文化的背景

絹 = 日本の伝統産業（群馬・長野・山梨）。シルクロード = 交易路。「絹の如し」= 滑らか。正絹 = 純絹。

#### 出典

- [[clothing-vocabulary-jp]]

---

### 綿 (men/wata)

**品詞:** 名詞

**定義:** 綿花から採れる柔らかい白色繊維。布地用。

**読み / ひらがな / ローマ字:** めん (men) / わた (wata)

**語源:** 中国語 "mián" → 日本語 "めん"。和名 "わた" = "綿"の訓読み。

#### 例文

- 100%**綿**シャツ。 — 表示
- **綿**は通気性が良い。 — 特性

#### 関連語

- ''綿花'' — 原料
- ''オーガニックコットン'' — 持続可能
- ''デニム'' — 綿ツイル

#### 文化的背景

木綿 = 江戸時代の普及品（海島綿→和綿）。「綿入れ」= 綿入れ半纏。「綿密」= 細かい。

#### 出典

- [[clothing-vocabulary-jp]]
