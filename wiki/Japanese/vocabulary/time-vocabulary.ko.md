# Time (시간) - Korean Translation

이 페이지는 한국인이 일본어 시간 어휘를 학습할 때 사용하는 한국어 관점 참고 자료입니다. 기본 일시 (今日/明日/昨日/朝/午後/夜/昼/朝晩/週末/時) 를 다룹니다. 각 단어의 한국어 정의, 발음 (히라가나/로마자), 한자 어원, 한국어 예문, 한국·일본 시간 문화 비교를 포함합니다.

**참고:** 본 페이지는 `wiki/Japanese/vocabulary/time-vocabulary.md` 의 한국어 번역/관점 페이지 입니다. 일본어 원문 표제(見出し)는 한자 + 히라가나(讀み方) 형식으로 표기.

## 일시 (Date / Day)

### 今日 (きょう / こんにちは)

**품사:** 명사 (noun)

**정의:** 오늘 — 현재 날짜. 한국어 "오늘" / 한자어 "금일(今日)" 의미. 부사적 용법: "오늘은" / "오늘날".

**読み方 (읽는 법):** きょう (히라가나) / kyou (로마자) / 今日 (한자, 音読み: きょう kyou, 訓読み: こんにち konnichi)

**IPA / 발음:** /kjoː/ (く) / /kon.ni.tɕi/ (こんにちは)

**어원:** 漢字 "今" (음읽 こん/きん, 訓읽 いま) + "日" (음읽 にち/じつ, 訓읽 ひ/か). 한국어 한자어 "금일(今日)" 동일 한자, 한국어 역음 "금일". 어원: 今 = 지금, 日 = 날.

#### 예문

- **今日**は月曜日です。 — 오늘은 월요일입니다. (날짜, 격식)
- **今日**は何曜日ですか? — 오늘은 무슨 요일입니까? (질문, 격식)
- **今日**中に終わらせます。 — 오늘 중으로 끝내겠습니다. (기간, 격식)

#### 관련 용어

- 今日は (きょうは) — 「오늘은 (조사)」
- こんにちわ / こんにちは (konnichiwa) — 「안녕하세요 (낮 인사)」
- 本日 (ほんじつ) — 「오늘 (격식)」
- 今日 (きょう) — 「오늘 (캐주얼)」
- [[time-vocabulary]] — 시간 어휘

#### 문화적 맥락

일본어 **今日 (きょう)** 발음 "쿄" — 한국어 "교" 와 ㄱ 발음 유사. **こんにちは (konnichiwa, 안녕)** 의 어원 = "오늘은" (오늘 같은 날 인사) — 한국어 "안녕" (평안) 어원과 완전히 다름. 일본 비즈니스: **本日 (ほんじつ, 오늘)** 가 격식. 한국어 "오늘" / "금일" (격식) / "오늘날" (요즘) 의 어원 구분. 발음: きょう (kyo-u) — 한국어 ㅋ + ㅛ 발음 연습.

### 明日 (あした / あす)

**품사:** 명사 (noun)

**정의:** 내일 — 다음 날. 한국어 "내일" / 한자어 "명일(明日)" 의미. 캐주얼: あした / 격식: あす.

**読み方 (읽는 법):** あした (히라가나) / ashita (로마자) / 明日 (한자, 音読み: みょうにち myounichi / めいにち meinichi, 訓読み: あした ashita / あす asu)

**IPA / 발음:** /a.ɕi.ta/ (あした) / /a.sɯ/ (あす)

**어원:** 漢字 "明" (음읽 めい/みょう, 訓읽 あ.かり/あ.くる/あ.ける) + "日" (날). 한국어 한자어 "명일(明日)" 동일 한자, 한국어 역음 "명일". 어원: 明 = 밝다, 日 = 날. "내일" = "밝아질 날".

#### 예문

- **明日**会いましょう。 — 내일 만납시다. (약속, 캐주얼)
- **明日**の天気は晴れです。 — 내일 날씨는 맑음입니다. (날씨, 격식)
- **明日**中に連絡します。 — 내일 중으로 연락합니다. (기간, 격식)

#### 관련 용어

- 明日 (あした) — 「내일 (캐주얼)」
- 明日 (あす) — 「내일 (격식)」
- 翌日 (よくじつ) — 「다음날 (격식)」
- 明後日 (あさって) — 「모레」
- [[time-vocabulary]] — 시간 어휘

#### 문화적 맥락

일본어 **明日 (あした / あす)** 발음 "아시타" / "아스" — 한국어 "아시타" 와 발음 동일. 발음 변이: あした (캐주얼) / あす (격식) / あした (만남/약속). 한국·일본 모두 **明日 (내일)** = 다음 날. 발음: あした (a-shi-ta) — 한국어 ㅅ 발음 주의. 한국어 "내일" 어원: 순 우리말 (어원 미상).

### 昨日 (きのう)

**품사:** 명사 (noun)

**정의:** 어제 — 지나간 날. 한국어 "어제" / 한자어 "작일(昨日)" 의미.

**読み方 (읽는 법):** きのう (히라가나) / kinou (로마자) / 昨日 (한자, 音読み: さくじつ sakujitsu, 訓読み: きのう kinou)

**IPA / 발음:** /ki.noː/

**어원:** 漢字 "昨" (음읽 さく, 訓읽 いま) + "日" (날). 한국어 한자어 "작일(昨日)" 동일 한자, 한국어 역음 "작일". 어원: 昨 = 지나가다/어제, 日 = 날.

#### 예문

- **昨日**は楽しかった。 — 어제는 즐거웠습니다. (평가, 캐주얼)
- **昨日**の会議はどうでしたか? — 어제 회의는 어땠습니까? (질문, 격식)
- **昨日**行きました。 — 어제 갔습니다. (과거, 캐주얼)

#### 관련 용어

- 一昨日 (おととい) — 「그저께」
- 昨日 (きのう) — 「어제 (캐주얼)」
- 昨日 (さくじつ) — 「어제 (격식)」
- 昨日分 (きのうぶん) — 「어제분 (양)」
- [[time-vocabulary]] — 시간 어휘

#### 문화적 맥락

일본어 **昨日 (きのう)** 발음 "키노-" — 한국어 "키노" 와 발음 동일. 캐주얼: きのう / 격식: さくじつ (昨日). 한국·일본 모두 **昨日 (어제)** = 지나간 날. 발음: きのう (ki-no-u) — 한국어 ㅋ + ㄴ + ㅗ 발음 연습. 한국어 "어제" 어원: 불명 (한자어 차용 아님).

## 시간대 (Time of Day)

### 朝 (あさ)

**품사:** 명사 (noun)

**정의:** 아침 — 일출부터 점심까지의 시간. 한국어 "아침" 의미.

**読み方 (읽는 법):** あさ (히라가나) / asa (로마자) / 朝 (한자, 音読み: ちょう chou, 訓読み: あさ asa)

**IPA / 발음:** /a.sa/

**어원:** 漢字 "朝" (음읽 ちょう, 訓읽 あさ). 한국어 한자어 "조(朝)" 의미 (한자어: 아침/나라). 어원: 日 + 月 (달이 떠오르는 시간) → 아침.

#### 예문

- **おはようございます** (좋은 아침입니다). — 좋은 아침입니다 (인사, 격식). (인사, 격식)
- **朝**ごはんを食べます。 — 아침을 먹습니다. (식사, 캐주얼)
- **朝**6時に起きます。 — 아침 6시에 일어납니다. (시간, 격식)

#### 관련 용어

- 今朝 (けさ) — 「오늘 아침」
- 明朝 (みょうちょう) — 「내일 아침 (격식)」
- 朝顔 (あさがお) — 「나팔꽃 (朝顔)」
- 早朝 (そうちょう) — 「이른 아침」
- [[time-vocabulary]] — 시간 어휘

#### 문화적 맥락

일본어 **朝 (あさ)** 발음 "아사" — 한국어 "아사" (납치/살해) 와 발음 동일. 한국어 "아침" / 한자어 "조(朝)" 의미 구분. 한국·일본 모두 **朝 (아침)** = 일출 시작 시간. 일상 인사: **おはよう (ohayou)** / **おはようございます (격식)** — 한자어 御早う 변경. 한국어 "좋은 아침입니다" 동일 인사. 발음: あさ (a-sa) — 한국어 ㅅ 발음 연습.

### 午後 (ごご)

**품사:** 명사 (noun)

**정의:** 오후 — 정오부터 일몰까지. 한국어 "오후" / 한자어 "오후(午後)" 와 의미 동일.

**読み方 (읽는 법):** ごご (히라가나) / gogo (로마자) / 午後 (한자, 音読み: ごご gogo / ごごごご)

**IPA / 발음:** /ɡo.ɡo/

**어원:** 漢字 "午" (음읽 ご, 訓읽 うま) + "後" (음읽 ご/こう, 訓읽 のち/うし.ろ/あと). 한국어 한자어 "오후(午後)" 동일 한자, 한국어 역음 "오후". 어원: 午 = 말 (말의 해, 지구 본位の 子午線) / 後 = 뒤.

#### 예문

- **午後**3時に会いましょう。 — 오후 3시에 만납시다. (약속, 격식)
- **午後**は会議があります。 — 오후에는 회의가 있습니다. (스케줄, 격식)
- **午後**から雨が降ります。 — 오후부터 비가 옵니다. (날씨, 격식)

#### 관련 용어

- 午前 (ごぜん) — 「오전」
- 午後 (ごご) — 「오후」
- 午後零時 (ごごれいじ) — 「정오 (12:00)」
- 午後三時 (ごごさんじ) — 「오후 3시」
- [[time-vocabulary]] — 시간 어휘

#### 문화적 맥락

일본어 **午後 (ごご)** 발음 "고고" — 한국어 "고고" (코고, 古古) 와 발음 동일. 한국·일본 모두 12시간제 + 24시간제 혼용. 일본 비즈니스: **午後三時 (ごごさんじ, 오후 3시)** 격식 / **15時 (じゅうごじ, 15시)** 간결. 한국어 동일. 발음: ごご (go-go) — 한국어 ㄱ + ㅗ 발음 연습. **午前 (오전)** vs **午後 (오후)** 의 Japanese 어원 = 말/뒤.

### 夜 (よる)

**품사:** 명사 (noun)

**정의:** 밤 — 일몰부터 일출까지. 한국어 "밤" 의미.

**読み方 (읽는 법):** よる (히라가나) / yoru (로마자) / 夜 (한자, 音読み: や ya, 訓読み: よる yoru / よ yo)

**IPA / 발음:** /jo.ɾɯ/

**어원:** 漢字 "夜" (음읽 や, 訓읽 よる/よ). 한국어 한자어 "야(夜)" 의미. 어원: 夕 + 寸 (오까의 손가락으로 표시?) → 어두운 시간.

#### 예문

- **こんばんは** / **おやすみなさい**. — 안녕하세요 / 안녕히 주무세요. (인사, 격식)
- **夜**ご飯は何? — 저녁은 뭐? (식사, 캐주얼)
- **夜**勤 (야근) — 「야근」

#### 관련 용어

- 夜 (よる) — 「밤 (캐주얼)」
- 夜 (よ) — 「밤 (격식 · 읽는 법)」
- 夜中 (よなか) — 「한밤중」
- 每晩 (まいばん) — 「매일 밤」
- [[time-vocabulary]] — 시간 어휘

#### 문화적 맥락

일본어 **夜 (よる)** 발음 "요루" — 한국어 "요루" 와 발음 동일. 캐주얼: よる / 격식: よ. 한국·일본 모두 **夜 (밤)** = 일몰 후 시간. 인사: **こんばんは (こんばんは 밤 인사)** / **おやすみなさい (おやすみ 주무세요)** — 한국어 "안녕히 주무세요" 동일. 발음: よる (yo-ru) — 한국어 ㅇ + ㅛ + ㄹ 발음 연습.

### 昼 (ひる)

**품사:** 명사 (noun)

**정의:** 낮 / 점심 — 정오 무렵 시간. 한국어 "낮" / "점심" 의미.

**読み方 (읽는 법):** ひる (히라가나) / hirı (로마자) / 昼 (한자, 音読み: ちゅう chou, 訓読み: ひる hiru)

**IPA / 발음:** /çi.ɾɯ/

**어원:** 漢字 "昼" (음읽 ちゅう, 訓읽 ひる). 한국어 한자어 "주(晝)" 의미 (낮). 어원: 日 + 尺 (자/막대) → 햇빛이 정중앙 → 한낮.

#### 예문

- **昼**ご飯を食べます。 — 점심을 먹습니다. (식사, 캐주얼)
- **昼**休みは12時からです。 — 점심시간은 12시부터입니다. (시간, 격식)
- **昼**に会いましょう。 — 낮에 만납시다. (시간, 캐주얼)

#### 관련 용어

- 昼ご飯 (ひるごはん) — 「점심밥」
- 昼食 (ちゅうしょく) — 「점심 (격식)」
- 昼休み (ひるやすみ) — 「점심시간」
- 昼夜 (ちゅうや) — 「낮과 밤」
- [[time-vocabulary]] — 시간 어휘

#### 문화적 맥락

일본어 **昼 (ひる)** 발음 "히루" — 한국어 "히루" 와 발음 동일. 캐주얼: ひる / 격식: ちゅう (晝). 한국·일본 모두 **昼 (하루)** = 점심 시간. 한국어 "점심" = "낮의 심(心)" 어원. **昼ご飯 (점심밥)** 가 **昼食 (점심)** 보다 캐주얼. 발음: ひる (hi-ru) — 한국어 ㅎ 발음 주의 (ㅎ → ㅎ 발음).

## 시간 표현 (Time Expressions)

### 朝晩 (あさばん)

**품사:** 명사 (noun)

**정의:** 아침저녁 — 매일 아침과 밤. 한국어 "아침저녁" 의미.

**読み方 (읽는 법):** あさばん (히라가나) / asaban (로마자) / 朝晩 (한자, 音読み: ちょうばん chouban)

**IPA / 발음:** /a.sa.ban/

**어원:** 漢字 "朝" (아침) + "晩" (한자, 음읽 ばん, 訓읽 お.そ.い/くれ). 한국어 한자어 "조반(朝晩)" 의미. 어원: 朝 = 아침, 晩 = 늦다/밤.

#### 예문

- **朝晩**は涼しいです。 — 아침저녁은 서늘합니다. (계절, 캐주얼)
- **朝晩**の散歩が好きです。 — 아침저녁 산책을 좋아합니다. (취미, 캐주얼)
- **朝晩**二回薬を飲みます。 — 아침저녁 두 번 약을 먹습니다. (건강, 격식)

#### 관련 용어

- 朝 (あさ) — 「아침」
- 晩 (ばん) — 「저녁 (걷지)」
- 朝晩 (あさばん) — 「아침저녁 (반복)」
- 早晚 (そうばん) — 「조만간 (이른 아침과 늦은 시간)」
- [[time-vocabulary]] — 시간 어휘

#### 문화적 맥락

일본어 **朝晩 (あさばん)** 발음 "아사반" — 한국어 "아사반" (의역: 사망) 과 발음 동일. 한국어 "아침저녁" / 한자어 "조반(朝晩)" 의미. **朝晩 (아침저녁)** 가 **朝夕 (あさゆう, 아침저녁)** 보다 빈번. 한국·일본 모두 건강 약 복용: **朝晩二回 (아침저녁 두 번)** — 한국어 동일 패턴. 발음: あさばん (a-sa-ban) — 한국어 ㅂ 발음 연습.

### 週末 (しゅうまつ)

**품사:** 명사 (noun)

**정의:** 주말 — 토요일과 일요일. 한국어 "주말" / 한자어 "주말(週末)" 와 의미 동일.

**読み方 (읽는 법):** しゅうまつ (히라가나) / shuumatsu (로마자) / 週末 (한자, 音読み: しゅうまつ shuumatsu)

**IPA / 발음:** /ɕɯː.mat͡sɯ/

**어원:** 漢字 "週" (음읽 しゅう, 訓읽 まわり) + "末" (음읽 まつ/ばつ, 訓읽 すえ/うら). 한국어 한자어 "주말(週末)" 동일 한자, 한국어 역음 "주말". 어원: 週 = 주 (一周 = 1주), 末 = 끝.

#### 예문

- **週末**は何をしますか? — 주말에 무엇을 합니까? (질문, 캐주얼)
- **週末**は家族と過ごします。 — 주말은 가족과 보냅니다. (계획, 캐주얼)
- **週末**に旅行します。 — 주말에 여행합니다. (계획, 캐주얼)

- 週末 (しゅうまつ) — 「주말」

#### 문화적 맥락

일본어 **週末 (しゅうまつ)** 발음 "슈-마쓰" — 한국어 "주말" (한자어) 와 발음 유사. 한국·일본 모두 **週末 (주말)** = 토·일. 한국어 "주말" = 한자어, 일본어 週末 = 같은 한자 차용. 일본 회사원: **週末出勤 (주말 출근)** 빈번 — 한국어 동일. 발음: しゅうまつ (shu-u-ma-tsu) — 촉음 っ + ㅆ 발음 연습.

### 時 (じ)

**품사:** 명사 (noun)

**정의:** 시간 — 60분 단위. 한국어 "시" (noun) / 한자어 "시(時)" 의미.

**読み方 (읽는 법):** じ (히라가나) / ji (로마자) / 時 (한자, 音読み: じ ji, 訓読み: とき toki)

**IPA / 발음:** /dʑi/

**어원:** 漢字 "時" (음읽 じ, 訓읽 とき). 한국어 한자어 "시(時)" 의미. 어원: 日 + 寸 (자) → 해의 길이를 측정 → 시간.

#### 예문

- 一**時**は60分です。 — 1시간은 60분입니다. (정의, 격식)
- 何**時**ですか? — 몇 시입니까? (질문, 격식)
- **時**を待ちます。 — 시간을 기다립니다. (대기, 격식)

#### 관련 용어

- 時間 (じかん) — 「시간 (duration)」
- 何時 (なんじ) — 「몇 시」
- 時 (〜じ) — 「○○ 시 (時刻)」
- 時計 (とけい) — 「시계」
- [[time-vocabulary]] — 시간 어휘

#### 문화적 맥락

일본어 **時 (じ)** 발음 "지" — 한국어 "지" (知, 알다) 와 동음. 한국어 "시" (한자어) 와 일본어 "時 (じ)" 의 한글 음가 차이. 한국·일본 모두 **時 (시)** = 60분. 일상 회화: **何時 (なんじ, 몇 시)** 빈번. 한국어 동일. 발음: じ (ji) — 한국어 ㅈ 발음 연습. **時間 (じかん, 시간)** + **時 (시)** = 한국어 "시간" (period) + "시" (hour) 구분.
