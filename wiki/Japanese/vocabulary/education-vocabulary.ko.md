# Education (교육) - Korean Translation

이 페이지는 한국인이 일본어 교육 어휘를 학습할 때 사용하는 한국어 관점 참고 자료입니다. 학교·학습·교육제도 관련 기본 어휘 (学校/学生/先生/本/ペン/鉛筆/宿題/テスト/図書館/大学) 를 다룹니다. 각 단어의 한국어 정의, 발음 (히라가나/로마자), 한자 어원, 한국어 예문, 한국·일본 교육 문화적 맥락을 포함합니다.

**참고:** 본 페이지는 `wiki/Japanese/vocabulary/education-vocabulary.md` 의 한국어 번역/관점 페이지 입니다. 일본어 원문 표제(見出し)는 한자 + 히라가나(讀み方) 형식으로 표기.

## 학교/학습 기본 어휘 (School/Learning Basics)

### 学校 (がっこう)

**품사:** 명사 (noun)

**정의:** 학교 — 초등·중등·고등 교육 기관. 한국어 "학교" / 한자어 "학교(學校)" 와 의미 동일.

**読み方 (읽는 법):** がっこう (히라가나) / gakkou (로마자) / 学校 (한자, 音読み: がっこう gakkou)

**IPA / 발음:** /ɡak.koː/

**어원:** 漢字 "學" (음읽 がく, 訓읽 まな.ぶ) + "校" (음읽 こう, 訓읽 くら.べる). 합성어 "学校" 한국어 한자어 "학교(學校)" 와 동일 한자, 한국어 역음 "학교". 어원: 학교 (學 = 배우다, 校 = 교실).

#### 예문

- 私は**学校**に行きます。 — 저는 학교에 갑니다. (등교, 캐주얼)
- **学校**は８時に始まります。 — 학교는 8시에 시작합니다. (시간, 격식)
- 彼は**学校**を休みました。 — 그는 학교를 쉬었습니다. (결석, 캐주얼)

#### 관련 용어

- 学校教育 (がっこうきょういく) — 「学校教育」
- 小学校 (しょうがっこう) — 「초등학교」
- 中学校 (ちゅうがっこう) — 「중학교」
- 高等学校 (こうとうがっこう) — 「고등학교」
- [[education-vocabulary]] — 교육 어휘

#### 문화적 맥락

일본어 **学校 (がっこう)** 발음 "학쿠오" — 한국어 "학교" 와 발음 유사 (장음 연습). 촉음 っ (small つ) + 고 (kko) 의 촉음 발음 중요. 한국·일본 모두 4월 학기 시작 (일본 4월 ~ 3월, 한국 3월 ~ 2월). 일본어 **学校 (がっこう)** = 한국어 "학교" (school) — 대학원 **大学院 (だいがくいん)** ≠ 한국어 "대학원" (graduate school). 한국어 화자에게 漢字 한자어 친숙.

### 学生 (がくせい)

**품사:** 명사 (noun)

**정의:** 학생 — 교육 기관에 재학 중인 자. 한국어 "학생" / 한자어 "학생(學生)" 와 의미 동일.

**読み方 (읽는 법):** がくせい (히라가나) / gakusei (로마자) / 学生 (한자, 音読み: がくせい gakusei)

**IPA / 발음:** /ɡakɯ.seː/

**어원:** 漢字 "學" (음읽 がく) + "生" (음읽 せい, 訓읽 い.きる/う.まれる/なま). 한국어 한자어 "학생(學生)" 와 동일 한자, 한국어 역음 "학생". 어원: 生 = "살다 → 그 상태의 사람".

#### 예문

- 私は**学生**です。 — 저는 학생입니다. (신분, 격식)
- 彼は大学生**学生**です。 — 그는 대학생입니다. (신분, 격식)
- **学生**時代に日本語を学びました。 — 학생 때 일본어를 배웠습니다. (기간, 격식)

#### 관련 용어

- 大学院生 (だいがくいんせい) — 「대학원생」
- 留学生 (りゅうがくせい) — 「유학생」
- 小学生 (しょうがくせい) — 「초등학생」
- 生徒 (せいと) — 「(초중고) 학생 — 児童 (しょうじ) ~ 生徒 (せいと) ~ 学生 (がくせい)」
- [[education-vocabulary]] — 교육 어휘

#### 문화적 맥락

일본어 **学生 (がくせい)** 발음 "가쿠세이" — 한국어 "학생" 과 발음 유사. 일본어 **学生** vs **生徒 (せいと)** vs **児童 (しょうじ)** — 한국어 "학생" 은 모든 학생 통칭. 일본어는 (초등) 児童, (중고등) 生徒, (대학) 学生 로 세분화. 한국어 화자에게 이 구분 중요. **大学生 (だいがくせい)** = 한국어 "대학생" (대학 재학). 발음: がくせい (ga-ku-se-i) — 한국어 ㄱ + ㅜ + ㅅ + ㅔ 발음 연습.

### 先生 (せんせい)

**품사:** 명사 (noun)

**정의:** 선생 — 교육 기관의 교사, 또는 직함/존칭 (의사·변호사·정치인). 한국어 "선생" / 한자어 "선생(先生)" 와 의미 동일.

**読み方 (읽는 법):** せんせい (히라가나) / sensei (로마자) / 先生 (한자, 音読み: せんせい sensei)

**IPA / 발음:** /sen.seː/

**어원:** 漢字 "先" (음읽 せん, 訓읽 さき/ま.ず) + "生" (음읽 せい/しょう). 한국어 한자어 "선생(先生)" 와 동일 한자, 한국어 역음 "선생". 어원: 先生 = "먼저(先) 태어난(生) 사람" (역사적으로 늙은 선생이 아님).

#### 예문

- 私の日本語の**先生**はカナダ出身です。 — 제 일본어 선생님은 캐나다 출신입니다. (관계, 격식)
- **先生**に質問があります。 — 선생님께 질문이 있습니다. (질문, 격식)
- 山田**先生**は数学を教えています。 — 야마다 선생님은 수학을 가르치고 있습니다. (직함, 격식)

#### 관련 용어

- 教師 (きょうし) — 「교사 (공식 직함)」
- 教授 (きょうじゅ) — 「교수 (대학)」
- 講師 (こうし) — 「강사 (대학)」
- 先生 (せんせい) — 일반 호칭 「선생님」
- [[education-vocabulary]] — 교육 어휘

#### 문화적 맥락

일본어 **先生 (せんせい)** 발음 "센세이" — 한국어 화자에게 비교적 친숙. 한국·일본 모두 **先生 (선생)** = 일반 호칭 + 교육자. 차이: 일본어 **先生** = 의사·변호사·정치인 등 직함 (한국어 "선생님" 도 동일). 발음: せんせい (sen-se-i) — 한국어 ㄴ + ㅔ + ㅅ 발음 연습. 일상 회화: **〜先生** = "〜선생님" — 한국어와 동일.

### 本 (ほん)

**품사:** 명사 (noun)

**정의:** 책 — 인쇄된 텍스트 묶음. 한국어 "책" / 한자어 "본(本)" 의미 (한자어: 출처, 뿌리 / 명사: 책).

**読み方 (읽는 법):** ほん (히라가나) / hon (로마자) / 本 (한자, 音読み: ほん hon, 訓読み: もと moto)

**IPA / 발음:** /hon/

**어원:** 漢字 "本" (음읽 ほん, 訓읽 もと). 한국어 한자어 "본(本)" 동일 한자, 한국어 역음 "본". 어원: 상형문자 (나무의 뿌리). 한국어 "책" 어원: 불명.

#### 예문

- 毎晩**本**を読みます。 — 매일 밤 책을 읽습니다. (독서, 캐주얼)
- **本**を買いました。 — 책을 샀습니다. (구매, 캐주얼)
- 彼の**本**は best seller です。 — 그의 책은 베스트셀러입니다. (저서, 격식)

#### 관련 용어

- 本棚 (ほんだな) — 「책장」
- 読書 (どくしょ) — 「독서 (음읽)」
- 日本語の本 (にほんごのほん) — 「일본어 책」
- 絵本 (えほん) — 「그림책」
- [[education-vocabulary]] — 교육 어휘

#### 문화적 맥락

일본어 **本 (ほん)** 발음 "혼" — 한국어 "혼" (재혼, 분홍) 과 발음 동일. 한국어 "책" / 한자어 "본" (out of print: 絶版) — 일본어 **本 (ほん)** = 한국어 "책". 한자어 매핑: **本 1권 (いっかん)** = 한국어 "한 권". 발음: ほん (ho-n) — 한국어 ㄴ (n) 발음 중요. 일음절 단어.

### ペン

**품사:** 명사 (noun)

**정의:** 펜 — 잉크/볼/만년필 등 필기 도구. 한국어 "펜" (loanword) 와 의미 동일.

**読み方 (읽는 법):** ペン (히라가나) / pen (로마자) / 漢字: pen (외래어 — 원래는 洋語)

**IPA / 발음:** /pen/

**어원:** 외래어 (外来語). 네덜란드어 "pen" → 영어 "pen" → 일본어 カタカナ 転写 **ペン**. 한국어 **펜 (pen)** — 같은 어원. 한국어 "펜" 은 서양어 유래 직접 차용.

#### 예문

- **ペン**を借りてもいいですか? — 펜을 빌려도 될까요? (대여, 격식)
- **ペン**で名前を書きました。 — 펜으로 이름을 썼습니다. (사용, 캐주얼)
- 赤い**ペン**で訂正してください。 — 빨간 펜으로 정정해 주세요. (지시, 격식)

#### 관련 용어

- ボールペン — 「볼펜」
- シャープペンシル — 「샤프펜슬」
- フェルトペン — 「매직펜/형광펜」
- ペン先 (penさき) — 「펜촉」
- [[education-vocabulary]] — 교육 어휘

#### 문화적 맥락

일본어 **ペン (pen)** — 한국어 "펜" 과 발음 동일. カタカナ 外래어 표기. 한국어 "펜" (영어 직접 차용) 와 거의 동일. 일상 회화: **ペン借りる** (ペンかりる) = "펜 빌리다" — 한국어 "펜 빌리다" 와 동일. 다른 필기 도구: **鉛筆 (えんぴつ, 연필)**, **ボールペン (볼펜)**, **シャープペンシル (샤프)** — 한국어 화자에게 친숙.

### 鉛筆 (えんぴつ)

**품사:** 명사 (noun)

**정의:** 연필 — 흑심(검정) 필기 도구. 한국어 "연필" / 한자어 "연필(鉛筆)" 와 의미 동일.

**読み方 (읽는 법):** えんぴつ (히라가나) / enpitsu (로마자) / 鉛筆 (한자, 音読み: えんぴつ enpitsu)

**IPA / 발음:** /em.pit͡sɯ/

**어원:** 漢字 "鉛" (음읽 えん) + "筆" (음읽 ひつ, 訓읽 ふで). 합성어 "鉛筆" (えんぴつ). 한국어 한자어 "연필(鉛筆)" 와 동일 한자, 한국어 역음 "연필". 어원: 鉛 = 납 (그래파이트), 筆 = 붓 (필기 도구). 한국어 "연필" 어원: 한자어 차용.

#### 예문

- テストに**鉛筆**が必要です。 — 시험에 연필이 필요합니다. (필요, 격식)
- **鉛筆**で絵を描きました。 — 연필로 그림을 그렸습니다. (사용, 캐주얼)
- **鉛筆**を削ります。 — 연필을 깎습니다. (행위, 캐주얼)

#### 관련 용어

- 色鉛筆 (いろえんぴつ) — 「색연필」
- 鉛筆削り (えんぴつけずり) — 「연필削り (가위)」
- 赤い鉛筆 (あかいえんぴつ) — 「빨간 연필 (채점용)」
- シャープペンシル — 「샤프펜슬 (대안)」
- [[education-vocabulary]] — 교육 어휘

#### 문화적 맥락

일본어 **鉛筆 (えんぴつ)** 발음 "엔핏스" — 한국어 "연필" 과 발음 유사. 한국·일본 모두 **赤鉛筆 (빨간 연필)** = 채점용. 발음: えんぴつ (em-pi-tsu) — ㄴ + ㅂ 발음 연습. 한국어 "연필" 은 한자어 차용, 동일 어원. 자동판매기/문구점에서 **鉛筆** 1本 (いっぽん) = "연필 1자루".

### 宿題 (しゅくだい)

**품사:** 명사 (noun)

**정의:** 숙제 — 교육 기관이 학생에게 부여한 학습 과제. 한국어 "숙제" / 한자어 "숙제(宿題)" 와 의미 동일.

**読み方 (읽는 법):** しゅくだい (히라가나) / shukudai (로마자) / 宿題 (한자, 音読み: しゅくだい shukudai)

**IPA / 발음:** /ɕɯ.kɯ.da.i/

**어원:** 漢字 "宿" (음읽 しゅく/す, 訓읽 やど/と.まる) + "題" (음읽 だい, 訓읽 なし). 한국어 한자어 "숙제(宿題)" 와 동일 한자, 한국어 역음 "숙제". 어원: 宿 = 숙박/남기다, 題 = 제목/문제. 宿題 = "숙박지에 남긴 문제" (숙제).

#### 예문

- **宿題**を終わらせましたか? — 숙제를 끝냈어요? (질문, 캐주얼)
- 日本語の**宿題**は難しいです。 — 일본어 숙제는 어렵습니다. (묘사, 캐주얼)
- **宿題**を忘れました。 — 숙제를 잊어버렸습니다. (낙제, 캐주얼)

#### 관련 용어

- 宿題帳 (しゅくだいちょう) — 「숙제 공책 (제출용)」
- 夏休みの宿題 (なつやすみのしゅくだい) — 「여름방학 숙제」
- 課題 (かだい) — 「과제 (대학/직장)」
- 宿題をやらない (しゅくだいをやらない) — 「숙제를 안 하다」
- [[education-vocabulary]] — 교육 어휘

#### 문화적 맥락

일본어 **宿題 (しゅくだい)** 발음 "슈쿠다이" — 한국어 "숙제" 와 발음 유사. 한국·일본 모두 **宿題 (숙제)** = 학교 학습 과제. 일본어 **課題 (かだい)** = 대학/직장 과제 (한국어 "과제" 동일). 발음: しゅくだい (shu-ku-da-i) — ㅠ + ㄱ + ㄷ 발음 연습. 한국어 "숙제" 는 한자어 차용, 동일 어원.

### テスト / 試験 (しけん)

**품사:** 명사 (noun)

**정의:** 시험 — 학습 평가 시험. 한국어 "시험" / 한자어 "시험(試驗)" 와 의미 동일. **テスト** 캐주얼, **試験** 격식.

**読み方 (읽는 법):** テスト (tesuto) / 試験 (しけん shiken / 히라가나)

**IPA / 발음:** /tes.to/ / /ɕi.ken/

**어원:** **テスト** 외래어 (英語 "test"). **試験** 漢字 "試" (음읽 し, 訓읽 こころ.みる/ため.す) + "驗" (음읽 けん, 訓읽 しるし). 한국어 한자어 "시험(試驗)" 동일 한자, 한국어 역음 "시험". 어원: 試 = 시험하다, 驗 = 검증하다.

#### 예문

- 数学の**テスト**は明日です。 — 수학 시험은 내일입니다. (시간, 캐주얼)
- **試験**に合格しました。 — 시험에 합격했습니다. (결과, 격식)
- **テスト**のために勉強します。 — 시험을 위해 공부합니다. (동기, 캐주얼)

#### 관련 용어

- 期末テスト (きまつテスト) — 「기말 시험」
- 入学試験 (にゅうがくしけん) — 「입학시험」
- 模擬試験 (もぎしけん) — 「모의시험」
- テスト用紙 (テストようし) — 「시험지」
- [[education-vocabulary]] — 교육 어휘

#### 문화적 맥락

일본어 **テスト / 試験** — テスト (test, 캐주얼) + 試験 (shiken, 격식). 한국어 "시험" (한자어/음차 모두). 발음: しけん (shi-ken) — 한국어 ㄴ + ㄱ 발음 연습. 한국어 "시험" 은 한자어 차용. 일본 입시제도: **センター試験 (센터시험)** → **大学入学共通テスト (대학입학공통테스트)** 로 2021년 개편. 한국 입시와 비교 가능.

### 図書館 (としょかん)

**품사:** 명사 (noun)

**정의:** 도서관 — 장서 대출/열람 시설. 한국어 "도서관" / 한자어 "도서관(圖書館)" 와 의미 동일.

**読み方 (읽는 법):** としょかん (히라가나) / toshokan (로마자) / 図書館 (한자, 音読み: としょかん toshokan)

**IPA / 발음:** /to.ɕo.kan/

**어원:** 漢字 "圖" (음읽 ず/と, 訓읽 え) + "書" (음읽 しょ, 訓읽 か.く/ふ.む) + "館" (음읽 かん, 訓읽 やかた/たて). 한국어 한자어 "도서관(圖書館)" 와 동일 한자, 한국어 역음 "도서관". 어원: 圖書 (도서) + 館 (관).

#### 예문

- **図書館**で勉強します。 — 도서관에서 공부합니다. (학습, 캐주얼)
- **図書館**は9時に開きます。 — 도서관은 9시에 엽니다. (시간, 격식)
- **図書館**から本を借りました。 — 도서관에서 책을 빌렸습니다. (대출, 캐주얼)

#### 관련 용어

- 図書館員 (としょかんいん) — 「사서/도서관 직원」
- 国立国会図書館 (こくりつこっかいとしょかん) — 「국립 국회 도서관 (일본)」
- 学校図書館 (がっこうとしょかん) — 「학교 도서관」
- 公共図書館 (こうきょうとしょかん) — 「공공 도서관」
- [[education-vocabulary]] — 교육 어휘

#### 문화적 맥락

일본어 **図書館 (としょかん)** 발음 "토쇼칸" — 한국어 "도서관" 과 발음 유사. 한국·일본 모두 공공 도서관 무료. 일본 **国立国会図書館 (국립국회도서관)** = 한국 **국립중앙도서관** 대응. 발음: としょかん (to-sho-kan) — しょ (sho) 촉음 발음 연습. 한국어 "도서관" 한자어 차용, 동일 어원.

### 大学 (だいがく)

**품사:** 명사 (noun)

**정의:** 대학교 — 고등 교육 기관. 한국어 "대학교" / 한자어 "대학(大學)" 와 의미 동일.

**読み方 (읽는 법):** だいがく (히라가나) / daigaku (로마자) / 大学 (한자, 音読み: だいがく daigaku)

**IPA / 발음:** /da.i.ɡakɯ/

**어원:** 漢字 "大" (음읽 だい/たい, 訓읽 おお.きい) + "學" (음읽 がく, 訓읽 まな.ぶ). 한국어 한자어 "대학(大學)" 와 동일 한자, 한국어 역음 "대학". 어원: 大 = 큰, 學 = 배우다.

#### 예문

- 彼女はソウル**大学**に通っています。 — 그녀는 서울대학교에 다니고 있습니다. (재학, 격식)
- **大学**を卒業しました。 — 대학을 졸업했습니다. (졸업, 격식)
- **大学**で日本語を勉強しています。 — 대학에서 일본어를 공부하고 있습니다. (학습, 격식)

#### 관련 용어

- 大学院 (だいがくいん) — 「대학원 (대학 부설)」
- 大学生 (だいがくせい) — 「대학생」
- 短期大学 (たんきだいがく) — 「단기대학 (전문대 정도)」
- 国立大学 (こくりつだいがく) — 「국립대학」
- [[education-vocabulary]] — 교육 어휘

#### 문화적 맥락

일본어 **大学 (だいがく)** 발음 "다이가쿠" — 한국어 "대학" 과 발음 유사. 한국어 "대학교" 와 일본어 "大学" 의 차이: 한국어 "대학교" = 보편 명사 (학부 과정), 일본어 "大学" = 학부 과정 (단·장기대학 구분). **短期大学 (たんきだいがく, 단기대학)** = 2년제 (한국 "전문대학" 유사). **大学院 (だいがくいん, 대학원)** = 대학 부설 (한국 "대학원" 동일). 발음: だいがく (da-i-ga-ku) — 한국어 ㄷ + ㅏ + ㅣ + ㄱ 발음.
