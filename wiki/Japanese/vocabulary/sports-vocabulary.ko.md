# Sports (스포츠) - Korean Translation

이 페이지는 한국인이 일본어 스포츠/취미 어휘를 학습할 때 사용하는 한국어 관점 참고 자료입니다. 일반 스포츠 (야구/축구/테니스/수영) + 피트니스 (조깅/요가/하이킹/캠핑) + 일본 특유 (무도/온천/노래방/스모) + 관련 (팀/경기/팬) 등 16 entries 를 다룹니다. 각 단어의 한국어 정의, 발음 (히라가나/로마자), 한자 어원, 한국어 예문, 한국·일본 스포츠·취미 문화 비교를 포함합니다.

**참고:** 본 페이지는 `wiki/Japanese/vocabulary/sports-vocabulary.md` 의 한국어 번역/관점 페이지 입니다. 일본어 원문 표제(見出し)는 한자 + 히라가나(讀み方) 형식으로 표기.

## 일반 스포츠 (General Sports)

### スポーツ (supōtsu)

**품사:** 명사 (noun)

**정의:** 스포츠 — 운동 전반. 한국어 "스포츠" (loanword) 와 의미 동일.

**読み方 (읽는 법):** スポーツ (히라가나 カタカナ) / supōtsu (로마자) / 漢字: 運動 (うんどう, 한자어)

**IPA / 발음:** /sɯ.poː.tsɯ/

**어원:** 외래어 (外来語). 영어 "sports" → 일본어 カタカナ 転写 **スポーツ**. 한국어 **스포츠** — 같은 어원 (영어 직접 차용).

#### 예문

- **スポーツ**が好きです。 — 스포츠를 좋아합니다. (취향, 캐주얼)
- 何か**スポーツ**をしますか? — 무슨 스포츠를 하나요? (질문, 캐주얼)
- 見る**スポーツ**が好きです。 — 봐서 즐기는 스포츠를 좋아합니다. (관람, 캐주얼)

#### 관련 용어

- スポーツ (supōtsu) — 「스포츠 (외래어)」
- 運動 (うんどう) — 「운동 (한자어)」
- 体育 (たいいく) — 「체육 (한자어, 학교)」
- レクリエーション (rekurieeshon) — 「레크리에이션」
- [[sports-vocabulary]] — 스포츠 어휘

#### 문화적 맥락

일본어 **スポーツ (supōtsu, 스포츠)** 발음 "스포-츠" — 한국어 "스포츠" (loanword) 와 발음 동일. 캐주얼: スポーツ / 한자어: 運動 (うんどう). 한국어 "스포츠" 동일. **スポーツ (외래어)** + **運動 (한자어)** 의 어원: 両方 모두 한국어에서 사용. 한국어 "스포츠" (영어 직접 차용) 와 어원 동일. 발음: スポーツ (su-po-o-tsu) — 장음 お + ㅅ 발음 연습.

### 野球 (やきゅう)

**품사:** 명사 (noun)

**정의:** 야구 — 일본의 국민 스포츠. 한국어 "야구" / 한자어 "야구(野球)" 와 의미 동일.

**読み方 (읽는 법):** やきゅう (히라가나) / yakyū (로마자) / 野球 (한자, 音読み: やきゅう yakyū)

**IPA / 발음:** /ja.kɯː/

**어원:** 漢字 "野" (음읽 や, 訓읽 の) + "球" (음읽 きゅう, 訓읽 たま). 한국어 한자어 "야구(野球)" 동일 한자, 한국어 역음 "야구". 어원: 野 (들판) + 球 (공) → 들판에서 하는 공놀이.

#### 예문

- **野球**を見ます。 — 야구를 봅니다. (관람, 캐주얼)
- 高校**野球**がとても人気です。 — 고교 야구가 매우 인기입니다. (스포츠, 격식)
- **野球**の練習は毎日。 — 야구 연습은 매일. (훈련, 캐주얼)

#### 관련 용어

- 野球 (やきゅう) — 「야구 (한자어)」
- 野球選手 (やきゅうせんしゅ) — 「야구 선수」
- プロ野球 (ぷろやきゅう) — 「프로 야구」
- 高校野球 (こうこうやきゅう) — 「고교 야구」
- [[sports-vocabulary]] — 스포츠 어휘

#### 문화적 맥락

일본어 **野球 (やきゅう)** 발음 "야큐-" — 한국어 "야구" (한자어) 와 발음 동일. 캐주얼: 野球 (ya-kyū) / 음읽: やきゅう. 한국어 "야구" 동일. **野球 (야구)** = 일본의 국민 스포츠 — 한국어 "야구" 와 어원 동일. 일본 **プロ野球 (프로야구, 日本野球機構)** 와 한국 **KBO (한국야구위원회)** 의 어원 비교. **春甲子圆 (봄 코시엔) 고교 야구 전국 대회** — 한국어 "봄 야구" 와 비교. 발음: やきゅう (ya-kyū) — 장音 お + ㄱ 발음 연습.
