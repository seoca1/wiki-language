# Weather (날씨) - Korean Translation

이 페이지는 한국인이 일본어 날씨 어휘를 학습할 때 사용하는 한국어 관점 참고 자료입니다. 기본 날씨 (晴れ/曇り/雨/雪) + 온도 형용사 (暑い/寒い/暖かい/涼しい) + 風/台風 + 자연 현상을 다룹니다. 각 단어의 한국어 정의, 발음 (히라가나/로마자), 한자 어원, 한국어 예문, 한국·일본 날씨 문화 비교를 포함합니다.

**참고:** 본 페이지는 `wiki/Japanese/vocabulary/weather-vocabulary.md` 의 한국어 번역/관점 페이지 입니다. 일본어 원문 표제(見出し)는 한자 + 히라가나(讀み方) 형식으로 표기.

## 기본 날씨 (Basic Weather)

### 晴れ (はれ)

**품사:** 명사 (noun)

**정의:** 맑음 — 하늘이 구름 없이 맑음. 한국어 "맑음" / 한자어 "청(晴)" 의미.

**読み方 (읽는 法):** はれ (히라가나) / hare (로마자) / 晴れ (한자, 音読み: せい sei, 訓読み: はる haru / はれる hareru)

**IPA / 발음:** /ha.ɾe/

**어원:** 漢字 "晴" (음읽 せい, 訓읽 はる/はれる). 한국어 한자어 "청(晴)" 의미. 어원: 日 + 青 (푸른 하늘) → 햇볕이 좋은 날.

#### 예문

- 今日は**晴れ**です。 — 오늘은 맑습니다. (날씨, 격식)
- 明日**晴れ**でしょう。 — 내일 맑겠습니다. (예보, 격식)
- 週末は**晴れ**る予定です。 — 주말에 맑을 예정입니다. (예보, 격식)

#### 관련 용어

- 晴れ (はれ) — 「맑음 (명사)」
- 晴れる (はれる) — 「개이다 (동사)」
- 快晴 (かいせい) — 「쾌청 (구름 한 점 없는 맑음)」
- 晴天 (せいてん) — 「맑은 하늘 (격식)」
- [[weather-vocabulary]] — 날씨 어휘

#### 문화적 맥락

일본어 **晴れ (はれ)** 발음 "하레" — 한국어 "하레" (???) 와 비교. 캐주얼: はれ / 격식: 晴天 (せいてん). 한국·일본 모두 **晴れ (맑음)** = 구름 없는 날. **晴天 (맑은 하늘)** 한국어 동일 의미. 일본 **梅雨 (つゆ, 장마)** + **晴れ** = 한국어 "장마" 와 "맑음" 대비. 발음: はれ (ha-re) — 한국어 ㅎ + ㄹ 발음 연습.

### 曇り (くもり)

**품사:** 명사 (noun)

**정의:** 흐림 — 구름이 낀 상태. 한국어 "흐림" / 한자어 "운(雲)" 의미.

**読み方 (읽는 법):** くもり (히라가나) / kumori (로마자) / 曇り (한자, 音読み: どん don, 訓読み: くもる kumoru)

**IPA / 발음:** /kɯ.mo.ɾi/

**어원:** 漢字 "曇" (음읽 どん, 訓읽 くも.る). 한국어 한자어 "돈(曇)" 의미. 어원: 日 (해) + 雲 (구름) → 해가 구름에 가려짐.

#### 예문

- 明日は**曇り**です。 — 내일은 흐림입니다. (날씨, 격식)
- 午後から**曇り**になる。 — 오후부터 흐려집니다. (변화, 격식)
- 今日は一日中**曇り**です。 — 오늘은 종일 흐립니다. (지속, 격식)

#### 관련 용어

- 曇り (くもり) — 「흐림 (명사)」
- 曇る (くもる) — 「흐려지다 (동사)」
- 薄曇り (うすぐもり) — 「약간 흐림」
- 曇天 (どんてん) — 「흐린 하늘 (격식)」
- [[weather-vocabulary]] — 날씨 어휘

#### 문화적 맥락

일본어 **曇り (くもり)** 발음 "쿠모리" — 한국어 "쿠모리" 와 발음 동일. 캐주얼: くもり / 격식: 曇天 (どんてん). 한국·일본 모두 **曇り (흐림)** = 구름 낀 날. 일상 회화: **曇り** 가 **曇天 (흐린 하늘)** 보다 빈번. 한국어 "흐림" / "흐린 하늘" / "구름 낀 날" 동일. 발음: くもり (ku-mo-ri) — 한국어 ㅋ + ㅁ + ㄹ 발음 연습.

### 雨 (あめ)

**품사:** 명사 (noun)

**정의:** 비 — 하늘에서 내리는 물방울. 한국어 "비" 의미.

**読み方 (읽는 법):** あめ (히라가나) / ame (로마자) / 雨 (한자, 音読み: う u, 訓読み: あめ ame)

**IPA / 발음:** /a.me/

**어원:** 漢字 "雨" (음읽 う, 訓읽 あめ). 한국어 한자어 "우(雨)" 의미. 어원: 雨 (비) → 작은 물방울.

#### 예문

- **雨**が降っています。 — 비가 내리고 있습니다. (현재, 격식)
- **雨**がやみました。 — 비가 그쳤습니다. (변화, 격식)
- **雨**が強くなりました。 — 비가 강해졌습니다. (강도, 격식)

#### 관련 용어

- 雨 (あめ) — 「비 (명사)」
- 雨が降る (あめがふる) — 「비가 내리다」
- 雨粒 (あまつぶ) — 「빗방울」
- 雨期 (うき) — 「우기 (비 오는 시기)」
- [[weather-vocabulary]] — 날씨 어휘

#### 문화적 맥락

### 雪 (ゆき)

**품사:** 명사 (noun)

**정의:** 눈 — 하늘에서 내리는 얼음 결정. 한국어 "눈" 의미.

**読み方 (읽는 法):** ゆき (히라가나) / yuki (로마자) / 雪 (한자, 音読み: せつ setsu, 訓読み: ゆき yuki)

**IPA / 발음:** /jɯ.ki/

**어원:** 漢字 "雪" (음읽 せつ, 訓읽 ゆき). 한국어 한자어 "설(雪)" 의미. 어원: 雨 (비) + 彗 (혜성) → 비와 같이 내리는 흰 결정.

#### 예문

- **雪**が降っています。 — 눈이 내리고 있습니다. (현재, 격식)
- **雪**が積もりました。 — 눈이 쌓였습니다. (축적, 격식)
- **雪**景色がきれいです。 — 설경이 아름답습니다. (풍경, 격식)

#### 관련 용어

- 雪 (ゆき) — 「눈 (명사)」
- 雪が降る (ゆきがふる) — 「눈이 내리다」
- 雪国 (ゆきぐに) — 「설국 (눈이 많이 오는 지방)」
- 大雪 (おおゆき) — 「대설」
- [[weather-vocabulary]] — 날씨 어휘

#### 문화적 맥락

일본어 **雪 (ゆき)** 발음 "유키" — 한국어 "유키" (이름) 와 발음 동일. 한국·일본 모두 **雪 (눈)** = 하늘에서 내리는 얼음 결정. 일본 **豪雪地帯 (豪雪 지대)** = 한국어 "대설 지역" 동일. 일상 회화: **雪 (눈)** + **雪まつり (눈 축제)** = 한국어 "눈 축제" (일본 삿포로 유력). 발음: ゆき (yu-ki) — 한국어 ㅇ + ㅋ 발음 연습.

## 온도/계절 (Temperature/Season)

### 暑い (あつい)

**품사:** い형용사 (i-adjective)

**정의:** 덥다 — 기온이 높음. 한국어 "덥다" 의미.

**読み方 (읽는 法):** あつい (히라가나) / atsui (로마자) / 暑い (한자, 音読み: しょ shou, 訓読み: あつい atsui)

**IPA / 발음:** /a.t͡sɯ.i/

**어원:** 漢字 "暑" (음읽 しょ, 訓읽 あつ.い). 한국어 한자어 "서(暑)" 의미. 어원: 日 + 者 (자) → 해 아래 사람 → 덥다.

#### 예문

- 夏は**暑い**です。 — 여름은 덥습니다. (계절, 캐주얼)
- 今日はとても**暑い**です。 — 오늘은 매우 덥습니다. (날씨, 캐주얼)
- **暑い**日に外出しないでください。 — 더운 날 외출하지 마세요. (주의, 격식)

#### 관련 용어

- 暑い (あつい) — 「덥다 (음식/날씨)」
- 熱い (あつい) — 「뜨겁다 (음식/감정)」
- 温暖 (おんだん) — 「온난」
- 猛暑 (もうしょ) — 「맹서 (심한 더위)」
- [[weather-vocabulary]] — 날씨 어휘

#### 문화적 맥락

일본어 **暑い (あつい)** 발음 "아쓰이" — 한국어 "아쓰이" 와 발음 동일. 캐주얼: あつい / 격식: 酷暑 (こくしょ). 한국어 "덥다" / "더워요" 동일. **暑 (더위)** 와 **熱 (뜨거움)** 어원 구분: 暑 = 天候 (날씨), 熱 = 状態 (음식/감정). 한국어 "덥다" (날씨) / "뜨겁다" (음식) 와 동일. **暑い vs 熱い (둘 다 あつい)** 한국어 화자에게 혼동 가능. 발음: あつい (a-tsu-i) — 촉음 っ + ㅇ + ㅣ 발음 연습.

### 寒い (さむい)

**품사:** い형용사 (i-adjective)

**정의:** 춥다 — 기온이 낮음. 한국어 "춥다" 의미.

**読み方 (읽는 법):** さむい (히라가나) / samui (로마자) / 寒い (한자, 音読み: かん kan, 訓読み: さむ.い samui)

**IPA / 발음:** /sa.mɯ.i/

**어원:** 漢字 "寒" (음읽 かん, 訓읽 さむ.い). 한국어 한자어 "한(寒)" 의미. 어원: 宀 (지붕) + 几 (꺼진) → (지붕 아래가) 꺼져 있다 → 춥다.

#### 예문

- 冬は**寒い**です。 — 겨울은 춥습니다. (계절, 캐주얼)
- 今日はとても**寒い**です。 — 오늘은 매우 춥습니다. (날씨, 캐주얼)
- **寒い**日にコートを着ます。 — 추운 날 코트를 입습니다. (의상, 캐주얼)

#### 관련 용어

- 寒い (さむい) — 「춥다」
- 寒気 (さむけ) — 「찬 기운 (몸서리)」
- 極寒 (ごくかん) — 「극한 (심한 추위)」

- [[weather-vocabulary]] — 날씨 어휘

#### 문화적 맥락

### 暖かい (あたたかい)

**품사:** い형용사 (i-adjective)

**정의:** 따뜻하다 — 온도가 적당히 따뜻. 한국어 "따뜻하다" 의미.

**読み方 (읽는 법):** あたたかい (히라가나) / atatakai (로마자) / 暖かい (한자, 音読み: だん dan / ノン non, 訓読み: あたた.かい atatakai)

**IPA / 발음:** /a.ta.ta.ka.i/

**어원:** 漢字 "暖" (음읽 だん/ノン, 訓읽 あたた.か.い/あたた.める/あたた.まる). 한국어 한자어 "난(暖)" 의미. 어원: 日 + 爰 (두 손으로 잡다) → 해의 온기를 잡다 → 따뜻하다.

#### 예문

#### 관련 용어

### 涼しい (すずしい)

**품사:** い형용사 (i-adjective)

**정의:** 서늘하다 — 가을의 시원함. 한국어 "서늘하다" / "선선하다" 의미.

**読み方 (읽는 법):** すずしい (히라가나) / suzushii (로마자) / 涼しい (한자, 音読み: りょう ryou, 訓読み: すず.しい suzushii)

**IPA / 발음:** /sɯ.zɯ.ɕiː/

**어원:** 漢字 "涼" (음읽 りょう, 訓읽 すず.しい). 한국어 한자어 "량(涼)" 의미. 어원: 冫 (얼음) + 京 (서울) → 얼음의 시원함 → 서늘하다.

#### 예문

- 秋は**涼しい**です。 — 가을은 서늘합니다. (계절, 캐주얼)
- 今朝は**涼しい**ですね。 — 오늘 아침은 서늘하네요. (날씨, 캐주얼)
- **涼しい**風が吹きます。 — 서늘한 바람이 붑니다. (바람, 격식)

#### 관련 용어

- 涼しい (すずしい) — 「서늘하다 (날씨)」
- 涼む (すずむ) — 「시원해지다」
- 涼感 (りょうかん) — 「서늘한 느낌」
- 涼 (りょう) — 「서늘함 (음읽)」
- [[weather-vocabulary]] — 날씨 어휘

#### 문화적 맥락

일본어 **涼しい (すずしい)** 발음 "스즈시-" — 한국어 "스즈시-" 와 발음 동일. 캐주얼: すずしい / 격식: 涼 (りょう). 한국어 "서늘하다" / "선선하다" 동일. **涼しい** 가 **寒い (춥다)** 와 **涼しい (서늘)** 의 중간 — 한국어 "서늘" / "선선" 동일. 가을 일상: **涼しい (서늘한)** + **紅葉 (こうよう, 단풍)** = 한국어 "단풍" 동일. 발음: すずしい (su-zu-shi-i) — 촉음 ずず + ㅅ + ㅣ 발음 연습.

## 자연 현상 (Natural Phenomena)

### 風 (かぜ)

**품사:** 명사 (noun)

**정의:** 바람 — 대기 중의 공기 흐름. 한국어 "바람" 의미.

**読み方 (읽는 법):** かぜ (히라가나) / kaze (로마자) / 風 (한자, 音読み: ふう fuu, 訓読み: かぜ kaze)

**IPA / 발음:** /ka.ze/

**어원:** 漢字 "風" (음읽 ふう/ふ, 訓읽 かぜ). 한국어 한자어 "풍(風)" 의미. 어원: 几 (꺼진) + 虫 (벌레) → 안 보이는 벌레가 움직임 → 바람.

#### 예문

- 強い**風**です。 — 강한 바람입니다. (강도, 격식)
- **風**が吹きます。 — 바람이 붑니다. (행위, 격식)
- 冷たい**風**が吹いています。 — 찬 바람이 불고 있습니다. (날씨, 격식)

#### 관련 용어

- 風 (かぜ) — 「바람 (날씨)」
- 風 (ふう) — 「바람 (음읽, 방식/풍습)」
- 突風 (とっぷう) — 「돌풍」
- 台風 (たいふう) — 「태풍」
- [[weather-vocabulary]] — 날씨 어휘

#### 문화적 맥락

일본어 **風 (かぜ)** 발음 "카제" — 한국어 "카제" 와 발음 동일. 캐주얼: かぜ / 음읽: ふう (방식/풍습). 한국·일본 모두 **風 (바람)** = 대기 공기 흐름. **風 (바람)** + **風 (풍속, 방식)** 의 어원 구분: 한자 동형, 발음 다름. **風 (かせ)** = 자연 현상, **風 (ふう)** = 추상/방식. 한국어 "바람" / "풍(風)" 동일. 발음: かぜ (ka-ze) — 한국어 ㅋ + ㅈ 발음 연습.

### 台風 (たいふう)

**품사:** 명사 (noun)

**정의:** 태풍 — 열대 저기압으로 발생하는 폭풍. 한국어 "태풍" / 한자어 "태풍(台風)" 와 의미 동일.

**読み方 (읽는 法):** たいふう (히라가나) / taifuu (로마자) / 台風 (한자, 音読み: たいふう taifuu)

**IPA / 발음:** /ta.i.fɯː/

**어원:** 漢字 "台" (음읽 だい/たい, 訓읽 うてな/つくえ) + "風" (음읽 ふう). 한국어 한자어 "태풍(台風)" 동일 한자, 한국어 역음 "태풍". 어원: 台 = 대 (Taiwan 대만 → typhoon 어원) + 風 = 바람.

#### 예문

- **台風**が来ています。 — 태풍이 오고 있습니다. (접근, 격식)
- **台風**が上陸します。 — 태풍이 상륙합니다. (도착, 격식)
- **台風**に気をつけてください。 — 태풍에 주의하세요. (경고, 격식)

#### 관련 용어

- 台風 (たいふう) — 「태풍」
- 台風の目 (たいふうのめ) — 「태풍의 눈」
- 台風一過 (たいふういっか) — 「태풍이 지나감」
- 台風情報 (たいふうじょうほう) — 「태풍 정보」
- [[weather-vocabulary]] — 날씨 어휘

#### 문화적 맥락

일본어 **台風 (たいふう)** 발음 "타이후-" — 한국어 "태풍" (한자어) 와 발음 유사. 캐주얼: たいふう / 약자: 台風 (동일). 한국·일본 모두 **台風 (태풍)** = 열대 폭풍. **台風 (타이푼)** 어원: 영어 "typhoon" → 일본어 台風 (한자 의역) + 한국어 "태풍" (한자어). 일본 **台風の上陸 (태풍의 상륙)** = 한국어 "태풍 상륙" 동일. 발음: たいふう (ta-i-fu-u) — 장음 お + ㅇ 발음 연습.
