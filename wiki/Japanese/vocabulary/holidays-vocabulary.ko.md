# Holidays (명절) - Korean Translation

이 페이지는 한국인이 일본어 명절 어휘를 학습할 때 사용하는 한국어 관점 참고 자료입니다. 기본 명절 (祝日/誕生日/クリスマス/正月/結婚式) + 축하 표현 (パーティー/プレゼント/ケーキ) + 일본 명절 (花火/祭り/バレンタイン/ホワイトデー) + 정통 명절 (お正月/お年玉/お盆) + 특별 휴일 (ゴールデンウィーク) 등 18 entries 를 다룹니다. 한국·일본 명절 문화 비교 (크리스마스/발렌타인/화이트데이/한가위 vs 일본 오본) 포함.

**참고:** 본 페이지는 `wiki/Japanese/vocabulary/holidays-vocabulary.md` 의 한국어 번역/관점 페이지 입니다. 일본어 원문 표제(見出し)는 한자 + 히라가나(讀み方) 형식으로 표기.

## 기본 명절 (Basic Holidays)

### 祝日 (しゅくじつ)

**품사:** 명사 (noun)

**정의:** 공휴일 — 일본 공휴일. 한국어 "공휴일" / 한자어 "축일(祝日)" 의미.

**読み方 (읽는 법):** しゅくじつ (히라가나) / shukujitsu (로마자) / 祝日 (한자, 音読み: しゅくじつ shukujitsu)

**IPA / 발음:** /ɕɯ.kɯ.dʑi.t͡sɯ/

**어원:** 漢字 "祝" (음읽 しゅく/しゅう, 訓읽 いわ.う) + "日" (음읽 にち/じつ, 訓읽 ひ). 한국어 한자어 "축일(祝日)" / "공휴일(公休日)" 의미. 어원: 祝 (축하) + 日 (날) = 축하의 날 = 공휴일.

#### 예문

- 明日(あした)は**祝日**です。 — 내일은 공휴일입니다. (사실, 격식)
- **祝日**は何ですか? — 공휴일 무슨 날인데요? (질문, 캐주얼)
- **祝日**は何曜日ですか? — 공휴일 무슨 요일입니까? (질문, 격식)

#### 관련 용어

- 祝日 (しゅくじつ) — 「공휴일 (한자어)」
- 祭日 (さいじつ) — 「제일 (한자어)」
- 休日 (きゅうじつ) — 「휴일 (한자어)」
- 公休日 (こうきゅうじつ) — 「공휴일 (한자어)」
- 国民の祝日 (こくみんのしゅくじつ) — 「국민의 축일 (일본 법률)」
- [[holidays-vocabulary]] — 명절 어휘

#### 문화적 맥략

일본어 **祝日 (しゅくじつ)** 발음 "슈쿠지쓰" — 한국어 "축일" (한자어) 와 발음 동일. 캐주얼: 祝日 (shu-ku-ji-tsu) / 한자어: 祝祭日 (しゅくさいじつ). 한국어 "공휴일" 동일. 일본 **祝日 (일본 공휴일)** = 한국어 "공휴일" 의 어원 비교. 일본 **'내일의 날' (みらいの日 4/15)** 같은 현대 명절이 있음 — 한국어 "공휴일" 비교. 발음: 祝日 (shu-ku-ji-tsu) — 촉음 っ + ㄱ + ㅈ + ㅅ 발음 연습.

### 誕生日 (たんじょうび)

**품사:** 명사 (noun)

**정의:** 생일 — 태어난 날. 한국어 "생일" / 한자어 "생일(生日)" 의미.

**読み方 (읽는 법):** たんじょうび (히라가나) / tanjōbi (로마자) / 誕生日 (한자, 音読み: たんじょうび tanjōbi)

**IPA / 발음:** /tan.dʑoː.bi/

**어원:** 漢字 "誕" (음읽 たん, 訓읽 -.うまれる) + "生" (음읽 せい/しょう, 訓읽 い.きる/なま) + "日" (날). 한국어 한자어 "생일(生日)" 비교 / 誕生 (탄생) + 日 (날) = 생일. 어원: 誕 (출생) + 生 (삶) + 日 (날) = 삶의 시작 날.

#### 예문

- **誕生日**おめでとう! — 생일 축하해! (축하, 캐주얼)
- **誕生日**はいつですか? — 생일 언제예요? (질문, 캐주얼)
- **誕生日**ケーキ (ケーキ) — 「생일 케이크」

#### 관련 용어

- 誕生日 (たんじょうび) — 「생일 (한자어)」
- 誕生 (たんじょう) — 「탄생 (한자어)」
- 祝う (いわう) — 「축하하다 (동사)」
- 誕生日会 (たんじょうびかい) — 「생일 파티」
- [[holidays-vocabulary]] — 명절 어휘

#### 문화적 맥략

일본어 **誕生日 (たんじょうび)** 발음 "탄조비" — 한국어 "생일" (한자어) 와 발음 동일. 캐주얼: 誕生日 (tan-jō-bi) / 음읽: たんじょうび. 한국어 "생일" 동일. **誕生日 (한자어)** = 한국어 "생일" 의 어원 비교. 일본 **鯛 (タイ, 도미) 케이크** 가 전통 = 한국어 "떡 케이크" 의 어원 비교. **誕生日会 (birthday party)** = 한국어 "생일 파티" 의 어원 비교. 발음: 誕生日 (tan-jō-bi) — 장음 お + ㅂ 발음 연습.

### クリスマス (kurisumasu)

**품사:** 명사 (noun)

**정의:** 크리스마스 — 12월 25일. 한국어 "크리스마스" (loanword) / 한자어 "성탄절(聖誕節)" 의미.

**読み方 (읽는 법):** クリスマス (히라가나 カタカナ) / kurisumasu (로마자) / 漢字: 聖誕節 (せいたんせつ, 한자어)

**IPA / 발음:** /kɯ.ɾi.sɯ.ma.sɯ/

**어원:** 외래어 (外来語). 영어 "Christmas" → 일본어 カタカナ 転写 **クリスマス**. 한국어 **크리스마스** — 같은 어원.

#### 예문

- **メリークリスマス**! — 메리 크리스마스! (인사, 캐주얼)
- **クリスマス**は how過ごす? — 크리스마스 어떻게 보내? (질문, 캐주얼)
- **クリスマス**ケーキ (ケーキ) — 「크리스마스 케이크」

#### 관련 용어

- クリスマス (kurisumasu) — 「크리스마스 (외래어)」
- 聖誕祭 (せいたんさい) — 「성탄절 (한자어)」
- サンタクロース (Santa Kurōsu) — 「산타클로스」
- イブ (ibu) — 「이브 (전날)」
- [[holidays-vocabulary]] — 명절 어휘

#### 문화적 맥략

일본어 **クリスマス (kurisumasu, 크리스마스)** 발음 "쿠리스마스" — 한국어 "크리스마스" (loanword) 와 발음 동일. 캐주얼: クリスマス (ku-ri-su-ma-su) / 한자어: 聖誕節 (せいたんせつ). 한국어 "크리스마스" 동일. **クリスマス (외래어)** + **聖誕節 (한자어 성탄절)** 의 어원 비교. 일본 **クリスマス = 연인 명절** (恋人たちの日) — 한국어 "크리스마스" 의 어원 비교. 일본 **チキン (치킨)** = 한국어 "치킨" 의 어원 비교 (1974년 KFC 일본 진출). 발음: クリスマス (ku-ri-su-ma-su) — 촉음 っ + ㄹ + ㅅ + ㅁ + ㅅ 발음 연습.

### 正月 (しょうがつ)

**품사:** 명사 (noun)

**IPA / 발음:** /ɕoː.gat͡sɯ/

**어원:** 和語 — 正 (정확한) + 月 (달). 어원: 음력 1월 = 정월 → 새해. 한국어 "설날" 어원: 歳 (새해) + 나 (날) = 새해날.

#### 예문

- **正月**どう過ごしましたか? — 설날 어떻게 보냈어요? (질문, 캐주얼)
- **正月**が大好きです。 — 설날을 매우 좋아합니다. (취향, 캐주얼)
- **正月**休み (しょうがつやすみ) — 「설날 연휴」

#### 관련 용어

- 正月 (しょうがつ) — 「설날 (한자어)」

- おせち料理 (おせちりょうり) — 「오세치 요리」
- [[holidays-vocabulary]] — 명절 어휘

#### 문화적 맥략

일본어 **正月 (しょうがつ)** 발음 "쇼-가쓰" — 한국어 "정월" (한자어) 와 발음 동일. 캐주얼: 正月 (shō-gatsu) / 음읽: しょうがつ. 한국어 "설날" 동일. **正月 (한자어)** = 한국어 "설날" 의 어원 비교. 일본 **お正月 (오쇼가쓰, 존칭)** = 한국어 "설날" 의 어원 비교. 일본 **お年玉 (오토시다마, 세뱃돈)** = 한국어 "세뱃돈" 의 어원 비교. 발음: しょうがつ (shō-ga-tsu) — 장음 お + ㄱ + ㅅ 발음 연습.

### 結婚式 (けっこんしき)

**품사:** 명사 (noun)

**정의:** 결혼식 — 혼인 의식. 한국어 "결혼식" / 한자어 "결혼식(結婚式)" 의미.

**読み方 (읽는 법):** けっこんしき (히라가나) / kekkonshiki (로마자) / 結婚式 (한자, 音読み: けっこんしき kekkonshiki)

**IPA / 발음:** /kek.koɴ.ɕi.ki/

**어원:** 漢字 "結" (음읽 けつ, 訓읽 むす.ぶ/ゆ.わ.える/ゆう) + "婚" (음읽 こん, 訓읽 -.) + "式" (음읽 しき, 訓읽 -.). 한국어 한자어 "결혼식(結婚式)" 동일 한자, 한국어 역음 "결혼식". 어원: 結 (맺다) + 婚 (혼인) + 式 (의식) = 혼인의 의식.

#### 예문

- **結婚式**に招待されました。 — 결혼식에 초대받았습니다. (상황, 격식)
- いつ**結婚式**ですか? — 언제 결혼식입니까? (질문, 캐주얼)
- **結婚式**場 (けっこんしきじょう) — 「결혼식장」

#### 관련 용어

- 結婚式 (けっこんしき) — 「결혼식 (한자어)」
- 披露宴 (ひろうえん) — 「피로연 (한자어)」
- 新郎 (しんろう) — 「신랑 (한자어)」
- 新婦 (しんぷ) — 「신부 (한자어)」
- お祝 (おいわい) — 「축하 (한자어)」
- [[holidays-vocabulary]] — 명절 어휘

#### 문화적 맥략

일본어 **結婚式 (けっこんしき)** 발음 "켓콘시키" — 한국어 "결혼식" (한자어) 와 발음 동일. 캐주얼: 結婚式 (kek-kon-shi-ki) / 음읽: けっこんしき. 한국어 "결혼식" 동일. **結婚式 (한자어)** = 한국어 "결혼식" 의 어원 비교. 일본 **披露宴 (ひろうえん, 피로연)** = 한국어 "피로연" 의 어원 비교. 일본 **白 (しろ) 드레스 + 神前式 (かみまえしき, 신전 결혼식)** 빈번 — 한국어 "결혼식" (한복 + 폐백) 의 어원 비교. 발음: けっこんしき (kek-kon-shi-ki) — 촉음 っ + ㄴ + ㅊ 발음 연습.

**IPA / 발음:** /paː.tiː/
