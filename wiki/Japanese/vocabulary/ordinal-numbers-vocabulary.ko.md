# Ordinal Numbers (서수) - Korean Translation

이 페이지는 한국인이 일본어 서수 (ordinal numbers) 어휘를 학습할 때 사용하는 한국어 관점 참고 자료입니다. 一番~十番 (첫째~열째) + 순서 표현 (何番目) 을 다룹니다. 각 단어의 한국어 정의, 발음 (히라가나/로마자), 한자 어원, 한국어 예문, 한국·일본 서수 표현 비교를 포함합니다.

**참고:** 본 페이지는 `wiki/Japanese/vocabulary/ordinal-numbers-vocabulary.md` 의 한국어 번역/관점 페이지 입니다. 일본어 원문 표제(見出し)는 한자 + 히라가나(讀み方) 형식으로 표기.

## 서수 (Ordinal Numbers 1-10)

### 一番 (いちばん)

**품사:** 부사 (adv) / 명사 (noun)

**정의:** 첫째 — 순서상 첫 번째. 한국어 "첫째" / 한자어 "제일(第一)" 의미. 부사: "가장" (最上級).

**読み方 (읽는 법):** いちばん (히라가나) / ichiban (로마자) / 一番 (한자, 音読み: いちばん ichiban)

**IPA / 발음:** /i.tɕi.ban/

**어원:** 漢字 "一" (음읽 いち) + "番" (음읽 ばん, 訓읽 つが.い). 한국어 한자어 "제일(第一)" / "일번(一番)" 의미. 어원: 一 = 1, 番 = 차례/순서.

#### 예문

- 私は**一番**最初に並んでいます。 — 저는 가장 먼저 줄 서 있습니다. (순서, 격식)
- **一番**好きな食べ物は? — 가장 좋아하는 음식은? (최상, 캐주얼)
- **一番**目 (いちばんめ) — 「첫 번째 (변형)」
- 彼は**一番**の選手です。 — 그는 최고의 선수입니다. (수상, 격식)

#### 관련 용어

- 一番 (いちばん) — 「가장/첫째 (서수)」
- 一番目 (いちばんめ) — 「첫 번째 (변형)」
- 第一 (だいいち) — 「제일 (격식)」
- 一 (いち) — 「1 (기수)」
- 第 (だい) — 「제 (서수 격식)」
- [[ordinal-numbers-vocabulary]] — 서수 어휘

#### 문화적 맥락

일본어 **一番 (いちばん)** 발음 "이치반" — 한국어 "이치반" (이치반) 와 발음 동일. 캐주얼: いちばん / 격식: 第一 (だいいち). 한국어 "첫째" / "제일" (한자어) / "일번" 동일. **一番 (いちばん)** = 二가지 의미: (1) 서수 첫째, (2) 최상급 (가장). 한국어 동일. 일상 회화: **一番 (가장)** + **一番目 (첫 번째)** 의 비교. 발음: いちばん (i-chi-ban) — 한국어 ㅊ + ㅂ + ㄴ 발음 연습.

**어원:** 漢字 "九" (음읽 く / 9 단독) + "番" (음읽 ばん). 한국어 한자어 "구번(九番)" 의미. 어원: 九 = 9, 番 = 차례.

#### 예문

- **九番**目の行に答えがあります。 — 아홉 번째 줄에 답이 있습니다. (위치, 격식)
- **九番**目に好きです。 — 아홉 번째로 좋아합니다. (서수, 캐주얼)
- **九番**線 (くばんせん) — 「9번 선 (전철)」
- 彼は**九番**目に走りました。 — 그는 아홉 번째로 달렸습니다. (순서, 격식)

#### 관련 용어

- 九番 (くばん) — 「아홉째 (단독)」
- 九番 (きゅうばん) — 「아홉째 (격식)」
- 九番目 (くばんめ) — 「아홉 번째 (변형)」
- 第九 (だいく) — 「제구 (격식)」
- 九 (く) — 「9 (기수)」
- [[ordinal-numbers-vocabulary]] — 서수 어휘

#### 문화적 맥락

일본어 **九番 (くばん)** 발음 "쿠반" — 한국어 "쿠반" (쿠반) 와 발음 동일. 캐주얼: くばん / 격식: きゅうばん. 한국어 "아홉째" / "제구" (한자어) / "구번" 동일. **九番 (くばん)** 의 캐주얼 발음 = く (단독) / きゅう (격식). 한국어 "구" / "아홉" 의 어원 (한자어/고유어). 발음: くばん (ku-ban) — 한국어 ㅋ + ㅂ + ㄴ 발음 연습.

### 十番 (じゅうばん)

**품사:** 부사 (adv) / 명사 (noun)

**정의:** 열째 — 순서상 열 번째. 한국어 "열째" / 한자어 "제십(第十)" 의미.

**読み方 (읽는 법):** じゅうばん (히라가나) / juuban (로마자) / 十番 (한자, 音読み: じゅうばん juuban)

**IPA / 발음:** /dʑɯː.ban/

**어원:** 漢字 "十" (음읽 じゅう) + "番" (음읽 ばん). 한국어 한자어 "십번(十番)" 의미. 어원: 十 = 10, 番 = 차례.

#### 예문

- これで**十番**目です。 — 이것으로 열째입니다. (서수, 격식)
- **十番**目に好きです。 — 열 번째로 좋아합니다. (서수, 캐주얼)
- **十番**線 (じゅうばんせん) — 「10번 선 (전철)」
- 彼女は**十番**目にゴールしました。 — 그녀는 열 번째로 결승점에 들어왔습니다. (순서, 격식)

#### 관련 용어

- 十番 (じゅうばん) — 「열째」
- 十番目 (じゅうばんめ) — 「열 번째 (변형)」
- 第十 (だいじゅう) — 「제십 (격식)」
- 十 (じゅう) — 「10 (기수)」
- [[ordinal-numbers-vocabulary]] — 서수 어휘

#### 문화적 맥락

일본어 **十番 (じゅうばん)** 발음 "주-반" — 한국어 "주반" (식탁) 와 발음 동일. 캐주얼: じゅうばん / 격식: 第十 (だいじゅう). 한국어 "열째" / "제십" (한자어) / "십번" 동일. 일상 회화: **十番 (열째)** + **十人 (じゅうにん, 열 명)** 의 비교. 발음: じゅうばん (jyu-ban) — 장음 お + ㅂ + ㄴ 발음 연습.
