# Transportation (교통) - Korean Translation

이 페이지는 한국인이 일본어 교통 어휘를 학습할 때 사용하는 한국어 관점 참고 자료입니다. 자동차·대중교통 (車/バス/電車/飛行機/船/自転車/タクシー/地下鉄/駅/切符) 을 다룹니다. 각 단어의 한국어 정의, 발음 (히라가나/로마자), 한자 어원, 한국어 예문, 한국·일본 교통 문화 비교를 포함합니다.

**참고:** 본 페이지는 `wiki/Japanese/vocabulary/transportation-vocabulary.md` 의 한국어 번역/관점 페이지 입니다. 일본어 원문 표제(見出し)는 한자 + 히라가나(讀み方) 형식으로 표기.

## 자동차/일반 교통 (Cars / General)

### 車 (くるま)

**품사:** 명사 (noun)

**정의:** 자동차 — 보통 자동차. 한국어 "자동차" / 한자어 "거(車)" 의미.

**読み方 (읽는 법):** くるま (히라가나) / kuruma (로마자) / 車 (한자, 音読み: しゃ sha / くるま kuruma, 訓読み: くるま kuruma)

**IPA / 발음:** /kɯ.ɾɯ.ma/

**어원:** 漢字 "車" (음읽 しゃ, 訓읽 くるま). 한국어 한자어 "거(車)" 의미. 어원: 바퀴 달린 수레/탈것 → 현대 자동차.

#### 예문

- **車**で仕事に行きます。 — 차로 출근합니다. (출퇴근, 캐주얼)
- 新しい**車**を買いました。 — 새 차를 샀습니다. (구매, 캐주얼)
- **車**を運転します。 — 차를 운전합니다. (운전, 캐주얼)

#### 관련 용어

- 車 (くるま) — 「차 (캐주얼)」
- 自動車 (じどうしゃ) — 「자동차 (격식)」
- 車庫 (しゃこ) — 「차고」
- 車線 (しゃせん) — 「차선」
- [[transportation-vocabulary]] — 교통 어휘

#### 문화적 맥락

일본어 **車 (くるま)** 발음 "쿠루마" — 한국어 "쿠루마" 와 발음 동일. 캐주얼: くるま / 격식: 自動車 (じどうしゃ). 한국·일본 모두 **車 (차)** = 자동차. 일본 **車社会 (しゃしゃかい, 차 문화)** — 대중교통 발달한 도시에서도 **車** 중요. 한국어 "차" / "자동차" 동일. 발음: くるま (ku-ru-ma) — 한국어 ㅋ + ㄹ + ㅁ 발음 연습.

### バス

**품사:** 명사 (noun)

**정의:** 버스 — 대중교통 버스. 한국어 "버스" (loanword) 와 의미 동일.

**読み方 (읽는 법):** バス (히라가나 カタカナ) / basu (로마자) / 漢字: 乗合自動車 (격식), 公共汽車 (구식)

**IPA / 발음:** /ba.sɯ/

**어원:** 외래어 (外来語). 영어 "bus" → 일본어 カタカナ 転写 **バス**. 한국어 **버스** — 같은 어원 (영어 직접 차용).

#### 예문

- **バス**が遅れています。 — 버스가 늦습니다. (지연, 격식)
- **バス**で会社に行きます。 — 버스로 회사에 갑니다. (출근, 캐주얼)
- 次の**バス**は何時ですか? — 다음 버스는 몇 시입니까? (질문, 격식)

#### 관련 용어

- バス (basu) — 「버스 (캐주얼)」
- 路線バス (ろせんバス) — 「노선 버스」
- 高速バス (こうそくバス) — 「고속 버스」
- バス停 (バスてい) — 「버스 정류장」
- [[transportation-vocabulary]] — 교통 어휘

#### 문화적 맥락

일본어 **バス (basu, 버스)** 발음 "바스" — 한국어 "바스" 와 발음 동일. 한국·일본 모두 **バス (버스)** = 대중교통. 일본 버스: **ICカード (IC 카드, Suica/Pasmo)** 로 결제 빈번 — 한국 **T-money** 와 동일. 일상 회화: **バス** 가 **乗合自動車 (노합자동차)** 보다 빈번. 한국어 "버스" / "고속버스" 동일. 발음: バス (ba-su) — 한국어 ㅂ + ㅅ 발음 연습.

### 電車 (でんしゃ)

**품사:** 명사 (noun)

**정의:** 기차 — 전기 기관차, 도시·광역 철도. 한국어 "전철" 의미 (한자어 차용).

**読み方 (읽는 법):** でんしゃ (히라가나) / densha (로마자) / 電車 (한자, 音読み: でんしゃ densha)

**IPA / 발음:** /den.ɕa/

**어원:** 漢字 "電" (음읽 でん) + "車" (음읽 しゃ). 한국어 한자어 "전차(電車)" 의미. 어원: 電 = 전기, 車 = 차 → 전기 차.

#### 예문

- **電車**でソウルに行きます。 — 전철로 서울에 갑니다. (교통, 격식)
- **電車**に乗り遅れました。 — 전철을 놓쳤습니다. (실수, 캐주얼)
- **電車**は何番線ですか? — 전철은 몇 번 홈입니까? (질문, 격식)

#### 관련 용어

- 電車 (でんしゃ) — 「전철 (일본 도시/광역)」
- 地下鉄 (ちかてつ) — 「지하철」
- 新幹線 (しんかんせん) — 「신칸센 (고속)」
- 私鉄 (してつ) — 「사철 (민간 철도)」
- [[transportation-vocabulary]] — 교통 어휘

#### 문화적 맥락

일본어 **電車 (でんしゃ)** 발음 "덴샤" — 한국어 "전차" (옛 의미: 도시 노면 전차) 와 다름. 한국어 "전철" = 한자어 차용, 일본어 電車 = 같은 한자. **전철** (한국, 지하철 의역) vs **地下鉄** (일본, 지하철) 의 어원 비교. 한국·일본 모두 **電車 (전철)** + **地下鉄 (지하철)** = 도시 대중교통. 발음: でんしゃ (den-sha) — 한국어 ㄴ + ㅅ 발음 연습.

### 飛行機 (ひこうき)

**품사:** 명사 (noun)

**정의:** 비행기 — 항공기. 한국어 "비행기" / 한자어 "비행기(飛行機)" 와 의미 동일.

**読み方 (읽는 법):** ひこうき (히라가나) / hikouki (로마자) / 飛行機 (한자, 音読み: ひこうき hikouki)

**IPA / 발음:** /çi.koː.ki/

**어원:** 漢字 "飛" (음읽 ひ, 訓읽 と.ぶ/と.ばす) + "行" (음읽 こう/あん/ぎょう, 訓읽 い.く/ゆ.く/おこな.う) + "機" (음읽 き, 訓읽 はた). 한국어 한자어 "비행기(飛行機)" 동일 한자, 한국어 역음 "비행기". 어원: 飛 = 날다, 行 = 가다, 機 = 기계.

#### 예문

- **飛行機**は速いです。 — 비행기는 빠릅니다. (속도, 캐주얼)
- **飛行機**に乗ります。 — 비행기를 탑니다. (탑승, 격식)
- **飛行機**で日本に行きます。 — 비행기로 일본에 갑니다. (여행, 캐주얼)

#### 관련 용어

- 飛行機 (ひこうき) — 「비행기 (캐주얼)」
- 旅客機 (りょかくき) — 「여객기 (격식)」
- ヘリコプター — 「헬리콥터」
- 空港 (くうこう) — 「공항」
- [[transportation-vocabulary]] — 교통 어휘

#### 문화적 맥락

일본어 **飛行機 (ひこうき)** 발음 "히코-키" — 한국어 "비행기" 와 발음 유사. 캐주얼: ひこうき / 격식: 旅客機 (りょかくき). 한국·일본 모두 **飛行機 (비행기)** = 항공기. 발음: ひこうき (hi-ko-u-ki) — 장음 お (o) + ㄱ 발음 연습. 한국어 "비행기" / "항공기" 모두 사용. 일본어 飛行機 vs 旅客機 — 한국어 "비행기" / "항공기" / "여객기" 의 구분.

### 船 (ふね)

**품사:** 명사 (noun)

**정의:** 배 — 선박. 한국어 "배" 의미.

**読み方 (읽는 법):** ふね (히라가나) / fune (로마자) / 船 (한자, 音読み: せん sen, 訓読み: ふね fune / ふな funa)

**IPA / 발음:** /ɸɯ.ne/

**어원:** 漢字 "船" (음읽 せん, 訓읽 ふね/ふな). 한국어 한자어 "선(船)" 의미. 어원: 舟 + 㕣 (몸체) → 배/선박.

#### 예문

- **船**は海を渡ります。 — 배는 바다를 건넙니다. (행위, 격식)
- **船**に乗ります。 — 배를 탑니다. (탑승, 캐주얼)
- **船**旅が好きです。 — 배 여행을 좋아합니다. (취미, 캐주얼)

#### 관련 용어

- 船 (ふね) — 「배 (캐주얼)」
- 船舶 (せんぱく) — 「선박 (격식)」
- 汽船 (きせん) — 「증기선 (구식)」
- 漁船 (ぎょせん) — 「어선」
- [[transportation-vocabulary]] — 교통 어휘

#### 문화적 맥락

일본어 **船 (ふね)** 발음 "후네" — 한국어 "후네" / "배" 와 발음 비교. 캐주얼: ふね / 격식: 船舶 (せんぱく). 한국·일본 모두 **船 (배)** = 선박. 일본은 **島国 (섬나라)** 라 **船 (배)** 문화 발달 — 한국어 "배" 와 비교. 일상 회화: **船 (ふね)** 가 **船 (せん, 음읽)** 보다 캐주얼. 발음: ふね (fu-ne) — 한국어 ㅂ + ㄴ 발음 연습.

### 自転車 (じてんしゃ)

**품사:** 명사 (noun)

**정의:** 자전거 — 페달 자전거. 한국어 "자전거" / 한자어 "자전거(自轉車)" 와 의미 동일.

**読み方 (읽는 法):** じてんしゃ (히라가나) / jitensha (로마자) / 自転車 (한자, 音読み: じてんしゃ jitensha)

**IPA / 발음:** /dʑi.ten.ɕa/

**어원:** 漢字 "自" (음읽 じ/し, 訓읽 おの.ずから/みずか.ら) + "転" (음읽 てん, 訓읽 ころ.がる/ころ.げる/ころ.がす) + "車" (음읽 しゃ). 한국어 한자어 "자전거(自轉車)" 동일 한자, 한국어 역음 "자전거". 어원: 自 = 스스로, 轉 = 돌다, 車 = 차.

#### 예문

- **自転車**で学校に行きます。 — 자전거로 학교에 갑니다. (교통, 캐주얼)
- **自転車**に乗ります。 — 자전거를 탑니다. (행위, 캐주얼)
- **自転車**を借ります。 — 자전거를 빌립니다. (대여, 캐주얼)

#### 관련 용어

- 自転車 (じてんしゃ) — 「자전거 (캐주얼)」
- ママチャリ (mamachari) — 「엄마 자전거 (일본 캐주얼)」
- ロードバイク — 「로드 자전거」
- 電動自転車 (でんどうじてんしゃ) — 「전동 자전거」
- [[transportation-vocabulary]] — 교통 어휘

#### 문화적 맥락

일본어 **自転車 (じてんしゃ)** 발음 "지텐샤" — 한국어 "자전거" (한자어) 와 발음 유사. 캐주얼: じてんしゃ / 줄임: チャリ (chari). 한국·일본 모두 **自転車 (자전거)** = 2륜 페달. 일본 캐주어: **チャリ (chari)** — 한국어 자전거 "자 (ja)" 와 비슷. 발음: じてんしゃ (ji-ten-sha) — 한국어 ㅈ + ㄴ + ㅅ 발음 연습.

### タクシー

**품사:** 명사 (noun)

**정의:** 택시 — 요금제 자동차. 한국어 "택시" (loanword) 와 의미 동일.

**読み方 (읽는 법):** タクシー (히라가나 カタカナ) / takushī (로마자) / 漢字: 辻自動車 (つじじどうしゃ, 구식), 運転代行 (うんてんだいこう)

**IPA / 발음:** /takɯ.ɕiː/

**어원:** 외래어 (外来語). 영어 "taxi" → 일본어 カタカナ 転写 **タクシー**. 한국어 **택시** — 같은 어원.

#### 예문

- **タクシー**で家まで帰りました。 — 택시로 집까지 갔습니다. (이동, 캐주얼)
- **タクシー**を呼んでください。 — 택시를 불러 주세요. (요청, 격식)
- **タクシー**代はいくらですか? — 택시비는 얼마입니까? (질문, 격식)

#### 관련 용어

- タクシー (takushī) — 「택시 (캐주얼)」
- タクシードライバー — 「택시 기사」
- 料金 (りょうきん) — 「요금」
- メーター (mētā) — 「미터기」
- [[transportation-vocabulary]] — 교통 어휘

#### 문화적 맥락

일본어 **タクシー (takushī, 택시)** 발음 "타쿠시-" — 한국어 "택시" 와 발음 동일. 한국·일본 모두 **タクシー (택시)** = 요금제 자동차. 일본 택시: **自動ドア (자동문)** + **運賃メーター (요금 미터기)** 표준. 한국어 동일. 발음: タクシー (ta-ku-shi-) — 한국어 ㅅ + ㅣ 발음 연습. 캐주얼: **流す (ながす, 택시 지나가게 두다)** / 캐치 가능.

### 地下鉄 (ちかてつ)

**품사:** 명사 (noun)

**정의:** 지하철 — 지하 도시 철도. 한국어 "지하철" / 한자어 "지하철(地下鐵)" 와 의미 동일.

**読み方 (읽는 법):** ちかてつ (히라가나) / chikatetsu (로마자) / 地下鉄 (한자, 音読み: ちかてつ chikatetsu)

**IPA / 발음:** /tɕi.ka.tet͡sɯ/

**어원:** 漢字 "地" (음읽 ち/じ, 訓읽 ところ) + "下" (음읽 か/げ, 訓읽 した/しも/もと) + "鉄" (음읽 てつ, 訓읽 くろがね). 한국어 한자어 "지하철(地下鐵)" 동일 한자, 한국어 역음 "지하철". 어원: 地 = 땅, 下 = 아래, 鉄 = 철.

#### 예문

- ソウルでは**地下鉄**が速いです。 — 서울에서는 지하철이 빠릅니다. (교통, 격식)
- **地下鉄**の駅はどこですか? — 지하철 역은 어디입니까? (질문, 격식)
- **地下鉄**で行きます。 — 지하철로 갑니다. (교통, 캐주얼)

#### 관련 용어

- 地下鉄 (ちかてつ) — 「지하철 (캐주얼)」
- 地下鐵 (ちかてつ) — 「지하철 (정자체)」
- 路線 (ろせん) — 「노선」
- 乗換 (のりかえ) — 「환승」
- [[transportation-vocabulary]] — 교통 어휘

#### 문화적 맥락

일본어 **地下鉄 (ちかてつ)** 발음 "치카텟스" — 한국어 "지하철" (한자어) 와 발음 유사. 한국·일본 모두 **地下鉄 (지하철)** = 도시 지하 철도. 일본 도시: **東京 (도쿄)** — **東京メトロ (도쿄 메트로)** + **都営 (도에이)** 2개 운영. 한국어 "지하철" + "전철" (도시 노면) 구분. 발음: ちかてつ (chi-ka-te-tsu) — 한국어 ㅊ + ㅋ + ㅌ + ㅅ 발음 연습.

**품사:** 명사 (noun)

**정의:** 역 — 철도역. 한국어 "역" / 한자어 "역(驛)" 와 의미 동일.

**読み方 (읽는 법):** えき (히라가나) / eki (로마자) / 駅 (한자, 音読み: えき eki)

**IPA / 발음:** /e.ki/

**어원:** 漢字 "駅" (음읽 えき). 한국어 한자어 "역(驛)" 동일 한자, 한국어 역음 "역". 어원: 馬 (말) + 駅 (역참) + 邑 (마을) → 역참 (기마 휴식처) → 현대역.

#### 예문

- **駅**は近いです。 — 역은 가깝습니다. (위치, 캐주얼)
- **駅**はどこですか? — 역은 어디입니까? (질문, 격식)
- **駅**で会いましょう。 — 역에서 만납시다. (약속, 캐주얼)

#### 관련 용어

- 駅 (えき) — 「역 (캐주얼)」
- 驛 (えき) — 「역 (정자체)」
- 駅前 (えきまえ) — 「역 앞」
- 駅員 (えきいん) — 「역무원」
- [[transportation-vocabulary]] — 교통 어휘

#### 문화적 맥락

일본어 **駅 (えき)** 발음 "에키" — 한국어 "에키" 와 발음 동일. 한국·일본 모두 **駅 (역)** = 철도 정거장. 일상 회화: **東京駅 (도쿄역)** / **ソウル駅 (서울역)** / **新宿駅 (신주쿠역)** — 한국어 동일. 일본 **新幹線 (신칸센)** 정차역 빈번. 발음: えき (e-ki) — 한국어 ㅔ + ㄱ 발음 연습. 한국어 "역" (한자어) + "정거장" (의역) 모두 사용.

### 切符 (きっぷ)

**품사:** 명사 (noun)

**정의:** 표 — 승차권. 한국어 "표" / 한자어 "표(票)" 와 의미 동일.

**読み方 (읽는 법):** きっぷ (히라가나) / kippu (로마자) / 切符 (한자, 音読み: きっぷ kippu)

**IPA / 발음:** /kip.pɯ/

**어원:** 漢字 "切" (음읽 せつ/さい, 訓읽 き.る/き.れる) + "符" (음읽 ふ, 訓읽 あ.たる). 한국어 한자어 "절부(切符)" 의미. 어원: 切 = 끊다, 符 = 표시/기호.

#### 예문

- **切符**をネットで買いました。 — 표를 인터넷으로 샀습니다. (구매, 캐주얼)
- **切符**をなくしました。 — 표를 잃어버렸습니다. (잃음, 캐주얼)
- **切符**を見せてください。 — 표를 보여 주세요. (제시, 격식)

#### 관련 용어

- 切符 (きっぷ) — 「표 (캐주얼)」
- 乗車券 (じょうしゃけん) — 「승차권 (격식)」
- 入場券 (にゅうじょうけん) — 「입장권」
- 片道切符 (かたみちきっぷ) — 「편도 표」
- [[transportation-vocabulary]] — 교통 어휘

#### 문화적 맥락

일본어 **切符 (きっぷ)** 발음 "킷푸" — 한국어 "킷푸" 와 발음 동일. 캐주얼: きっぷ / 격식: 乗車券 (じょうしゃけん). 한국·일본 모두 **切符 (표)** = 승차/입장권. 현대 일본: **ICカード (IC 카드, Suica/Pasmo)** 보급 — 종이 切符 감소. 한국어 **T-money** 와 동일 트렌드. 발음: きっぷ (ki-ppu) — 촉음 っ + ㅂ 발음 연습.
