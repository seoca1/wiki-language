# 日本のサイバーパンク美学 (Japanese Cyberpunk Aesthetics)

**Overview:** 日本のサイバーパンク (Nihon no saibāpanku, Japanese cyberpunk) + アニメ (anime) + スタジオジブリ (Studio Ghibli) は 世界 (sekai, world) の 映像 (eizō, visual) 文化 + 文学 (bungaku, literature) に 深い (fukai, deep) 影響 (eikyō, influence). 起源: 1982 年 士郎正宗 (Shirow Masamune, 1961-) 『攻殻機動隊 (Kōkaku Kidōtai, Ghost in the Shell, 1989-)』 + 1988 年 『AKIRA (アキラ, 1988)』 + 宮崎駿 (Miyazaki Hayao, 1941-) 1985 年 『天空の城ラピュタ (Tenkū no Shiro Rapyuta)』 + 『となりのトトロ (Tonari no Totoro)』 + 『千と千尋の神隠し (Sen to Chihiro no Kamikakushi)』 + 1995 年 『GHOST IN THE SHELL / 攻殻機動隊 (Kōkaku Kidōtai)』 押井守 (Oshii Mamoru, 1951-) + 2024 年 『君たちはどう生きるか (Kimi-tachi wa Dō Ikiru ka)』.

## Key Points

- **Ghost in the Shell 攻殻機動隊 (Kōkaku Kidōtai)**: 1989 年 士郎正宗 (Shirow Masamune) 漫画 (manga) 連載開始, 1995 年 押井守 (Oshii Mamoru) 劇場版 (gekijōban) 公開, 2004 年 神山健治 (Kamiyama Kenji) TV アニメ, 2015 年 『攻殻機動隊 新劇場版 (ARISE)』, 2017 年 ネットフリックス (Netflix) 『SAC_2045』. 「電脳化 (dennōka, cyberization)」 + 「ゴースト (gōsuto, ghost = 魂 (tamashii)) + 「電脳 (dennō, cyber brain)」 + 「義体 (gaitai, prosthetic body)」 = 「サイバーパンク + 哲学 (tetsugaku, philosophy)」. 1995 年 米国 Wired 誌 「the most sophisticated work of cinematic science fiction yet seen」.
- **AKIRA アキラ (1988)**: 大友克洋 (Ōtomo Katsuhiro, 1954-) 漫画 (manga) + 1988 年 劇場アニメ (gekijō anime). 「ネオ東京 (Neo-Tōkyō, 2019)」 + 「バイク (baiku, motorcycle) + カウ (kau, cow)」 + 「超能力 (chōnōryoku, psychic powers)」 + 「軍 (gun, military) + 反乱 (hanran, rebellion)」. 世界初の (sekai-hatsu, world's first) 「本格的 (honkakuteki, full-scale) SF アニメ映画 (anime eiga)」. 米国 興行収入 (kōgyō shūnyū, box office) $2.5M (1989) + 現在 $1.6B+ 累計 (ruikei, cumulative). 「AKIRA スライド (slide, バイク シーン)」 + 「救世主 (kyūseishu, messiah) テツオ (Tetsuo)」 + 「金田 (Kanada)」 + 「鉄雄 (Tetsuo)」 + 「ケイ (Kei)」 + 「あき ら (AKIRA)」.
- **宮崎駿 (Miyazaki Hayao, 1941-) + スタジオジブリ (Studio Ghibli)**: 1985 年 スタジオジブリ 設立 (setsuritsu, established) + 高畑勲 (Takahata Isao) + 徳間書店 (Tokuma Shoten). 主要作品 (shuyō sakuhin, main works): (1) 天空の城ラピュタ (Laputa, 1986) + (2) となりのトトロ (My Neighbor Totoro, 1988) + (3) 千と千尋の神隠し (Spirited Away, 2001, アカデミー賞 Academy Award 2003) + (4) もののけ姫 (Princess Mononoke, 1997) + (5) 崖の上のポニョ (Ponyo, 2008) + (6) 風立ちぬ (The Wind Rises, 2013) + (7) 君たちはどう生きるか (The Boy and the Heron, 2023, アカデミー賞 2024). 「宮崎 + 反戦 (hansen, anti-war) + 自然 (shizen, nature) + 少女 (shōjo, young girl) + 飛行 (hikō, flying)」 의 テーマ.
- **アニメ の 国際 (kokusai, international) 影響 (eikyō, influence)**: 
  - **米国 (USA)**: ドラゴンボール (Dragon Ball, 鳥山明 Toriyama Akira) + ポケモン (Pokémon) + ナルト (Naruto) + ワンピース (One Piece) + 進撃の巨人 (Attack on Titan) + 鬼滅の刃 (Demon Slayer) + Jujutsu Kaisen (呪術廻戦) + 「Anime (アニメ)」 米国 オックスフォード辞書 言葉 (kotoba, word) of the year 2020 候補 (kōho, candidate). 米国 アニメ 産業 (sangyō, industry) ¥1.5 兆 (chō, trillion) 規模 (kibo).
  - **フランス (France)**: アニメ 漫画 (manga) 文化 + 宮崎駿 + スタジオジブリ 影響 + 「アニメ大国 (taikoku, anime power)」 + フランス (France) 「Manga market + Anime festival + Japan Expo (Japan Expo Paris)」.
  - **韓国 (Korea)**: アニメ 共有 (sharing) + 「韓国 (Korean) アニメ + 일본 (Japan) アニメ」 + 「Webtoon (ウェブトゥーン)」 + 「OJK (original Japan-Korea)」 + 「NAVER (네이버) + LINEマンガ」.

## Cross-language Connections

- **Coreano**: 한국 「사이버펑크 (saibeopankeu, 사이버펑크)」 + 「애니메이션 (aenimeisyeon, 애니메이션)」 + 「웹툰 (webtun, 웹툰)」 + 「오타쿠 (otaku, 오타쿠)」 + 「만화 (manhwa, 만화)」 + 「한국 애니 (Korean anime)」 + 「오리지널 (original) 콘텐츠」 의 共有. 한국 「웹툰 (webtoon)」 + 일본 「漫画 (manga)」 + 「縦スクロール (vertical scroll)」 + 「カラフル (colorful)」 + 「スマホ (smartphone)」 의 共有. 일본 「漫画 (manga) + アニメ (anime)」 + 韓国 「웹툰 + 애니 + ドラマ (drama)」 + 「K-콘텐츠 (K-content)」 + 「한류 (Hallyu, 한류)」 + 「韓流 (hallyu)」 의 共有.
- **Japonés**: 韓國 + 日本 + 米国 + フランス + 中国 = 「アニメ + 漫画 + キャラクタービジネス + サイバーパンク + ファンタジー (fantasy)」 の 国際 (international) 文化. 日本 + 韓國 = 「동아시아 (東アジア, East Asia) コンテンツ 산업 (産業, industry)」 의 双璧 (쌍벽, dual center). 일본 「アニメ + 漫画 + ゲーム」 + 한국 「K-드라마 + K-팝 + 웹툰」 + 「한류 + 日流」 의 동아시아 콘텐츠 双壁.
- **Inglés**: Western 「Cyberpunk (William Gibson, 1984) + Matrix (1999) + Star Wars (1977) + Marvel (2008+) + DC (2005+)」 의 比較. 最も 近い 比較는 「Disney + Marvel + Star Wars (米国 entertainment giant)」 + 「宮崎駿 + Studio Ghibli (Japan animation master)」 + 「Pixar + Disney (USA) + Anime (Japan)」 의 国際 文化 中心.

## Ejemplos

「 『Ghost in the Shell / 攻殻機動隊 (Kōkaku Kidōtai)』 (1995) は、 サイバーパンク (saibāpanku) と哲学 (tetsugaku) を融合した作品として、 『ブレードランナー (Blade Runner)』 や 『マトリックス (The Matrix)』 などハリウッド映画に大きな影響 (eikyō) を与えました。」

「宮崎駿 (Miyazaki Hayao) 監督の 『千と千尋の神隠し (Sen to Chihiro no Kamikakushi)』 は 2003 年にアカデミー賞 (Academy Award) を受賞し、 日本のアニメ (anime) が世界 (sekai) で高く評価 (hyōka) される象徴となりました。」

「大友克洋 (Ōtomo Katsuhiro) の 『AKIRA (アキラ)』 (1988) は、 世界初の (sekai hatsu no) 本格 SF アニメ映画 (honkaku SF anime eiga) として、 全世界 (zensekai) でカルト的 (karuto-teki, cult) な人気 (ninki) を誇ります。」
