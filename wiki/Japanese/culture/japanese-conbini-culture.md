# コンビニ文化 (Convenience Store Culture)

**Overview:** コンビニ (こんびに, konbini, convenience store) は 24 時間 営業 (24 jikan eigyō, 24-hour operation) + 全国 約 56,000 店舗 (2024, 日本 フランチャイズ トップ 3 = セブン-イレブン (Seven-Eleven) + ローソン (Lawson) + ファミリーマート (FamilyMart)) + 弁当 (bentō, boxed meal) 文化. 起源: 1974 年 5 月 15 日 豊洲 (Toyosu, 東京 江東区) に 1 号店 (ichigō-ten, first store) 開店 (kaiten, open). 米国 (USA) 「セブン-イレブン (Seven-Eleven)」 1974 年 イトーヨーカドー (Itō-Yokadō, 伊藤洋華堂) と 業務提携 (gyōmu teikei) 開始. 現在 日本独自文化 (Nihon dokujimo bunka) 形成.

## Key Points

- **3 大コンビニ (sandai konbini, big 3)**: 
  - **セブン-イレブン (Sebun Irebun, Seven-Eleven)**: 1 位 (1-i, 1st), 約 21,000 店舗 (2024), 米国 Southland Corporation 起源. 「セブンカフェ (Sebun Kafe)」 自家焙煎コーヒー (jika baishen kōhī) + ¥100-¥200.
  - **ローソン (Rōson, Lawson)**: 2 位 (2-i, 2nd), 約 14,000 店舗 (2024), 1939 年 米国 オハイオ州 設立. 「MACHI café (マチ カフェ)」 コーヒー + 「からあげクン (Karaage Kun)」 が ロウ ソン 名物.
  - **ファミリーマート (Famirī Māto, FamilyMart)**: 3 位 (3-i, 3rd), 約 16,000 店舗 (2024), 1981 年 創業 (sōgyō), 伊藤忠商事 (Itō Chū Shōji) 子会社. 「Famima Collection」 プライベートブランド.
- **弁当 (Bentō, boxed meal) 文化**: 幕の内弁当 (makunouchi bentō, 日本 標準) + おにぎり (onigiri, 三角 rice ball) + 寿司 (sushi, 巻き) + サンドイッチ (sandoicchi, sandwich) + 弁当 (bentō) ¥300-¥700. 「店内 (tennai, in-store) 電子レンジ (denshi renji, microwave)」 + 「おでん (oden, hot pot, 冬)」 + 「肉まん (nikuman, meat bun)」 + 「クリームパン (kurīmu pan, cream bread)」 の イートイン (ītoin, eat-in) 文化.
- **サービス (Sābisu, services)**: 公共料金 (kōkyō ryōkin, public utilities) 収納 (shūnō, payment) + コピー (kopī, copy) + FAX (ファックス) + ATM (エーティーエム) + チケット (chiketto, ticket) 発券 (hakken, issue) + 写真 (shashin, photo) プリント (purinto) + 郵便 (yūbin, mail) + 宅配便 (takuhaibin, delivery) 引受 (hikiuke, acceptance). 「何でも屋 (nandemoya, everything store)」 の 異名 (imei, nickname).
- **店員 (Tenin, staff) の マナー (manners)**: 「いらっしゃいませ (irasshaimase, welcome)」 + 「袋 (fukuro, bag)」 + 「温めますか (atatameru ka, warm it up?)」 + 「必要 (hitsuyō) な 物 は 他に (hoka ni) ございますか (gozaimasu ka)」。 外国人 (gaikoku-jin, foreigners) = 「ポイント カード (pointo kādo, point card) お持ち (o-mochi) ですか (desu ka)」 + 「お支払い (oshiharai, payment)」 + 「袋 (fukuro)」 + 「温め (atatame)」 + 「ご来店 (go-raiten, visiting)」 + 「ありがとうございました (arigatō gozaimashita, thank you)」.
- **支払 (shiharai, payment)**: 現金 (genkin, cash) + 電子マネー (denshi manē, e-money, Suica/Pasmo/WAON/nanaco) + クレジット カード (kurejitto kādo, credit card) + QR コード決済 (kessai, payment, PayPay/LINE Pay/Rakuten Pay) + バーコード (bākōdo) 決済. 「クイック ペイ (ku~ikku pei)」 + 「iD (アイディー)」 + 「QUICPay」.

## Cross-language Connections

- **Coreano**: 한국 「편의점 (pyeonuijeom, 편의점)」 + 「GS25 + CU + 세븐일레븐 + 이마트24 (Emart 24)」 의 다단계 (다단계) 文化. 韓國 편의점 도 「24 時間 営業 (24시간 영업)」 + 「배달 (baedal, delivery)」 + 「도시락 (dosirak, 도시락)」 + 「삼각김밥 (samgakgimbap, 삼각김밥)」 의 共有. 차이 (차이) = 한국 「배달의민족 (Baedal Minjok)」 + 「쿠팡 (Coupang, 쿠팡)」 + 「배민 (Baemin)」 가 「배달 (delivery)」 + 「편의점」 의 中心, 日本 「直接 (chokusetsu, direct)」 店内 (in-store) 飲食 (inshoku, eating) + 「おでん (oden)」 + 「弁当」 가 中心.
- **Japonés**: 韓國 + 中国 + 日本 + 台湾 + タイ (Thailand) = 「コンビニ (convenience store)」 の 東アジア + 東南アジア 共有. 하지만 日本 만 「全国 5 万 6 千店舗 (56,000 stores)」 + 「高密度 (kōmitsudo, high-density) + 1 店舗 単位 (kōmitsudo)」 + 「弁当 (bentō) + おにぎり (onigiri) + スイーツ (suītsu)」 + 「ATM (atm)」 + 「公共料金 (kōkyō ryōkin)」 의 多機能 (takinoō). 韓國 「편의점 + 배달」 + 「GS25 + CU + 세븐일레븐 + 이마트24」 + 「삼각김밥 (samgakgimbap)」 의 共有.
- **Inglés**: US 「7-Eleven + Wawa + Circle K + QuikTrip」 + UK 「Tesco Express + Sainsbury's Local」 + Australia 「7-Eleven + Caltex Woolworths」 의 比較. 最も 近い 比較는 US 「7-Eleven (Japanese standard adapted)」 + UK 「Tesco Express (food focus)」 — 日本 「弁当 + ATM + 公共料金 (公共料金)」 + 「温かい (warm)」 + 「すぐ食べる (eat immediately)」 의 文化.

## Ejemplos

「セブン-イレブン (Seven-Eleven) + ローソン (Lawson) + ファミリーマート (FamilyMart) は、 日本 三大コンビニ (sandai konbini) で、 全国に合計 (gōkei) 約 56,000 店舗 (2024) あります。」

「日本のコンビニ (konbini) では、 弁当 (bentō) + おにぎり (onigiri) + パン (pan) + スイーツ (suītsu) など バラエティ豊かな (barietī yutaka) 食品 (shokuhin) を買うことができます。」

「コンビニ (konbini) では公共料金 (kōkyō ryōkin) の 支払い (shiharai)、 ATM (エーティーエム)、 コピー (kopī)、 チケット (chiketto) の 発券 (hakken) など 多様な (tayō na) サービス (sābisu) を受けられます。」
