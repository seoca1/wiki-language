# 日本の伝統芸能 (Japanese Traditional Arts)

**Overview:** 日本の伝統芸能は 「四大古典芸能 (yodai koten geinō)」 歌舞伎 (kabuki) + 能 (nō) + 文楽 (bunraku) + 狂言 (kyōgen) + 「生活芸 (seikatsu gei)」 茶道 (sadō) / 華道 (kadō) / 書道 (shodō) + 「園芸芸 (engei gei)」 盆栽 (bonsai) / 庭 (niwa) が中核。 2001 年に 「人形浄瑠璃文楽 (ningyō jōruri bunraku)」 + 「能楽 (nōgaku)」 + 「歌舞伎 (kabuki)」 が UNESCO 無形文化遺産 に登録。

## Key Points

- **歌舞伎 (Kabuki, 1603 起源)**: 出雲阿国 (Izumo no Okuni, 慶長年間 1603) が 京都 で 「歌舞伎踊 (kabuki odori)」 を興したことに起源。 女性は 「遊女 (yūjo)」 と混同されるため 1629 年に 女歌舞伎 (onna kabuki) 禁止、 すべて男性演者 (女方, onnagata) が女性役を演じる形に。 江戸の市村座 + 森田座 + 中村座 が三大劇場。 演目: 「勧進帳 (Kanjinchō)」 + 「助六 (Sukeroku)」 + 「鳴神 (Narukami)」。
- **能 (Nō, 14 世紀起源)**: 観阿弥 (Kan'ami) + 世阿弥 (Zeami, 1363-1443) 親子により大成。 演者 + 笛 + 小鼓 + 大鼓 + 太鼓の 5 人編成、 能面 (nōmen) で感情を抽象化。 5 番立て (go-ban-date): 脇能 (waki-nō) + 修罗物 (shuramono, warrior) + 鬘物 (kazuramono, wig play) + 切 (kiri, conclusion) + 狂言 (kyōgen, comic interlude)。
- **文楽 (Bunraku, 1684 起源)**: 浄瑠璃 (jōruri) 語りに合わせて人形 (ningyō) を 3 人で遣う文楽座の人形浄瑠璃 (竹本義太夫 + 1703 竹田出雲)。 1972 年に文楽協会 (Bunraku Kyōkai) が三業 (人形 + 太夫 + 三味線) の統合で発足。 演目: 「曽根崎心中 (Sonezaki Shinjū, 1703)」 + 「義経千本桜 (Yoshitsune Senbon Zakura)」。
- **茶道 (Sadō/Chadō, 16 世紀起源)**: 千利休 (Sen no Rikyū, 1522-1591) が 「侘茶 (wabi-cha)」 を大成。 四規 (shiki, four principles): 和 (wa, harmony) + 敬 (kei, respect) + 清 (sei, purity) + 寂 (jaku, tranquility)。 表千家 (Urasenke) + 裏千家 (Omotesenke) + 武者小路千家 (Mushanokōji-senke) が三千家 (sanzenke) の三大宗家。 茶室 (chashitsu) は 4 畳半 (4.5 tatami mats) が標準。
- **華道 (Kadō / Ikebana, 6 世紀起源)**: 池坊 (Ikenobō, 京都) が最古の流派 (1462 池坊専慶)。 三大流派: 池坊 + 小原流 (Ohara-ryū, 1897) + 草月流 (Sōgetsu-ryū, 1927 勅使河原蒼風)。 生け花 (ikebana) は 天 + 地 + 人 (ten + chi + jin) の三才 (sansai) 構成が基本。
- **書道 (Shodō) + 盆栽 (Bonsai)**: 書道は 平安時代に 「三筆 (sanpitsu)」 空海 / 嵯峨天皇 / 橘逸勢 が定着、 江戸時代に 「三跡 (sanseki)」 小野道風 + 藤原佐理 + 藤原行成 が続き、 現代は 漢字 + 仮名 + 漢字仮名交じり の三分野。 盆栽は奈良時代に起源 + 平安時代に鑑賞化、 江戸時代に大衆化、 松柏類 (松 / 杉) + 雑木類 (楓 / 梅) + 花物類 (桜 / 梅) + 実物類 (柿 / 葡萄) の四分類。

## Cross-language Connections

- **Coreano**: 한국에도 国乐 (국악, gugak) 의 盤索里 (판소리, pansori) + 農樂 (농악, nongak) + 假面舞 (가면무, gamyeonmu) 가 유사한 전통 공연 예술. 日本の 能 / 歌舞伎 / 文楽 와 한국의 板索里 / 탈춤 / 강강술래 는 모두 동아시아 「舞台芸術 (무용극)」 의 공통 계보. 茶道 의 영향은 한국의 다도 (茶道, dado) 에 미쳤고, 華道 의 영향은 한국 花卉 (화훼) 문화 에 깊이 뿌리박음.
- **Japonés**: 한자문화권의 「芸 (예, gei / yì)」 개념 공유. 중국은 京劇 (경극, Beijing opera) + 昆曲 (kunqǔ) + 越劇 (越劇) + 書画 (서화) + 茶藝 (다예) 가 일본의 伝統芸能 와 구조적으로 대응. 일본의 盆栽 은 중국 盆景 (pénjǐng) 에서 전래.
- **Inglés**: US / UK 는 opera + theater + ballet + fine art 의 구분이 명확. 일본처럼 「茶道 + 華道 + 書道 + 盆栽」 의 단일 「生活芸 (life arts)」 개념은 없음. 영국의 Royal Opera House / West End theatre 가 일본의 歌舞伎座 + 国立劇場 (theatre) 와 대응.

## Ejemplos

「歌舞伎 (kabuki) は江戸時代に発展した日本の伝統的な演劇で、 女形 (onnagata) という男性が女性を演じる役が重要な特徴です。」

「茶道 (sadō) は 千利休 (Sen no Rikyū) によって大成された茶の湯の文化で、 『和敬清寂 (wa-kei-sei-jaku, harmony respect purity tranquility)』 の 四規 (shiki, four principles) が基本理念です。」

「盆栽 (bonsai) は鉢植えで育てられた小さな樹木で、 松 (matsu, pine) や 楓 (momiji, maple) などの樹種があり、 何十年もかけて育てられます。」
