# 温泉の礼儀 (Onsen Etiquette)

**Overview:** 温泉 (おんせん, onsen, hot spring) は 火山国 (kazan-koku, volcanic country) 日本 (Nihon) が 世界 (sekai) でも珍しい (mezurashii, rare) 「自然湧出 (shizen yūshutsu, natural emergence)」 温泉文化. 起源: 縄文 (Jōmon, 14500-300 BCE) 時代 から 湧出 利用. 奈良 (Nara, 710-794) 仏教 + 平安 (Heian, 794-1185) 湯治 (tōji, therapeutic bathing) + 室町 (Muromachi, 1336-1573) 温泉寺 (onsen-dera) + 江戸 (Edo, 1603-1868) 湯治場 + 明治 (Meiji, 1868-) 観光化. 2019 年 温泉 (onsen) 数 = 約 27,000 ヶ所 (kkasho, locations). 入浴料金 (nyūyoku ryōkin) = ¥400-¥1,500 平均 (heikin).

## Key Points

- **入浴 マナー (nyūyoku manā, bathing manners)**: (1) 脱衣所 (datsuijo, changing room) で 服 + アクセサリー (akusesarī, accessories) + 時計 (tokei, watch) を 脱ぐ (nugu) + (2) 浴室 (yokushitsu) で かけ湯 (kakeyu, pouring hot water on oneself) + かけ湯 もう一度 (mō ichido, once more) + (3) 浴槽 (yokusō, bathtub) に 入る (hairu). 「かけ湯」 = 体を 清め + 浴室 の 湯 を 汚さない (kegasanai) + シャワー (shawā) で 局所 (kyokusho, localized) 洗浄 (senjō, washing) しない = 全員 (zen'in, everyone) が 「かけ湯」 の 代わり (kawari).
- **タオルの 使用 (shiyou, usage)**: タオル (taoru, towel) = 頭 (atama, head) に のせる (noseru) + 浴槽 + 体 に 入れない (irenaide). 「タオル 浸け (tsuke)」 + 「浴槽 + タオル」 = 「不潔 (fuketsu, unclean) + 他者 (tasha) に 失礼 (shitsurei)」. 脱衣所 + 浴室 移動 中 = 「タオル 巻 (maki)」 = 「裸 (hadaka, naked)」 標準.
- **入れ墨 (irezumi, tattoo) タブー (tabū)**: 入れ墨 = ヤクザ (yakuza, Japanese mafia) + 暴力団 (bōryokudan, gangster) + 犯罪 (hanzai, crime) の 象徴 (shōchō). 江戸時代 (1603-1868) 「入れ墨 刑罰 (keibatsu, punishment)」 + 「犯罪者 (hanzai-sha) 烙印 (rakuin, brand)」 + 「ヤクザ 構成員 (kōsei-in)」. 現代 (gendai, present) は 「タトゥー スタジオ (tattoo studio)」 + 「外国人観光客 (gaikoku kankōkyaku, foreign tourist)」 + 「入れ墨 禁止 (kinshi, prohibited) = 入浴 拒否 (kyohi, rejection)」. 一部 (ichibu) 旅館 (ryokan) + 温泉 (onsen) は 「入れ墨 カバー (cover, 絆創膏 + タオル)」 で 入浴 容認 (ninyō yōnin).
- **髪の長い人 (nagai hito, long-haired person)**: 髪が 浴槽 に 浸かると (tsukaru) 「不潔 (fuketsu)」 + 「髪を まとめる (matomeru, tie up)」 + 「ヘアカラー (hair color)」 + 「タオルを 頭 (atama) に のせる」 が 標準.
- **入浴 順序 (nyūyoku junjo, bathing order)**: (1) かけ湯 (kakeyu) で 体を 清める (kiyomeru) + (2) 浴槽 に 浸かる (tsukaru, soak). 「かけ湯なし」 = 「日本人 として マナー違反 (manā ihan, etiquette violation)」 + 「温泉 ルール (rūru, rules) を 無視 (mushi, ignore)」 と みなされる.
- **温泉 種類 (onsen shurui, types)**: 単純温泉 (tanjun onsen, simple) + 塩化物泉 (enkabutsu-sen, chloride, 塩) + 炭酸水素塩泉 (tansan suisoen-sen, bicarbonate, 美肌) + 硫黄泉 (iōsen, sulfur, 乳頭温泉 + 草津温泉) + 鉄泉 (tessen, iron) + 放射能泉 (hōshanōsen, radioactive, ラドン温泉) + 酸性泉 (sansei-sen, acidic).

## Cross-language Connections

- **Coreano**: 한국 「온천 (oncheon, 온천)」 + 「찜질방 (jjimjilbang, 찜질방)」 + 「목욕탕 (mogyoktang, 목욕탕)」 + 「사우나 (sauna, sauna)」 + 「스파 (spa, 스파)」 의 다단계 (다단계) 温泉文化. 韓國 온천 + 일본 온센 의 共有 文化 (예: 부산 + 제주 + 덕구). 한국 온천 + 일본 온센 의 차이 (차이) = 「온천 + 옷 (clothing)」 + 「혼욕 (hon'yoku, mixed gender)」 + 「외국인 (foreigner)」 + 「가족탕 (familial bathing)」 + 「특성 (characteristic)」 의 비교.
- **Japonés**: 韓國 + 中国 + 日本 + ニュージーランド (NZ) + アイスランド (Iceland) = 「温泉 (hot spring)」 의 自然 共有. 하지만 日本 만 「裸 (hadaka, naked) + 共通浴槽 (kyōtsū yokusō, common bath) + かけ湯 (kakeyu) + タオル 浸け 禁止 + 入れ墨 (irezumi) タブー」 의 独自 (独自) 体系. 韓國 「온천 (oncheon)」 + 「찜질방 (jjimjilbang)」 + 日本 「温泉 (onsen)」 + 「銭湯 (sentō)」 + 「スーパー銭湯 (sūpā sentō)」 의 多段階.
- **Inglés**: Western 「Bathhouse (NY Russian bath)」 + 「Spa (modern)」 + 「Sauna (Finnish)」 + 「Turkish bath (Hammam)」 의 比較. 가장 近い 比較는 Finnish 「Sauna (nude, common, religious)」 + Russian 「Banya (birch branch, nude)」 — 日本 「裸 (naked)」 + 「共通浴槽 (common bath)」 + 「入れ墨 (tattoo) タブー」 의 文化.

## Ejemplos

「日本の温泉 (onsen) では、 浴室 (yokushitsu) に入ったら、 まず体を洗わずに かけ湯 (kakeyu) をします。 これは体を 清める (kiyomeru) ためと、 浴槽 (yokusō) の湯を汚さないためです。」

「入れ墨 (irezumi, tattoo) がある方は、 一部の温泉 (onsen) で入浴を断られる (kotowarareru) ことがあります。 近年 (kinnen) はタトゥーカバー (tatū kabā) で対応する (taiō suru) 施設も増えています。」

「温泉 (onsen) では、 タオル (taoru) を浴槽 (yokusō) に浸けたり、 頭や体の上に置いたまま浴槽に入ることは しない (shinai) のがルールです。」
