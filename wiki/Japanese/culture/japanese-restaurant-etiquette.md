# 日本のレストランの礼儀 (Japanese Restaurant Etiquette)

**Overview:** 日本のレストラン (resutoran, restaurant) + 居酒屋 (izakaya, Japanese pub) 文化は チップ (chippu, tip) なし (nashi, none) + 飲み放題 (nomihōdai, all-you-can-drink) + 二次会三次会 (nijikai sankai) の 独特 (dokutoku, unique) 文化. 起源: 明治 (Meiji, 1868-1912) 洋食 (yōshoku) + 大正 (Taishō, 1912-1926) 珈琲店 (kōhiten, coffee shop) + 昭和 (Shōwa, 1926-1989) 居酒屋 + 平成 (Heisei, 1989-2019) チェーン (chain). チップ なし = 明治以来 「日本文化独特 (unique to Japan)」 + 「サービス (service) が 商品 (shōhin) の 一部 (ichibu)」 + 「対等 (taitō, equal) 関係 (kankei)」.

## Key Points

- **チップ (Tip, tip) なし (nashi) 文化**: 日本では チップ を 渡すと 「特別な サービス (tokubetsu na sābisu)」 + 「賄賂 (wairo, bribe)」 + 「特別扱い (tokubetsu atsukai)」 と 誤解 (gokai) される 可能性. 稀 (mare, rare) に 高級 (kōkyū, high-class) 旅館 (ryokan, Japanese inn) + 個人タクシー (kojin takushī) で チップ 文化 残存. 「お心遣い (okokubarakoi) は ありがたい (arigatai) です」 + 「特別 サービス します」 が 文化 標準 (bunka hyōjun).
- **注文 (chūmon, ordering)**: タッチパネル (tacchipaneru, touch panel, 居酒屋 + ファミレス 主流) + 口頭注文 (kōtō chūmon, verbal ordering, 寿司 + 高級) + モバイルオーダー (mobairu ōdā, mobile ordering, 2020+). 「注文 (chūmon)」 は 「すみません (sumimasen)」 + 「お願いします (onegaishimasu)」 + 「〜を ください (kudasai)」. 店員 (tenin, staff) を 呼ぶ (yobu) 時 = 目を合わせる (me wo awaseru) + 「お呼び (oyobi)」.
- **割り勘 (Warikan, split-the-bill)**: グループ (group) で 「割り勘 (warikan)」 = 「平等 (byōdō, equal) に 分割 (bunkatsu, split)」. 「おごり (ogori, treat someone)」 = 上司 (jōshi, boss) + 先輩 (senpai, senior) + 誕生日 (tanjōbi, birthday) + 告白 (kokuhaku, confession) 成功 時. 「立て替え (tatekae, pay upfront)」 + 「後で 精算 (seisan, settle) 」 文化 + 「PayPay + LINE Pay」 で 個人送金.
- **食事 (shokuji) マナー (manners)**: 音 (oto) = 「音を立て ずに 食べる (oto wo tatenzu ni taberu)」 が 標準 (hyōjun, standard). 例外 (reigai, exception) = 麺類 (menrui, noodles, ズーズー音 + 啜る音) + スープ (sūpu, soup). 「箸 (hashi) を 立たせない (tatasenai, don't stick upright, funeral taboo) 」 + 「箸渡し (hashiwatashi, chopstick passing)」 = 「葬式」 + 「箸 を 揃える (hashi wo soroeru)」 + 「口 + 箸 を 同時に動かさない (同時に動かさない)」.
- **居酒屋 (Izakaya, Japanese pub) 文化**: 「乾杯 (kanpai, cheers)」 + 「お通し (otoshi, automatic appetizer, ¥300-¥500)」 + 「飲み放題 (nomihōdai, all-you-can-drink, 90 分 1,500-3,000 円)」 + 「二次会 (nijikai, after-party) + 三次会 (sankai)」. ネクタイ (nekutai) 外す + 上司 + 部下 の 区別 + 接待 (settai) + コンパ (konpa, company party) の 階層 (kaisō).

## Cross-language Connections

- **Coreano**: 한국 「식당 (sikdang, 식당)」 + 「술집 (suljip, 술집)」 + 「회식 (hoesik, 회식, company dinner)」 의 文化 共有. 韓國 도 「チップなし (팁 없음)」 + 「분담 (bundan, 분담)」 + 「한턱 (hanteok, 한턱)」 의 体系. 韓國 「회식 (hoesik)」 + 日本 「飲み会 (nomikai)」 의 대응. 韓國 「수저 (sujeo, スジョー)」 + 「젓가락 (jeotgarak, 젓가락)」 = 日本 「箸 (hashi)」 + 「匙 (saji)」 의 비교. 韓國 「안주 (anju, 안주)」 = 日本 「お通し (otoshi)」 + 「つまみ (tsumami)」 + 「肴 (sakana)」 의 대응.
- **Japonés**: 韓國 + 中国 + 日本 + 台湾 = 「チップなし」 + 「箸 (chopstick)」 + 「乾杯 (건배, 건배)」 + 「飲み会 (회식)」 의 文化 共有. 日本 만 「お通し (otoshi)」 + 「飲み放題 (nomihōdai)」 + 「二次会三次会」 + 「回転寿司 (kaiten sushi)」 + 「タッチパネル」 + 「食券 (shokken, 食券)」 의 独自 形式. 韓國 「식당 (sikdang)」 + 「술집 (suljip)」 의 비교 + 日本 「居酒屋 (izakaya)」 + 「食堂 (shokudō)」 + 「レストラン」 + 「料亭 (ryōtei)」 의 다단계 (다단계).
- **Inglés**: Western 「Tip (15-20%, 필수)」 + 「Business dinner (split OR treat)」 + 「BYOB + individual checks」 + 「Valet + Sommelier」 의 文化. 가장 近い 比較는 Eastern European 「Slivovitz tradition (no tip, snack included)」 + British 「Pub (no service)」 — 共有 文化 (sharing culture). 일본 「チップなし + お通し」 의 独特 文化.

## Ejemplos

「日本 (Nihon) のレストランでは、 チップ (chippu) は基本的に不要 (fuyō) です。 サービス料は料金に含まれて (fukumarete) います。」

「居酒屋 (izakaya) で グループ (group) で食事をする場合、 割り勘 (warikan, split-the-bill) が一般的です。 最近はPayPayなどのモバイル決済 (kesai) で個人送金 (kojinkinsō) もよく使われています。」

「お通し (otoshi) は 居酒屋 (izakaya) に入ると自動的に (jidōteki ni) 出される小さな一品料理 (ippin ryōri) で、 席料 (seki-ryō) の代わり (kawari) とされています。」
