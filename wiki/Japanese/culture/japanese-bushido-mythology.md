# 武士道の神話と現実 (Bushido Mythology and Reality)

**Overview:** 武士道 (ぶしどう, bushidō, 「the way of the warrior」) は 明治 (Meiji, 1868-1912) + 大正 (Taishō, 1912-1926) 時代 に 「再発見 (saihakken, rediscovered)」 + 「再構築 (saikōchiku, reconstructed)」 された 概念 (gainen, concept). 歴史 (rekishi, history) 上 の 武家 (buke, warrior class) 規範 (kihan, norms) = 鎌倉 (Kamakura, 1185-1333) + 室町 (Muromachi, 1336-1573) + 江戸 (Edo, 1603-1868) = 「忠義 (chūgi, loyalty) + 勇 (yū, courage) + 義 (gi, righteousness) + 名誉 (meiyo, honor)」. 1900 年 新渡戸 稲造 (Nitobe Inazō, 1862-1933) が 英語 (Bushido: The Soul of Japan) で 海外 (kaigai, overseas) 紹介.

## Key Points

- **武士道 の 七德 (shichi-toku, seven virtues)**: (1) 義 (gi, 正義 justice) + (2) 勇 (yū, 勇気 courage) + (3) 仁 (jin, 慈悲 benevolence) + (4) 礼 (rei, 礼儀 propriety) + (5) 名誉 (meiyo, honor) + (6) 忠義 (chūgi, loyalty) + (7) 誠 (makoto, 誠実 sincerity). 1940 年代 戦時 (senji, wartime) 体制 (taisei, regime) 下 (ka) で 「尊皇攘夷 (sonnō jōi, revere the emperor + expel the barbarians)」 + 「滅私奉公 (messhi hōkō, self-effacement for public duty)」 + 「死 (shi, death)」 + 「殉国 (junkoku, dedication to country)」 として 政治利用 (seiji riyo).
- **武士 vs 武士道 の 違い (samurai vs bushidō)**: 史実 (shijitsu, historical fact) = 武士 (samurai) は 中世 (chūsei, medieval) + 近世 (kinsei, early modern) の 武装階層 (busō kaikō). 「侍 (samurai)」 = 「仕える (tsukaeru, serve)」 起源 = 「主君 (shukun, lord) に仕える 人 (hito)」. 武士道 = 明治 以降 (1900s+) 「武士 文化」 の 美化 (bika) + 「国民道徳 (kokumin dōtoku, national morality)」 として 体系化 (taikeika). 江戸 武士 の 実生活 (jisseikatsu, actual life) = 「俸禄 (hōroku, salary, 年貢 rice)」 + 「武術 (bujutsu, martial arts)」 + 「教育 (kyōiku, education)」 + 「子孫繁栄 (shison han'ei, lineage)」 の 「実利 (jitsuri, practical)」 中心, 「切腹 (seppuku, ritual suicide)」 + 「忠義 (loyalty)」 は 例外 (reigai, exception).
- **武士道 の 国際的 (kokusai-teki, international) 影響 (eikyō, influence)**: 山本 五十六 (Yamamoto Isoroku, 1884-1943) + 三船 久蔵 (Mifune Kyūzō) + 黒澤 明 (Kurosawa Akira, 1910-1998) 「七人の侍 (Shichinin no Samurai, 1954)」 + 「用心棒 (Yojimbo, 1961)」 + 「影武者 (Kagemusha, 1980)」 + 「乱 (Ran, 1985)」 + 「椿三十郎 (Tsubaki Sanjūrō)」 + 「隠し砦の三悪人 (Kakushi-toride no San Akunin)」 = スターウォーズ (Star Wars) + ラストサムライ (Last Samurai) + キルビル (Kill Bill) 의 国際 影響.
- **武士道 の 現代 (gendai, modern) 展開 (tenkai, development)**: 「剣道 (kendō)」 + 「弓道 (kyūdō)」 + 「柔道 (jūdō)」 + 「空手 (karate)」 + 「合気道 (aikidō)」 + 「弓道 + 侍 精神 (samurai seishin, samurai spirit)」 の 武道 (budō, martial arts). 「侍 (samurai)」 + 「サムライ ブルー (Samurai Blue, 日本代表 サッカー soccer)」 + 「侍 ジャパン (Samurai Japan, 日本代表 野球 baseball)」 + 「サムライ (Samurai)」 ブランド + 「侍 精神 (samurai seishin)」 + 「武士道 (bushidō)」 書籍 (sho, books) + 「企業 (kigyō, corporate) 文化 + 武士道」 + 「山口 揚平 (Yamaguchikai)」 + 「経営 + 武士道」 의 산업 (sangyō, industry) 文化.
- **武士道 の 矛盾 (mujun, contradiction)**: 武士 + 「詰腹 (tsubura, forced seppuku)」 + 「殉死 (junshi, following lord in death)」 + 「喧嘩 (kenka, fighting)」 + 「辻斬り (tsujigiri, random street killing)」 + 「敵討ち (katakiuchi, vendetta)」 + 「風俗 (fūzoku, vice)」 = 「美化 (bika, beautification)」 + 矛盾. 「武士道 の 逆 (gyaku, inverse)」 = 「弱肉強食 (jakuniku kyōshoku, survival of the fittest)」 + 「敵 (teki, enemy) + 裏切り (uragiri, betrayal)」 + 「暴 (bō, violence)」 + 「闇 (yami, darkness)」 + 「裏 (ura, dark side)」.

- **Coreano**: 한국 「무사도 (musado, 무사도)」 + 「의리 (uiri, 의리)」 + 「충신 (chungsin, 충신, 忠臣)」 + 「충효 (chunghyo, 충효, 忠孝)」 의 共有. 韓國 「의리 (uiri, 의리)」 + 「형제 (hyeongje, 형제)」 + 「전사 (jeonsa, 전사, 戰士)」 + 「무인 (muin, 무인)」 + 「의병 (uibyeong, 의병)」 + 「독립 운동가 (doknip undongga)」 의 共有. 韓國 「무사 (musa, 무사)」 + 「무인 (muin, 무인)」 + 「의병 (uibyeong)」 + 「해방 (haebang, 해방)」 + 「광복 (gwangbok, 광복)」 + 「독립 (doknip)」 의 体系. 하지만 日本 「武士道」 + 「サムライ (samurai)」 의 국제 (국제) 문화 (culture) 영향 (eikyō) 이 강 (강) 함.
- **Japonés**: 韓國 + 中国 + 日本 + モンゴル = 「武士 + 騎士 (기사, gisa)」 + 「武将 (장수, jangsu)」 + 「武功 (무공, mugong)」 의 동아시아 + 중앙아시아 共有. 韓國 「무사 + 의리」 + 日本 「武士 + 武士道」 + 欧州 「기사 (knight) + 기사도 (knighthood)」 + 「사무라이 (samurai)」 의 비교. 日本 「サムライ」 가 국제 映像 (映像) 문화 의 中心 (center), 한국 「의리」 + 「충신」 가 무사 (musa) 의 高 (고) 価値 가치 (kachi).

## Ejemplos

「武士道 (bushidō) は 明治時代 (Meiji jidai) に新渡戸稲造 (Nitobe Inazō) が著書 (chosho, book) 『Bushido: The Soul of Japan』 で海外に紹介し、 世界に広く知られるようになりました。」
