# 日本の結婚式の伝統 (Japanese Wedding Traditions)

**Overview:** 日本の結婚式 (kekkon-shiki, wedding ceremony) は 明治維新 (Meiji Ishin, 1868) 以降に 「神前式 (shinzen-shiki, Shintō wedding)」 + 「仏前式 (butsuzen-shiki, Buddhist wedding)」 + 「キリスト教式 (Kirisutokyō-shiki, Christian wedding)」 + 「人前式 (ninzen-shiki, human-witness wedding)」 の 4 形式が並存、 現在 約 60% が 「神前式 + 披露宴 (hirōen, reception)」 の セット。 起源: 神前式 1900 年 (明治 33) 日比谷大神宮 (Hibiya Daijingū, 旧 大手町) で最初の 公式 神社挙式。

## Key Points

- **神前式 (Shinzen-shiki)**: 神社 (jinja) 神前 (shinzen) で執り行う (toritsukuri) 形式、 三三九度 (san-san-kudo, three-three-nine cups of sake) が中心。 順序: (1) 参進の儀 (sanshin no gi, 神職 (shinshoku) 先導で本殿 (honden) へ) + (2) 修祓 (shūhatsu, 祓 = けがれ 清める) + (3) 祝詞奏上 (norito sōjō, 神職 祝詞 (のりと) 朗読) + (4) 三三九度 (san-san-kudo, 大 (ō) + 小 (ko) + 小 (ko) の盃 3 回, 計 9 口) + (5) 指輪交換 (yubiwa kōkan, ring exchange) + (6) 誓詞奉呈 (seishi hōtei, 結婚 誓い 言葉) + (7) 玉串奉奠 (tama-kushi hōten, 榊 (sakaki) の枝を神に奉納)。
- **披露宴 (Hirōen, reception)**: ホテル (hotel, 例: 帝国ホテル / ホテルニューオータニ) + 専門式場 (senmon shikijō, 例: 八芳園 / アニヴェルセル) で披露宴 (披露 + 宴). 構成: 新郎新婦 入場 (nyūjō) + 主賓 (shuhin, 媒酌人 baishaku-nin) 挨拶 + ケーキ入刀 (kēki-nyūtō, cake-cutting ceremony, 米国発) + 乾杯 (kanpai) + 食事 + 祝辞 (shukuji) + 媒酌人 紹介 + 花嫁の手紙 (hanayome no tegami) + 新郎 中締め (nakazume) + 二次会 (nijikai, after-party). 費用 ¥3,000,000-¥5,000,000 (2024, 平均 ¥3,580,000).
- **衣装 (ishō)**: 白無垢 (shiromuku, 全身白色の着物 + 白い綿帽子 watabōshi) → 色打掛 (irowake, 色付き着物) → 振り袖 (furisode) → 洋装 (Western dress, カラードレス + ウェディングドレス) の 「お色直し (ironaoshi, costume change)」 を 2-3 回. 新郎 (hanro): 紋付袴 (montsuki hakama, 黒着物 + 袴) → タキシード (tuxedo).
- **媒酌人 (Baishaku-nin)**: 仲人 (nakōdo) とも呼ぶ夫婦の立会人 (tachi'ai-nin). 通常 1 組 (夫婦) で媒酌、 主賓挨拶 + 新郎新婦 紹介 + 仲人 紹介 役割. 仲人 への 謝礼 (sharei) は 「お礼の品 (礼状 + 菓子折り)」 = ¥100,000 相当が相場 (sōba).
- **ハネムーン (hanemūn, honeymoon)**: 沖縄 (Okinawa) + ハワイ (Hawaii) + ヨーロッパ (Yōroppa) + グアム (Guam). 「新婚旅行 (shinkon ryokō)」 として 式後 1 週間-10 日間. 友人 (yūjin) から 「ご祝儀 (goshūgi, gift money)」 ¥30,000 が平均 (友人) / 上司 (jōshi) ¥30,000-¥50,000 / 上司 (jōshi) 連名 ¥50,000.

## Cross-language Connections

- **Coreano**: 한국 결혼 (결혼) 의 「혼례 (honrye, 韓式 婚礼)」 + 「폐백 (pyebaek, 新婦 茶礼)」 + 「웨딩 (wedding, 西式)」 의 합작. 한국 「폐백」 = 日本 「媒酌人 挨拶」 의 대응. 韓國 現代 의 西式 婚礼 = 日本 披露宴 (Western style) 의 比較. 韓國 「혼수 (hon-su, 嫁入り 道具)」 = 日本 「家具 + 家電 (kagu + kaden)」 의 대응.
- **Japonés**: 韓國 + 中国 + 日本 + 西洋 = 「神前式 (Shintō) + 仏前式 (Buddhist) + 西式 (Christian)」 의 三重 文化 共有. 하지만 日本 만 「三三九度 (san-san-kudo)」 의 独自 (独自) 儀式 를 持つ. 韓國 「의전 (儀典)」 + 中国 「拜堂 (bàitáng)」 + 西洋 「vows」 의 합작.
- **Inglés**: Christian wedding + US 「ring bearer + flower girl + bridesmaid」 의 西式 伝統 + Jewish 「chuppah」 + Hindu 「seven steps (saptapadi)」 — 全て 「指輪 + 酒杯 + 神への誓い」 共有. 가장 近い 比較는 Jewish 「chuppah (婚礼 テント)」 + 酒杯 (wedding cup) 의 일본 「三三九度」.

## Ejemplos

「神前式 (shinzen-shiki) の中心となる 三三九度 (san-san-kudo) では、 大 (ō) + 小 (ko) + 小 (ko) の 3 組の盃を交互に 9 回 口をつけ、 夫婦の固い契り (katameshi) を結びます。」

「披露宴 (hirōen) では、 新郎新婦が白無垢 (shiromuku) + 色打掛 (irowake) + カラードレスと衣装を 2-3 回 変えながら (お色直し) ゲストをもてなします。」

「結婚祝い (kekkon iwai) の 祝儀袋 (shūgi bukuro) は、 ご祝儀 (goshūgi) として友人からは 3 万円が相場で、 新札 (shinsatsu) を 袱紗 (fukusa, silk wrapping) に入れて持参するのが一般的です。」
