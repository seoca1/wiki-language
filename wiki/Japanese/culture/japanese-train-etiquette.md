# 電車のマナー (Japanese Train Etiquette)

**Overview:** 日本の電車 (densha, train) + 地下鉄 (chikatetsu, subway) は 世界 (sekai, world) 最高水準 (saikō suijun, world-class) の 公共輸送 (kōkyū yusō, public transport) システム. 「優先席 (yūsen-seki, priority seats)」 + 「クワイエットカー (kuwa~etto kā, quiet car)」 + 「マナーモード (manā mōdo, silent mode)」 + 「通話禁止 (tsūwa kinshi, no calls)」 の マナー 文化. 起源: 明治 (Meiji, 1868-) 鉄道 (tetsudō, railway) 導入 + 昭和 (Shōwa, 1926-1989) 「通勤地獄 (tsūkin jigoku, commuting hell)」 + 平成 (Heisei, 1989-2019) スマホ (sumaho, smartphone) + マナー 啓蒙 (keimō, enlightenment). JR 旅客 (ryokaku) = 1 日 約 16,000,000 人 (2023), 満員電車 (man'in densha) = 東京 地下鉄 200%.

## Key Points

- **優先席 (Yūsen-seki, priority seats)**: 各車両 (kasharyō, each car) 入口 (iriguchi, entrance) 付近 (fukin, vicinity) に 4-6 席 (せき). 対象 (taishō, target): 高齢者 (kōreisha, elderly) + 妊婦 (ninpu, pregnant) + 乳幼児 (nyūyōji, infants) + 怪我人 (kegashita, injured) + 障害者 (shōgaisha, disabled). 「優先席 標識 (hyōshiki, signs)」 = 「シルバーシート (Shirubā shīto)」. 1973 年 JR + 1975 年 地下鉄 で 設定, 「立つ + 席 を 譲る (yuzuru)」 が 文化 標準. 「お年寄り (otoshiyori)」 = 「声かけ (koegake)」 + 「席 譲る (seki yuzuru)」 + 「気配り (kikubari)」 の 視点 (shiten, perspective).
- **クワイエットカー (Quiet car, silent car)**: 東海道新幹線 (Tōkaidō Shinkansen) + 一部 私鉄 (shitetsu, private railway) に 設定. 「通話禁止 (tsūwa kinshi, calls prohibited)」 + 「大声禁止 (ōgoe kinshi, loud voice prohibited)」 + 「音楽 (ongaku, music) イヤホン (iyahon) 限定 (gentei)」. 違反者 (ihansha, violator) = 周囲 (shūi, surroundings) の 視線 (shisen) + 「迷惑 (meiwaku, nuisance)」 + 「公共交通機関 (kōkyō kōtsū kikan)」 の 看板 (kanban, sign) で 表示. 東海道新幹線 は 7 号車 (nanagōsha, car 7) が クワイエットカー.
- **マナーモード (Silent mode) + 通話禁止 (No calls)**: 2000 年代後半 (2000s later) 携帯電話 (keitai denwa, mobile phone) + 2007 年 iPhone 日本上陸 + 「マナーモード (manā mōdo, silent mode)」 + 「通話禁止 (tsūwa kinshi)」 の 啓蒙 (keimō). JR 公式 (kōshiki, official) 「電車 での 通話 は 控えて (hikaete, refrain)」 + 「マナーモード 設定 (settei)」. 違反者 = 「なぜ 電車 で 通話 する の (naze densha de tsūwa suru no)」 の 強い非難 (kyōna hinan, strong criticism).
- **優先席 (yūsen-seki) + お年寄り (otoshiyori) + リング (ring) + ヘルプマーク (Herupu Māku)**: ヘルプマーク (help mark, 義足 + 妊娠初期 + 内部障害 + PTSD) 利用者 (riyōsha) の 補助 (hojo). 「マタニティーマーク (matanitī māku, maternity mark, 妊娠)」 の 標識 (hyōshiki) で 妊婦 に席を譲る + 「ベビーカー マーク (Bebīkā māku, baby stroller mark) + 「お年寄り 席 (Otoshiyori seki)」.
- **優先席 + スマホ (Sumaho) + 立って スマホ (Tatte sumaho, standing smartphone)**: 2020 年代 (2020s) 課題 (kadai, issue) = 「スマホ 歩き (sumaho aruki, smartphone walking)」 + 「ながらスマホ (nagara sumaho, simultaneous smartphone)」 = 「危険 (kiken, danger)」 + 「事故 (jiko, accident)」. 「歩きスマホ 禁止 (aruki sumaho kinshi)」 + 「マナーモード」 + 「触らない (sawarenai)」.

## Cross-language Connections

- **Coreano**: 한국 「지하철 (jihacheol, subway)」 + 「전철 (jeoncheol, 전철)」 + 「버스 (beoseu, 버스)」 의 公共交通 (公共交通) 文化. 韓國 도 「노약자석 (norakjaseok, 老弱者席)」 + 「임산부석 (imsanbuseok, 妊産婦席)」 + 「양보 (yangbo, 양보)」 + 「핸드폰 (haendeupon, 핸드폰) 禁止」 의 共有 文化. 차이 (차이) = 한국 「통화 (tonghwa, 통화)」 + 「음악 (eumak, 음악)」 + 「대화 (daehwa, 대화)」 가 비교적 (비교적) 許容 (허용), 日本 「クワイエットカー + 通話禁止」 의 強 (강) 規範 (規範).
- **Japonés**: 韓國 + 中国 + 日本 + シンガポール (Singapore) + 香港 (HK) = 「公共輸送 (public transport) マナー (manners)」 의 東アジア + 東南アジア 共有. 하지만 日本 만 「マナーモード (silent mode)」 + 「優先席 (yūsen-seki)」 + 「クワイエットカー (quiet car)」 + 「ヘルプマーク (help mark)」 + 「呼び出し (yobidashi, 駅員 (ekin) 呼び出し)」 의 独自 (独自) 細密 (細密) 規範. 韓國 「노약자석 + 임산부석」 + 日本 「優先席 + ヘルプマーク」 + 「マタニティーマーク」 의 다단계 (다단계) 体系.
- **Inglés**: Western 「Quiet car (Amtrak, USA)」 + 「Priority seating」 + 「Mobile phone use」 의 文化. 가장 近い 比較는 Singapore 「Priority seats (yellow)」 + 「Mobile phone mode」 + UK 「Quiet coach」 — 日本 「マナーモード」 + 「優先席」 + 「クワイエットカー」 의 細密 (세밀) 規範.

## Ejemplos

「電車 (densha) の中では、 携帯電話 (keitai denwa) を マナーモード (manā mōdo, silent mode) に設定し、 通話 (tsūwa, calls) は控えます。」

「優先席 (yūsen-seki) 付近では、 高齢者 (kōreisha) や妊婦 (ninpu) の乗客 (jōkyaku) がいれば、 進んで席を譲る (susunde seki wo yuzuru) のが日本のエチケット (echiketto) です。」

「東海道新幹線 (Tōkaidō Shinkansen) の 7 号車 (nanagōsha) は 通話禁止 (tsūwa kinshi) + 大声禁止 (ōgoe kinshi) のクワイエットカー (quiet car) となっています。」
