# お辞儀 (Oijigi, Bowing)

**Overview:** お辞儀 (おじぎ, ojigi) は日本の 鞠躬 (jigi, きょくげい kyokugei) 礼 (rei) の 主要 (shuyō) 形式。 起源: 奈良 (Nara, 710-794) + 平安 (Heian, 794-1185) 時代 + 仏教伝来 (bukkyō denrai, Buddhism arrival) + 中国礼法 (chūgoku reihō, Chinese etiquette) 融合. 鞠躬の角度 (kakudo, angle) で 敬語 強弱 (kyōgo kyōjaku, politeness intensity) を 表現. 西洋 (seiyō, West) と 異なり 「握手 (akushu, handshake)」 + 「抱擁 (hōyō, hug)」 + 「キス (kisu, kiss)」 の 身体接触 (shintai sesshoku) なし.

## Key Points

- **3 段階 (3 dankai) の 鞠躬**: 
  - **会釈 (Eshaku, 15°)**: 「軽い (karui, light)」 日常挨拶 (nichijo aisatsu) + 知人 (chijin) + すれ違い (surechigai). 上半身 (jōhanshin) を 5°-15° 傾ける (katamukeru). 「こんにちは」 + 「おはようございます」 と同時.
  - **敬礼 (Keirei, 30°)**: 「普通 (futsū)」 の ビジネス (bijinesu) + 訪問 (hōmon, visit) + 顧客 (kokyaku, customer) + 目上 (meue, superior). 上半身 を 30° 傾け 2-3 秒 (byō, seconds) 静止 (seishi). 「いらっしゃいませ」 + 「失礼します」 + 名刺交換 (meishi kōkan).
  - **最敬礼 (Saikeirei, 45°)**: 「深い (fukai, deep)」 謝罪 (shazai, apology) + 感謝 (kansha, gratitude) + 敬意 (keii, respect). 45° + 頭 (atama) を 下に + 2-4 秒 + 腰 (koshi) + 背中 (senaka) を 真直ぐ (massugu, straight) 維持 (iji). 「申し訳ございません」 + 「ありがとうございます」 + 「恐れ入ります」.
- **立礼 (Ritsurei, standing bow) vs 座礼 (Zarei, seated bow)**: 立礼 (立 = 立つ tatsu, standing) = 日常 + 訪問. 座礼 (座る suwaru, seated) = 茶道 (sadō, tea ceremony) + 華道 (kadō, ikebana) + 書道 (shodō, calligraphy) + 正座 (seiza, formal kneeling) + 畳 (tatami) 上 儀式. 座礼 は 「目礼 (mokurei, 30°, 浅い 坐礼) + 真 (shin, 45°-50°) + 最敬礼 (saikeirei, 60°+)」 の 3 段階 構成.
- **男女差 (danjo sa, gender difference)**: 歴史的 (rekishiteki, historical) に 男子 (danshi) = 手 (te) を 腿 (momo) に + 女子 (joshi) = 手を 身前 (ma'e) で 重ねる (kasaneru). 現在 (げんざい, present) は 共 (tomo) に 手 を 腿 または 身前 の 自然 (shizen, natural) な 位置 (ichi, position).
- **タイミング (taimingu, timing)**: 「こんにちは」 = 会釈 + 「さようなら」 = 敬礼 + 「ありがとうございます」 = 敬礼 + 「お詫び (owabi)」 = 最敬礼 + 「新年 (shinnen) あけましておめでとうございます」 = 最敬礼. 「空気 (kūki) を 読む (yomu)」 (read the air) + 「タイミング」 の 文化 と 融合.
- **鞠躬 + 敬語 (keigo) の セット**: 鞠躬 だけ 強い + 敬語 弱い = 「不自然 (fushizen, unnatural)」 + 逆 (gyaku, opposite) も 同様 (dōyō). 鞠躬 + 敬語 + 態度 (taido, attitude) の 三位一体 (sanmiittai, three-in-one) が 真の礼儀 (rei gi).

## Cross-language Connections

- **Coreano**: 한국 「경례 (gyeongrye, 경례)」 + 「인사 (insa, 인사)」 + 「절 (jeol, 절, 跪拝)」 의 体系. 韓國 은 「90°의 큰절 (큰 절, big bow) + 30°의 가벼운 인사」 의 二段階 中心, 日本만 「3 段階 (会釈 + 敬礼 + 最敬礼)」 + 「座礼 (zarei)」 + 「最敬礼 (saikeirei)」 의 細密 (細密) 体系. 한국 「인사 (insa)」 + 「목례 (mokrye, 軽い 鞠躬)」 + 「절 (jeol)」 + 「배례 (baerye, 高い 礼)」 의 多段階 体系, 日本 + 韓國 합쳐 「東アジア 礼法 文化」 의 代表.
- **Japonés**: 韓國 + 中国 + 日本 + モンゴル = 「鞠躬 + 敬語」 의 東アジア 礼法 (reihō, 礼法) 共有. 하지만 日本 만 「角度 (kakudo) 数字 + 静止時間 + 手位置 + 足の位置」 의 厳密 規範 (genmitsu kihan). 韓國 「인사 (insa)」 가 一段階 多用途, 日本 「角度 + 敬語 + シーン」 の 細密 (細密) 分類.
- **Inglés**: Western 「Nod (nod)」 + 「Tip the hat (tipping the hat, 19 century)」 + 「Slight bow (queen's wave)」 의 比較. 最も 近い 比較는 Korean 「경례 (military salute)」 + British 「Bow (royal)」 — 角度 + 静止 + 場所 의 文化.

## Ejemplos

「お辞儀 (ojigi) の 会釈 (eshaku) は 15°の軽い (karui) 鞠躬で、 『こんにちは』 のような日常の挨拶 (aisatsu) に使われます。」

「ビジネスシーンで顧客 (kokyaku) や目上 (meue) の人に対応するときは、 敬礼 (keirei, 30°) が適切 (tekisetsu) です。」

「深い感謝 (kansha) や謝罪 (shazai) を表現するときは、 最敬礼 (saikeirei, 45°) を 2-4 秒間 (byōkan) 保ち、 『申し訳ございません (mōshiwake gozaimasen)』 と深く 頭 (atama) を下げます。」
