# 名刺交換の礼儀 (Meishi Exchange Etiquette)

**Overview:** 名刺交換 (めいしかん, meishi kōkan, business card exchange) は日本のビジネス儀礼 (gyōrei, business etiquette) の象徴。 起源: 明治 (Meiji) 時代 (1868-) に洋式 ビジネス 導入時 に 採用 (saiyō) された 西洋 式 カード + 日本 式 敬語 (keigo) + 鞠躬 (ojigi) + 順 (jun, order) の 融合. 現代は 100% 必須 (必須, hissu) ビジネス 儀礼、 日本企業 (Nihon kigyō) + 海外企業 (kaigai kigyō) 共に 第一印象 (daiichi inshō, first impression) + 関係構築 (kankei kōchiku, relationship building) の出発点.

## Key Points

- **名刺 (Meishi, business card) の形式 (keishiki)**: 白無地 (shiro-muji, plain white) + 和文 + 英文 の 両面 (ryōmen, both sides) 表記 + 縦書き (tategaki, vertical) + 楷書 (kaisho) の 標準 (hyōjun). 会社名 (kaisha-mei) + 部署名 (busho-mei) + 役職 (yakushoku, position) + 氏名 (shimei, name) + 連絡先 (renraku-saki, contact) + 会社 URL. サイズは 91mm × 55mm (欧米 85mm × 55mm より 若干 大).
- **交換の順序 (kōkan no junjo)**: (1) 「お名刺 (o-meishi) を お取らせください (o-torase kudasai)」 + (2) 訪問者 (hōmonsha) → 先方 (senpō) 側 + 下位 (kai, lower rank) → 上位 (jō, higher rank) の順. (3) 両手 (ryōte, both hands) または 右手 (migite, right) + 左手を 下に添える (soeru). (4) 文字 (moji) 向き = 相手 (aite) が読める方向. (5) 一瞬 (isshun, moment) 視線 (shisen, eye contact) で 確認 (kakunin).
- **鞠躬 (Ojigi, bowing) の 角度 (kakudo)**: 「名刺を差し出す際 (sashidasu sai) の 一礼 (ichirei)」 + 「受け取る際の 一礼」 の 二回 (nikai, twice) が 標準. 角度 (kakudo): 「会釈 (eshaku, 15°)」 / 「敬礼 (keirei, 30°)」 / 「最敬礼 (saikeirei, 45°)」 の 3 段階 (dankai). 交換 時 = 「敬礼 (keirei, 30°)」 が 標準.
- **受け取り後 (uketori-go) の マナー (manners)**: テーブル (tēburu) 上 に 置いて 閲覧 (etsuran, look) + 「○○ (name) さん ですね」 + 「お名前は どちらで (dochira de) 読みますか (yomimasu ka)」 + 名刺入れ (meishi-ire, card case) に 丁寧に (teinei ni, carefully) 収納 (shūnō). 名刺の 上 に 他の 物を 載せない (nosenaide, don't place on top) = 不敬 (fukei).
- **受け取る + 渡す (uketoru + watasu) の 禁忌 (kinki, taboo)**: ポケット (poketto) に 直接 (chokusetsu) 入れない (irenaide) + 飲食 (inshoku) 中 (chū) に 交換 しない (shinai) + 名刺を 投げる (nageru, throw) ように渡す + 文字 を 下に向けて 渡す + 受け取ったら 即座 (sokuzani) しまう (shimau) = 「相手の存在 を 軽んじる (karinjiru)」 失礼 ( shitsurei).

## Cross-language Connections

- **Coreano**: 한국 「명함 교환 (myeongham gyohwan, 명함 교환)」 + 「인사 (insa, 인사)」 의 문화 共有. 韓國 은 「양손 (양손, 両手)」 + 「약간의 허리 굽힘 (腰部 傾斜)」 + 「비율 (比率)」 의 比較. 韓國 「독배 (독배, 名刺 독립 케이스)」 + 「명함 지갑 (명함 지갑, 명함 지갑)」 = 日本 「名刺入れ (meishi-ire)」. 韓國 은 「직함 (직함, title)」 + 「직급 (직급, position)」 의 重視 (重視) 가 일본보다 더 강함.
- **Japonés**: 韓國 + 中国 + 日本 = 名刺 (명함/名片/名刺) 交換 의 文化 共有. 하지만 日本 만 「縦書き (tategaki)」 + 「両手 渡し (ryōte watashi)」 + 「受け取る時の 凝視 (gyōshi)」 + 「テーブル 置く」 의 独特 (독특) 礼儀. 韓國 + 中国 + 日本 中 「카드 케이스 (card case)」 文化 가장 古い.
- **Inglés**: Western business card exchange = single-hand + brief glance + pocket storage (no ritual). 最も 近い 比較는 South Asian 「Namaste greeting (合掌, gasshō)」 + 「双手 (sōshu, 両手)」 渡し — 동아시아 文化圏의 二重礼儀. 일본 式 「teinei (丁寧)」 의 심화 (深化) = unique.

## Ejemplos

「初対面 (shodaimen) の名刺交換 (meishi kōkan) では、 訪問者 (hōmonsha) が 下位 (kai) の側から先に、 両手 (ryōte) で相手の読める方向に向けて差し出します。」

「受け取った名刺 (meishi) は、 テーブル (tēburu) の上に置いて名前を確認し、 丁寧に名刺入れ (meishi-ire) に収納します。 決してポケットにそのまま入れた り、 名刺の上に他の物を載せたりしてはいけません。」

「交換時には『お名刺 (o-meishi) を お取らせください (o-torase kudasai)』と言い、 敬礼 (keirei, 30°) の鞠躬 (ojigi) をします。」
