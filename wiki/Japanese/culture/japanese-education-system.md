# 日本の教育制度 (Japanese Education System)

**Overview:** 日本の教育制度は 6-3-3-4 制 (roku-san-san-yon sei) — 小学校 6 年 / 中学校 3 年 / 高校 3 年 / 大学 4 年。 文部科学省 (MEXT) 管轄。 受験 (juken) 文化と 偏差値 (hensachi) システムが国内外で有名で、 塾 (juku, cram school) は小中学生の半数以上が通う。

## Key Points

- **6-3-3-4 制 (Roku-san-san-yon sei)**: 義務教育 (gimu kyōiku, compulsory education) は小学校 (shōgakkō, 6-12 歳) + 中学校 (chūgakkō, 12-15 歳) の 9 年間。 高校 (kōkō, 15-18 歳) 進学率は約 98%、 大学 (daigaku) 進学率は約 53% (2023 文科省)。
- **幼稚園・保育園 (Yōchien / Hoikuen)**: 3-6 歳、 両方とも 2019 年から無償化。 幼稚園は文部科学省、 保育園は厚生労働省管轄の二元制度。 認定こども園 (ninteï kodomo-en) が統合窓口。
- **受験 (Juken) 文化**: 高校受験 (kōkō nyūshi) + 大学受験 (daigaku nyūshi) の二重構造。 共通テスト (kyōtsū test) は 2021 年にセンター試験から移行、 1 月 13-14 日に実施。 AO・推薦入試 (suisen nyūshi) も増加傾向。
- **塾 (Juku, cram school)**: 河合塾 (Kawaijuku) / 駿台 (Sundai) / 東進 (Tōshin) などの大手。 小学生平均月謝 ¥20,000-40,000、 中学生 ¥40,000-80,000。 個別指導 (kobetsu shidō) とオンライン塾が伸長中。
- **偏差値 (Hensachi, deviation score)**: 平均 50、 標準偏差 10 の偏差値システム。 65 以上で上位層、 70+ で最難関校 (灘 / 開成 / 筑波大附属)。 65 ≠ 65% との誤読に注意、 統計的指標。
- **部活 (Bukatsu, club activities)**: 体育系 (野球 / サッカー / 柔道 / 剣道) と文化系 (茶道 / 書道 / 吹奏楽)。 3 年引退制度 (sannensei intō) で 3 年生は夏までに部活を終え受験に集中。 教員の 部活指導 (bukatsu shidō) は長時間労働の元凶。
- **学歴 (Gakureki) 信仰**: 就職・結婚における学歴ロンダリング (ronde) が社会問題化。 新卒一括採用 (shinsotsu ikkatsu saiyō) と結びつき、 大学名 > 学力の傾向が批判される。

## Cross-language Connections

- **Coreano**: 한국도 비슷한 6-3-3-4 제 + 입시 (入試) 전쟁. 한국은 사교육 (私教育, private education) 비용 GDP 대비 세계 최고 수준. 日本の 塾 와 한국의 학원 (학원, hag-won) / 과외 (gwaje) 가 직접 대응. 한국은 修能 (수능, CSAT) 이 단일 시험인 반면, 일본은 共通テスト + 個別試験 の 二重構造.
- **Japonés**: 漢字文化圏共通 — 中国の 高考 (gāokǎo) は日本の 共通テスト に相当、 受験 (入試) 地獄 (juken jigoku) という 概念 自体 も 동아시아 공통어. 偏差値 のような 정량 지표 는 한국 대학수학능력시험 등급 (grade) 과 유사.
- **Inglés**: US / UK は GPA + standardized tests (SAT/ACT/A-Level) だが、 日本の 偏差値 のように 全国統一 標準化 점수 가 없음. Ivy League 入学은 holistic (総合的) — 일본보다 덜 numerics-driven.

## Ejemplos

「東京大学 (Tōkyō Daigaku) を目指す高校生は、 駿台 (Sundai) や 東進 (Tōshin) などの 塾 (juku) で毎日 3-5 時間、 共通テスト (kyōtsū test) と二次試験対策の勉強をします。」

「日本の 6 歳 (rokusai) の子供は 4 月 (shigatsu) に 小学校 (shōgakkō) に入学します。 入学式 (nyūgakushiki) で 校長先生 (kōchō sensei) の話を聞くのが伝統です。」

「中学生 (chūgakusei) の半数以上が 塾 (juku) に通いますが、 文部科学省 (MEXT) は 2020 年代から 公立学校 (kōritsu gakkō) の部活動時間を削減する方針を出しました。」
