# 日本の葬式の伝統 (Japanese Funeral Traditions)

**Overview:** 日本の葬式 (そうしき, funeral) は 仏教式 (bukkyō-shiki) が約 90% を占める (神道式 + キリスト教式 合計 約 10%). 「死 = 仏 (hotoke, Buddha)」 信仰、 「あの世 (ano yo, the other world)」 への旅立ち の 仏教式 儀礼 (ぎれい). 平均費用 ¥1,500,000-¥2,500,000 (2024). 鎌倉時代 (1185-1333) 「中陰 (chūin)」 の 49 日間 が死後の審判 (judgement) 期間という仏教思想 + 江戸時代 (1603-1868) 「檀家制度 (danka seido, parish system)」 がほぼ全ての 形式を確定。

## Key Points

- **死亡 (shibō) 直後**: 逝去 (seikyo, passing) → 末期の水 (matsugo no mizu, 死者の口に最後の一口の水) → 湯灌 (yukan, 清拭 seishoku + 着せ替え) → 納棺 (nōkan, 棺 に安置) → 枕飾り (makura kazari, 白木位牌 (shiraki ihai) + 香炉 + 遺影 設置). 24 時間 (一昼夜) 安置 + 通夜 (tsuya) 準備。
- **通夜 (Tsuya, wake)**: 死後 当日 または 翌日 夜、 親族 + 親しい 友人 + 隣人 が 線香 (senkō, incense) + 焼香 (shōkō, incense-burning) + 読経 (dokkyō, sutra chanting) を 行う. 「通夜ぶるまい (tsuya burumai, wake feast)」 で 遺族 (izoku, family) と食事. 通夜 + 葬儀式 + 初七日 = 2 日間 (前日 + 翌日) が 標準 (hyōjun).
- **葬儀 (Sōgi, funeral service) + 告別式 (Kokubetsu-shiki, farewell ceremony)**: 寺院 (jiin) 住職 (jūshoku, priest) が 読経 + 引導 (indō, transition guidance) → 焼香 (shōkō, 2-3 分, 各人) → 出棺 (shukkan, coffin leaving) → 火葬場 (kasōjō, crematorium) 移動. 火葬 (kasō, cremation) は 法律 (eisei-hō, 衛生法) で 原則 (gensen, principle). 骨上げ (kotsuage, bone-picking) で 遺骨 (ikotsu) を 箸 (hashi) で 骨壷 (kotsutsubo) に.
- **四十九日 (Shijūkunichi, 49th-day memorial)**: 死後 7 週目 (7 weeks) = 49 日目 が 「忌明け (ki-ake, mourning end) + 満中陰 (man-chūin)」。 死者の魂 (tamashii) が 「極楽浄土 (gokuraku jōdo, Pure Land)」 に到達する日. 49 日目までに 七七日 (なななのか, 七回忌) の 7 回 法要 (hōyō) 実施: 初七日 (shonanoka, 7 日目) + 二七日 (futsunoka, 14 日目) + 三七日 (minanoka, 21) + 四七日 (yonnanoka, 28) + 五七日 (itsunoka, 35) + 六七日 (muinoka, 42) + 七七日 (nanoka, 49). 現代は 「7 + 49」 の 2 回 法要 が主流.
- **香典 (Kōden, condolence money)**: 通夜 + 葬儀 で 持参 (jisan, bring) する 金銭 (kinsen). 相場 (sōba): 友人 ¥5,000-¥10,000 + 上司 ¥10,000-¥30,000 + 親戚 ¥30,000-¥50,000 + 会社 ¥10,000 (複数 社員 で分担). 袱紗 (fukusa) + 奉書紙 (hōshoshi, formal paper) の 白い封筒 (kōdenbukuro) + 薄墨 (usuzumi, light sumi ink) 筆書き.

## Cross-language Connections

- **Coreano**: 한국 葬式 (장례식, jangnyesik) 의 「초 (弔問, condolence) + 영정 (영정, funeral portrait) + 상 (상, coffin altar) + 입관 (입관, coffin) + 발인 (출관, funeral procession) + 화장 (화장, cremation) + 수의 (수의, shroud)」 의 한자 漢字 共有. 韓國 「49 일 (사십구일)」 + 7 일 忌 + 100 일 + 1 년 + 3 년 의 차례 (茶禮) 와 日本 49 日法要 의 대응. 한국 「제사 (祭祀)」 의 周期 (주기) 比較.
- **Japonés**: 韓國 + 中国 + 日本 = 仏教 (불교) + 儒教 (유교) + 道教 (도교) 의 死生観 共有. 하지만 日本 만 「火葬 (kasō, ほぼ 100%)」 + 「遺骨 (ikotsu, bone のみ 保管)」 + 「骨壷 (kotsutsubo)」 의 形式. 한국 + 中国 + 日本 中 唯一 ほぼ 全員 火葬 (火葬률 거의 100%) — 国土 (land) 制約 + 仏教的 思想.
- **Inglés**: Western Christian funeral (burial + church + cemetery) + Jewish Tahara (shrouding) + Christian Ash Wednesday (ashes symbolism) — 仏教 式 の 火葬 + 49 日 + 法要 의 体系 (体系) は unique. 가장 近い 比較는 Catholic 「Masses for the dead」 + Jewish 「Yahrzeit (週年 記念)」 — 共に 死後 記念日 (memorial cycle) の 伝統.

## Ejemplos

「通夜 (tsuya) は 故人 (kojin) の魂 (tamashii) を偲び (shinobi)、 遺族 (izoku) と最後のお別れの時を過ごすための儀式 (gishiki) です。」

「四十九日 (shijūkunichi, 49 日間) は 故人が極楽浄土 (gokuraku jōdo) に到達するとされる日で、 現代では 初七日 (shonanoka) と四十九日 (shijūkunichi) の 2 回 法要 (hōyō) を営むことが多いです。」

「香典 (kōden) は 白い封筒に薄墨 (usuzumi) で金額を書き、 袱紗 (fukusa) に入れて持参するのが正式 (seishiki) な形式です。」
