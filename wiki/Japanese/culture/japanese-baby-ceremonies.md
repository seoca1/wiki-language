# 日本の赤ちゃんの儀式 (Japanese Baby Ceremonies)

**Overview:** 日本の赤ちゃんの儀式 (あかちゃんのぎしき, baby ceremonies) は 誕生 (tanjō, birth) から 成人 (seijin, adulthood) までの間に行われる神道 + 仏教の伝統儀礼。 主な 4 儀式: (1) お七夜 (oshichiya, 7 日目 命名式) + (2) お宮参り (omiyamairi, 30 日目 神社参拝) + (3) お食い初め (okuizome, 100 日目 食事儀礼) + (4) 初節句 (hatsu sekku, 節句 祝い, 「端午 (Tango, 5/5) 男の子」 + 「雛祭り (Hina-matsuri, 3/3) 女の子」)。 起源: 平安 (794-1185) + 室町 (1336-1573) + 江戸 (1603-1868) 各時代.

## Key Points

- **お七夜 (Oshichiya, 7th night ceremony)**: 出産後 (shussango) 7 日目 (or 7 晩目 = 7 日目) に 「命名式 (meimei-shiki, naming ceremony)」 行う。 父親 (chichioya) + 母親 (hahaoya) が 命名書 (meimeisho, 命名書) に 子供の正式名 (seishiki-mei, legal name) を 楷書 (kaisho) で 書く。 元は 中国 「洗三 (Xi San)」 + 仏教 「七日 (nananoka, 7th day) 命名」 + 日本 民俗 融合. 生後 7 日 = 「産神 (ubugami, birth deity)」 が退去 (taikyo) する日、 新たに 氏神 (ujigami) の 保護 下に.
- **お宮参り (Omiyamairi, shrine visit)**: 男児 (danji) 30 日目 + 女児 (joji) 33 日目に 神社 (jinja) 参拝 (haipai) する 儀式。 「産土神 (うぶすながみ, ubusunagami, local birth deity)」 に 出産 (shussan) + 母子 健康 (boshiken) 報告. 服装: 白い 産着 (ubugi, baby kimono) + 母 方 実家 (haha-kata jikka, maternal home) の 母親 (hahaoya) が 白羽二重 巻 (shiro habutae maki) + 父親 (chichioya) は スーツ. 費用 ¥10,000-¥30,000 (祈祷 + 初穂料 hatsuho-ryō + 記念品).
- **お食い初め (Okuizome, 100th-day weaning ceremony)**: 生後 100 日目 に 「一生 (isshō) 食べることに困らないように」 の 願いを込める。 歯固め石 (hashigame-ishi, stone used to rub baby's gums, 二組の石 + 小石を豆腐代わりに使用) + 祝い膳 (iwai-zen, ceremonial meal) + 鯛 (tai) + 尾頭付き (otō-zuki, head-and-tail fish) + 赤飯 (osekihan, red rice) + 煮物 (nimono) + 汁物 (shirumono) + 香の物 (kōnomono, pickles). 「一汁三菜 (ichijū sansai)」 の原型. 「養い親 (yashi-oya, ceremonial parent)」 = 父親の父 (chichioya no chichi, paternal grandfather) が 抱っこ (dakko) + 「お食い初め膳 食べる 振りをした (furishita)」.
- **初節句 (Hatsu sekku, first seasonal festival)**: 男の子 = 5/5 端午 (Tango) で 鯉のぼり (koinobori) + 鎧 (yoroi) + 兜 (kabuto) + 武者人形 (musha-ningyō) + 柏餅 (kashiwa mochi) を飾る. 女の子 = 3/3 雛祭り (Hina-matsuri) で 雛人形 (hina-ningyō, 7 段飾り 7-dan kazari) + 菱餅 (hishimochi) + 雛あられ (hina-arare) + 白酒 (shirozake) を 飾る. 1 番目 (ichibanme) の 節句 (sekku) を 「初節句 (hatsu sekku)」 = 「お正月 (Oshōgatsu)」 + 「端午」 + 「雛祭り」 の 3 つ が 中心.

## Cross-language Connections

- **Coreano**: 한국 「백일 (Baekil, 100 일)」 = 日本 「お食い初め (okuizome)」 의 대응. 韓國 「돌 (Dol, 1 歳)」 + 「차례 (charye, 祭祀)」 + 「풍물 (pungmul, 풍물)」 의 문화 共有. 한국 「택일 (taekil, 택한 吉日)」 + 「명식 (myeongsik, 命名式)」 = 日本 「命名式 (meimei-shiki)」 + 「お七夜 (oshichiya)」 의 대응. 韓國 「금줄 (geumjul, 金줄)」 + 「백일잔치 (baekil janchi, 100 日 宴)」 의 형식.
- **Japonés**: 韓國 + 中国 + 日本 = 「命名式 (Meimei-shiki) + 神社参拝 (Shintō) + 100 日 食事」 의 共通 (공통) 体系. 하지만 日本 만 「お宮参り (Omiyamairi, 30 日 / 33 日)」 + 「お食い初め (Okuizome, 100 日)」 + 「初節句 (Hatsu sekku, 5/5 + 3/3)」 의 独自 形式. 韓國 「백일 (Baekil)」 + 中国 「抓周 (Zhuā Zhōu)」 와 形式 比較.
- **Inglés**: Christian baptism (洗礼, 生後 数か月) + Jewish Brit Milah (割礼, 8 日目) + Catholic Christening (命名 + 受洗) + Hindu Namakarana (命名, 11 日目) — 全て 「出生 + 神 + 命名 + 共同体」 의 의식. 最も 近い 比較는 Jewish Brit Milah (8 日目) + Hindu Namakarana (11 日目).

## Ejemplos

「お七夜 (oshichiya) は 出産 (shussan) から 7 日目に行われる命名式 (meimei-shiki) で、 父親 (chichioya) が命名書 (meimeisho) に子供の正式名 (seishiki-mei) を書き記します。」

「お宮参り (Omiyamairi) は、 男児は生後 30 日目、 女児は 33 日目に 神社 (jinja) を訪れ、 産土神 (ubusunagami) に子供の誕生を報告する行事です。」

「お食い初め (Okuizome) は 生後 100 日目に行われ、 歯固め石 (hashigame-ishi) で赤ちゃんの歯茎をそっとなぞって、 一生 (isshō) 食べ物に困らないように願います。」
