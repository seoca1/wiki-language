# 彼岸 (Higan)

**Overview:** 彼岸 (ひがん, equinox week) は 春分の日 (shunbun no hi, 3/20-21) + 秋分の日 (shūbun no hi, 9/22-23) を含む前後 3 日間 + 春分/秋分当日 = 計 7 日間の仏教行事。 「彼岸 (higan)」 は サンスクリット 「pāramitā (到彼岸, とうひがん)」 + 「paramam (最上)」 = 「到彼岸 (tōhigan, the other shore = nirvana)」 の略。 「此岸 (shigan, this shore = 迷いの世界)」 から 「彼岸 (higan, that shore = 悟り)」 に先祖の霊が渡ると信じ、 祖先供養 (sosen kuyō) する。 奈良時代 (710-794) に宮中行事化、 江戸時代 (1603-1868) に民間に定着。

## Key Points

- **春の彼岸 (haru no higan, 3/18-24)**: 春分の日 (Shunbun no Hi) を含む 7 日間。 暑 (atsu) さ寒 (samu) さも彼岸まで (hot and cold last until higan) と表現。 ぼた餅 (botamochi, 春) を供える、 牡丹 (botan, 春の花) から命名。
- **秋の彼岸 (aki no higan, 9/20-26)**: 秋分の日 (Shūbun no Hi) を含む 7 日間。 暑さ寒さも彼岸まで。 おはぎ (ohagi, 秋) を供える、 萩 (hagi, 秋の七草) から命名。 ぼた餅/おはぎ は 同じ食べ物 (same food, different name by season)。
- **六波羅蜜 (Rokuharamitsu, six perfections)**: 彼岸の期間に 6 つの修行 を実践。 布施 (fuse, charity) + 持戒 (jikai, morality) + 忍辱 (ninniku, patience) + 精進 (shōjin, diligence) + 禅定 (zenjō, meditation) + 智慧 (chie, wisdom)。
- **墓参 (hakamairi, grave visit)**: 期間中に 家族 で 墓地 (bochi, cemetery) を訪れ、 墓石 (boseki) を掃除 (sōji) + 花 (hana) + 線香 (senkō, incense) + 供花 (kyōka, offering flowers) を備える。 「お彼岸 (Ohigan)」 = 墓参り の 代名詞 (shorthand for grave visits)。
- **食べ物 (tabemono)**: ぼた餅 (botamochi) / おはぎ (ohagi) — 小豆 (azuki) 餡の餅 (mochi)。 春の 牡丹 (botan) vs 秋の 萩 (hagi) の花で呼び名が変わる、 食べ物自体は同じ。 地域差: 関東 = おはぎ / 関西 = ぼた餅 が多い。

## Cross-language Connections

- **Coreano**: 한국은 春分 (춘분) + 秋分 (추분) 을 「24 절기 (二十四節気)」 의 하나로 지내지만 彼岸 行事는 거의 없음. 韓國 佛教 (한국 불교) 는 「환희 (歓喜)」 + 「재 (齋)」 중심으로 彼岸식 의식을 거의 残さない. 한국의 가장 近い 行事는 寒食 (한식, 4/5) — 祖先 追慕 + 食べ物 行事.
- **Japonés**: 中国 24 節気 + 浄土宗 (Jōdo-shū) + 鎌倉 仏教 의 彼岸 思想 + 日本 民俗의 墓参 風習 의 融合. 韓國 + 中国 + 日本 中 가장 形式的 (가장 격식) 으로 彼岸 行事 를 残す.
- **Inglés**: Christian Ash Wednesday (灰の水曜日, 四旬節 Lent 開始) + All Souls Day (諸聖人の日, 11/2) + Celtic Samhain (11/1) 의 합작. 全て 春秋 (spring/autumn) の 死生 観 (view of life and death) + 食物 行事 (food ritual). 일본 彼岸 의 七日 (七日) 行事 는 Western 에서 거의 볼 수 없는 長期 의식.

## Ejemplos

「春の彼岸 (haru no higan, 3 月下旬) には、 ぼた餅 (botamochi) を仏壇 (butsudan) に供え、 お墓参り (ohakamairi) に行きます。」

「お彼岸 (ohigan) には、 仏教で大切にされる六波羅蜜 (rokuharamitsu) の修行を一つでも実践することが勧められています。」

「秋分の日 (shūbun no hi) を含む秋の彼岸 (aki no higan) には、 萩 (hagi) の花にちなんでおはぎ (ohagi) を作って食べます。」
