# 落語 (Rakugo, Comic Storytelling)

**Overview:** 落語 (らくご, rakugo) は 江戸時代 (1603-1868) 大阪 (Osaka) + 江戸 (Edo) で 成立 (seiritsu, established) した 一人芝居 (hitori shibai, one-person play) の 伝統芸能 (dentō geinō, traditional performing art). 「落語」 = 「落 (raku) = 「落とす」 + 「語 (go) = 「語る」 = 「落ち (ochi, punchline) まで語る」. 噺家 (hanashika, storyteller) 1 人 が 扇子 (sensu, fan) + 手拭い (tenugui, hand towel) + 座布団 (zabuton, cushion) だけ で 30 分 - 60 分 の 話 (hanashi) を 「声色 (koweiro, character voices)」 + 「表情 (hyōjō, expressions)」 + 「動き (ugoki, movements)」 で 表現 (hyōgen, express). 2017 年 ユネスコ無形文化遺産 (UNESCO, mukei bunka isan) 提案 (teian, proposed) + 2024 年現在 「日本の 芸能 (performing arts)」 として 国 指定 (kuni shitei, nationally designated) 無形文化財 (mukei bunkazai).

## Key Points

- **話芸 (Wagei, storytelling art) の 構造 (kōzō, structure)**: 「まくら (makura, pillow, 導入 dōnyū)」 + 「本題 (hondai, main topic)」 + 「落ち (ochi, punchline)」. 「まくら」 = 季節 (kisetsu, season) + 自己紹介 (jiko shōkai) + 軽い 雑談 (zatsudan, small talk). 「本題」 = 古典 (koten, classic) + 創作 (sōsaku, original). 「落ち」 = 突然 (totsuzen, sudden) の 洒落 (share, pun) + オチ (ochi) + 結末 (ketsumatsu).
- **噺家 (Hanashika, storyteller) の 階級 (kaikyū, rank)**: 修行 (shugyō, training) + 前座 (zenza, opening act, 2-4 年) + 二ツ目 (futatsume, intermediate, 5-9 年) + 真打 (shinuchi, top-rank, 10+ 年). 真打昇進 (shinuchi shōshin) = 「名前を 名乗る (na wo naonoru)」 許可 (kyoka, permission). 「前座 (zenza)」 = 「太鼓 (taiko)」 叩き (tataki, drum-beating) + 「お茶 (ocha, tea) 出し (dashi, serving)」 + 「短編 (tanpen, short) 噺 (hanashi)」 + 「二ツ目」 = 中堅 (chūken, mid-rank) + 「真打」 = 名人 (meijin, master).
- **古典演目 (Koten enmoku, classic repertoire)**: (1) 「時そば (Toki Soba)」 + (2) 「芝浜 (Shibahama)」 + (3) 「寿限無 (Jugemu)」 + (4) 「猫の皿 (Neko no Sara)」 + (5) 「子別れ (Kowakare)」 + (6) 「文七元結 (Bunshichi Motoyui)」 + (7) 「死神 (Shinigami)」 + (8) 「心眼 (Shingan)」 + (9) 「甲州街道 (Kōshū Kaidō)」 + (10) 「佐野政言 (Sano Masamoto)」。 寿限無 (Jugemu) は 名前 の 長さ (nagasa, length) + 「寿限無 寿限無 五劫のすりきれ 海砂利水魚の 水行末 雲来末 風来末…」 の 超長文名 (chōchōbunmei, super-long name) で 有名.
- **古典 + 創作 (Koten + Sōsaku)**: 「古典 (koten)」 = 江戸 (Edo, 1603-1868) + 大正 (Taishō, 1912-1926) までの 完成 (kansei, completed) 演目 (enmoku). 「創作 (sōsaku)」 = 現代 (gendai, present) の 噺家 (hanashika) が 新作 (shinsaku, new work) 創作. 「新作落語 (shinsaku rakugo)」 = 三遊亭 圓朝 (San'yūtei Enchō, 1839-1900) が 開拓 (kaitaku, pioneered) + 林家 正蔵 (Hayashiya Shōzō) + 笑福亭 鶴瓶 (Shōfukutei Tsurube, 1951-) + 春風亭 昇太 (Shunpūtei Shōta) + 立川 談志 (Tatekawa Danshi, 1936-2011) 의 현대 (modern) 작가.
- **演芸場 (Engeijō, performance hall)**: 「新宿 末廣亭 (Shinjuku Suehirotei)」 + 「上野 本牧亭 (Ueno Honmokutei)」 + 「浅草 演芸ホール (Asakusa Engei Hōru)」 + 「国立演芸場 (Kokuritsu Engeijō)」 + 「天満天神 繁昌亭 (Tenma Tenjin Hanshōtei, 大阪)」. 料金 (ryōkin) = 前座 ¥500-¥1,000 + 二ツ目 ¥1,500-¥2,500 + 真打 ¥2,500-¥4,500 + 興行 (kōgyō, performance) ¥10,000.

## Cross-language Connections

- **Coreano**: 한국 「만담 (mandam, 만담)」 + 「아나운서 (anaunseu, announcer)」 + 「토크 (tokeu, talk show)」 + 「방언 (bang-eon, 방언)」 + 「설창 (seolchang, 설창, 説唱)」 의 比較. 韓國 「만담 (mandam)」 + 「설창 (seolchang)」 + 「판소리 (pansori, 판소리)」 + 「민요 (minyo, 민요)」 + 「아리랑 (arirang, 아리랑)」 + 「강변가요 (gangbyeon gayo)」 의 共有. 韓國 「전통 설화 (jeontong seolhwa, 伝統 説話)」 + 「구비 설화 (gubi seolhwa, 口碑 説話)」 + 「이야기꾼 (iyagikkun, 이야기꾼)」 의 共有. 하지만 日本 「落語」 처럼 「扇子 + 手拭い + 座布団」 + 「一 人 芝居」 + 「声色」 의 独自 (独自) 形式.
- **Japonés**: 韓國 + 中国 + 日本 + モンゴル = 「話芸 (wagei, storytelling art)」 의 東アジア 共有. 韓國 「판소리 (pansori)」 + 「민요 (minyo)」 + 「만담 (mandam)」 + 日本 「落語 (rakugo)」 + 「講談 (kōdan)」 + 「浪曲 (rōkyoku)」 + 「浄瑠璃 (jōruri)」 + 「能 (nō)」 + 「狂言 (kyōgen)」 의 다단계 (다단계). 日本 만 「落語」 의 「一人で (hitori de) + 扇子 (sensu) + 手拭い (tenugui) + 座布団 (zabuton)」 의 独自 形式.
- **Inglés**: Western 「Stand-up comedy (comedian, microphone)」 + 「Storytelling (Seth MacFarlane, The Moth)」 + 「Monologue (TV show)」 의 比較. 最も 近い 比較는 UK 「Punch & Judy + pantomime」 + 「The Moth (storytelling podcast)」 + 「Comic monologues」 + 「Stand-up」 — 日本 「落語」 의 独自 形式.

## Ejemplos

「落語 (rakugo) は噺家 (hanashika, storyteller) 1 人で扇子 (sensu, fan) 1 本と手拭い (tenugui, hand towel) 1 枚だけを使い、 30 分から 1 時間かけて物語 (monogatari) を聴かせる (kikaseru) 伝統的な話芸 (wagei) です。」

「落語 (rakugo) の 演目 (enmoku) には『時そば (Toki Soba)』+『芝浜 (Shibahama)』+『寿限無 (Jugemu)』 など約 300 演目が伝えられています。」

「前座 (zenza) として修行 (shugyō) を始めてから 二ツ目 (futatsume) + 真打 (shinuchi) に 至るまでには 10 年以上の歳月 (saigetsu, years) がかかります。」
