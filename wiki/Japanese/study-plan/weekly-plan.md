# 日本語 週次学習計画 (Japanese Weekly Study Plan)

**Level:** N3-N2 (中級)
**Weekly commitment:** 3-4 hours (weekday 30min × 5 + weekend 60min × 2)
**Started:** 2026-08-19
**Cycle:** 4-week rotation (one grammar axis + one vocabulary theme + one output per cycle)

---

## Plan philosophy

- **Microlearning on weekdays**: 30 min sessions minimize friction
- **Deep work on weekends**: 1-hour focused sessions
- **4-week rotation**: one grammar axis + one vocab theme + one output per cycle
- **Output obligation**: every Sunday, ship a 5-sentence Japanese summary to blog
- **Native script first**: prioritize reading kanji + hiragana mix

## Weekly distribution

### 月〜金 (Mon–Fri · 30 min each day)

| Day | Block 1 (10 min) | Block 2 (10 min) | Block 3 (10 min) |
|---|---|---|---|
| 月 | 単語 (Anki 新規15) | 表現 1個 分析 | 軽い読み物 (新聞1頁) |
| 火 | 単語 復習 (Anki) | 文法 1ポイント | 聴解 (Podcast 5-10分) |
| 水 | 単語 (Anki 新規15) | 表現 1個 分析 | 軽い読み物 |
| 木 | 単語 復習 (Anki) | 文法 1ポイント | 聴解 |
| 金 | 週間 単語 復習 | 表現 1個 分析 | 自由読み/視聴 (YouTube) |

**Tools:**
- 単語: Anki (JLPT-tagged decks)
- 表現: 1 entry/day to `expressions/`
- 読み: 村上春樹, 吉本ばなな, 東野圭吾 (light chapters)
- 聴解: *JapanesePod101*, *Nihongo con Teppei* (beginner), *バイリンガルニュース* (intermediate)

### 土曜日 (Saturday · 60 min · deep session)

1. **深い読み (25 min)**: 原書 1章 or 長いエッセイ1編
   - 知らない単語を `vocabulary/` に 1-3個 追加 (over-collection 禁止)
2. **文法整理 (20 min)**: 今週の文法 axis
   - `grammar/` ページを更新
3. **表現ノート (15 min)**: 集めた表現 5個を使用例と共に整理

### 日曜日 (Sunday · 60 min · output + review)

1. **作文/会話 (25 min)**: 日本語で 5-8文 書く
   - Optional: italki / Preply 25-min session (週1回)
2. **週間復習 (20 min)**: Anki 全復習 + 表現 総整理
3. **ブログ発行 (15 min)**: wiki 内容 → markdown → ブログ publish
4. **来週計画 (with LLM)**:
   ```
   "今週学習した表現と文法に基づき来週計画を作成してください。
   不足3点と補強資料も提案してください。"
   ```

## 4-week rotation

### Block A · て形 + 補助動詞 (1-4週)

- **文法 axis**: て形, 〜ている, 〜てしまう, 〜ておく
- **語彙 axis**: 日常動作 + 補助動詞表現
- **読み**: 短編 (*Japanese short stories*)
- **Output**: 自己紹介拡張 (200字)
- **文法ページ**: `grammar/japanese-te-form-usage.md`

### Block B · 条件形 + 敬語 (5-8週)

- **文法 axis**: ば/なら/と/たら + 敬語 (sonkeigo/kenjougo/teineigo)
- **語彙 axis**: ビジネス・丁寧表現
- **読み**: *コンビニ人間* (村田沙耶香) 1-3章
- **Output**: ビジネスメール 1通 + 翻訳解説
- **文法ページ**: `grammar/japanese-conditional-forms.md`

### Block C · 受身 + 使役 (9-12週)

- **文法 axis**: 受身形, 使役形, 使役受身
- **語彙 axis**: 報告・指示・命令
- **読み**: *嫌われる勇気* (岸見一郎) 抜粋
- **Output**: 物語回想 短編 (300字)
- **文法ページ**: ユーザー選択

### Block D · 統合 · 自由プロジェクト (13-16週)

- **文法 axis**: 複合 (条件 + 敬語 + 受身)
- **語彙 axis**: 自由 (ユーザー興味分野)
- **読み**: ユーザー選択
- **Output**: 自由テーマ エッセイ or 動画スクリプト
- **文法ページ**: ユーザー選択
