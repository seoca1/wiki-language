# 助数詞 — ものの数え方 (Japanese Counters)

**Type:** grammar
**Level:** JLPT N5-N4
**Date Added:** 2026-08-11

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 일본어는 명사를 종류별로 분류해 각각 다른 助数詞(じょすうし)를 쓴다 (개/명/권/장/마리/대/층). 한국어 "한 개" 처럼 거의 모든 명사에 個 를 쓰지만, 일본어는 명사 성격에 따라 다름.
> - **한국어 차이:** 한국어 "한 개/한 명/한 마리/한 대" 가 모두 동일 (의미별 3~4종). 일본어는 명사 성격별 助数詞가 50+ 종. 音読み 변화(음독)도 동반.
> - **학습자 우선순위:** 個(汎用) → 人(사람) → 本(긴물건) → 枚(종이/접시) → 匹(동물) → 台(기계) → 階(층) → 冊(책) → 杯(음료).
> - **한국어 학습자 주의:** "교재 하나" = 教科書**一冊** (冊 = 책/바인더). 한국어 "한" 은 항상 1, 일본어 1은 **訓読み**(hitotsu) + 音読み (一/いち) 2계통.

## 기본 구조 (Basic Structure)

### 数字 + 助数詞
- Formula: **Number + Counter** (e.g., 三個 = 3 pieces, 五人 = 5 people)
- Numbers 1-10 have **two readings**: 訓読み (kun, native Japanese) + 音読み (on, Sino-Japanese). Counters always use **音読み**.
- Exception: 1 person only uses ひとり (訓読み). All other 1+X with 人 use 音読み: 二人(ふたり, exception again), 三人(さんにん).

| # | 訓読み | 音読み | Example (個) | Example (人) | Korean |
|---|---|---|---|---|---|
| 1 | ひとつ | いち | 一個 (ikko) | 一人 (hitori) | 한 개 / 한 명 |
| 2 | ふたつ | に | 二個 (niko) | 二人 (futari) | 두 개 / 두 명 |
| 3 | みっつ | さん | 三個 (sanko) | 三人 (sannin) | 세 개 / 세 명 |

## 주요 助数詞 9종 (Nine Core Counters)

### 1. 個 (ko). General-purpose
- **Use:** Small, round objects. Apples, eggs, cookies, cups (drink containers), general default.
- **Examples:** りんご三個 (3 apples) / 卵一個 (1 egg).

### 2. 人 (nin). People
- **Use:** Counter for people. Has irregular readings for 1 (ひとり) and 2 (ふたり).
- **Examples:** 先生一人 (1 teacher) / 友達三人 (3 friends).

### 3. 本 (hon / pon / bon). Long, cylindrical objects
- **Use:** Bottles, pens, umbrellas, rivers (counted as flow lines), roads, sticks, trees (sometimes 樹).
- **Reading:** ほん for 1, 6, 8; ぽん for counter changes (一本 = ippon, 三本 = sanbon, 六本 = roppon); ぼん for 八 (haphon but 八本 = happon with p).
- **Examples:** ペン三本 (3 pens) / ビール二本 (2 beers).

### 4. 枚 (mai). Flat objects
- **Use:** Paper, photographs, plates, tickets, shirts (clothing items treated as flat), CDs, leaves.
- **Examples:** 写真二枚 (2 photos) / 皿三枚 (3 plates).

### 5. 匹 (hiki / piki / biki). Small animals
- **Use:** Dogs, cats, fish, insects. Larger animals (horses, elephants, cows) use **頭 (tō)**.
- **Reading:** ひき for 1, 6, 8; びき for 2-5, 7, 9; counter irregular (一匹 = ip piki → ip piki; 三匹 = san biki).
- **Examples:** 猫二匹 (2 cats) / 虫三匹 (3 bugs).

### 6. 台 (dai). Machines, vehicles
- **Use:** Cars, TVs, computers, refrigerators, bicycles. Large mechanical items.
- **Examples:** 車一台 (1 car) / パソコン二台 (2 computers).

### 7. 階 (kai). Floors of buildings
- **Use:** Building floors. Often combined with suffix: 一階 (1F), 二階 (2F).
- **Special:** Japanese ground floor = 1階. Second floor = 2階. So if a building has 3 visible floors in Korea, it is 3階 in Japanese.
- **Examples:** 三階の教室 (3rd-floor classroom) / 五階に住んでいます (I live on 5F).

### 8. 冊 (satsu / satsu). Books, bound volumes
- **Use:** Books, magazines, notebooks, manga, binders, dossiers.
- **Reading:** さつ for most; さっ irregular for 1, 6, 8 (一冊 = issatsu, 六冊 = rokusatsu).
- **Examples:** 本二冊 (2 books) / ノート一冊 (1 notebook).

### 9. 杯 (hai / bai / pai). Drinks, cups of liquid
- **Use:** Glasses/cups of beverages, bowls of rice (sometimes), alcoholic drinks.
- **Reading:** はい for 1, 6, 8; ばい for 2-5, 7, 9; ぱい counter (一杯 = ip pai, 二杯 = ni hai).
- **Examples:** ビール二杯 (2 beers) / コーヒー一杯 (1 coffee).

## Key Points

- **모든 명사에는 助数詞 필수.** Korean "교과서 하나" requires counter: 教科書**一冊**.
- **音読み + 助数詞 조합 고정.** Numbers 1-10 with each counter have specific pronunciation (e.g., 二本 = にほん, 二枚 = にまい, 二台 = にだい).
- **人 만 불규칙:** 一人 = ひとり, 二人 = ふたり. 나머지 3+ = さん**にん** +.
- **本 / 匹 / 杯 는 音読み 변화:** 1/6/8 ≠ 2-5/7/9 발음 다름. 六本 = ろっ**ぽん**, 三本 = さん**ぼん**.
- **1~10 訓読み 사용:** ひとつ/ふたつ/みっつ は **助数詞 없을 때만** 사용. 助数詞 동반 시 무조건 音読み.
- **0 reading:** Zero is 零 (rei) or ゼロ (zero), with counter: ゼロ個 (zero pieces). Rare in natural speech.
- **Keigo note:** お客様 (okyakusama) for polite customer. Counter compounds with お prefix are limited (お一人 = one person, polite).

## Korean Learner Pitfalls

### 1. 한국어 "한 개" ≠ 무조건 個
- "한 대" (car) = 一**台**. "한 마리" (animal) = 一**匹**. "한 잔" (drink) = 一**杯**. 個 는 정말 작고 둥근 물건에만.
- 사과/계란/쿠키 = 個, 차/TV/컴퓨터 = 台, 책/공책 = 冊, 맥주/커피 = 杯.

### 2. 人 발음 함수
- 一人 = ひとり (NOT いちにん), 二人 = ふたり (NOT ににん).
- 3+ 는 규칙: 三人 = さんにん, 四人 = よにん. 단 4人 = よにん vs よんじん 모두 가능 (음독 변화).

### 3. 本 / 匹 / 杯 의 音便
- 一本 = いっ**ぽん** (NOT いほん), 三本 = さん**ぼん** (NOT さんぽん but similar), 六本 = ろっ**ぽん**.
- 일(一)/육(六)/팔(八) + 모음 시작 助数詞 (ほん/ひき/はい/まい → ぽん/びき/ばい/まい): 반탁음 변화.

### 4. 階 (floors) counting mismatch
- 한국어 1층 = 일본어 一階 (NOT 0階). 한국 2층 = 일본 2階. 日本은 **ground floor = 1階** (NOT 1階 ≠ ground floor).
- 日本の 1階 = 한국의 1층.

### 5. 助数詞 생략 불가
- 한국어 "사과 두 개 샀어" 처럼 "개" 생략 가능. 일본어는 個 필수.
- ❌ りんご二つ → ✅ りんご二**個**.

## Cross-language Connections

- **Korean:** 개/명/마리/대/잔 — 의미별 3~4종. 한국어 조수(助數) 형태.
- **English:** No mandatory counter; "3 apples" uses plural -s only. Measure words limited (a cup of, a head of cattle).
- **Spanish:** No mandatory counter for general objects. Collective use limited.
- **Chinese:** 量词 (个/条/只/张/本/杯) — 가장 발달한 체제. 일본어와 직접 비교 가능 (개/마리/장).
- **Japanese uniqueness:** 50+ 종 助数詞 + 음독 변화 (一本=ippon, 二本=nihon, 六本=roppon). 한국어보다 훨씬 세분화.

## Ejemplos

«りんご**を三個**買いました。』 — 個 for apples (3 apples bought).

«写真**を二枚**撮りました。』 — 枚 for photos (took 2 photos).

«友達**と三人で**映画を見ました。』 — 人 for people (saw a movie with 3 friends).

«ペンを**二本**ください。』 — 本 for pens (2 pens please).

«車**を一台**持っています。』 — 台 for cars (I have 1 car).

«この建物**は五階**まであります。』 — 階 for floors (this building has 5 floors).

«先生**と二人で**話しました。』 — 人 irregular (2 people talked with teacher).

«ノート**を三冊**買いました。』 — 冊 for notebooks (bought 3 notebooks).

«ビール**を二杯**飲みました。』 — 杯 for drinks (drank 2 beers).

«猫**を一匹**飼っています。』 — 匹 for small animals (I have 1 cat).

«りんご**を一つ**ください。(casual)』 — 訓読み form, no counter, casual only.

«一人**で**来ました。』 — 人 irregular + で (came alone).
