# 日本語 動詞の形式 (Verb Forms)

**Type:** 文法 (grammar)
**Level:** JLPT N5-N4
**Date Added:** 2026-08-08

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 일본어 동사는 6 가지 기본 형식 (辞書形 / ます形 / て形 / た形 / ない形 / 意向形) + 3 그룹 분류 (五段 / 一段 / 不規則).
> - **한국어 차이:** 한국어 동사 활용은 시제 + 경어 + 존칭 결합 (~15 종). 일본어는 형식별로 활용 분리 (~30 종).
> - **학습자 우선순위:** ます형 → て형 → た형 → ない형 → 辞書形 순서.
> - **한국어 학습자 주의:** Group 1 (五段) 동사는 음운 변화 규칙 외울 필요. Group 2 (一段) 는 비교적 규칙적.

---

## 3 그룹 분류

### Group 1: 五段動詞 (ごだんどうし, godan)
- 어미가 う단 (단, 단 以外) 으로 끝남
- 5 개 모음 활용
- 예: 書く (かく), 話す (はなす), 飲む (のむ), 作る (つくる)

### Group 2: 一段動詞 (いちだんどうし, ichidan)
- 어미가 -える 또는 -いる (단, える/いる 제외)
- 활용 시 어미 제거 + 새 어미 부착
- 예: 食べる (たべる), 見る (みる), 起きる (おきる)

### 不規則動詞 (Irregular)
- する / 来る (くる) — 개별 외우기

---

## 6 가지 기본 형식

### 1. 辞書形 (Dictionary Form) — 원형
- 사전 등재 형태
- Group 1: う단 그대로 (書く, 話す, 飲む)
- Group 2: -える / -いる 그대로 (食べる, 起きる)
- 不規則: する, 来る

### 2. ます形 (Masu Form) — 정중형
- 일상 회화 / 공손
- Group 1: う단 → い단 + ます (書く → 書**きます**)
- Group 2: -える → -ます (食べる → 食べ**ます**)
- 不規則: する → **します**, 来る → **来ます**

### 3. て形 (Te Form) — 접속
- 연속동작, 요청, 진행형
- Group 1: 음운 변화 (書く → **書いて**, 話す → **話して**, 飲む → **飲んで**)
- Group 2: -て (食べる → **食べて**)
- 不規則: する → **して**, 来る → **来て**

### 4. た形 (Ta Form) — 과거
- て형 + た
- Group 1: 음운 변화 (書いた, 話した, 飲んだ)
- Group 2: -た (食べた)

### 5. ない形 (Nai Form) — 부정
- "~안 하다"
- Group 1: う단 → あ단 + ない (書かない, 話さない, 飲まない)
- Group 2: -ない (食べない)

### 6. 意向形 (Ikō Form) — 의지 / 의도
- "~하자", "~할 거야"
- Group 1: う단 → おう단 (書こう, 話そう, 飲もう)
- Group 2: -よう (食べよう, 起きよう)

## Group 1 음운 변화 표

| 사전형 (う단) | て/た형 | ない형 | 意向形 | 예 |
|---|---|---|---|---|
| う / く / ぐ | って / いで | わない / がない | おう | 書く → 書いて / 書かない / 書こう |
| す | して | さない | そう | 話す → 話して / 話さない / 話そう |
| む / ぶ / ぬ | んで | まない / ばない / な | もう | 飲む → 飲んで / 飲まない / 飲もう |
| る / つ | って | らない / たない | ろう | 作る → 作って / 作らない / 作ろう |

## 활용 예시 (飲む = 마시다)

| 형식 | 형태 | 한국어 |
|---|---|---|
| 사전형 | 飲む | 마시다 |
| ます형 | 飲みます | 마십니다 |
| て형 | 飲んで | 마시고 |
| た形 | 飲んだ | 마셨다 |
| ない형 | 飲まない | 마시지 않다 |
| 意向形 | 飲もう | 마시자 |

## 활용 예시 (食べる = 먹다)

| 형식 | 형태 | 한국어 |
|---|---|---|
| 사전형 | 食べる | 먹다 |
| ます형 | 食べます | 먹습니다 |
| て형 | 食べて | 먹고 |
| た形 | 食べた | 먹었다 |
| ない형 | 食べない | 먹지 않다 |
| 意向形 | 食べよう | 먹자 |

## 한국어 학습자 주의

1. **존댓말 (ます형) 기본**: 日常 회화는 ます형. 사전형은 사전 / 문어 / 강조.
2. **て형 활용**: 진행 (-ている), 요청 (-てください), 연속 (-て、-て), 사유 (-て) 등 다기능.
3. **음운 변화 (음독)**: Group 1 동사는 발음 규칙에 따라 て형 달라짐. 외울 필요.
4. **불규칙 동사 (する / 来る)**: Group 2 와 비슷해 보이지만 활용 다름. 개별 외우기.
5. **ます형 + た**: ます형 과거 = ました. 사전형과 다른 형식.

## Ejemplos

«毎日コーヒーを飲みます» — 매일 커피를 마십니다 (ます형, 습관).

«昨日コーヒーを飲みました» — 어제 커피를 마셨습니다 (ました, 과거).

«コーヒーを飲みませんか» — 커피 마시지 않겠습니까? (ません + か = 권유)

«コーヒーを飲んで、仕事をしました» — 커피를 마시고, 일했습니다 (て형 + た형).

«明日は早く起きよう» — 내일은 일찍 일어나자 (意向形).

## Cross-language Connections

- **한국어**: 동사 활용이 시제 + 경어 + 존칭 결합 (~15 종 어미). 일본어보다 활용이 단순하지만 경어가 필수.
- **스페인어**: 3 그룹 (AR / ER / IR) × 6 시제형 (현재 / 과거 / 미래 / 불완료 / 완료 / 조건) = ~30 활용형. 일본어보다 많지만 시제 중심.
- **영어**: 12 시제형 (시제 2 × 상 4). 활용 변화 적음 (V-ed / V-ing / have + p.p.). 동사 시제형 결합이 일본어와 비슷.
