# 条件形 — と・ば・なら・たら (Japanese Conditionals)

**Type:** grammar
**Level:** JLPT N4-N3
**Date Added:** 2026-08-11

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 일본어 조건 표현은 4종. と (자연 귀결), ば (일반 조건), なら (화제 조건), たら (시간/조건). 한국어 "면" 1종과 1:1 매칭 불가 — 각각 다른 뉘앙스.
> - **한국어 차이:** 한국어 조건은 시제 + 어미로 통합 ("으면/면/다면"). 일본어는 4개 별도 조사(助詞) 로 의미 분리 — 한국어보다 정교.
> - **학습자 우선순위:** たら (가장 범용, 시간+조건) → と (자연 귀결/습관) → ば (일반/가정) → なら (화제/의사결정).
> - **한국어 학습자 주의:** と 는 의지/명령과 결합 불가 (식사해라 같은 명령문 결합 시 ば/たら 사용). なら 는 "그렇다면" 화제 전환 표현.

---

## 4가지 조건의 구분 (Four Conditionals Overview)

| Conditional | Function | Korean equivalent | Volition/will |
|---|---|---|---|
| **と** (to) | Natural consequence, habits, facts | ~으면 (자연) | ❌ No volition |
| **ば** (ba) | General/hypothetical condition | ~다면 (가정) | ✅ With volition |
| **なら** (nara) | Topic-conditional, "if it's X" | ~(이)라면 | ✅ With volition |
| **たら** (tara) | Temporal/event-based, "when/if" | ~으면/~았으면 | ✅ With volition |

---

## 1. と (Natural Consequence)

### Structure
**Verb (辞書形) + と**

### Usage
- **Automatic/natural consequence:** When A always causes B (law of nature, repeated habits, automatic results).
- **Discoveries:** 見ると (when I see) = on seeing / looking.
- **NOT for volitional commands:** ❌ 食べ**と** なさい (X) → ✅ 食べ**たら** なさい (O).

### Examples
- 春になると、花が咲きます (Haru ni naru to, hana ga sakimasu) = When spring comes, flowers bloom (natural cycle).
- ボタンを押すと、ドアが開きます (Oshite botan o osu to, doa ga akimasu) = When you press the button, the door opens (automatic).
- あの店に行くと、コーヒーも飲めます (Ano mise ni iku to, kōhī mo nomemasu) = When I go to that shop, I can drink coffee too (habit).
- 空港に着くと、連絡してください (Kūkō ni tsuku to, renraku shite kudasai) = When you arrive at the airport, please contact me (temporal discovery).

### Restrictions
- ❌ 命令形 (command): 「行き**と** なさい」 → ✅ 「行き**なさい**」or 「行き**たら** なさい」
- ❌ 의지/의도: 「明日**と** 私が行きます」 → ✅ 「明日**なら** 私が行きます」 or 「明日**なら** 行けます」
- ❌ 過去文 결합 시 自然 帰結 의미 약해짐: 「食べ**た** と」 = "if I had eaten" — 비표준.

## 2. ば (General/Hypothetical Condition)

### Structure
**Verb (ば-form)** — Group 1: replace final う with え + ば. Group 2: drop -ru + れ + ば. Irregular: special.

### Conjugation

| Group | Rule | Example (食べる) |
|---|---|---|
| Group 1 (五段) | -u → -e + ば | 食べる → 食べ**れば** |
| Group 2 (一段) | -ru → -re + ば | 食べる → 食べ**れば** (drop ru, add れば) |
| する (Irregular) | す + れば | する → す**れば** |
| 来る (Irregular) | く + れば | 来る → 来**れば** (kureba) |
| い형용사 | -い → -く + ば | 高い → 高**ければ** |
| な형용사 | + なら + ば (or + であれば) | 静か → 静か**なら** (preferred) |

### Usage
- **General/hypothetical conditions:** "if [A], then [B]". Often paired with general truths or hypotheticals.
- **Suggestions with volition:** Uses ば良い (ba ii) = "should do / would be good".
- **Noun:** N + であれば (de areba). N + なら (nara, colloquial).

### Examples
- 安ければ買いたい (Yasukereba kaitai) = If it's cheap, I want to buy it.
- 勉強すれば上手になります (Benkyō sureba jōzu ni narimasu) = If you study, you'll get better.
- 春になれば花が咲きます (Haru ni nareba hana ga sakimasu) = When spring comes, flowers bloom (general).
- もっと若ければいいのに (Motto wakakereba ii no ni) = If only I were younger.

### Useful Pattern: ば + いい
- Verb (ば) + いい = "should do / would be good".
- 安**ければ** いい (Yasukereba ii) = It would be good if cheap.

## 3. なら (Topic-Conditional)

### Structure
**N/Adj (stem) + なら** (or ならば for written) / Verb (辞書形) + なら

### Usage
- **Topic-based conditional:** "If it's X (the topic we're discussing)...". Implies speaker is responding to a stated/assumed topic.
- **Stereotypes/generalizations:** ~なら + general statement.
- **Volitional-friendly:** Pairs with 行く/したい/etc. (intention possible).

### Examples
- 日本に行くなら、京都がおすすめです (Nihon ni iku nara, Kyō ga osusume desu) = If you're going to Japan, Kyoto is recommended.
- 食べるなら、和食がいい (Taberu nara, washoku ga ii) = If we're eating, Japanese food is good.
- 田中さんなら知っているでしょう (Tanaka-san nara shitte iru deshō) = If it's Tanaka-san, he'd probably know.
- 札幌に行くなら、新千歳空港がいいです (Sapporo ni iku nara, Shin-Chitose kūkō ga ii desu) = If you're going to Sapporo, New Chitose Airport is good.

### Distinguishing Feature
- なら introduces a **new topic that may or may not be true**. Often translated "in that case / if it's X".
- と describes **automatic/real-world conditions**; ば describes **hypothetical**. なら is about **topic**.

---

## 4. たら (Temporal/Conditional)

### Structure
**Verb (た-form) + ら**

### Usage
- **Temporal sequence:** "When [A happened], [B] happened". Most flexible conditional.
- **Conditional:** "If [A] happens, [B] happens".
- **Discovery:** たら + 発見 (found that...). 「家に**帰ったら**、誰もいなかった」(When I came home, no one was there).
- **Works with all conjugations.** Volition OK.

### Examples
- 春になったら、花が咲きます (Haru ni nattara, hana ga sakimasu) = When spring comes, flowers bloom.
- 家に帰ったら、電話してください (Ie ni kaettara, denwa shite kudasai) = When you get home, please call.
- 日本に行ったら、京都にも行きたい (Nihon ni ittara, Kyō ni mo ikitai) = If I go to Japan, I want to go to Kyoto too.
- お金があったら、旅行したい (Okane ga attara, ryokō shitai) = If I had money, I'd want to travel.
- 試験に失敗したら、もう一度受けます (Shiken ni shippai shitara, mō ichido ukemasu) = If I fail the exam, I'll take it again.

### Distinguishing Feature
- たら = event/time-based, "when / if [it happens]". Most general-purpose.
- Past + ら = "if [had happened]" or "when [happened]".
- Allows volition, command, request freely.

## Comparison Table (4 Conditionals)

| Feature | と | ば | なら | たら |
|---|---|---|---|---|
| **Volition** | ❌ No | ✅ Yes | ✅ Yes | ✅ Yes |
| **Command** | ❌ No | ⚠️ Rare | ✅ Yes | ✅ Yes |
| **Past tense** | Limited | Limited | Limited | ✅ Natural |
| **Discoveries** | ✅ (見ると) | ❌ | ❌ | ✅ (たら + 発見) |
| **Natural law** | ✅ Best | ⚠️ OK | ❌ | ⚠️ OK |
| **Topic** | ❌ | ⚠️ | ✅ Best | ⚠️ |
| **Time/sequence** | ⚠️ | ⚠️ | ❌ | ✅ Best |
| **Common translation** | when/if (natural) | if (general) | if it's X | when/if |

## Key Points

- **と = automatic/natural.** Spring → flowers. No volition/command. Korean "~으면 (자연 귀결)".
- **ば = hypothetical/general.** "If cheap, I'll buy" / general truths. Often paired with ば + いい = "should do".
- **なら = topic-conditional.** "If it's X" — responding to a stated topic. Speaker assumes the topic.
- **たら = temporal/event-based.** Most flexible. "When/if it happens". Past tense natural.
- **と + 의지/명령 불가.** ❌ 「行き**と** なさい」 → ✅ 「行き**たら** なさい」or「行き**なさい**」.
- **なら + 意志 OK.** 「日本**なら** 行きたい」 (If it's Japan, I want to go).
- **たら + 発見.** 「見**たら** 分かった」(When I looked, I understood).
- **ば の 活用.** Group 1: 飲**め**ば (drink, replace む with め). Group 2: 食べ**れば** (drop ru, add れば). する: す**れば**. 来る: く**れば**.
- **Keigo note:** でしたら (de shitara, polite past of なら), ございますなら (extreme politeness). なら + お + stem: 「お休み**なら**」(if you're resting, polite).

## Korean Learner Pitfalls

### 1. と + 의지/명령 결합 오류
- 한국어 "~으면 ~하겠다" → 일본어 は ❌「食べ**ると** 食べる」 → ✅「食べ**たら** 食べる」or「食べ**れば** 食べる」.
- と 는 자연 귀결만, 의지/명령은 ば/たら/なら 사용.

### 2. ば vs たら 뉘앙스
- ば = 가정적 일반 조건 (만약 ~한다면). たら = 시간/사건 기반 (어떤 일이 일어나면).
- "비 싸면 안 사" = 高**ければ** 買わない (general). "더 비싸면 안 사" = もっと高**かったら** 買わない (event).
- 뉘앙스 차이일 뿐 둘 다 가능. 단 자연 귀결이면 と 사용.

### 3. なら = "If it's X (the topic)"
- 한국어 "라면" 과 다름. なら 는 "그것에 대해 이야기하자면" 의미.
- ❌「日本**なら** 好きです」(if it's Japan, I like) — 명사 자체 평가. ✅「日本**に** 行く**なら**」(if you're going to Japan).

### 4. たら 의 시제 처리
- たら 는 た형 기반이라 과거 시제 자연스러움. ❌「食べ**る** + たら」 → ✅「食べ**たら**」.
- 다른 조건(と/ば/なら)은 과거 시제 결합 비자연스러움.

### 5. ば 의 활용 분리
- Group 1: 飲む → 飲**め**ば (replace む with め). Group 2: 食べる → 食べ**れば** (drop -ru).
- ❌ 飲む → 飲む**ば** (X) → ✅ 飲**め**ば. Group 1 음운변화 (う단 → え단).

## Cross-language Connections

- **Korean:** 조건/가정 (~으면, ~다면, ~(이)라면, ~(았/었)으면). 한국어는 시제/양태 결합. 일본어보다 어미 통합.
- **English:** If/When (4 types: zero, 1st, 2nd, 3rd conditional) + As soon as/Whenever (temporal).
- **Spanish:** Si (presente + futuro/presente/Subjuntivo). 4 subjunctive moods for conditional + temporal.
- **Chinese:** 如果/要是 (if) / 一...就... (as soon as). 2~3 형식, 시제 의존도 낮음.
- **Japanese uniqueness:** 4종 조건 + 각각 다른 제약 (volition/natural/topic/temporal). 한국어보다 세분화, 스페인어 subjuntivo 와 유사한 의미론적 복잡성.

## Ejemplos

«春**になると**、花が咲きます。』 — と + 자연귀결 (when spring comes, flowers bloom).

«ボタン**を押すと**、ドアが開きます。』 — と + 자동반응 (when you press, door opens).

«安**ければ** 買いたいです。』 — ば + 가정 (if cheap, I want to buy).

«もっと安**ければ** いいのに。』 — ば + いい (if only it were cheaper).

«日本**に行くなら**、京都がおすすめです。』 — なら + 화제 (if you're going to Japan, Kyoto is recommended).

«田中さん**なら** 知っているでしょう。』 — なら + 사람 (if it's Tanaka-san, he'd know).

«春**になったら**、花が咲きます。』 — たら + 시간 (when spring comes, flowers bloom).

«日本**に行ったら**、京都にも行きたいです。』 — たら + 의지 (if I go to Japan, want to go to Kyoto too).

«お金**があったら**、旅行したいです。』 — たら + 가정 (if I had money, would travel).

«家**に** 帰**ったら**、電話してください。』 — たら + 부탁 (when you get home, please call).

«明日**なら** 行くことができます。』 — なら + 가능 (if it's tomorrow, I can go).

«六時**に** な**れば**、会社を出ます。』 — ば + 일반 (when it becomes 6, leave office).
