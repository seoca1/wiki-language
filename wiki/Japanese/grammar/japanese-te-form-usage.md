# て形の用法 — 4가지 핵심 (Te-form Usage)

**Type:** grammar
**Level:** JLPT N5-N4
**Date Added:** 2026-08-11

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** て형(て형) 은 일본어 동사 활용 중 가장 파생이 많은 형식. 4대 핵심 용법: ① てください (요청) ② ています (진행) ③ てもいいです (허가) ④ てから (순서).
> - **한국어 차이:** 한국어 연결어미 "-아/어" 는 용법 제한적 (접속/시도 정도). 일본어 て형 은 12+ 가지 파생 패턴 보유.
> - **학습자 우선순위:** てください (요청, 매일 사용) → ています (진행/상태) → てもいいです (허가) → てから (순서) → てみる (시도) → てしまう (완료).
> - **한국어 학습자 주의:** 한국어 "-고 있다" 와 ています 의미 거의 동일하나, ています 는 **현재/현재완료 상태** 표현에도 쓰임. 결과 상태: 結婚**しています** = 결혼해 있다 (지속 상태).

## て형의 기본 (Te-form Basics)

### Te-form Sound Changes

See [[verb-forms-jp]] for the full Group 1/2/Irregular conjugation tables. Key sound changes:

| Verb ending | Te-form | Example |
|---|---|---|
| う/く/ぐ | って/いで | 書く → 書いて (kaite) |
| す | して | 話す → 話して (hanashite) |
| む/ぶ/ぬ | んで | 飲む → 飲んで (nonde) |
| る/つ/う | って | 作る → 作って (tsukutte) |
| Group 2 (-eru/-iru) | -て (drop -ru) | 食べる → 食べて (tabete) |
| Irregular する | して | 勉強する → 勉強して |
| Irregular 来る | 来て | 来る → 来て (kite) |

### Te-form Function
- **Sequence connector:** Links 2+ actions (Verb て + Verb = action sequence).
- **Grammatical host:** Attaches to **suffixes** (ください/います/もいいです/から/みる/しまう/おく/あげる/もらう/やる).

## 4가지 핵심 용법 (4 Core Usages)

### 1. てください (Polite Request)

#### Structure
**Verb (て-form) + ください**

#### Usage
- Polite request: "please do [action]". Standard everyday politeness (softer than 命令形).
- お願い**します** = humble request.

#### Examples
- 食べてください (tabete kudasai) = please eat.
- 待ってください (matte kudasai) = please wait.
- 見せてください (misete kudasai) = please show me.
- 来てください (kite kudasai) = please come.

#### Negative Request
- Verb (ないで-form) + ください: 食べ**ないで** ください = please don't eat.
- Alternative: Verb (なかっ-form) + てください? NO. Use ないで for negative politeness.

---

### 2. ています (Progressive / Result State)

#### Structure
**Verb (て-form) + います**

#### Usage
- **Progressive:** Action in progress (Verb + ている = "-ing").
- **Result state:** Result of past action continuing to present (結婚している = "is married", 字が読めている = "can read now").

#### Progressive vs Result State

| Pattern | Progressive | Result State |
|---|---|---|
| 食べる → 食べている | 食べている (is eating) | (rare result state) |
| 結婚する → 結婚している | (rare) | 結婚している (is married) |
| 知る → 知っている | (rare) | 知っている (knows) |
| 死ぬ → 死んでいる | (rare) | 死んでいる (is dead) |

#### Examples
- 今、本を読んでいます (Ima, hon o yonde imasu) = I am reading a book now (progressive).
- 結婚しています (Kekkon shite imasu) = I am married (result state).
- 雨が降っています (Ame ga futte imasu) = It is raining.

---

### 3. てもいいです (Permission)

#### Structure
**Verb (て-form) + もいいです**

#### Usage
- Permission: "may do / it's OK to do". Softer than 命令形, more polite than ても構わない.
- てもいい vs ても構わない: もいい is neutral polite; ても構わない emphasizes "doesn't matter".

#### Examples
- 食べて**も**いいです (Tabete mo ii desu) = You may eat.
- 写真を撮ってもいいですか (Shashin o totte mo ii desu ka) = May I take a photo?
- 早く帰ってもいい (Hayaku kaette mo ii) = You may leave early.

#### Prohibition (opposite)
- Verb (ては) + いけません: 食べて**は**いけません (Tabete wa ikemasen) = must not eat / forbidden.
- Casual: 食べて**は** だめ. Polite: ては いけません / ては なりません.

---

### 4. てから (Sequence)

#### Structure
**Verb (て-form) + から**

#### Usage
- Temporal sequence: "after doing [A], [B] happens". Korean "-고 나서" 와 유사.
- 前に (mae ni) is "before" (opposite direction).
- B で starting sentence: 食べて**から** = "after eating".

#### Examples
- 食べてから勉強します (Tabete kara benkyō shimasu) = I'll study after eating.
- 手を洗ってから食べてください (Te o aratte kara tabete kudasai) = Please wash your hands before eating.
- 日本に来てから三年です (Nihon ni kite kara san nen desu) = It's been 3 years since I came to Japan.

#### Sequence alternatives
- Verb (た-form) + ら: 食べ**たら** 行く (after eating, will go) = casual.
- Verb (辞書形) + 前に: 食べる**前に** 手を洗う = before eating, wash hands.

## Key Points

- **て형 파생 12+ 종.** 4대 핵심: てください/ています/てもいいです/てから. 나머지: てみる (시도), てしまう (완료), ておく (준비), てあげる/てもらう/てやる (授受), ては (조건).
- **います 는 진행 + 상태.** Progressive (読んでいる = reading) AND result state (結婚している = married). 한국어 "-고 있다" 는 진행만.
- **ても vs ては.** ても = permission/even if (食べても = "even if you eat"). ては = conditional/prohibition (食べては = "if you eat" / "must not eat").
- **てから + 前に.** てから = "after [A], [B]". 前に = "before [B], [A]". 두 표현 다 시제 마커 결합 가능.
- **Group 1 음운변화 의존.** 5 vowel 변화 (書いて/泳いで/作って/話して/飲んで) 정확히 숙지 필수. 잘못 활용 시 다른 동사처럼 들림.
- **Irregular 별도:** する → して, 来る → 来て. 활용 패턴 자체가 다름.
- **Keigo note:** てください 는 일반 정중. 비즈니스: Verb stem + いただけますか (食べて**いただけますか** = "would you kindly eat?"). てください 보다 격식 高.

## Korean Learner Pitfalls

### 1. ています = "-고 있다" 만 아님
- 한국어 "-고 있다" 는 진행만. 일본어 ています 는 **결과 상태** 도 포함: 結婚**しています** = 결혼해 있다 (지속 상태).
- 知**っています** = 알고 있다 (지식 보유). 死**んでいます** = 죽어 있다 (사망 상태).

### 2. ても vs ては 발음 구분
- ても (tabete**mo** = "even if" / permission). ては (tabete**wa** = conditional / prohibition).
- 발음 차이: も vs は (particles). 구어에서 も = ermo 느낌, 는 = wa 발음.

### 3. てください vs ないでください
- ❌ 食べ**なくて** ください → ✅ 食べ**ないで** ください.
- Negative request uses ないで, NOT なくて.

### 4. てから vs たら
- てから = 단순 순서 강조 (after V-ing). たら = 시간/조건 (when/if).
- "밥 먹고 나서 공부해" = 食べて**から** 勉強する (sequence).
- "밥 먹으면 출근해" = 食べ**たら** 出勤する (when/if).

### 5. Group 1 음운변화 적용 안 함
- 한국 학습자 흔한 오류: 書く → 書きて (X) → 書いて (O).
- う/く/ぐ → って/いで, む/ぶ/ぬ → んで, る/つ/う → って. 외우기 필수.

## Cross-language Connections

- **Korean:** 연결어미 (~고, ~아서, ~니까) — 시제/조건/이유 다양. 다만 용법별 어미 분리 (~고 나서 순서, ~으면 조건).
- **English:** Gerund (eating, having eaten) + auxiliary (have eaten) — progressive vs perfect split. Less unified than Japanese て-form.
- **Spanish:** Gerundio (-ando / -iendo) + perifrástico (estar + gerundio). Conditional forms 별도.
- **Chinese:** 了/过/着/在 — 동사 뒤/앞 결합. 시상 + 상 분리. 한국어/일본어보다 simple.
- **Japanese uniqueness:** て형 1형식에서 12+ 용법 파생. Group 1 음운변화 의존. 가장 압축적인 활용 형식.

## Ejemplos

«ここ**に座って**ください。』 — て-form + ください (please sit here).

«今**、雨が降っています**。』 — ています (it is raining now).

«写真**を撮ってもいいですか**。』 — ても いい + question (may I take a photo?).

«ごはん**を食べてから** 勉強します。』 — てから (after eating, I'll study).

«日本**に来てから** 三年になります。』 — てから + 状態 (it has been 3 years since I came to Japan).

«結婚**しています**。』 — ています + 結果状態 (I am married).

«ここで**煙草を吸ってはいけません**。』 — ては + いけません (smoking is forbidden here).

«日本**に** 行って**、** 京都**に** 行って**、** 大阪**に** 行きます。』 — て-form + 接続 (go to Japan, then Kyoto, then Osaka).

«日本語**を勉強してみます**。』 — てみる (I'll try studying Japanese).

«宿題**をしてしまいました**。』 — てしまう (I ended up doing the homework / regret).
