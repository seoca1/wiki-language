# 日本語 助詞 (Particles)

**Type:** 文法 (grammar)
**Level:** JLPT N5-N4
**Date Added:** 2026-08-08

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 일본어 조사 9 종 (は/が/を/に/で/へ/から/まで/より) — 한국어 조사 (~30 종) 의 절반 수준이지만 정교함.
> - **한국어 차이:** 한국어 "이/가" 와 일본어 "は/が" 의 비대응. 한국어는 주격 1 종, 일본어는 주제/주어 2 종 (は vs が).
> - **학습자 우선순위:** は/が → を → に/で → から/まで/より 순서로.
> - **한국어 학습자 주의:** "에" vs "에서" 의 한국어 대응이 일본어 では に/で 구분이 안 됨. 맥락 의존.

---

## 9대 핵심 조사

### 1. は (wa) — 주제 / 대조
- **용도**: 문장 주제, 대조 ("~은/는 ~이다")
- **예**:
  - 私**は**学生です (나는 학생입니다)
  - 今日**は**休みます (오늘**은** 쉽니다 — 대조)

### 2. が (ga) — 주어 / 강조
- **용도**: 문법적 주어, 강조 ("누가/무엇이")
- **예**:
  - 私**が**行きます (제**가** 갑니다 — 강조)
  - 水**が**飲みたい (물**이** 마시고 싶다)

### 3. を (o) — 목적어
- **용도**: 타동사의 직접 목적어
- **예**:
  - 本**を**読みます (책**을** 읽습니다)
  - ご飯**を**食べます (밥**을** 먹습니다)

### 4. に (ni) — 다기능
- **용도**: 방향 / 시간 / 간접 목적어 / 귀착점 / 존재
- **예**:
  - 学校**に**行きます (학교**에** 갑니다 — 방향)
  - 3時**に**会いましょう (3시**에** 만납시다 — 시간)
  - 友達**に**プレゼントをあげます (친구**에게** 선물 줍니다)

### 5. で (de) — 다기능
- **용도**: 행동의 장소 / 수단 / 원인 / 범위
- **예**:
  - 図書館**で**勉強します (도서관**에서** 공부합니다 — 장소)
  - バス**で**行きます (버스**로** 갑니다 — 수단)
  - 病気**で**休みました (병**으로** 쉬었습니다 — 원인)

### 6. へ (e) — 방향 (문어)
- **용도**: に 의 문어적 변형
- **예**: 京都**へ**行きます (교토**로** 갑니다)

### 7. から (kara) — 출발 / 원인
- **용도**: 시간 / 공간의 시작, 원인
- **예**: 9時**から**始まります (9시**부터** 시작)

### 8. まで (made) — 종점
- **용도**: 시간 / 공간의 끝
- **예**: 5時**まで**待ちます (5시**까지** 기다립니다)

### 9. より (yori) — 비교
- **용도**: 비교의 기준
- **예**: 彼**より**背が高い (그**보다** 키가 크다)

## 핵심 구분: は vs が

가장 어려운 구분. 한국어 "이/가" 와 비대응.

| 상황 | 사용 | 예 |
|---|---|---|
| 처음 소개 / 일반 진술 | は | 私は学生です |
| 이미 알려진 정보 / 대조 | は | 今日は休みます (오늘**은** 쉽니다) |
| 강조 / 정보 | が | 私が行きます (제**가** 갑니다) |
| 목적어 있을 때 주어 | が | コーヒーが飲みたい (커피**가** 마시고 싶다) |
| 의문문 (의문사) | が | 誰が来ましたか (누가 왔습니까) |
| 가능 / 능력 | が | 日本語が話せます (일본어**가** 말할 수 있습니다) |

---

## 핵심 구분: に vs で

장소 / 방향 / 시간 표시의 핵심 구분.

| 상황 | 사용 | 예 |
|---|---|---|
| 동작의 **귀착점** (목적지) | に | 学校**に**行きます (학교**에** 갑니다) |
| 동작의 **장소** (행동) | で | 図書館**で**勉強します (도서관**에서** 공부합니다) |
| 시간 | に | 3時**に**会いましょう |
| 방향 (문어) | へ | 京都**へ**行きます |
| 수단 | で | バス**で**行きます |
| 원인 | で | 病気**で**休みました |

## 한국어 ↔ 일본어 조사 대응 표

| 한국어 | 일본어 | 의미 |
|---|---|---|
| 이/가 (주격) | が (subject) / は (topic) | 주어 표시 |
| 을/를 (목적격) | を | 목적어 |
| 에 (장소) | に (귀착) / で (행동) | 장소 |
| 에서 (행동) | で | 동작 장소 |
| 로/으로 (방향) | に / へ | 방향 |
| 부터 (시간) | から | 시간 출발 |
| 까지 (시간) | まで | 시간 종점 |
| 보다 (비교) | より | 비교 기준 |
| 은/는 (대조) | は | 주제 / 대조 |
| 의 (소유) | の | 소유격 |
| 와/과 (동반) | と | 동격 / 함께 |

## 한국어 학습자 실수 패턴

1. **は vs が 혼동**: 한국어 "이/가" 만 알면 일본어 진입 어려움. 주제/주어 구분이 필수.
2. **에 vs 에서 혼동 (に vs で)**: 한국어 "에/에서" 모두 "에" 또는 "에서" 로 통합. 일본어 に/で 구분.
3. **을/를 (를) 누락**: 한국어 원어민은 종종 를/을 생략. 일본어 を 는 필수.
4. **은/는 ↔ は**: 한국어 "은/는" 와 일본어 "は" 의 직접 대응. 한국어 "이/가" 와는 비대응.

## Ejemplos

«私は学生です» — 나는 학생입니다 (は = 주제).

«私が行きます» — 제가 갑니다 (が = 강조 / 정보).

«学校に行きます» — 학교**에** 갑니다 (に = 방향).

«図書館で勉強します» — 도서관**에서** 공부합니다 (で = 행동의 장소).

«9時から5時まで働きます» — 9시**부터** 5시**까지** 일합니다 (から/まで).

## Cross-language Connections

- **한국어**: 조사 ~30 종 (은/는, 이/가, 을/를, 에, 에서, 로/으로, 와/과, 만, 도, 처럼, 부터, 까지, 의 등). 일본어 조사 (9 종) 의 3배. 한국어 조사가 더 정교.
- **스페인어**: 전치사 (preposiciones) — a, de, en, con, por, para, sin 등 ~25 종. 일본어 / 한국어 조사와 다른 시스템.
- **영어**: 전치사 ~150 종 — 가장 많은 시스템. in / on / at / by / with / to / from / for / of 등.
