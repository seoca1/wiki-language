# 日本語助詞 — 9大核心助詞

**Type:** grammar
**Level:** JLPT N5-N4
**Date Added:** 2026-08-08

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 일본어 조사 9종 (は/が/を/に/で/へ/から/まで/より) — 한국어 조사(~8종)보다 정교함.
> - **한국어 차이:** 한국어는 단어 순서 + 조사로 명사 역할 표시, 일본어는 조사로 문법 관계(주제/주어/목적어/방향/수단/비교 등) 세분화.
> - **학습자 우선순위:** は vs が (가장 빈번) → に vs で (장소/방향) → を (목적어 필수) → へ/から/まで/より.
> - **한국어 학습자 주의:** 한국어 "이/가" 1종 vs 일본어 は/가 2종. 한국어 "에" 1개 vs 일본어 に/で 용법 분리. 한국어 "을/를" 생략 가능 vs 일본어 を 필수.

## 9 Core Particles

### 1. は (wa) — Topic / Contrast
- **Structure:** [Noun] + は
- **Usage:** Marks sentence topic (what the sentence is about); contrastive focus
- **Examples:**
  - 私は学生です。 — "I am a student." (topic)
  - 今日は休みます。 — "Today I rest." (contrast: other days I work)

### 2. が (ga) — Subject / Emphasis
- **Structure:** [Noun] + が
- **Usage:** Grammatical subject (esp. with intransitive verbs, adjectives of desire/ability); exhaustive listing ("it is X that...")
- **Examples:**
  - 私**が**行きます。 — "It is **I** who goes." (emphasis)
  - 水**が**飲みたい。 — "I want to drink **water**." (desire)

### 3. を (o) — Direct Object
- **Structure:** [Noun] + を
- **Usage:** Direct object of transitive verbs
- **Examples:**
  - 本**を**読みます。 — "Read **a book**."
  - ご飯**を**食べます。 — "Eat **rice**."

### 4. に (ni) — Multifunctional
- **Usages:**
  - **Direction/Goal:** 学校**に**行きます (go **to** school)
  - **Time point:** 3時**に**会いましょう (meet **at** 3)
  - **Indirect object:** 友達**に**あげます (give **to** friend)
  - **Existence location:** 部屋**に**猫がいます (cat is **in** room)
  - **Purpose (motion verb):** 買い物**に**行きます (go **for** shopping)

### 5. で (de) — Multifunctional
- **Usages:**
  - **Action location:** 図書館**で**勉強します (study **at** library)
  - **Means/Instrument:** バス**で**行きます (go **by** bus)
  - **Cause/Reason:** 病気**で**休みました (rested **due to** illness)
  - **Scope/Limit:** 3時間**で**終わります (finish **in** 3 hours)

### 6. へ (e) — Direction (Literary)
- **Structure:** [Noun] + へ (pronounced "e")
- **Usage:** Direction marker; literary variant of に for motion verbs
- **Example:** 京都**へ**行きます — "Go **to** Kyoto."

### 7. から (kara) — Source / Cause
- **Structure:** [Noun] + から
- **Usages:**
  - **Temporal/Spatial start:** 9時**から**始まります (starts **from** 9)
  - **Cause/Reason:** 風邪**から**治りました (recovered **from** cold)

### 8. まで (made) — Endpoint
- **Structure:** [Noun] + まで
- **Usage:** Temporal/spatial endpoint ("until", "up to")
- **Example:** 5時**まで**待ちます — "Wait **until** 5."

### 9. より (yori) — Comparison
- **Structure:** [Noun] + より
- **Usage:** Standard of comparison ("than")
- **Example:** 彼**より**背が高い — "Taller **than** him."

## Korean Learner Pitfalls

### 1. は vs が (Topic vs Subject)
- Korean "이/가" = 1 form, Japanese は/が = 2 forms.
- **は** = topic (old info), **が** = subject (new info, emphasis, exhaustive).
- "私は学生" (As for me, student) vs "私が学生" (It is I who am student).

### 2. に vs で (Location Particles)
- Korean "에" covers both; Japanese splits:
  - **に** = goal of motion / existence location / time point
  - **で** = location where action takes place
- 図書館**に**行く (go to library) vs 図書館**で**勉強する (study at library)

### 3. を Obligatory
- Korean drops 을/를 in casual speech; Japanese を is **always required** for transitive verbs.
- ❌ 本読みます → ✅ 本**を**読みます

### 4. へ vs に (Direction)
- **へ** = literary, emphasizes direction/destination
- **に** = neutral, also covers time, indirect object, purpose
- 京都**へ**行く (poetic) vs 京都**に**行く (neutral)

## Comparison Table (Korean ↔ Japanese)

| Korean | Japanese | Meaning |
|---|---|---|
| 이/가 (주격) | が (subject) / は (topic) | Subject marker |
| 을/를 (목적격) | を | Object marker |
| 에 (장소) | に (goal) / で (action loc.) | Location + direction |
| 에서 (행동처) | で | Action location |
| 로/으로 (방향/수단) | に / へ / で | Direction / means |
| 부터 (기점) | から | Start point |
| 까지 (종점) | まで | End point |
| 보다 (비교) | より | Comparison |
| 은/는 (대조) | は | Topic / contrast |
| 의 (소유) | の | Possessive |
| 와/과 (함께) | と | Together / and |

## Ejemplos

«私は日本人です。日本語**が**話せます。』 — Topic (wa) for self-intro, subject (ga) for ability.

«図書館**で**本**を**読みます。』 — Action location (de), object (o).

«三時**から**五時**まで**働きます。』 — Start (kara), end (made).

«彼**より**速いです。』 — Comparison (yori).

## Cross-language Connections

- **Korean:** 조사 (~8종) — 이/가, 을/를, 에, 에서, 로, 부터, 까지, 보다, 은/는, 의, 와/과
- **English:** Prepositions (to, at, in, on, by, from, until, than) + word order for subject/object
- **Spanish:** Preposiciones (a, en, por, para, de, desde, hasta, que) + case pronouns
- **Chinese:** 助词 — 了/过/着 (aspect), 的/地/得 (modification), 把/被 (voice), 比 (comparison)
- **Japanese uniqueness:** 조사 필수, 주제/주어 분리(は/が), 동작 장소/목적지 분리(で/に)
