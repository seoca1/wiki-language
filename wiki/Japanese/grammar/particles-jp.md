## Summary (개요)

日本語の助詞 (じょし, particles) は韓国語の 조사와 유사하지만 더 정교함. 한국어 조사 (~12종) vs 일본어 조사 (~50종). 핵심 9종 (は, が, を, に, で, へ, から, まで, より) 을 한국어 학습자 관점에서 정리. 한국어 학습자가 자주 혼동하는 は vs が, に vs で, を 생략 문제 등 포함.

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 일본어 조사 9종 (は/が/を/に/で/へ/から/まで/より) — 한국어 조사(~8종)보다 정교함.
> - **한국어 차이:** 한국어는 단어 순서 + 조사로 명사 역할 표시, 일본어는 조사로 문법 관계(주제/주어/목적어/방향/수단/비교 등) 세분화.
> - **학습자 우선순위:** は vs が (가장 빈번) → に vs で (장소/방향) → を (목적어 필수) → へ/から/まで/より.
> - **한국어 학습자 주의:** 한국어 "이/가" 1종 vs 일본어 は/가 2종. 한국어 "에" 1개 vs 일본어 に/で 용법 분리. 한국어 "을/를" 생략 가능 vs 일본어 を 필수.

## Key Takeaways (핵심 정리)

- **9 핵심 조사**: は, が, を, に, で, へ, から, まで, より
- **한국어 차이**: 한국어 조사 (~12종) vs 일본어 조사 (~50종) — 일본어가 더 정교
- **학습자 핵심 혼동**: は vs が (주제 vs 주어), に vs で (귀착점 vs 행동장소), を 생략 문제
- **한국어 대응**: は ↔ 은/는, が ↔ 이/가 (주어), を ↔ 을/를, に/で ↔ 에/에서, へ/に ↔ 에게/로, から ↔ 부터, まで ↔ 까지, より ↔ 보다

## 9 Core Particles (9대 핵심 조사)

### 1. は (wa) — 주제 / 대조 (Topic / Contrast)

- **Structure / 구조:** [Noun] + は
- **Usage / 용도:** Marks sentence topic (what the sentence is about); contrastive focus. 문장의 주제 표시 (전체 진술의 대상), 대조.
- **Examples / 예:**
  - 私は学生です。 — "I am a student." (topic) / "나는 학생입니다."
  - 今日は休みます。 — "Today I rest." (contrast: other days I work) / "오늘은 쉽니다."

### 2. が (ga) — 주어 / 강조 (Subject / Emphasis)

- **Structure / 구조:** [Noun] + が
- **Usage / 용도:** Grammatical subject (esp. with intransitive verbs, adjectives of desire/ability); exhaustive listing ("it is X that..."). 문법적 주어 (특히 목적어가 있을 때), 강조, 신체 욕구/능력 표현.
- **Examples / 예:**
  - 私**が**行きます。 — "It is **I** who goes." (emphasis) / "제가 갑니다."
  - 水**が**飲みたい。 — "I want to drink **water**." (desire) / "물**이** 마시고 싶다."

### 3. を (o) — 목적어 (Direct Object)

- **Structure / 구조:** [Noun] + を
- **Usage / 용도:** Direct object of transitive verbs. 타동사의 직접 목적어.
- **Examples / 예:**
  - 本**を**読みます。 — "Read **a book**." / "책**을** 읽습니다."
  - ご飯**を**食べます。 — "Eat **rice**." / "밥**을** 먹습니다."

### 4. に (ni) — 다기능 (Multifunctional)

- **Usages / 용도:**
  - **Direction/Goal / 방향/귀착점:** 学校**に**行きます (go **to** school) / 학교**에** 갑니다
  - **Time point / 시간:** 3時**に**会いましょう (meet **at** 3) / 3시**에** 만납시다
  - **Indirect object / 간접 목적자:** 友達**に**あげます (give **to** friend) / 친구**에게** 줍니다
  - **Existence location / 존재:** 部屋**に**猫がいます (cat is **in** room) / 방**에** 고양이가 있습니다
  - **Purpose (motion verb) / 목적(이동동사):** 買い物**に**行きます (go **for** shopping) / 쇼핑**하러** 갑니다

### 5. で (de) — 다기능 (Multifunctional)

- **Usages / 용도:**
  - **Action location / 행동의 장소:** 図書館**で**勉強します (study **at** library) / 도서관**에서** 공부합니다
  - **Means/Instrument / 수단:** バス**で**行きます (go **by** bus) / 버스**로** 갑니다
  - **Cause/Reason / 원인/이유:** 病気**で**休みました (rested **due to** illness) / 병**으로** 쉬었습니다
  - **Scope/Limit / 범위:** 3時間**で**終わります (finish **in** 3 hours) / 3시간**에** 끝납니다

### 6. へ (e) — 방향 (문어) / Direction (Literary)

- **Structure / 구조:** [Noun] + へ (pronounced "e")
- **Usage / 용도:** Direction marker; literary variant of に for motion verbs. 방향, に의 문어적 변형.
- **Example / 예:** 京都**へ**行きます — "Go **to** Kyoto." / "교토**로** 갑니다."

### 7. から (kara) — 출발 / 원인 (Source / Cause)

- **Structure / 구조:** [Noun] + から
- **Usages / 용도:**
  - **Temporal/Spatial start / 시간/장소 출발:** 9時**から**始まります (starts **from** 9) / 9시**부터** 시작
  - **Cause/Reason / 원인:** 風邪**から**治りました (recovered **from** cold) / 감기**에서** 나았습니다

### 8. まで (made) — 종점 (Endpoint)

- **Structure / 구조:** [Noun] + まで
- **Usage / 용도:** Temporal/spatial endpoint ("until", "up to"). 시간/공간의 끝 (한국어 "~까지").
- **Example / 예:** 5時**まで**待ちます — "Wait **until** 5." / "5시**까지** 기다립니다."

### 9. より (yori) — 비교 (Comparison)

- **Structure / 구조:** [Noun] + より
- **Usage / 용도:** Standard of comparison ("than"). 비교의 기준 (한국어 "~보다").
- **Example / 예:** 彼**より**背が高い — "Taller **than** him." / "그**보다** 키가 크다."

## Korean Learner Pitfalls (한국어 학습자 실수 패턴)

### 1. は vs が (Topic vs Subject)
- Korean "이/가" = 1 form, Japanese は/が = 2 forms.
- **は** = topic (old info), **が** = subject (new info, emphasis, exhaustive).
- "私は学生" (As for me, student) vs "私が学生" (It is I who am student).
- 한국어 "이/가" 와 일본어 "は/가" 의 비대응. 한국어는 1종 (이/가)인데 일본어는 주제/주어 2종.

### 2. に vs で (Location Particles)
- Korean "에" covers both; Japanese splits:
  - **に** = goal of motion / existence location / time point
  - **で** = location where action takes place
- 図書館**に**行く (go to library) vs 図書館**で**勉強する (study at library)
- 일본어 に vs で 의 한국어 대응 동일 ("에"). 맥락 의존.

### 3. を (o) 누락
- Korean drops 을/를 in casual speech; Japanese を is **always required** for transitive verbs.
- ❌ 本読みます → ✅ 本**を**読みます
- 韓国어에 목적격 조사 필수인데, 韓国어 원어민은 종종 를/을 생략. 일본어는 항상 を.

### 4. へ vs に (Direction)
- **へ** = literary, emphasizes direction/destination
- **に** = neutral, also covers time, indirect object, purpose
- 京都**へ**行く (poetic) vs 京都**に**行く (neutral)
- 문어 (へ) vs 중립 (에) — 방향 강조 시 に 대신 へ 사용 가능.

## Cross-Language Comparison (Korean ↔ Japanese)

| 한국어 | 日本語 | 의미 |
|---|---|---|
| 이/가 (주격) | が (subject) / は (topic) | 주어 표시 (Subject marker) |
| 을/를 (목적격) | を | 목적어 (Object marker) |
| 에 (장소) | に (goal) / で (action loc.) | 장소 + 방향 (Location + direction) |
| 에서 (행동처) | で | 동작의 장소 (Action location) |
| 로/으로 (방향/수단) | に / へ / で | 방향 / 수단 (Direction / means) |
| 부터 (기점) | から | 시작점 (Start point) |
| 까지 (종점) | まで | 종점 (End point) |
| 보다 (비교) | より | 비교 기준 (Comparison) |
| 은/는 (대조) | は | 주제 / 대조 (Topic / contrast) |
| 의 (소유) | の | 소유격 (Possessive) |
| 와/과 (함께) | と | 동격 / 함께 (Together / and) |

## Ejemplos (Ejemplos en español)

«私は日本人です。日本語**が**話せます。』 — Topic (wa) for self-intro, subject (ga) for ability.

«図書館**で**本**を**読みます。』 — Action location (de), object (o).

«三時**から**五時**まで**働きます。』 — Start (kara), end (made).

«彼**より**速いです。』 — Comparison (yori).

## Cross-language Connections (4개 언어 비교)

- **Korean:** 조사 (~8종) — 이/가, 을/를, 에, 에서, 로, 부터, 까지, 보다, 은/는, 의, 와/과
- **English:** Prepositions (to, at, in, on, by, from, until, than) + word order for subject/object
- **Spanish:** Preposiciones (a, en, por, para, de, desde, hasta, que) + case pronouns
- **Chinese:** 助词 — 了/过/着 (aspect), 的/地/得 (modification), 把/被 (voice), 比 (comparison)
- **Japanese uniqueness:** 조사 필수, 주제/주어 분리(は/が), 동작 장소/목적지 분리(で/に)
