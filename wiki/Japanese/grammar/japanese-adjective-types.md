# 形容詞の種類, い形容詞 vs な形容詞

**Type:** grammar
**Level:** JLPT N5-N4
**Date Added:** 2026-08-11

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 일본어 형용사는 2대류. い형용사(赤い/大きい) vs な형용사(綺麗だ/静かだ). 한국어 형용사(~다)는 1종류, 영어 형용사도 1종류. 일본어가 가장 정교함.
> - **한국어 차이:** 한국어 형용사는 "~다 / ~지 않다 / ~았다" 만 구분. 일본어는 형용사 종별(い/な) + 시제 + 정중도 별도 결합.
> - **학습자 우선순위:** い형용사 (빈도 高) → な형용사 (중간) → 불규칙 (良い/綺麗) → く/에 부사화. 特別(とくべつ)/大丈夫(だいじょうぶ) 등 な형용사 특수 case 외우기.
> - **한국어 학습자 주의:** 한국어 "예쁘다" 1종 vs 일본어 "綺麗だ" (な형용사, "綺麗"만으로는 문장 끝 못 만듦). 부사화 시 く vs え 구분.

---

## い形容詞 (I-adjectives / Keiyōshi)

### Structure
- Dictionary form ends in **-い** (preceded by -i syllable: あい/かい/さい/たい/ない/ばい/まい/らい/がい/ざい/だい)
- Conjugates by replacing final **-い** with: **-くない** (negative) / **-かった** (past) / **-くなかった** (past-negative)
- The **-い** itself becomes **-く** when adverbial: 美しい → 美しく
- Attaches directly to nouns: 赤い + 花 = 赤い花

### Examples
- 赤い (akai). Red. Dictionary 赤い / negative 赤くない / past 赤かった / adverb 赤く.
- 高い (takai). Tall, expensive. 高くない / 高かった / 高く.
- 美味しい (oishii). Delicious. 美味しくない / 美味しかった / 美味しく.

### Conjugation Pattern

| Form | Pattern | Example (高い) | Korean |
|---|---|---|---|
| 辞書形 (Dictionary) | 赤い | 高い (takai) | 높다 |
| 否定 (Negative) | 赤くない | 高くない (takanai) | 높지 않다 |
| 過去 (Past) | 赤かった | 高かった (takakatta) | 높았다 |
| 過去否定 (Past-Neg) | 赤くなかった | 高くなかった | 높지 않았다 |
| 副詞形 (Adverbial) | 赤く | 高く (takaku) | 높게 |
| 名詞修飾 (Noun-mod) | 赤い + N | 高い山 | 높은 산 |

## な形容詞 (Na-adjectives / Keiyōdōshi)

### Structure
- Dictionary form ends in **-だ** (e.g., 静かだ) or appears bare (e.g., 静か). The **だ** is dropped in casual speech and modified noun phrases.
- Conjugates: **-じゃない** (negative) / **-だった** (past) / **-じゃなかった** (past-negative)
- Adverbial form: replace **-だ** with **-に** (静かに)
- Attaches to nouns via **-な**: 静かな + 場所 = 静かな場所

### Examples
- 綺麗 (kirei). Beautiful, clean. 綺麗だ / 綺麗じゃない / 綺麗だった / 綺麗に.
- 静か (shizuka). Quiet. 静かだ / 静かじゃない / 静かだった / 静かに.
- 大丈夫 (daijōbu). Okay, safe. 大丈夫だ / 大丈夫じゃない / 大丈夫だった / 大丈夫に.

### Conjugation Pattern

| Form | Pattern | Example (静か) | Korean |
|---|---|---|---|
| 辞書形 (Dictionary) | 静かだ | 静かだ (shizuka da) | 조용하다 |
| 否定 (Negative) | 静かじゃない | 静かじゃない | 조용하지 않다 |
| 過去 (Past) | 静かだった | 静かだった | 조용했다 |
| 過去否定 (Past-Neg) | 静かじゃなかった | 静かじゃなかった | 조용하지 않았다 |
| 副詞形 (Adverbial) | 静かに | 静かに (shizuka ni) | 조용히 |
| 名詞修飾 (Noun-mod) | 静かな + N | 静かな部屋 | 조용한 방 |

## 不規則形容詞 (Irregular Adjectives)

### 良い (yoi / ii). Good
- **Special rule:** 良い has dictionary form **いい** (casual) or **良い** (yoi, written/keigo). Past = **よかった** (NOT いいかった). Negative = **よくない** (NOT いじない).
- 良いです (ii desu). 良いです follows the **よく + ある** pattern, not the regular い-arimasu.
- Pattern: when the 〜い ending is preceded by よ, the conjugation keeps **よ**: よい → よくない / よかった.

### 綺麗 (kirei). Beautiful, clean (looks like い-adj, actually な-adj)
- **Special case:** Ends in **-い** when written (綺麗**い**?), but it's a **な-adjective**. No final い exists in pronunciation (kirei). Conjugation follows な-adj pattern: 綺麗だ / 綺麗じゃない / 綺麗だった / 綺麗に.
- Same trap: 嫌い (kirai), 幸せ (shiawase), 立派 (rippa).

## Key Points

- **い形容詞** ends in **-い** (red い), drops final い for conjugation: 高い → 高くない / 高かった / 高く.
- **な形容詞** drops **-だ** for conjugation: 静かだ → 静かじゃない / 静かだった / 静かに.
- **不規則 良い** = いい + よくない / よかった (preserves **よ** stem).
- **綺麗 / 嫌い / 幸せ** look like い형용사 but are **な형용사** (dictionary ends with -i sound, conjugation follows な).
- **特別 (tokubetsu)** = special (な형용사). **本当 (hontō)** = true (な형용사). Both used with な before nouns.
- **Adverb transformation:** い형용사 → く (美しく); な형용사 → に (静かに).
- **Polite form:** い형용사 + です (高いです); な형용사 + です (静かです); plain だ form is the casual register.
- **Keigo note:** い형용사 can nominalize via さ suffix: 高**さ** (height), 美**しさ** (beauty). Honorific prefix お + い형용사 stem is standard: **お忙しい** (honorific, o-isogashii), **お優しい**. な형용사 with お is uncommon (avoid お静か).

## Korean Learner Pitfalls

### 1. 綺麗 = な形容사 (NOT い形容사)
- Spelling ends in い but it's **な-adj**. ❌ 綺麗**い** → ✅ 綺麗**な**.
- 綺麗な場所 (clean/beautiful place), not 綺麗い場所. Same for 嫌い (kirai = dislike, な형용사).

### 2. 良い past = よかった (NOT いいかった)
- ❌ いいかった → ✅ よかった.
- よい / いい / 良かった all share stem **よ**.

### 3. く vs に 부사화
- い형용사 → く (美しく歌う = sing beautifully).
- な형용사 → に (静かに歩く = walk quietly).
- ❌ 美しに → ✅ 美しく / ❌ 静か**く** → ✅ 静か**に**.

### 4. ~だ 脱落 (casual / Noun-modifier)
- な형용사 + だ 는 정중. Casual: 綺麗. 명사수식: 綺麗な + N. い형용사 never takes だ.
- ❌ 静か**なだ** → ✅ 静かな or 静かだ.

### 5. Korean "이다/아니다" 와 1:1 매칭 불가
- 한국어 "예쁘지 않다" ↔ 綺麗じゃない. 한국어 형용사 부정은 "지 않다" 1종, 일본어는 형용사 종별별로 어미 다름.
- 綺麗**じゃない** (な-neg) vs 赤い**くない** (い-neg).

## Cross-language Connections

- **Korean:** 형용사 (~다 / ~지 않다 / ~았다). 1종류, 종별 무관.
- **English:** Adjectives (big/bigger/biggest) with comparative/superlative. No conjugation for tense.
- **Spanish:** Adjetivos (alto/alta with gender agreement; bueno/mejor irregular). 종별 + 성별.
- **Chinese:** 形容词 (高/高**的** / 很高) using 的 before nouns. Adverb 很高地.
- **Japanese uniqueness:** い/な형용사 이분법 + 정중도 별도 결합. お + い형용사 stem honorific (お忙しい) is unique among the 5.

## Ejemplos

«この部屋**は静かです**。』, な형용사 정중 현재 (조용합니다).

«この部屋**は静かじゃないです**。』, な형용사 부정 정중 (조용하지 않습니다).

«昨日**は静かだった**です。』, な형용사 과거 (조용했습니다).

«この料理**は美味しいです**。』, い형용사 정중 현재 (맛있습니다).

«この料理**は美味しくない**です。』, い형용사 부정 (맛있지 않습니다).

«この料理**は美味しかった**です。』, い형용사 과거 (맛있었습니다).

«この部屋**に静かに**入ってください。』, 부사형 に (조용히).

«先生**の話し方**は美**しく**て、優**しく**て、丁寧**です**。』, 복수 い형용사 (아름답고, 친절하고, 정중합니다).

«今日**はいい天気**ですね。』, 不規則 良い (いい = 良い casual, NOT いいい).

«昨日の映画**は良かった**です。』, 不規則 過去 (좋았습니다, NOT いいかった).

«あの場所**は綺麗だった**です。』, 綺麗 = な형용사 과거 (아름다웠습니다).

«特別**な日**だから、綺麗**な服**を着たいです。』, な형용사 명사수식 (특별한 날, 아름다운 옷).
