## Summary

日本語の助詞 (じょし, particles) は韓国語の 조사와 유사하지만 더 정교함. 한국어 조사 (~12종) vs 일본어 조사 (~50종). 핵심 9종(は, が, を, に, で, へ, から, まで, より)을 한국어 학습자 관점에서 정리. 한국어 학습자가 자주 혼동하는 は vs が, に vs で, を 생략 문제 등 포함.

---

## Key Takeaways

- **9 핵심 조사**: は, が, を, に, で, へ, から, まで, より
- **한국어 차이**: 한국어 조사 (~12종) vs 일본어 조사 (~50종) — 일본어가 더 정교
- **학습자 핵심 혼동**: は vs が (주제 vs 주어), に vs で (귀착점 vs 행동장소), を 생략 문제
- **한국어 대응**: は ↔ 은/는, が ↔ 이/가 (주어), を ↔ 을/를, に/で ↔ 에/에서, へ/に ↔ 에게/로, から ↔ 부터, まで ↔ 까지, より ↔ 보다

## 9 Core Particles (9대 핵심 조사)

### 1. は (wa) — 주제 / 대조 (Topic Marker)
- **구조**: [명사] + は
- **용도**: 문장의 주제 표시 (전체 진술의 대상), 대조
- **예**: 私は学生です。(Watashi wa gakusei desu) = "나는 학생입니다." / 今日は休みます。(Kyō wa yasumimasu) = "오늘은 쉽니다."

### 2. が (ga) — 주어 / 강조 (Subject Marker)
- **구조**: [명사] + が
- **용도**: 문법적 주어 (특히 목적어가 있을 때), 강조, 신체 욕구/능력 표현
- **예**: 私**が**行きます。(Watashi ga ikimasu) = "제가 갑니다." / 水**が**飲みたい。(Mizu ga nomitai) = "물**이** 마시고 싶다."

### 3. を (o) — 목적어 (Object Marker)
- **구조**: [명사] + を
- **용도**: 타동사의 직접 목적어
- **예**: 本**を**読みます。(Hon o yomimasu) = "책**을** 읽습니다."

### 4. に (ni) — 다기능
- **용도**: 방향/귀착점, 시간, 간접 목적자, 존재, 목적(이동동사)
- **예**: 学校**に**行きます (학교**에** 갑니다), 3時**に**会いましょう (3시**에** 만납시다), 友達**に**プレゼントをあげます (친구**에게** 선물 줍니다)

### 5. で (de) — 다기능
- **용도**: 행동의 장소, 수단, 원인/이유, 범위
- **예**: 図書館**で**勉強します (도서관**에서** 공부합니다), バス**で**行きます (버스**로** 갑니다), 病気**で**休みました (병**으로** 쉬었습니다)

### 6. へ (e) — 방향 (문어)
- **구조**: [명사] + へ (발음 "에")
- **용도**: 방향, に의 문어적 변형
- **예**: 京都**へ**行きます (교토**로** 갑니다)

### 7. から (kara) — 출발 / 원인
- **구조**: [명사] + から
- **용도**: 시간/장소 출발, 원인
- **예**: 9時**から**始まります (9시**부터** 시작), 風邪**から**治りました (감기**에서** 나았습니다)

### 8. まで (made) — 종점
- **구조**: [명사] + まで
- **용도**: 시간/공간의 끝 (한국어 "~까지")
- **예**: 5時**まで**待ちます (5시**까지** 기다립니다)

### 9. より (yori) — 비교
- **구조**: [명사] + より
- **용도**: 비교의 기준 (한국어 "~보다")
- **예**: 彼**より**背が高い (그**보다** 키가 크다)

## Korean Learner Common Mistakes (한국어 학습자 실수 패턴)

1. **は vs が**: 韓国어 "이/가" 와 일본어 "は/가" 의 비대응. 한국어는 1종 (이/가)인데 일본어는 주제/주어 2종.
2. **に vs で**: 일본어 に vs で 의 한국어 대응 동일 ("에"). 맥락 의존.
3. **を (o) 누락**: 韓国어에 목적격 조사 필수인데, 韓国어 원어민은 종종 를/을 생략. 일본어는 항상 を.
4. **은/는 ↔ は**: 한국어 "은/는" (대조/주제) = 일본어 "は" (대조/주제). 직접 대응.

## Cross-Language Comparison (Korean ↔ Japanese)

| 한국어 | 日本語 | 의미 |
|---|---|---|
| 이/가 (주격) | が (subject) / は (topic) | 주어 표시 |
| 을/를 (목적격) | を | 목적어 |
| 에 (장소) | に (귀착점) / で (행동) | 장소 + 방향 |
| 에서 (행동) | で | 동작의 장소 |
| 로 / 으로 (방향) | に / へ | 방향 / 수단 |
| 부터 (시간) | から | 시간 출발 |
| 까지 (시간) | まで | 시간 종점 |
| 보다 (비교) | より | 비교 기준 |
| 은/는 (대조) | は | 주제 / 대조 |
| 의 (소유) | の | 소유격 |
| 와/과 (동반) | と | 동격 / 함께 |
