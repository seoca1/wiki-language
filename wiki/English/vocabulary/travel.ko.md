# Travel Essentials - 여행 필수 어휘 (Korean Translation)

**Source:** [[travel-basics]]
**Theme:** Travel & Tourism
**Level:** A1-A2

핵심 여행 어휘의 한국어 번역본. 공항, 호텔, 식당, 교통, 관광 등 여행의 기본 시나리오에서 자주 쓰이는 단어들.

---

## 공항 (Airport)

### 명사 (Nouns)

- **passport** (명사) — 여권 — 해외 여행 시 필요한 신분 증명서
- **ticket** (명사) — 티켓, 표 — 여행 교통편 이용권
- **boarding pass** (명사) — 탑승권 — 비행기 탑승 시 발행되는 권리
- **luggage / baggage** (명사) — 수하물 — 여행 시 휴대하는 짐
- **suitcase** (명사) — 여행가방 — 바퀴 달린 큰 가방
- **carry-on** (명사) — 기내 휴대품 — 기내로 가져가는 소형 짐
- **gate** (명사) — 탑승구 — 비행기 탑승 위치
- **terminal** (명사) — 터미널 — 공항 건물
- **runway** (명사) — 활주로 — 비행기 이착륙 길

### 동사 (Verbs)

- **check in** (동사) — 체크인하다 — 공항에서 탑승 수속
- **board** (동사) — 탑승하다 — 비행기/배에 타다
- **land** (동사) — 착륙하다 — 비행기가 도착하다
- **take off** (동사) — 이륙하다 — 비행기가 떠나다
- **arrive** (동사) — 도착하다 — 목적지에 닿다
- **depart** (동사) — 출발하다 — 떠나가다

## 호텔 (Hotel)

### 명사

- **reservation** (명사) — 예약 — 사전에 방을 잡는 것
- **reception** (명사) — 프론트 데스크 — 호텔 접수처
- **room** (명사) — 방 — 호텔 숙소
- **single room** (명사) — 1인실 — 한 사람이 묵는 방
- **double room** (명사) — 2인실 — 두 사람이 묵는 방
- **suite** (명사) — 스위트룸 — 고급 대형 객실
- **key card** (명사) — 키 카드 — 전자 도어락 열쇠
- **lobby** (명사) — 로비 — 호텔 입구 대기 공간
- **elevator** (명사) — 엘리베이터 (미국) — 승강기
- **lift** (명사) — 엘리베이터 (영국) — 승강기

### 동사

- **reserve / book** (동사) — 예약하다
- **check in** (동사) — 체크인하다 — 호텔 도착 시
- **check out** (동사) — 체크아웃하다 — 호텔 떠날 때
- **stay** (동사) — 묵다 — 호텔에 머물다

### 명사

- **menu** (명사) — 메뉴판 — 음식 목록
- **waiter / waitress** (명사) — 웨이터/여종업원 — 식당 직원

- **appetizer** (명사) — 전채 — 식사 전 가벼운 요리
- **main course** (명사) — 메인 요리 — 주식
- **dessert** (명사) — 디저트 — 식사 후 달콤한 요리
- **drink** (명사) — 음료 — 마실 것

### 동사

- **order** (동사) — 주문하다
- **recommend** (동사) — 추천하다
- **taste** (동사) — 맛보다 — 음식을 먹어보다
- **pay** (동사) — 지불하다 — 돈을 내다
- **split** (동사) — 나누다 — 계산서를 나누다

## 교통 (Transportation)

### 명사

- **subway** (명사) — 지하철 (미국) — 도시 지하철
- **metro** (명사) — 지하철 (유럽) — 도시 지하철
- **bus** (명사) — 버스 — 대중교통
- **taxi / cab** (명사) — 택시 — 유료 차량
- **train** (명사) — 기차 — 철도 교통
- **station** (명사) — 역 — 기차/지하철 정류장
- **stop** (명사) — 정류장 — 버스 정류장
- **ticket** (명사) — 표 — 교통 이용권
- **transfer** (명사) — 환승 — 다른 노선으로 갈아타기
- **platform** (명사) — 승강장 — 열차 승하차 위치

### 동사

- **ride** (동사) — 타다
- **drive** (동사) — 운전하다
- **walk** (동사) — 걷다
- **take** (동사) — (교통수단을) 타다
- **get on / get off** (동사) — 승하차하다
- **transfer** (동사) — 환승하다

## 방향 (Directions)

### 핵심 표현 (Key Phrases)

- **Where is...?** — ...는 어디에 있나요?
- **How do I get to...?** — ...에 어떻게 가나요?
- **Go straight** — 직진하세요
- **Turn left / right** — 좌회전/우회전하세요
- **on the left / right** — 왼쪽/오른쪽에
- **next to** — 옆에
- **across from** — 건너편에
- **between** — 사이에
- **near** — 가까이에
- **far** — 멀리

---

## 유용한 표현 (Useful Phrases)

- **Excuse me** — 실례합니다 (호출) — 사람 부를 때
- **How much?** — 얼마예요?
- **Where is the bathroom?** — 화장실 어디예요?
- **I don't understand** — 이해가 안 돼요
- **Could you help me?** — 도와주실 수 있나요?
- **Thank you** — 감사합니다
