# English Conditionals — 조건문 (0/1/2/3 + Mixed)

**Type:** grammar
**Level:** B1-B2 / CEFR
**Date Added:** 2026-08-11

> 🇰🇷 **한국어 요약 (Korean Summary)**
> - **핵심:** 영어 조건문 4 형 (0/1/2/3) + 혼합 조건 (mixed) + "unless / provided that" 접속사. if-절 시제 + 주절 시제 조합으로 16 가지 의미 매핑.
> - **한국어 차이:** 한국어 "-(으)면 / -다면 / -았/었으면" 으로 통합. 영어는 if-절 시제 고정 (Type 1 = present, Type 2 = past subjunctive) 으로 의미 구분.
> - **학습자 우선순위:** Type 1 (실제 가능) → Type 2 (비현실 현재) → Type 3 (과거 반사실) → Mixed (시제 교차).
> - **한국어 학습자 주의:** Type 2 의 "If I **were**" 는 현재 비현실 — 한국어 "-(이었)다면" + 현재 시제 결합. 한국어 "과거" 와 영어 "subjunctive" 가 다르다.

## Overview

English conditionals express cause-and-effect relationships between a condition (if-clause) and a result (main clause). There are four core types (0/1/2/3) defined by **the tense pattern in each clause**: Type 0 = general truth (present/present), Type 1 = real future (present/will), Type 2 = unreal present (past subjunctive/would), Type 3 = unreal past (past perfect/would have). The connection words **"unless"** (= if...not) and **"provided that"** (= if and only if) refine the condition logic. **Mixed conditionals** (Type 2/3 cross) express a present result from a past condition, or a past result from a present/standing condition.

## Key Points

- **Type 0** (general truth): if + present / present. "If you heat water to 100°C, it boils."
- **Type 1** (real future): if + present / will. "If it rains, I will stay home."
- **Type 2** (unreal present): if + past subjunctive / would. "If I **were** rich, I would travel the world." (were for all persons in formal style)
- **Type 3** (unreal past): if + past perfect / would have + p.p. "If I **had studied** harder, I **would have passed** the exam."
- **"unless"** = "if...not". "Unless you hurry, you will miss the train." (= "If you don't hurry...")
- **"provided that" / "providing that"** = "if and only if" (strict condition). "I will go **provided that** you go too."
- **Mixed conditional 2→3** (past condition → present result): "If I had studied medicine, I would be a doctor now."
- **Mixed conditional 3→2** (present condition → past result): "If I were braver, I would have spoken up."
- **"if" + will in clause** = polite request, NOT conditional: "If you will sign here, please." (modal willingness, not future)

## Cross-language Connections

- **스페인어**: 스페인어 조건문도 3 형 (real / improbable / impossible) + 접속법 (subjuntivo) 필수 — *Si tuviera dinero, viajaría* = "If I had money, I would travel" (Type 2). 스페인어 si + 접속법 시제 = 영어 if + 과거형 (subjunctive).
- **일본어**: 일본어 조건문은 **5 종 가정형** — ば/なら/と/たら/場合. たら ≈ Type 1, ば ≈ Type 1/2, なら ≈ arbitrary condition. 영어보다 접속사 종류 많음.
- **한국어**: 한국어 조건문은 2 종 — "-(으)면" (일반 조건, Type 1) + "-(으)라면" (반사실, Type 2/3). 영어 4 형 vs 한국어 2 종.
- **중국어**: 중국어 조건문 — 如果/要是 (Type 1) + 的话 (emphatic). 반사실은 "如果...就..." + 완료/과거 양상사. 영어 if 시제 매핑이 다르다.

## Examples

«If you mix red and blue, you get purple.» — Type 0 (불변의 진실) — 빨강과 파랑을 섞으면 보라색이 나온다.

«If I **see** her, I will tell her.» — Type 1 (실제 가능 미래) — 내가 그녀를 보면 말해 줄게.

«If I **were** you, I would apologize.» — Type 2 (현재 비현실) — 내가 너라면 사과할 텐데.

«If I **had known**, I would have called.» — Type 3 (과거 반사실) — 알았더라면 전화했을 텐데.

«Unless it stops raining, the picnic will be cancelled.» — unless = if...not — 비가 그치지 않으면 소풍은 취소된다.

«You can borrow the car **provided that** you return it by 6 PM.» — provided that = strict condition — 6 시까지 돌려주면 차를 빌려줄게.
