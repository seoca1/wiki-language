# English Articles Reference (a/an/the/zero)

**Source:** Murphy's English Grammar in Use (Unit 70-80) + Cambridge Grammar of English (synthesized reference)
**Type:** 문법 레퍼런스 (grammar reference)
**Theme:** 관사 (articles)
**Level:** A1-A2 / CEFR
**Created:** 2026-08-08

---

## Context

영어 관사는 한국어에 없는 문법 카테고리. 한국어는 단어 순서 + 조사로 명사의 역할 표시, 영어는 관사로 명사의 가변성 (불특정/특정) 표시.

핵심 구분:
1. **a/an** (불특정 단수) — 처음 언급, 1 개 + 비특정
2. **the** (특정 단복수) — 다시 언급, 유일, 맥락 특정
3. **zero article** (무관사) — 복수 일반화, 추상 명사, 고유명사 일부

한국어 학습자 가장 흔한 실수: 관사 누락 ("I have cat.") 또는 과잉 ("I have the cat." 한국어 "나는 고양이 한 마리 있어" 는 무관사).

---

## 1. a / an (불특정 단수관사)

### a vs an
- **a** + 자음 발음: a book, a cat, a university (uni- = /juː/, 발음이 모음이지만 자음 /j/ 로 시작)
- **an** + 모음 발음: an apple, an hour (silent h), an honest man

### 용도
- **처음 언급**: "I saw a dog in the park. The dog was black."
- **한 개의 비특정**: "I need an umbrella." (any one)
- **직업 / 신분**: "She is a doctor." "He is an engineer."
- **비율 / 단위**: "$5 a kilo" / "twice a week"

### 한국어 대응
- "a book" = "한 권의 책" 또는 "어떤 책" (불특정 단수)
- 한국어 조사 "가/이" 와 직접 대응 아님 — 한국어는 단수/복수 표시 없음

---

## 2. the (특정관사)

### 용도
- **재언급**: "I saw a dog. The dog was black."
- **유일 / 맥락 특정**: "the sun", "the president", "the book I gave you"
- **양쪽 다 알고 있음**: "Close the door." (문맥상 특정 문)
- **최상급**: "the tallest", "the most beautiful"
- **서수**: "the first", "the second"
- **악기**: "play the piano" (vs "play soccer" 무관사)
- **지리적 그룹**: "the Netherlands", "the Andes", "the Pacific Ocean"
- **고유명사 + of**: "the King of Spain"

### 한국어 대응
- "the book" = "그 책" (특정) 또는 "그것의 책" (관형절 의존)
- 한국어 "그/이" + 명사 = 영어 "the" 와 유사한 역할

---

## 3. Zero Article (무관사)

### 용도
- **복수 일반화**: "Dogs are loyal." (개라는 종 전체)
- **추상 명사**: "Love is important." "I like music."
- **고유명사 일부**: "John" / "Paris" / "Asia" (대륙, 도시는 무관사)
- **식사**: "have breakfast" / "have lunch" (vs "have a breakfast = 1번의 아침식사")
- **재료 / 스포츠**: "Gold is expensive." / "play tennis"
- **직접 목적어 동명사**: "I like swimming" (vs "I like the swimming you did")

### 한국어 대응
- "Dogs are loyal" = "개는 충성스럽다" (무관사 + 조사)
- 한국어 고유명사도 일반적으로 무관사 대응 ("파리" = Paris)

---

## 4. a/an vs the 결정 요약

| 상황 | 사용 |
|---|---|
| 처음 언급 (단수) | a/an |
| 재언급 | the |
| 양쪽 다 알고 있음 | the |
| 일반화 (단수) | a/an ("A dog is loyal") |
| 일반화 (복수) | zero ("Dogs are loyal") |
| 유일 존재 | the ("the sun") |
| 직업 / 역할 | a/an ("a doctor") |
| 고유명사 (도시, 국가) | zero ("Tokyo") |
| 지리적 그룹 | the ("the USA") |
| 최상급 | the ("the best") |

## 한국어 학습자 실수 패턴

1. **관사 누락**: "I have cat." → "I have a cat." / "I have cats."
2. **과잉 관사**: "I like the music" (특정 음악 아닌 일반 음악) → "I like music."
3. **a vs the 혼동**: "I read a book. The book was interesting." (재언급 = the)
4. **고유명사 오용**: "the Tokyo" (도시) → "Tokyo" / "the Tokyo station" (특정 역)
5. **식사**: "I have a breakfast" (특정 1번) vs "I have breakfast" (일반) — 둘 다 가능, 맥락 의존
