## Cultural Notes

- 日本はプロ野球(NPB)・Jリーグ・サッカーが盛ん
- 相撲は日本の国技(東京両国国技館)
- 武道: 柔道、空手、合気道がメジャー
- アニメ・マンガ: スポーツ漫画文化(『SLAM DUNK』『キャプテン翼』『ハイキュー!!』)
- 趣味多様化: キャンプ・登山・アニメ制作等
- ゴールデンウィーク/お盆/年末年始 = 旅行シーズン
- 日本の部活文化: 中学・高校の運動部

## Pronunciation Notes (発音変動ノート)

| Pattern | Example | Korean Learner Tip |
|---------|---------|-------------------|
| つ | つづく, つつみ | Tongue tip touches alveolar ridge |
| す | すき, すし | Tongue tip touches alveolar ridge |
| し | しずか, しんぶん | Palatal fricative (sounds like "shi") |
| ち | ちち, ちず | Palatal affricate (sounds like "chi") |
| じ | じてん, じんじ | Voiced palatal fricative (sounds like "ji") |
| づ | ずつ, ぶどう | Voiced alveolar stop + /tsu/ |
