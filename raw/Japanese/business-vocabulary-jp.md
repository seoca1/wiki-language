## 1. 이메일/서신 (Email/Correspondence)

| 한글 | 로마자 | 의미 |
| --- | --- | --- |
| 이메일 | メール (meeru) | email |
| 주소 | 住所 (じゅうしょ) | address |
| 보낸 사람 | 送信者 (そうしんしゃ) | sender |
| 받는 사람 | 受信者 (じゅしんしゃ) | recipient |
| 제목 | 件名 (けんめい) | subject |
| 첨부 | 添付 (てんぷ) | attachment |
| 보내다 | 送る (おくる) | send |
| 받다 | 受け取る (うけとる) | receive |
| 답장 | 返信 (へんしん) | reply |
| 저장 | 保存 (ほぞん) | save |
| 삭제 | 削除 (さくじょ) | delete |
