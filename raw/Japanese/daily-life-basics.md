## 1. 挨拶と一般的な表現 (Greetings & Common Phrases)

| 日本語 | 英語 | 韓国語 |
|---------|--------|--------|
| おはようございます | good morning | 좋은 아침입니다 |
| こんにちは | good afternoon | 안녕하세요 |
| こんばんは | good evening | 안녕하세요 (저녁) |
| おやすみなさい | good night | 안녕히 주무세요 |
| ありがとう | thank you | 감사합니다 |
| すみません | excuse me | 죄송합니다 |
| いただきます | (before eating) | 잘 먹겠습니다 |
| ごちそうさま | (after eating) | 잘 먹었습니다 |

## 7. 重要な表現 (Essential Phrases)

- ありがとうございます — thank합니다
- すみません — 죄송합니다
- いただきます — 잘 먹겠습니다
- ごちそうさまでした — 잘 먹었습니다
- おはようございます — 좋은 아침입니다
- はじめまして — 처음 뵙겠습니다
| よろしくお願いします — 잘 부탁합니다

## Pronunciation Notes (発音変動ノート)

| Pattern | Example | Korean Learner Tip |
|---------|---------|-------------------|
| つ | つづく, つつみ | Tongue tip touches alveolar ridge |
| す | すき, すし | Tongue tip touches alveolar ridge |
| し | しずか, しんぶん | Palatal fricative (sounds like "shi") |
| ち | ちち, ちず | Palatal affricate (sounds like "chi") |
| じ | じてん, じんじ | Voiced palatal fricative (sounds like "ji") |
| づ | ずつ, ぶどう | Voiced alveolar stop + /tsu/ |
