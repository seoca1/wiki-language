## Context

일본어 동사는 한국어보다 정교한 활용 (conjugation) 시스템 보유. 6 가지 기본 형식 + 다양한 파생:

- **辞書形** (じしょけい) — 사전형 / 원형
- **ます形** — 정중형 (공손체)
- **て形** — 접속 (te-form)
- **た形** — 과거형
- **ない形** — 부정형
- **意向形** — 의지/의도형

각 활용은 동사 그룹 (Group 1 五段, Group 2 一段, 不規則) 에 따라 다름.

---

## 3 그룹 분류

### Group 1: 五段動詞 (ごだんどうし, godan)
- 동사 어미가 う단 (단, 단 以外) 으로 끝남
- 5개 모음 (あ/い/う/え/お) 으로 활용
- 예: 書く (かく), 話す (はなす), 飲む (のむ), 作る (つくる), 泳ぐ (およぐ)

### Group 2: 一段動詞 (いちだんどうし, ichidan)
- 동사 어미가 -える 또는 -いる 으로 끝남 (단, える/いる 제외)
- 활용 시 -える/-いる 제거 + 새 어미 부착
- 예: 食べる (たべる), 見る (みる), 起きる (おきる), 寝る (ねる)

### 不規則動詞
- **する** (する → します, して, した, しない)
- **来る** (くる → きます, きて, きた, こない)

---

## 6 가지 기본 형식

### 1. 辞書形 (じしょけい, Dictionary Form) — 원형
- 사전에 등재된 형태
- Group 1: う단 그대로 (書く, 話す)
- Group 2: -える / -いる 그대로 (食べる, 起きる)
- 不規則: する, 来る

### 2. ます形 (Masu Form) — 정중형
- 日常 회화 / 정중한 맥락
- Group 1: う단 → い단 + ます
  - 書く → 書きます, 話す → 話します, 飲む → 飲みます
- Group 2: -える/-いる → -ます
  - 食べる → 食べます, 起きる → 起きます
- 不規則: する → します, 来る → 来ます

### 3. て形 (Te Form) — 접속
- 연속동작, 요청, 진행형
- Group 1: う단 → って / んで / いて / いで / して (발음 규칙)
  - 書く → 書いて, 話す → 話して, 飲む → 飲んで, 作る → 作って
- Group 2: -える/-いる → -て
  - 食べる → 食べて, 起きる → 起きて
- 不規則: する → して, 来る → 来て

### 4. た形 (Ta Form) — 과거형
- て형 + た = 과거
- Group 1: う단 → った / んだ / いた / いだ / した
  - 書いた, 話した, 飲んだ
- Group 2: -える/-いる → -た
  - 食べた, 起きた

### 5. ない形 (Nai Form) — 부정형
- 한국어 "~안 하다" 대응
- Group 1: う단 → あ단 + ない
  - 書く → 書かない, 話す → 話さない, 飲む → 飲まない
- Group 2: -える/-いる → -ない
  - 食べる → 食べない, 起きる → 起きない

### 6. 意向形 (Ikō Form) — 의지 / 의도
- "~하자", "~할 거야"
- Group 1: う단 → おう단
  - 書く → 書こう, 話す → 話そう, 飲む → 飲もう
- Group 2: -える/-いる → -よう
  - 食べる → 食べよう, 起きる → 起きよう

## Group 1 어미 변화 (음운 변화 표)

| 사전형 (う단) | て/た형 | ない형 | 意向形 | 예 |
|---|---|---|---|---|
| う / く / ぐ | って / いで | わない / がない | おう | 書く → 書いて |
| す | して | さない | そう | 話す → 話して |
| む / ぶ / ぬ | んで | まない / ばない / な | もう | 飲む → 飲んで |
| る / つ | って | らない / たない | ろう | 作る → 作って |

## 활용 예시 (飲む = to drink)

| 형식 | 형태 | 한국어 의미 |
|---|---|---|
| 사전형 | 飲む | 마시다 |
| ます형 | 飲みます | 마십니다 |
| て형 | 飲んで | 마시고 |
| た형 | 飲んだ | 마셨다 |
| ない형 | 飲まない | 마시지 않다 |
| 意向形 | 飲もう | 마시자 |

| ます형 | 食べます | 먹습니다 |
| て형 | 食べて | 먹고 |
| た형 | 食べた | 먹었다 |
| ない형 | 食べない | 먹지 않다 |

## 한국어 학습자 주의

1. **존댓말 (ます형) 기본**: 한국어 "습니다/~습니다" 와 유사하지만 ます형은 동사 자체의 형식 (시제 / 부정 별도).
2. **て형 활용**: 한국어 "-아/어" 와 유사하지만 더 다양한 파생 (진행 / 요청 / 연속).
3. **음운 변화 (음독)**: Group 1 동사는 발음 규칙에 따라 て형 달라짐. 외울 필요 있음.
4. **불규칙 동사 (する / 来る)**: Group 2 와 비슷해 보이지만 활용이 다름. 개별 외우기.
