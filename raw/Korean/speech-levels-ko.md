## Context

한국어는 화자-청자 관계에 따라 동사 어미가 변하는 **경어법** 보유. 일본어 の敬語 (keigo) 와 비슷하지만 더 체계적이고 필수적.

4 대 격식 (격식체):
1. **합쇼체** (합쇼합니다, formal) — 공식 / 비즈니스
2. **해요체** (해요, polite) — 일상 존댓말
3. **해체** (한다, plain) — 친구 / 가족
4. **하소서체** (하옵니다, literary) — 매우 격식적 / 문어

각 격식은 동사 어미 변화 + 조사 (이/가, 은/는, 을/를) 변화.

---

## 4 대 격식 체계

### 1. 합쇼체 (Formal — 격식체)
- **용도**: 비즈니스, 공식 발표, 뉴스, 군대
- **종결 어미**: -(으)ㅂ니다 / -습니다
- **연결 어미**: -고 / -며 / -아서 (격식 유지)
- **예**:
  - "저는 학생**입니다**." (I am a student — formal)
  - "회의를 시작하**겠습니다**." (Let me begin the meeting)
  - "결과를 보고하**였습니다**." (I reported the result)
  - "내일 또 만나**겠습니**다." (We'll meet again tomorrow)

### 2. 해요체 (Polite — 일상 존댓말)
- **용도**: 일상 대화 (친구 부모, 직장 상사,陌生人), 일반 TV
- **종결 어미**: -아/어요 / -어요 / -이에요/예요
- **연결 어미**: -고 / -면서 / -아서 (같은 격식)
- **예**:
  - "저는 학생**이에요**." (I am a student — polite)
  - "회의를 시작할게**요**." (Let me begin the meeting)
  - "밥 먹었**어요**?" (Have you eaten? — polite question)
  - "날씨가 좋**네요**." (Nice weather, isn't it?)

### 3. 해체 (Plain — 반말)
- **용도**: 친구, 가족, 동생, 자기 일기 / 메모
- **종결 어미**: -는다 / -다 / -아/어 / -(느)ㄴ다 / -냐 / -지
- **연결 어미**: -고 / -면서 / -아서
- **예**:
  - "나는 학생**이다**." (I am a student — plain)
  - "회의를 시작**하자**." (Let's begin the meeting)
  - "밥 먹었**어**?" (Have you eaten? — plain question)
  - "날씨가 좋**다**." (The weather is good)

### 4. 하소서체 (Literary — 문어)
- **용도**: 매우 격식적 문어, 기도, 고문서 (현대 한국어에서는 거의 사용 안 함)
- **종결 어미**: -옵 / -사옵 / -나이다 / -습니다 (특수)
- **예**:
  - "저**옵**은 학생이옵니다." (I, formally, am a student)
  - "회의를 시작하겠**사옵니**다." (We shall begin the meeting)

## 시제 + 경어 결합

각 격식은 과거/현재/미래 시제 결합:

### 현재 + 합쇼체
- "학생**입니다**" (am)

### 과거 + 합쇼체
- "학생**이었습니다**" (was)

### 미래 + 합쇼체
- "학생**이겠습니다**" (will be)

### 현재 + 해요체
- "학생**이에요**" (am)

### 과거 + 해요체
- "학생**이었어요**" (was)

### 미래 + 해요체
- "학생**이겠어요**" (will be)

### 현재 + 해체
- "학생**이다**" (am)

### 과거 + 해체
- "학생**이었다**" (was)

### 미래 + 해체
- "학생**이겠다**" (will be)

## 인사말 격식 (인사 = ㄹ 불규칙 활용)

| 격식 | 인사 (현재) | 인사 (과거) |
|---|---|---|
| 합쇼체 | 인사**합니다** | 인사**했습니다** |
| 해요체 | 인사**해요** | 인사**했어요** |
| 해체 | 인사**한다** | 인사**했다** |

동사 원형 + 각 격식 어미. "인사하다" 의 활용.

## 한국어 학습자 주의

1. **격식 선택 필수**: 한국어는 거의 모든 문장에서 화자-청자 관계 명시. 잘못된 격식은 무례 / 부자연스러움.
2. **해요체 기본**: 대부분의 외국인 학습자는 해요체로 충분. 합쇼체는 비즈니스 / 격식.
3. **해체 (반말) 조심**: 친한 사이 또는 어린 자녀에게만. 처음 보는 사람에게 해체 사용 = 매우 무례.
4. **음성 변화**: "습니다" 의 연속 발음 "슴니" (발음 자연스러움) vs "습니 다" (부자연).
5. **종결 어미 일관성**: 한 문장 안에서 같은 격식 유지. 격식 혼용 = 부자연 / 촌스러움.

## 비교 표 (일본어 경어 ↔ 한국어 경어)

| 상황 | 日本語 | 한국어 |
|---|---|---|
| 비즈니스 | 敬語 (です/ます) | 합쇼체 (입니다/습니다) |
| 일상 존댓말 | 普通語 (です/ます) | 해요체 (이에요/해요) |
| 친구 / 가족 | 常体 (だ / 食べる) | 해체 (이다 / 먹다) |
| 격식 문어 | 丁重語 / 謙譲語 | 하소서체 (옵/사옵니다) |
