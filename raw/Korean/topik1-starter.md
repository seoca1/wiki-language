# TOPIK 1 Starter Vocabulary

> **상태**: 골격. Phase 6에서 본격 확장.
> **출처**: 국립국어원 표준국어대사전, TOPIK 1급 기출 어휘 목록 (https://www.topik.go.kr)
> **라이선스**: 사실/언어 자체는 저작권 없음. 학습 목적 fair use.

## 학습 순서 권장

1. 인사 (Greetings)

## 발음 변동 노트 (한국어 입력 시 주의)

| 패턴 | 예시 | 입력 시 주의 |
| --- | --- | --- |
| ㄷ + ㅣ/ㅕ → ㅊ | 같이 → gachi | ㄷㄷ가 아니라 ㅊ |
| ㅂ + ㄴ → ㅁ | 감사합니다 → gamsahamnida | 합ㄴ → 함 |
| ㅎ + 모음 → 모음 | 좋아요 → joayo | ㅎ 생략 |
| ㅅ + ㅇ → ㄴ | 있어요 → isseoyo (실제 표기는 isseoyo) | ㅅㅇ → ㅆ + ㅇ (ㅂ+ㅅ→ㅆ) |
| ㄱ + ㄴ/ㅁ/ㄹ → ㅇ | 한국 → hangug | 받침 연음 |
| ㄹ + 모음 → ㄹㄹ (격음) | 사람 → salam (ㅅ+ㅏ→ㅅㅏ) | ㄹㄹ 발음되지만 표기는 salam |
