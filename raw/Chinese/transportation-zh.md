## 6. 한국어와 차이점 (Key Differences for Korean Learners)

### 1. "타다" = 坐 (zuò) — "앉다" 의미 확장
| 한국어 | 중국어 | 비고 |
|--------|--------|------|
| 버스 타다 | 坐公交车 | 坐 = 앉다 → 타다 확장 |
| 지하철 타다 | 坐地铁 | |
| 택시 타다 | 坐出租车 | |
| 비행기 타다 | 坐飞机 | |
| 기차 타다 | 坐火车 | |

> **핵심**: 한국어 "타다" = 중국어 坐 (zuò) "앉다" → 교통수단 이용 시 "앉다" 의미 확장

### 2. "오르다/타다" = 上车 (shàng chē) / 下车 (xià chē)
| 한국어 | 중국어 | 비고 |
|--------|--------|------|
| 차 타다/오르다 | 上车 (shàng chē) | 上 (오르다) + 车 |
| 차 내리다 | 下车 (xià chē) | 下 (내리다) + 车 |

### 3. "운전하다" = 开车 (kāi chē)
- 开 (kāi) = 열다, 작동시키다, 운전하다
- 开车 (kāi chē) = 운전하다 / 차를 몰다
- 我会开车 (wǒ huì kāi chē) — 저는 운전할 줄 알아요

### 4. 주차/정차
| 한국어 | 중국어 | 비고 |
|--------|--------|------|
| 주차하다 | 停车 (tíng chē) | 停 (멈추다) + 车 |
| 정차하다 | 停车 (동일) | 정차도 停车 |
| 주차장 | 停车场 (tíng chē chǎng) | 停车 + 场 |

### 5. 환승 = 换乘 (huàn chéng)
- 换 (huàn) = 바꾸다, 교환하다
- 乘 (chéng) = 타다
- 换乘 (huàn chéng) = 갈아타다/환승하다
- 换乘站 (huàn chéng zhàn) = 환승역

### 6. 표/티켓 관련
| 한국어 | 중국어 | 비고 |
|--------|--------|------|
| 표/티켓 | 票 (piào) | 비행기표=机票, 기차표=火车票 |
| 표 사다 | 买票 (mǎi piào) | 买 (사다) + 票 |
| 표 예약하다 | 订票 (dìng piào) / 预约 (yù yuē) | 订 = 예약하다 |
| 왕복표 | 往返票 (wǎng fǎn piào) | 往返 = 왕복 |
| 편도표 | 单程票 (dān chéng piào) | 单程 = 편도 |

### 7. 거리/시간 단위
| 한국어 | 중국어 | 비고 |
|--------|--------|------|
| 미터 | 米 (mǐ) | meter |
| 킬로미터 | 公里 (gōng lǐ) | kilometer (公共+里) |

## 7. 한국어 학습자 필수 팁 (Key Tips for Korean Learners)

### 1. 坐 (zuò) = "앉다" → "타다" 확장
- 한국어 "타다" = 중국어 坐 (zuò) "앉다" 의미 확장
- 坐车 (zuò chē) = 차 타다, 坐飞机 (zuò fēi jī) = 비행기 타다

### 2. 上车 (shàng chē) / 下车 (xià chē) — 오르다/내리다
- 上 (shàng) = 오르다, 위
- 下 (xià) = 내리다, 아래
- 车 (chē) = 차

### 3. 换乘 (huàn chéng) = 환승
- 换 (huàn) = 바꾸다
- 乘 (chéng) = 타다
- 换乘站 (huàn chéng zhàn) = 환승역

### 4. 票 (piào) = 표/티켓 — 카운터 张 (zhāng) 필수
- 一张票 (yī zhāng piào) — 표 한 장
- 两张票 (liǎng zhāng piào) — 표 두 장

### 4. 거리/시간 표현
- 公里 (gōng lǐ) = 킬로미터
- 米 (mǐ) = 미터
- 小时 (xiǎo shí) = 시간 (단위)
- 分钟 (fēn zhōng) = 분 (시간 단위)

## 8. 한국어 학습자 주의 (Pitfalls)

| 실수 | 올바른 표현 | 설명 |
|------|-------------|------|
| 버스 타다 | 坐公交车 (O) / 乘公交车 (△) | 坐 표준, 乘 = 격식/문어 |
| 차 타다 | 上车 (O) / 坐车 (△) | 上车 = 오르다/타다 (동작), 坐车 = 차 타다 (상태) |
| 차에서 내리다 | 下车 (O) / 下了车 (△) | 下车 단독으로 완료 표현 |
| 운전해요 | 开车 (O) / 驾车 (△) | 开车 일상 표준, 驾车 = 격식/문어 |
| 주차해요 | 停车 (O) / 停车 (동일) | 주차/정차 동일 |
| 표 한 장 | 一张票 (O) / 一票 (X) | 个/장 필수: 张 (zhāng) |
| 왕복표 | 往返票 (O) / 来回票 (△) | 往返 = 왕복 표준 |
| 환승해요 | 换乘 (O) / 换车 (△) | 换乘 = 정식 용어, 换车 = 차 바꾸다 |

## 9. 필수 문장 패턴 (Essential Sentence Patterns)

### 길 찾기/교통
- 请问，去机场怎么走? — 공항 어떻게 가요?
- 坐几路公交车? — 몇 번 버스 타요?
- 换乘站在哪里? — 환승역 어디예요?
- 请买一张去北京的票 — 베이징 가는 표 한 장 주세요
- 往返票多少钱? — 왕복표 얼마예요?

### 교통수단 이용
- 我坐地铁去公司 — 저는 지하철로 회사 가요
- 请开车送我去车站 — 차 태워 역까지 데려다 주세요
- 我要下车 — 저 내리겠어요
- 这里停车吧 — 여기 세워주세요

### 길 안내
- 直走 — 직진하세요
- 左转 — 왼쪽으로 도세요
- 右转 — 오른쪽으로 도세요
- 掉头 — 유턴하세요
- 过马路 — 길 건너세요

## 10. 한국어 학습자 주의 (Pitfalls)

| 실수 | 올바른 표현 | 설명 |
|------|-------------|------|
| 버스 타다 | 坐公交车 (O) | 坐 = 앉다 → 타다 확장 |
| 차 타다 | 上车 (O) | 上 = 오르다, 车 = 차 |
| 차 내리다 | 下车 (O) | 下 = 내리다 |
| 운전하다 | 开车 (O) | 开 = 열다/작동하다 |
| 주차하다 | 停车 (O) | 停 = 멈추다 |
| 환승하다 | 换乘 (O) | 换(바꾸다) + 乘(타다) |
| 표 한 장 | 一张票 (O) | 张 (zhāng) 카운터 필수 |
| 왕복표 | 往返票 (O) | 往返 = 왕복 |
