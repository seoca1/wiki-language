## 7. 한국어와 차이점 (Key Differences for Korean Learners)

### 1. 방향어 순서 (Direction Word Order)
| 한국어 | 중국어 | 비고 |
|--------|--------|------|
| 동쪽 | 东边 (dōng biān) | 방향 + 边 (쪽) |
| 앞쪽 | 前边 (qián biān) | 前 (앞) + 边 |
| 왼쪽 | 左边 (zuǒ biān) | 左 (왼쪽) + 边 |
| 안쪽 | 里边 (lǐ biān) / 里面 (lǐ miàn) | 里 (안) + 边/面 |

### 2. 방향 동사 — 한국어와 어순 차이
| 한국어 | 중국어 | 비고 |
|--------|--------|------|
| 왼쪽으로 가다 | 左转 (zuǒ zhuǎn) | 왼쪽 + 돌다 (turn left) |
| 오른쪽으로 가다 | 右转 (yòu zhuǎn) | 오른쪽 + 돌다 |
| 직진하다 | 直走 (zhí zǒu) | 직진 + 걷다 |
| 유턴하다 | 掉头 (diào tóu) | 머리 돌리다 = 유턴 |

> **핵심**: 중국어 "좌회전" = 左转 (왼쪽+돌다), 한국어 "왼쪽으로 가다"와 어순 다름

### 3. 위치어 + 边/面 (Position + Side/Surface)
| 한국어 | 중국어 (边) | 중국어 (面) | 비고 |
|--------|-------------|-------------|------|
| 위 | 上边 (shàng biān) | 上面 (shàng miàn) | 边=쪽, 面=면/표면 |
| 아래 | 下边 (xià biān) | 下面 (xià miàn) | |
| 앞 | 前边 (qián biān) | 前面 (qián miàn) | |
| 뒤 | 后边 (hòu biān) | 后面 (hòu miàn) | |
| 왼쪽 | 左边 (zuǒ biān) | 左面 (zuǒ miàn) | 左面 덜 사용 |
| 오른쪽 | 右边 (yòu biān) | 右面 (yòu miàn) | |
| 안 | 里边 (lǐ biān) | 里面 (lǐ miàn) | 里面 더 일반적 |
| 밖 | 外边 (wài biān) | 外面 (wài miàn) | 外面 더 일반적 |

### 4. 방향 동사 + 来/去 (Directional Complements)
| 패턴 | 예시 | 의미 |
|--------|--------|------|
| 동사 + 来 | 进来 (jìn lái) | 들어오다 |
| 동사 + 去 | 进去 (jìn qù) | 들어가다 |
| 동사 + 上 | 走上 (zǒu shàng) | 위로 올라가다 |
| 동사 + 下 | 走下 (zǒu xià) | 아래로 내려가다 |
| 동사 + 回 | 回来 (huí lái) | 돌아오다 |
| 동사 + 过 | 过去 (guò qù) | 지나가다 |

## 8. 필수 문장 패턴 (Essential Sentence Patterns)

### 길 묻기/가르쳐주기
- 请问，去机场怎么走? — 공항 어떻게 가요?
- 去火车站怎么走? — 기차역 어떻게 가요?
- 请问，最近的地铁站在哪儿? — 근처 지하철역 어디예요?

### 길 안내하기
- 直走 — 직진하세요
- 左转 — 왼쪽으로 도세요
- 右转 — 오른쪽으로 도세요
- 掉头 — 유턴하세요
- 直走然后左转 — 직진하다가 왼쪽으로
- 红绿灯左转 — 신호등에서 왼쪽으로
- 十字路口右转 — 사거리에서 오른쪽으로

### 위치 확인
- 这里对吗? — 여기가 맞아요?
- 这里是... — 여기가 ~예요
- 在...前面 — ~앞에 있어요
- 在...后面 — ~뒤에 있어요
- 在...旁边 — ~옆에 있어요
- 在...对面 — ~건너편에 있어요
- 在...附近 — ~근처에 있어요

### 위치 묘사
- 书在桌子上面 — 책이 책상 위에 있어요
- 球在箱子里面 — 공이 상자 안에 있어요
- 猫在椅子下面 — 고양이가 의자 아래에 있어요
- 学校在公园旁边 — 학교가 공원 옆에 있어요
- 银行在超市对面 — 은행이 슈퍼마켓 건너편에 있어요

### 방향 지시
- 往左走 — 왼쪽으로 가세요
- 往右走 — 오른쪽으로 가세요
- 直走 — 직진하세요
- 掉头 — 유턴하세요
- 往回走 — 되돌아 가세요
- 往前走 — 앞으로 가세요
- 往后退 — 뒤로 가세요

## 9. 한국어 학습자 필수 팁 (Key Tips for Korean Learners)

### 1. 边 (biān) vs 面 (miàn)
- 边 (biān) = "쪽", "가장자리" — 방향/위치 강조
- 面 (miàn) = "면", "표면" — 공간/면적 강조
- 上边/上面, 下边/아래면, 前边/앞면, 后边/뒷면 — 둘 다 가능
- 里边/里面 (안쪽), 外边/外面 (바깥쪽) — 面 더 일반적

### 2. 방향 동사 + 来/去 (Directional Complements)
- 来 (lái) = 화자 쪽으로 / 이쪽으로
- 去 (qù) = 화자 반대쪽으로 / 저쪽으로
- 上来 (shàng lái) = 올라오다 / 上去 (shàng qù) = 올라가다
- 下来 (xià lái) = 내려오다 / 下去 (xià qù) = 내려가다
- 回来 (huí lái) = 돌아오다 / 回去 (huí qù) = 돌아가다

### 3. 방향 지시 — 한국어와 어순 차이
| 한국어 | 중국어 | 비고 |
|--------|--------|------|
| 왼쪽으로 가다 | 左转 (zuǒ zhuǎn) | 왼쪽 + 돌다 |
| 오른쪽으로 가다 | 右转 (yòu zhuǎn) | 오른쪽 + 돌다 |
| 직진하다 | 直走 (zhí zǒu) | 직진 + 걷다 |
| 유턴하다 | 掉头 (diào tóu) | 머리 돌리다 |

### 4. 위치어 + 在 (zài) 패턴
- 在 + 위치어 + 边/面
- 书在桌子上 (책이 책상 위에 있다)
- 猫在椅子下 (고양이가 의자 아래에 있다)
- 学校在公园旁 (학교가 공원 옆에 있다)

## 9. 한국어 학습자 필수 팁 (Key Tips)

### 1. 边 (biān) vs 面 (miàn)
- 边 = "쪽/가장자리" (방향성)
- 面 = "면/표면" (공간성)
- 里边/里面 — 面 더 일반적 (안쪽)
- 外边/外面 — 面 더 일반적 (바깥쪽)

### 2. 방향 보어 (Directional Complements) 필수
- 来 (lái) = 이쪽으로 (화자 방향)
- 去 (qù) = 저쪽으로 (화자 반대)
- 上来/上去, 下来/下去, 进来/进去, 回来/回去, 过来/过去

### 3. 방향 지시 어순 차이
- 한국어: "왼쪽으로 가다" (방향 + 가다)
- 중국어: "左转" (왼쪽 + 돌다) — "돌다" 중심

### 4. 直走 (zhí zǒu) = 직진
- 直 (곧게) + 走 (걷다/가다)
- 直走别转 — 직진하세요, 돌지 마세요

### 5. 掉头 (diào tóu) = 유턴
- 掉 (돌리다/떨어뜨리다) + 头 (머리)
- "머리를 돌리다" = 유턴하다

## 10. 한국어 학습자 주의 (Pitfalls)

| 실수 | 올바른 표현 | 설명 |
|------|-------------|------|
| 왼쪽으로 가세요 | 左转 (O) / 往左走 (△) | 左转 = 좌회전 표준 |
| 오른쪽으로 가세요 | 右转 (O) | 右转 = 우회전 표준 |
| 직진하세요 | 直走 (O) / 往直走 (X) | 直走 단독 사용 |
| 유턴하세요 | 掉头 (O) / 掉头 (동일) | 掉头 = 유턴 표준 |
| 왼쪽에 있어요 | 在左边 (O) / 在左面 (△) | 边 더 자연스러움 |
| 안에 있어요 | 在里面 (O) | 里面 > 里边 (일반적) |
| 앞에 있어요 | 在前面 (O) | 前面 > 前边 (일반적) |
