## 6. 의료 표현/문장 (Medical Expressions/Sentences)

### 증상 말하기
- 我头疼 (wǒ tóu téng) — 머리가 아파요
- 我发烧了 (wǒ fā shāo le) — 열이 나요
- 我感冒了 (wǒ gǎn mào le) — 감기 걸렸어요
- 我咳嗽 (wǒ ké sou) — 기침해요
- 我肚子疼 (wǒ dù zi téng) — 배가 아파요
- 我嗓子疼 (wǒ sǎng zi téng) — 목이 아파요
- 我牙疼 (wǒ yá téng) — 이가 아파요
- 我眼睛疼 (wǒ yǎn jing téng) — 눈이 아파요
- 我耳朵疼 (wǒ ěr duo téng) — 귀가 아파요
- 我腰疼 (wǒ yāo téng) — 허리가 아파요
- 我腿疼 (wǒ tuǐ téng) — 다리가 아파요
- 我全身疼 (wǒ quán shēn téng) — 온몸이 아파요
- 我感到恶心 (wǒ gǎn dào è xīn) — 메스꺼워요
- 我想吐 (wǒ xiǎng tǔ) — 토할 것 같아요
- 我拉肚子 (wǒ lā dù zi) — 설사해요
- 我便秘 (wǒ biàn mì) — 변비예요
- 我过敏了 (wǒ guò mǐn le) — 알레르기 생겼어요

### 병원에서
- 我要看病 (wǒ yào kàn bìng) — 진찰받고 싶어요
- 请给我开点药 (qǐng gěi wǒ kāi diǎn yào) — 약 좀 지어주세요
- 这个药怎么吃? (zhè ge yào zěn me chī?) — 이 약 어떻게 먹어요?
- 一天吃几次? (yī tiān chī jǐ cì?) — 하루에 몇 번 먹어요?
- 饭前吃还是饭后吃? (fàn qián chī hái shì fàn hòu chī?) — 식전/식후에 먹어요?
- 我对药过敏 (wǒ duì yào guò mǐn) — 약 알레르기 있어요
- 我要打针 (wǒ yào dǎ zhēn) — 주사 맞고 싶어요
- 我要输液 (wǒ yào shū yè) — 링거 맞고 싶어요 (수액)
- 我要住院 (wǒ yào zhù yuàn) — 입원하고 싶어요
- 我要做手术 (wǒ yào zuò shǒu shù) — 수술하고 싶어요

### 약국에서
- 买点感冒药 (mǎi diǎn gǎn mào yào) — 감기약 좀 사주세요
- 买点止痛药 (mǎi diǎn zhǐ tòng yào) — 진통제 좀 사주세요
- 买点创可贴 (mǎi diǎn chuāng kě tiē) — 반창고 좀 사주세요
- 买点碘伏 (mǎi diǎn diàn fú) — 소독약(포비돈) 좀 사주세요
- 这药多少钱? (zhè yào duō shǎo qián?) — 이 약 얼마예요?

### 건강 관리
- 多喝水 (duō hē shuǐ) — 물 많이 드세요
- 多休息 (duō xiū xi) — 푹 쉬세요
- 早点休息 (zǎo diǎn xiū xi) — 일찍 쉬세요
- 别熬夜 (bié áo yè) — 밤새지 마세요
- 多运动 (duō yùn dòng) — 운동 많이 하세요
- 少吃油腻 (shǎo chī yóu nì) — 기름진 거 적게 드세요
- 戒烟 (jiè yān) — 금연하세요
- 戒酒 (jiè jiǔ) — 금주하세요

## 7. 한국어와 차이점 (Key Differences for Korean Learners)

### 1. "아프다" = 疼 (téng) — 동사/형용사 겸용
| 한국어 | 중국어 | 비고 |
|--------|--------|------|
| 머리가 아프다 | 头疼 (tóu téng) | 머리 + 아프다 |
| 배가 아프다 | 肚子疼 (dù zi téng) | 배 + 아프다 |
| 이가 아프다 | 牙疼 (yá téng) | 이 + 아프다 |
| 목이 아프다 | 嗓子疼 (sǎng zi téng) | 목 + 아프다 |

> **핵심**: 疼 (téng) = 동사 "아프다" / 형용사 "아픈" 겸용

### 2. "열나다" = 发烧 (fā shāo)
- 发 (fā) = 나다, 발생하다
- 烧 (shāo) = 열, 불타다
- 发烧 (fā shāo) = 열이 나다 (발열)

### 3. "감기" = 感冒 (gǎn mào)
- 感 (gǎn) = 느끼다/감지하다
- 冒 (mào) = 덮다/거스르다
- 感冒 (gǎn mào) = 감기 (풍한/한기 맞음)

### 4. 신체 부위 + 疼 (téng) 패턴

## 9. 한국어 학습자 필수 팁 (Key Tips for Korean Learners)

### 1. 疼 (téng) = 아프다 — 동사/형용사 겸용
- 我头疼 (wǒ tóu téng) — 머리가 아파 (주어+동사)
- 我头很疼 (wǒ tóu hěn téng) — 머리가 매우 아파 (很 + 형용사)
- 疼 (téng) 단독 사용 가능: "疼!" = "아파!"

### 2. 发烧 (fā shāo) = 열나다
- 发 (fā) = 나다/발생하다
- 烧 (shāo) = 열/불타다
- 我发烧了 (wǒ fā shāo le) — 열이 났어요 (了 = 상태 변화)

### 4. 疼 vs 痛 (tòng)
- 疼 (téng) = 아프다 (일상, 구어)
- 痛 (tòng) = 통증/아픔 (명사, 더 격식/의학)
- 疼痛 (téng tòng) = 통증 (의학 용어)
- 痛楚 (tòng chǔ) = 고통/아픔 (문어)

### 5. 약 복용 빈도 (Medicine Frequency)
| 한국어 | 중국어 | 비고 |
|--------|--------|------|
| 하루 3번 | 一天三次 (yī tiān sān cì) | 하루 세 번 |
| 식후 30분 | 饭后半小时 (fàn hòu bàn xiǎo shí) | 식후 30분 |
| 식전 | 饭前 (fàn qián) | 식전 |
| 식후 | 饭后 (fàn hòu) | 식후 |
| 자기 전 | 睡前 (shuì qián) | 자기 전 |
| 빈속에 | 空腹 (kōng fù) | 빈속에/공복에 |

## 10. 한국어 학습자 주의 (Pitfalls)

| 실수 | 올바른 표현 | 설명 |
|------|-------------|------|
| 머리 아프다 | 头疼 (O) / 头痛 (△) | 疼 = 일상, 痛 = 격식/의학 |
| 열나요 | 发烧 (O) / 有热 (X) | 发烧 = 열나다 표준 |
| 감기 걸렸어요 | 感冒了 (O) / 得感冒 (△) | 感冒 + 了 = 걸렸어요 |
| 약 먹어요 | 吃药 (O) / 喝药 (X) | 약 = 吃 (먹다), 물약도 吃 |
| 주사 맞아요 | 打针 (O) / 打针了 (△) | 打针 단독으로 충분 |
| 병원 가요 | 去医院 (O) / 看病 (△) | 看病 = 진찰받다, 去医院 = 병원 가다 |
| 입원해요 | 住院 (O) / 住院了 (△) | 住院 단독으로 입원하다 |
| 퇴원해요 | 出院 (O) | 出院 = 퇴원하다 |

## 11. 문화적 배경 (Cultural Notes)

### 1. 중의학 (Traditional Chinese Medicine - TCM)
- 中医 (zhōng yī) = 중의학/한의학
- 中药 (zhōng yào) = 한약/중약
- 针灸 (zhēn jiǔ) = 침구/침술+뜸
- 拔罐 (bá guàn) = 부항
- 刮痧 (guā shā) = 괄사
- 推拿 (tuī ná) = 추나 (마사지/수기요법)

### 2. 병원 문화

- 普通号 (pǔ tōng hào) = 일반 진료

- 急诊 (jí zhěn) = 응급진료/응급실
