## 1. 标准商务邮件结构

### 1.1 邮件要素

| 要素 | 格式规范 | 示例 |
|------|----------|------|
| 主题行 | [项目/事项] - [动作:汇报/申请/确认/通知] - [姓名/部门] | 【Q3营销计划】- 申请审批 - 张三/市场部 |
| 称呼 | 尊敬的 [职称/姓名] / 各位同事好 / [职称] 您好 | 尊敬的李总 / 王经理您好 / 各位同事好 |
| 开头 | 邮件正文第一段：背景/目的（1-2句） | 关于Q3营销推广预算申请，现汇报如下： |
| 正文 | 核心内容/数据/附件说明（分点陈述） | 1. 预算总额 500万... 2. 预计ROI 1:3.5... 3. 附件为详细预算表 |
| 结尾 | 下一步行动/需对方协助/截止时间 | 请李总于周五前审批，如有疑问随时联系。 |
| 落款 | 此致 / 敬礼 / 顺颂商祺 / 祝工作顺利 | 此致 敬礼 |
| 署名 | [姓名] / [职称/部门] / [电话/微信] / [日期] | 张三 / 市场部高级经理 / 138-0000-0000 / 2026-08-12 |

| 场景 | 中文标准句式 | 英文对照 |

### 2.2 微信职场礼仪

| 场景 | 做法 | 禁忌 |
|------|------|------|
| 加同事微信 | 备注：公司-部门-姓名 | 无备注/昵称奇怪 |
| 发语音 | 先问"方便听语音吗？" / 文字优先 | 直接发60秒长语音，尤其是群里 |
| 回复消息 | 收到回"收到"/"好的"/👍 | 已读不回/隔天回 |
| 请假/报销/审批 | 走企业微信/钉钉/飞书流程 | 只发微信不走系统 |
| 群发通知 | 用"群公告"或@所有人 | 刷屏/无关转发/表情包刷屏 |
| 下班后 | 非紧急不发/延时发送(定时发送) | 深夜发"在吗"非紧急事 |

### 2.3 常用微信回复

| 中文 | 场景 |
|------|------|
| 收到，好的。 | 确认收到任务/通知 |
| 明白，马上处理。 | 确认并立即行动 |

## 3. 常用办公模板

### 3.1 请假申请（微信/企业微信/邮件）

```
【请假申请】- [姓名] - [部门] - [日期]
事由：[年假/病假/事假/婚假/产假/陪产假/丧假]
时间：[开始日期 时间] - [结束日期 时间] 共 [天数] 天
交接人：[同事姓名/工号] 已确认交接事项：[简述]
联系方式：请假期间电话/微信保持畅通
审批：请 [直属领导姓名] 审批
```

### 3.2 报销申请

```
【报销申请】- [姓名] - [部门] - [月份]
项目：[差旅/招待/办公用品/培训/设备采购]
金额：¥[总金额] (含税)
明细：
1. [日期] [项目名称] ¥[金额] - [备注：发票号/事由]
2. ...
附件：发票原件/电子发票PDF/行程单/合同复印件
经办人：[姓名] 审批人：[领导姓名]
```

### 3.3 周报/月报汇报

```
【周报】- [姓名] - [部门] - [第X周 YYYY.MM.DD-YYYY.MM.DD]
一、本周完成工作
1. [项目A] - [进度/产出] - [关键数据/结果]
2. [项目B] - [进度/产出] - [关键数据/结果]
二、遇到的问题/风险
1. [问题描述] - [影响] - [已采取措施/需支持]
三、下周重点计划
1. [任务1] - [预计产出] - [截止时间]
2. [任务2] - [预计产出] - [截止时间]
四、需协调/支持事项
- [事项] - [需协调部门/人员] - [期望完成时间]
```

### 3.4 会议邀请/纪要

**邀请：**
```
【会议邀请】[会议主题] - [日期] [时间] - [地点/腾讯会议/飞书会议号]
参会：[姓名1/姓名2/...] 抄送：[知情人]
议程：
1. [议题1] - [汇报人] - [预计时长]
2. [议题2] - [汇报人] - [预计时长]
资料：[会前阅读材料链接/附件]
备注：请提前5分钟入会/测试音视频
```

**纪要：**
```
【会议纪要】[会议主题] - [日期] [时间]
参会：[姓名1/姓名2/...] 缺席：[姓名] 记录：[记录人]
决议事项：
1. [决议内容] - [执行人] - [截止时间]
2. [决议内容] - [执行人] - [截止时间]
待办事项：
1. [事项] - [负责人] - [截止时间]
下次会议：[日期时间/暂定]
```

## 6. 离职/入职流程

### 入职

| 环节 | 关键动作 | 备注 |
|------|----------|------|
| Offer谈薪 | Base/绩效/年终/期权/签字费/入职礼包 | 薪资结构确认书签署 |
| 背调 | 学历/工作经历/离职原因/薪资/征信 | 第三方背调/HR电话核实 |
| 体检 | 指定医院/项目/报告 | 入职前1周完成 |
| 签合同 | 劳动合同/保密协议/竞业限制/IP归属 | 试用期1-6个月，法律上限6个月 |
| 入职办理 | 工牌/邮箱/权限/工位/设备/社保公积金开户 | 入职首日/首周完成 |

### 离职

| 环节 | 关键动作 | 备注 |
|------|----------|------|
| 提离职 | 书面/邮件/系统提交 | 提前30天(试用期3天)，注明最后工作日 |
| 交接 | 文档/代码/账号/客户/资产/密钥 | 交接清单双方签字，录屏/文档留痕 |
| 离职面谈 | HR/领导谈话 | 真实离职原因/建议/保密提醒 |
| 结算 | 工资/年假折现/年终奖/期权/报销 | 离职后15个工作日内结清 |
| 社保公积金 | 减员/封存/转移 | 离职次月办理，新单位入职后增员/转移 |
| 离职证明 | 劳动合同解除证明 | 必须开具，含入职/离职日期/岗位/薪资 |
| 离职证明 | 劳动合同解除证明 | 必须开具，含入职/离职日期/岗位/薪资 |

## 7. 薪资结构/福利

| 项目 | 说明 | 注意点 |
|------|------|--------|
| 基本工资 | 月固定部分 | 缴纳社保公积金基数 |
| 绩效奖金 | 月度/季度/半年/年度 | 考核挂钩，可能不发 |
| 年终奖 | 13薪/14薪/16薪/项目奖金 | 春节前发放，离职前发放比例 |
| 股票期权 | 行权价/行权期/分批行权/锁定期 | 上市公司/独角兽/期权池 |
| RSU | 限制性股票单位 | 归属后自动发放，税务处理 |
| 五险一金 | 养老/医疗/失业/工伤/生育/住房公积金 | 缴纳基数/比例/上下限 |
| 补充医疗 | 大额医疗/门诊/牙科/体检 | 免赔额/报销比例/封顶线 |
| 补充公积金 | 企业额外缴纳 | 税前扣除 |
| 年假 | 法定5-15天/公司额外给 | 入职满1年享受，带薪 |
| 病假/事假/婚假/产假/陪产假/丧假 | 法定/公司补充 | 需证明材料 |
| 补充商业保险 | 意外/重疾/寿险/住院医疗 | 保额/保费/受益人 |
| 午餐补贴/交通补贴/通讯补贴/房补 | 现金/实物/卡券 | 免税额度/发放方式 |
| 高温补贴/采暖补贴/独生子女费 | 地区/政策差异 | 按当地标准 |
